# 国男志 · 纯文档仓（A Gentleman's War Docs）

本仓是**白机工作区与发布副本**，只放《国男志》的设计/调研/技术/美术文档与 AI 交接单。
**代码、Unity 工程、贴图、构建产物全部不在本仓**——它们只在黑机全量仓 `G:\A Gentleman's War`（无远程）。

- 白机：只在本仓改 `docs/`、`.ai/`、`AGENTS.md`、`CHANGELOG.md`、`README.md`，然后 pull/commit/push
- 黑机：在全量仓工作；开工 `tools/sync-docs-repo.ps1 pull`（本仓→全量），收尾 `push`（全量→本仓→GitHub）
- 本仓与黑机全量仓每次同步后一致；README 两仓各自维护，不参与自动同步
- 仓库：<https://github.com/chen136523510/A-Gentleman-s-War>
