## 五、双机协作、工程锚点与防踩坑

**协作节奏**：黑机开工 `sync-docs-repo.ps1 pull` → 收尾 commit 本仓 + `push`；白机只在文本仓改文档、提交前缀 `[docs]`；禁止给全量仓配 remote；过程件进 `tmp/`，**成品模拟脚本进 `sim/`（入库，黑白机共用）**。

**交接单纪律（院长 11-13 第 8 条）**：handoff "待裁"只列**未裁项**；裁定当回合即落专题文档、从待裁移除并进"已裁登记"；黑白机 commit/push 后以文本仓为准，**黑机全量仓 pull 后必须同步 handoff**，避免已裁项反复出现在待裁列表。

**工程锚点**：
- L1：L1Map.unity + L1MapBuilder/GameState/SimulationRunner/SmokeTestRunner；自检=AGW/数值自检·200 回合模拟、AGW/烟雾测试、AGW/BatchBuildTest；构建 AgwMenu.BuildOnly。
- L2：tools/l2planner（plan.js + bake_terrain.py + bake_buildings.py + bake_city.py）；数据 Assets/_Project/Data/L2/{city}/map.json；Unity `Scripts/L2/`；菜单 `AGW/L2 预览（深圳）`。
- 模拟：**`sim/v22/full.js`（基准，node 直接跑；A1 外交意图机已接入）**；历史脚本待黑机迁 `sim/v21/`；`tmp/` 只放过程件。
- 建造：Scripts/L1/ConstructionSystem.cs（城级多队列）；兵营初始 5 城。

**防踩坑**：①`status:"draft"` 不参与结算，接入须翻状态+全量盘；②升级不变占地=铁律；③模拟必须同算粮+战争；④changelog/bug-log 只读顶部索引；⑤commit 格式 `[feat|fix|refactor|chore|docs](模块): 动作及意图`；⑥参数纪律：常数入 balance.json 禁内联；⑦数值自治：数值不列待裁，模拟闭环；⑧ComfyUI 生图 GPU 必须独占；FLUX 纹理上限 768²；⑨样张验收走"截全图→视觉自评→修→复验"；⑩Unity 编译有锁，多 agent 不得并行 batchmode；⑪**v17a~v21 是旧尺度，全部作废**，v22 是唯一基线；⑫L2 整图烘焙 32 px/tile≈3072²，建筑不进底图；⑬武将加成按**建筑级**结算（Q1），禁止"城市轴聚合"；⑭**参数定稿必须回写模拟器**（BUG-G013：文档 2.5、模拟 4.0）；⑮**数值卡效果必须能在主公式找到落点**（BUG-G014：医院增速白写）；⑯**长局数值验 200 回合终点**；⑰**新专题文档闭环后一次进盘**（院长 11-12：防连锁返工）；⑱**白机能跑盘自己跑**，黑机只落库/工程；⑲**3D 三阶段**：基础版网页（可旋转）→ 进阶版地图 → 归档版 exe；先批量过基础版，未过不得进地图/exe；城市地形差异化、通用建筑不做差异化（院长 11-12）。⑳**Blender 批量 runner 必须逐座 purge 场景**（ASSET/CTX 清空+孤儿数据回收）——否则多座叠加污染 blend/渲染/导出（11-13 踩过）。㉑**网页画廊 >16 个 WebGL iframe 会超浏览器上下文上限**（旧上下文被丢弃变黑格）——大区画廊用缩略卡（Cycles 渲染图）+跳转独立页（11-13 定）。㉒**Agent 会话 token 成本 ≈ 请求数 × 平均上下文**（11-13 实测：100 请求 × 16.6 万 = 1664 万 token，lite 5h 套餐 96.7%；缓存 96.9% 只省单价不省额度）——**重工程会话必须拆窗口**（一专题一窗），单窗口上下文 >15 万即收尾；大文件用 Explore 子 agent、长跑盘输出落 `tmp/` 只取关键行。㉓**building Status 三态口径**（11-14 起）：`draft`=不参与结算/不可建、`active`=已翻正参与结算可建、缺省=引擎已消费——引擎判断一律 `=="draft"` 才拦（旧口径"非空即拦"会误拦 active 卡）；**新卡翻正用 `status:"active"`，不要删字段**。㉔** Unity 数据文件是 indent=1（buildings/balance）与 indent=2（cities/factions/officers）两种缩进**——脚本回写 JSON 必须先探原缩进，整文件 re-dump 缩进不符会产生千行假 diff（11-14 踩过两次，靠 `git checkout` 回滚救回）。
