# 事件

> 权威源：[06-事件/](../../06-设计/06-事件/)（**事件卡专题 v0.2 讨论稿（定位/时点/卡面）**、事件卡总表 v0.2、起义、天灾与异族、民生与消费事件）· 同步日期：2026-11-19 · 状态：**📝 事件卡专题 v0.2（院长 8 条口径已落；定位待院长确认）；机制类多数已定**

## 一句话

事件分两层：**剧情事件**（教程/剧本脚本，固定触发，如教程 WLT 自立 t2）和**普通事件**（游戏机制下自然产生、符合玩家预期、可推算，如自由沙盒某城自立/起义/外逃/事件卡）。卡名必须是历史事件/专有名词，不能是"税收 +10%"。

**事件卡的作用**（除丰富剧情/触发机制）：①状态可读化（把民生/战争/增长翻译成可见的局部变化）②短期策略窗口（改变局部最优，诱导经营调整）③给政策卡等对冲工具创造需求 ④机制自动调节（低民生缓冲/战后恢复/高福利挑战）；叙事沉浸为次要。

**事件卡=普通事件的社会经济子类**（2026-11-19 院长定位）：按规则层状态公式触发、可推算，不是剧情、不是黑箱随机；玩家不可触发/取消，只能政策对冲。

## 关键规则

```
① 频率：全局同时最多 1 张"卡"；同卡冷却按卡配置（视情况而定；当前 40/50/60）；
   两张卡间全局至少 10 回合（保留，后续细讲）；200 回合内同类 1~3 次
② 随机性：条件满足后按 triggerChance 每回合掷骰（不是满足即触发）
③ 时点：过回合时出现（事件条+驻城武将汇报，数值不变）→ 下回合开始结算
   （出现≠结算，2026-11-19 院长令）
④ 数值展示：卡面只显示变化项；主数字=当前城实际 ±（不是写死百分比）
   Δ = 当前值 × (倍率 − 1)
⑤ 唯一事件（王乐添自立）一局一次，固定触发；教程版=剧情事件、沙盒版=普通事件
⑥ 事件卡判定粒度：全局每回合至多 1 次（多城满足→随机选 1 城掷骰）——待裁
⑦ 效果封顶：同类总倍率 ±50%；民生/治安偏置累计 ±5；只乘/偏置已有量（禁虚空产出）
```

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| 2026-11-19 | **事件两层定位**：剧情事件（教程/剧本）vs 普通事件（机制自然产生、可推算）；事件卡归普通事件 | 剧情事件固定触发不可推算；普通事件必须可从状态推算，否则玩家无法预期 |
| 2026-11-19 | **时点：过回合时出现、下回合开始结算**（出现≠结算） | 触发与结算分离，玩家先看到事件再承受数值 |
| 2026-11-19 | **冷却视情况而定**（逐卡配置，不设统一区间）；两张卡间 ≥10 回合先保留 | 卡少不好评判，后续细讲 |
| 2026-11-19 | **卡面只显示变化项** | 减少信息噪音，玩家只看实际影响 |
| 2026-11-19 | **事件卡专题 v0.2**：四通道数据落点/触发 DSL/落点挂主公式/3 卡定稿表/天灾二期接口 | 统一模板与落点，事件卡不再是散落特例 |
| 2026-11-02 | 卡名必须用**专有名词/历史事件** | "玩家看到名字就知道大概是什么"；不用数值当卡名 |
| 2026-11-02 | 事件**低频+条件**，不是每回合随机刷 | 稀有、具体、有名 |
| 2026-11-02 | 只保留已有机制 + 3 张商业卡 | 绿色革命/婴儿潮等宽泛事件不符合定位 |
| 2026-11-02 | 事件卡专题**另立项**，不随专题回溯补卡 | 避免专题串味 |

## 易踩的坑

1. **不要写"每回合随机 1%"**——必须有明确触发条件（民生/战争/忠诚/人口/科技/建筑）。
2. **起义/叛乱只看忠诚度**，民生只是间接影响（0.55 权重）。
3. 天灾/异族不是"卡"，是低频压力事件，不参与卡池。
4. **事件卡不改基础公式**：消费池 2.5×K_desire 不动，低欲望 = 临时事件乘区；效果无落点不进卡（BUG-G014）。
5. **剧情事件与普通事件不混用通道**：教程 WLT 自立=EventScript；沙盒某城自立=起义机制产物；同一名字按剧本配置区分。
6. **出现≠结算**：过回合只判定+出现（数值不变），下回合开始才结算；pending 状态必须入档。
