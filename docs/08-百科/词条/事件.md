# 事件

> 权威源：[06-事件/](../../06-设计/06-事件/)（事件卡总表/起义/天灾与异族/民生与消费事件）· 同步日期：2026-11-10 · 状态：**📝 v0.1 整理中**（事件卡专题未立项；机制类多数已定）

## 一句话

两类东西：**机制类**（起义/自立/外逃/天灾/异族，按各自规则触发）和**事件卡**（低频、有专有名词、有条件）。卡名必须是历史事件/专有名词，不能是"税收 +10%"。

## 机制类（已定）

| 名称 | 触发 | 效果 | 状态 |
|---|---|---|---|
| **王乐添自立** | 第 2 回合固定；台北+王乐添 | 台北→WLT；CN 关系 −20；城防军 30% 转民兵 | ✅ 定（唯一事件，一局一次） |
| **起义** | 忠诚 <30 连续 3 回合（普通城） | 驻军倒戈、整城变中立；人口/兵损失 | ✅ 定 |
| **叛乱** | 忠诚 <20 连续 10 回合；f≥75% | 外籍叛军攻防；胜=归母国/复国 | 🏗️ 草案 |
| **围城断供** | 敌军城外驻扎围城 | 粮食/民生/驻军损耗 | 🏗️ 草案 |
| **难民接收** | 战争/灭国产生难民 | 人口+、外籍比例+、民生冲击（上限 30） | 🏗️ 草案 |
| **天灾**（沙尘暴/台风/海啸/地震） | 城/区域+概率；提前 5 回合预告 | 宜居/人口/设施损失 | 🏗️ 二期 |
| **核泄漏** | 核电站失修/被攻破 | 本城宜居 −30、邻城 −10（3 回合衰减） | 🏗️ 二期 |
| **异族入侵** | 50 回合波次；提前 5 回合明牌 | 强度=全图平均军力×0.6 | 🏗️ 二期 |

**难民冲击公式**：`冲击值 = 难民规模 / 本城人口 × 系数`（上限 30 民生）；要收全收，不能部分接收。

## 关键规则

```
① 频率：全局同时最多 1 张"卡"；同卡冷却 40~60 回合；200 回合内同类 1~3 次
② 随机性：条件满足后按 triggerChance 每回合掷骰（不是满足即触发）
③ 明牌：触发前 1 回合驻城武将汇报预警；不做暗判
④ 数值展示：卡面显示当前城实际 ±（不是写死百分比）
   Δ = 当前值 × (倍率 − 1)
⑤ 唯一事件（王乐添自立）一局一次，固定触发
```

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| 2026-11-02 | 卡名必须用**专有名词/历史事件** | "玩家看到名字就知道大概是什么"；不用数值当卡名 |
| 2026-11-02 | 事件**低频+条件**，不是每回合随机刷 | 稀有、具体、有名 |
| 2026-11-02 | 只保留已有机制 + 3 张商业卡 | 绿色革命/婴儿潮等宽泛事件不符合定位 |
| 2026-11-02 | 事件卡专题**另立项**，不随专题回溯补卡 | 避免专题串味 |

## 易踩的坑

1. **不要写"每回合随机 1%"**——必须有明确触发条件（民生/战争/忠诚/人口/科技/建筑）。
2. **起义/叛乱只看忠诚度**，民生只是间接影响（0.55 权重）。
3. 天灾/异族不是"卡"，是低频压力事件，不参与卡池。
