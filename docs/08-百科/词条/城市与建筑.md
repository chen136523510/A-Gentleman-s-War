## 一句话

六区域（农业/工业/商业/学院/文化/军事基地）+ 居民楼 + 市政设施；所有建筑走同一套自洽基准（生产=20×工期、财=4.5×生产、维护 1%、升级^1.4），**升级不新增占地**是铁律。

## 核心公式

```
① 建筑自洽基准
   生产 = 20 × 工期（2~6 回 → 40~120）
   财 = 4.5 × 生产
   维护 = 造价 × 1%/回
   升级成长 = 等级^1.4
② 建造队列（v2 多队列制，11-05 裁）
   多队列排队；产能按序投送；一回合可连完多个；溢出储备与财买保留
   工程占 1 条，不再独占全城
③ 电力（工业区）
   城市级电力 + 电力运输；停电托底
④ 岗位/服务人口（双维度）
   岗位 = 建筑提供的就业；服务人口 = 能服务的人口上限
   覆盖强度 c = min(1, Σ服务人口/城市人口)
⑤ 消费池（商业/文化）
   城消费力池 = 民用人口/1000 × 2.5（城市级，不设全国池）
   份额：零售 60% / 娱乐 25% / 文旅 15%，缺类归一回流
⑥ 城市热度（文化）
   热度 = 10 + 城文化产出×0.8 + 陈列文物×1.2 + 事件；污染/战争/占领/起义衰减
   五档：寂寂无闻/初露锋芒/声名远扬/名扬四海/万邦来朝
⑦ 区域与城市
   六区域 + 城墙 + 资源 + 驻守城态（正常/空虚/起义）
```

### ⑩ NPC 武将培养机制（11-09 定向；细则归武将专题）

```
① 玩家想要某系人才（如军事系）
② 前提 = 该城已建对应产出建筑（军事=战争学院 / 商业=商学院 / 科技=未来技术学院 / 文化=传媒大学 / 政治=市政府）
③ 在该建筑内触发"人才培养"（建筑=培养入口与场所）
④ 建筑展示可培养的候选池（属性各异的 NPC 列表）
⑤ 玩家从候选池选 1 名开始培养（消耗资源+时间；同一时间全局仅 1 个培养位）
⑥ 完成 = 获得 NPC 武将
```

> ⚠️ 防坑：**玩家自选的是"建筑"不是人才**——不是全局人才市场直接挑人；无对应建筑就无法培养该系；候选池由建筑提供（三国志 12 威力加强版式）。

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| B1 | 四条自洽基准（生产/财/维护/等级） | 全建筑同一套数值语言 |
| 11-05 | 建造队列 **v2 多队列** | 单队列在大城瓶颈；一回合可连完多个 |

| 11-05 | 升级不新增占地 | 铁律（L2 落格） |

## 易踩的坑

1. **升级不新增占地**是铁律——L2 落格时不要按等级扩地。
2. **岗位 ≠ 服务人口**：岗位是就业，服务人口是覆盖能力，两列分开。
3. 覆盖圈口径已作废（旧表 §3.8），现用服务人口覆盖强度 c。
4. 文化/商业建筑数值仍是**草案**，定稿前勿写入 `buildings.json`。
