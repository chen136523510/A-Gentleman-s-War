# 典藏

> 权威源：[典藏专题开题.md](../../06-设计/03-内政/典藏专题开题.md) / [典藏文物池-CN候选.md](../../06-设计/03-内政/典藏文物池-CN候选.md) · 同步日期：2026-11-05 · 状态：**🏗️ v0.7（CN 6 件定稿，机制已定，全表未定完）**

## 一句话

国家持有的**独一无二**物件系统；持有即吃常驻效果，部署到博物馆/赐予武将再叠加额外效果；不做价值分类、不做件间平衡、不影响主系统。

## 核心模型

```
三组效果可叠加（11-05 院长 3 样例确立）
  passive（常驻）：持有即生效，国家级
  display（陈列）：放本城博物馆时额外生效，城市级
  grant（赐予）  ：给武将时额外生效，武将级
  同一件不能同时陈列和赐予

归属三规则
  陈列随城 / 武将持有随武将 / 国库随国

收回铁律
  revokePenalty > grant.loyalty（保底 ×1.5）——防"送了又收"刷忠诚

考古
  遗迹=开局城市数据字段（每城 1~5 件；院长定深圳仅 1 件）
  博物馆详情页发起；每城 1 条独立队列；80 财/约 3 回
  同时发掘数=博物馆等级；Lv2 会展才显示剩余遗迹

身份归属
  无价值分类（无 tier）；不提供城市热度；不做主动脉冲（CD 技能）；系列彩蛋暂缓
```

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| 11-04 | 定名「典藏」 | "国库"已被 B12 财政占用 |
| 11-05 | **不做价值分类** | 每件独一无二，档位反而公式化 |
| 11-05 | **三组效果可叠加** | 院长 3 样例都是三组俱全 |
| 11-05 | **归属三规则** | 掠夺有叙事，不做概率夺宝 |
| 11-05 | **收回惩罚 > 赐予** | 防刷忠诚 |
| 11-05 | **不提供热度 / 不做主动脉冲 / 系列暂缓** | 热度已有体系；主动技是调研引入非项目需求 |
| 11-05 | **风味优先**，不做件间平衡 | 每件独立数值+故事钩子 |
| 11-05 | 门槛类参数必须可追溯 | 势差门槛从 3000 改为"文化建筑≥1" |

## 易踩的坑

1. **常驻是"持有即生效"**，不是"部署才生效"。
2. **同一件不能同时陈列和赐予**——但常驻始终生效。
3. 台积电那类**质变型常驻**需要系统字段支持（科技树 `nodeCostMultiplier`）。
4. 赐予效果按件独立配置（有的只加忠诚不加属性）。
