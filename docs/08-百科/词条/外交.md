# 外交

> 权威源：[外交行动.md](../../06-设计/05-外交/外交行动.md) / [关系规则与LLM.md](../../06-设计/05-外交/关系规则与LLM.md) · 同步日期：2026-11-05 · 状态：**🏗️ v0 数值已立待院长认**（专题未开；一期规则判定+模板话术，不接 LLM）

## 一句话

关系值 R（−100~+100）驱动的规则型外交：同盟/停战/劝降/共同防御/贸易协定/资源采购/核武惩罚；AI 按"收益>阈值"接受。

## 核心公式

```
① 关系值 R：−100 ~ +100（初始 0；四阵营互为对手，无同阵营加成）
   事件增量：共同敌人交战 +10/次｜贸易协定 +3/回｜破弃 −40｜掠夺其城 −25
            俘虏处决 −30｜共同防御期 +20
② 行动成功率 = 基础值 + 关系修正 + 筹码修正 + 属性修正（钳 5%~95%）
   同盟（R≥+60）：20% + R×0.5% + 筹码(每500财+5%，上限+25%) + 使者政治×0.3%
   停战：40% + R×0.4% + 筹码(双方疲惫 +15%)
   劝降：(综合值−1.0)×80%，钳 5~90%
③ AI 接受：iff（关系收益 + 资源收益 + 安全收益）> 阈值(难度参数)
④ 资源采购谈判（外交官）
   谈判分 = clamp(0.30 + 使者政治/200 + (R+100)/400 + 合同期/50 + 筹码修正, 0, 1)
   成交价 = 参考价 × (1.5 − 0.5×谈判分)      // 1.0~1.5×
⑤ 核武惩罚（R33）
   发展核武：全阵营谴责，声誉 −15，文化输出 −10%
   发射核武：关系 −100（宣战级）；文化输出全矩阵归零级衰减（长期难恢复）
⑥ 自立新阵营（WLT）
   初始声望 10、关系全 −20（叛徒 debuff）；招降时声望要求 ×0.5
```

## 易踩的坑

1. **关系值是双向的**：掠夺其城 −25 是"被掠夺方对掠夺方"的关系。
2. **核武不动民生**（R33 修正）——不要写成"本国民生 −20"。
3. 外交官不是新单位，是武将的**额外身份**，保留原职。
