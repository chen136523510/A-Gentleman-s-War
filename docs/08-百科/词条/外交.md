> **AI 摘要**：关系值 R（−100~+100）驱动规则型外交；**弃权不算同意、同意严格过半**（5→3/4→3/3→2/2→2）；战争制裁全员参与、经济/裁军同意+弃权参与；义务卡违约=撕毁（rep −3/关系 −15/−8/CB 按提案）；政策卡关系声誉流 ±0.15~0.3/回 + 存量饱和衰减（v26 v1.2）；`perfidy` 缺省 0（初始 21 将无无信人格）。

## 一句话

关系值 R（−100~+100）驱动的规则型外交：同盟/停战/劝降/共同防御/贸易协定/资源采购/核武惩罚；AI 按"收益>阈值"接受。

## 核心公式

```
① 关系值 R：−100 ~ +100（初始 0；四阵营互为对手，无同阵营加成）
   事件增量：共同敌人交战 +10/次｜贸易协定 +3/回｜破弃 −40｜掠夺其城 −25
            俘虏处决 −30｜共同防御期 +20
② 行动成功率 = 基础值 + 关系修正 + 筹码修正 + 属性修正（钳 5%~95%）
   同盟（R≥+60）：20% + R×0.5% + 筹码(每500财+5%，上限+25%) + 使者政治×0.3%
   停战：40% + R×0.4% + 筹码(双方疲惫 +15%)
   劝降：(综合值−1.0)×80%，钳 5~90%
③ AI 接受：iff（关系收益 + 资源收益 + 安全收益）> 阈值(难度参数)
④ 资源采购谈判（外交官）
   谈判分 = clamp(0.30 + 使者政治/200 + (R+100)/400 + 合同期/50 + 筹码修正, 0, 1)
   成交价 = 参考价 × (1.5 − 0.5×谈判分)      // 1.0~1.5×
⑤ 核武惩罚（R33）
   发展核武：全阵营谴责，声誉 −15，文化输出 −10%
   发射核武：关系 −100（宣战级）；文化输出全矩阵归零级衰减（长期难恢复）
⑥ 新阵营诞生（如剧情事件「自立门户」的 WLT；自然自立已删 2026-11-26）
   初始声望 10、关系全 −20（叛徒 debuff）；招降时声望要求 ×0.5
```

## 已定稿（原"待办"项 11-20/11-24 补齐）

- **提案与加入**（~~联合国投票/常任理事国~~已删 11-27）：提案**去中心化**——任一阵营发起、面向阵营逐国邀约、各自选择是否加入（加入制裁=断贸易、加入反法西斯=参战）；义务类提案（环保/裁军/核）加入方挂义务卡，撕毁义务=授予对方战争借口。详见[战争与提案流程细则](../../06-设计/05-外交/战争与提案流程细则.md)。
- **外交义务卡（Mandate）**：提案通过→发卡带 `mandatory`→义务期 N 回合必须挂；不挂/中途卸=**违约=撕毁**；后果=rep −3 / 关系 发起方 −15、同意方 −8 / CB 按提案配置（环保无、裁军有）；累进 100 回窗口 ×1.5→×2；负财强制通过 + 国库<100 → 获 100 财国际援助（虚空产出）。**落地状态=11-20 已落库 68 测试绿**。
- **无信人格 `perfidy`**：缺省 0（**初始 21 将全部 0**）；仅后续新增 NPC 按人设配置。
- **政策卡外交侧**：关系/声誉流全类 ±0.15~0.3/回 + 存量饱和衰减；绝对中立 `canDeclareWar=false` **只锁自身宣战**；外交政策**默认公开可见**（外交面板可查他国卡组，AI 据此反制）。
- **仍待**：外交 AI 决策层深化 / 会议余项 / 同盟深度（外交二期）；LLM 谈判（二期，JSON 闸门）；典藏国库件交易 AI 估值（B6 接口 C4）。

## 易踩的坑

1. **关系值是双向的**：掠夺其城 −25 是"被掠夺方对掠夺方"的关系。
2. **核武不动民生**（R33 修正）——不要写成"本国民生 −20"。
3. 外交官不是新单位，是武将的**额外身份**，保留原职。
