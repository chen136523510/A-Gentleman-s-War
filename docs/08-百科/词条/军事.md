# 军事（战斗与兵种）

> 权威源：[04-军事/](../../06-设计/04-军事/)（战斗总述/战斗类型/兵种与装备目录/操作与交互/内政战场联动/L3 战斗场景）· 同步日期：2026-11-05 · 状态：**🏗️ 框架已定，数值未定**（专题未开，是"军事排队"队列对象）

## 一句话

轻量 RTS（路径 C）：**一套战斗判定模型两档共用**——自动结算=自动档，L3 手动档只加渲染与指令层。胜负=攻方粮草定时限 + 市政府血条清零 + 陆战驻留占领。

## 核心机制（框架级，公式待设计）

```
① 胜负判定
   攻方赢：市政府血条清零 + 陆战驻留占领完成
   守方赢：拖到攻方粮尽 / 端掉攻方根据地
② 双档共用
   自动档 = 数值结算 + 文字战报
   手动档 = L3 战场（一期已含，R36）：市政府血条实体 + 占领读条 + 根据地实体
③ 双档参数映射
   粮草 → 结算回合上限
   血条 → 城防结算阶段
   驻留读条 → 终局占领判定参数
   根据地 → 守方反攻判定参数
④ 战斗类型（攻守城市对自动判定）
   内陆战 / 登陆战（深圳→台北等）/ 围城
⑤ 兵种（R34 钦定：古典步/骑/弓三系，推翻 R23 六底盘制）
   克制系数与质量 q 见 数值设计总纲 §4.4/§3.2
   装备四档谱系 T1~T4（老档长卖）
⑥ 核打击（R34）
   目标：城防 −50%、血条 −30%、驻军歼灭 40%、核残留 10 回合（产出 −50%/宜居 −30）
   进攻被核打击过 10 回合内的城：进攻方战力 −20%（核污染不分敌我）
   拦截：基础 30% + 反核科技（JP）+40% + 萨德城（首尔）+20%
⑦ 战俘
   带队角色随败兵概率被俘；全角色被俘=战役败；四处置（劝降/释放/拷打/处决）
```

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| R4 | 路径 C：轻量 RTS（非全战式） | 单机可玩性/成本 |
| R36 | **L3 手动档进一期**（推翻"一期仅自动结算"） | 手动战斗是三国志 12 之魂 |
| R34 | 兵种改**古典步/骑/弓三系**（推翻六底盘制） | 简化便于操作 |
| R27b | 战略层出兵与行军 | 战争不影响文化值、只影响输出 |

## 待办（军事专题开题时补）

- 数值结算公式（吃设施等级/科技/四维/兵力/城防）——**一期核心，尚未设计**
- 兵种具体数值/克制矩阵
- 行军时长/路线/口粮换算
- AI 出兵概率公式（军力/政策/国家性质三因子）
- **典藏掠夺执行时机**（B6 接口 C3）
- 城防 800 百分比制数值

## 易踩的坑

1. **两档不能写两套规则**——手动档只加渲染与指令层，判定内核同一套。
2. **数据一期就按二期战场实体建模**（设施等级/位置战场可读），避免两套数据。
3. 战争只清零文化**输出**，不动文化**存量**（R27b）。
