## 一句话

轻量 RTS（路径 C）：**一套战斗判定模型两档共用**——自动结算=自动档，L3 手动档只加渲染与指令层。胜负=**战役回合上限（粮草只定回合数，粮尽不判负）** + 市政府血条清零 + 陆战驻留占领。

## 核心机制（框架级，公式待设计）

```
① 胜负判定
   攻方赢：市政府血条清零 + 陆战驻留占领完成
   守方赢：拖到攻方粮尽 / 端掉攻方根据地
② 双档共用
   自动档 = 数值结算 + 文字战报
   手动档 = L3 战场（一期已含，R36）：市政府血条实体 + 占领读条 + 根据地实体
③ 双档参数映射
   粮草 → 结算回合上限
   血条 → 城防结算阶段
   驻留读条 → 终局占领判定参数
   根据地 → 守方反攻判定参数
④ 战斗类型（攻守城市对自动判定）
   内陆战 / 登陆战（深圳→台北等）/ 围城
⑤ 兵种（R34 钦定：古典步/骑/弓三系，推翻 R23 六底盘制）
   克制系数与质量 q 见 数值设计总纲 §4.4/§3.2
   装备点 EP + 装备率；质量走科技乘区（T1~T4 已移除）
⑥ 核打击（R34）
   目标：城防 −50%、血条 −30%、驻军歼灭 40%、核残留 10 回合（产出 −50%/宜居 −30）
   进攻被核打击过 10 回合内的城：进攻方战力 −20%（核污染不分敌我）
   拦截：基础 30% + 反核科技（JP）+40% + 萨德城（首尔）+20%
⑦ 战俘
   带队角色随败兵概率被俘；全角色被俘=战役败；四处置（劝降/释放/拷打/处决）
```

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| R4 | 路径 C：轻量 RTS（非全战式） | 单机可玩性/成本 |
| R36 | **L3 手动档进一期**（推翻"一期仅自动结算"） | 手动战斗是三国志 12 之魂 |
| R34 | 兵种改**古典步/骑/弓三系**（推翻六底盘制） | 简化便于操作 |
| R27b | 战略层出兵与行军 | 战争不影响文化值、只影响输出 |
| 11-06 | **军备移除**：军工厂→装备厂，军饷类系数制衡（T1~T4 档位第三轮移除） | 中间资源无手感，"军备不足"只有挫败 |
| 11-06 | **T1~T4 移除**：装备点 EP + 装备率 + 科技乘区 q_tech；建军四步 | 档位与科技树重复；6 类×4 档=24 变体太重 |
| 11-06 | **士气跟随部队**：单位级 m=60+修正，q_morale=0.8+0.4×m/100 | 士气落在具体部队上，战报可解释 |
| 11-06 | **战争状态机仅冷却 5 回硬性**，动员/行军/战役随时 | 不设强制前摇，节奏交给玩家 |
| 11-06 | **空军四裁**：a 全实体单位 / 统一部队制（无伤兵，击落=战损）/ 新增独立机场三级 / 制空权仅侦察视野 | 空军与陆军同概念，不另立体系；机场=战略点；空军不直接改地面数值 |

## 易踩的坑

1. **两档不能写两套规则**——手动档只加渲染与指令层，判定内核同一套。
2. **数据一期就按二期战场实体建模**（设施等级/位置战场可读），避免两套数据。
3. 战争只清零文化**输出**，不动文化**存量**（R27b）。
