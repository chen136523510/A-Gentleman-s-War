# 科技与终局

> 权威源：[科技树.md](../../06-设计/03-内政/科技树.md) / [学院区开题.md](../../06-设计/03-内政/学院区开题.md) / [胜利条件.md](../../06-设计/00-总纲/胜利条件.md) · 同步日期：2026-11-05 · 状态：**✅ 学院区+科技线 v1.0 定稿**（代码未实装）

## 一句话

三线（军红 / AI 蓝 / 民生绿）× 六时代 × 38 节点 + 3 个终极工程；**科技胜利 = 率先建成任一终极工程**（工程制，不是爬满树）。

## 核心结构

```
三线：
  军红线   —— 军事/装备/核
  AI 蓝线  —— 信息/智能/无人机
  民生绿线 —— 民生与环保（环境系统对策）

六时代 × 38 节点；3 终极工程：
  上帝之杖（军红）/ AGI 红皇后（AI 蓝）/ 人造太阳（民生绿）
  先建成任一 = 科技胜利

C0 = 500 + 时代乘数          // 科技节点成本基数
开局学院城 = 深圳 / 首尔 / 墨尔本 / 名古屋
```

## 学院区建筑（v2.5）

- **学校树**：集团高校 / 综合大学 / 艺术学院 / 军校 → 三级方向分化
- **图书馆两级**：国图（阵营唯一）+ 城市书屋
- **研究院树**：实验室（武将入驻激活）
- 文化直产：美院 12 / 传媒 10 / 艺术学院 10 / 影视 8 / 文理 7 / 图书馆 2 / 国图 8
- **传媒大学**：每城限 1，本城文化产出 ×1.10（11-05 改城市级乘区，不再全国叠加）

## 三胜利途径（R27b）

| 途径 | 判定 | 状态 |
|---|---|---|
| **统一** | 占领 13 阵营城（达尔文不计） | 纯规则判定 |
| **科技** | 率先建成任一终极工程 | 纯规则判定 |
| **文化** | 联合国成立→当选盟主→全部成员国完全入侵+维持 10 回 | 纯规则判定（见文化输出词条） |

- 外交胜利**并入文化链**，不独立成胜利。
- 胜利判定只读全局状态（城池归属/科技完成度/关系值/文化值）→ 一期判定即终局判定，二期无返工。
- **失败结局**：海平面 +1.5m 大陆陷落 = 所有阵营共同失败（环境词条）。

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| R30 | 政体选择制（非文明 6 演进）+ 科技影响文化 | 阵营对应现实政体 |
| 2026-11-03 | 科技树改**三线制 + 工程制胜利** | 爬树太慢；工程=可观测的终点 |
| 2026-11-05 | 传媒大学乘区改**本城 ×1.10** | 层级铁律：城市产出=城市级 |
| 2026-11-05 | 互联网民生乘数（双方解锁即生效） | "好的更好、差的更差"；电子长城政策可屏蔽 |

## 易踩的坑

1. **科技胜利不是爬满 38 节点**——是抢建一个终极工程，路线选择才是核心。
2. **传媒大学乘区只作用本城**，不是全国输出叠加。
3. 科技节点耗额可被典藏质变（台积电光刻机残骸：半导体节点耗额减半）——需 `nodeCostMultiplier` 字段。
