# 贸易

> 权威源：[贸易最小规则.md](../../06-设计/03-内政/贸易最小规则.md)（v0.2 财流版）· 同步日期：2026-11-05 · 状态：**⏸ v0.9 暂定**（随商业区暂停；待外交/B12 回改）

## 一句话

**民间贸易只有财**：玩家只看到"贸易收入 +N 财/回"一个数，不追踪货物、不记价格、不选航线；粮/铁/煤只在国内产需平衡，不进出口。

## 核心公式

```
① 伙伴贸易额 = 伙伴商业产出 × 0.10 × 关系系数 × 协定系数 × 国家贸易倾向
   关系系数 = clamp(0.50 + R/100, 0, 1.50)     // R −100~+100 → 0~1.5
② 国家贸易收入 = min( Σ伙伴贸易额, 贸易容量 )
③ 贸易容量（港口）：Lv1 50 / Lv2 80 / Lv3 110；保税线 Lv3「自由贸易港区」+20
   无港口 = 0（内陆阵营只能靠本阵营沿海城）
④ 超容量：按伙伴贸易额比例截断；UI 显示"贸易 50/50（容量满）"
```

## 关键参数

| 参数ID | 值 | 含义 | 出处 |
|---|--:|---|---|
| `tradePenetration` | 0.10 | 贸易渗透率（伙伴每 10 财产出→1 财贸易额） | ⚠️ 草案，模拟标定 |
| `tradeRelationBase` | 0.50 | 关系系数基础 | 🟡 v0.2 |
| `tradeRelationSlope` | 0.01 | 每点关系 | 🟡 v0.2 |
| `tradeRelationCap` | 1.50 | 关系系数上限 | 🟡 v0.2 |
| `tradeCapPortLv1/2/3` | 50/80/110 财/回 | 港口容量 | ⚠️ 草案 |
| `tradeCapFreePort` | +20 | 保税线 Lv3 | ⚠️ 草案 |
| `tradeMostFavored` | ×1.2 + 关系 +2/回 | 最惠（R≥+20） | 🟡 外交规则 |
| `tradeWarRetain` | 50%（R≥+60）/ 0 | 战时贸易线 | 🟡 同上 |
| `tradeEmbargo` | 0 | 禁运制裁 | 🟡 同上 |

**示例**：60k 伙伴商业净 328 → 伙伴贸易额 32.8 × 关系 1.0 × 最惠 1.2 = **39.4 财/回**；两个伙伴 ~79，Lv1 港口容量 50 → 截断到 **50 财/回**。

## 三档协定

| 协定 | 门槛 | 效果 |
|---|---|---|
| 民间通商 | R≥0 | 自动财流，无加成（默认） |
| 最惠贸易 | R≥+20 | 该伙伴贸易额 ×1.2；关系 +2/回 |
| 禁运制裁 | 同盟级/会议 | 该伙伴贸易额 = 0 |

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| 2026-11-02 | **民间贸易只体现为财**（院长 #3） | 避免玩家在"粮够不够/铁够不够/价格多少"之间做微观管理 |
| 2026-11-02 | 粮/铁/煤**不进出口**，只国内产需平衡 | 同上 |
| 2026-11-02 | 资源采购（铁/煤/铀/装备/粮）走**外交官谈判** | 不占贸易容量，是一份国家合同 |
| 2026-11-02 | 贸易政策=国家级（外交柱下），具体贸易=城市级 | R29b 裁定 |

## 易踩的坑

1. **外交采购不是贸易**：不占容量、不产生伙伴贸易线，走外交面板。
2. **容量截断是按比例**，不是先到先得。
3. **无港口=0 贸易**——内陆阵营必须靠本阵营沿海城。
