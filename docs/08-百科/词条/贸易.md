# 贸易

> 权威源：[贸易最小规则.md](../../06-设计/03-内政/贸易最小规则.md)（**v1.0 简化版，2026-11-25**）· 同步日期：**2026-11-25** · 状态：**✅ v1.0 定稿**（统一容量/中断简化/两档协定/倾向派生闭环）
>
> **11-24 注**：**贸易协定 `+2/回` 保持不动**（关系封顶 100 是基线规则正常结果）；政策卡贸易类效果用商业乘区近似（sim 无独立渗透系统）。

## 一句话

**民间贸易只有财**：玩家只看到"贸易收入 +N 财/回"一个数，不追踪货物、不记价格、不选航线；内陆国照常有贸易（陆路），海路城市靠港口额外提升。

## 核心公式

```
① 城容量 = 该城商业净产出 × 0.10（统一容量，不分海陆）
   国家容量 = Σ 各城容量
② 伙伴贸易额 = 伙伴商业产出 × 0.10 × 关系系数 × 协定 × 倾向
   关系系数 = clamp(0.50 + R/100, 0, 1.50)
③ 国家贸易收入 = min( Σ伙伴贸易额, 国家容量 )；超额按线额比例截断
④ 海路城市建港口 → 该城容量系数 +0.05/Lv（Lv1/2/3）
```

## 中断规则（简化版，11-25 院长裁）

| 情形 | 规则 |
|---|---|
| 交战 A-B | A-B 线**完全中断**（旧"战时贸易线保留 50%"删除） |
| 封锁 A→B | A-B 线中断（**禁运并入封锁**） |
| 第三方 | **不受牵连**（A-C/B-C 不动，除非 C 自己参战/封锁） |
| 转口 | **不做** |

## 两档协定

| 协定 | 门槛 | 效果 |
|---|---|---|
| 民间通商 | R≥0 | 自动财流（默认） |
| 最惠贸易 | R≥+20 | 该伙伴 ×1.2；关系 +2/回 |

## 关键参数

| 参数ID | 值 | 含义 |
|---|--:|---|
| `tradeCapacityK` | 0.10 | 统一容量系数 |
| `tradePenetration` | 0.10 | 渗透率（伙伴每 10 财产出→1 财我方净得） |
| `tradeRelationBase/Cap` | 0.50 / 1.50 | 关系系数 |
| `portCapacityCoefPerLv` | +0.05 | 港口容量系数/Lv |
| `tradeMostFavored` | ×1.2 + 关系 +2/回 | 最惠 |
| `tradeBreakRelation` | −40 | 撕协定 |

## 贸易倾向（派生）

`倾向 = 国家性质基准(0.8~1.2) × 大统领相性修正(0.9~1.1)`——从国家性质标签与武将倾向池读取（换大统领会变），不写死国家系数数组。

## 易踩的坑

1. **外交采购不是贸易**：不占容量、走外交面板（铁/煤/铀/装备）。
2. **内贸不算贸易**：城间流动已由商业产出消化，勿双算。
3. **容量截断按比例**，不是先到先得；**内陆国也有贸易**（陆路=统一容量）。
4. **转口概念已删**；旧 50/80/110 港口容量、保税 +20、战时贸易线、禁运独立档全部作废。
5. **复苏副本不出港口建筑**（贸易照常走统一容量）。
