# 政策卡

> 权威源：[政策卡架构](../../06-设计/00-总纲/政策卡架构.md) **v0.7** · [政策卡目录](../../06-设计/00-总纲/政策卡目录.md) **v1.4** · [政策卡内容专题](../../06-设计/00-总纲/政策卡内容专题.md) **v2.1**（卡面权威；11-23 严肃政策命名）· [政策卡内容重塑专题](../../06-设计/00-总纲/政策卡内容重塑专题.md) v0.4（命名依据）· [外交内容专题](../../06-设计/05-外交/外交内容专题.md) **v0.4**（义务卡）· 同步日期：2026-11-23 · 状态：✅ 收费与冷却已定稿（11-19）/51 张已落库（11-20）/**49 张改名（11-23 严肃政策命名）**

## 一句话

无政体；五槽（军/经/文/外/通）各 2 槽 = 10，统一卡池 51 张（50 基础+环保主义 event 解锁）；卡=长期国策（低频），**装卡免费、收费只由冷却决定**。

## 核心机制

- **五槽对五卡**：军事红/经济黄/文化紫/外交绿/通用白；通用卡只进通用槽；额外槽只走事件/典藏。
- **卡池**：51 张 = 军10/经10/文10/外10/通10（50 基础）+ 第 51 张 environmentalism 环境保护政策（event 解锁，卡面权威=外交内容专题 §六，11-20）；基础池 27 纯正 + 23 机制型 + **0 附加惩罚**；**10 组互斥**硬校验；**2026-11-23 严肃政策命名：相对 v1.0 共 49 张改名 + 2 张保留**（军工优先/金元外交；卡名=政策/制度/战略/计划/体制改革名，如"减税→减税降费政策""反腐→反腐败政策"；对照表见内容专题 §十一）。
- **收费与冷却（2026-11-19 定稿）**：
  - **装卡免费**（含首次；旧"装卡 100 财"作废——免初次大额支出）。
  - **冷却期**=装卡后 `slotUnlockDelay=2` 回合；**期内改动（卸/换）100 财/次**；**期满改动 0 财**。
  - 限制短期频繁折腾、鼓励长期调整；同一槽最快 3 回合自然冷却（付费可提前）。
- **解锁**：只科技/事件/开局；事件·典藏可加槽；外交提案可发卡。
- **外交义务卡（Mandate）**：提案通过→发卡带 `mandatory`→**义务期 N 回合必须挂着**（无宽限）；不挂/中途卸=**违约**（违约=撕毁统一）；后果=声誉 −3 / 关系 发起方 −15、同意方 −8 / **CB 按提案配置**（环保无、裁军有）；**补救**=义务期内补挂恢复履约（数值不退）。
- **负财政**：AI 不接受带义务提案；玩家不置灰仅提示；全球安全型强制通过且国库 <100 → 获 100 财国际援助（虚空产出，无人支付）。
- **无信相性**：大统领人格位 `perfidy`（0~1），越高越倾向违约。

## 常见误解 / 易踩的坑

1. **装卡不花钱**（11-19 起）；花钱的是"冷却期内改动"。
2. **义务卡不是特殊卡**：它就是普通政策卡 + `mandatory` 标记；可自愿装、占槽、免费装。
3. **环保提案违约无 CB、裁军提案有 CB**——CB 是提案级配置，不要按"所有违约都给 CB"理解。
4. 冷却期内不是"不能改"，是"付费可改"（100 财/次）。
5. **百科不是设计源**：权威在 `06-设计/`；但每次裁定必须同步本词条+参数索引+决策索引（11-19 院长令）。
