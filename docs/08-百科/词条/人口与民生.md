# 人口与民生

> 权威源：[人口算法-v1.md](../../06-设计/03-内政/人口算法-v1.md) / [人口数值表.md](../../06-设计/03-内政/人口数值表.md) / [粮食与人口算法.md](../../06-设计/03-内政/粮食与人口算法.md) · 同步日期：2026-11-05 · 状态：**✅ 数值表 v1.0 定值 + 算法 v1.2（部分待拍板）**

## 一句话

人口是底层驱动：**粮食决定能不能活，民生决定活得好不好，忠诚决定会不会反**。三者用"流量积分"（每回缓慢变动）而非派生值，防止单回合冲击导致猝死。

## 核心公式

```
① 粮食（城级）
   net_i = Q_i − D_i                      // 本城优先供给
   余粮按人口比例分配；缺粮城按缺口死人口
   库存 K 为唯一安全指标（可为负）；8×D 储备；出征一次性带粮
② 宜居（W）
   由居民楼/医疗/娱乐/污染/战争等因子合成（0~100）
③ 民生（W_cap 上限）
   W = min(W_calc, W_cap)
   W_cap = 85 + 15×n                      // n=文化归一因子 min(1, 城文化产出/30)（11-05 裁 B+C）
④ 忠诚（Q1 流量积分，2026-11-05 定稿）
   ΔLoyalty = 民生流 + 治安流 + 治理流 + 外籍流 + 占领流 + 文化流 + 驻军流 + 武将流 + 自然回流
   民生流 = −0.15×(40−W)^1.1（W<40）/ +0.15×(W−55)^0.8（W>55）
   文化流 = +0.5×n（11-05 裁 C）
   clamp(Δ, −10, +5)；连续 N 回合双保险
⑤ 同化（11-05 改相对均值）
   2%/回 × clamp(1+1.5×(Cnat−Cavg)/Cavg, 1, 2.5)，上限 5%/回
⑥ 起义/叛乱
   起义：忠诚 <30 连续 3 回合（普通城）→ 驻军倒戈、整城中立
   叛乱：忠诚 <20 连续 10 回合 且 外籍比例 f≥75% → 外籍叛军攻防
```

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| 2026-10-29 | 人口数值表 v1.0（398k/14 城/征募 8 财+1 军备） | 一期数值成型 |
| 2026-10-29 | **起义只看忠诚**，75% 分界（f≥75% 叛乱、<75% 起义） | 简化判定 |
| 2026-11-05 | **忠诚改流量积分制**（推翻派生式"现算"） | 派生式在单回合冲击下忠诚骤降→起义猝死，玩家不可接受；派生式转为**初始锚定公式** |
| 2026-11-05 | 同化文化因子改**相对均值** | 原绝对式被打满（CN 1.97，其余 1.0） |
| 2026-11-05 | W_cap = 85+15×n（B+C） | 文化抬民生上限，缺文化只压上限不掉生存 |

## 易踩的坑

1. **两套忠诚不要混**：城市民生（本词条）/ 武将个人忠诚（武将词条）。
2. **库存 K 可为负**——这是"缺粮死人"的判定入口，不要 clamp 到 0。
3. 忠诚是**流量**，不要写成"民生=忠诚"的派生关系。
4. 文化只抬 W_cap 上限，**不直接加民生**。
