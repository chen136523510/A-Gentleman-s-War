# 人口与民生

> 权威源：[人口算法-v1.md](../../06-设计/03-内政/人口算法-v1.md) / [人口数值表.md](../../06-设计/03-内政/人口数值表.md) / [粮食与人口算法.md](../../06-设计/03-内政/粮食与人口算法.md) / [模拟规范](../../06-设计/00-总纲/模拟规范.md)（v22 ×8 尺度口径） · 同步日期：**2026-11-24** · 状态：**✅ 数值表 v1.0 定值 + 算法 v1.2 + v22 ×8 尺度 + 单一人口公式（11-13 限速）**

## 一句话

人口是底层驱动：**粮食决定能不能活，民生决定活得好不好，忠诚决定会不会反**。三者用"流量积分"（每回缓慢变动）而非派生值，防止单回合冲击导致猝死。

## 核心公式

```
① 粮食（城级）
   net_i = Q_i − D_i                      // 本城优先供给
   余粮按人口比例分配；缺粮城按缺口死人口
   库存 K 为唯一安全指标（可为负）；8×D 储备；出征一次性带粮
② 宜居（W）
   由居民楼/医疗/娱乐/污染/战争等因子合成（0~100）
③ 民生（W_cap 上限）
   W = min(W_calc, W_cap)
   W_cap = 85 + 15×n                      // n=文化归一因子 min(1, 城文化产出/30)（11-05 裁 B+C）
④ 忠诚（Q1 流量积分，2026-11-05 定稿）
   ΔLoyalty = 民生流 + 治安流 + 治理流 + 外籍流 + 占领流 + 文化流 + 驻军流 + 武将流 + 自然回流
   民生流 = −0.15×(40−W)^1.1（W<40）/ +0.15×(W−55)^0.8（W>55）
   文化流 = +0.5×n（11-05 裁 C）
   clamp(Δ, −10, +5)；连续 N 回合双保险
⑤ 同化（11-05 改相对均值）
   2%/回 × clamp(1+1.5×(Cnat−Cavg)/Cavg, 1, 2.5)，上限 5%/回
⑥ 起义/叛乱
   起义：忠诚 <30 连续 3 回合（普通城）→ 驻军倒戈、整城中立
   叛乱：忠诚 <20 连续 10 回合 且 外籍比例 f≥75% → 外籍叛军攻防
```

## 三大主式（11-13/11-24 增补 · 与 sim v22 基线同源）

> 以下为 2026-11-05 之后新增的权威口径（原 §核心公式 的忠诚/民生流数值不变，此处补主式与尺度）。

```
⓪ 数值尺度：全局 ×8（人口/岗位/产出/造价/维护/单座上限/服务人口/粮/兵员/矿产）
   —— 人口十万级、战争十万人级；所有显示数值均为 ×8 后口径

① 人口（单一式，2026-11-13 限速）
   g  = 0.006 × h × f_L^1.5 × f_F × (1.5 − r)
        h   = 医院档位增速（无医院 1.10 / 三甲 1.30 等）
        f_L = clamp(宜居 L / 60, 0.5, 1.5)     f_F = clamp(粮安 F / 70, 0, 1)
        r   = 人口/承载比（舒适容量；可超载至 ~2 倍）
   ΔP = P × clamp(g, −2%, +2%)                —— 单回限速 ±2%（防爆涨/猝跌）

② 民生主式 W（人口算法-v1 §五）
   W_raw = B_W + 0.22×(F−50) + 0.28×(L−50) + 0.12×(Se−50) + 0.10×(G−50)
           + 0.08×(Ea−50) − Φ − Β + warSupport + 0.10×(T−50) + 0.10×M + pol_W
   W = clamp(W_raw, 0, W_cap)                 —— pol_W = 政策卡民生偏置（−20~+20）
   说明：W 抬升 → 治安 Se +0.40×(W−50)（民生是治安唯一正反馈入口）

③ 消费与欲望（K_desire，全局乘区）
   消费池 = 民用人口/1000 × 2.5 × K_desire × 8
   K_desire = clamp(1 + 0.3×(在岗率−0.95) + 0.2×(宜居−50)/50
                    − 0.15×交战 − 0.10×军管 − 0.20×税负 − 0.15×供给危机, 0.5, 1.5)
```

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| 2026-10-29 | 人口数值表 v1.0（398k/14 城/征募 8 财+1 军备） | 一期数值成型 |
| 2026-10-29 | **起义只看忠诚**，75% 分界（f≥75% 叛乱、<75% 起义） | 简化判定 |
| 2026-11-05 | **忠诚改流量积分制**（推翻派生式"现算"） | 派生式在单回合冲击下忠诚骤降→起义猝死，玩家不可接受；派生式转为**初始锚定公式** |
| 2026-11-05 | 同化文化因子改**相对均值** | 原绝对式被打满（CN 1.97，其余 1.0） |
| 2026-11-05 | W_cap = 85+15×n（B+C） | 文化抬民生上限，缺文化只压上限不掉生存 |
| 2026-11-12 | **数值尺度全局 ×8**（人口十万级/产出/造价/维护/兵员）；医院增速修复；人口政策只保留 2 卡（生育补贴/计划生育，补贴耗财、无延迟） | 十万人级战争规模需要；政策卡过多则失真 |
| 2026-11-13 | **人口改单一式 + 限速 ±2%/回**（推翻分段式）；W 主式定稿（民生/治安互为输入） | 单一式便于调参；限速防爆涨猝跌（院长第 7 条） |

## 易踩的坑

1. **两套忠诚不要混**：城市民生（本词条）/ 武将个人忠诚（武将词条）。
2. **库存 K 可为负**——这是"缺粮死人"的判定入口，不要 clamp 到 0。
3. 忠诚是**流量**，不要写成"民生=忠诚"的派生关系。
4. 文化只抬 W_cap 上限，**不直接加民生**。
