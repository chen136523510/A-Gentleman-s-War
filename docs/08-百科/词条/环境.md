# 环境系统

> 权威源：[环境系统.md](../../06-设计/00-总纲/环境系统.md) · 同步日期：2026-11-05 · 状态：**✅ R42 定稿**（唯一完全定稿的世界级系统）

## 一句话

跨国家公共层：五本账（碳/臭氧/酸雨/核污染/资源枯竭）由各国共同制造、共同承受；碳账驱动温度→海平面三级灾害，第三级 = **全局失败结局**。

## 核心公式

```
① 碳账（全球）
   全球碳累计 += Σ建筑碳排放（钢铁+8/火电+6/矿业+2/垃圾焚烧+2/清洁能源0）每回合
   温度指数 = min(累计碳 / K, 100)         // K≈200~400（由"200 回合到 1.5m"反推）
   显示口径：≈+X.X°C = 温度指数 × 0.04
② 海平面（只升不降）
   年速率：T<30 → 3mm；30~60 → 4~8；60~80 → 8~12；>80 → 12~16
   累计：+0.5m 一级 → +1.0m 二级 → +1.5m 三级（灭世线）
③ 臭氧（全球 CFC）
   钢铁+2 / 火电+1 每回合；AU 先受（宜居 −X/回）；条约可治
④ 酸雨（局部 SO₂）
   重工业城粮产 −10%、维护 +20%；脱硫科技 SO₂ −50%
⑤ 核污染（区域）
   残留每 30 回合减半；除染一次 −50%
⑥ 资源枯竭（矿城）
   每开采 50 回合降一档（满→富→中→贫→尽）；AU/达尔文 ×1.2 慢枯
```

## 决策史

| 日期 | 裁定 | 理由 |
|---|---|---|
| 2026-10-28 | 五账本**全部一期** | 分期按系统整体最优，不按工作量；避免两期接口割裂 |
| 2026-10-28 | 海平面第三级=**全局失败结局** | 大陆陷落=所有阵营共同失败，无胜者 |
| 2026-10-28 | 数据与内容分离：账本=独立数据层 | 存档 `state.environment` + `balance.json` 环境区 |
| 2026-10-28 | 面板=水文监测站仪表盘（不单独用红色预警） | 紧迫感靠水位逼近刻度的物理直觉，不靠红字 |
| 2026-10-28 | 垃圾发电每城限 1 | 一城垃圾只够一座 |

## 易踩的坑

1. **温度指数会长期贴 0**：现有排放量级 100~300 碳/回，200 回合累计 20~60Gt，按 TCRE 只升温 0.01~0.03°C → 二三级永不触发。**必须定 `envTempK`**（核账 §9.1 已标）。
2. **海平面只升不降**——治理只能减缓，不能回退。
3. **AI 同规则承受**：AI 也怕全局失败，所以有治理动机（不是玩家单方面负担）。
4. **红色只作辅助**：UI 禁止"红屏死亡"式预警（负反馈纪律）。
