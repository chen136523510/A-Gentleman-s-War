# 文化输出

> 权威源：[文化输出算法.md](../../06-设计/00-总纲/文化输出算法.md) · 同步日期：2026-11-05 · 状态：**v1 定稿（A 案 + 势差乘区 + 文化失所）**

## 一句话

国家文化存量通过"N×N 文化压力矩阵"争夺各国认同度；某国认同被单极压到 60% 持续 5 回 = **完全入侵**；多极碎片化则触发**文化失所**。文化胜利 = 联合国路线：全部成员国完全入侵 + 维持 10 回。

## 核心公式

```
① 城市文化产出
   城文化 = (基础值 + Σ建筑文化×在岗率) × (1+0.10×传媒大学数) × 宜居/人口/科技因子 − 污染

② 国家文化存量（历史累计，失城不回溯）
   Culture_t = Culture_0 + Σ[ Σ城文化产出 × (1+政策加成) ]

③ 文化压力（每对国家，每回合）
   P[A→B] = √Culture_A × 距离 × 联系 × 情报 × 战争 × 势差乘区
   势差乘区 = clamp((Culture_A/Culture_B)^0.5, 1.0, 2.0)   [仅 Culture_A ≥ 3000]

④ 本国自压（抵抗的落点）
   P[B→B] = √Culture_B × (1 + 抵抗加成)       抵抗加成 ≤ 50%

⑤ 目标份额
   Target[A→B] = P[A→B] ÷ Σ_X P[X→B]

⑥ 认同收敛
   Identity[B:A] += 0.05 × (Target − Identity)     本国认同兜底 ≥ 20%

⑦ 完全入侵
   Identity[B:A] ≥ 60% 持续 5 回 → 入侵；< 50% 解除

⑧ 文化失所
   触发：Identity[B:B] < 40% 且 max(外国认同) < 60%
   效果：征兵 ×0.85 + 战斗 ×0.9 + 忠诚流水 −0.5/回（不扣文化产出）
   解除：Identity[B:B] ≥ 45%

⑨ 文化胜利
   联合国成立 → 当选盟主 → 全部成员国完全入侵 + 维持 10 回
```

## 决策史（为什么变成现在这样）

| 日期 | 裁定 | 理由 |
|---|---|---|
| 2026-10-26 | 立项；**√Culture** 而非线性 | 凸性仿真：4 倍文化只 2 倍输出，小国有追赶空间；参数宽容度高 |
| 2026-10-26 | 三数 60/50/20 | 60% 入 + 50% 出缓冲 + 本国 20% 兜底（文化清洗不可彻底） |
| 2026-11-05 | **旧机制判死**：`Δ=k×Output÷Resistance` 数学上到不了 60% | Output∝√存量、Resistance∝存量 → 速率∝1/√t；k=0.01 时本国认同已崩 |
| 2026-11-05 | **改份额收敛式**（A 案），r=0.05 | 认同度向"输出市场份额"收敛；多极自动锁死、单极可达、抵抗有落点 |
| 2026-11-05 | **加文化势差乘区** | 不加则 0 入侵（√ 压缩大国优势）；加上后 CN 押注文化 → 1~2 入侵 |
| 2026-11-05 | **新立文化失所** | 多极僵持从"双方无事"变"负和"；不扣文化产出防死亡螺旋 |
| 2026-11-05 | 抵抗上限 50% | 模拟 35% vs 50% 几乎同结果，50% 更安全 |

## 模拟证据（v12a，2026-11-05）

| 场景 | 完全入侵 | 最高外国认同 |
|---|--:|--:|
| 无人经营文化输出 | **0** | 33.5% |
| CN 全力押注文化（文化×1.5+情报全开） | **1~2** | 59.8~63.9% |

→ 文化胜利是**经营可达成的目标**。

## 常见误解 / 易踩的坑

1. **"抵抗是减伤"**：不是。抵抗抬高本国自压，稀释外国份额——本质是"自己也要输出自己"。
2. **"k 调大就能入侵"**：旧机制下 k=0.01 会让所有国家认同碎掉但无人到 60%；新机制不靠 k。
3. **"文化失所=被入侵"**：不同。完全入侵=认同别人；文化失所=谁都不认同（包括自己）。
4. **"战争只影响输出"**：对——文化存量不受战争影响（R27b），但认同一场战争后会以 r 速率回落。
5. **"势差乘区会滚雪球"**：封顶 2.0 + gate，20 回合内不会一统。
