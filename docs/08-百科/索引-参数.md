### 碳回收机制

```
净碳 = 排放 − 碳回收（可为负）
累计碳 += 净碳
温度指数 = max(上回合温度, 累计碳/50000×100)   // 单调不减：温度不再上升≠温度回落
温度指数 = clamp(累计碳/envTempK×100, 0, 100)    // 可降
海平面速率：净碳≤0 且持续≥20回 → 0mm（停涨）；否则 f(T)：T<30→3；30~60→4~8；60~80→8~12；>80→12~16
海平面累计只增不减（已淹没不回滚）
```
