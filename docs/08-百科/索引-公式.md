## 一、文化输出（✅ 完整）

**权威源**：[文化输出算法.md](../06-设计/00-总纲/文化输出算法.md) · 词条：[文化输出](./词条/文化输出.md)

```
① 城市文化产出（v0.2 建筑卡口径）
   城文化 = (基础值 + Σ建筑文化×在岗率)
            × (1 + 0.15×宜居因子 + 0.20×人口因子 + 0.15×科技因子)
            × (传媒大学?1.10:1) × (1 − 污染惩罚0~30%)
            + 典藏陈列末端注入（不吃因子）
   宜居因子=clamp((L−50)/50,−0.5,0.5)；人口因子=min(P/50000,1)；科技因子=min(科技数/38,1)
② 国家文化存量
   Culture_t = Culture_0 + Σ[ Σ城文化产出 × (1+政策加成) ]
③ 文化压力（每对国家每回合）
   P[A→B] = √Culture_A × 距离 × 联系 × 情报 × 战争 × 势差乘区
   势差乘区 = clamp((Culture_A/Culture_B)^0.5, 1.0, 2.0)   [攻击方文化建筑 ≥1 时生效]
④ 本国自压
   P[B→B] = √Culture_B × (1 + 抵抗加成)      [抵抗 ≤ 50%]
⑤ 目标份额
   Target[A→B] = P[A→B] ÷ Σ_X P[X→B]
⑥ 认同收敛（每回合）
   Identity[B:A] += 0.05 × (Target − Identity)
   本国认同兜底 ≥ 20%
⑦ 完全入侵
   Identity[B:A] ≥ 60% 持续 5 回 → 入侵；< 50% 解除
⑧ 文化失所（多极碎片）
   Identity[B:B] < 40% 且 max(外国) < 60%
   → 征兵 ×0.85 + 战斗 ×0.9 + 忠诚流水 −0.5/回（不扣文化产出）
   Identity[B:B] ≥ 45% 解除
⑨ 文化胜利
   联合国成立 → 当选盟主 → 全部成员国完全入侵 + 维持 10 回
```

**参数ID一览**：`cultureOutputExp / cultureGapExp / cultureGapCap / cultureGapGate / cultureResistCap / cultureConvergeR / cultureInvadeThreshold / cultureInvadeRelease / cultureSelfFloor / cultureLostThreshold / cultureLostRelease / cultureDistAdjacent / cultureDistOversea / cultureLinkRoute / cultureIntelKnown / cultureWarActive ...`

## 八、外交（🏗️ v0）

**权威源**：[外交行动.md](../06-设计/05-外交/外交行动.md) · 词条：[外交](./词条/外交.md)

```
关系 R：−100~+100
成功率 = 基础 + 关系修正 + 筹码 + 属性（钳 5~95%）
同盟：20% + R×0.5% + 筹码(5%/500财,上限25%) + 政治×0.3%
谈判分 = clamp(0.30 + 政治/200 + (R+100)/400 + 合同期/50 + 筹码, 0, 1)
成交价 = 参考价 × (1.5 − 0.5×谈判分)
```
