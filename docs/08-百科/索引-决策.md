# 索引 · 决策时间线

> 关键裁定的"什么时候、谁、裁了什么、为什么"。用于切窗口后快速恢复设计上下文。
> 只记**影响架构/公式/数值口径**的裁定；日常细节在各模块 changelog。

## 2026-11（内政深化期）

| 日期 | 专题 | 裁定 | 为什么（设计意图） |
|---|---|---|---|
| 11-05 | 世界观 | **时间线去具体年份**：只说"曾经发生剧变，现在是剧变后某个时间点" | 时间只为故事点缀；解除内容创作约束（现代物件可作"剧变前遗物"） |
| 11-05 | 武将 | **魅力升为第五维**（统率/武力/智力/政治/魅力），总点数 320~400 | 典藏赐予效果引入"魅力+2"；五维更适配外交/招降玩法 |
| 11-05 | 文化输出 | **改份额收敛式（A 案）**：认同度向输出份额收敛，r=0.05 | 旧机制 `Δ=k×Output÷Resistance` 转移速率 ∝1/√t，数学上永远到不了 60%；k 拉大先崩本国认同 |
| 11-05 | 文化输出 | **新增文化势差乘区** `clamp((C_A/C_B)^0.5,1,2)`，gate 3000 | √ 凹函数压缩大国优势（2.46 倍文化→1.57 倍输出），不加则 0 完全入侵 |
| 11-05 | 文化输出 | **抵抗加成上限 50%**（建筑/政策/科技/事件四源） | 模拟验证 35% vs 50% 结果几乎相同，50% 把最低本国认同从 23% 抬到 25%，更安全 |
| 11-05 | 文化输出 | **新立「文化失所」**：多极冲击→本国认同碎片化受罚 | "国民不知道认同什么文化，但肯定不认同自身文化"；把多极僵持从"无事"变负和 |
| 11-05 | 文化输出 | 文化失所**不扣文化产出**，改罚征兵/战争/忠诚 | "不然太难追上"——防文化落后方死亡螺旋 |
| 11-05 | 典藏 | **不做价值分类**（无档位，每件独立配置） | 每件独一无二，档位反而公式化 |
| 11-05 | 典藏 | **三组效果可叠加**：常驻（持有）/陈列（本城）/赐予（武将） | 院长 3 个样例（小霸王/台积电光刻机/兵马俑）都是三组俱全 |
| 11-05 | 典藏 | **归属三规则**：陈列随城 / 武将持有随武将 / 国库随国 | 掠夺有叙事，不再做概率夺宝 |
| 11-05 | 典藏 | **收回忠诚惩罚 > 赐予**（保底 ×1.5） | 防"送了又收"刷忠诚 |
| 11-05 | 典藏 | **典藏不提供城市热度**；**不做主动脉冲**；**系列彩蛋暂缓** | 热度已有独立体系；主动技属调研引入非项目需求；系列后续再提 |
| 11-05 | 典藏 | **风味优先**：典藏间不做平衡，只保证不影响主系统 | 每件独立数值 + 故事钩子 |
| 11-05 | 全程 | **参数可追溯纪律**：公式每个常数必须有参数ID + 基础数值出处 | 供知识库/代码同源；禁止魔法数字 |
| 11-05 | 文化区 | 耕地 40→30；池系数 2.5；Q1 忠诚=流量制；传媒大学每城限 1×1.10 | 见 B5 changelog |

## 2026-10（架构与专题期）

| 日期 | 专题 | 裁定 | 为什么 |
|---|---|---|---|
| 10-30 | 架构 | 三级架构（世界-国家-城市）；国家五柱+情报位 | 讨论框架防方向偏移 |
| 10-29 | 人口 | 人口数值表 v1.0（398k/14 城）；起义只看忠诚，75% 分界 | 数值一期成型后统一微调 |
| 10-28 | 环境 | 五账本全进一期；海平面三级→全局失败结局 | 分期按系统整体最优，不按工作量 |
| 10-28 | 战斗 | L3 手动档进一期（推翻原"仅自动结算"） | 单机体验优先 |
| 10-27 | 胜利 | 三途径并存（统一/科技/文化），外交并入文化链 | 纯规则判定，不依赖表现层 |
| 10-26 | 文化 | 文化输出算法立项；√Culture 凹函数（凸性仿真两案对比） | 小国追赶空间 + 参数宽容度 |
| 10-26 | 世界观 | 大剧变/14 幸存城/AU 漂移；1 回合=1 年 | 解释"为什么只有 14 城" |
| 10-26 | 政策 | 政体选择制 + 四槽位政策卡（文明 6 式） | 国家级第五柱 |
