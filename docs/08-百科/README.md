# 国男志百科（Wiki）

> **定位**：**检索层 + 快照**，不是第二套设计文档。权威源永远在 `docs/06-设计/`；本百科只做三件事——
> ① **跨模块索引**（设计散落在 8 个模块，切窗口后能一页找回）
> ② **公式与参数单点查询**（每个公式/常数在哪、什么意思、值多少、出处是什么）
> ③ **决策时间线**（谁在什么时候裁了什么、为什么）
>
> **院长令（2026-11-05）**："我们游戏最好也仿照 Wiki 做一个类似的百科，你来维护。也用于你后续切换窗口后，能够方便找回当初的设计思路和具体的公式详情。"

## 一、怎么用（AI 新窗口起手）

```
1. 读 AGENTS.md + .ai/handoff.md（状态）
2. 要查"某系统怎么算" → 本百科 索引-公式.md → 点进词条 → 点进权威文档
3. 要查"某个数字哪来的" → 索引-参数.md（参数ID + 基础数值出处）
4. 要查"这个设定什么时候定的" → 索引-决策.md（时间线）
5. 要做新裁定 → 先查词条避免与旧裁冲突 → 裁定后同步更新词条 + 参数表 + 决策索引
```

## 四、维护规则（写进每次收尾）

1. **裁定即同步**：每次院长裁定后，更新 ①对应词条 ②索引-参数（若新增/改常数）③索引-决策（若改设计）——三件一起，不拖到下次。
2. **不双写正文**：词条写"公式 + 参数 + 为什么"，细节规则留在权威文档；冲突时**以权威文档为准**并在词条标注"⚠️ 已过期，见权威源"。
3. **同步日期必填**：每个词条顶部写"同步日期"，便于判断是否过期。
4. **参数纪律**（院长 2026-11-05 令）：公式里每个常数必须有参数ID + 基础数值出处；无出处的标 ⚠️ 并设复核期限。
5. **术语术语**：新概念首现必须进 [术语表](../06-设计/00-总纲/术语表.md)，百科词条引用术语表。
