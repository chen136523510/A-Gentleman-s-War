## 判定方式

依据攻方出发城/港口 与 守方目标城 的地理邻接关系（数据在 [01-地图与城市/连通图与航线.md](../01-地图与城市/连通图与航线.md)）自动确定战场类型。

| 例子 | 城市对 | 判定类型 |
|---|---|---|
| 西安 → 深圳 | 内陆—内陆 | **纯内陆战** ❌**已被 2026-11-22 连通图覆盖：西安仅邻北京（无西安—深圳线），示例失效；内陆战改用北京→西安** |
| 深圳 → 台北 | 跨海 | **登陆战** |
| 首尔 → 东京 | 跨海（对马海峡直连） | 登陆战 |
| 北京 → 首尔 | 微缩陆连 | 内陆战（按钦定架空接壤处理） |

## 类型清单

| 类型 | 触发 | 规则要点 | 状态 |
|---|---|---|---|
| 内陆战/野战 | 内陆邻接城市互攻 | 普通战场 | 框架 |
| 攻城 | 攻击有城墙的城市 | 拆墙破门→**占领市政府**才完全占城（R11；红警范式） | 框架 |
| **登陆战** | 跨海邻接（**无海战**，R7 拍板） | 守军可在海岸设防/布滩头阵地；登陆方需先夺滩再向城内推进 | 框架 |
| 平叛 | 攻击起义中立城/自立新阵营城 | 中立城只守不攻 | 框架 |
| 讨伐战 | 二期异族/海盗据点 | 特殊规则战场 | ⛏ 二期 |

## 守军构成按城态分化（R11）

- 攻**正常城**：面对**城防部队**（城防军不随驻城武将消失；**无武将驻守的城**无将指挥→战力打折，折扣待数值）；
- 攻**起义城（平叛）**：面对**起义民兵**（守军构成不同，强度与原城防/人口的关系待数值）；
- 城态定义见 [03-内政/驻守与城态.md](../03-内政/驻守与城态.md)（11-09 起两态：正常/起义；空虚已删）。
