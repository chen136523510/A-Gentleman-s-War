# 兵种生产与兵工厂数值（B1 · v1.2）

> 状态：🏗️ **v1.2（2026-11-12 院长令：轻兵种 1 回合/批、重兵种 2 回合/批；生产回合=装备生产+训练时间；征募慢无所谓，服役人口够用即可）**。v1.1 的“连续流”口径作废，回到批次制。
> 依据：院长 11-12 兵种裁定（服役人口默认普通步兵 / 取消装备率 / 兵工厂直出三系 / 石油第五矿 / 轰炸机重定）；[兵种与装备目录](./兵种与装备目录.md) v3；[兵种数值表](./兵种数值表.md)（q_base/克制/地形沿用）。
> 口径：本表为**基准值（v22 缩放前）**；v22 起财/生产/兵员/矿产/造价一律 **×8**（见 §六）。**1 批 = 1,000 兵员（基准）/ 8,000 兵员（v22）**。
> 数值自治（院长 11-12 第 3 条）：数值不逐条待裁，模拟盘输出后统一分析。

## 一、生产链（两步）

```
人口 ──①征募（兵营，8 财/兵）──▶ 服役人口 = 普通步兵（默认可战，零铁）
                                        │
                        ②兵工厂（独立产线，不占 40 座建造位）
                          输入：服役人口 1:1 + 财/铁/煤/石油
                          输出：进阶兵种（突击/特种/坦克/武直/机动炮/重炮）
```

- **兵营 = 增兵入口**：和平 0.5%/回、战时 2%/回本城人口（军事建筑数值 §3.1）；征募速度不作为本专题的调优目标——**服役人口够支撑战争即可**。
- **兵工厂 = 装备+训练入口，不新增兵员**：把已征募的服役人口 1:1 转成进阶兵种，保留原兵员数。
- **按批次生产**：1 批 = **1,000 兵员**（基准）/ **8,000 兵员**（v22）；**轻兵种 1 回合/批、重兵种 2 回合/批**。
- **“每批回合”= 生产装备 + 训练的时间**（不是等待排队的空转）；首批同样按该回合数交付，之后每完成一批立刻接下一批。
- 兵工厂产线与建造队列**并行**，不抢建造位。

## 三、兵工厂（新建筑 · 军事区）

| 项 | 值 |
|---|---|
| 财/生产/工期 | 3,000 / 600 / 4 |
| 维护 | 30（造价 1%） |
| **产线** | **Lv1 1 条 / Lv2 2 条 / Lv3 3 条**（每条产线同时生产 1 批） |
| 队列 | 3 项（排队，不并行） |
| 上限 | 每城 1 座 |
| 初始城 | 深圳(CN) / 长崎(JP) / 首尔(KR) / 悉尼(AU)（沿用动员中心前线城框架） |
| 升级 | Lv2/Lv3 各 +1 条产线；造价 ×1.6；**升级不变占地**（铁律） |
| 解锁 | 军备重整(Ⅰ) |

**每回合产出（基准，满产）**

| 等级 | 轻兵种（1 回合/批） | 重兵种（2 回合/批） |
|---|---:|---:|
| Lv1（1 条产线） | **1,000 兵/回** | **500 兵/回** |
| Lv2（2 条产线） | **2,000 兵/回** | **1,000 兵/回** |
| Lv3（3 条产线） | **3,000 兵/回** | **1,500 兵/回** |

- **v22 ×8**：Lv1 轻 8,000 / 重 4,000；Lv2 轻 16,000 / 重 8,000；Lv3 轻 24,000 / 重 12,000（兵/回）。
- **示例（基准 Lv1）**：突击步兵 1 批/回 = 1,000 兵/回，扣 240 财 + 8 铁；坦克 1 批/2 回 = 500 兵/回，扣 1,600 财 + 64 铁 + 16 煤 + 32 石油（石油不足时按 §五上限减产）。
- **首批**：与后续批次同节奏——轻兵第 1 回合末交付，重兵第 2 回合末交付；之后循环。
- **兵工厂不产 EP**（EP 作废）；产线只用于兵种进阶。
- 城墙/军事基地/机场/防空建筑见 [军事建筑数值](./军事建筑数值.md)（本表不重复）。

## 四、空军（轰炸机 + 无人机）

### 4.1 轰炸机

| 项 | 值 |
|---|---|
| 生产 | 财 600 + 铁 30 + **石油 20** / 架；2 回合；机场机位 1 |
| 部署 | 进攻方**大营** / 防守方**机场** |
| 出击次数（弹药） | 财 100 + **石油 10** / 次；即时购买；存量上限 = 机场机位 ×2 |
| 冷却 | **3 回合/次** |
| AOE | L3 半径 **3 格**；对部队 **15% 战损**；对建筑 **降 1 级**；**无友伤** |
| 防空 | 进入防空建筑半径（炮塔 4 格 / 防空导弹 5 格）→ **确定性击落，本体永久损失** |
| 占人口 | **不占**（支援层） |

### 4.2 无人机（消耗品）

| 项 | 值 |
|---|---|
| 生产 | 财 120 + **石油 5** / 架；1 回合 |
| 编制 | **不占编制**（机场不占机位） |
| 作用 | 侦察（视野 4 格）/ 自杀式打击（对部队 8% 战损） |
| 反制 | 防空建筑击落 |

### 4.3 与三系的关系

- 空军**不参与**步/骑/弓克制环；不占服役人口；**不能占城**
- 地空协同唯一正确打法：**地面部队先清除防空 → 轰炸机进场**
- 战斗机取消（与武直定位重叠）

## 五、石油消耗汇总（每国油源 → 每回产出上限）

| 国 | 油田（档位） | 石油/回（基准） | 坦克上限（兵/回） | 武直上限（兵/回） | 轰炸机 |
|---|---|---:|---:|---:|---|
| CN | 北京寻常 + 西安富集 | 4.8 + 6.0 = **10.8** | **337**（v22 2,700） | **270**（v22 2,160） | 20 油/架 |
| JP | 东京/名古屋双贫化 | 3.0 + 3.0 = **6.0** | **187**（v22 1,500） | **150**（v22 1,200） | — |
| KR | 首尔单贫化 | **3.0** | **93**（v22 750） | **75**（v22 600） | — |
| AU | 悉尼/墨尔本双丰饶 | 7.2 + 7.2 = **14.4** | **450**（v22 3,600） | **360**（v22 2,880） | — |
| 达尔文 | 富集（无主） | 6.0 | **187**（v22 1,500） | **150**（v22 1,200） | — |

- 坦克 32 油/批、武直 40 油/批 → 每回上限 = 石油/回 ÷ 单兵油耗。
- **JP/KR 不会死锁**：贫化油田仍能维持小规模装甲/空军；200 回合累计远超 10 千坦克当量。
- **大规模扩军必须进口**：外交资源采购/贸易（院长 11-12 石油设计意图）。
- 合成燃料（Ⅴ）后：1 煤 = 0.3 油，缺油国战略翻盘。

## 六、v22 缩放（S=8）

| 对象 | 基准 → ×8 |
|---|---|
| 批次 | 1 批 = 1,000 → **8,000 兵** |
| 财/生产/造价 | ×8（坦克 12,800 财 / 兵工厂 24,000 财 + 4,800 生产） |
| 铁/煤/石油 | ×8（坦克 512 铁 / 128 煤 / **256 石油** / 8,000 兵） |
| 兵工厂产出 | Lv1 轻 8,000 / 重 4,000；Lv2 轻 16,000 / 重 8,000；Lv3 轻 24,000 / 重 12,000（兵/回） |
| 每批回合 | **1（轻）/ 2（重）不变**——时间不缩放 |
| 产线/占地/百分比 | **不变** |

- 缩放只放大“人/财/矿”的量纲；**装备生产+训练的时间仍是 1/2 回合**。
- 资源成本与批次兵员同比例 ×8，相对平衡不变。

## 七、模拟口径（full.js）

> **已接入（2026-11-12 黑机，首版）**：[全量模拟-v22-B1兵种](../00-总纲/全量模拟-v22-B1兵种.md)。首版简化：铁/煤/油用**国家级资源池**（油按 §五，铁/煤按 2 座矿场/城 ×48 估）；初始 4 城各 1 座 Lv1 兵工厂（1 条产线）；AI 科技 5 后逐城补建；Lv2/Lv3 产线、轰炸机、防空圈尚未入模。

1. **石油轴**：全国池；坦克/武直/轰炸机/弹药消耗；库存上限 5 回合收入（防无限囤积）。
2. **兵种生产（批次）**：每城兵工厂 Lv1=1 条产线；每批 8,000 兵员（v22）；轻兵 1 回合、重兵 2 回合；开工扣整批财/铁/煤/油；产线空闲立即接下一批。
3. **部队构成**：阵营兵力 = Σ各兵种 N；战力 = Σ N_i × q_i × 克制 × `(1+科技×1%)`；克制按对方**主兵种系**结算。
4. **轰炸**：未入模（下一轮）。
5. **AI 生产**：战时/军事人格优先机械化（坦克→武直），否则按“当前数量最少且可负担”轮产；缺油/缺铁自动降级到步兵/炮兵。
