> 状态：🏗️ **v1（2026-11-12 院长令：先 A1 再 B1；数值由白机定，模拟盘出结果分析）**
> 依据：院长 11-12 兵种裁定（服役人口默认普通步兵 / 取消装备率 / 兵工厂直出三系 / 石油第五矿 / 轰炸机重定）；[兵种与装备目录](./兵种与装备目录.md) v3；[兵种数值表](./兵种数值表.md)（q_base/克制/地形沿用）。

## 一、生产链（两步）

```
人口 ──①征募（兵营，8 财/兵）──▶ 服役人口 = 普通步兵（默认可战，零铁）
                                        │
                        ②兵工厂（独立队列，不占 40 座建造位）
                          输入：服役人口 1:1 + 财/铁/煤/石油 + 回合
                          输出：进阶兵种（突击/特种/坦克/武直/机动炮/重炮）
```

- 征募即得普通步兵：**不再有"未武装兵员"**，被奇袭时可拉出最低战力
- 进阶兵种**保留原兵员数**（1:1），只加装备与训练
- 兵工厂队列与建造队列**并行**，不抢建造位

## 四、空军（轰炸机 + 无人机）

### 4.1 轰炸机

| 项 | 值 |
|---|---|
| 生产 | 财 600 + 铁 30 + **石油 20** / 架；2 回合；机场机位 1 |
| 部署 | 进攻方**大营** / 防守方**机场** |
| 出击次数（弹药） | 财 100 + **石油 10** / 次；即时购买；存量上限 = 机场机位 ×2 |
| 冷却 | **3 回合/次** |
| AOE | L3 半径 **3 格**；对部队 **15% 战损**；对建筑 **降 1 级**；**无友伤** |
| 防空 | 进入防空建筑半径（炮塔 4 格 / 防空导弹 5 格）→ **确定性击落，本体永久损失** |
| 占人口 | **不占**（支援层） |

### 4.2 无人机（消耗品）

| 项 | 值 |
|---|---|
| 生产 | 财 120 + **石油 5** / 架；1 回合 |
| 编制 | **不占编制**（机场不占机位） |
| 作用 | 侦察（视野 4 格）/ 自杀式打击（对部队 8% 战损） |
| 反制 | 防空建筑击落 |

### 4.3 与三系的关系

- 空军**不参与**步/骑/弓克制环；不占服役人口；**不能占城**
- 地空协同唯一正确打法：**地面部队先清除防空 → 轰炸机进场**
- 战斗机取消（与武直定位重叠）

## 六、v22 缩放（S=8）

| 对象 | 基准 → ×8 |

| 兵员 | 1 单位 = 1,000 → **8,000 兵** |

## 七、模拟口径（full.js）

1. **石油轴**：全国池，油田按城产出（矿脉档位系数）×8；坦克/武直/轰炸机/弹药消耗
2. **兵种生产队列**：每城兵工厂独立队列；服役人口 → 进阶兵种；受财/铁/煤/油约束
3. **部队构成**：阵营兵力 = Σ各兵种 N；战力 = Σ N_i × q_i × 克制 × 装备质量（q_tech）
4. **轰炸**：机场产轰炸机 + 弹药；每 3 回合可出击一次（AOE 战损）；防空圈击落
5. **AI 生产**：按胜利路径（军事线优先机械化；经济线优先步兵）
