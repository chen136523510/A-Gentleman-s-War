# L3 战斗场景

> 状态：🏗️ v0 立项（R35 院长首批九项设计落档；二期主战场，一期自动结算共用判定）
> 定位：**城市级第三层——更细则的城防构建与战役处理**（架构总图 R29）；近现代战争不止城池攻坚。
> 上游：兵种三系六类（兵种与装备目录 v2）/ 战斗总述（胜负/粮草/根据地）/ 内政战场联动（同一套设施数据）
> 更新：2026-10-26 R35

## 一、战场规模与构成（R35 钦定）

- **战场拉大——类似红警地盘大小**：近现代战争不是只有城池攻坚，战场=城市+周边野地的完整地图；进攻方有运营空间（先扫外场/单刀直入都可行）。
- 战场地图来源：**L2 城市建设数据生成**（内政战场联动铁律：同一套设施数据）+ 周边野地（地形类型：树林/丛林/山/河/丘——R15 地形设计四类落地）。
- 城市发育度→战场纵深（城墙圈大小/塔位/市政府离城门距离，R6 城市成长机制不变）。

## 二、战前布置阶段（R35 钦定：军棋式布阵）

- **进攻方和防守方都可以提前布置军力**（在各自所属范围内）——类似下军旗前的布置：
  - 守方：所属范围=城防圈（城墙线/市区/建筑点位）；
  - 攻方：所属范围=进攻出发点（战场边缘集结区）。
- 布置示例（院长钦定）：**炮兵安排在后点**；**步兵在前点**或**隐藏在树林丛林里**（隐匿位）。
- 布置信息不对称：双方布置互相不可见（战争迷雾口径），开战后靠侦察点亮。

## 三、战役进行（R35 钦定：自由派遣）

- **进攻方可自由派遣兵力**：
  - **先扫外场再包围城市**（稳扎稳打：清剿守方外围部队/掠夺城外建筑→合围）；
  - **单刀直入全力冲刺主城**（斩首：直扑市政府，赌守方外线部队回援不及）。
- 地图要大才有运营空间（战场规模条款呼应）。
- 守方应对：守军出城迎击=市政府方向空虚（R13 守家优势口径不变）。

## 四、单位与操作（R35 钦定：极简）

- **武将作为一个单位编入某支队伍**（御驾亲征 L3 落地：角色单位随队，被歼→独立单位脱身窗口→被俘，R13 流程不变）。
- **所有兵种动作只有三种：待命 / 攻击 / 移动**——不做技能微操/阵型/俯仰等 RTS 复杂操作（平 A/集火/寻路交部队 AI，R4 口径不变；武将招牌技能=主动单击发动，采配消耗）。
- 一期自动结算 = 本文档规则的数值化压缩；二期手动档 = 本文档规则的可操作形态。

## 五、地形与高程规则（R35 钦定）

- **所有步兵系兵种都能爬山过河**（R35 修正：不再是特种小队独占——步兵系的共性能力；特种小队特色待重定义 ⛏，候选：隐匿/侦察专精）。
- **城墙布置**：城墙上可以布置**弓兵系**（守方城防构建核心）。
- **高程差**：城墙下弓兵打城墙上弓兵**有减益**；**高打低有增益但不高**（城墙优势真实但不绝对化）。

## 六、建筑与驻兵（R35 钦定）

- **建筑自带血量，但没有驻兵=视作平地可直接通行**（建筑不是墙，兵才是墙）。
- **军事基地**：建筑血量高 + 额外增益 + **可消耗人口和军备产出兵力**（红警造兵逻辑落地：战时产兵/补兵；**尤其可造侦察兵进行视野侦察**——战争迷雾的主动点亮手段）。
- 造兵资源链：人口（城市人口池）+ 军备（装备档库存）→ 新单位；产能约束待数值。
- 城防工事（箭塔等）：军事基地附属（内政战场联动映射表不变）。
