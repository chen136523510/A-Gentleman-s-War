# L3 战斗场景

> 状态：🏗️ v0→v1（R35 立项九项 · R36 战役规则十二项定稿：结束/增援/撤离/侦察/多战/导弹/时长/存档/观战/造兵流）
> 定位：**城市级第三层——更细则的城防构建与战役处理**（架构总图 R29）；近现代战争不止城池攻坚。
> 上游：兵种三系六类（兵种与装备目录 v2）/ 战斗总述（胜负/粮草/根据地）/ 内政战场联动（同一套设施数据）
> **范围变更（R36）**：L3 手动档**直接进一期**（原二期）；其他国家开战玩家可**观战**（AI 沙盒模拟，可快进/跳过）。
> 更新：2026-10-26 R36

## 一、战场规模与构成（R35）

- **战场拉大——类似红警地盘大小**：战场=城市+周边野地完整地图；进攻方有运营空间。
- 战场地图来源：**L2 城市建设数据生成**（同一套设施数据铁律）+ 周边野地（地形：树林/丛林/山/河/丘）。
- 城市发育度→战场纵深（城墙圈/塔位/市政府离城门距离）。
- **L3 大地图按进攻方向四分**（R36）：**左上/右上/左下/右下**四方向安置攻方与守方，并展示部分建筑——**L2 可预览各方向战场**，城市规划据此做方向性设防（城墙全包围 vs 单方向强化（**马奇诺防线**式））。

## 二、战前布置阶段（R35 军棋式）

- 攻守双方在各自所属范围内提前布置（守方=城防圈，攻方=战场边缘集结区/营地）；炮兵后点/步兵前点/树林丛林隐匿位；布置互相不可见。

## 三、战役进行（R35 自由派遣 + R36 增援）

- **进攻方自由派遣**：先扫外场再包围 / 单刀直入冲刺主城。
- **增援（R36）**：多股势力进入同一 L1 城市的 L3 地图——**同阵营=统一调度（粮草共享直接并入）；不同阵营=单独行动**（出发点按帮助守方还是攻方）。**简化逻辑：不做包围反包围**（院长钦定：体系太庞大，无军事顾问）。
- **一城多战/第三方入场（R36）**：完全独立的第三方阵营到场→触发**外交大会要求选边**（进攻方/防守方）：
  - 选一方 = 视作对另一方**宣战**；
  - 都不选 = **三方混战**（同时与两方宣战）；国际声誉相应变化；
  - 多方混战的 L3 布局：第三方从四分方向中剩余一侧进场（攻方占来向一边、守方城居中、第三方另一边）；胜负仍=市政府最终归属。
  - L2 联动：城墙四方向各自设防等级，单方向设防（马奇诺）在混战下有被多向夹击的风险——规划取舍点。

## 四、单位与操作（R35 极简）

- **武将作为一个单位编入某支队伍**（被歼→独立单位脱身→被俘，R13 流程）。
- **动作只有三种：待命 / 攻击 / 移动**；平 A/寻路/集火交部队 AI；武将招牌技能单击发动（采配）。

## 五、地形与高程规则（R35）

- **所有步兵系兵种都能爬山过河**（步兵共性；特种小队特色⛏重定义）。
- **城墙可布置弓兵系**；城墙下弓兵打城墙上弓兵**有减益**；**高打低有增益但不高**。
- **城墙总是有门（R36）**：攻方可**直接破门进入，不破墙也行**——城墙=减速与高地优势，不是绝对屏障。

## 六、建筑与驻兵（R35 + R36 造兵流）

- **建筑自带血量，无驻兵=视作平地可直接通行**。
- **军事基地**：血量高+增益+**消耗人口和军备产出兵力**（红警造兵）；可产**侦察兵**开视野。
- **守方不会真正全灭（R36）**：只要还有**粮食和军备**，守方就能源源不断造兵——攻方想赢**必须占领市政府**（斩首终局，消耗战无解）。

## 七、战役结束规则（R36 定稿）

| 结束方式 | 条件 | 结果 |
|---|---|---|
| 攻方胜 | 占领市政府（驻留读条） | 占城 |
| 守方胜 | 拖到攻方粮草耗尽 / 端攻方营地 | 攻方败退 |
| 全俘判负 | 任一方武将全员被俘 | 该方战役失败 |
| **打平（R36 新增）** | **攻方全军退回营地（进攻方控制区域）→ 发起撤离** | 此局打平，进入下一回合；**武将必须全部回到营地才能提前撤离** |

- **撤离伤亡规则（R36）**：提前撤离时，**未进入营地的部队按比例返回**，失去的兵力视作**殿后伤亡**；战役结束时还在场的**败方部队按比例撤离战场**。
- **守方弃城撤离**：想全身而退须先让所有部队**进入市政府区域**，否则外面的部队只能按比例撤离。

## 八、驻扎与后勤压力（R36 院长设计）

- 打平后下一回合攻方可选**驻扎**（围而不攻）：
  - 驻扎**不消耗行军粮草**（视作有后勤线）；
  - 但**外战人口抬升后勤压力**：例——100 人口每回合耗 100 粮，其中 50 人外战则消耗×2 当量（等效 150/回）；
  - 还要计入**战役期间阵亡人数**的累积损耗。
- **设计意图**：进攻方压力特别大——**除非毕其功于一役或国力大幅碾压**；前期战事天然稀少（呼应和平期），后期**用战役加量抵消城市规划的垃圾时间**（院长钦定节奏观）。

## 九、侦察与反侦察（R36）

- **侦察兵**=独立步兵兵种：**消耗资源少、产出快、机动性强、无战斗力、一触即溃**。
- **隐藏状态**：通过**地形（树林丛林等）或科技**进入隐藏，**持续传递周边信息**。
- **反侦察手段**：
  - **区域频段干扰**（电子战类）；
  - **扫荡模式**：步兵兵种大幅降低移速进入扫荡，**扫荡模式下的步兵可以看见敌方侦察兵**。

## 十、洲际导弹（R36 定稿）

- **间断时间向攻击距离内的敌方部队发起一次打击**——**只要弹药充足就能一直攻击**（持续火力投送）。
- **可手操，可自动化**。
- 与机动炮兵的差异：**炮兵可以移动**（导弹=固定点位）。

## 十一、战斗时长与节奏（R36）

- **单场战役半小时都行**（推翻 R4"5~8 分钟"口径——大地图运营需要时间）。
- 前期几乎无战事（进攻收益与代价失衡=天然和平），后期战役加量=核心体验填充。

## 十二、存档与观战（R36 范围变更）

- **战役途中可存档**：保留场上所有状态（战役太久）——**推翻 R23"回合边界快照、无战中存档"口径**，存档设计 v3 挂账（07-技术架构）。
- **一期直接做 L3**（原二期 RTS 档提前）——一期二期范围表刷新。
- **观战（R36）**：其他国家之间的战争，玩家可选**观战**——看一场 AI 之间的**沙盒模拟战斗**，允许**快进和跳过**。

## 十三、时间、撤离恢复与拉锯规则（R37 定稿）

### 13.1 战役时间轴

- **一场战役在一回合内进行**（1 回合=1 年，一年够打完一场战役）；一回合打下=**闪电战**（评价口径，无需额外奖励）。
- **跨回合（驻扎）情况**：世界继续转——**守方可外调援军或偷家**（偷家=战略层另派部队攻攻方其他城；攻方老家被威胁，围城方陷入两难）。

### 13.2 营地与溃败

- **营地被端 = 攻方全军溃败**（R37 定稿：不再是可撤离——营地=命根，守方端营地=决定性胜利）。

### 13.3 伤兵与撤离恢复

- **按比例撤离的存活部队视作满状态**（回归即战力，无伤兵管理——简化）。
- **军事基地/医院建筑可提升撤离比例**（医院=新建筑，R37 增列：伤员收治/撤离保全率）；**有边际效应上限**（防无限堆叠）。

### 13.4 围城期外交（R37）

- **可以谈判和介入**：守方可开城下之盟（割地/赔粮换撤军）；第三方可介入（联合国决议停火/共同防御条约援军/共同军参战）——与外交模块（一票否决权/同盟）联动。

### 13.5 多线并发

- **按顺序打**（我方同时多线时逐场进行）；**兵力跟随部队**——部队出城=守城兵力减少；**出征须武将带队**（守城武将相应减少）——多线作战天然受限于兵将与武将数量。

### 13.6 掠夺军事基地

- **可选择掠夺军事基地获取"战备"**——**战备=新子资源**：提升部队战斗力的数值加成（掠夺型玩家的即战力路线，代价=掠夺四代价 R14 不变）。

### 13.7 探索体系分层

- **L1 探索（海军舰队探图联系澳洲）与 L3 侦察兵（战场侦察）两套体系分开**——不共用单位与情报界面（L1 情报=国家级能力，L3 侦察=战术层）。

### 13.8 平局拉锯（驻扎期进攻规则，R37 定稿）

- 平局后攻守双方**每回合都可以发起进攻**：
  - **攻方发起 / 双方同时发起**：和正常一致（攻方进攻战）。
  - **守方发起**：攻方选**撤离**=回到己方城（等同撤离结束）；守方选**撤离**后，攻方可选**不追击（平局）**或**追击（开始消耗行军粮）**。

## 十四、待讨论（R37 后余留小尾巴）

3. 偷家判定细则（攻方老家被攻时围城方是否强制回援/可继续围城）——M6 或数值期。
