# 战斗总述

> 状态：✅ 框架已定（R4 路径 C 拍板；R13 战场细则大更新；R27b 战略层出兵与行军院长设计）· 更新：2026-10-26

## 定位：轻量 RTS（路径 C）

院长提出的矛盾：即时战斗像"开一局中盘红警"——加料则战斗喧宾夺主（经营是主菜），不加则与原版无差。
破题：**料加在情境差异、角色技能、决策节奏上，不加在每场必经的操作量上。**

### 三层设计

1. **战场情境层**：每场仗的地形/可拆建筑/防御塔由该城内政决定（打军事基地满级的北京与打空城是两张图）；现代战争变量（制信息权、无人装备、天网）只增变量不增操作；战斗类型按城市对分化（见 [战斗类型.md](./战斗类型.md)）。
2. **轻量 RTS + 带队武将技能**：保留 RTS 直感操控，**每个带队武将有各自可发动的招牌技能**（替代被否决的"战术牌组"提案）；技能消耗采配点数；平 A/寻路/集火交部队 AI。
3. **伪回合制（主动暂停）**：见 [操作与交互.md](./操作与交互.md)。

### 红警边界（防全面 RTS 化）

只借"建筑实体化 + 防御塔 + 拆基地"三点；**不借战中造兵/造建筑**——兵力内政期编成，战场是定局对弈，单场目标约半小时（R36 推翻 R4 的 5~8 分钟口径——大地图运营需要时间）。

## 自动 / 手动双档

| 档 | 形态 | 时期 |
|---|---|---|
| 自动档 | 全自动数值结算 + 文字战报 | **一期与手动档并存（R36）**；二期保留为选项 |
| 手动档 | 进入 L3 战场亲自指挥 | **一期已进（R36）**；二期表现力增强 |

**一套战斗判定模型两档共用**：自动结算公式即 L3 部队 AI 内核（R36 一期两档并存），手动档只加渲染与指令层，不写第二套规则。

## 部队与兵种（🏗️ 待专题）

- 部队规模：6~10 支/场（与暂停部署的操作量匹配）；
- 兵种：参考三国志 12 三角相克（枪/骑/弓）+ 攻城器械；现代化映射与无人装备（无人机蜂群/无人平台）待科技树专题联动（近现代武器装备调研见 `prd/01-需求文档/00-调研/03-产品与游戏设计/`）；
- **部队指挥双模式（R13，取代"部队必须由武将率领"旧规）**：
  - **远程遥控**：部队无角色亲率，玩家/AI 远程指挥——无技能加成，无被俘风险；
  - **御驾亲征**：角色编入部队亲率——可发动技能（采配消耗），但部队被歼灭时角色有被俘风险（见下节）；
  - 城内驻军可守不可攻（AI 补偿规则之一，保留）；
- 采配：随时间积累的技能资源（1~10 点档，参照原版）。

## 御驾亲征与被俘（R13）

- 角色编入的部队被**击溃消灭** → 角色变为**独立单位**：移速快、**5s 无敌不可选取**（脱身窗口）；
- 独立单位形态的角色**再被进攻** → **被俘获**，并**降低己方士气**；
- **全部角色被俘获 = 战役失败**（本场战斗判负，非全局败）；
- 被俘角色进入俘虏系统（劝降/释放/拷打/处决四处置，见 [02-武将/俘虏与处置.md](../02-武将/俘虏与处置.md)）；一期自动结算中表现为：带队角色随败兵概率被俘、全角色被俘直接判负。

## 战争迷雾与守军（R13）

- **守方兵力有限**：守军规模有硬约束（军事基地决定上限，不可战中无限刷兵）；
- **战争迷雾**：战场能看到**地形和建筑**，但**看不到其上的敌部队**；只有己方部队路过的区域才被彻底点亮；存在**科技点可开启视野**（卫星侦察类科技）；
- **侦察**：他城布防信息通过**外交或科技**获得（R13 院长定）——无侦察时仅见城防数字，有侦察可见 L2 布防图（细节待战斗/科技专题）；
- **守家优势 > 野战**（R13 院长定调）：城墙/工事/补兵加成下守方占优——**贸然出城野战容易被偷家**（守军出城=市政府方向空虚，呼应攻方根据地机制与驻留占领）。

## 胜负（R11 粮草时限制 + R13 市政府血条驻留占领）

- **攻方发起进攻必须提前组织粮草**：粮草量决定本次进攻的可持续时长上限（带多少粮 = 能打多久）；
- **攻方胜利（R13 细化）**：突破城墙防线 → 将**市政府血条清零** → 派出**陆战军队占据市政府一段时间**（驻留读条）才完全占城；**守方可将部队派入市政府**（相当于最后打一次巷战，读条期间可反夺）；
- **守方胜利（两条件任一）**：
  1. **拖到攻方粮草耗尽**——攻方时限归零自动败退；
  2. **占领攻方根据地**——攻方在城外的出发阵地/营地可被守军反打，端掉即攻方败退；
- **全军覆没条款（R13）**：攻/守任一方**全部角色被俘**即战役失败（先于上述判定）；
- 破城后：俘获太守（可逃跑）→ 四处置（见 [02-武将/俘虏与处置.md](../02-武将/俘虏与处置.md)）；
- 双档表达：自动结算中，粮草→结算回合上限、血条→城防结算阶段、驻留读条→终局占领判定参数、根据地→守方反攻判定参数；L3 手动档中（一期已含，R36），市政府血条实体 + 占领读条 UI + 攻方根据地实体。

## 战略层出兵与行军（R27b 院长设计全量落档）

> 位置：L1 大地图层面的军事操作模型——从"决定出兵"到"抵达前线"的全流程。战斗内细则见后续章节。

### 出兵决策（AI 与玩家共用规则）

- **防守优势 > 进攻**：攻城需集结显著优势兵力，AI 评判军力是否足够才发起进攻；**军力越大，进攻可能性越高**。
- **AI 出兵概率模型**：AI 用一个**概率**作进攻指令，该概率受**军力、政策、国家性质**影响（公式进数值期；国家性质=阵营特性表，见 [00-总纲/阵营与世界观.md](../00-总纲/阵营与世界观.md)）。
- **和平期结束后即有动手可能**（软引导期一过 AI 即恢复侵略性评估）。

### 行军与可见性（R34 修订：时长翻倍 + 亡国难民机制）

- **行军时长（R34 翻倍）**：内陆邻接 **2 回合**达 / 跨海 **4 回合** / 远洋（经达尔文）**6 回合**（1 回合=1 年口径，翻倍=战略纵深更真实，也给情报侦察留反应窗口）。
- **出兵需要时间**：部队从发兵到抵达前线有行军过程，**在陆地与海洋上可见行军**（L1 大地图实体移动）。
- **情报门槛**：看见他国行军需要**情报能力**（一期占位树"视野小科技"；无情报则行军不可见，抵达才知）。

### 不宣而战（sneak attack）

- 未宣战直接发兵进攻 = **不宣而战**：**降低目标国对本国的文化认同度 + 损害国际声誉**。

### 撤军（R40 补充，R40c 优先级定稿）

- 发兵后、**兵力到达前线前**可撤回；但撤军若**被发现**（对方有情报），**会被谴责**（关系 −5、声誉 −2，v0）。
- **撤离=上一回合内的决策**（R40c）：看到对方行军当回合下令，本回合结算执行——**撤离优先级高于进攻**：攻城结算前先执行守方撤离（有情报的守军撤得掉；无情报抵达才知、照常挨打）。
- **撤离不计算行军回合**（R40）：默认一回合内回城，回城兵力**即刻计入守军**——该城再被进攻时加回这部分兵力；代价=撤离时**按比例扣除兵力**（殿后伤亡，比例数值期待定）。
- 驻守部队可召回：返程 1 回合，不再扣粮（去程口粮已含往返）。

### 行军途中后方有变（R34 院长新立）

- **行军中原始城市被攻克**：军队**自行前往最近的己方城市**（不溃散，指挥链转移）。
- **若已亡国（无己方城市）**：军队变为**武装难民**（带军备的人口）——细则 R39 定稿：
  - **规模**：= 亡国时**残余军力全量**（人+装备）+ 该国**全部武将随军**；按"最近城市"自动分流多队（各地就近前往）。
  - **到达最近的他阵营城市**：该国**直接三选一**（不召开会议）——**接收 / 迁移 / 驱赶**：
    - **接收**：**要收全收，不能部分接收**；获得人口（他国人口）+装备入军备池；**代价**=进驻城市民生直接降低：`冲击值 = 难民规模 / 本城人口 × 系数`（上限 30 民生）——接收收益高，代价必须高额限制（R39 院长定）；
    - **迁移**：转送**本阵营其他城市**（分摊冲击）；
    - **驱赶**：推向邻国，双边关系 **−20**。
  - **到达最近的无主城市**（达尔文/起义中立城等）：**自立流亡政府**（难民必有武将带队）——流亡政府=已灭亡阵营的**半存续形态**：有据点城+残余军力+武将，但无外交席位/无内政全功能；**复国会议通过 = 流亡政府转正**（见 [05-外交/外交行动.md](../05-外交/外交行动.md) 复国会议）；
  - **两股难民**进入同一流亡政府 → **组队合并**；分别建立流亡政府 → **相互敌对、争夺正统**（谁转正由复国会议投票决出）；
  - 人口结构：接收难民=**他国人口**进入本城，他国人口过多会持续压低民生（见 [03-内政/人口与宜居度.md](../03-内政/人口与宜居度.md)）；政策可遣返/限制移民；
  - 滞留中立地带无人处置时，可走联合国会议表决（同议程，见外交行动）。

### 抵达前线后的选择

行军到目标城市，可选：

1. **进攻**：自动档=触发结算；手动档=进入 L3 战场（一期两档并存，R36）；
2. **驻守（就地驻扎）**：按回合数持续消耗粮食。

### 粮草口径（后勤从简）

- **行军口粮一次性扣除**：发兵时即一次性扣除**往返口粮**——**不要让玩家做太多后勤相关工作**（负反馈纪律）。
- 战斗期间的攻方粮草时限（拖粮尽守胜法）沿用 R11 口径。

## 核武器机制（R32 钦定 · R34 细化定稿）

| 项 | 定稿（R34） |
|---|---|
| **解锁链** | **物理实验室**（建筑，前置）→ 民生环保线"核能和平利用"（科技）→ 军事线"核武化"（二段科技）——核武化即触发全阵营谴责（R33 已定） |
| **铀贸易规则** | 铀**可买卖**，但要求**开采国有能力开采**（铀矿场建筑在开采国境内）；**他国入境开采**=特殊贸易协定（需付出足够多代价，或足够高友好值+文化认同——R34 院长钦定） |
| **生效层级** | **核武在 L2 级生效，不在 L3 级生效**——核打击是战略层指令（点地图发射），不进入战斗场景操作 |
| 载具 | 洲际导弹（弓兵系固定点位类，兵种目录 v2）：射程=邻接+远洋 1 跳；不需行军 |
| 打击效果 | 目标城防 −50%、市政府血条 −30%、驻军歼灭 40%、核污染残留（10 回合产出 −50%/宜居 −30） |
| **核辐射 debuff（R34 新增）** | **进攻被核打击后 10 回合内的城市，进攻方军队也受 debuff**（v0 战力 −20%——核污染不分敌我，废土攻坚有代价） |
| 拦截 | 基础 30% + 反核科技（JP 特色）+40% + 萨德词条城（首尔）+20% |
| 产能 | 每国每 5 回合至多 1 枚（防核 spam） |

- 外交惩罚（发展谴责/发射敌对/文化输出重创）见 [05-外交/外交行动.md](../05-外交/外交行动.md) §核武器与声誉。

## 战后处理（R13 负反馈纪律 / R14 掠夺机制）

- **掠夺（R13/R14 定）**：战役期间攻方可**掠夺建筑获取资源**——掠夺商业区得财、农业区得粮（对应二期"城外地表建筑"实体）；
  **掠夺的四项代价（R14）**：①引起（对方城）民众反感 ②影响攻占之后的战后重建 ③国际声誉受损 ④本国国内民众反对——掠夺是"眼前资源 vs 长期代价"的攻方选择，不掠夺则占城后接收更完整、重建更快（掠夺程度待战斗专题参数化）；
- **从轻**：不轻易出现"设施破坏需要修复"类惩罚（负反馈纪律见 [00-总纲/游戏定位与范围.md](../00-总纲/游戏定位与范围.md)）——掠夺由攻方主动选择，非掠夺的战损不进"废墟清理"流程，具体从轻方案（自动保留/轻微损毁快速自愈）待战斗专题定。
