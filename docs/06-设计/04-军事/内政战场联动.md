## 映射表

| 内政建造 | 一期（数值结算）效果 | 二期（实时战场）实体形态 |
|---|---|---|
| 城墙（等级） | 城防值上限、攻城减伤/坚守 | 环绕市政府核心区的可破坏墙体 + 城门（突破点） |
| 军事基地 | 守军兵力上限、训练度加成 | 战场内"出兵建筑"：战损补充/援军刷出点；被拆=失去补兵能力 |
| 城防炮塔（原箭塔） | 守方杀伤系数 | 自动射击的防御塔（红警哨戒炮逻辑）；Lv1~2 需炮兵驻守/Lv3 免驻守 |
| 农田/商业中心 | 城内存粮/财（影响围城坚持时间） | 城外地表建筑，可被攻方掠夺（焦土压力，逼野战） |
| 娱乐中心 | 守军士气/民生 | 市政府附近士气光环 |
| 科技线节点 | 解锁兵种/结算系数 | 新兵种单位、建筑外观与攻击方式升级 |
| 城市范围（发育度） | 破城难度系数 | 战场半径/塔位数/市政府离城门距离（见 [01-地图与城市/城市成长与城防.md](../01-地图与城市/城市成长与城防.md)） |

> 建筑级数值与 L3 实体映射见 [军事建筑数值](./军事建筑数值.md) §四（兵营/城墙/基地/炮塔/防空/雷达/机场；实体归属=L3 战场模板内——2026-11-29 B 方案）。

## 胜负目标

攻方：突破城墙防线 → **占领市政府** = 完全占城（R11 定；军事基地为必经削弱目标）。守方：拖到攻方粮草耗尽，或占领攻方根据地。详见 [战斗总述.md](./战斗总述.md) 胜负节。

## 架构纪律

一期引擎数据结构必须数据同源（城市/阵营/数值数据同一份 GameState），严禁各写一套；表现分离——L2=经营渲染，战斗=独立会战图按 BattleContext 单向注入实例化（2026-11-29 院长裁 B 方案，见 [00-总纲/L2L3关联性讨论](../00-总纲/L2L3关联性讨论.md)；架构总述见 [07-技术架构/架构总述.md](../07-技术架构/架构总述.md)）。
