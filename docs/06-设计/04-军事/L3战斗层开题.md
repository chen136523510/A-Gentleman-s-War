## 一、定位与边界

1. **L3 是什么（R35/36 已定）**：红警式地盘战场（城+野地）/军棋式战前布置/四方向地图/增援与第三方选边/观战 AI 沙盒/**单场约半小时**/不做战中造兵、不做包围反包围。
2. **双档铁律（战斗总述 2026-11-13 院长令）**：一套战斗判定模型两档共用；**自动档=L3 缩略加速**（禁抽象战力比、禁第二套规则）；L3 实时无回合；手动档 L1 只回填结果。
3. **L3 可操纵的可移动单位 = 部队 + 武将**（院长 11-22 裁，见 D1）。
4. **本开题管**：实时演算内核（单位/战斗解/士气/指挥/自动档）+战场表示+与经营层耦合。**不管**：L1 战争规则（宣战/动员/和约=军事专题方向 A 另单）。

## 四、架构（E1~E10 已裁，2026-11-23）

### 4.1 战场表示（D10）
- **L3 地图=L2 城市 96×96 格网同步**：地形/建筑/街道=同一份数据；L2 建筑在 L3 的实体映射（血量/掩体/驻扎容器）随施工展开。
- 无新增据点系统（D7）——占领/胜负走既有实体（市政府/根据地）。
- 增援：第三方选边/增援队列沿 R35/36；容量暂无上限（D13）。

### 4.2 部队与武将（D1）
- **部队**：单兵种人数集合（兵员数=战斗力基数），字段=兵种/兵员数/伤兵数/装备档/番号名/主将(可空)/士气/趣味统计（战役次数/杀敌数/阵亡数）；番号跨战役保留；解散回退未编队池。
- **L1/L2/L3 一致性**：L1 兵种池（f.units 七类）−已编队人数=可编队余量；编队/调整/解散只在 L2（战役内冻结编制）。
- **武将单位**：L3 独立可操纵单位（与部队并列）；属性/被攻击/被俘口径对接监狱系统——细则随 M 施工展开（挂账）。

### 4.3 战斗解（D2/D3/D14）
- 逐帧事件结算（攻击事件→伤害→伤兵/阵亡）；聚合战损对齐 sim B1（校验带 ≤10%，超差调帧参数不改公式）。
- **必中**；例外清单当前为空（原则：例外只来自明示机制）。
- **友伤全对局永久关闭**（无开关）。

### 4.4 士气（D8，数值=黑机初值，模拟盘可调，全进 balance.json `l3` 组）
- 士气值 0~100（有主将初始 +15，即 75 起步）；**乘区**作用于攻击与防御：高昂 ≥85 ×1.10｜正常 45~84 ×1.00｜低落 20~44 ×0.85｜溃散 <20 **或只剩伤兵** ×0.60。
- 事件：歼灭敌部队 +10（己方全队）｜己方部队被歼 −10｜主将阵亡/被俘 −25。
- **UI 链**：高昂-正常-低落-溃散（溃散=只剩伤兵强制触发）——链=表现层，无溃走/俘获机制。
- **士气事件**：歼灭/被歼/主将阵亡三项；**伏兵攻击减士气保留（v0 −15，2026-11-24 院长裁）**；**突袭士气 ±20 已作废（2026-11-24）**——突袭只保留前 3 tick 攻方 ×1.20 乘区（兵种数值表 §8.1）。

### 4.5 操控（D5）
- 命令三态+机制开关（默认驻守自动攻击）；A+左键=攻击移动；特殊状态（潜行/隐身类战技）不自动攻击、碰撞体积接触才交火。

### 4.6 技能（D6）
- 武将主动战技（1 武将 1 主动，军事专题 E 项）+**空军使用**（轰炸机冷却出击 AOE/无人机侦察——机场/大营实体对接 96draft 五卡翻正）。

### 4.7 自动档（D9）
- 同一实时模拟跑 AI vs AI（禁第二套规则）；**AI 只读已知信息**（视野/已侦察，无天眼）；**难度=操作水平档**（决策频率/走位精度/集火效率，不加数值）；玩家中途接管；战报同 seed 可复盘。
- AI 行为参考王者荣耀 AI 档次（可调档），行为设计随 M4 施工细化。

### 4.8 经营耦合（D11）
- **驻扎**：城内建筑替驻军承伤（血量阈值自动撤离）、**驻军可从建筑内攻击**。
- **电力闸门（简版）**：开战查电力满足率 pr——低电力→防御工事火力/视野按 pr 折减（消费现有乘区，不新增系统）。
- 老兵暂不做（挂账）；海军两栖不做。

### 4.9 与 UI 基座
PanelRouter L3Battle 状态位；战场 HUD（部队面板/士气链图标/武将面板/战报）等手绘稿；部队管理 UI 在 L2（编组/调整/命名/统计查看）。

### 4.10 建筑交互、光标与表现规格（2026-11-23 院长裁定）

#### 4.10.1 建筑战斗状态与进入规则
- `buildings.json` 增字段：`attackable`（可攻击）/`enterable`（可进入）/`plunderable`（可掠夺）/`blocksMovement`（硬挡）/`capturable`（可占领）/`destructible`（可摧毁）/`fadeWhenOccupied`（进入淡出）。现有 `category`/`defense` 为基础（城墙 defense 200、军事基地 100）。
- **敌方军事/防御建筑**（城墙/军事基地等）：完整时**可攻击、不可进入**；城墙被摧毁后对应网格变可通行（只更新受损段）；军事基地 HP 归零后**转为普通建筑**（可进入/可掠夺，掠夺爆产出 ×2）。
- **敌方普通建筑**：**可直接进入**（掠夺前提）、可掠夺；一期不作为攻击目标（避免与掠夺冲突；若后续开放拆毁，同样按"摧毁后可进入"通用规则）。
- **占领**：市政府等 `capturable` 建筑被攻占后归己方，可进入/驻守；**敌方建筑被摧毁或攻占后即可进入**（通用规则——主要针对完整时不可进入的军事/防御建筑）。
- **己方/中立建筑**：可进入/驻守；进入即淡出（`fadeWhenOccupied`），关闭该建筑表现层碰撞，呈现"室内"。
- **表现层碰撞**只作用于被画出来的近景士兵；建筑淡出/摧毁后关闭；sim 只认部队锚点，士兵碰撞不反馈逻辑。

#### 4.10.2 驻守与掠夺
- **驻守**：部队在己方/中立/已占领建筑内可用；防御提升、不可移动、可攻击范围内敌军、伤兵恢复；建筑替驻军承伤（D11 既有口径）；可撤离。
- **掠夺**：仅当部队站在**敌方普通建筑**内可用；持续引导，按建筑等级 **Lv1 8s / Lv2 12s / Lv3 16s**（`balance.l3.plunderSeconds`，可调）；受击打断、可手动打断；打断后再掠夺需从 0 重新引导。
- 掠夺产出：**3 回合建筑产出**（`plunderYieldTurns=3`），等级系数 1/1.5/2；军事基地废墟掠夺 **×2 爆产出**（`plunderMilitaryBurstMult=2`；R37 战备产出沿用，爆产出指建筑产出侧）；具体数值进 `balance.l3`，随后续模拟调。
- 玩法：掠夺=有取舍的持续行为（给敌方反应时间）；进度条+建筑淡出；被攻击立即中断。

#### 4.10.3 光标与右键交互（待 UI 设计）
- 光标状态机（数据驱动 `cursorRules`，UI 只做解释器）：`Default/Move/Attack/Enter/Plunder/Garrison/Select/Invalid/Target`。
- 优先级：`Attack`（敌方部队/可攻击建筑）> `Plunder/Garrison/Enter` > `Select` > `Move` > `Default`。
- 视觉约定：**红剑=可攻击**；**门/箭头=可进入**；**金币+门=可掠夺**；**盾/房=可驻守**；**空地/脚印=可移动**；**禁止符号=不可操作**；己方部队=友好框。
- 右键菜单（选中己方部队）：驻守/掠夺/撤离/停止/攻击/技能；按条件亮起或灰显，灰显带 tooltip 说明（如"需站在敌方普通建筑内"）。
- 无障碍：红剑不只靠颜色，配形状/图标；色盲模式可换图标。
- **UI 设计待院长手绘稿/UI 专题**；本节只锁定交互语义与优先级。

#### 4.10.4 LOD 与表现比例（4060/16GB 基准）
- **渲染 60fps + 逻辑 30Hz**（E2）；LOD 只影响表现，不影响玩法。
- LOD 按**屏幕像素高度**分档（1080p 初值）：近景 ≥16px（低模+烘焙动画+胶囊碰撞）；中景 5~16px（Impostor 面片）；远景 <5px（方阵/色块/军旗+数字）；迟滞 16/13px、5/4px；**默认镜头=中景**；玩家用**鼠标滚轮**缩放、LOD 自动切换；具体阈值待地图/UI 后调（`balance.l3.lodNearPx/lodFarPx`）。
- **质量档**：高 6000 低模+50000 面片 / 中 3000+30000 / 低 1500+15000 / 极低 500+5000；自动降档优先关阴影→缩 impostor 距离→降预算→降特效→降渲染分辨率；逻辑 tick 不变。
- **表现比例**：`R = nice_ceil(总兵力 / 视觉预算)`，开局算一次、整场不变；每部队视觉人数：兵力 <20 时按 1:1；否则 `max(20, min(2000, round(兵力/R)))`；全局总数超预算时提高 R 重算；方阵占地 ∝ √兵力；损耗按 R 递减模型数、方阵收缩；UI 数字精确。**不要求 1:1 全画**。
- 例：3M 大会战 B=6000 → R=500，30 队各 200 模型；2k 小队战 → R=1，2 队各 1000 模型（全模型）。
- 帧预算（4060/1080p60）：CPU ≤8ms、GPU ≤14ms；逻辑 1~2ms；表现层第一天按 SoA/NativeArray/实例缓冲设计，Burst/Jobs 后置但不改架构。

## 七、验收标准
1. 同 seed 两场自动档战报逐帧一致；聚合战损与 sim B1 偏差 ≤10%。
2. 手动档指令响应 <100ms；暂停中命令队列恢复后正确执行。
3. 教学局科技胜利收尾不受 L3 影响；前 10 回合和平。
4. N 阵营 smoke 必过；参数零内联（balance `l3` 组）；L2↔L3 同步一致。
5. 单场时长：手动 ~30min；自动档 8x ≤5min 实时。
6. **建筑**：城墙摧毁后网格通行；军事基地血量归零转普通建筑且掠夺 ×2 爆产出；敌方建筑摧毁/占领后可进入；驻守/掠夺条件正确。
7. **掠夺**：Lv1/2/3 引导 8/12/16s；受击/手动打断；重掠夺从 0 引导；产出=3 回合×等级系数（军事基地废墟 ×2）。
8. **表现**：默认中景；滚轮缩放 LOD 自动切换；16/5px 初值；高/中/低档自动降档保 60fps；3M 兵力下模型≤6000+面片≤50000；方阵占地/损耗/UI 数字可读。
9. **光标**：红剑/门/金币/空地/禁止状态与优先级正确；右键菜单条件与灰显 tooltip 正确。
