## 八、使用纪律

1. **教程不写通用旁白文本**；只写教程专属对话/事件卡/提示弹窗。
2. 文本模型填充时保持：公文白话、无性格梗、无隐喻（院长 11-16 文风令）。
3. 专有名词用变量占位，由 UI 着色（武将/城市/阵营三色）。
4. 新增系统先在 §一~§七 补场景行，再交文本填充；不在代码里内联文案。
