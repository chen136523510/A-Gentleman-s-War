## 三、经济类（黄 · 10 张 · 11-24 四裁：耕地红线移出）

> 槽位 2。**11-24 四裁：耕地红线移入通用**（§六 通-14）→ 经济 10 张：减税/增税/生育补贴/优生优育/私有化/国有化/基建狂魔/福利国家/产业补贴/反垄断。
> **私有化/国有化数值审慎（院长 11-24 第 1 条）**：商业产出经结算反哺财收（净商业:税=3.10），**私有化不扣"财政收入"**——否则商业×1.10 与财收×0.90 同轴自我抵消（减税 P0 教训）。方向定、数值待 v26 模拟盘。

### 经-07 私有化 `privatization`（✅ 11-24 院长定向 · 替换招商引资）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 黄 / 中期 |
| 效果 | **商业产出提升；消费力池提升；财政收入下降**（国资收益流失，机制型成本） |
| 解锁 | 开局 |
| 落点 | `CalcCommercial` / `poolK` / 税收 |
| 互斥 | `industry`（vs 国有化） |

**设计思路**：院长 11-24 裁——"跟国有化互斥的应该是私有化市场经济"：招商引资不是国有化的反面，**私有化**才是（撒切尔/休克疗法；真实政策语）。国有化=国家集中（财收↑、消费池↓），私有化=市场化（商业↑、消费池↑、财收↓）——正好同轴镜像。原 `investmentWelcome`/招商引资作废。
**数值**（**v26 盘 v1.2 定**）：**商业 ×1.15 / 池 ×1.025**——不扣财政收入（商业产出经结算反哺财收，扣则同轴抵消）。池乘区只有 ±2.5%：v26 实测池 ±5% 在真实建造盘有复利放大（消费池→商业→财政→建造），会压过 comm 主效果，故幅度减半保留方向。稳态（nobuild）增益 +8.4%。

### 经-08 国有化 `stateIndustry`（✅ 11-23 定）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 黄 / 中期 |
| 效果 | **财政收入大幅提升；消费力池下降（示意市场流动性下降）** |
| 解锁 | 开局 |
| 落点 | 税收 / `poolK` |
| 互斥 | `industry`（vs 私有化） |

**设计思路**：国有化（院长 11-23 口径）——国家集中产业，财政收入大幅增；但市场流动性下降，消费力池走低。与私有化互斥（国家集中 vs 市场开放）。
**数值**（**v26 盘 v1.2 定**）：**总财收（税+商业）×1.07 / 池 ×0.975**。口径必须是**总财收**——只乘独立税项会使国企增益相对私有化不可感知（v26 实测只乘税时净增益近乎为零）。稳态增益 +11.6%；建造盘 +4.7%。与私有化分工：本卡强在财收轴（短期现金流）、弱在商业/消费轴；私有化强在长期复利（7 seed 均值建造盘 +16.7%）。

### 经-13 反垄断 `antitrust`（✅ 11-24 院长定）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 黄 / 中期 |
| 效果 | **消费力池 ×1.08（消费力随之实现）；商业产出 ×0.95**（院长口径：提升消费力池和消费力、降低商业） |
| 解锁 | 开局 |
| 落点 | `poolK` / `CalcCommercial` |

**设计思路**：反垄断——拆巨头、护竞争：消费端受益（池上限抬升，消费力=池内实现随之增加；不另设独立"消费力"乘区，避免虚空参数），商业利润受压（大企业规模效应削弱）。
**数值**（白机定）：消费力池 ×1.08；商业产出 ×0.95（机制型成本）。
