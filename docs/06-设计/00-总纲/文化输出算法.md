# 文化输出算法专题

> 状态：🏗️ v0 骨架（R28 立项仿真定案 · R30 文化值口径修订：城市总和制+科技因子+互联网民生乘数）
> 定位：文化胜利的核心引擎——N×N 文化输出值矩阵的完整算法链（文化值→输出值→认同度转移→完全入侵判定）。
> 上游口径：[胜利条件.md](./胜利条件.md) §二（概念定义与判定链）；数值风格对齐 [数值设计总纲](./数值设计总纲.md)（体验先行/回合本位/收放成对/明牌）。

## 一、算法总览（结算流程，每回合结算阶段执行）

```
① 文化值结算     各国文化值 Culture += 本回合文化增速（内政产出，§二）
② 输出值结算     输出矩阵 Output[A→B] = f(文化值, 传播系数, 战争状态)（§三、§四）
③ 认同度转移     各国认同度 Identity[B: A] 按 Output[A→B] 与 B 的文化抵抗力变化（§五）
④ 完全入侵判定   Identity[B: A] ≥ 60% 且持续 → B 对 A 完全文化入侵（§六）
⑤ 胜利检查       文化胜利判定链（联合国成立→当选盟主→全部完全入侵+维持 10 回合）
```

- 明牌纪律：矩阵与认同度**可在情报界面查看**（自己做主的内政数据不做暗账）；对别国的**认同度细节需情报/外交**（侦察他城布防同理）。

## 二、文化值（对内积累层；R30 口径 + 11-05 文化区修订）

> **R30 院长口径（部分已被 11-05 文化区裁 A 覆盖）**：①每个城市都会提供文化值，**国家文化值 = 城市文化值历史累计**（失城不回溯）；②可通过**政策（政策卡）整体加成**；③~~城市维度的文化值由因子间接影响（不直接建"文化区"建筑）~~ → **11-05 改：建筑直产为主 + 因子修正层**；④**科技影响文化**（1999 剧变科技退化严重——科技落后的文明文化吸引力低）；⑤**互联网互连效应**：两个国家都接入互联网科技时，**民生水平也影响文化输出**。

```
国家文化值 Culture_t = Culture_0 + Σ_{τ≤t} [ Σ(当前城市文化产出_τ) × (1 + 政策加成) ]
城市文化产出 = ( 基础值(压低) + Σ(建筑文化值 × 在岗率) ) × (1 + 0.10 × 传媒大学数[每城限1]) × 宜居/人口/科技因子 − 污染惩罚
互联网互连乘数：见下方输出层乘区 ②（11-05 院长修正：双方均解锁"互联网"科技即生效，不要求互连/航线）
输出层乘区（乘在 Output 公式尾，不动存量层——防复利；11-05 院长裁 #9 落位）：
  ① 传媒大学乘区（11-05 院长修正）：**每城限 1 所、本城文化产出 ×1.10**——城市级乘区（进 §二 城市文化产出公式），**不再是全国输出叠加**（层级铁律：城市产出=城市级）；学院区三级卡
  ② 互联网民生乘数（院长定性"好的更好、差的更差，尤其是同受多国输出比较时"）：
     生效条件（11-05 院长修正）：A、B **双方均解锁"互联网"科技即生效**，不要求互连/航线；
     m(A→B) = clamp(1 + 0.6 × (W_A − W_B) ÷ 100, 0.7, 1.3)
     W=国家级民生（人口加权）。民生高者输出被放大、低者被压缩——同一目标国市场上强者通吃；
     民生差 50 点满档 ±30%；单方未解锁不适用；交战双边清零（§三）优先于本乘数
  ③ "电子长城"政策（11-05 院长新增，当世朝鲜式锁网）：实施国 A → 互联网民生乘数对 A **双向失效**
     （m(A→*)=m(*→A)=1，退回无乘数状态）——既放弃己方民生优势的放大，也挡住外国的压制输出
     （锁网动机=防渗透）；政策卡登记见 [政策与政体.md](./政策与政体.md) §四
```

- **存量历史累计、失城不回溯（11-05 裁）**：城市被占领后，**过去贡献的文化值已入原主国家级存量**；只有**未来产出**改归占领方。战争滚雪球可接受（战争本身有高代价）。
- **战争不影响文化值增速**（R27b 钦定）——文化存量是"家底"，打仗烧的是输出（见 §四）；11-05 补充：军管期（10 回合）被占城文化产出 ×0.5。
- 收放成对：文化增速没有直接 sink（存量只涨），消耗发生在输出层（输出竞争与战争衰减）——对账表在 §四。

## 三、文化输出值（对外渗透层，N×N 矩阵）

```
Output[A→B]（A 对 B 的文化输出值，/回 结算一次）

v0 公式：Output[A→B] = Culture_A × 距离系数 × 联系系数 × 情报系数 × 战争衰减
```

| 系数 | v0 取值 | 说明 |
|---|---|---|
| 距离系数 | 邻接 1.0 / 远洋 0.6 / 未联系 0（澳洲隔绝门槛） | 邻接城越多输出越强；远洋需经达尔文枢纽 |
| 联系系数 | 有航线 1.0 / 无 0.5；同盟 +0.2；共同语言事件待定 | 开航线=文化通道 |
| 情报系数 | 有情报 1.0 / 无 0.3 | 不了解对方=输出盲目（呼应侦察体系） |
| 战争衰减 | 交战 0 / 停战 0.3 恢复期 / 和平 1.0（停战后每回 +0.1 至 1.0） | **战争只影响输出值**（R27b 钦定） |

### 凸性仿真结论（R28，「都跑一遍，用数据说话」）

> 仿真设定：60 回合四国对局（CN 增速 10+invest×0.3 / JP 增速 9+每 15 回合战争 3 回合 / KR 增速 11 / AU 增速 7+25 回合前隔绝），脚本 `tmp/culture_sim*.js`（过程产物不入库）。

| 维度 | 线性（Culture/10） | √Culture |
|---|---|---|
| 同参数下入侵节奏 | 更快更狠（k=0.002 已 2 个入侵） | 更缓更稳（k=0.003 才 1~2 个） |
| 大国压制力 | 后期文化 4 倍=输出 4 倍，小国数学绝望 | 4 倍文化只 2 倍输出，小国有追赶空间 |
| 两极锁死验证 | ✅（瓜分各 40%<60%） | ✅（瓜分各 40%<60%） |
| 平衡手感 | 平衡点敏感（k 微调入侵数跳变大） | 平衡点宽容（k 区间内节奏平滑变化） |

- **结论：采 √Culture 凹函数**——两案闸门效果等价，但凹函数在"小国追赶空间"与"参数宽容度"上全面占优，与"KR 种子选手/AU 后期发力"的阵营设计最契合；线性案留作修改器对照档。
- **k 参数建议区间**：0.002~0.003（√ 模式）——60 回合达成 1~2 个完全入侵（KR→JP 文化共振真实涌现；CN→AU 隔绝解除后的单向碾压），"能赢但很难"；具体值进 balance.json 数值期定。

- **四大闸门的算法内建**（R27 院长设计 → 公式化落地）：
  - 澳洲隔绝 → 联系系数=0（未解锁联系门槛时矩阵整列为 0）
  - 韩日文化两极 → 认同度转移的"对等抵消"规则（§五.瓜分）
  - CN 倾向吞并 → AI-CN 不投资文化输出竞争（AI 行为层，不进公式）
  - 日本军国主义 → 频繁战争使 Output[JP→*] 长期低位（战争衰减拖住）

| 资源 | 来源 | sink/消耗 |
|---|---|---|

## 五、认同度转移（B 国的认同度如何被 A 改写）

```
B 的认同度集合 Identity[B] = {本国: x%, A: y%, C: z%, ...}，Σ = 100%

每回转移量 Δ = k × Output[A→B] ÷ B 的文化抵抗力 Resistance_B
Resistance_B = 40 + Culture_B ÷ 50（v0：文化值越高越抗打）

本国认同转移方向：本国认同 → 输出国认同（按各输出国 Output 占比瓜分）
多国对同一国输出时：份额 = Output[A→B] ÷ Σ(所有国对 B 的 Output)
```

- **对等抵消（两极格局公式化）**：A、C 文化值相等且同时彻底输出 B → B 的外国认同份额按 1:1 瓜分（院长 50/50 示例的公式化）——两国对峙时 B 的认同被"撕扯"，谁都到不了 60%。
- **本国认同底线**：本国认同 ≥ 20% 恒成立（极端例子只是极端——完全入侵后本国仍留 20% 底，文化清洗不可彻底，负反馈纪律）。
- **反向侵蚀**：B 对 A 输出同样在跑（双向矩阵）——文化战是攻防一体的，小国"高抵抗力+精准输出"可反向逆袭（KR 种子选手机制的算法底座）。

## 九、v1 修订提案：让文化入侵真正有效（11-05 院长令"可以优化数值，让文化入侵有效"）

> 状态：🏗️ **提案待裁**（白机起草 2026-11-05）。不改 R28 已裁的 √ 凹函数骨架与 60/50/20 三数；**改的是"转移机制"**。

### 9.1 诊断：0 完全入侵不是 k 太小，是数学上永远达不到

现行 §五：`Δ = k × Output ÷ Resistance`，`Resistance_B = 40 + Culture_B ÷ 50`。

- Output ∝ **√存量**，Resistance ∝ **存量**（线性）→ 转移速率 ∝ **1/√t**，越到后期越慢；
- 用 v11c 实测代入（t200）：CN 存量 34.4k → Resist 728；KR→CN 的 √14000=118 → Δ≈0.0004/回量级；
- k 扫描实证后果（v11c）：k 提到 0.01，**本国认同全线崩到 24~41%，但仍 0 完全入侵**——因为多国同时从本国认同里"各抢一块"，谁也到不了 60%。
- **结论**：现行机制下"完全入侵"只能靠暴力拉 k，而拉 k 先崩本国认同（负反馈失效）。这是**结构问题**，不是参数问题。

### 9.2 方案 A（推荐）：份额收敛式

把"多国各抢一块"换成"认同度向**输出份额**收敛"——本国也是一路输出，抵抗投入=抬高自己的份额。

```
① 文化压力（沿用 R28 √ 凹函数 + 四系数，去 k）
   P[A→B] = √Culture_A × 距离系数 × 联系系数 × 情报系数 × 战争衰减
   本国自压  P[B→B] = √Culture_B × (1 + 抵抗力加成)     ← 抵抗投入的落点（文化建筑/政策/事件）
② 目标份额
   Target[A→B] = P[A→B] ÷ ( P[B→B] + Σ_{X≠B} P[X→B] )
③ 收敛（每回一次）
   Identity[B:A] += r × ( Target[A→B] − Identity[B:A] )      r = 0.05
④ 判定不变：≥60% 且持续 5 回 = 完全入侵；<50% 解除；本国认同 ≥20% 兜底
```

- **对等抵消自动成立**（R28 §五原裁不用改）：A、C 输出相等 → Target 各 40%（B 自压 118/(185+118+185)≈24%），谁都到不了 60%——两极锁死由公式天然给出。
- **单极碾压可达**：CN 对 KR 若占份额 65%（邻接+航线+情报全开 = 1.0，他国远洋无情报 = 0.09），60 回内收敛到 62% → 完全入侵。**文化胜利从"添头"变成"经营可达成的目标"**。
- **抵抗有落点**：不想被入侵 → 建文化建筑/政策卡抬 P[B→B]（份额防御），不是考数学硬墙；且开销在财/产能，与军事防御争资源——负反馈闭环成立。
- **k 扫描的"本国崩塌"问题消失**：本国份额是分母里的实打实一项，多国输出只是分掉剩余份额，不会再出现"大家都在抢、本国归零"的怪象。
- 收敛速率 r=0.05：约 20 回走完 63%、60 回走完 95%——单局 200 回合内可完成 2~3 次入侵节奏，给"文化胜利=200 回合内达成"留出空间。

### 9.3 方案 B（保骨架微调，备选）

- `Resistance_B = 40 + 60 × clamp(Culture_B ÷ Culture_avg, 0, 1.5)`（绝对墙→相对墙，clamp 40~130）
- k 上调 0.0025 → **0.012~0.02**；完全入侵阈值 60% → **50%**（缓冲 42%）。
- 校验风险：k=0.01 已在 v11c 造成本国认同 24~41%，k 再翻倍会更碎；阈值降到 50% 会削弱"独占性优势"语义（与"多国瓜分"设计冲突）。**不推荐**，仅作修改器对照档。

### 9.4 配套：文化产出数值调整（院长授权"文化产出可以继续调整"）

- **不动已降档的建筑本体**（博物馆 4/会展 6/世博 10）——降档理由是"不影响节奏只压数值展示"，v11c 存量 34.4k 偏高的问题仍由 v11d 复核；
- **改输出侧口径**：份额模型下，**决定性变量是系数差与份额**，而非绝对存量——这让"开航线/派情报/同盟"从"聊胜于无"变成"文化战略的主操作"，与经济/军事决策同权重；
- 若 v12 实测仍偏慢：balance.json 留三档总闸（`cultureOutputScale` 0.8/1.0/1.25，乘在 P 上）——**参数化而非写死**，调参不动公式。
- 文物池数值随 v0.2 建筑卡同批（对撞 1）：份额模型下文物不追求绝对量级，保持"子弹"定位即可。

### 9.5 新增机制：**文化失所**（✅ 2026-11-05 院长新立）

> 院长原话："在有多极文化冲击本国文化时，本国要受到相当于被文化入侵的特效。意义在于：虽然国民不知道认同什么文化，但肯定不认同自身文化。"
> 命名：**文化失所**（术语表待收录；备选"文化迷茫"）。定义=**多极文化同时冲击导致本国认同碎片化，本国遭受近似被入侵的惩罚**——不同于被单一国家完全入侵（那是"认同别人"），这是"谁的都不认同，包括自己"。

```
触发条件（两条同时满足）：
  ① 本国认同 Identity[B:B] < 40%
  ② 最大外国认同 < 60%（=没有任何单极主导，纯碎片化；若已有单极主导则走完全入侵）

效果（✅ 11-05 院长修订：不减文化产出，改罚"人"与"军"）：
  - 征兵能力 ×0.85（不愿为不知道为何的国而战——征募上限 −15%）
  - 战争能力 ×0.9（战斗结算乘区，与被入侵同档）
  - 忠诚流水 −0.5/回（迷茫期，接 Q1 流量制）
  ✗ 不扣文化产出（院长："不然太难追上"——文化落后方本来就被动，再砍产出会陷入死亡螺旋）

解除：Identity[B:B] ≥ 45%（迟滞带，防抖动）
```

- **设计意义（补上份额模型的关键一环）**：份额模型下多极对峙=谁也到不了 60%（对等抵消），原先读作"文化战僵持、双方无事"。文化失所把僵持变成**负和**——多国混战的文化战场，小国/被围攻国先受伤，逼迫玩家在"文化对抗"与"文化自守（抬自压）"之间做选择。
- 与"完全入侵"的区别：

| 状态 | 触发 | 语义 | 效果强度 |
|---|---|---|---|
| 完全入侵 | 某外国认同 ≥60% 持续 5 回 | 认同**别人** | 战斗 ×0.9 + 开战 debuff |
| **文化失所** | 本国认同 <40% 且无单极 | 谁都不认同，**包括自己** | 征兵 ×0.85 + 战斗 ×0.9 + 忠诚 −0.5/回（**不扣文化产出**） |

### 9.7 v12a 模拟结果（✅ 2026-11-05 已跑 · 脚本 `tmp/sim-culture-v12b.js`，不入库）

**口径**：200 回合、四阵营、r=0.05、文化失所、抵抗 0/25/35/50% 四档 × 两种玩法（baseline=谁都不经营文化输出 / culturePush=CN 全力押注：文化×1.5+情报全开+航线全开）。

**第一轮结果（不加势差乘区）→ 0 完全入侵**。最高外国认同仅 43.7~49.4%。原因：√ 凹函数把 2.46 倍文化差压缩成 1.57 倍输出差，叠加他国分流，单极份额到不了 60%。**这是机制缺口，不是参数问题。**

**结论四条**：
1. **机制达成设计目标**：押注文化 → 能入侵（1~2 个）；不押注 → 0 入侵。文化胜利=**经营可达成的目标**，不是靠参数。
2. **抵抗 50% 不高**（回答院长疑问）：35% 与 50% 结果几乎相同（都是 1 个入侵），但 50% 把最低本国认同从 23.2% **抬到 25.1%**，更安全。**建议保留 50%**，v12 全量版再看是否下调。

### 9.8 模拟发现的新增机制：**文化势差乘区**（⏳ 待院长裁）

> v12a 第一轮 0 入侵暴露的机制缺口：√ 凹函数压缩了大国优势，单极份额永远到不了 60%。

```
P[A→B] = √Culture_A × 距离 × 联系 × 情报 × 战争 × 势差乘区
势差乘区 = clamp( (Culture_A ÷ Culture_B) ^ 0.5, 1.0, 2.0 )    仅当 Culture_A ≥ gapGate(3000) 时生效
```

- **语义**：文化强势国对弱势国有"潮流效应"（强者通吃），只放大优势方、不惩罚劣势方（下限 1.0）。
- **为什么需要**：CN 文化是 KR 的 2.46 倍，√ 后输出只差 1.57 倍；乘以势差乘区（1.57）后拉回到可入侵区间。**不加则文化胜利数学上不可达**。
- **为什么封顶 2.0**：防"滚雪球锁死"——大势国不能无限放大；20 回合内不会出现"一统文化"。
- **为什么 gate=3000**：防开局文化值极小时的比值失真（3k vs 0.5k 的 6 倍势差是噪音，不是霸权）。
- **与 R28 的关系**：不推翻 √ 凹函数（骨架不动），是在输出层加一个"相对优势"修正——R29 已预留"后续叠加建筑/政策卡时会有微调参数"的口子。

**✅ 2026-11-05 院长定稿：采纳。** 参数取值见下（全部登记进 [参数登记表](../../08-百科/索引-参数.md)，遵循"公式参数必须能在基础数值里找到出处"纪律）：

| 参数 | 值 | 基础数值出处 |
|---|--:|---|
| 势差指数 `gapExp` | **0.5** | 与 R28 裁定 √Culture 同源（0.5=平方根指数，骨架一致） |
| 势差封顶 `gapCap` | **2.0** | 开局文化极差：CN 城市文化 30~140 vs KR 30 → 约 4.7 倍，√4.7≈**2.16**；封顶取 2.0（略低于极差，留调整空间） |
| 势差门槛 `gapGate` | **3000**（暂定） | ⚠️ 标定值，非基础数值推导——**白机建议改为"目标国文化建筑数 ≥1"**（有文化设施才有文化受众，参数直接来自建筑表；见 §9.9 待裁） |

### 9.9 参数可追溯纪律（✅ 2026-11-05 院长令）

> 院长原话："我们加的任何公式，公式里的任何参数都要能在游戏的基础数值里找到。后续我们的游戏知识库需要用到。"

- **禁止魔法数字**：公式里出现的每个常数必须有 `参数ID`，登记在 [参数登记表](../../08-百科/索引-参数.md)——含**定义/当前值/基础数值出处/可调范围/权威文档**。
- **出处三选一**：①来自基础数据（城市文化值/建筑产出/人口/粮产等）；②来自已裁定骨架（如 √ 指数 0.5）；③明确标注"标定值（待基础数值支撑）"并设复核期限。
- **代码同步**：参数一律进 `balance.json`，键名=参数ID；代码不得内联常数。
- **本次登记**：`cultureGapExp=0.5`、`cultureGapCap=2.0`、`cultureGapGate=3000`、`cultureResistCap=0.5`、`cultureConvergeR=0.05`、`cultureInvadeThreshold=0.6`、`cultureLostThreshold=0.4`。
