# 游戏模式与副本规划（v0.1 · 院长口述）

> 状态：📝 **v0.1（2026-11-16 院长口述；先记录以保证底座兼容，细节后续展开）**
> 定位：本作最终形态 = **L0 主界面 + 教学关卡 + 自由沙盒 + 多个副本**。一期只做教学关卡与底座兼容；副本内容二期做，但**底座现在必须按最终形态设计**。
> 三层区分：
> - `sim/` 模拟沙盒 = **验收功能与数据底座**，不是玩家体验；
> - 玩家真实游玩 = **exe 内自由沙盒**（带全部资源）；
> - 教程 = **自由沙盒之前的教程关卡**（事件驱动剧本，见 [教学关卡设计](./教学关卡设计.md)）。

## 一、L0 主界面（2026-11-16 院长定）

| 项 | 口径 |
|---|---|
| 菜单项 | **新游戏 / 继续游戏 / 设置 / 退出**（**数据驱动，不写死**） |
| 继续游戏 | 继续上一盘**自动保存的最近一回合**，直接进入游戏 |
| 新游戏 | 进入**教学关卡 / 不同游戏内容（副本）**；副本列表数据驱动 |
| 解锁 | **完成教学关卡后才解锁其他副本**（解锁条件数据化，不写死） |
| 设置 | 目前只做音效、声音、画面类；不做玩法设置 |
| 数据 | `MenuDefinition` + `ScenarioDefinition.unlockCondition`；主界面/副本卡片不写死 |

> 教程是**前置**：完成教程才解锁副本。副本之间无先后依赖（数据化配置）。

## 四、数值兼容性（重点）

- **当前 v22 数值（S=8、14 城、4 阵营、318.4 万人口）= 一期教学剧本数值，不是通用平衡**。
- 副本需要**按剧本覆盖**：阵营数（8/7/4/3/2）、城市规模、单城起点、远古/中期科技、邪族单位、环境压力、随机开局曲线。
- **禁止把 4 阵营/14 城/21 将/21 城上限写进公式或规则**；所有数值走 `balance.json` + `ScenarioDefinition` 覆盖。
- 8 阵营/单城/远古开局的增长曲线、AI 扩张节奏、外交制衡、胜利节奏，需要**独立模拟盘**（可复用 `sim/`，但必须参数化或另建副本测试场）。
- 邪族单位/建筑/波次、群星环境因子、内战永久战争，需要各自的数值子表；不能塞进人类 B1 兵种表。

## 五、待确认/待展开（v0.1 → v0.2）

1. **复苏**：随机城市落位是"固定城位随机分配"还是"地图程序化落位"？8 阵营的武将池是否就是 21 将（8 初始+13 可招募）？远古科技树是**新增古代/中世纪段**还是把现有 40 节点压缩前移？国名/颜色池来源？
2. **复苏胜利**：三胜利全开还是另有主胜利？（用户说"常态游戏"，暂按三胜利，待确认）
3. **逐鹿**：7 阵营/古国名/古城名清单；"初始文明中期"对应科技树哪一段；仅军事胜利的判定（灭全部敌国？占全部城？）。
4. **群星**：胜利条件（生存 N 回合/征服全部/摧毁其他角？）；高频环境因子的类型/数值；斗转星移的触发回合与连通方式。
5. **复仇者**：邪族单位/建筑/AI 波次规则；3 人类阵营"平分三大初始武将"是每家 1 将还是共享 3 将；人类胜利是否要求邪族本营被拆（任一阵营拆=全员胜）。
6. **内战**：无外交/永久战争的 AI 行为；科技/文化辅助战争的具体效果（科技乘区/文化 debuff？）。
7. **L0**：副本解锁顺序（教程→全部？还是按难度递进）；自动存档槽位/覆盖规则；设置项范围。
8. **典藏**：一期教学只需部分内容（1~2 件 CN 文物 + 博物馆陈列 + 赐予），全量 14 城/84 件候选留二期；见下节。
9. **科技树**：三线方向不变，但"不同世界线起点/速度/节点"需要 `TechTreeDefinition` 覆盖；古代/中世纪节点是新增内容还是压缩现有节点，需院长定。
10. **武将池**：当前 21 将绑定 CN/JP/KR/AU/城；副本随机开局需要"池子与阵营解耦"（officers 只存属性/倾向，剧本运行时分配阵营/城）。这是数据模型改动，优先做。

## 六、典藏：教学够用吗？

- **机制够用**：B6 v0.8 已定稿（B1=A 份额收敛、B2 r=0.05、B3 不设抵抗、陈列热度 +1.2、三组效果）。做教学只需演示"考古→陈列→热度/文化→赐予/忠诚"一条链。
- **内容不需要全量**：教学用 1~2 件 CN 文物（西安/北京）+ 1 座博物馆 + 1 次赐予即可；CN 6 件定稿足够；84 件候选/JP/KR/AU 8 城底稿留二期。
- **缺的是 Unity 实现**：考古队列/博物馆陈列/赐予/热度 UI 若未接，教程可把典藏作为**可选教学节点**，不阻塞主线；全量内容二期补。
- **结论**：**部分教学够用**；不需要全量内容，但需要最小可玩的典藏 UI。若底座时间紧，教程可先跳过典藏，在"文化发展"章节用文化建筑/娱乐/文旅替代演示。

## 七、与一期/二期关系

- **一期**：教学关卡 + 底座兼容（L1/L2/L3、Scenario/Event/Tutorial、可变阵营/开局/胜利/外交/科技/特殊阵营的 schema）。**副本内容不在 一期做**，但 schema/接口必须留。
- **二期**：复苏/逐鹿/群星/复仇者/内战 + 新地图/新阵营 + 平衡 + 表现力。
- **L3**：大模块，黑机先 L1/L2；L3 后续要求真实完全；教程在 L3 完成后接入。
- **施工顺序**：底座全部完成 → 教学关卡 → 一期验收 → 二期副本增量。
