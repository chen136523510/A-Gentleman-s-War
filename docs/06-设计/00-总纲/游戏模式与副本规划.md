# 游戏模式与副本规划（v0.1 · 院长口述）

> 状态：📝 **v0.1（2026-11-16 院长口述；先记录以保证底座兼容，细节后续展开）** · 同步日期：**2026-11-24**（语义核对：过时口径词表零命中，机械指针段已清理）
> 定位：本作最终形态 = **L0 主界面 + 教学关卡 + 自由沙盒 + 多个副本**。一期只做教学关卡与底座兼容；副本内容二期做，但**底座现在必须按最终形态设计**。
> 三层区分：
> - `sim/` 模拟沙盒 = **验收功能与数据底座**，不是玩家体验；
> - 玩家真实游玩 = **exe 内自由沙盒**（带全部资源）；
> - 教程 = **自由沙盒之前的教程关卡**（事件驱动剧本，见 [教学关卡设计](./教学关卡设计.md)）。

## 一、L0 主界面（2026-11-16 院长定）

| 项 | 口径 |
|---|---|
| 菜单项 | **新游戏 / 继续游戏 / 设置 / 退出**（**数据驱动，不写死**） |
| 继续游戏 | 继续上一盘**自动保存的最近一回合**，直接进入游戏 |
| 新游戏 | 进入**教学关卡 / 不同游戏内容（副本）**；副本列表数据驱动 |
| 解锁 | **完成教学关卡后才解锁其他副本**（解锁条件数据化，不写死） |
| 设置 | 目前只做音效、声音、画面类；不做玩法设置 |
| 数据 | `MenuDefinition` + `ScenarioDefinition.unlockCondition`；主界面/副本卡片不写死 |

## 四、数值兼容性（重点）

- **基础数值定版后冻结（2026-11-16 院长令；当前数值仍可调）**：建筑产出/成本/单位属性/科技成本等**现有基础值全部不变**；副本只改规则/内容组合/地图/阵营/开局/胜利，不重平衡基础值；新增内容（古代/中世纪节点、NPC、邪族单位）**另加值，不回改现有值**。
- **复苏=主副本/通用规则基准**：8 阵营/固定城位随机分配/单城/远古/三胜利是通用规则；教程/逐鹿/群星/复仇者/内战只在复苏规则上覆写差异。
- 当前 v22（S=8/14 城/4 阵营/318.4 万）是**教程实例**；复苏用同一套基础值，只改起始组合/科技闸门/地图/阵营，不重算建筑产出。
- **8 阵营/单城/远古开局的节奏**需要模拟验证（可复用 `sim/`，但必须参数化或另建副本测试场）；验证的是"起始组合/科技闸门"是否合理，不是改基础值。
- **UN/文化胜利**：文化胜利=**存活阵营全入侵**（不要求初始全存活）；**UN ≥2/3 同意（弃权不算）**；常任理事国选举第一轮相对多数、未过半空位；**复国国投票跟随复国者（不是额外一票）**；不做大国无反对；只有常任理事国一票否决。
- **邪族/群星/内战**：邪族单位/建筑/波次、群星环境因子、内战永久战争需要各自的内容/规则子表；不改人类 B1 基础值。
- **禁止把 4 阵营/14 城/21 将/21 城上限写进公式或规则**；所有副本差异走 `ScenarioDefinition` 覆盖。

## 五、已定 / 待展开

### 已定（2026-11-16 院长答复）

- **复苏**：固定城位随机分配；中国地图；8 阵营；**21 将池=8 初始+13 招募**；三胜利全开；**远古/中世纪新增节点**；**主副本/通用规则基准**。
- **逐鹿**：战国七雄；**7 阵营×3 随机将（21 全用）**；战国时期科技起点；**仅军事=灭全部敌国**。
- **群星**：**三胜利（同复苏）**；环境/斗转星移细节开发时定；**固定回合直接改 L1 地图**；四角 5 将 + 玩家角多 1 = 21。
- **复仇者**：**3 人类阵营平分 21 将（7/7/7）**；**任一阵营拆邪族本营=全员胜**；**任一阵营被灭→邪族加强**；人类可外交贸易互援。
- **内战**：AI 想方设法征服玩家；科技/文化沿用现有辅助效果，不加新内容。
- **L0**：**教程→全部解锁**；**单自动档每回合覆盖+手动存档多槽**；继续游戏读最近自动档；设置=音效/声音/画面（后续可扩展）。
- **武将池**：**21 群友=通用池**；各副本加不同 NPC；**NPC 与初始将平级，但不遵 400 属性点原则**；**单属性 1~99，总属性不设区间**（符合世界观即可）。
- **基础数值**：**定版后冻结**（当前数值仍可调；定版后不再改）；副本只改组合/规则/地图/阵营/开局/胜利；新增内容（古代/中世纪节点、NPC、邪族单位）另加值，不回改现有值。
- **UN/文化胜利**：**存活阵营全入侵**（不要求初始全存活）；**UN ≥2/3 同意（弃权不算）**；**常任理事国选举第一轮相对多数、未过半空位**（不投自己）；**复国国投票跟随复国者（不是额外一票）**；**不做大国无反对**；**只有常任理事国有一票否决权**；游戏内不叫"盟主"，统一"常任理事国"。
- **军事单位**：远古/古代/中世纪/近代/现代均按**三兵种（步/弓/骑）×轻/重 = 3×2**；**空军近现代才出现**。
- **空城**：复苏其余固定城位=**空城**（自带市政府+农业区+少量人口）；**扩张刹车机制待设计**（见下）。
- **典藏**：教程只做最小展示（1~2 件 CN 文物+博物馆+赐予）；全量/分副本内容二期。

### 待展开/待讨论

1. **古代/中世纪科技树**：三线方向不变（远古→古代→中世纪→近代→现代→未来；蓝线古代叫"工程/机械"，现代叫 AI）；现有 40 节点是现代段，新增古代/中世纪段怎么排；逐鹿"战国时期"对应哪一段。
2. **复苏"爆铺"刹车**：空城自带市政府/农业/少量人口；但"爆铺收益高、玩家一开局就紧急殖民"需要限制。候选：**行政容量/统治力软上限**（城市数超限→腐败/治安/维护上升，随政体/科技提升）+ **殖民远征成本/时间** + **距离维护/补给** + AI 争抢。推荐行政容量为主，待细化。
3. **基础数值定版后冻结 + 远古起点**：当前数值仍可调；定版后冻结。古代/中期节点如何闸门现有建筑/单位（不改基础值）；单城远古节奏需模拟验证。
4. **群星**：四角武将分配（5/5/5/5 + 玩家+1）；环境因子类型/频率；斗转星移固定回合/连通方式。
5. **复仇者**：邪族单位/建筑/波次；3 人类阵营 7/7/7 的初始城/将分布；被灭加强邪族的数值口径。
6. **逐鹿**：七国古名/古城名清单；战国时期节点映射。
7. **复苏 vs 教程**：教程用 4 阵营/14 城/CN 6 城，但 **UN/选举/复国等通用规则与复苏完全一致（不做特例）**；教程只是特殊 Scenario（地图/阵营/事件/教学开关不同）。
8. **建筑时间线专题**：把建筑拉到远古时期重新梳理（与科技树专题同批）；军事仍 3×2。

## 六、典藏：教学够用吗？

- **机制够用**：B6 v0.8 已定稿（B1=A 份额收敛、B2 r=0.05、B3 不设抵抗、陈列热度 +1.2、三组效果）。做教学只需演示"考古→陈列→热度/文化→赐予/忠诚"一条链。
- **内容不需要全量**：教学用 1~2 件 CN 文物（西安/北京）+ 1 座博物馆 + 1 次赐予即可；CN 6 件定稿足够；84 件候选/JP/KR/AU 8 城底稿留二期。
- **缺的是 Unity 实现**：考古队列/博物馆陈列/赐予/热度 UI 若未接，教程可把典藏作为**可选教学节点**，不阻塞主线；全量内容二期补。
- **结论**：**部分教学够用**；不需要全量内容，但需要最小可玩的典藏 UI。若底座时间紧，教程可先跳过典藏，在"文化发展"章节用文化建筑/娱乐/文旅替代演示。

## 七、与一期/二期关系

- **一期**：教学关卡 + 底座兼容（L1/L2/L3、Scenario/Event/Tutorial、可变阵营/开局/胜利/外交/科技/特殊阵营的 schema）。**副本内容不在 一期做**，但 schema/接口必须留。
- **二期**：复苏/逐鹿/群星/复仇者/内战 + 新地图/新阵营 + 平衡 + 表现力。
- **L3**：大模块，黑机先 L1/L2；L3 后续要求真实完全；教程在 L3 完成后接入。
- **施工顺序**：底座全部完成 → 教学关卡 → 一期验收 → 二期副本增量。
