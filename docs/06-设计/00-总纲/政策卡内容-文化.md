### 文-04 全域旅游 `tourismPowerhouse`（✅ 11-24 院长定名 · 第三轮确认"全域旅游可行"）
| 项 | 内容 |

**定名说明**：院长 11-24 第三轮确认"全域旅游可行"（初问"是什么"、白机曾改推观光立国被否）。**全域旅游**=中国 2016 年起国家旅游局推的政策（全域旅游示范区）——把一个区域整体当旅游目的地建设，旅游与农业/工业/文化融合。
**设计思路**：把文化资源变现为财——文旅容量与收入双升，走财收入路线（经济侧感知）。
**数值思路**：沿用 v1.0（×1.3/×1.2），**待模拟盘**。

### 文-13 民族主义 `nationalism`（✅ 11-24 院长令 · 新增 · 多段效果）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 紫 / 中期 |
| 效果 | **外交亲密度下降**（对所有国家关系流 −0.5/回）；**本国人为主的城市忠诚大幅提升**（外籍 <10% → 忠诚 +1/回）；**每 2% 外籍人口 → 宜居 −0.5、治安 −1**；**服役比例上限 +1pp** |
| 解锁 | 开局 |
| 落点 | relation / 忠诚流 / 宜居 / 治安 / `serviceRatioCap` |
| 互斥 | 建议 `ideology` 意识形态（vs 女权主义；**待院长裁**） |

**设计思路**：院长 11-24 第 6 条原文——"外交亲密度下降，若城市以本国人为主，则忠诚度大幅提升，每有 2% 外籍人口，则宜居度、治安下降；服役上限提升"。玩"同质化社会"：本族城越强、外籍越少越稳；扩张吸收外籍城会反噬（扩张与内政的取舍）。多段效果=单卡内部条件式（按人口构成），**不是卡间联动**（符合不联动纪律）。
**数值**（白机定）：对所有国家关系 **−0.5/回**；外籍 <10% 城市忠诚 **+1/回**（"大幅"=忠诚流最强档，同反腐）；每 2% 外籍 → 宜居 **−0.5**、治安 **−1**（20% 外籍城 = −5 宜居/−10 治安，重）；服役比例上限 **+1pp**。
