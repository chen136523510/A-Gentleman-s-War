**原特殊 6 张重分类**：电子长城→文化、文化自信→文化、情报管制→通用、限制移民→通用、配额法案→通用、绿色转型→通用。
**重分类理由**：①电子长城/文化自信是文化输出算法 §237 的文化工具，天然属文化；②情报管制是跨部门内务安全；③限制移民是边境/人口社会政策（非纯经济手段）；④配额法案/绿色转型是"全球公共品"环境政策，且外交提案发"环保主义"卡的原型就是通用白卡——环境三卡统一走通用，表达"超越单一部门的国家政策"。

**每类 10 张 vs 每类 2 槽 = 5:1 选择比**（调研判定 3.4:1 偏薄，5:1 健康）。通用槽另有全属性卡可装，白卡需靠"跨领域 + 低负面"竞争。

## 二、军事类（红 · 10 张）

> 槽位 2。路线：数量（兵役登记/紧急动员/战地医疗）、质量（参谋本部/军备自给）、工业（军工优先/战略储备）、统治（尚武精神/铁律军法）、防御（边关要塞/核威慑）。

### 军-01 兵役登记 `conscription`（已有）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 红 / 早期 |
| 效果 | 征募费 ×0.8（8→6.4 财/兵）；宜居 −1 |
| 解锁 | 开局 |
| 落点 | `recruitFee` / 宜居 |

**设计思路**：义务兵役制的代表卡——用社会负担换人力成本，是"数量建军"路线的起点。与通用卡"紧急动员"（×0.7、宜居 −5）构成平时/战时的梯度：兵役登记是常年制度，紧急动员是战时超频；两者可叠（×0.56）但宜居合计 −6，逼玩家算总账。
**数值思路**：征募费 8 财/兵是 v22 定值（院长 11-13 裁）。×0.8 让万人军省 1.6 万财，约等于多征 2000 兵；不再更低（×0.7 留给紧急动员），因为征募是一次性成本、真正大头是军饷 0.05 财/兵/回——这张卡只解决"入场费"，强度克制。宜居 −1 ≈ 1/8 个医院（医院 +8），可感知不致命。

### 军-02 军工优先 `warIndustryFirst`（已有）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 红 / 中期 |
| 效果 | 兵工厂批次产出 ×1.25；同城民生产出 ×0.95 |
| 解锁 | 开局 |
| 落点 | 兵工厂批次（B1）/ 民生乘区 |

**设计思路**：战时工业动员——把民用产能转向军工。与"军备自给"（维护端）配对：一个增产、一个省养。与"国企集中"（工业 ×1.1）是同一逻辑的军事版，但更极端、代价更具体（同城民生）。
**数值思路**：兵工厂是 L3 装备供给核心（1 批 = 8000 兵装备）；×1.25 相当于 3 级兵工厂每回合多 1/4 批，约多 2000 兵的装备产能。25% 是全表最高乘区（调研已注明"中强卡"），对冲是同城民生 −5%（消费/文旅收入）——战争国家的真实代价。

### 军-03 战略储备 `strategicReserve`（已有 · 修订）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 红 / 后期 |
| 效果 | 铁/煤/油/铀池上限 ×1.3 ~~市政维护 +2%~~（删） |
| 解锁 | 开局 |
| 落点 | `resourceCapTurns` 池上限 |

**设计思路**：资源安全——为长期战争囤积战略物资。后期大战拼消耗，储备上限决定"扛不扛得住封锁"。与"军备自给"（降单价）互补：一个囤得多、一个用得省。
**数值思路**：资源池 = 5 回合产量（`resourceCapTurns=5`），×1.3 → 6.5 回合。CN 铁 576/回：池 2880→3744，多 864 铁 ≈ 1.7 批坦克。原"市政维护 +2%"经审计为无感代价（中后期财多），按院长 11-17"绝大多数卡无负面"直接删除——占红槽即代价。

| 项 | 内容 |
|---|---|
| 卡色/阶段 | 红 / 中期 |

**设计思路**：军事化社会——战争凝聚人心、和平滋生厌战。全表唯一"和平期负、战时正"的动态卡，配合槽位冷却（t1 装→t2 冻→t3 改）形成择时博弈：开战前装、战后卸。
**数值思路**：军管 10 回合底线 +5，直接降低新占领城市起义概率（阈值 20）；战时 +0.3/回 ×10 回 = +3 忠诚，约半个反腐；和平 −0.2/回 ×50 回 = −10，可感知。原文写 +0.02/回 疑为单位笔误（与"增税 −1/回"不同口径），**建议统一为 0-100 制的 ±0.2~0.3/回**。

| 项 | 内容 |
|---|---|
| 卡色/阶段 | 红 / 中期 |
| 效果 | 城市忠诚 +0.5/回 |
| 解锁 | 开局 |
| 落点 | 忠诚流 |

**设计思路**：军纪/军法体系——对外是战力，对内是统治工具，适合大幅扩张后压新领土。与"反腐"（白，+1/回）构成军民两条忠诚线：反腐治吏、军法治军，可叠（+1.5/回）但占两个槽（红+白）。

|---|---|
| 卡色/阶段 | 红 / 后期 |

**数值思路**：城防 ×1.25 让攻城方多投入 25% 兵力/时间；守军 q +10% 只在被围时生效（条件型强效果，约等于免费半个参谋本部）；攻城 q ×0.95 是路线代价。L3 未定前严格占位，数值随城防公式校准。

### 军-09 核威慑 `nuclearDeterrence`（新增）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 红 / 后期 |
| 效果 | 他国对我宣战阈值 +2（diploAI aggression）；rep −1/回 |
| 解锁 | 科技（核技术） |
| 落点 | 外交 AI 侵略阈值 / rep |

**设计思路**：终极防御——拥有核武后的战略平衡。不直接打仗，而是"让别人不敢打你"，是军事卡的外交表达。与"强硬外交"（+1 阈值）可叠到 +3，但 rep 代价叠加（−1/回 + 侵略 rep 惩罚），形成"威慑流"的极限与代价。
**数值思路**：aggression 是外交 AI 的战争倾向判定（`warStart=100`）；+2 阈值约等于多 2 点缓冲，实际效果是"周边国家从'可打'变'慎打'"。rep −1/回 ×20 回 = −20，足以从"中立"掉到"孤立"——核扩散的真实代价，也是平衡阀（安全不能白拿）。

## 三、经济类（黄 · 10 张）

> 槽位 2。全部为已登记/已裁卡，本专题只补设计思路与数值思路，并按调研 P0 重写减税/紧缩、删除 3 处无感负面。

### 经-01 减税 `taxCut`（已有 · 按调研 P0 重写）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 黄 / 早期 |
| 效果 | 人口税率 ×0.8（财收入 −20%）；消费池 ×1.08；城市忠诚 +0.5/回 |
| 解锁 | 开局 |
| 落点 | 税率 / `poolK` / 忠诚流 |

**设计思路**：藏富于民——减税不是"纯亏"，而是把财政让利转成消费与稳定。重写后"效果/负面"不再自我抵消：财收入 −20% 是代价，消费池 +8% + 忠诚 +0.5/回 是收益。与"紧缩"镜像：一个放水、一个收水。
**数值思路**：税率 0.8~1.2 已裁，×0.8 是下沿。CN 6 城约 −1160 财/回，靠商业/贸易补；消费池 +8%（K_desire 2.5→2.7，商业约 +4~5%）；忠诚 +0.5/回对冲增税的 −1/回。净收益依赖商业规模——富国减税划算、穷国减税伤财政，天然有使用门槛。

| 解锁 | 开局 |

**设计思路**：战时财政/扩军筹款。与减税镜像，是"钱从哪来"的另一端，适合短期筹款——配合槽位冷却，装两回合拿了钱就换。
**数值思路**：+20% 税收（CN 约 +1160 财/回），忠诚 −1/回 = 100 回归零，极重负面；逼玩家在钱与稳定间取舍。与"反腐"（+1/回）可对冲成"增税+反腐"组合（净忠诚 0、净收入 +1160，但占 2 槽）——经典的高压财政组合。

|---|---|

**数值思路**：阈值 +2（等同核威慑的威慑力，但无 rep 代价）、同盟收益 ×0.5（放弃 `allyRatio=0.6` 的援助/联攻）——用"安全"换"孤立"，中立国的真实困境。

## 七、跨类校验与路线组合

### 7.1 数值纪律自查

| 项 | 结论 |
|---|---|
| 单卡乘区 | 新增卡 5~15%；军工优先 25% 为历史例外（同城民生 −5% 对冲）；无 20%+ 无代价卡 |
| 负面纪律 | 新增 23 张中 **11 张纯正面**、12 张带可感知成本：其中 6 张"财支出/关系流"交易型（金元外交/国际援助/舆论战/条约体系/不结盟/关税同盟）、3 张"军饷/商业/攻城 q"机会成本型（参谋本部/战时经济/边关要塞）、3 张风险型（核威慑 rep/言路管制科技/百家争鸣忠诚）；**无纯惩罚型负面**——所有成本都对应明确收益，且无感成本（<1% 税、维护 +1~2%）一律删除 |
| 落点 | 全部挂主公式参数（见各卡"落点"行）；6 处旧卡落点待黑机核对（§八.3） |
| 乘区封顶 | 文化防御三卡合计受 `resistCap +50%` 约束；税率 0.8~1.2 已裁；消费池/工业/商业为相乘，无双卡超模组合 |

### 7.2 路线组合（选定 2 槽后的自然玩法）

| 路线 | 核心卡（槽位） | 玩法 |
|---|---|---|
| **数量建军** | 兵役登记 + 紧急动员（红/白）+ 战地医疗 | 爆兵流：征募 ×0.56、宜居 −6，用人口换兵力 |
| **质量建军** | 参谋本部 + 军备自给（红）+ 铁律军法 | 精兵流：q +5%、装备维护 −20%、忠诚 +0.5/回 |
| **总体战** | 军工优先 + 战时经济（红/白）+ 国企集中 | 军工 ×1.375、工业 ×1.1，民生/消费受损 |
| **守势发育** | 边关要塞 + 核威慑（红）+ 不结盟运动 | 龟壳流：城防 ×1.25、宣战阈值 +4、同盟收益减半 |
| **富国扩张** | 减税 + 消费刺激（黄）+ 招商引资 | 商业爆发、税收入 −20%，适合 AU |
| **战时财政** | 增税 + 紧缩（黄）+ 反腐（白） | 税 +25%、忠诚净 0，短期筹款 |
| **人口长线** | 生育补贴 + 基建狂魔（黄）+ 土地改革 | 人口复利 + 承载扩容 |
| **文化进攻** | 光影出海 + 雅言远播（紫）+ 舆论战（绿） | 输出 ×1.21、文化值 +15%，文化胜利 combo |
| **文化防御** | 文化自信 + 言路管制（紫）+ 遗产保护 | 自压 ×1.38、抵抗封顶，龟壳流 |
| **外交和平** | 睦邻友好 + 国际援助（绿）+ 金元外交 | 关系/rep 双涨，走 UN/文化胜利 |
| **外交强势** | 强硬外交 + 条约体系（绿）+ 关税同盟 | 阵营化：阈值 +1、同盟门槛 −10%、贸易 +20% |

> 注意：紫槽只有 2，文化进攻/防御各需 2 紫卡，**同一套槽位无法同时走两线**——这是文化路线的核心取舍。

### 7.3 每类 10 张的选择深度

- 军事：数量/质量/工业/统治/防御 五线，2 槽任选。
- 经济：扩张/紧缩/人口/基建 四线，10 张全是"经济旋钮"。
- 文化：防御/输出/基础 三线，2 槽。
- 外交：和平/强势/中立 三线。
- 通用：行政/廉政/安全/人口/环境/数字/土地/战时 八线，2 槽最卷。
