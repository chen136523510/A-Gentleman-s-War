## 2026-10-24 R15 · UI 雏形先行定调

- 类型：决策
- 依据：院长 2026-10-24 原话「是否需要先做一个雏形出来，我想先把界面UI设计好」
- 变更：开发序列调整为 UI 雏形先行——先做界面雏形（布局/交互/信息密度，假数据占位不接逻辑）；军事兵种目录等玩法细化作为讨论线并行推进、不阻塞 UI。界面清单九屏建议落 [07-技术架构/UI雏形规划.md](../07-技术架构/UI雏形规划.md) 待院长圈选
- 影响：07-技术架构（新文件）、需求池 R-059 待裁决项（L2 网格升级为 UI 前置）
