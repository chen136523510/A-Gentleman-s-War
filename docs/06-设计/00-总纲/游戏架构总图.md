# 游戏架构总图（世界-国家-城市三级）

> 状态：🏗️ v0 骨架（R29 院长提出三级架构，白机展开）· 更新：2026-10-26 R29
> 定位：**全游戏讨论框架的地图**——任何模块讨论前先对图，防方向偏移。层级从上往下=从全局到细节。
> 配套交互图：会话内可视化（世界-国家-城市三级树+各层模块挂点）。

## 一、三级总览

```
【世界级】  环境系统（内政之上一层） · 城市扩张（远期规划）
              │
【国家级】  文化值 · 科技值 · 财政（国家/地方双层） · 外交
              │
【城市级】  L1 大地图（城际贸易/军事冲突） · L2 内政（M3 轮） · L3 城防构建/战役处理
```

## 二、世界级（在内政之上的一层）

### 2.1 环境系统（环保=世界级概念，R29 院长立）

- **定位**：环境是跨国家的公共层——碳排放、污染等由各国共同制造、共同承受，单一国家无法独善其身；**环保科技线（R23 科技树四线之一"民生与环保"）在此层的对应物**。
- **环境破坏素材库**（R29 起持续填充，二期天灾联动）：

| 环境议题 | 机制方向 | 受威胁方 |
|---|---|---|
| 碳排放→全球变暖 | 各国工业碳排放累积→全球温度指数 | 全图 |
| 海平面上升 | 温度指数过阈→沿海城市淹没风险/产出衰减 | **沿海与低海拔城市**：上海/深圳/香港/台北/仁川/东京/名古屋/长崎/悉尼/墨尔本（威胁沿海国家和岛国） |
| 臭氧层空洞 | 氟化物工业累积→紫外线灾害（澳新先受） | AU 先受、全球后受 |
| 核污染 | 核事故/核打击残留区→周边产出+宜居长期衰减 | 事发地+邻城（长崎原爆素材呼应） |
| 酸雨 | 工业密集区→农田产出衰减 | 重工业城市周边 |
| 沙尘暴 | 干旱化→沙尘事件（北京二期天灾已有伏笔） | 北京/西安方向 |
| 海洋污染/过度捕捞 | 近海渔业衰减→粮产出 | 沿海城市 |
| 物种入侵/生态破坏 | 贸易航线带入侵物种→农业事件 | 有航线城市 |
| 资源枯竭 | 矿业城市长期开采→矿脉衰减事件 | AU 矿业/资源型城市 |

- **设计原则**：世界级环境=**长周期慢变量**（以 10 回合为尺度累积），与城市级快变量（回合产出）区分节奏；环境恶化是全球负和——联合国时代（文化胜利链）共同治理是世界级与国家级的衔接点。
- 分期：一期只做**数值底层**（碳排放/污染累积进存档数据结构）；表现与事件（淹没/沙尘暴等）二期天灾轮展开。

### 2.2 城市扩张（更后期规划）

- **概念**：在野地建新城（现 14 城之外）——**二期都不实现，留到更后期**（R29 院长定）。
- 预留钩子：城市上限 ≤21 的扩展格即此概念的接口；世界级环境系统先跑起来，扩张落地时受环境承载力约束（如污染区不可建城）。

## 三、国家级（四柱）

| 柱 | 内容 | 备注 |
|---|---|---|
| **文化值** | 对内积累层（R28 算法专题） | 经文化输出矩阵作用他国；来源广泛（回填涉诸多模块，M3 轮起逐模块挂） |
| **科技值** | 四线科技树（军事/民生与环保/经济与产业/信息与智能） | 科技胜利判定面；**民生与环保线=世界级环境系统的国家级对策** |
| **财政（双层）** | **国家财政 + 地方财政**：地方财政总和=国家财政；**平时按比例抽调统一调配**（国家调配层），**地方财政只在自立时有用**（自立阵营以地方财政为初始盘） | R29 院长新立——为自立系统提供经济底座；抽调比例=政策参数 |
| **外交** | 关系值/同盟/联合国/国际声誉 | 文化胜利链（联合国投票）；贸易协定等经济联动 |

- 国家级与城市级的关系：国家级数值=城市级产出的**汇总与再分配**（财政显式再分配、文化/科技隐式汇总），国家级不直接生产。

## 四、城市级（L1/L2/L3 三层）

| 层 | 语义 | 内容归属 |
|---|---|---|
| **L1 大地图** | 城市**之间**的层：贸易往来、军事冲突（出兵/行军/航线） | 连通图与航线/战略层出兵与行军（R27b）/城际贸易 ⛏ |
| **L2 城市内政** | 单城经营界面：六区域/建筑/人口/宜居 | **= M3 内政轮的讨论对象**（下一站） |
| **L3 战斗场景** | 更细则的**城防构建+战役处理** | 战斗总述/兵种装备/操作交互；城防构建=战前布防 ⛏ 细化 |

## 五、架构审查记录（R29 白机意见，待院长裁决）

1. **国家级缺"情报/侦察"柱？** 战争迷雾与行军可见性（R27b）已定，情报归属国家级（科技挂靠+外交获取）还是城市级（建筑产出）建议明确——倾向：**情报=国家级能力**（科技树节点+外交条约），L1 层消费。
2. **L1 贸易归城市级还是国家级？** 城际贸易（R29 院长把 L1 定义为"城市之间的贸易往来和军事冲突"）建议：**贸易规则=L1 层，贸易协定=国家级外交**，产出入地方财政——与财政双层制自洽。
3. **环境系统与天灾系统的边界**：环境=慢变量累积（人类活动导致，可治理）；天灾=快变量事件（随机触发，二期）——两者因果可联动（环境恶化提高天灾频率）但系统分离。
4. **建议补：国家级"政策"位**——政策卡（院长 R29 提及"后续叠加政策卡"）挂国家级，作用到城市级产出与文化输出参数。
