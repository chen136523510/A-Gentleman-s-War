## 二、军事类（红 · 10 张 · 11-24 五裁补足）

> 槽位 2。**2026-11-23 院长军事过卡（两轮 17 条）定稿**：征募/服役采用**服役比例**基础数值（每城默认比例 + 上限；院长确认口径见 §2.0）；军事卡保留 7 张 + 新增 军队经商 1 张 = **8 张**（删除 8 张：战略物资储备制度/联合作战指挥体制/军事法治建设/边境防御体系/战地医疗体系/军民融合/军事采购制度/预备役制度）。
> **11-24 已补足 10 张**：+电子长城（四裁移入，+反谍）、+维和行动（四裁新增）。

### 2.0 征募/服役机制口径（院长 2026-11-23 确认）
1. **服役比例=基础数值（百分比），每城有默认值**（例：5%）：100 人口城 → 5 服役人口，**可直接武装成兵种投入战斗**。
2. **征募=在剩余人口中额外征兵**：再征 5 人 → 服役人口 10、服役比例 10%（**计数示例**；当前定值：常规上限 8%，超过 8% 的部分=强征，强征硬顶 10%）。
3. **服役比例上限**（定值 8%）：最多再征 3 人；**超出上限的征募=强征**（强征最高到 10%）。
4. **征募批次**：第一批**志愿兵** → 第二批**义务兵** → 第三批**强征兵**（对应军饷/成本档）。
5. **服役且未训练的人口随时可投入训练**（训练=成为正式兵种、可编入部队）。
6. **训练过的服役人口不需再训练**（兵种固定）。
> **✅ 2026-11-24 黑机定值（院长授权「由你定」；未冻结可调）**：`serviceRatioBase=5%` / `serviceRatioCap=8%`（常规征募上限）/ `serviceRatioMax=10%`（强征硬顶）/ **超限=强征**；批次成本系数 **志愿 ×1.0 / 义务 ×1.5 / 强征 ×2.2**（军饷与征募同乘）；400v² 软刹车保留；模拟器 `peaceService=0.5%` 为旧占位，v27 复苏盘起按 **和平 5% / 战时 10%** 重跑。

### 军-01 全民服役 `conscription`（已有 · 11-23 定）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 红 / 早期 |
| 效果 | **服役比例上限提升（兵源池=人口×比例）**；军队战斗力小幅提升（兵员素质） |
| 解锁 | 开局 |
| 落点 | `serviceRatioCap` / B1 `q` |
| 互斥 | `militaryDoctrine`（vs 志愿兵役制） |

**设计思路**：全民兵役制（韩国现行）——提高服役比例上限，让更多人口可转为兵源；玩家要多养兵，要么提比例（本卡）、要么提人口。与志愿兵役制互斥（数量 vs 质量）。
**数值思路**：**待填**。

### 军-08 军队经商 `militaryBusiness`（新增 · 11-23 院长点名 · 唯一强负面卡）
| 项 | 内容 |
|---|---|
| 卡色/阶段 | 红 / 中期 |
| 效果 | **财收入提升（按军队规模：每兵 X 财/回）**；**战斗力下降（q 显著降低）**；**城市忠诚下降**；**国际声誉下降（走私/腐败丑闻）** |
| 解锁 | 开局 |
| 落点 | 财（军队规模×系数）/ B1 `q` / 忠诚流 / `rep` |

**设计思路**：1985–1998 中国军队经商（"军队要忍耐"：财政只拨六成军费、四成自筹）——用军队经营收入补军费，规模越大赚得越多；但现实副作用严重且被官方后来定性：**腐败与走私（军车军牌/免税优势）、训练废弛（"抓训练不如抓创收"）、战斗力下降、与民争利**。院长 11-23 令："根据军队规模提升财产出，但要有足够大副作用"——本卡是全池**唯一带可感知强负面**的政策卡（特批）。
**数值思路**：**待填**；设计参考=收益"军队规模 × 系数财/回"（军队越大收益越高）、副作用 q ×0.9 / 忠诚 −0.3/回 / rep −0.3/回（数值定版填）。
