### 1.3 关键原始量

```
总人口 P = P_own + P_foreign
驻军/军队 A（计入 P；不产出）
平民 Pc = P − A
承载 C = Σ居民楼容量
```

## 二、L1 基础量（公式 + 意义）

### 2.1 住房分 H

```
承载率 r = P / C
拥挤分 crowd = clamp(1.10 − 0.60×r, 0, 1)
住房质量 q = Σ(居民楼类型分 × 承载占比)     // 鸽子笼20/公寓40/小区70/别墅90
H = 100 × (0.5×q/100 + 0.5×crowd)
```

- **意义**：把“住得挤不挤”和“住得好不好”合成一个 0~100 的住房分。
- **为什么**：r=0.9→crowd≈0.56、r=1.5→0.20、r≥1.83→0；质量分独立，避免“只堆鸽子笼”也算高宜居。单调、无死区。

### 2.2 人口结构

```
外籍比例 f = P_foreign / P
本国比例 o = 1 − f
服役比例 v = A / P
驻军比 g = A / P
```

- **意义**：外籍/本国比例影响文化错位与同化；v 决定兵役负担；g 决定忠诚正影响（v3 起不再有叛乱分类/压制）。
- **为什么**：军队计入总人口（院长 #7），所以 v 与 g 同源；不另设“驻军”独立账。

### 2.3 粮食供需（城级收支 + 国家池分配）

> **2026-10-30 B1-F v4 重写**：粮安 F 指标**已删除**，改为"城级余粮 + 库存年数"。权威版见 [03-内政/粮食与人口算法.md](../03-内政/粮食与人口算法.md)。

```
① 城级收支  net_i = Q_i − D_i                    // 本城优先供给本城
   D_i = Pc_i/1000 + 1.5×A_garrison_i/1000        // 驻军 1.5 倍；出征部队一次性带粮，不计入
   Q_i = Σ农田(净产) + Σ牧场(净产) + Σ渔场(48) + Σ食品工业(45)

② 国家池    P = Σ max(0, net_i)，G = Σ max(0, −net_i)
③ 分配      缺粮城按人口比例领 P（不超过本城缺口；两轮分配）
④ 库存      K' = clamp(K + Σnet_i + 进口 − 出口, 0, 8×D_total)   // 8 年战略储备
⑤ 饥荒      分配后仍缺 → 该城按缺口减人口；有余粮的城永不饥荒
```

- **意义**：**本城粮食优先供给本城**，各城余粮之和 = 国家总粮食（可直接对应库存变化率）。
- **为什么**：旧"全国单一池 + 粮安 F"掩盖了三件事——哪个城在拖后腿、玩家在吃老本、危机和饥荒的区别。改成城级后，UI 一句"余粮 −28"就说清了。
- **危机 ≠ 饥荒**：库存下降是危机（红箭头），库存为负才是饥荒（死人）。
- **不做手动调粮**：不允许"牺牲 A 城把粮全给 B 城"，分配全自动。
- **来源**：农田 40 / 牧场净产 32~36 / 渔场 48 / 食品工业 45 固定（科技只解锁）。

### 2.4 文化错位 m（占领城专用）

```
母国文化比 = 母国文化输出 / (母国文化输出 + 占领者文化输出)   // 0~1
同化淡出 = clamp((0.80 − o) / 0.30, 0, 1)                     // 本国50%→80% 线性淡出
m = f × (0.50 + 0.50×母国文化比) × 同化淡出                    // 0~1
```

- **意义**：外籍人口越多、母国文化越强，文化错位越重；本国人口到 80% 时几乎消失。
- **为什么**：院长 #4——母国文化输出与人口比例直接影响文化错位；同化到 80% 视为完全同化。

### 2.5 占领惩罚 occPen

```
if o ≥ 0.50:  occPen = 15 × clamp((0.80 − o) / 0.30, 0, 1)
else:         occPen = 15
```

- **意义**：占领初期 −15 忠诚；本国人口 50%→80% 线性淡出；80% 归零。
- **为什么**：院长 #4——避免“占领永久 −15”让同化无意义；给占领者一条“同化→正常化”的路。

### 2.6 治安建筑加成 S_b

```
S_b = Σ(警察局/行政建筑治安贡献 × 等级系数)
```

- **意义**：治安的直接来源是**行政建筑**（警察局等），不是驻军。
- **为什么**：院长 #1——驻军只管忠诚，治安靠行政；间接靠降低外籍比例。避免“军国主义自动高治安”。

## 三、L2 状态量（目标值 + 缓动）

> 统一规则：`目标值` 读上回合末状态；`实际值 += (目标−实际)×0.25`（L/S/W/Loyalty 都走缓动），单回 ±10；事件冲击只扣实际值，不污染目标值。

### 3.1 宜居度 L

```
L* = B_L
   + 0.40×(H − 50)          // 住房
   + 0.20×(E − 50)          // 娱乐覆盖（满覆盖=+6/Lv）
   + 0.25×(S − 50)          // 治安
   + 0.15×(Me − 50)         // 医疗
   − 0.30×U                 // 本地污染
   − 10×海平面等级
   − 0.30×臭氧伤害
   − 0.30×核残留
   + 政策直接
```

- **意义**：客观居住环境质量；影响**全产出乘区**与人口增速。
- **为什么**：加法保可解释（面板可拆到每项）；环境惩罚独立扣，避免与住房/治安双算。

### 3.2 治安 S

```
S* = B_S
   + 0.40×(W − 50)          // 民生（秩序的基础）
   + S_b                    // 警察局等行政建筑（直接）
   − 25×f^1.1               // 外籍比例（间接：摩擦）
   + 0.20×(G − 50)          // 治理
   − 12×WAR                 // 战争
   − 10×max(0, r−1)         // 超承载拥挤
   + 政策直接
```

- **意义**：城市秩序；影响宜居、民生、生产稳定。
- **为什么**：驻军不进此式（院长 #1）；警察局直接、外籍比例间接；f^1.1 凸性让“少数外籍无感、过半剧痛”。

### 3.3 民生 W

```
W* = B_W
   + (11 − 30×min(d,1))                   // 粮食：d=本城缺口率；无缺口=+11（v4）
   + 0.28×(L−50)                          // 宜居
   + 0.12×(S−50)                          // 治安
   + 0.10×(G−50)                          // 治理
   + 0.08×(Ea−50)                         // 财富/就业
   − 35×f^1.3×(1−0.005×O)                 // 外籍摩擦（舆论调制）
   − 400×v²                               // 兵役负担
   + warSupport                           // 战争支持度
   + 0.10×(T−50)                          // 耐受
   + 0.10×M                               // 短期情绪
   + 政策直接
```

- **意义**：最顶层生活水平指标；**不直接决定起义**，只通过忠诚度间接影响。
- **为什么**：粮食缺口凸性（越缺越痛）；外籍/兵役幂函数（边际递增）；战争支持度按意识形态分化；冲击分离（伤/病）。

### 3.4 忠诚度 Loyalty（R47 流量积分模型：民生只改升降速度）

**忠诚度是 0~100 的存量慢变量，不是民生派生值。民生只决定每回合升降多少，不能一年改命。**

```
ΔLoyalty = 民生流 + 治安流 + 治理流 + 外籍流 + 占领流 + 文化流
         + 驻军流 + 武将流 + 镇压流 + 自然回流
Loyalty' = clamp(Loyalty + clamp(ΔLoyalty, −10, +5), 0, 100)

民生流（舒适带 [40,55]）：
  W < 40:  −0.15 × (40 − W)^1.1
  W > 55:  +0.15 × (W − 55)^0.8
  带内:    0

其他流：
  治安：S<40 → −0.08×(40−S)；S>60 → +0.04×(S−60)
  治理：+0.05×(G−50)
  外籍：−4×f
  占领：−2.5×(occPen/15)（occPen 随本国人口 50→80% 淡出）
  文化错位：−2.0×m
  驻军：+1.0×min(g/0.05, 1)
  武将：+0.5
  镇压：+3/回合，共 5 回合（合计 +15）
  自然回流：W∈[40,55] 且无负项时 +0.3×(60−Loyalty)/60
```

- **意义**：信任是存量，民生只决定"变好/变坏多快"；低民生一年只掉 5 分左右，长期低民生+外籍/占领/治安才会压到 30。
- **为什么**：院长 #1/#2——民生不直接改写忠诚；一年低民生 100→90 多仍忠诚；只有长期综合发力才到起义线。负流比正流强（信任建得慢、塌得快），正流封顶 +5/回。
- **参数（C2 已采纳，R48）**：`kn=kp=0.15`、舒适带 `[40,55]`、单回 `[−10,+5]`、起始忠诚按城市数据（核心城 80~100，占领城 60 底线）。
- **实测（C2）**：

| 场景 | 结果 |
|---|---|
| 一年 W=15 | 100→**94.8**，仍忠诚 |
| 3 年 W=15 | 90→75.6，不反 |
| 10 年 W=15 | 90→**38.3**（警戒，未到 30） |
| 20 年 W=15 | 0（起义） |
| 10 年低后 W=80 | 恢复到 60 需 **22 回合**（余震期） |
| 正弦 W20~60 | 100 年逐步降到 0（长期低均值，慢死） |

- **起义判定（v3）**：读 `Loyalty` 实际值；普通城 `Loyalty<30` 连续 3 回合，占领城 `<20` 连续 10 回合。**不掷概率、不分外籍类别**；触发后城市中立起义（2026-11-26 自立已删；原城武将→最近己方城，飞城→归隐）。
- **占领军管**：前 10 回合 `Loyalty = max(60, Loyalty)`；之后按流量走。
- **判定不再读民生**；民生、治安、外籍、占领、文化、驻军、武将、镇压全部通过"流"影响忠诚。

### 3.5 粮食安全 F

❌ **已删除（2026-10-30 B1-F v4）**：粮安 F 指标不再存在，见 §2.3；现行口径=城级余粮 + 库存年数（[粮食与人口算法](../03-内政/粮食与人口算法.md)）。本小节仅留索引。

### 3.6 士气 Morale（跟随部队 · 2026-11-06 院长裁） ❌**已被 2026-11-22 裁定覆盖：L3 士气=部队乘区（0~100/60 起/主将 +15；四档 ×1.10/1.00/0.85/0.60；溃散<20 或只剩伤兵；无溃走/俘获机制），见 L3战斗层开题 v0.3 §4.4（D8）**

单位士气 m（0~100，每支部队独立）：

```
m = clamp(60 + 战略修正 + 战斗修正, 0, 100)
战略修正：缺粮 −20 / 民生崩 −15 / 被围>3 回 −10 / 战争支持 +5
战斗修正：突袭 +20（攻）/−20（守，前 3 tick）/ 胜仗 +10 / 败仗 −15 /
          武将阵亡或被俘 −20 / 主动撤退 −10 / 友军全灭 −10 / 老兵 +5 / 精锐 +10
战力乘区：q_morale = 0.8 + 0.4 × (m/100)      // 0.8~1.2；m=60 → 1.04
阈值：m≤20 动摇（q×0.85、不能主动进攻）；m≤0 溃逃（退出战斗，按 30% 撤离）
```

- **意义**：士气是**单位级**乘区，跟随部队；战略层只提供基座修正，不再直接乘全军。
- **为什么**：围城→粮→民生→士气的耦合落到具体部队上，战斗层可解释（战报可列每支部队士气）。

## 四、L3 结果量

### 4.1 产出

```
Pc = P − A
产出 = Σ(建筑产出 × 等级^1.4)
      × (1 + max(0, 驻城政治−50)/150)     // 建筑派驻武将政治；无派驻 ×1.0（11-10 口径；sim/Unity 未实装，11-25）
      × (1 + 0.5×min(Pc/60000, 1))       // 人口红利，封顶 +50%
      × (0.8 + 0.4×L/100)                 // 宜居乘区 0.8~1.2
      × (0.85 + 0.3×S/100)                // 治安乘区 0.85~1.15
      × (0.8 + 0.4×W/100)                 // 民生乘区 0.8~1.2
      × (1 + 政策)
      − 俸禄 − 维护
```

- **意义**：低民生/低治安/低宜居都会直接砍产出，哪怕忠诚被驻军撑住。
- **为什么**：院长 #10——低民生高忠诚只能少起义，产出照样掉；军队占人口（Pc）所以不产出。
- **B1-C 商业特则（2026-11-02，院长 #7）**：商业建筑的**消费回收**（商业街/商场）**不乘民生乘区**——民生不直接作为消费力因子，只通过就业/人口/治安/事件耦合间接影响；**写字楼/工业/农业产出仍乘民生乘区**（生产力耦合）。见 [03-内政/商业区公式登记.md](../03-内政/商业区公式登记.md) P0-3。
- **闭环**：产出→Ea→W→产出，增益≈0.01，稳定。

### 4.2 人口增长 ❌**已被 2026-11-12/13 裁定覆盖：单一人口公式 g=0.006×h×f_L^1.5×f_F×(1.5−r)、ΔP=P×clamp(g,±2%)、无 f_C 硬闸门、平衡点 1.5×承载（人口算法-v1 §7.2）**

```
f_L = clamp(L/60, 0.5, 1.5)
f_F = clamp(0.40 + 0.30×min(m,2), 0, 1)   // m=K/D 国家库存年数（v4）
f_C = clamp((C − P)/C, 0, 1)
增长 = Pc × 2%/回 × f_L × f_F × f_C
if 本城缺口 d>0: 增长 = −min(5%, 10%×d)   // 城级饥荒（v4）
if L<20: 增长 = −3%×Pc
```

- **意义**：人口是慢变量，被粮食/宜居/承载三闸门卡住。
- **为什么**：比例制避免“基础10人”与城市规模脱钩；承载卡顶让居民楼成为人口阀门。

### 4.3 同化

```
文化因子 = clamp(1 + 1.5×(国家文化值−50)/150, 1.0, 2.5)
同化/回 = min( P_foreign × 2% × 文化因子 × (1 − 0.5×占领), P_foreign × 5% )
```

- **意义**：外籍→本国；占领城也按此产生本国人口（院长 #4）。
- **为什么**：文化强城同化快；占领减半；上限 5%。

### 4.4 起义（v3：城市忠诚度单阈值，2026-11-10 简化）

```
触发（只看城市忠诚度，不掷概率）：
  普通城：Loyalty < 30 连续 3 回合
  占领城：Loyalty < 20 连续 10 回合

结局（触发时）：
  城市中立起义（只守不攻；起义城 AI 自行发展）
  原城武将→最近己方城，飞城→归隐（2026-11-26 自立已删）
```

- **已删**：叛乱（外籍≥75%）支线、`(30−Loyalty)/30` 概率、驻军/人口≥5% 硬零、75% 类别分界。
- **意义**：城市忠诚度是唯一开关；民生/治安/外籍/占领/驻军/武将都通过忠诚流生效。外籍比例只影响民生/治安/同化，不再分类。
- **占领城**：10 回合军管（Loyalty 维持 60 底线）；同化到 80% 后占领惩罚/文化错位归零，城市正常化。
- **镇压**：v0 提案一次性忠诚 +15、人口等量消耗、W−5、声誉−5、无难民流（简化待定）。
- **叛逃/归隐**：个人忠诚<40 的驻城武将每回合概率触发去向（先于起义判定；2026-11-26 取代已删的外逃/自立），见 [02-武将/忠诚度.md](../02-武将/忠诚度.md)。

### 4.5 军力 ❌**士气乘区口径已被 2026-11-22 L3 裁定覆盖（见 §3.6 标注）；战斗解以 [L3战斗层开题](../04-军事/L3战斗层开题.md) §4.3 为准**

```
军力 = A × 兵种质量 × 装备率 × 士气 × 补给 × 城防
装备率 = min(1, 已配发EP / 需求EP)        // 需求EP=Σ(N_i/1000×兵种装备系数)
士气 = 部队平均 q_morale                  // 0.8+0.4×(m/100)，m 跟随部队（§3.6）
```

- **意义**：军队规模 × 质量 × 装备匹配 × 士气/补给/城防；围城缺粮会一路打到军力。
- **为什么**：粮食不是独立“进攻时间”公式，而是通过士气/补给进入军力（院长 #5）；装备率替代旧"军备效率"，与兵种数值表 §五 同源。

### 4.6 战争支持度

```
warSupport = WAR × ((O<0 或 军国主义) ? +3 : −2)
           − 0.35×warTurns
           − 0.15×max(0, 2−m)     // 库存不足 2 年 → 反战（v4，m=K/D）
```

- **意义**：民族主义/军国主义 rally；久战疲劳；缺粮反战。
- **为什么**：战争真实代价走军队占人口/军粮/兵员/财；不堵统一路线（院长 #5）。

### 4.7 围城断供（只在围城驻扎时）

```
本城 F_local = 100 × clamp((Q_local + K_local)/(1.2×D_local),0,1)
D_local = P/1000 + A/1000×0.5
K_local' = max(0, K_local + Q_local − D_local)，上限 8×D_local
```

- **意义**：被围城从全国池剔除，只吃本城；本城产出**不打折**（院长 #2），玩家用库存/产出/消耗算坚持回合。
- **攻方粮尽**：`驻扎回合 + 进攻回合 > 携带粮草回合` → 必须原路撤军（院长 #5）；每回合武将询问攻城/驻守与剩余粮草。
- **投降**：F_local=0 连续 3 回合 → 投降/突围。

## 五、结算顺序与耦合环

### 5.0 回合节点框架（2026-11-26 院长定，权威时序）

```
回合开始
  ├─ [turnStart 事件卡出现并即时生效]
  ├─ pending 事件生效（上回合结算中出现的事件此刻生效/可响应）
  ├─ 持续效果 tick / 到期恢复
  ├─ 会议/UN 投票（AI 发起/定期全球大会/紧急会议）
可操作回合中
  ├─ 玩家/AI 操作（建造/政策/军事/外交）
  ├─ 玩家发起会议=当场谈判当场结算（耗外交行动槽）
  ├─ 选择型事件卡弹出选择（一律回合初）
点击"下一回合"
  ├─ 本阵营（玩家）[preSettle 事件卡出现] → 本阵营数值 → 本阵营行动
  ├─ A 阵营 [preSettle 事件卡出现] → A 数值 → A 行动
  ├─ B 阵营 [preSettle 事件卡出现] → B 数值 → B 行动
  │    …（逐阵营"事件卡→数值→行动"；贸易/协定结算在数值阶段；
  │      preSettle 事件本轮不处理其效果，下回合开始才生效）
  ├─ 回合末判定：叛逃/归隐→起义（同回合先叛逃/归隐后起义）
  ├─ [turnEnd 全局事件卡出现]（无归属/剧情杀，如斗转星移；下回合初生效）
  └─ 结算完毕
回合开始（循环）
```

- **事件卡三个出现节点**（`card.appearAt`）：**turnStart**（回合开始，出现即生效）/ **preSettle**（**归属阵营结算前**出现——2026-11-26 院长细化：按阵营挂载，本阵营卡在本阵营结算前、B 阵营卡在 B 阵营结算前；下回合初生效）/ **turnEnd**（全结算完毕，仅全局无归属/剧情杀使用；下回合初生效）。
- **生效纪律**：preSettle/turnEnd 类事件的数值效果**不参与本轮结算**——本轮一切计算基于事件前状态（如自立门户改变阵营数量，本轮结算仍按自立前阵营算）。
- **玩家体验纪律**：结算阶段玩家无操作——事件卡出现不得让玩家产生"被安排"感；选择型交互**一律回合初弹出**（玩家可操作时选择，选择完成才生效）；剧情杀（如群星·斗转星移）允许结算阶段强制出现。
- 插入点总表：会议/UN=回合初；贸易/协定=逐阵营数值阶段；叛逃/归隐/起义=回合末（先叛逃/归隐后起义）；pending 生效=回合初；自动存档=每回合覆盖。

### 5.1 数值结算顺序（11 步）

```
1 环境：五账本→每城 envMods
2 全国粮池：Q/D/K/F
3 每城：住房分→宜居目标→缓动；治安目标→缓动
4 每城：民生目标→缓动+冲击；忠诚度目标
5 人口：增长/流失、同化；军队=驻军分配
6 士气/军力：F_local、W、战争支持、围城
7 起义（阵营顺序；城市忠诚单阈值）
8 围城：本城消耗、士气、投降/突围/解围
9 产出：Pc、L、S、W→财/粮/生产力/科技
10 战争：动员、粮/装备消耗、伤亡、warSupport
11 统一判定：无中立/其他阵营
```

**主环**：`围城→F_local↓→W↓→L/S↓→人口↓→A/P↑→忠诚↑（驻军）但与 W↓ 对冲→士气↓→军力↓→城破→全国池/其他城 F 变化`。
**正反馈**：治安恶化（W↓→S↓→L↓→W↓）；难民/外籍摩擦（f↑→S↓/W↓）。**负反馈**：粮食人口、同化、兵役、拥挤。正反馈增益约 0.08 <1，不发散。

## 六、占领城特则

| 规则 | 口径 |
|---|---|
| 定义 | `owner ≠ motherNation`，包括达尔文（NONE 母国被占） |
| 10 回合军管 | Loyalty **维持 60 底线**；公式算得更高则正常上升 |
| 占领惩罚 | 忠诚流 −2.5/回合（按 occPen/15），随本国人口 50→80% 淡出；o≥80% → 0 |
| 文化错位 | f × 母国文化比 × 同化淡出；o≥80% ≈0 |
| 起义资格 | Loyalty<20 连续 10 回合（占领城）；触发后城市中立 |
| ~~叛乱~~ | ❌ 已删（2026-11-10：外籍 75% 分类/5% 硬零/叛军攻防全部作废） |
| ~~自立~~ | ❌ **已删（2026-11-26 院长裁）**：不再带城自立建新阵营；低忠诚武将走**叛逃/归隐**（见 [忠诚度](../02-武将/忠诚度.md)） |

| **收复** | `motherNation == 攻击方阵营` 且 `owner != motherNation`（新阵营/被占）：`P_own += P_foreign, P_foreign=0`（**人口不算外籍**）；征收率 1.0；无占领惩罚/外籍摩擦；Loyalty 重置 60；10 回合军管不适用。见 [03-内政/人口税与土地价格.md](../03-内政/人口税与土地价格.md) §四 |
