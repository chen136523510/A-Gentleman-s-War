# 数值公式总纲（权威）

> 状态：✅ **R49 v1.3 权威文档**（R47 忠诚改流量积分、C2 采纳；R49 人口全量数值落地见 [人口数值表.md](../03-内政/人口数值表.md)）——代码逻辑与数值开发以此为准；任何改动先改本文件 + changelog，再改 `balance.json`。
> 范围：人口/内政/军事/粮食/占领/起义核心链。科技/外交/事件/环境五账本的细则后续按同一分层补入。
> 读法：**L0 原始数据 → L1 基础量 → L2 状态量 → L3 结果量 → L4 终局**。每层只依赖下层，不反向定义。

## 〇、分层总图

```
L0 原始数据
  城市：人口/建筑/地形/母国/占领者/军队/装备/武将
  建筑：类型/等级/产出/宜居/治安/粮食/承载/维护/污染
  政策：直接修正/意识形态/耐受/兵役/移民/环保
  世界：碳/温度/海平面/臭氧/酸雨/核/矿脉
  常数：balance.json 全部系数
        ↓
L1 基础量（一次算出，供多层用）
  住房分 H、承载率 r、外籍比例 f、本国比例 o、服役比例 v、
  粮食供需 Q/D、文化错位 m、占领惩罚 occPen、驻军比 g、建筑治安加成 S_b
        ↓
L2 状态量（每回合目标值 + 缓动）
  宜居度 L、治安 S、民生 W、粮食安全 F、忠诚度 Loyalty、士气 Morale
        ↓
L3 结果量（读 L2 或 L1）
  产出、人口增长/流失、同化、起义/叛乱、军力、战争支持度、环境衰减
        ↓
L4 终局
  统一/文化/科技胜利、海平面三级全局失败
```

**设计原则**：L2 只写“状态”，不写“后果”；L3 只写“后果”，不反写 L2。循环依赖靠“目标值读上回合末状态”切断。

## 一、L0 原始数据

### 1.1 城市字段

| 字段 | 含义 | 来源 |
|---|---|---|
| `population.own` / `population.foreign` | 本国/外籍人口 | 存档 |
| `owner` / `motherNation` | 当前所有者 / 母国 | 数据+剧本 |
| `buildings[]` | 建筑列表（类型/等级） | 存档 |
| `army` | 驻军（=军队驻城部分，计入总人口） | 存档 |
| `equipment` | 军备存量 | 存档 |
| `general` | 坐镇武将（可为空） | 存档 |
| `occupationTurn` | 占领回合（无占领=-99） | 存档 |
| `baseLivability` / `baseSecurity` | 城市固有基线 | `cities.json` |
| `cultureMismatchSource` | 母国文化输出/占领者文化输出 | 运行时 |

### 1.2 建筑字段

| 字段 | 含义 |
|---|---|
| `output` | 财/粮/生产力/科技基础产出 |
| `livability` | 宜居贡献（娱乐/居民楼/医疗） |
| `security` | 治安贡献（**警察局等行政建筑**，R45 院长定） |
| `capacity` | 居民楼承载 |
| `food` | 农田/牧场/食品工业粮食产出 |
| `maintenance` | 维护费 |
| `pollution` | 本地污染 |
| `level` | 等级（产出 × level^1.4） |

### 1.3 关键原始量

```
总人口 P = P_own + P_foreign
驻军/军队 A（计入 P；不产出）
平民 Pc = P − A
承载 C = Σ居民楼容量
```

## 二、L1 基础量（公式 + 意义）

### 2.1 住房分 H

```
承载率 r = P / C
拥挤分 crowd = clamp(1.10 − 0.60×r, 0, 1)
住房质量 q = Σ(居民楼类型分 × 承载占比)     // 鸽子笼20/公寓40/小区70/别墅90
H = 100 × (0.5×q/100 + 0.5×crowd)
```

- **意义**：把“住得挤不挤”和“住得好不好”合成一个 0~100 的住房分。
- **为什么**：r=0.9→crowd≈0.56、r=1.5→0.20、r≥1.83→0；质量分独立，避免“只堆鸽子笼”也算高宜居。单调、无死区。

### 2.2 人口结构

```
外籍比例 f = P_foreign / P
本国比例 o = 1 − f
服役比例 v = A / P
驻军比 g = A / P
```

- **意义**：外籍/本国比例决定起义 vs 叛乱、文化错位、同化；v 决定兵役负担；g 决定忠诚正影响与叛乱压制。
- **为什么**：军队计入总人口（院长 #7），所以 v 与 g 同源；不另设“驻军”独立账。

### 2.3 粮食供需（全国粮池）

```
全国需求 D = Σ城市( P/1000 + A/1000 × 0.5 )      // 粮单位=千人份/年；军队 1.5 倍口粮
全国供给 Q = Σ农田 + Σ牧场 + Σ食品工业 + 进口     // 农田/牧场受耕地容量；工业受产能+科技
库存 K' = max(0, K + Q − D)，且 K ≤ 8×D           // 8 年战略储备（院长 #1）
全国粮安 F = 100 × clamp( (Q + K) / (1.2×D), 0, 1)
```

- **意义**：粮食是国家级共享资源，不是各城自产自吃；**上海缺粮可从西安调**。
- **为什么**：全国池避免“每城单独算粮”的心智负担；8 年上限防“种够躺平”；被围城断供（见 §六）。
- **来源**：农田/牧场同级同产出；食品工业（罐头/预制菜）把产能+科技转粮、不占耕地。

### 2.4 文化错位 m（占领城专用）

```
母国文化比 = 母国文化输出 / (母国文化输出 + 占领者文化输出)   // 0~1
同化淡出 = clamp((0.80 − o) / 0.30, 0, 1)                     // 本国50%→80% 线性淡出
m = f × (0.50 + 0.50×母国文化比) × 同化淡出                    // 0~1
```

- **意义**：外籍人口越多、母国文化越强，文化错位越重；本国人口到 80% 时几乎消失。
- **为什么**：院长 #4——母国文化输出与人口比例直接影响文化错位；同化到 80% 视为完全同化。

### 2.5 占领惩罚 occPen

```
if o ≥ 0.50:  occPen = 15 × clamp((0.80 − o) / 0.30, 0, 1)
else:         occPen = 15
```

- **意义**：占领初期 −15 忠诚；本国人口 50%→80% 线性淡出；80% 归零。
- **为什么**：院长 #4——避免“占领永久 −15”让同化无意义；给占领者一条“同化→正常化”的路。

### 2.6 治安建筑加成 S_b

```
S_b = Σ(警察局/行政建筑治安贡献 × 等级系数)
```

- **意义**：治安的直接来源是**行政建筑**（警察局等），不是驻军。
- **为什么**：院长 #1——驻军只管忠诚，治安靠行政；间接靠降低外籍比例。避免“军国主义自动高治安”。

## 三、L2 状态量（目标值 + 缓动）

> 统一规则：`目标值` 读上回合末状态；`实际值 += (目标−实际)×0.25`（L/S/W/Loyalty 都走缓动），单回 ±10；事件冲击只扣实际值，不污染目标值。

### 3.1 宜居度 L

```
L* = B_L
   + 0.40×(H − 50)          // 住房
   + 0.20×(E − 50)          // 娱乐覆盖（满覆盖=+6/Lv）
   + 0.25×(S − 50)          // 治安
   + 0.15×(Me − 50)         // 医疗
   − 0.30×U                 // 本地污染
   − 10×海平面等级
   − 0.30×臭氧伤害
   − 0.30×核残留
   + 政策直接
```

- **意义**：客观居住环境质量；影响**全产出乘区**与人口增速。
- **为什么**：加法保可解释（面板可拆到每项）；环境惩罚独立扣，避免与住房/治安双算。

### 3.2 治安 S

```
S* = B_S
   + 0.40×(W − 50)          // 民生（秩序的基础）
   + S_b                    // 警察局等行政建筑（直接）
   − 25×f^1.1               // 外籍比例（间接：摩擦）
   + 0.20×(G − 50)          // 治理
   − 12×WAR                 // 战争
   − 10×max(0, r−1)         // 超承载拥挤
   + 政策直接
```

- **意义**：城市秩序；影响宜居、民生、生产稳定。
- **为什么**：驻军不进此式（院长 #1）；警察局直接、外籍比例间接；f^1.1 凸性让“少数外籍无感、过半剧痛”。

### 3.3 民生 W

```
W* = B_W
   + 0.22×(F−50) − 0.35×max(0,50−F)^1.3   // 粮食（饥荒膝）
   + 0.28×(L−50)                          // 宜居
   + 0.12×(S−50)                          // 治安
   + 0.10×(G−50)                          // 治理
   + 0.08×(Ea−50)                         // 财富/就业
   − 35×f^1.3×(1−0.005×O)                 // 外籍摩擦（舆论调制）
   − 400×v²                               // 兵役负担
   + warSupport                           // 战争支持度
   + 0.10×(T−50)                          // 耐受
   + 0.10×M                               // 短期情绪
   + 政策直接
```

- **意义**：最顶层生活水平指标；**不直接决定起义**，只通过忠诚度间接影响。
- **为什么**：粮食缺口凸性（越缺越痛）；外籍/兵役幂函数（边际递增）；战争支持度按意识形态分化；冲击分离（伤/病）。

### 3.4 忠诚度 Loyalty（R47 流量积分模型：民生只改升降速度）

**忠诚度是 0~100 的存量慢变量，不是民生派生值。民生只决定每回合升降多少，不能一年改命。**

```
ΔLoyalty = 民生流 + 治安流 + 治理流 + 外籍流 + 占领流 + 文化流
         + 驻军流 + 武将流 + 镇压流 + 自然回流
Loyalty' = clamp(Loyalty + clamp(ΔLoyalty, −10, +5), 0, 100)

民生流（舒适带 [40,55]）：
  W < 40:  −0.15 × (40 − W)^1.1
  W > 55:  +0.15 × (W − 55)^0.8
  带内:    0

其他流：
  治安：S<40 → −0.08×(40−S)；S>60 → +0.04×(S−60)
  治理：+0.05×(G−50)
  外籍：−4×f
  占领：−2.5×(occPen/15)（occPen 随本国人口 50→80% 淡出）
  文化错位：−2.0×m
  驻军：+1.0×min(g/0.05, 1)
  武将：+0.5
  镇压：+3/回合，共 5 回合（合计 +15）
  自然回流：W∈[40,55] 且无负项时 +0.3×(60−Loyalty)/60
```

- **意义**：信任是存量，民生只决定"变好/变坏多快"；低民生一年只掉 5 分左右，长期低民生+外籍/占领/治安才会压到 30。
- **为什么**：院长 #1/#2——民生不直接改写忠诚；一年低民生 100→90 多仍忠诚；只有长期综合发力才到起义线。负流比正流强（信任建得慢、塌得快），正流封顶 +5/回。
- **参数（C2 已采纳，R48）**：`kn=kp=0.15`、舒适带 `[40,55]`、单回 `[−10,+5]`、起始忠诚按城市数据（核心城 80~100，占领城 60 底线）。
- **实测（C2）**：

| 场景 | 结果 |
|---|---|
| 一年 W=15 | 100→**94.8**，仍忠诚 |
| 3 年 W=15 | 90→75.6，不反 |
| 10 年 W=15 | 90→**38.3**（警戒，未到 30） |
| 20 年 W=15 | 0（起义） |
| 10 年低后 W=80 | 恢复到 60 需 **22 回合**（余震期） |
| 正弦 W20~60 | 100 年逐步降到 0（长期低均值，慢死） |

- **起义/叛乱判定**：读 `Loyalty` 实际值；`Loyalty<30` 连续 3 回合（占领城且本国≥75% 时 `<20` 连续 10 回合）。
- **占领军管**：前 10 回合 `Loyalty = max(60, Loyalty)`；之后按流量走。
- **判定不再读民生**；民生、治安、外籍、占领、文化、驻军、武将、镇压全部通过"流"影响忠诚。

### 3.5 粮食安全 F

见 §2.3；被围城用本城 Q/K/D 单独算（§六）。

### 3.6 士气 Morale

```
Morale = 1.0
       − 0.20×[F_local < 30]        // 缺粮
       − 0.15×[W < 30]              // 民生崩
       − 0.10×[被围 > 3 回合]       // 围城疲劳
       + 0.05×[warSupport > 0]      // 战争 rally
```

- **意义**：军力的乘区；粮食/民生/围城/战争支持都会打到军队上。
- **为什么**：这是“围城→粮→民生→战力”的耦合落点，不走独立公式。

## 四、L3 结果量

### 4.1 产出

```
Pc = P − A
产出 = Σ(建筑产出 × 等级^1.4)
      × (1 + 太守政治/150)
      × (1 + 0.5×min(Pc/60000, 1))       // 人口红利，封顶 +50%
      × (0.8 + 0.4×L/100)                 // 宜居乘区 0.8~1.2
      × (0.85 + 0.3×S/100)                // 治安乘区 0.85~1.15
      × (0.8 + 0.4×W/100)                 // 民生乘区 0.8~1.2
      × (1 + 政策)
      − 俸禄 − 维护
```

- **意义**：低民生/低治安/低宜居都会直接砍产出，哪怕忠诚被驻军撑住。
- **为什么**：院长 #10——低民生高忠诚只能少叛乱，产出照样掉；军队占人口（Pc）所以不产出。
- **闭环**：产出→Ea→W→产出，增益≈0.01，稳定。

### 4.2 人口增长

```
f_L = clamp(L/60, 0.5, 1.5)
f_F = clamp(F/70, 0, 1)
f_C = clamp((C − P)/C, 0, 1)
增长 = Pc × 2%/回 × f_L × f_F × f_C
if F<20 或 L<20: 增长 = −3%×Pc
```

- **意义**：人口是慢变量，被粮食/宜居/承载三闸门卡住。
- **为什么**：比例制避免“基础10人”与城市规模脱钩；承载卡顶让居民楼成为人口阀门。

### 4.3 同化

```
文化因子 = clamp(1 + 1.5×(国家文化值−50)/150, 1.0, 2.5)
同化/回 = min( P_foreign × 2% × 文化因子 × (1 − 0.5×占领), P_foreign × 5% )
```

- **意义**：外籍→本国；占领城也按此产生本国人口（院长 #4）。
- **为什么**：文化强城同化快；占领减半；上限 5%。

### 4.4 起义 / 叛乱（只看忠诚度）

```
分线：o ≥ 0.50 → 起义（占领城需 o≥0.75 才可起义；50~75% 稳定）
      o < 0.50（f>50%）→ 叛乱
共同触发：Loyalty < 30 连续 3 回合（普通城）
          Loyalty < 20 连续 10 回合（占领城且 o≥0.75，极难）

起义：p = clamp((30 − Loyalty)/30, 0, 1)
      触发 → 驻军默认倒戈 → 整城带兵变中立/新阵营（有武将=WLT 逻辑；无武将=达尔文式 NONE）

叛乱：p = clamp((30 − Loyalty)/30, 0, 1)
         × clamp((f − 0.50)/0.50, 0, 1)
         × (1 − g/0.05)
      若 g≥0.05 → p=0
      攻防战：外籍叛军（弱质量/低军备）攻，驻军守；
      守军胜=外籍人口等量消耗、Loyalty 临时+15/5回合、W−5、声誉−5；
      叛军胜=城归母国（母国已灭→复国）
```

- **意义**：忠诚是唯一开关；民生/治安/外籍/占领/驻军/武将都通过忠诚生效。
- **为什么**：院长 #3/#4；占领城 10 回合军管（Loyalty 维持 60 底线）；同化到 80% 后占领惩罚/文化错位归零，城市正常化。
- **镇压**：临时忠诚 +15（5 回合衰减）、人口等量消耗、W−5、声誉−5、无难民流。

### 4.5 军力

```
军力 = A × 兵种质量 × 军备效率 × 士气 × 补给 × 城防
军备效率 = min(装备/(A×K), 1.2)
```

- **意义**：军队规模 × 质量 × 装备匹配 × 士气/补给/城防；围城缺粮会一路打到军力。
- **为什么**：粮食不是独立“进攻时间”公式，而是通过士气/补给进入军力（院长 #5）。

### 4.6 战争支持度

```
warSupport = WAR × ((O<0 或 军国主义) ? +3 : −2)
           − 0.35×warTurns
           − 0.15×max(0,50−F)
```

- **意义**：民族主义/军国主义 rally；久战疲劳；缺粮反战。
- **为什么**：战争真实代价走军队占人口/军粮/兵员/财；不堵统一路线（院长 #5）。

### 4.7 围城断供（只在围城驻扎时）

```
本城 F_local = 100 × clamp((Q_local + K_local)/(1.2×D_local),0,1)
D_local = P/1000 + A/1000×0.5
K_local' = max(0, K_local + Q_local − D_local)，上限 8×D_local
```

- **意义**：被围城从全国池剔除，只吃本城；本城产出**不打折**（院长 #2），玩家用库存/产出/消耗算坚持回合。
- **攻方粮尽**：`驻扎回合 + 进攻回合 > 携带粮草回合` → 必须原路撤军（院长 #5）；每回合武将询问攻城/驻守与剩余粮草。
- **投降**：F_local=0 连续 3 回合 → 投降/突围。

## 五、结算顺序与耦合环

```
1 环境：五账本→每城 envMods
2 全国粮池：Q/D/K/F
3 每城：住房分→宜居目标→缓动；治安目标→缓动
4 每城：民生目标→缓动+冲击；忠诚度目标
5 人口：增长/流失、同化；军队=驻军分配
6 士气/军力：F_local、W、战争支持、围城
7 起义/叛乱（阵营顺序；只看忠诚）
8 围城：本城消耗、士气、投降/突围/解围
9 产出：Pc、L、S、W→财/粮/生产力/科技
10 战争：动员、粮/装备消耗、伤亡、warSupport
11 统一判定：无中立/其他阵营
```

**主环**：`围城→F_local↓→W↓→L/S↓→人口↓→A/P↑→忠诚↑（驻军）但与 W↓ 对冲→士气↓→军力↓→城破→全国池/其他城 F 变化`。
**正反馈**：治安恶化（W↓→S↓→L↓→W↓）；难民/外籍摩擦（f↑→S↓/W↓）。**负反馈**：粮食人口、同化、兵役、拥挤。正反馈增益约 0.08 <1，不发散。

## 六、占领城特则

| 规则 | 口径 |
|---|---|
| 定义 | `owner ≠ motherNation`，包括达尔文（NONE 母国被占） |
| 10 回合军管 | Loyalty **维持 60 底线**；公式算得更高则正常上升 |
| 占领惩罚 | 忠诚流 −2.5/回合（按 occPen/15），随本国人口 50→80% 淡出；o≥80% → 0 |
| 文化错位 | f × 母国文化比 × 同化淡出；o≥80% ≈0 |
| 起义资格 | o≥75% 且 Loyalty<20 连续 10 回合（极难；玩家内政烂到爆炸才触发） |
| 叛乱 | f>50% 时按叛乱；驻军/人口≥5% → 0 |
| 同化 | 占领减半；外籍→本国；o 达 80% 视为完全同化，城市正常化 |
