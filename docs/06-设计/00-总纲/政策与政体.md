# 政策与政体

> 状态：🏗️ v0 骨架（R29b 立项文明 6 式政策卡 · R30 政体选择制定稿+初始政体钦定+可选政体扩充）· 更新：2026-10-26 R30
> 定位：国家级第五柱（政策）；政体决定政策卡池；政策卡作用于财政抽调/文化输出参数/AI 出兵概率/环境治理等乘区。

## 一、核心规则（R29b 院长钦定 + R30 修正）

- **政体是选择制，不是演进制**（R30 院长修正，推翻文明 6 演进制）——开局即选定政体，可变更（变更有代价，待数值期）。
- **四类政策槽位**：军事 / 经济 / 外交 / 特殊。
- **不同政体有不同的政策卡可供选择**；**政策卡选项全部可见**，标注适配政体；另有**通用政策卡**（不限政体）。

## 二、四阵营初始政体（R30 院长钦定：现实是什么就继续）

| 阵营 | 初始政体 | 依据 |
|---|---|---|
| CN | **社会主义** | 现实延续 |
| JP | **君主立宪** | 现实延续 |
| KR | **民主政府**（现韩国政体映射） | 现实延续 |
| AU | **民主政府**（联邦议会制映射） | 现实延续 |
| 自立阵营（WLT 等） | **军政府**（default） | 剧变后自立武装起家 |

## 三、可选政体列表（R30 院长指示多列，白机起草 v1）

> 开局可自选（不限阵营），变更另计。定位与槽位倾向为设计方向，数值待政策卡目录专题。

| 政体 | 定位 | 槽位倾向 | 适配玩法 |
|---|---|---|---|
| **社会主义** | 计划集中，举国体制 | 经济+特殊各+1 | 大基建/资源调配流（CN 初始） |
| **君主立宪** | 传统与稳定 | 外交+1，文化输出小加成 | 文化/传统流（JP 初始） |
| **民主政府** | 民意驱动 | 经济+外交各+1，军事槽-1 | 民生文化流（KR/AU 初始） |
| **军政府** | 秩序优先 | 军事+1，经济槽-1 | 早期扩张/备战流（自立初始） |
| **威权政府** | 强人集中 | 特殊+1 | 铁腕内政流 |
| **技术官僚** | 专家治国 | 经济+1，科技城加速 | 科技种田流 |
| **联邦制** | 地方分权 | 经济+1，**地方财政留存率高** | 财政流/防自立（与财政双层制联动） |
| **神权/传统政体** | 信仰凝聚 | 特殊+1，忠诚加成 | 忠诚稳定流 |
| **军国主义** | 总体战体制 | 军事+2、经济-1、**文化输出大减益** | JP 深沦形态（战争损耗输出，R27b 口径的政体层表达） |

- 政体效果三入口：槽位数量/专属卡池/全局乘区（文化输出、AI 出兵概率的"国家性质"因子即政体，见战斗总述 §出兵决策）。

## 四、政策卡框架（卡面内容随各模块逐轮填充）

```
政策卡 = { 名称, 类别(军事/经济/外交/特殊/通用), 适配政体[], 效果(乘区/解锁/倾向修正) }
```

- 卡池填充挂账：军事卡随 M4、经济卡随 M3 数值期、外交卡随 M5、环境卡随世界级环境系统专题、通用卡随各轮零星立项。
