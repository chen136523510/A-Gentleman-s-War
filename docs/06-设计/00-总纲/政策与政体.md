## 一、核心规则（2026-11-17 最终裁定）

- **无政体系统**：没有政体选择/变更/专属池/政体特效/时代挂钩；所有阵营政策卡**同一起跑线**。
- **五槽保留**：军事/经济/文化/外交/通用；基础槽 **2/2/2/2/2 = 10**；无政体加成。
- **槽位扩展**：基础槽之外，**只能通过事件、典藏等额外获取**（外交提案可发卡）。
- **统一卡池**：初始卡池全阵营相同；设计池 **52 张**（每类 10 张 ×5 + 特殊 2：碳排放配额〔提案获取；~~UN~~已删 11-27〕/环境保护政策〔环保提案/event〕，11-24 定版）；**引擎已落库 52 张（11-24 黑机 `policies.json`）**。
- **卡色**：军红 / 经黄 / 文紫 / 外绿 / 通白（后续卡面用）。
- **装卡免费；冷却期内改动 100 财/次、冷却期满改动 0 财**（2026-11-19 定稿：收费只由冷却决定）。
- **编辑态预览确认+重置保留**（体验优化，不砍）。
- **解锁只留科技/事件**。
- **阵营倾向由大统领特性影响**（游戏里自然产生，不专门写规则）；不做政体/剧本事件；四大阵营仅教学关卡出现。

## 三、政策卡框架

```
政策卡 = {
  id, 名称,
  attribute: 军事 | 经济 | 文化 | 外交 | universal,
  effects: [{ 参数, mult|switch|bias, 值 }],
  costs: [{ 参数, 值 }],          // 可选；绝大多数卡无负面
  unlock: { type: tech | event },
  phase, color, tags
}
```

- 属性通用卡（白）只进通用槽；属性专属卡进同属性槽或通用槽。
- 卡池统一；解锁差异来自科技路线/事件，不是阵营/政体。
- 卡池：**设计池 52 张定版（11-24）**——普通 50（军/经/文/外/通各 10）+ 特殊 2（碳排放配额（提案获取，UN 已删 11-27）/ 环境保护政策 环保提案·event）；**引擎已落库 52（11-24）**；现有 27 张已按五属性归一（原"特殊类"6 张已重分类）。

## 四、外交提案发卡（新机制）

- 外交提案通过后，给**每个阵营**发一张卡（如环保提案→通用“环境保护政策”卡）。
- 发卡带 **mandatory** 标记：要求挂着；**不挂=违约**。
- 违约判定时点/惩罚/能否卸——**后续专题讨论**；架构已留接口（`grantPolicyCard`）。
