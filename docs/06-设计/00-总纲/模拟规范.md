## 一、目的与原则

1. **定版即入模**：任何专题一旦定稿（✅），其核心公式/参数必须进入模拟；草案（📝）标注“草案入模”，未定稿（⏳）标注“未覆盖”。
2. **模拟不是设计权威**：模拟用来**发现冲突/标定参数**，最终口径以设计文档为准；模拟结果写回文档时必须标注“设计级/引擎级”。
3. **可复现**：脚本、参数、版本、输出文件必须可追溯；`tmp/` 脚本不入库，但报告摘要入文档。
4. **不静默遗漏**：本文件 §二 覆盖矩阵是“模拟体检表”；每次新模拟先对表，缺什么写清楚。
5. **⭐ 全量模拟为标准（2026-11-06 院长令）**：**以后所有模拟一律走全量盘**（全区域建筑+人口分配+全专题链路），专题验证盘只作补充——"设计那么多内容，就是要保证全局的游戏性和平衡性，不要为了局部优化导致全局负优化"。首版全量盘=`tmp/sim-full.js`（60+ 建筑卡+缺口驱动决策器+劳动力分配，见文化区开题 §6.4）。
6. **⭐ 变盘矩阵（同令）**：模拟盘要能看到**蝴蝶效应**——标准跑法=多流派 AI 倾向（均衡/文化/工业/军事/科技/商业）×事件变体（自立/和平/战争强度）×3 seed，观察分化与极端结局（灭世/入侵/胜利线）。首版矩阵=`tmp/matrix.js`。

## 四、AI 行为定义（“聪明 AI”）

- **建造**：对每城每类建筑算边际收益/成本（含地价、池剩余、岗位约束），取 ROI 最高；每阵营每回合最多 `ceil(城市数/2)` 个动作。
- **升级**：新建 ROI 不足时，算升级边际收益/成本；Lv2/Lv3 输出 ×1.4/×1.96；升级不占新地。
- **农场**：粮食缺口优先（ROI 高），保证 WLT 正确运营能活。
- **贸易**：假设 R=+30、已签最惠；不做逐伙伴谈判。
- **军事**：固定包，不做军备竞赛/AI 宣战；战争按日程。
- **不做什么**：不优化政策卡、不谈判资源采购、不建 L2 细节、不做科技选择。

## 九、纪律

1. 新模拟先对 §二 覆盖矩阵，缺项写明“未覆盖+原因”。
2. 模拟结果与文档冲突 → 以文档为准，回写“模拟发现”并标 P0/P1。
3. 定版专题未入模 → 不允许宣称“全量模拟通过”。
4. 报告必须给“口径/假设/偏差”，禁止只给结论。
