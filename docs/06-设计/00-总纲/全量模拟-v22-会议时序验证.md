# 全量模拟 v22 · 会议时序验证（白机，2026-11-13）

> 脚本：[sim/v22/full.js](../../../sim/v22/full.js)（`node sim/v22/full.js 200 <seed>`）
> 依据：[外交会议体系](../05-外交/外交会议体系.md) §3.0/§3.2（院长 2026-11-13 第 3 条：会议在"回合结算之后、下回合行动之前"；小范围全票；紧急会议无成本；每回合每阵营最多发起 1 次）
> 口径：本轮只接**全球定期大会 + 全球紧急会议**；同盟会议/经济同盟会议/环保提案按会议体系 §六 后置（运行系统未接）。

## 一、接入（时序）

模拟器回合流水线改为：

```
[阵营结算/资源/征募/兵工厂/科技]
  → [战争结算 + 包围网]
  → [会议阶段 meetingPhase]
  → [常规外交行动]
  → 下回合
```

- `meetingPhase` 插在 `diploTick` 内：战争结算与包围网之后、`if (diplo.war) return` **之前**（战争期也开紧急会议）、常规行动之前——即模拟器语义下的"结算后 → 会议 → 行动前"。
- 会议结果（战争制裁 CB / 经济 / 裁军）写入 `diplo.sanctions`（expire=t+12），**本回合行动直接可用**（`sanctionCb` 判定宣战 CB）——满足"会议结果影响本回合决策操作"。
- 灭国（战争占领最后一城 / 劝降）写入 `diplo.extinct`（fac/by/t），作为紧急会议事由。

## 二、规则落点

| 规则（院长裁定） | 实现 |
|---|---|
| **定期全球大会** | 每 20 回合（t≥warStart=100）；议程=领先制裁（科技+8 / 文化 1.5× / 军事 1.5×） |
| **全球紧急会议** | 事由触发：rep<20 / 侵略记录≥4 / **灭国 10 回合内**（一次性事由，可插队 40 回合事由冷却） |
| **三选项投票** | 同意=参与 / 弃权=随大流 / 反对=不参与；**弃权不算同意、严格过半** |
| **门槛** | 全球会议过半（3 国需 2 / 4 国需 3） |
| **发起制** | 每阵营每回合最多发起 1 次；**发起无成本**；紧急会议发起国冷却 10 回合；定期大会自动召开、不占发起配额 |
| **否决成本** | 发起国 **rep −3** |
| **事由冷却** | `target:type` 40 回合（沿用 A1.2）；已有同类制裁不重复开会 |
| **参与范围** | 战争制裁=全员（非目标）；经济/裁军=同意+弃权参与 |

## 六、观察项 / 待办

1. **全活 4/5 → 5/5**：会议（否决 rep −3、战争期开会、制裁改变科技/收入）改变了外交链，seed2 未灭国。属可接受漂移，是否"过和平"待院长。
2. **科技 26~30 → 25~27**：经济制裁（科技×0.7）频率上升；同时战争期 `return` 仍压掉常规外交行动。观察项，不调参。
3. **定期大会每 20 回合召开，但议程隔 40 回合**（事由冷却 40）：t100 否决 → t140 再议。符合"制裁频率保持 20 回合"的既有裁定（A1.3 ⑥）。
4. **灭国事由插队**已生效（t320），但灭国后若 alive<3 即无会可开（双边）——符合"全球会议 3 国起"。
5. **同盟会议（联合进攻）/ 经济同盟会议 / 环保提案**：按会议体系 §六 后置（分别随同盟运行系统、经济协定、环境系统）。
6. **玩家发起即时结算**：模拟器无玩家，AI 侧统一走会议阶段；玩家侧（UI 发起按钮）归黑机 UI 规格。

## 七、结论与下一步

- **会议时序接入成功**：定期大会/紧急会议/发起制/否决 rep −3/灭国事由全部落点；5 seed 全活 5/5、确定性 ✅、长盘 t346 科技胜利、5% 压力盘不受影响。
- **下一步**：多胜利条件（军事/文化）——科技胜利已收束，余两条胜利路线待定口径后接入。
