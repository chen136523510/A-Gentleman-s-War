# 游戏定位与范围

> 状态：✅ 已定 · 更新：2026-10-26 R25（口径全套刷新：Unity/14 城/四胜利途径/软引导和平期；R8 的 Web/13 城口径作废）

## 一句话定位

仿三国志 12 的实时策略经营游戏 × 文明 6 区域/科技内政 × 红警式"内政建筑即战场实体"联动；**魔改现实世界观：1999 年地球剧变、文明断层，幸存 14 城（13 阵营城 + 达尔文无主据点）逐鹿重建**，男德学院 21 名群友分属 CN/JP/KR/AU 四阵营。

## 基本盘

| 项 | 定案 | 演进 |
|---|---|---|
| 模式 | **单机**（不做网络对战） | R1 起 |
| 世界观 | **1999 年地球剧变**：巨大断层、绝大部分城市毁灭、澳洲漂移至太平洋、各国失联——14 城=幸存城市（R27 院长定稿） | R27 立 |
| 时间口径 | **1 回合 = 1 年**（起点 1999 年；叙事用不参与计算） | R27 院长钦定 |
| 技术形态 | **Unity 2022.3.62f3c1 LTS 中国版 + URP 2D**，JSON 数据驱动，打包 exe 分发 | R18 ADR-009 取代 R1"浏览器权威"（Web 版已归档主仓） |
| 运算位置 | 全本地单机；无部署线 | 同上 |
| 城市 | **14 城**（13 阵营城 + 达尔文无主城；上限 ≤21，留扩展格） | R22 达尔文转正第 14 城 |
| 武将 | **学院 21 人群友，不加 NPC、不补员**（异族击退俘虏=NPC 入将唯一渠道的边界解释，见 06-事件） | R8 定；R23 补边界 |
| 阵营 | 4 个：CN/JP/KR/AU；玩家开局自选（CN 简单 / KR·AU 困难） | R8 定 |
| 单局时长 | **不设上限**（R13："可以一局打好几天"）；默认节奏一晚（3~4h ≈ 60~120 回合）见分晓 | R13 定 |
| 成本纪律 | 全免费/开源路线（引擎个人版/ComfyUI/自研），零订阅；LLM 二期走现有火山方舟通道 | R8 定 |
| 商业化 | 不商业化，内部群体消遣；内容尺度相应放宽（真人玩梗仍需本人过目） | R8 定 |
| 验收方式 | 黑机随时构建 exe 实机验收；白机零 exe 工作（只文档） | R24 双机分工 + R25 定验收口径 |

## 核心循环

```
内政（区域建设/科技/调将/资源）
  → 募兵编成（武将率军，太守出征则后方衰减、跌破临界才空虚）
  → 出征（仅邻接可攻；跨海=登陆战；需提前组织粮草定进攻时限）
  → 战斗（一期全自动结算 / 二期轻量 RTS 可手动）
  → 破城（占领市政府；俘获太守/城池起义中立化）
  → 处置俘虏（劝降/释放/拷打/处决，联动外交）
  → 扩张与镇守（无将空城持续衰减→易空虚起义，受 21 将总数硬约束）
  → 外交/科技破局 → 任一胜利途径达成
```

## 设计原则

- **负反馈纪律（R13 院长定调）**：不给玩家设置过多负反馈——不轻易出现"设施破坏需要修复"类惩罚（战后重建从轻）；**不教玩家玩游戏**，只提供足够丰富的选择和路线；**前期不要有太多战事发生**——R25 已机制化：**开局软引导和平期**（前 10 回合 AI 出兵评分阈值 ×1.5、不排冲突类事件、玩家行为不受限；详见 [数值设计总纲](./数值设计总纲.md) §3.4/§五）。
- **内容体量优先（R14 院长定调）**：整个游戏通过 AI 搭建，玩法不是核心竞争力（拼凑各家游戏精华即可），**游戏体量才是引人留存的关键**——设计工作按"一个模块一个模块拓展内容"推进（扩内容不扩玩法复杂度），白机依授权逐模块产出内容目录（03-内政目录 v1 已启，见 [03-内政/区域与建筑.md](../03-内政/区域与建筑.md)）。

## 胜利条件（R25 定：一期四途径并存）

| 途径 | 达成方向（骨架） | 备注 |
|---|---|---|
| **统一胜利** | 占领全部 13 阵营城（消灭/劝降其他阵营） | 基本途径，R1 起 |
| **科技胜利** | 率先研究完成当前版本全部科技节点（一期占位 3 节点起步，随四线树展开扩充判定面） | R25 立 |
| **文化胜利** | **联合国路线**（R27 院长设计）：全阵营存活+联合同盟成立联合国 → 投票选出唯一常任理事国（盟主）→ 对所有成员国完全文化入侵并维持 10 回合；文化值通过"文化差"驱动文化入侵，不直接作国力 | R27 机制落档 |
| **外交胜利** | 与文化胜利并轨中（联合国成立+当选盟主节点），并轨方案待裁决 | R25 立/R27 并轨 |

- 一期全部途径生效（纯规则判定，不依赖 LLM）；二期仅表现力增强，不改判定。
- 文化胜利机制细则（认同度分配/四大闸门/战争 debuff 等）：[胜利条件.md](./胜利条件.md) §二。
- 外交胜利并轨裁决（§四）：待院长裁（a 并入文化线=三途径 / b 保留浅文化线独立）。
- 达尔文无主城不计入统一胜利的"全部城"口径（=13 阵营城）。
