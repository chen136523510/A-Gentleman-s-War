## 五、商业:税

**定义**：`净商业:税 = 净商业 / 人口税`；`净商业 = 毛商业 − 商业维护（3%×财造价）`；`人口税 = 60 + 1.5×民用人口/1000`。分子只含商业街/商场/写字楼（银行乘数后），**不含贸易、港口固定 10 财、工业财、金矿**；分母只含人口税。

**来历**：2026-11-02 B1-C §4.10 数值复核，v7 模拟跑出商业约税 3.5 倍；院长裁 `60+1.5×民用/1000` + 商业维护 3%，v8.2 实测 **3.10**，落进 **2.5~3.5** 目标带；`模拟规范.md` §4 将其列为验收红线，`商业区公式登记.md` C-08 登记公式。**它不是现实税率，也不是玩家 UI 数，是设计/模拟健康指标**：低于 2.5 商业不划算，高于 3.5 商业滚雪球、税变零头。

**v17a 读数**：CN 2.83 / KR 2.61 / WLT 2.88 达标；AU 2.46 接近；JP 1.58 偏低（科技/工业流，商业只 12 座）。**加贸易后** `(商业+贸易):税`：CN 3.23 / JP 2.67 / KR 3.37 / AU 3.74 / WLT 4.34——A2 多渠道下，低商业单项不等于财政不健康。若要求商业单项全进带：多建商场/写字楼、提高零售池系数、降税基（B12）或降商业维护；会抹平 JP 科技流特色。
