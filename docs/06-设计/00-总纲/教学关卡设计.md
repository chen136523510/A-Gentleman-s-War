## 〇、总长与节奏

- **12 回合**（实机时长待验收）；关键步骤 t1~t7，余 5 回合缓冲。
- **两场 L3**：上海防守（t4）、反攻台北（t6）；L3 实时战斗、无回合，一场在 1 个 L1 回合内打完。

- **无剧情开场**：进入游戏直接落在主界面，由步骤卡/目标高亮开始机制引导（不播开场旁白）。

## 一、表现层口径（无剧情）

> 原则：**教程只写机制提示，不写故事**。文本只允许出现在目标卡/面板说明/结果提示中，且只写操作、数值、条件。

| 通道 | 教程是否编写 | 口径 |
|---|---|---|
| **机制提示**（目标卡/面板内说明） | ✅ 写 | 只写“打开哪个面板、点哪个按钮、达成什么条件”；不写人物、背景、动机 |
| **通用旁白** | ❌ 不写 | 发兵/登陆/城破/投降等走系统通用模板 |
| **事件卡** | ❌ 不写剧情文本 | 系统事件卡若触发，只用系统文本；教程不新增故事卡 |
| **对话字幕** | ❌ 不使用 | 取消角色对话/教程引导者台词；引导改用目标卡+高亮 |
| **提示弹窗** | ✅ 仅结果确认 | 只写机制结果（会议通过/教程完成）；不写剧情叙述 |
| **情报气泡** | ❌ 不写 | 由情报站系统产出 |
| **功能面板** | ❌ 不写文案 | 外交/政策/科技/处置面板直接操作；教程只高亮 |

### 1.1 教程引导底座（沿用 v0.5）

- 教程介入时：**冻结其他所有操作、游戏静止**；只有 `allowedActions`（目标按钮/目标内容）可用；
- 非目标区域覆盖**雾遮挡特效**，目标按钮/内容高亮；具体表现由黑机实现；
- 每次引导只做一件事：高亮目标 → 玩家操作 → 推进步骤。
- **教程预置**：上海**情报站 Lv1**；上海城墙 Lv1/兵营 Lv1/兵工厂 Lv1/军事基地 Lv1（教程 `initialBuildings`）。

### 1.2 名词着色（仅系统文本）

- 系统旁白/事件卡如出现武将名、城市名、阵营名，由 UI 统一着色（武将=金、城市=青、阵营=红）；**教程不新增此类文本**。

### 2.1 L2 军事教程指标（沿用 v0.5）

玩家在上海完成（教程逐步高亮，四步）：

| 步 | 操作 | 指标 |
|---|---|---|
| 1 | **征兵** | 普通步兵 **2,400**（0.3 批，兵营） |
| 2 | **造兵** | 突击步兵 **1 批（8,000）**、机动炮 **0.2 批（1,600）**（兵工厂） |
| 3 | **编队** | 编成 **3 队**：突击步兵队、普通步兵队、机动炮队 |
| 4 | **武将编入** | 魏嘉豪编入突击步兵队 |

- 完成后才进入 t4（上海防守）；数值为教程演出值，可实测微调。
- 若玩家已自行造兵/征兵，`sh-defense-prep` 不重复给兵。
- **资金/资源不足时用 CN 初始数据覆写辅助**（教程 Scenario 给 CN 国库/资源/建筑加成；见 §十二 #9，不动 v22 基础值）。

### 2.2 政策卡教程（新增 · 只教操作）

| 步 | 操作 | 说明 |
|---|---|---|
| 1 | 打开政策面板 | 五槽 2/2/2/2/2=10；卡色军红/经黄/文紫/外绿/通白 |
| 2 | 预览 1 张卡 | 预览显示装卡前后的基础数值 diff；确认后生效 |
| 3 | 装卡 | 扣 100 财；槽位进入冷却 t1/t2/t3（按卡档位） |
| 4 | 卸卡 | 免费；卸卡后槽位按规则恢复 |

- **只演示操作与约束**：不讲解卡组策略、不推荐卡、不涉及 AI 决策。
- 互斥组：装卡时如有互斥已装卡，面板提示冲突并禁止确认（教程只演示 1 次冲突提示即可）。
- 教程不强制玩家保留某张卡；完成装/卸各 1 次即推进。

## 三、引导文本口径（无剧情）

- 允许的文本：目标卡标题/一句话操作说明、面板字段名、数值、条件、失败重试提示、完成提示。
- 禁止的文本：角色名台词、剧情旁白、世界观叙述、事件故事卡、教程专属“开场白”。
- 语气：公文白话、无人物性格、无隐喻；不出现“主席/将军”等角色称呼。
- 示例（允许）：“打开政策面板，预览一张卡后装卡。”“本市粮食不足：在农业区建 1 座农田。”
- 示例（禁止）：“陈梓键：深圳粮食不足，建议先建一座农业区。”

## 四、科技终局（v0.5 口径不变）

> 院长第 20/21 条：不再用“独立 9 节点树 + 事件授予”；教程把主树节点全部置为已完成，只留终极工程由玩家手动研究。
> **开局高度（11-19 口径）**：主树全完成 + 教程加成（§十二 #9）构成教学局的**开局高度**——直接展示后期内容、展示终局玩法；属教学展示取值，**非平衡取值**，教学局不参与平衡验收。

| 项 | 口径 |
|---|---|
| 科技树 | **主树 40 节点全部 `completed`**（科技面板显示三线全完成）；不改主树节点/成本 |
| 可选工程 | 3 个终极工程（上帝之杖/AGI 红皇后/人造太阳） |
| 玩家操作 | 科技面板手动选 1 个工程 → 显示研究回合数（**固定 1 回合**）→ 确认研究 |
| 结算 | 下一回合结算时判定科技胜利（建成即判） |
| 结束 | 胜利结算后【提示】“已完成教程” + 按钮“返回主界面” |
| 数据落点 | `ScenarioDefinition.techTreeOverrides.completedNodes=all`；`ultimateProject.turnsOverride=1`（教程参数） |
| 面板展示 | **完整三线可拖动查看**；教程中**所有节点点亮**；UI 样式由黑机处理 |
