## 一、表现层分工（底座概念，院长第 13/15 条）

> 原则：**通用系统负责通用行动表现，教程只写专属引导**。不为每个行动/副本写全排列文案。

| 通道 | 定义 | 谁提供 | 教程是否编写 |
|---|---|---|---|
| **事件卡** | 事件发生时的卡片内容；专有名词着色（§1.2） | 事件系统 | ✅ 教程写事件文本（如自立/韩流） |
| **通用旁白** | 通用行动播报：发兵、登陆、城破、投降、劫掠等 | 系统模板 | ❌ **不写**，教程复用 |
| **对话字幕** | 屏幕底部字幕，教程引导者对话 | 教程 | ✅ 只写引导对话 |
| **提示弹窗** | 屏幕中央弹窗 + 确认按钮，重要信息 | 教程/系统 | ✅ 写需要玩家确认的信息（会议结果/教程完成） |
| **情报气泡** | 情报系统产出（情报站/侦察） | 情报系统 | ❌ 不写，由情报站提供 |
| **功能面板** | 外交/科技/处置等面板：数值、按钮、选项 | UI 系统 | ❌ 不写文案，直接操作面板 |

### 1.1 教程引导底座（院长第 13 条）

- 教程介入时：**冻结其他所有操作、游戏静止**；只有 `allowedActions`（目标按钮/目标内容）可用；
- 非目标区域覆盖**雾遮挡特效**，目标按钮/内容高亮；具体表现由黑机实现；
- 每次引导只做一件事：高亮目标 → 玩家操作 → 推进步骤。
- **教程预置**：上海**情报站 Lv1**（情报气泡来源；院长第 5 条）；上海城墙 Lv1/兵营 Lv1/兵工厂 Lv1/军事基地 Lv1（教程 `initialBuildings`）。

### 1.2 专有名词着色（院长第 7 条）

- 旁白/台词/事件卡中出现**武将名、城市名、阵营名**时，分别用不同颜色区分（色值由 UI 规格定，建议：武将=金、城市=青、阵营=红）；
- 事件卡不做武将台词介入；事件说明直接写在卡内容里。

## 二、章节流程 v0.5（8 章 / 12 回合）

| 回合 | 章 | 触发 | 玩家操作 | 教学 | 表现通道 | 完成条件 |
|:--:|---|---|---|---|---|---|
| t1 | **0 开场 + 1 L2 深圳** | 游戏开始 | 看开场；进 L2；建农业区；派将 | L1 总览；L2 建造/农业；派将 | 旁白（开场）+ 对话字幕 | 建成农业区 + 派 1 将 |

| t3 | **3 KR 韩流 + 情报 + L2 军事准备** | 下一回合 | 建文化建筑；看情报；进上海 L2 征兵/造兵/编队 | 文化入侵/抵御；情报；征兵/造兵/编队 | **事件卡** + **情报气泡** + 对话字幕 + 冻结引导 | 文化建筑建成 + 部队编成 |

| t5 | **5 反法西斯提案** | 防守胜利 | 在**会议面板**发起提案/投票 | 会议/制裁/CB/同盟 | **会议面板** + **提示弹窗** | 提案通过 |
| t6 | **6 反攻台北（L3）+ 灭国必俘** | 提案通过 | 宣战/发兵；L3 攻城；处置面板三选一 | 攻城/占领/灭国必俘/处置 | 通用旁白（发兵/城破）+ **处置面板** | 占市政府 + 处置完成；失败读 `snap_taipei` |
| t7 | **7 科技终局** | 收复台北 | 科技面板选工程；下一回合结算 | 三线/终极工程/科技胜利 | **科技面板** + 旁白 + **提示弹窗** | 科技胜利结算 + "已完成教程"弹窗 |

> 共 8 章（0~7）。发兵、登陆、城破、投降等**不写教程专属台词/旁白**，走通用系统（清单见 [通用旁白模板清单](./通用旁白模板清单.md)）。

### 2.1 第 3 章 · L2 军事教程指标（院长第 4 条）

玩家在上海完成（教程逐步高亮，四步）：

| 步 | 操作 | 指标 |
|---|---|---|
| 1 | **征兵** | 普通步兵 **2,400**（0.3 批，兵营） |
| 2 | **造兵** | 突击步兵 **1 批（8,000）**、机动炮 **0.2 批（1,600）**（兵工厂） |
| 3 | **编队** | 编成 **3 队**：突击步兵队、普通步兵队、机动炮队 |
| 4 | **武将编入** | 魏嘉豪编入突击步兵队 |

- 完成后才进入 t4（上海防守）；数值为教程演出值，可实测微调。
- 若玩家已自行造兵/征兵，`sh-defense-prep` 不重复给兵。
- **资金/资源不足时用 CN 初始数据覆写辅助**（教程 Scenario 给 CN 国库/资源/建筑加成；见 §十二#9，不动 v22 基础值）。

## 三、台词/旁白/事件卡/提示弹窗（v0.5 全文）

> 文风：公文白话；不体现武将性格、不用隐喻；专有名词着色（§1.2）。
> 通道标注：**【旁白】**通用旁白 / **【对话】**底部字幕 / **【事件卡】**事件弹窗 / **【提示】**中央弹窗+确认 / **【情报】**情报气泡 / **【面板】**功能面板。

### 第 0 章 · 开场

- 【旁白】"剧变之后，大部分城市被毁，澳洲漂移到太平洋。"
- 【对话】陈梓键（深圳）："主席，深圳的初步情况已经整理完毕。请先查看主界面。"

### 第 1 章 · L2 深圳

- 【对话】陈梓键："深圳粮食不足，建议先建一座农业区。"
- 【对话】陈梓键（派将）："驻城武将可以派驻到建筑上。"

### 第 2 章 · 结算、AU 贸易、WLT 自立

- 【对话】马逸杰（AU）："AU 提议签订贸易协定。请确认。"
- 【面板】贸易协定：外交面板展示收入加成、关系变化、期限与"接受/拒绝"按钮（不写旁白念数值）。
- 【事件卡】"王乐添于台北自立，建立 WLT。"（武将/城市/阵营名着色）
- 【对话】陈梓键："台北的问题暂时只能搁置，先处理粮食。"

### 第 3 章 · KR 韩流 + 情报 + L2 军事准备

- 【事件卡】"KR 文化输出大幅提高，CN 认同度下降。"（阵营名着色）
- 【对话】陈梓键："文化建筑可以提升文化值，抵消 KR 的影响。"
- 【情报】情报站气泡："JP 与 WLT 结盟，预计进攻上海。"（武将/阵营/城市名着色）
- 【对话】魏嘉豪（上海）："报告：JP 舰队正在接近上海，台北方向也有部队调动，预计同时登陆。"
- 【对话】魏嘉豪："请进入上海城市内景，完成征兵和编队。"
- 【对话】陈梓键："军事区可以征兵和建造部队。"
- 教程引导：冻结操作 + 雾遮挡，依次高亮"进入上海 L2 → 征兵 → 造兵 → 编队"。

### 第 4 章 · L3 上海防守

- 【旁白】发兵/登陆：通用系统播报（教程不写）。
- 【对话】魏嘉豪（战中）："步兵在前，炮兵上城墙。注意兵种克制。"
- 【旁白】劫掠、占领读条、胜负：通用系统播报（教程不写）。

### 第 5 章 · 反法西斯提案

- 【对话】陈梓键："JP 和 WLT 联合进攻 CN。建议召开紧急会议，提出反法西斯提案。"
- 【面板】会议面板：提案、目标、投票、结果（不写投票台词）。
- 【提示】"全球紧急会议提案通过。CN、KR、AU 组成反法西斯同盟，获得 12 回合合法战争授权。"

### 第 6 章 · 反攻台北（L3）+ 灭国必俘

- 【对话】陈梓键："CN 已获得对 WLT 的战争授权。现在可以发兵台北。"
- 【旁白】发兵/登陆/攻城/城破："台北失守，WLT 投降。"（通用系统播报，非武将台词）
- 【旁白】"大统领王乐添被俘。请选择处置方式：收押、处决、释放。"
- 【面板】处置面板：收押 / 处决 / 释放（**不含劝降**）。
- **收押→监狱**：监狱为**市政区建筑**，教程默认自带；**劝降在监狱内进行**（升级与效果后续讨论，教程不演示）。

### 第 7 章 · 科技终局

- 【旁白】"科技树分三条线。终极工程三选一：上帝之杖、AGI 红皇后、人造太阳。率先建成任意一个，即可获得科技胜利。"
- 【面板】科技面板：三线节点全部显示已完成，只剩 3 个终极工程；玩家手动选择 1 个，面板显示研究回合数（教程=1 回合）。
- 下一回合结算 → **科技胜利结算**。
- 【提示】"已完成教程" + 按钮"返回主界面"。

## 四、科技终局（v0.5 口径）

> 院长第 20/21 条：不再用"独立 9 节点树 + 事件授予"；改为**教程关卡把主树节点全部置为已完成**，只留终极工程由玩家手动研究。

| 项 | 口径 |
|---|---|
| 科技树 | **主树 40 节点全部 `completed`**（科技面板显示三线全完成）；不改主树节点/成本 |
| 可选工程 | 3 个终极工程（上帝之杖/AGI 红皇后/人造太阳） |
| 玩家操作 | 科技面板手动选 1 个工程 → 显示研究回合数（**固定 1 回合，院长确认**）→ 确认研究 |
| 结算 | 下一回合结算时判定科技胜利（建成即判） |
| 结束 | 胜利结算后【提示】"已完成教程" + 按钮"返回主界面" |
| 数据落点 | `ScenarioDefinition.techTreeOverrides.completedNodes=all`；`ultimateProject.turnsOverride=1`（教程参数） |
| 面板展示 | **完整三线可拖动查看**；教程中**所有节点点亮**；UI 样式由黑机处理（院长第 7 条） |
