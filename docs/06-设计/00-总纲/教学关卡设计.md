# 教学关卡设计 v0.3（院长 12 条裁定落地）

> 状态：✅ **v0.3（2026-11-16 院长 12 条裁定已落地；待实机验收时长）**——v0.2 可执行版骨架保留，剧情改为**两场 L3**（JP+WLT 联合进攻上海 → 上海防守 → 反法西斯提案 → 反攻台北）。
> 定位：自由沙盒之前的**事件驱动教程关卡**（非 100~200 回合自由沙盘）；**CN 视角、默认 CN、无选阵营**。

## 〇、总长与节奏（院长裁定）

- **教程总长 12 回合**（具体实机时长待验收；关键节点 t1~t9，余 3 回合缓冲）。
- **两场 L3**：①上海防守（t4，JP+WLT 联军）；②反攻台北（t6，攻城+灭国）。
- **L3 实时战斗、无回合，一场战役在 1 个 L1 回合内打完**（院长确认）。
- 预计实机：内政/外交约 40~60 分钟 + 两场 L3 每场 15~25 分钟 = **2~3.5 小时**。
- 失败只可能发生在 L3：每场战前自动快照，失败读快照重打，次数不限（必须赢）。

## 七、科技终局（教程额外进度）

> 主树 40 节点（红 13/蓝 13/绿 14），12 回合不可能自然爬完。**教程关卡直接提供额外进度**（院长第 6 条），主树成本不动（冻结纪律）。

| 项 | 教程口径 |
|---|---|
| 教程树 | `tutorial-tech`：红（军备重整Ⅰ/精确制导Ⅱ/天基系统Ⅴ）、蓝（重工业化Ⅰ/半导体物理Ⅱ/深度学习Ⅳ）、绿（农业机械化Ⅰ/石油化工Ⅱ/可控核聚变Ⅵ）= **9 节点** |
| 授予 | `tutorial-tech-grant` 在 t7 **直接授予 9 节点**（面板标"剧本解锁"） |
| 入场券 | 本线 3 节点全研 + 他线各 ≥1（教程参数，不是主树"他线各≥4"） |
| 工程成本 | **财 500 + 生产 300**（深圳 ~150~200 生产/回 → 1~2 回合）；前置视为满足（深圳学院+高新技术园） |
| 胜利 | 建成即科技胜利（即时判定） |
