## 一、输入与候选集接口

| 输入 | 来源 | 用途 |
|---|---|---|
| 宣战/停战 U（既有） | 外交规范 §6.1/§6.3 | 开战/结束决策（本线不重定义） |
| 敌城清单（人口/产出/资源/守备/城防） | 城结算快照 | 战役目标选择 |
| `pr`（战力比，B1 口径：攻方组成战力 ÷ (守方+盟友)） | 既有 compositionPower | 可行性+门槛 |
| 战备（兵种构成/装备等级/油弹库存/兵源） | 军事结算（既有） | 动员判断 |
| 制裁/多线/和平期段位 | 感知步（骨架①） | 进攻时机 |
| `maxWars`/开战冷却/包围网/UN 和平锁 | 外交线既有 | 硬约束 |

**候选集**（战略层三拍各自出候选）：
```
宣战候选  = { T | 外交 §6.1 U_war 可算 ∧ pr(T) ≥ warFloor(1.0) ∧ 冷却/UN锁/包围网约束通过 }   ← pr<1.0 硬过滤（开题验收 6）
战役候选  = { c ∈ 敌城 | 战争进行中 }                  ← 替代"占最小城"（见 §二）
停战候选  = { T ∈ 交战方 | 外交 §6.3 U_peace 或战损触发 } ← 战损过大自动停战（见 §四）
```

## 二、战役目标选择（替换"占最小城"，sim full.js:922）

```
U_target(c) = 0.35 × 城价值(c) + 0.25 × 战略位置(c)
            − 0.25 × 守备强度(c) − 0.15 × 盟友保护(c) − 0.10 × 治理成本(c)
（权重进参数表，sim/Unity 同源）

城价值    = 归一(人口) ×0.5 + 归一(净财产出) ×0.3 + 资源稀缺度(c 资源 −本国缺口) ×0.2
战略位置  = 与本国已占城邻接 +0.5（推进轴）；海岸/航线节点 +0.3；首都标记 +0.2
守备强度  = 归一(守军+城防)（B1 城防公式口径）
盟友保护  = 目标城主盟友数 ×0.3（已有盟友实际参战另算）
治理成本  = 归一(人口) ×文化抗拒（assimilation 压力：异文化/大城占领后治理贵）
```

- **执行**：战中每回合结算拍，从战役候选 softmax 择 1 为 `warTarget`；`pr > captureTh`(1.3) 且目标存活 → 占领（既有结算公式不动：人口 ×0.8、rep−5、rel−40 等全保留）。
- **不锁结局（BUG-G011）**：`U_target` 高≠必占——占领仍走 `pr` 门槛；AI 不会为高价值城送人头（守备强度负项压 U）。
- 灭国口不变：一国最后一城被占=灭国（院长 11-13 第 3 条既有口径，不设死守特例）。

## 三、兵力动员（宣战前置拍）

- **触发**：宣战候选存在但 `pr(T) < readyTh`(1.25)（§6.1 可行性饱和线）→ 不宣战，转入动员状态：
  1. **建造联动**：`arsenalNeed` 加急（建造 AI 军事 role 权重战时 ×1.7 既有衔接）、机场/防空补位；
  2. **募兵联动**：`pickUnit` 兵种选择转战时序（既有），油/铁/煤缺口 → 外交 §6.7 资源采购候选权重上调；
  3. **挂起不遗忘**：动员状态每回合复查 `pr`，达标 → 宣战候选回主拍；超过 `mobilizeGiveUp`(30) 回合仍不达标 → 放弃该目标（清记忆，防永久挂起）。
- **战备口径**：兵种构成对目标克制（B1 counter 公式已验证）、装备等级差、油料≥预期战役消耗 ×1.5（轰炸/坦克耗油）。
- JP 军事优先（院长第 7 条既有）：`aggression>0.7` 人格动员线常开，和平期也保持战备。

## 四、进攻时机与战损停战

### 4.1 时机加成（乘 `U_war(T)` 或直接加当量，参数化）

| 时机 | 条件 | 加成 |
|---|---|---|
| 对方被制裁 | 目标存在生效制裁 | +`timingSanction`(0.20) |
| 对方多线 | 目标已卷入 ≥1 场战争 | +`timingMultifront`(0.30) |
| 和平后段 | 本国和平持续 ≥`peaceLong`(60) 回合 | +`timingPeaceLong`(0.15)（免"永久和平锁"，AGW 全程战备 tension） |
| 我方动员完成 | §三 达标 | 本来就是前置，无额外 |

- 时机项不破坏 §6.1 结构，作为独立加当量项（骨架④"人格修正"位）。

### 4.2 战损过大自动停战

- **战损追踪**：`warCasualty[f][T]` 累计（代理值阶段按既有 applyLoss 比例折算；L3 成型后接真实战损）。
- **触发**：累计战损兵源比 ≥`lossPeaceTh`(0.35) 或连续 `lossStreak`(5) 拍无进展（无占领且 pr 未升）→ 停战候选强制入池：
  - `U_peace`（外交 §6.3）加 `lossPenalty`(0.30) 当量 → 通常直接触发停战；
  - `caution` 高人格阈值 ×0.8（更早收手）。
- 停战后冷却/声誉走外交既有（peaceCooldown 10 回合、rep 代价）。

## 九、N 阵营裁剪

- 公式/候选集零阵营特判；`maxWars`、`warFloor` 与 N 无关。
- 无外交局（内战/单城）：宣战候选走同一骨架（同国城=目标集），UN 锁/盟友项自然缺席；包围网项缺席。
- 2/4/7/8 阵营 smoke 必过；战争与粮同算（防踩坑 #3）。
