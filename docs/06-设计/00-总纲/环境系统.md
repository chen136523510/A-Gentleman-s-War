# 环境系统 — 世界级（R42 院长拍板定稿）

> 状态：✅ R42 定稿（2026-10-28）。世界级概念（R29 院长立），本文件=机制细则；真实数据依据见 [00-调研/环境数值调研.md](../../00-调研/环境数值调研.md)。
> 分期口径（R42 院长立）：**分期不按工作量分，按系统整体最优开发分**——臭氧伤害与碳/海平面同批一期实现，避免两期接口割裂出 bug。
> 数据与内容分离（R42 院长定）：**账本=独立数据层**（存档 state.environment 世界级共享块 + balance.json 环境区），规则文档只管机制。

## 一、总览

- **定位**：跨国家公共层，各国共同制造、共同承受，单一国家无法独善其身（R29）。
- **五个账本**（R42 院长定，全部一期）：①碳排放（全球）②臭氧/CFC（全球）③酸雨（局部）④核污染（区域）⑤资源枯竭（矿城）。
- **生效方式**：阈值触发（慢变量 10 回合尺度累积，平时纯记账，过阈才生效）。
- **海平面**：由碳排放账驱动，**只升不降**（现实不可逆性），三级灾害阶梯。
- **全局失败结局**：海平面第三级触发（见 §五，胜利条件.md 同落）。
- 一期表现=L1 级"地球环境面板"（体检报告式，§七）；建筑/科技/外交接口 §六。

## 二、五个账本

### 2.1 碳排放账（全球账）→ 全球温度指数 → 海平面

- **记账**：全球共享累计账（不分阵营）。排放源=建筑固定值（碳/回合）：钢铁冶炼厂 +8、火电 +6、矿业 +2、垃圾焚烧 +2、核电/水电/光伏/风电 0。
- **温度指数**：`温度指数 = f(全球累计碳)`，0~100 抽象刻度（每点≈现实 +0.04°C；线性累积照搬 TCRE 真实关系）。面板显示"全球温度指数 X（≈+X.X°C）"。
- **海平面年速率**（mm/回合，只升不降）：温度 <30 → 3mm；30~60 → 4~8mm；60~80 → 8~12mm；>80 → 12~16mm。
- **三级海平面**（累计上升量）：
  - **第一级 +0.5m**：10 座沿海城（上海/深圳/香港/台北/仁川/东京/名古屋/长崎/悉尼/墨尔本）产出 −20%、宜居 −10；
  - **第二级 +1.0m**：上述沿海城**被淹没**→ 功能全停（不可生产/驻守/建造，人口归零，军队自动撤离），城市保留在地图=**海底遗迹**（⛏ 多状态 L1 大地图美工，黑机专栏，见需求池挂账）；
  - **第三级 +1.5m**：大陆级联崩塌（1999 断层世界观自洽）→ **全局失败结局**（§五）。

### 2.2 臭氧账（全球账，R42 院长定进一期）

- **记账**：CFC 累积（全球账）。产生源=工业区建筑（钢铁冶炼厂 +X）与火电（+Y）；环保科技/条约治理。
- **伤害（一期实现，院长定）**：臭氧恶化时 **AU 先受**（南半球臭氧洞现实）——AU 城市宜居每回合持续 −X；恶化到阈值后全球陆续受影响（数值期）。
- **面板倒计时**：按 CFC 累积与治理速度推算"臭氧空洞**修复剩余年数**"（治理中）或"**破坏剩余年数**"（无治理）——现实蒙特利尔 80 年修复周期压缩至游戏尺度（数值期校准）。
- **条约接口**：臭氧条约=会议议程（道义型或区域经济型，复用 R41 三案体系）；现实原型=蒙特利尔议定书（最成功全球环境协议，游戏内环保合作正面样本）。

### 2.3 酸雨账（局部账）

- **记账**：SO₂ 按重工业城记账（钢铁冶炼厂每回合 +X SO₂，本城局部账）。
- **伤害**：该城及邻城粮产出 −10%、建筑维护费 +20%（现实减产/腐蚀量级）。
- **治理**：环保线"脱硫"节点（SO₂ 排放 −50%）+ 替换清洁能源。

### 2.4 核污染账（区域账）

- **分层**：①短期冲击= R39 已定（核泄漏：本城宜居 −30/邻城 −10 三回合衰减；被攻破=严重事故立即触发）；②**长期残留（本账）**：事故/核打击落点生成"污染残留值"，**每 30 回合减半**（Cs-137 半衰期 30 年映射），期间持续压宜居/粮产。
- **治理**：**除染行动**（花财一次，残留值 −50%，福岛除染 30~76% 经验取中）。

### 2.5 资源枯竭账（矿城账）

- **记账**：矿业城市开采量累积（按城独立账）。
- **档位**：满 → 富 → 中 → 贫 → 尽，**每开采 50 回合降一档**（现实铀 200 年/4 档反推）；**AU 两城/达尔文 ×1.2 慢枯**（现实澳储量第一）。
- **伤害**：贫档起矿场产能减半；尽档不可开采（矿场建筑保留，可拆除）。

## 三、治理对策（R42 院长定：A+B 双向联动）

- **建筑替换（B 案）**：火电可替换为光伏/风电（零碳，产能略降）；垃圾发电站（§六，每城限 1，垃圾燃料）——替换=操作性治理。
- **科技反哺（A 案双向）**：民生与环保线解锁新建筑/燃料（垃圾发电、脱硫、远期核聚变二期彩蛋）——**科技发展到新内容（垃圾发电/新能源）能反哺政策**：解锁同时为对应政策卡入池提供前置（政策卡目录专题时填卡面）。
- **联合国治理（公地困境部分靠联合国，院长定）**：碳配额法案（§四）+ 臭氧条约——全球账的负外部性由会议体系兜底；本地账（酸雨/核污染/枯竭）靠本国治理。

## 四、碳排放配额法案数值接口（R41 议程落 R42 数值）

- **配额由发起国决定**（院长定）：发起国提案时写配额系数（如全国排放 ×0.8 为上限）与额度分配，参与国见数值投票（区域经济型=全投同意才通过，R41）。
- **以国家为单位提供额度（可交易，院长定）**：
  - 签国每回合排放 ≤ 配额；**超排**：每回合扣财 X + 声誉减值；连续超排 → 其他签署国关系递减。
  - **购买额度=免超排惩罚与声誉减值，但不额外加分**（院长定）。
  - 交易渠道：**外交菜单**——对签国发起"购买碳额度"，价格=基础价（数值期，建议 10 财/单位碳），每回合每国限购 N 单位；超排国回合结算时自动提示可购。
  - **AI 同规则**：AI 国超排且有钱时自动购买额度（R42 院长定）。
- 未签国不受配额限制，但享"搭便车"道义压力（可被发起道义型谴责议程，R41 联动）。
- 退出=撕毁法案机制（降国际声誉，R40 已定）。

## 五、全局失败结局（R42 院长定，新立）

- **触发**：海平面第三级（+1.5m）→ 所有大陆陷落 → **人类阵营失败**。
- **语义**：全局失败结局=游戏结束（所有阵营共同失败，无胜者）。触发后进结局画面，可读档回溯（详见 [胜利条件.md](./胜利条件.md) 失败判定节）。
- 面板上第三级明确标红警示"人类失败线"（负反馈纪律：明牌，不突袭）。

## 六、建筑与科技接口

- **垃圾发电站**（能源产业新建筑，R42 院长定）：燃烧垃圾发电=**火电家族**；垃圾燃料来自城市自身（**一城垃圾产量只够供给 1 座**，故每城限建 1）；低碳（+2 碳/回合，远低于火电 +6）+ 消化城市垃圾（降低宜居压力）；**民生与环保线节点解锁**。产能/成本参数数值期。
- **民生与环保线节点更新**（科技树.md 同步）：脱硫（酸雨 −50%）、垃圾发电（解锁建筑）、光伏风电强化、污染治理（重工业宜居惩罚减免，R23 原有）、核能和平利用（原有）。
- CN 特色：北京 民生与环保线 ×0.85（R23 原有，与 §七 CN AI 环保倾向呼应）。

## 七、地球环境面板（L1 级，体检报告式，R42 院长设计）

- **位置**：新面板（底部居中，R40 已定位）内开"环境页"；主 HUD 六项不动。
- **内容**（全部数据来自独立账本层，只读展示）：
  - 全球温度指数（≈+X.X°C）；
  - **年碳排放 / 总碳排放**；
  - **海平面：去年上升 Xmm / 总上升 X.XXm** + 三级水位标尺（0.5m / 1.0m / 灭世线 1.5m，样式见 §7.1）；
  - **臭氧：修复剩余年数 / 破坏剩余年数**；
  - 酸雨重工业城列表、核污染残留区列表（残留值+衰减进度）、矿脉档位（各矿城满/富/中/贫/尽）；
  - 配额法案状态（签国配额/当前排放/可用额度）。

### 7.1 紧迫感设计（R42b 院长裁决：数值无感，感知靠设计；**禁用烂大街的红色预警**）

> 背景：第三级才 +1.5m，数字本身毫无末日感——但语义是大陆陷落。紧迫感必须由 UI 样式与演出承担，且不用"红字+红条"这类俗套。

- **面板样式=水文监测站仪表盘**（呼应 1999 技术退化世界观：旧式水电站监控室质感，指针/刻度/水纹，整体仪器美学而非游戏进度条）：
  - **海平面不用进度条，用潮汐水位标尺**：0 / 0.5 / 1.0 / 1.5 四刻，水面（动态水纹）逐年上涨逼近刻度——危险感来自**水面逼近刻度的物理直觉**，不靠颜色；
  - 第三级刻度命名"**灭世线**"（不加红、不写"危险"——命名本身即压迫）；
  - **倒计时叙事**："按当前速率，距大陆陷落约 X 年"（像臭氧修复年数一样的时间叙事，比"还差 0.4m"有重量）；
  - 温度指数=**温度计样式**（水银柱），比进度条有实体感。
- **地标参照剪影**（水位可视化的关键）：面板海平面区画**上海外滩剪影**，水位逐年上淹地标——一级淹到塔基、二级漫过裙楼、三级灭顶——用玩家认识的地标做参照物，一米半的重量感直接可见。
- **地图层联动（⛏ 黑机专栏：多状态 L1 大地图美工）**：沿海城市贴图边缘出现**海水侵蚀/堤坝**视觉态（一级=堤防告急、二级=海水漫入），大地图本身就是最大画布——挂账补记。
- **事件层预警（复用 R39 首长汇报机制）**：一级/二级触发时各沿海城首长汇报，**叙事化不喊话**（如"上海首长报：外滩堤防告急，潮位异常"）——内容制造紧迫，不靠弹红窗。
- **负反馈纪律平衡**：紧迫感靠呈现不靠惩罚——面板永远可查、阈值明牌，玩家有治理窗口；不搞"突然红屏死亡"。

## 八、AI 行为（R42 院长定）

- **同规则承受 + 简单对策**（Q7-B）：AI 同样吃全部阈值惩罚（含海平面三级失败——AI 也怕，故 AI 有治理动机）；宜居/产出跌破阈值时 AI 执行治理（替换清洁能源/点环保线节点），优先级低于军事/经济主线。
- **CN AI 额外注意环境治理**（院长定）：环保优先级高于其他 AI——治理触发阈值更早、环保线节点权重更高、更倾向签署碳配额/臭氧条约。
- AI 购买碳额度（§四）。
