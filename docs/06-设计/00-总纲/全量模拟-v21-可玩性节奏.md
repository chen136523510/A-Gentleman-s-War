# 全量模拟 v21：可玩性节奏盘（环境事件 / 需求 AI / 战争灭国）

> 院长 2026-11-11 口径：环境后置+分级事件；AI 不能硬编码；绿能倾向按己方沿海城数量；观察每类建筑在 AI 手中的表现；200 极限胜利局；战争可灭国/统治胜利。
> 脚本：`tmp/sim-full-v21.js`；数据：`tmp/sim-full-v21-{BASE,LONG}-{profile}-seedN.txt`。
> 结论先行：**环境节奏基本达标**（t100 全球变暖预警、t154 一级、t223~242 二级、300 内不到三级）；**战争灭国/统治胜利已跑通**（mixed 5/10 种子、military 5/5 种子达成，CN 滚雪球到 13 城）；**但科技胜利 200/300 回合均未出现**，建筑类型只用 46/150，AI 节奏仍缺“科技/文化/住宅”的长期拉力。

## 一、v21 按院长口径做了什么

### 1.1 环境：后置灭世 + 分级事件

| 项 | v21 实现 |
|---|---|
| 预警事件 | 海平面到 **0.3m（一级前）** 触发「全球变暖」：全城宜居 **−3**，只触发一次；t100 触发 |
| 一级事件 | 海平面 **0.5m**：沿海城全产出 **−20%**、宜居 **−10**；t154 触发 |
| 二级事件 | 海平面 **1.0m**：沿海城淹没、人口归零；t223~242 触发 |
| 三级事件 | 海平面 **1.5m**：大陆崩塌、全局失败；**300 回合内未触发**（后置成功） |
| 数值放宽 | 碳排 ×0.7、污染 ×0.7；海平面速率 3/6/10/14mm（未再放大） |
| AI 反应 | 环境压力进入 `green` 需求；沿海城占比越高，绿能倾向越强 |

### 1.2 AI：从硬编码候选改成需求驱动

- 每城每回合计算需求：粮食、现金、建造积压、电力、住房、治安、医疗、科技、文化、军事、绿能、商业。
- 每个建筑按 `out`/tags/category 映射到角色，按“需求 × 倾向权重 × 边际递减”打分，**不再写死“缺商场只造商场”**。
- 倾向权重：commercial/industrial/tech/military/green 各自放大对应需求；mixed 按阵营分配。
- 生存护栏：粮食/电力紧急优先；维护预算 = 净收入 ×75% + 国库 5%；同类型边际递减，避免单类铺满。
- 建筑使用审计：记录每类建筑的实际数量、未建类型。

### 1.3 战争：灭国 + 滚雪球 + 统治胜利

- 动态宣战（每 8 回合最多一场）：强弱差 + 倾向决定；military 倾向最激进。
- 战胜国战后**占领一城**（人口/建筑随城转移、人口 ×0.8、忠诚 40），败国失去该城。
- 败国城市归零 → 灭国；只剩一个可战阵营 → **统治胜利**。
- 终局只剩两国时，强者高概率发动统一战争。

## 六、建筑使用审计

以 mixed seed1 为例：**实际使用 46/150 类型**（150 = 126 buildings.json + 24 旧 CAT legacy；含 93 draft）。

| 类别 | 未使用情况 | 原因判断 |
|---|---|---|
| 旧 CAT legacy/重复 | 13 个（school/research/police/internet/nuclear/... 与新版 ID 重名或重复） | **数据清理问题**：同一功能两套 ID，AI 只用其中一套 |
| 93 条 draft | 84 条未建 | **设计未定稿**：无输出/无 tags/无需求场景；部分有 tags 但 utility 低 |
| 非 draft 未建 | 21 条（农业 10、住宅 3、工业 2、商业 1、科学 1、娱乐 1、市政 1、军事 1、防御 1） | **需求场景未出现或随机**：粮食过剩→不再铺土豆/大豆/养猪；人口未触顶→不铺住宅；科技需求弱→不铺学院 |
| 无输出字段 | 30 条 | **设计漏洞**：建筑卡没有产出/角色，AI 无理由建 |

**结论**：
- 不是“所有建筑都必须被用上”，但当前 **46/150 偏低**；
- 主要噪声是 **13 个 legacy 重复 + 30 个无输出 draft**；
- 真实可解释的未建（粮食过剩、人口未触顶、科技需求弱、战争没打到）是正常的场景缺失，应逐条复盘，而不是强行让 AI 铺满。

## 七、本轮结论与下一步

### 已达成
- 环境后置 + 全球变暖/一级/二级/三级事件 ✅（t100/t154/t223~242/300 后）。
- 需求驱动 AI（非硬编码）✅；沿海城占比影响绿能倾向 ✅。
- 战争灭国/滚雪球/统治胜利 ✅；200 极限局 5/10 种子、300 正常局 10/10 种子。
- 建筑使用审计 ✅（46/150；已定位 legacy/draft/无输出三类噪声）。

### 待调
1. **科技胜利缺失**：AI 科技节点 10~19/38，200/300 均无科技胜利。需要给科技/学院/工程加“终局拉力”（阶段目标、科技胜利倒计时），否则 tech 倾向没有意义。
2. **统治胜利单一 CN**：CN 初始 6 城/10 将，战争滚雪球后无对手；需要给弱国防御/外交/地形优势，或调整战争占领节奏（一次战役只割一城、不能连续滚）。
3. **建筑目录清理**：删/合并 13 个 legacy 重复 ID；给 30 个无输出 draft 补角色或标为“内容未定稿”，否则审计永远有噪声。
4. **需求缺口**：粮食过剩后农业类型不再使用（正常），但住宅/文化/医疗的触发阈值偏低，导致这些线在 AI 手里不明显；需要按“玩家节奏”提高中期需求（人口容量、文化入侵、宜居压力）。
5. **环境三级**：300 回合内未到 1.5m；如果希望 300 正常局看到三级，需要略提高海平面速率或降低 SEA3；当前“后置”已达成，是否再压到 300 由院长定。
