## 四、⚠️ 首要发现：复苏盘 200 回合 0 战争

- `[v24 战争] 宣战 0 次`（5 seed 一致）。100 回合 UN 成立后全球停战和平锁，进一步压制战争。
- **影响**：口红/报复性消费（战争条件卡）永不触发；军事胜利/占领/武将战损链路未走通；「诸侯争霸军阀混战」叙事与模拟现实脱节。
- **可能根因**（v27 盘观察，未裁）：①八足鼎立国力均衡→战力比难超 captureTh 1.3，AI 评估不划算；②WarAI 宣战阈值在复苏人格参数下偏保守；③和平锁 UN 成立太早（t100）。
- **待院长裁**：复苏 AI 是否需要进攻性参数上调（如 F5 高 aggression 0.85 应有扩张行为）？或接受"和平默认、战争罕见"的玩法基调？

## 六、简化与挂账（报告注明）

1. **空城占领不做**（11-27 院长裁：复苏无空城）；原 v27 空城建模任务删除。
2. S4「商业财收低」判定=城就业过饱和连击代理（sim 无独立商业财收口径）。
3. P1 起义的"守军 50% 转民兵"=全军 −10% 近似（sim 无城级驻军）。
4. 三选一（接纳/遣返/驱离）AI 化：属性高 60% 接纳 / 25% 遣返 / 其余驱离——精确决策随 L3/UI。
5. 派驻乘区同类连乘封顶 1.5（防爆）；主属性映射=军事→统率/商业·市政→政治/学院→智力/文化→魅力/警察→武力。
6. H1/H2 教学专属历史卡未进复苏盘（内容库 §四：复苏历史卡暂空）。
7. **v22~v24 历史盘财政结论引用注意**（俸禄口径旧错）延续；v25 起已修正。
