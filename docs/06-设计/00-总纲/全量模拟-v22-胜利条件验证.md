# 全量模拟 v22 · 胜利条件验证（白机，2026-11-13）

> 脚本：[sim/v22/full.js](../../../sim/v22/full.js)（`node sim/v22/full.js 200 <seed>`）
> 依据：[胜利条件.md](胜利条件.md)（**院长 11-13 第 4 条确认**：军事=统一全球、文化=文化入侵全球并维持、科技=终极工程、经济无胜利）+ [文化输出算法.md](文化输出算法.md) v1 份额收敛式（2026-11-05 院长定稿）
> 口径：模拟器只验证趋势；文化失所/认同度为简化接入，上线仍以 L3/正式系统为准。

## 一、本轮接入（三胜利判定 + 文化系统）

| 件 | 实现（模拟器） |
|---|---|
| **军事胜利** | 其他阵营全部灭国（`alive=1`）→ 统一全球；达尔文 NONE 不计入 |
| **文化胜利** | 文化输出算法 v1（份额收敛式）全链接入：文化存量累计 → N×N 压力矩阵 → 认同度收敛（r=0.05）→ 完全入侵（≥60% 持续 5 回，<50% 解除）→ **全阵营存活 + 对所有其他阵营 ≥60% 维持 10 回合** |
| **科技胜利** | 终极工程 60 回合（已有，A1.3 收束） |
| **经济胜利** | 无（按院长裁定不设） |
| **统一胜者** | `winner={id,type,t}` 先到先得；主输出改为 `胜利=CN（tech t328）` |

**文化输出简化口径**（文档 v0 系数表 → 模拟器）：

| 系数 | 取值 |
|---|---|
| 压力 | `P[A→B]=√Culture_A × 距离 × 联系 × 情报 × 战争 × 势差` |
| 距离 | 邻接 1.0 / 远洋 0.6；**AU 联系门槛 = 双方科技 ≥10**（未解锁则整列 0，澳洲隔绝） |
| 联系 | 同盟 1.2 / 其他 1.0（航线系统未接） |
| 情报 | 1.0（情报系统未接，报告标注） |
| 战争 | 交战 0 / 停战 0.3 / 和平 1.0 |
| 势差 | `clamp((Ca/Cb)^0.5,1.0,2.0)`，攻击方需 ≥1 座文化建筑（gapGate） |
| 自压/抵抗 | `√C_B × (1+resist)`；resist=pub×0.03+tour×0.05+ent×0.02，封顶 +50% |
| 文化失所 | 本国认同<40% 且最大外国<60% → 征兵 ×0.85 / 战争能力 ×0.9；≥45% 解除 |
| 文化初值 | 城市基础文化值（文化区 v1.0 压低档 5/6/3…）×8 |

| seed | 存活 | CN 国库 | 科技 | CN 文化 | KR 本国 | 完全入侵 | 失所 |

## 五、可达性分析（关键观察）

1. **军事胜利在现机制下不可达**：关科技跑 800 回仍 3/4 僵持（JP t206 灭后 CN/KR/AU 均势）；激进战争盘（warStart 20/冷却 5）t33 AU 灭后仍 3/4 到 400 回。原因是战争节奏：每场战争 2 回合判定、只占 1 城、战后停战、宣战冷却 30——**与"战争是否延长"待裁直接相关**。
2. **文化胜利自然盘不可达（设计预期 + AI 缺口）**：①200 回只能 1 个完全入侵（文档 v12c 预期）；②JP 文化存量 ~30k + 抵抗 50%，把 CN→JP 份额压到 31~41%，到不了 60%；③AU 前期隔绝、文化存量低；④文化胜利要求**全阵营存活**，而 AI 战争会灭国（两条路线互斥）。**AI 无"文化输出经营"行为**（开航线/派情报/文化 push 未接），故当前文化胜利只能靠构造盘验证。
3. **文化失所影响战争链**：失所国征兵 ×0.85/战力 ×0.9 改变了 5 seed 战争结果——CN 兵 17k~28k（会议版 15k~17k）、国库 1.7~14 万（会议版 7~89 万）。属新基线连锁，报告记录；是否回调待观察。
4. **文化存量尺度**：城市基础文化 ×8 后 CN 开局 208 / JP 104 / KR 48 / AU 80，与文档 v12c（34.4k 旧尺度）不同；份额模型只看相对关系，绝对值不影响判定结构。

## 六、待办 / 挂账

1. **军事胜利可达性** → 依赖院长裁"战争是否延长（多轮轰炸/连续吞并）"，裁定后重跑统一盘。
2. **文化胜利可达性** → 需 AI 文化行为层（航线/情报/文化 push）+ 联合国/盟主中间节点（本作原链），当前未接。
3. 文化失所→忠诚流水 −0.5/回：模拟器无忠诚系统，未接（征兵/战力两项已接）。
4. 情报系数、航线联系系数、联合国大会/盟主选举：模拟器简化或未接，报告标注。

## 七、结论

- 三胜利条件（统一/科技/文化）判定全部接入且分支验证通过；经济无胜利按裁定不设。
- 200 回节奏：全活 5/5、无胜者（科技 25~27/40），符合"200 回合是节奏锚点非硬上限"。
- 军事/文化的**自然达成**受战争节奏与 AI 文化行为限制——机制已就位，可达性待后续裁定/行为层。
