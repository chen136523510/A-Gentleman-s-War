# 全量模拟 v19 诊断：建筑密度、商业占比与环境

> 起因（院长 2026-11-11）：① 怎么几乎都是商业建筑、200t 建筑太少；② 做那么多建筑内容没意义；③ 确定是全量盘吗、环境没提；④ 再跑数据。
> 数据：`tmp/sim-full-v19-PEACE-seed42.txt`（v19 基准）、`tmp/sim-full-v19-PEACE-seed42-green.txt`（绿能路线）；对照 `tmp/sim-full-v18-PEACE-seed42.txt`（v18a）。
> 结论先行：**v18a 是“经济全量盘”，不是“建筑内容全量盘”**；建筑少/商业多主要是模拟器的四个建模问题，不是建筑内容本身少；v19 修掉这些问题后，建筑密度上来了，但环境会崩——高密度必须配绿能，而绿能又会挤压商业。三者需要设计取舍。

## 一、为什么 v18a 建筑少、商业多

| 原因 | 机制 | 证据 |
|---|---|---|
| **1. 地价指数爆炸** | `landPrice = 10 × 1.5^floor(landUsed/5) × (1+pop/5万)`；L2 农田占地 16 格、公寓 4 格，20 座后地价上千 | 一刀切掉地价（`AGW_LAND=0`）后，CN 建筑 110→113、KR 48→69 |
| **2. 每城只有 1 个建造位** | 模拟器 `city.active` 单槽；设计是 `buildQueueSlots=2` | 建造提速 2×（`AGW_FASTBUILD=1`）后，CN 110→117、JP 66→71 |
| **3. 强制单候选阻塞** | 缺商场/港口时 `candidates` 只返回 `['mall']`；买不起就整城整回合不建造 | 首尔 v19 前只有 11 座建筑、无商场/银行/写字楼；改成“优先但不阻塞”后恢复 |
| **4. 目录与 AI 偏好** | 模拟器 CAT 只有 53 个旧类型；当前 `buildings.json` 126 条中 **93 条是 draft 不参与结算**；AI 商业评分高、工业受矿/装备条件限制 | v18a CN 47/110 商（43%）、JP 15/66 商（23%）；v19 加多样性约束后 CN 商占比降到 33% |

> 注：`buildings.json` 非 draft 只有 33 条，模拟器旧 CAT 53 条含大量 draft/legacy；两边口径本来就没对齐。这是“内容没意义”的根因之一。

## 二、v19 调整内容

1. **地价线性化**：`10 × (1 + landUsed/25) × (1 + pop/5万)`，取消 1.5 指数。
2. **建造提速 1.7×**：近似 2 个建造队列（设计 `buildQueueSlots=2`）。
3. **强制项不阻塞**：港口/商场/银行/写字楼从 `return ['x']` 改为优先候选，买不起仍可排其他建筑。
4. **多样性约束**：商业占比 ≥42% 时不再新增普通商业；工业/住宅/学院占比低时加权。
5. **补入 10 个当前非 draft 建筑**：学院、商业中心、高新技术园、重工业、兵营、烟草/棉花/油料/甘蔗/茶叶农田。
6. **环境标定**：温度 `碳/500`（对齐设计表；原模拟器用 `/2000`）；快照输出环境时间线。

### 3.2 环境时间线（v19）

| 回合 | 基准盘 碳/温度/海平面 | 绿能盘 碳/温度/海平面 |
|---|---|---|
| t50 | 0 / 0.0 / +0.105m | 0 / 0.0 / +0.105m |
| t100 | 7,263 / 14.5 / +0.300m | 4,487 / 9.0 / +0.300m |
| t150 | 20,972 / 41.9 / +0.510m | 8,654 / 17.3 / +0.450m |
| t200 | 37,714 / 75.4 / +0.902m | 12,847 / 25.7 / +0.600m |
| t220 | 41,529 / 83.1 / **+1.158m** | 14,527 / 29.1 / +0.660m |

- **t150 左右过一级（0.5m）**：沿海城产出 −20%、宜居 −10（模拟器目前只实现了粮食 ×0.8，未实现全产出 −20%，这是第二个环境口径缺口）。
- **t200~220 过二级（1.0m）**：基准盘所有沿海城人口归零（设计如此：二级=淹没、功能全停）；绿能盘停在 0.66m，安全。

## 四、建筑内容覆盖审计

| 项 | 数量 | 说明 |
|---|---:|---|
| `buildings.json` 总条目 | 126 | 全量设计内容 |
| 非 draft（可结算） | 33 | 模拟器/Unity 实际可用 |
| draft（不参与结算） | 93 | 商业/文化/娱乐/军事大量未定稿；这是“内容没意义”的主因 |
| 模拟器 CAT | 53 | 旧 v17a 目录，含 draft/legacy，和当前数据不一致 |
| v19 新增非 draft 类型 | 10 | 学院/商业中心/高新园/重工业/兵营/5 种经济作物 |
| v19 实际被 AI 建造的新类型 | 少 | 学院 1、兵营 5、太阳能 58、水电 10；**商业中心 0、高新园 0、重工业 0、经济作物 0、污水/环保园 0** |

**结论**：即使补了类型，AI 在“电力优先/现金有限”下仍不会铺开所有内容。要验证全部建筑，需要单独的**内容覆盖盘**（按类型强制建造/检查产出/维护/升级），不能指望经济平衡盘自然覆盖。

## 五、调整建议

| 优先级 | 动作 | 理由 |
|---|---|---|
| P0 | **先把环境口径统一**：温度 K=500；一级 +0.5m 补全“全产出 −20%、宜居 −10”；二级淹没逻辑保留 | 现在 v18a/v19 环境数值不一致，不能用于验收 |
| P0 | **建筑密度三件套保留**：地价线性、2 建造位（真实现，不是 1.7× 近似）、强制候选不阻塞 | v19 证明这三项能把总建筑 301→372（基准）/399（绿能） |
| P1 | **绿能路线**：grn4 抢跑 + 太阳能；但需解决“绿能挤压商业”——建议太阳能/风电低劳动力、低占地（v19 已试 labor 200/land 1，商业仍被挤），或给绿能建筑额外财政/就业补偿 | 高密度盘不绿能会在 t200 前后二级淹没 |
| P1 | **商业:税目标分档**：高密度+绿能盘下 CN/JP/KR/AU 掉到 0.25~1.34；若坚持 2.5~3.5，需要更多商业位或降低税基 | 三者（密度/商业/环境）目前不可兼得 |
| P2 | **内容覆盖盘**：按 33 个非 draft 类型逐类强制建造，输出/维护/升级/电力/污染逐项校验 | 这才是“建筑内容全量”的正确验证方式 |
| P2 | **draft 建筑分批定稿**：93 条 draft 是内容主体，未定稿就不该进结算盘 | 否则永远只有 33 类在跑 |

## 六、结论

1. **不是建筑内容少，是模拟器只用了 33 条非 draft + 旧 CAT 53 条**；93 条 draft 不参与结算。v18a 的“全量”应改称“经济全量”，不是“内容全量”。
2. **建筑少/商业多**的主因是地价指数、单建造位、强制单候选阻塞、AI 商业偏好；v19 修掉后总建筑 301→372/399，CN 商业占比 43%→33%。
3. **环境不是没跑，是没报**：v18a 只打了终局一行，且温度用 K=2000；v19 输出时间线后，基准盘 t220 海平面 1.158m、沿海城全灭，绿能盘 0.66m 存活。
4. **当前模型存在三方权衡**：密度↑ + 商业↑ → 环境崩；密度↑ + 环境稳 → 商业占比/商业:税降。下一步需要院长定优先级，或加“绿能不占商业位/不挤就业”的机制。
