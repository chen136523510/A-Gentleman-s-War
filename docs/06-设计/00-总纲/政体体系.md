## 一、三个大方向问题的结论（先答）

### 1.1 政体之间是否存在绝对高低上下？

**结论：不存在绝对高低，存在"时代相性/玩法相性"的高低。**

| 判断 | 说明 |
|---|---|
| **不做等级制** | 政体不是"T1→T2→T3"的数值升级；后期政体不全面碾压前期政体 |
| **同家族后期形态=换维** | 如君主制→立宪君主制：从"君主主权"换成"传统合法性+议会协商"，稳定性/文化更强，但君主权力/动员速度下降——**有得有失** |
| **跨家族无高低** | 民主 vs 军政府：前者经济/文化/外交强、军事弱；后者军事/秩序强、经济/外交弱；**是取舍，不是强弱** |
| **情境强弱存在** | 军国主义战时强、和平期弱；神权稳定强、科技弱——这是**相性**，不是绝对高低 |
| **防碾压三机制** | ①每个政体有独特特效/专属卡，不是数值升级；②变更成本高（1k 财+清空卡槽+冷却）；③可选"传统合法性"：政体使用越久，忠诚/稳定加成越高（守旧成为可行策略） |

> 历史依据：波利比乌斯"政体循环"与"混合政体"说明没有永恒最优；韦伯三合法性也非进化排名。游戏化后=**结构取舍**，不是科技树式升级。

### 1.2 是否需要将政体和时代挂钩？

**结论：弱挂钩（时代标签+解锁池），不搞强制演进制。**

| 方案 | 做法 | 评价 |
|---|---|---|
| A 强挂钩 | 政体分时代，进入新时代必须换政体/旧政体失效 | ❌ 违反 R30"选择制，非演进制"；玩家被逼换体 |
| **B 弱挂钩（推荐）** | 政体有 `era` 标签与解锁条件；**时代决定可选池**；旧政体跨时代仍可用；不强制更换 | ✅ 有时代感，保留选择自由 |
| C 不挂钩 | 所有政体开局全开 | ❌ 丧失时代感/剧本差异 |

**弱挂钩落地**：
- 主剧本（现代）：九政体开局全可选（`unlock.type=start`）；变更受 1k+清空+冷却。
- 复苏副本（远古）：只开远古政体池；随科技/事件解锁古代政体。
- 逐鹿（古代/战国）：古代政体池（城邦共和/古典共和/君主制/帝国/寡头）。
- 二期"文明演进"剧本：全时代池，按时代解锁（可选规则，不是主剧本默认）。
- 旧政体跨时代：可用；专属卡池偏旧、相性下降；**可选"传统合法性"**（使用回合数→忠诚/稳定），使"守旧"有独立价值。
- **不做**"时代到了强制换政体"，也**不做**"旧政体失效"。

### 1.3 目前兵种和建筑是否跟政体挂钩？

**结论：目前不挂钩；建议保持"不硬挂钩"。**

- **现状核查**：文档层无 `governmentReq` 类字段；`sim/v22/full.js` 无 `government` 变量。兵种靠科技/资源/兵工厂；建筑靠科技/资源/地块。
- **不建议全面挂钩**：每个政体一套兵种/建筑=内容爆炸+平衡困难+换政体后建筑失效体验差。
- **推荐表达方式**：政体通过**政策卡 + 政体特效**间接影响——征募费、兵工厂产出、建造工期、维护费、征募上限等。
- **二期可选**：少量"政体标志性建筑/兵种"（如神权神庙、军政府军管所、社会主义国企），默认不做全套。
- **接口预留**：`BuildingDefinition.governmentReq?` / `UnitDefinition.governmentReq?` 默认空，未来需要时再加数据。

## 二、政体谱系总表（家族树）

| 家族 | 谱系（早→晚） | 核心逻辑 |
|---|---|---|
| **君主系** | 酋邦 → 君主制 → 等级君主制 → 绝对君主制 → 立宪君主制 | 血缘/传统→主权集中→宪政分权 |
| **共和系** | 城邦共和 → 古典共和 → 商业共和国 → 共和制 → 民主政府 → 联邦制 | 公民参与→代议→分权 |
| **神权系** | 神权城邦 → 神权政治 → 神权共和/传统 | 祭司→教权→教士监护+选举 |
| **军事系** | 军事民主 → 军政府 → 军国主义 | 战士大会→军人集团→总体战 |
| **集权/官僚系** | 帝国 → 威权政府 → 技术官僚 → 算法治理 | 皇权官僚→强人→专家→AI |
| **社会主义系** | 社会主义 → 后稀缺公社 | 计划/公有→AI 生产/按需 |
| **未来系** | 企业国家 / 网络国家 / 生态政体 / 星际联邦 | 主权碎片化/生态化/星际化 |

> 谱系只表达"历史形态演变"，**不表达强弱**；同家族后段不是前段的升级版，而是结构换维。

## 三、全政体讲解（按时代）

> 计数说明：本节按时代列出 **32 个条目**；其中"立宪君主制"与现九政体"君主立宪"、"军政府"与现九政体"军政府"是**同一政体跨时代表述**，**唯一政体 30 个**。历史层（远古~近代）为副本/时代演进备用，现代 9 个为主剧本现行政体池。

### 3.1 远古（4）

**部落制（Tribal）**
- 意义：血缘+互惠的最小政治单位；没有官僚、没有常备军，但凝聚力强、成本极低。游戏里是"单城起步"的原点。
- 机制/特效：建造/维护成本低；人口增长/忠诚稳定；军事=全民动员但无职业军。
- 正负：+低成本/高凝聚；−规模上限/无官僚/科技慢。
- 解锁：远古剧本开局。

**酋邦（Chiefdom）**
- 意义：世袭首领+再分配，是从部落到国家的第一步；出现亲兵与祭祀，等级开始固化。
- 机制/特效：资源再分配（粮/资源池效率）；亲兵（少量职业军）；首领权威（忠诚）。
- 正负：+动员/秩序；−寡头/个人化/创新弱。
- 解锁：远古剧本 + 农业/聚落科技。

**军事民主（Military Democracy）**
- 意义：战士大会+战时首领，全民皆兵但决策靠武力共识；早期扩张型政体。
- 机制/特效：征募费低、战时动员快、占领军管强；和平期忠诚/秩序下降。
- 正负：+战争动员；−和平期治理/经济。
- 解锁：远古剧本 + 军事科技/战争事件。

**神权城邦（Theocratic City-State）**
- 意义：祭司统治，神庙=粮仓+金库+学校；文化/忠诚极强，但世俗化阻力大。
- 机制/特效：文化自压/忠诚/稳定；神庙建筑加成；科技/世俗化惩罚。
- 正负：+文化/忠诚；−科技/外交摩擦。
- 解锁：远古剧本 + 祭祀/宗教科技。

### 3.2 古代（5）

**城邦共和（City-State Republic）**
- 意义：公民大会+商贸城邦（雅典/威尼斯前身）；经济/外交/文化强，规模小。
- 机制/特效：商业/贸易/外交关系流；公民兵；城市自治。
- 正负：+经济/外交/文化；−规模/陆军弱/排外。
- 解锁：古代剧本 + 法典/城邦事件。

**古典共和（Classical Republic）**
- 意义：元老院+执政官+公民大会的混合政体（罗马）；制衡与稳定，但决策慢、寡头倾向。
- 机制/特效：稳定/忠诚/法治；同盟信任；决策延迟（重大变更成本高）。
- 正负：+稳定/制衡/外交；−决策慢/寡头。
- 解锁：古代剧本 + 法典+贵族妥协事件。

**君主制（Monarchy）**
- 意义：王权+贵族，传统合法性的典型；稳定、文化强，但改革/动员受贵族掣肘。
- 机制/特效：传统合法性（忠诚/稳定）；王朝外交（联姻）；贵族阻力（改革成本）。
- 正负：+稳定/文化；−改革慢/军事依赖贵族。
- 解锁：古代剧本 + 王权/王朝事件。

**帝国（Empire）**
- 意义：皇帝+官僚+常备军，规模与军事的极致；但腐败/边缘叛乱/治理成本高。
- 机制/特效：城市上限/资源调配/军事规模；官僚维护费；边缘忠诚下降。
- 正负：+规模/军事/资源；−腐败/治理成本/叛乱。
- 解锁：古代剧本 + 官僚制+征服事件。

**寡头制（Oligarchy）**
- 意义：少数精英（贵族/富商/军头）统治；经济/军事效率高，但合法性/公平弱。
- 机制/特效：商业/工业产出；精英阶层加成；平民忠诚/消费下降。
- 正负：+经济/效率；−合法性/公平/创新。
- 解锁：古代剧本 + 财富/商业科技。

### 3.3 中世纪（4）

**封建制（Feudalism）**
- 意义：领主-封臣契约，权力分散；地方自保强、中央动员慢，是联邦制的历史原型。
- 机制/特效：地方财政留存/地方防御；中央征募/建造效率低；骑士/地方兵。
- 正负：+分权/地方自保；−中央动员/统一市场。
- 解锁：中世纪剧本 + 封建契约科技。

**等级君主制（Estates Monarchy）**
- 意义：君主+等级会议（贵族/教士/市民），协商式王权；立宪君主制的前身。
- 机制/特效：合法性/稳定；议会协商（外交/税收）；改革需会议同意。
- 正负：+合法/稳定；−效率/集权弱。
- 解锁：中世纪剧本 + 等级会议事件。

**商业共和国（Merchant Republic）**
- 意义：商人寡头+贸易城邦（威尼斯/热那亚）；经济/海军/外交极强，陆权/公平弱。
- 机制/特效：贸易/商业/海军；贸易条约；雇佣军。
- 正负：+经济/外交/海军；−寡头/陆权弱/平民。
- 解锁：中世纪剧本 + 航海/商业科技。

**神权政治（Theocracy）**
- 意义：教权高于政权（教廷）；文化/忠诚极强，科技/世俗化阻力大。
- 机制/特效：文化自压/忠诚/稳定；宗教外交；科技/世俗惩罚。
- 正负：+文化/忠诚；−科技/外交摩擦。
- 解锁：中世纪剧本 + 宗教权威事件。

### 3.4 近代（4）

**绝对君主制（Absolute Monarchy）**
- 意义：君主主权+常备军+官僚，主权集中；动员/军事强，但税负/腐败/合法性风险。
- 机制/特效：常备军/征募效率；统一税制；宫廷维护费；革命风险。
- 正负：+动员/军事/统一；−税负/腐败/革命。
- 解锁：近代剧本 + 主权/常备军科技。

**立宪君主制（Constitutional Monarchy，现"君主立宪"）**
- 意义：君主虚位+议会，传统与现代的妥协；稳定/文化/外交强，军事动员慢。
- 机制/特效：传统合法性+议会协商；文化自压/同盟信任；军事槽少/动员慢。
- 正负：+稳定/文化/外交；−军事/改革慢。
- 解锁：近代剧本 + 宪政科技。

**共和制（Republic）**
- 意义：议会/总统制，主权在民；经济/外交/文化强，决策慢/政策反复。
- 机制/特效：民意/消费/民生；联盟信任；政策反复（换届/事件）。
- 正负：+经济/文化/外交；−军事槽少/决策慢。
- 解锁：近代剧本 + 启蒙/革命事件。

**军政府（Military Junta，现九政体之一）**
- 意义：军人集团直接统治；秩序/军事强，经济/外交/合法性弱。
- 机制/特效：治安/军管/征兵效率；经济活力/外交惩罚。
- 正负：+秩序/军事；−经济/外交/合法性。
- 解锁：近代/现代剧本 + 政变/战争事件。

## 四、政体解锁机制（不要文化线）

> 院长令：文明 6 用文化线解锁政体，我们**不用文化线**。以下为替代机制。

### 4.1 推荐组合：时代池 + 科技节点 + 事件 + 合法性条件

| 机制 | 用法 | 适用 |
|---|---|---|
| **时代池** | `ScenarioDefinition.governmentPool` 指定本剧本可用政体；时代只决定"池"，不强制换 | 主剧本/副本开局 |
| **科技节点** | `unlock.type=tech`：关键政治/社会科技解锁政体（法典→古典共和；封建契约→封建；宪政→立宪；AGI→算法治理） | 副本/古代/未来 |
| **事件解锁** | `unlock.type=event`：革命/政变/战争/危机事件解锁（军国主义=总体战；威权=危机；神权共和=宗教革命） | 全剧本特殊政体 |
| **建筑/条件** | `unlock.type=building`：议会/法院/神庙/广播中心等标志性建筑 | 可选补充 |
| **合法性条件** | 变更政体需满足现有指标（忠诚/稳定/战争状态/财），不新增资源 | 变更前的门槛 |

### 4.2 各剧本的解锁口径

| 剧本 | 政体池 | 解锁方式 |
|---|---|---|
| **主剧本（现代/教学）** | 九政体 | **开局全可选**（`start`）；变更 1k+清空+冷却；不设解锁线 |
| **复苏（远古）** | 远古 4 | 开局 1~2 个；其余靠科技/事件解锁 |
| **逐鹿（古代/战国）** | 古代 5 | 开局按势力给 1 个；科技/事件解锁 |
| **二期文明演进** | 全时代 | 时代+科技+事件解锁（可选规则） |

### 4.3 明确不采用

- ❌ 文化线/市政树解锁（院长令）；
- ❌ 新增"政体点数"资源（避免资源堆叠；财出口已足够）；
- ❌ 抽卡/随机解锁（政策/政体是战略选择，不是奖励）；
- ❌ 时代到了强制换政体（违反选择制）。

## 五、时代挂钩的落地字段

```
GovernmentDefinition {
  id, name,
  era: ancient|classical|medieval|earlyModern|modern|future,
  unlock: { type: start|tech|event|building|era, id? },
  slotBonuses{...}, effects[], globalModifiers[]
}

ScenarioDefinition {
  era,
  governmentPool: [govId...],       // 本剧本可用政体池
  allowLegacyGovernments: bool,     // 是否允许旧时代政体（默认 true）
  legacyLegitimacy?: bool           // 是否启用"传统合法性"（使用越久越稳）
}
```

- 旧政体跨时代：默认可用；专属卡池偏旧/相性下降；`legacyLegitimacy` 开启时给忠诚/稳定加成（可选）。
- 新剧本/新阵营只加数据，不改规则。

## 六、兵种/建筑挂钩结论

- **现状**：不挂钩（文档无 `governmentReq`；sim 无 `government`）。
- **默认**：保持不硬挂钩；政体通过政策卡/特效影响征募费、兵工厂产出、建造工期、维护费。
- **二期可选**：少量政体标志性建筑/兵种（每政体 ≤2 个），数据驱动，默认空。
- **接口预留**：`BuildingDefinition.governmentReq?` / `UnitDefinition.governmentReq?`，默认 null=不限制。

## 七、待裁（院长）

| # | 事项 | 本轮建议 |
|---|---|---|
| 1 | 政体池规模 | 条目 32（历史 17+现代 9+未来 6），**唯一政体 30**（立宪君主=君主立宪、军政府跨时代同一）；一期主剧本只用现代 9，历史/未来二期 |
| 2 | 主剧本九政体是否开局全开 | **建议全开**（选择制）；特殊政体（军国主义/威权）可挂事件解锁 |

| 5 | 历史政体是否进一期 | 复苏/逐鹿需要远古/古代政体；建议**数据化进一期底座**，内容二期 |
| 6 | 未来政体时点 | 二期（奇点时代/副本） |
