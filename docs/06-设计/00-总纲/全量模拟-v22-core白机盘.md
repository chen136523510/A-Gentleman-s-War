## 三、发现的问题与待办

1. **JP 灭 KR（而非 CN 扩张）**——core 盘战争=战力差 1.3 的"弱邻优先"（JP 3.8 万 vs KR 2.4 万兵），地缘上合理；但 **CN 最强却旁观**（随机 50%+每阵营 2 战上限）——full 盘需**外交/威胁评估/均势**逻辑（BUG-G011：CN 滚雪球或旁观都不理想）。
2. **国库暴涨（430 万）**——core 盘财出口只加了简化行政项（城市×200+2,000）；**按既有 19 项出口回归**（军饷/装备/俸禄/维护/文化维护/征募等）后应回落——full 盘执行。
3. **娱乐供给**：core 盘影院 caps 2 座不够吃 25% 份额（单城 100 万人口娱乐份额 ≈520 财/回，2×144=288）；已调 caps=6（≈多娱乐线合集）——full 盘按文化区 18 种娱乐建筑验。
4. **core 盘未覆盖**：电力/污染/科技树细节/建造工期/军备/战争细规则/文化输出/人口政策卡——full 盘补齐。
