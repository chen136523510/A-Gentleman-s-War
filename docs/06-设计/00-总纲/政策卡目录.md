## 一、卡模型

```
PolicyCardDefinition {
  id, name,
  attribute: military|economy|culture|diplomacy|universal,
  exclusiveGroup?: string,                  // v1.0 新增：互斥组（同组最多装 1 张）
  effects: [{ param, op: mult|switch|bias, value }],
  costs:   [{ param, value }],              // 可选；绝大多数为空
  unlock:  { type: tech|event|start },
  phase:   early|mid|late,
  color:   red|yellow|purple|green|white,   // 由 attribute 派生
  tags:    []
}
```

- **统一卡池**：初始卡池全阵营相同；无政体/阵营专属池；阵营特性由大统领特性决定。
- **五槽对五卡**：军事/经济/文化/外交/通用；卡色军红/经黄/文紫/外绿/通白。
- **不做隐藏卡/抽卡**：政策不是奖励系统，是国家战略选择。

## 二、槽位规则

| 槽位 | 数量 | 卡色 | 装卡规则 |
|:--:|:--:|:--:|---|
| 军事 | 2 | 红 | 只能装军事卡 |
| 经济 | 2 | 黄 | 只能装经济卡 |
| 文化 | 2 | 紫 | 只能装文化卡 |
| 外交 | 2 | 绿 | 只能装外交卡 |
| 通用 | 2 | 白 | 任意属性卡可装；通用卡只进通用槽 |
| **合计** | **10** | — | 所有阵营同一起跑线；无政体加成 |

- 额外槽：**只能通过事件/典藏**获取（永久、上限不设、难度控制）；科技/建筑不加槽。
- 剧本可覆写 `policySlots.base`（副本/教学特例）；无减槽机制。

## 三、切换成本与低频原则

| 项 | 规则 |
|---|---|
| 装卡/换卡 | **装卡免费**；**冷却期内改动 100 财/次、冷却期满改动 0 财**（11-19 定稿：收费只由冷却决定）；编辑态预览+确认后生效（不即时） |
| 槽位冷却 | t1 装 → 冷却期（`slotUnlockDelay=2`）内付费可改、期满改动免费（11-19） |
| 卸卡 | 冷却期内 **100** / 冷却期满 **0**；无次数 |
| 每回合上限 | **无**（冷却收费自然限频） |
| 额外槽 | 事件/典藏 +1，永久 |
| 外交强制卡 | 提案通过发卡；**不挂=违约**（细则归外交专题） |
| **低频原则（v1.0）** | ①全池 51 张效果**全常驻**（无"战时/和平"条件卡）；②不设"装卡即收益→卸卡"套利；③UI 提供**三套预设配置**一键套用；④教程只教一次；⑤不做政策任务/每周推荐等高频玩法 |

**生命周期**：可见 → 解锁（开局/科技/事件）→ 编辑态搭配（预览/总消耗/互斥提示）→ 确认（装卡免费、槽位进入冷却）→ 生效（下次结算）→ 冷却期内改动 100 财 / 冷却期满改动免费 → 回池。四态：已装/可装/已有不可用（灰）/未获得（显示途径）。
