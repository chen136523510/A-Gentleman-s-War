## 一、卡模型（定稿）

```
政策卡 = {
  id, 名称,
  类别: 军事 | 经济 | 外交 | 特殊 | 通用,      // 通用类=任意槽可装
  适配政体: [政体id...] | 空=所有政体可用,        // 空=通用卡（不限政体）
  效果: [{ 参数, 乘区/开关/倾向修正, 值 }],       // 必须引用主公式参数名
  负面:  [{ 参数, 值 }],                        // 有代价的强卡必须填
  解锁: 开局 | 科技节点 | 建筑/时代条件,
  阶段: 早 | 中 | 后
}
```

- **选项全部可见**（v0 R29b 已定）：玩家在政策面板看到所有卡（标注适配政体、效果、代价、解锁条件）；未解锁显示灰+条件。
- **不做隐藏卡/抽卡**：政策不是奖励系统，是国家战略选择。
- **卡池分层**：政体专属池 + 通用池（适配政体为空）。换政体后，已装的不适配卡**自动卸下**（不退款、不报错，面板提示）。

## 二、槽位规则（本轮定稿）

### 2.1 基础槽位（任何政体）

| 槽位 | 数量 | 说明 |
|:--:|:--:|---|
| 军事 | 2 | 只能装军事类卡 |
| 经济 | 2 | 只能装经济类卡 |
| 外交 | 1 | 只能装外交类卡 |
| 特殊 | 1 | 只能装特殊类卡 |
| **通用（万能槽）** | 1 | **任何类别卡都可装**（文明 6 wildcard 口径） |
| **合计** | **7** | — |

### 2.2 政体槽位加成（对齐 [政策与政体](./政策与政体.md) §三 倾向）

| 政体 | 加成 | 实际总槽（军/经/外/特/通） |
|---|---|:--:|
| **社会主义**（CN 初始） | 经济 +1、特殊 +1 | 9（2/3/1/2/1） |
| **君主立宪**（JP 初始） | 外交 +1 | 8（2/2/2/1/1） |
| **民主政府**（KR/AU 初始） | 经济 +1、外交 +1、军事 −1 | 8（1/3/2/1/1） |
| **军政府**（自立初始） | 军事 +1、经济 −1 | 7（3/1/1/1/1） |
| **威权政府** | 特殊 +1 | 8（2/2/1/2/1） |
| **技术官僚** | 经济 +1 | 8（2/3/1/1/1） |
| **联邦制** | 经济 +1（地方财政留存高，另见财政双层制） | 8（2/3/1/1/1） |
| **神权/传统** | 特殊 +1 | 8（2/2/1/2/1） |
| **军国主义** | 军事 +2、经济 −1（文化输出大减益=政体层全局乘区） | 8（4/1/1/1/1） |

- **槽位不叠加冲突**：政体加成是唯一来源；科技/建筑/事件不加槽（防无限叠）。
- **军事槽下限 1**：任何政体至少 1 军事槽（民主政府 2−1=1，不出现 0 槽）。
- 数值口径：基础 7 槽+加成后 7~9 槽；**一期教学剧本默认 CN=社会主义=9 槽**；新剧本可覆写（ScenarioDefinition `policySlots`）。

## 三、切换成本与生命周期（本轮定稿）

| 项 | 规则 | 依据 |
|---|---|---|
| **装卡/换卡** | **100 财/次**（X4 已裁区间 50~200 取中值）；**立即生效**（不做延迟，同人口政策口径） | 财政收支全景 X4 |
| 每回合切换上限 | **2 张/回合**（防微操；超过提示"本回合政策调整已满"） | 新增（模拟盘可调） |
| 卸卡 | 免费 | — |
| **政体切换** | **0 财**（X4 已裁）；**交战状态下禁改政体**（新增建议）；切换后 **3 回合**内不可再切（防抖动） | X4 + 本轮 |
| 换政体时 | 不适配卡自动卸下（不退款）；通用卡保留 | 本轮 |
| 战时限令 | **战时禁改政体；军事类卡仍可换**（前线换将不换国体） | 本轮建议 |

**卡生命周期**：可见（全卡池）→ 解锁（条件满足）→ 装槽（100 财、即时）→ 生效（每回合结算）→ 切换/卸下（免费或 100 财）→ 政体变更（自动卸不适配）→ 回池。政策面板显示：已装/可装/未解锁/不适配当前政体四种态。
