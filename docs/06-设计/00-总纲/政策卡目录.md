## 一、卡模型（定稿）

```
政策卡 = {
  id, 名称,
  attribute: 军事 | 经济 | 文化 | 外交 | universal,   // 五属性
  effects: [{ 参数, 乘区/开关/倾向修正, 值 }],          // 必须引用主公式参数名
  costs: [{ 参数, 值 }],                              // 可选；绝大多数卡为空
  unlock: { type: 科技 | 事件 },
  phase, color, tags
}
```

- **统一卡池**：初始卡池全阵营相同；**无政体/阵营专属池**；阵营特性由大统领特性决定。
- **五槽对五卡**：军事/经济/文化/外交/通用；卡色军红/经黄/文紫/外绿/通白。
- **不做隐藏卡/抽卡**：政策不是奖励系统，是国家战略选择。
- **槽位扩展**：基础槽之外只能通过事件/典藏等获取（外交提案可发卡）。

## 二、槽位规则（2026-11-17 最终裁定）

### 2.1 基础槽位（所有阵营相同）

| 槽位 | 数量 | 卡色 | 说明 |
|:--:|:--:|:--:|---|
| 军事 | 2 | **红** | 只能装军事属性卡 |
| 经济 | 2 | **黄** | 只能装经济属性卡 |
| 文化 | 2 | **紫** | 只能装文化属性卡 |
| 外交 | 2 | **绿** | 只能装外交属性卡 |
| **通用槽（万能槽）** | 2 | **白** | 任意属性卡可装；属性通用卡只进通用槽 |
| **合计** | **10** | — | 所有阵营同一起跑线；无政体加成 |

### 2.2 额外槽获取（事件/典藏）

- 基础 10 槽之外，**只能通过事件、典藏等额外获取**；**不设硬上限，获取频率/数量由难度控制**。
- 外交提案发卡（不是加槽）：见 §三与 [架构 §七](./政策卡架构.md)。
- **无政体加成、无科技加槽**；槽位扩展永久生效。

- **槽位不叠加**：无政体加成；加槽只走事件/典藏（§2.2），科技/建筑不加槽。
- **无减槽机制**；基础槽固定 2/2/2/2/2，剧本可覆写（ScenarioDefinition `policySlots`）。
