# 数值尺度重定 v22（人口 ×8 · 十万人级战争）

> 状态：✅ **院长裁定（2026-11-12）**：①目标=**十万人级战争**；②接受**人口基数大改**；③**准备重新全量模拟盘（v22）**。
> 起因：200 回合单城人口仅 2~5 万，全阵营总动员（10%）只有 2 万兵——"郡级冲突"，组织不起大规模国战。
> 方案：**全局经济缩放 S=8**（无量纲系数与公式结构完全不变，只放大所有"人/财/粮/岗/EP"量纲的数字）。
> 配套：承载初值 **人口 ×1.5**（**舒适容量，不是硬上限**——人口可超载至 1.5~2 倍，自然平衡点≈2 倍）+ **生育率公式正式化**（出生率−死亡率+超载压力，医院增速接入；BUG-G014）。

## 二、缩放清单（S=8）

### 2.1 缩放 ×8（量纲为 人 / 财 / 粮 / 岗位 / EP / 服务人口）

| 对象 | 原基准（示例） | ×8 后 |
|---|---|---|
| 城市人口 / 承载 | 32,000 / 40,000 | 256,000 / 384,000（承载另按 ×1.5 重定） |
| 居民楼承载 | 鸽子笼 12,000 / 小区 5,000 | 96,000 / 40,000 |
| 建筑岗位 | 写字楼 3,000 / 商场 1,500 | 24,000 / 12,000 |
| 建筑财收/产出 | 写字楼 35 财/回 / 农田 40 粮 | 280 / 320 |
| 建筑造价/生产/维护 | 商场 300 财/60 生产/维护 9 | 2,400 / 480 / 72 |
| 单座回收/池上限 | 商业街 12 / 商场 60 / 影城 18 | 96 / 480 / 144 |
| 消费力 | 人口×2.5 财/千人（公式不变，人口×8 自动 ×8） | 25.6 万城 = 640 财/回 |
| 服务人口 | 医院 5k~40k、警察 20k~80k | ×8 |
| 粮产 | 农田 40 / 牧场 32~36 / 食品工业 45 | 320 / 256~288 / 360 |
| EP/军备 | 装备厂 0.5 EP/回、1 EP=1000 兵份 | 4 EP/回、1 EP=8000 兵份 |
| 军事 | 守军上限、兵营征募（按人口%自动）、军饷（按兵自动） | ×8 |
| 税 | 税率常数 100 → **800**；P/1500 项随人口自动 ×8 | 25.6 万城 ≈ 971 财/回 |
| 初始国库 | 1,500 | **12,000** |
| 建设财买 | 1 财=1 生产 | **1 财=8 生产**（保持购买力比例） |

### 2.2 不变（无量纲 / 时间 / 空间 / 比例）

- **所有百分比与乘区**：基础出生率 2%、兵役负担 400v²、维护 1%/3%、消费份额 60/25/15、K_desire 系数、升级 ×1.6、等级 ^1.4、医疗/娱乐/治安覆盖式。
- **时间**：回合数、工期、建造回合、事件节奏。
- **空间**：占地 landW×landH、L2 地块、地图、航线、城市数量。
- **结构**：每城建筑上限、公式形式、存档 schema。
- **城防**：0~800 百分比制不缩放。
- **人口增长公式**：`增长 = P × (0.02 + 医院增速) × f_L × f_F × f_C`（P×8 自动放大；见 §三）。

## 三、配套修正（随 v22 一起入模）

| # | 修正 | 说明 |
|---|---|---|
| 1 | **生育率公式（取代 f_C 硬闸门）** | `b=(0.008+h)×f_L×f_F`、`d=0.004×(1+0.6o²+0.2U/100)`、`ΔP=P×(b−d)`；`o=max(0,P/C−1)` 超载率。**P 可大于 C**，人口有惯性（L/F 缓动+死亡率连续），平衡点≈2 倍承载（BUG-G014） |
| 2 | **承载 = 舒适容量（人口×1.5），非硬上限** | 承载只经"住房拥挤→宜居→出生率"与"超载率→死亡率"两条连续通道生效；人口可超载 1.5~2 倍 |
| 3 | **消费欲望 K_desire 入模** | 池上限 ×K_desire（0.5~1.5）——与缩放正交 |
| 4 | **消费剩余回流** | 缺类/吃不完回流（消费力专题 §1.1） |

## 五、影响面声明

- **v17a~v21 全部基线作废**（商业:税、人口、消费、财政、战争结论均在旧尺度）——v22 是唯一有效基线，旧报告只作趋势参考。
- 存档：v22 新基线不兼容旧档（数值尺度变更，读档需迁移 ×8 或拒绝）。
- 文档：各建筑数值表保留**基准值（缩放前）**，表头统一加注"v22 起 ×8"；人口数值表/军事表给出缩放后数字；参数表无量纲参数不变。
- 设计原则（R49"数值一期成型后统一微调"）：本次是**尺度重定**，相对平衡不变，属于可接受的统一调整；之后仍走模拟微调。
