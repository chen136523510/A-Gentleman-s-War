# 术语表

> 全游戏术语统一定义，新增术语先在此登记。🏗️ 随专题持续扩充。

## 阵营与身份

| 术语 | 定义 |
|---|---|
| 阵营 | CN/JP/KR/AU 四国之一；玩家开局自选 |
| 太守 | 驻守一座城的主责武将，每城 1 人；影响内政与忠诚；太守不在引起数值衰减，跌破临界才进入空虚（R11） |
| 幕僚 | 同城除太守外的武将，可率军出征而不引起城市衰减 |
| 公务员 | 城市培养的无名 NPC 层，降低太守不在时的负面影响；不进入太守候选（R11） |
| 自立 | 武将个人忠诚过低且独领一城时发动，建立以其名缩写命名的新阵营（如 WLT） |
| 大统领 | **玩家本人**（AI 阵营由 AI 代表）；武将全体平级、废除主席/总统/君主等领袖称谓；UI 不显示具名领袖（R39/2026-10-28 院长口径） |
| 外交官 | 外交场合对外示人的角色（不是大统领/领袖具名）；带魅力、智力等属性或被动技能；具体系统待外交轮实现（2026-10-28 院长口径） |
| 流亡政府 | 亡国后武装难民进驻无主城自立的**半存续势力**：有据点城/残余军力/武将，无外交席位、无内政全功能；复国会议通过即转正；多方流亡政府相互敌对争夺正统（R39） |
| 灭世线 | 地球环境面板海平面第三级刻度（+1.5m=大陆陷落全局失败）；命名即压迫，红色只作辅助元素、不单独用红色预警（R42b/2026-10-28 澄清） |

## 城市状态

| 术语 | 定义 |
|---|---|
| 正常 | 城市运转良好；太守不在≠立即空虚，底蕴足够（正收益/忠诚不降）则保持正常（R11） |
| 空虚 | 太守不在且衰减跌破临界点，进入无政府状态：产出/忠诚惩罚生效（R11） |
| 起义（中立） | 城市民生恶化到阈值触发；城池变无主之地，**中立只守不攻** |
| 城市范围 | 城市发育程度的外化；发育越好范围越大→二期战场布防纵深越大、越难攻破 |

## 资源与内政

| 术语 | 定义 |
|---|---|
| 财 | 通用财政资源（UI 统一显示“财”）；商业中心产出；募兵/外交/俸禄/升级 |
| 金（矿产） | 金矿场产出的矿产资源；经贸易/结算间接转化为财，不直接作为货币 |
| 粮 | 农田产出；养兵与出征消耗，断粮影响士气 |
| 军力 | 军事基地产出；部队规模与守军 |
| 城防 | 城墙提供的防御值（0~800 点、百分比扣减制）；**与守军区分**（R40c） |
| 守军 | 城市驻守兵力（军力）；随出兵/撤离即时增减——撤离回城兵力计入**守军**而非城防（R40） |
| 生产力 | 工业区（算力中心/发电中心/核电站等效形态）产出；建造速度 |
| 生产资料 | 建造消耗的材料类资源统称（R13；具体由哪些资源构成待数值期） |
| 科技值 | 学院产出；推进科技线 |
| 人口 | 城市人口存量+增速（R13）：受粮食/宜居度/住所/政策影响；高人口提升生产、推高基建成本 |
| 他国人口（移民） | 城市人口的**本国/他国分账**（R39）：可作生产力、过多压民生；政策可引入/遣返/限额；城市级可见每回合移民数与年度引入配额 |
| 宜居度 | 城市居住环境质量（R13）：受娱乐覆盖/污染/基建成本影响；过低→居民流失/忠诚降低/生产力下降 |
| 居民楼 | 人口承载量建筑（R13，六区域之外新增）：量优先（鸽子笼/密集公寓）/质优先（小区/别墅）等类型 |
| 民生 | 城市层面对统治的满意度（原"城市忠诚度"概念）；过低→起义。宜居度是其上游输入之一（建模见 [03-内政/人口与宜居度.md](../03-内政/人口与宜居度.md)） |
| 个人忠诚 | 武将对所属势力的忠诚；过低+独领城→自立 |
| 六区域 | 学院/商业中心/军事基地/工业区/娱乐中心/农田 |
| 城防 | 城墙提供的防御值（参照三国志 12 的 800 百分比制，数值待定） |

## 军事

| 术语 | 定义 |
|---|---|
| 采配 | 战场技能资源，随时间积累；武将技能消耗（1~10 点档，待定） |
| 技能（战法） | 带队武将各自可发动的招牌能力；统一效果模板=伤害/增益/弱化/恢复 |
| 自动档 | 战斗全自动数值结算+战报（一期与手动档并存，R36；二期保留为选项） |
| 手动档 | 一期已进（R36）：进入 L3 战场亲自指挥；与自动档并存、不互斥 |
| 伪回合制 | 主动暂停：右键下令自动时停、移动实时遥控、暂停可全军部署路线 |
| 战斗类型 | 由攻守城市对自动判定：内陆战/登陆战等（见 [04-军事/战斗类型.md](../04-军事/战斗类型.md)） |
| 登陆战 | 跨海攻击形态；无海战，守军可布滩头阵地 |
| 市政府 | 占领判定建筑（R13 定名，R11 原称"市中心"）：有**血条**；攻方须清零血条 + 派陆战部队**驻留占领一段时间**才完全占城；守方可将部队派入市政府（最后巷战） |
| 攻方根据地 | 攻方在守方城外的出发阵地/营地；被守军占领则攻方败退（R11） |
| 粮草组织 | 攻方发起进攻前必须组织的补给，量决定进攻可持续时长上限（R11） |
| 城防部队 | 城市常驻守军，不随太守消失；空虚城无将指挥战力打折（R11）；**守方兵力有限**（R13） |
| 起义民兵 | 起义中立城的守军构成，区别于城防部队（R11） |
| 战争迷雾 | 战场可见地形与建筑、**不见其上敌部队**；仅己方部队路过的区域彻底点亮；科技点可开启视野（R13） |
| 御驾亲征 | 角色编入部队亲率（可发动技能）；部队被歼灭→角色成为独立单位（高移速、5s 无敌不可选取）；再被攻击则**被俘**并降己方士气（R13）；全部角色被俘=战役失败 |
| 侦察 | 获取他城 L2 布防信息的手段：**外交或科技**获得（R13）；与战争迷雾联动 |

## 外交与人才

| 术语 | 定义 |
|---|---|
| 俘虏四处置 | 劝降/释放/拷打机密/处决；每项引发外交变化 |
| 逃跑 | 城破前太守可选择逃跑（规则待战斗专题） |
| 声望 | 外交子资源 0~100，全阵营可见；来源=击退异族/履约/不掠夺，消耗=破弃/处决/掠夺（R23） |

## 军事与数值（R23 新增）

| 术语 | 定义 |
|---|---|
| 回合 | 一期战略循环时间单位（玩家阶段任意时长+结算阶段原子执行）；数值速率均以 /回 表达；**1 回合=1 年**（R27） |
| 支队 | 出征编成单位（6~10 支/场）=底盘×装备档×军力份额；带队（御驾亲征）或遥控 |
| 底盘 | ~~兵种分法作废~~（R34 改三系六类：步/骑/弓，见兵种与装备目录 v2） |
| 装备档 | 技术代际 T1 二战库存/T2 冷战主力/T3 精确制导/T4 无人化；**价格与档位刻意不正相关** |
| 克制系数 | 克制 ×1.3 / 被克 ×0.8 / 无关 ×1.0（R34 三系简化矩阵） |
| 质量 q | 部队综合战力密度=底盘基础×装备档×科技×克制×武将×技能（总纲 §4.4） |
| 民生 | 城市对统治的满意度 0~100（宜居度只是因子之一）；<30 连续 3 回合→起义 |
| **战备（R37）** | 掠夺军事基地获得的子资源：提升部队战斗力的数值加成 |
| **战备值（R37）** | 战备资源的量化值，作用于部队战力乘区（数值期定） |
| **武装难民（R34）** | 亡国后残留带军备的人口群：去向国选择接收/迁移/驱赶，或开难民国际会议表决 |
| **复国会议（R35）** | 持原属他阵营城市+该阵营已被他人所灭→半数通过即可用该城复国；灭国者禁入 |
