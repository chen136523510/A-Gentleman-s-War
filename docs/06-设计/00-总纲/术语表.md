# 术语表

> 全游戏术语统一定义，新增术语先在此登记。🏗️ 随专题持续扩充。

## 阵营与身份

| 术语 | 定义 |
|---|---|
| 阵营 | CN/JP/KR/AU 四国之一；玩家开局自选 |
| **驻城武将** | 驻守一座城的武将；**不区分太守/幕僚，无首长概念**（2026-11-10 院长裁）；可分配到一个建筑提供加成；同城多将平级 |
| **建筑派驻** | 驻城武将分配至具体建筑（军事基地/商业中心/市政府/学院/文化建筑/警察局/兵营/红灯区等），按该建筑主属性提供加成；每将 1 个派驻位 |
| **驻城武将汇报** | 事件预警/情报出口；一般事件随机选 1 名驻城武将，事件关联建筑时优先该建筑派驻武将（仍有随机性）；城中无武将则无汇报但信息不静默（2026-11-10 细化） |
| **NPC 武将** | 后续由五系建筑培养的武将（商学院/未来技术学院/战争学院/市政府/传媒大学 + 国安局间谍）；与 21 初始武将**同等地位**（可驻城/带队/被俘/处决） |
| 公务员 | **市政府在岗人员**（铁饭碗，不允许调离）；不是武将，不进入武将层（2026-11-09 裁定） |
| 自立 | **起义触发时**，城中仅 1 名武将且其个人忠诚<40 → 该将带城自立，建立以其名缩写命名的新阵营（如 WLT）；玩家可提前调走该将避免 |
| **外逃** | 驻城武将个人忠诚<40 时每回合概率离城→在野（可被招揽）；宝物随将；先于起义判定（2026-11-10 新立） |
| 大统领 | 阵营最高意志，**2026-11-11 实体化为武将**：每阵营一名，AI 局默认 **CN 丘序明（主席）/ JP 陈睿（君主）/ KR 徐浩森（总统）/ AU 马逸杰（总统）**；玩家选任一阵营→**玩家作为该国君主（大统领）**；不受忠诚影响、不可招安、不可俘获；AI 大统领默认兼职外交官；自立武将=WLT 大统领（覆盖 R39 称谓废除） |
| 外交官 | 外交场合对外示人的角色（不是大统领/领袖具名）；由各阵营**自行选择己方武将兼任**，作为额外身份属性（保留原职），带魅力、智力等属性或被动技能；具体系统待外交轮实现（2026-10-28 院长口径） |
| 流亡政府 | 亡国后武装难民进驻无主城自立的**半存续势力**：有据点城/残余军力/武将，无外交席位、无内政全功能；复国会议通过即转正；多方流亡政府相互敌对争夺正统（R39） |
| 灭世线 | 地球环境面板海平面第三级刻度（+1.5m=大陆陷落全局失败）；命名即压迫，红色只作辅助元素、不单独用红色预警（R42b/2026-10-28 澄清） |

## 城市状态

| 术语 | 定义 |
|---|---|
| 正常 | 城市运转良好；**无驻城武将≠衰败**，只是吃不到建筑派驻加成（2026-11-09/11-10 口径） |
| ~~空虚~~ | **已删除**（2026-11-09 院长令）：无政府惩罚链作废，城市只回落到基础产出 |
| 起义（中立） | **城市忠诚度** <30 连续 3 回合（普通城）/ <20 连续 10 回合（占领城）触发；城池变无主之地，**中立只守不攻、AI 自行发展**（参考达尔文） |
| 城市范围 | 城市发育程度的外化；发育越好范围越大→二期战场布防纵深越大、越难攻破 |

## 资源与内政

| 术语 | 定义 |
|---|---|
| 财 | 通用财政资源（UI 统一显示“财”）；商业中心产出；募兵/外交/俸禄/升级 |
| 金（矿产） | 金矿场产出的矿产资源；经贸易/结算间接转化为财，不直接作为货币 |
| 粮 | 农田产出；养兵与出征消耗，断粮影响士气 |
| 军力 | 军事基地产出；部队规模与守军 |
| 城防 | 城墙提供的防御值（0~800 点、百分比扣减制）；**与守军区分**（R40c） |
| 守军 | 城市驻守兵力（军力）；随出兵/撤离即时增减——撤离回城兵力计入**守军**而非城防（R40） |
| 生产力 | 工业区（算力中心/发电中心/核电站等效形态）产出；建造速度 |
| 生产资料 | 建造消耗的材料类资源统称（R13；具体由哪些资源构成待数值期） |
| 科技值 | 学院产出；推进科技线 |
| 人口 | 城市人口**三账**（R44）：本国/外籍/在途；总人口=本国+外籍；受粮食/宜居/住所/政策影响；高人口提升生产、推高粮食与住房压力 |
| **承载（舒适容量）** | 城市住房/公共服务可舒适容纳的人口（2026-11-12 改口）：居民楼/初始承载给基数；**不是硬上限**——人口可超载，**平衡点在 1.5 倍承载**（g=0 处），超过回压（住房拥挤/宜居下降/人口流失） |
| **人口自然增长公式** | 人口变化主式（2026-11-12，取代出生率/死亡率分列与 f_C 硬闸门）：`g = 0.008 × h × f_L × f_F × (1.5 − r)`、`ΔP = P × clamp(g, −3%, +3%)`；h=医院乘区 1.05~1.30，r=P/C；**玩家只看人口变化（↗/↘），不暴露出生/死亡**——权威 [人口算法](../03-内政/人口算法-v1.md) §7.2 |
| **无人口结构** | 2026-11-12 口径：**总人口即劳动力人口**，不设老幼/年龄/性别分层；岗位/就业/在岗率/兵源/消费/粮需求全部按总人口算（与既有设计兼容） |
| **人口政策** | B8 政策卡（2026-11-12 立）：生育鼓励（+增长，10 回滞后）/ 计划生育（−增长，忠诚负）/ 开放移民（+外籍人口）/ 住房保障（+承载）/ 延迟退休（+在岗率、−增长）——权威 [人口政策调研](../00-调研/人口政策调研.md) |
| 他国人口（外籍人口） | 城市人口的**本国/外籍分账**（R39/R44）：可作生产力、不可征募（同化后可）；比例过高压民生/治安；政策可引入/遣返/限额 |
| 外籍人口比例 | 外籍人口÷总人口（R44）；民生与治安的摩擦项，同化后衰减 |
| 宜居度 | 城市**客观**居住环境质量 0~100（R44）：受住房/娱乐/环境/治安/医疗影响；**影响生产产出**、人口增速；民生主因子 |
| 民生 | **最顶层状态指标** 0~100（R44，**非资源**）：综合评估人民生活水平；受粮食/宜居/外籍比例/治安/舆论/服役等影响；**影响城市忠诚度/起义** |
| 治安 | 城市秩序水平 0~100（R44/R45）：直接来源=警察局等行政建筑；间接来源=外籍比例↓；影响宜居、民生、生产稳定；**驻军不再加治安** |
| **消费** | 居民/访客的**支出行为**泛称（非数值概念）：含零售/娱乐/文旅三类；只用于描述消费端建筑与收入来源，**不进任何公式** |
| **消费力** | 城市每回合的**购买力总量**（数值概念，财/回）：`消费力 = 民用人口/1000 × 2.5 × K_desire`（民用人口=总人口−服役），可被政策/科技修正；**城市级、不设全国池**（2026-11-02 院长裁）——权威 [消费力专题](../03-内政/消费力专题.md) §一/§三 |
| **消费欲望** | 居民"**愿不愿意花钱**"的宏观系数 `K_desire`（0.5~1.5，基准 1.0，11-12 立）：受就业（在岗率）/宜居/战争/税负/基本需求供给（缺粮/缺电/民生<30）影响；**消费力 × 欲望 = 有效需求**（池上限）——有钱不敢花时池上限低于购买力（预防性储蓄）——权威 [消费力专题](../03-内政/消费力专题.md) §1.1 |
| **有效需求** | **有支付能力且愿意实现的需求**（池上限）：`有效需求 = 消费力 × K_desire`；与"潜在购买力"（人口算出的名义消费力）区分——战争/重税时有效需求低于名义值 |
| **消费池** | **消费力的分配容器**（与"消费力"同一概念；"消费力池"为历史别名，正文统一用"消费池"）：每回合按固定份额 60/25/15 分给零售/娱乐/文旅，建筑从本类份额回收；**份额=需求结构基准、不是硬上限**——某类无建筑或吃不完时按现存类权重回流（§消费份额） |
| **消费回收** | 消费端建筑把消费转化为财政收入的公式：`本类回收 = min(本类份额剩余, 单座上限) × 在岗率`；在岗率=供给端服务能力（战时劳动力转军工→回收下降，**池本身不变**，11-02 裁） |
| **消费饱和** | 本类份额剩余趋零的状态：新建同类建筑收益边际递减直至白建，**无惩罚**——建造预览红字"本城消费已饱和"（心智负担：不考试、不设门槛） |
| **消费份额** | 同池三类的固定分配：**零售 60% / 娱乐 25% / 文旅 15%**（11-05 裁；依据=真实居民消费结构：商品零售 60%、教文娱 25%、旅游≈14%）；**缺类/吃不完的剩余按现存类份额权重回流**——只做娱乐时娱乐可吃满 100%，不是锁死 25% |
| **消费情景标签**（11-12） | 城市消费状态五档诊断：**消费繁荣**（有效需求高+供给匹配≈市场出清）/ **消费饱和**（打满但池小，居民掏不出钱）/ **供不应求**（池高但回收<50%，有钱没处花/消费外流）/ **消费低迷**（池低+回收低，有钱不敢花/预防性储蓄）/ **平稳**；城市面板一行显示，只做提示不惩罚——权威 [消费力专题](../03-内政/消费力专题.md) §2.6 |
| 警察局 | 行政建筑（R45）：**治安直接来源**（S_b），与驻军脱钩；驻军只管忠诚/防御 |
| 粮食安全 | **全国统一粮池**（R44d）：农田+牧场+食品工业+进口 vs 全国人口+服役需求；各城共享、被围城断供；库存上限 2×年需求 |
| 牧场 | 农田子类型（R44d，不新增第七区域）：与种植同级同产出，地形/草原导向，与农田共享耕地容量 |
| 食品工业 | 粮食第三来源（R44d）：罐头/预制菜，产能+科技驱动、不占耕地 |
| 战争支持度 | 战争对民生的修正（R44d）：民族主义/军国主义开战 rally，随战争回合疲劳；多元主义反战；真实代价走服役/军粮/兵员 |
| 军管期 | 占领城前 10 回合（R44d）：起义不触发；之后按城市忠诚度流量判定 |
| 服役 / 服役比例 | 从本国人口征募的士兵（R44）；比例=服役÷总人口，**联合国裁军会议指标**；占人口、吃粮、压民生 |
| 舆论倾向 | 国家长期意识形态（民族主义↔多元主义，R44）；决定事件冲击的符号与幅度 |
| 耐受度 | 政策养成的民生抗压能力（R44）；直接修正民生、缓冲负面冲击 |
| 同化 | 外籍人口→本国人口（R43/R44）：基础 2%/回合×文化因子（**11-05 改相对均值** `1+1.5×(Cnat−Cavg)/Cavg`，clamp 1~2.5），上限 5%/回合 |
| **服务人口** | 建筑**能服务的人口上限**（与岗位区分）：覆盖强度 `c=min(1,Σ服务人口/城市人口)`，用于娱乐 E/医疗/治安/文化服务；例：2k 岗位可服务 8k 人口（2026-11-05 院长裁） |
| **城市热度** | 城市级状态量（2026-11-05 定名）：衡量城市对访客的吸引力，是文旅财乘区；`基础10+本城文化产出×0.8+事件`，污染/战争/占领/起义衰减；五档=寂寂无闻/初露锋芒/声名远扬/名扬四海/万邦来朝 |
| **文化值** | 城市/国家的**对内文化积累量**（R30；2026-11-12 文化区 v1.0 定稿）：城市文化产出=基础值+Σ(建筑文化直产×在岗率)×宜居/人口/科技因子−污染；国家存量=历史累计、**失城不回溯**——权威 [文化区数值](../03-内政/文化区数值.md) |
| **文化输出值** | 国家对外的**文化渗透强度**（R28）：`Output=√Culture×距离×联系×情报×战争衰减`，按 N×N 矩阵逐国逐回结算——权威 [文化输出算法](./文化输出算法.md) §三 |
| **认同度** | 目标国人口对某国文化的**认同占比**（0~100%），按份额收敛式演变；外国认同 ≥60% 持续 5 回=**完全入侵**；本国认同 <40% 且无外国 ≥60%=**文化失所**——权威 [文化输出算法](./文化输出算法.md) §五/§六/§9.5 |
| **文化失所** | 国家级状态（2026-11-05 院长新立）：**多极文化同时冲击导致本国认同碎片化**——Identity[本国] < 40% 且无任何外国 ≥60% 时触发；语义="国民不知道认同什么文化，但肯定不认同自身文化"。效果=征兵 ×0.85 + 战斗 ×0.9 + 忠诚流水 −0.5/回（**不扣文化产出**）；Identity ≥45% 解除（迟滞） |
| **碳回收** | 环境系统机制（2026-11-05 院长定名）：**抵消碳排放的负排放来源**——绿化带 −1/国家公园 −3/生态保护区 −5/CCS 碳捕集站 −20 碳/回。净碳 ≤0 时**温度不再上升**（锁定，不回落）；持续 20 回合后**海平面停止上升**（已淹没城市不回滚） |
| **典藏** | 国家持有的**独一无二**物件总系统（2026-11-05 院长定名；"国库"已被 B12 财政占用）：来源=考古/掠夺/外交/事件；部署=陈列本城博物馆/常驻（国家级被动）/赐予武将；**不做价值分类**，每件独立配置效果 |
| 居民楼 | 人口承载量建筑（R13，六区域之外新增）：量优先（鸽子笼/密集公寓）/质优先（小区/别墅）等类型 |
| 个人忠诚 | 武将对所属势力的忠诚；<40 每回概率外逃；起义时孤城低忠诚将→自立 |
| 六区域 | 学院/商业中心/军事基地/工业区/娱乐中心/农田；**市政设施（医院/警察局/交通等）不在六区域内**，走独立建筑类 |
| 城防 | 城墙提供的防御值（参照三国志 12 的 800 百分比制，数值待定） |

## 军事

| 术语 | 定义 |
|---|---|
| 采配 | 战场技能资源，随时间积累；武将技能消耗（1~10 点档，待定） |
| 技能（战法） | 带队武将各自可发动的招牌能力；统一效果模板=伤害/增益/弱化/恢复 |
| 自动档 | 战斗全自动数值结算+战报（一期与手动档并存，R36；二期保留为选项） |
| 手动档 | 一期已进（R36）：进入 L3 战场亲自指挥；与自动档并存、不互斥 |
| 伪回合制 | 主动暂停：右键下令自动时停、移动实时遥控、暂停可全军部署路线 |
| 战斗类型 | 由攻守城市对自动判定：内陆战/登陆战等（见 [04-军事/战斗类型.md](../04-军事/战斗类型.md)） |
| 登陆战 | 跨海攻击形态；无海战，守军可布滩头阵地 |
| 市政府 | 占领判定建筑（R13 定名，R11 原称"市中心"）：有**血条**；攻方须清零血条 + 派陆战部队**驻留占领一段时间**才完全占城；守方可将部队派入市政府（最后巷战） |
| 攻方根据地 | 攻方在守方城外的出发阵地/营地；被守军占领则攻方败退（R11） |
| 粮草组织 | 攻方发起进攻前必须组织的补给，量决定进攻可持续时长上限（R11） |
| 城防部队 | 城市常驻守军，不随驻城武将消失；**无武将驻守的城**守军无将指挥→战力打折（2026-11-09/11-10 口径）；**守方兵力有限**（R13） |
| 起义民兵 | 起义中立城的守军构成，区别于城防部队（R11） |
| 战争迷雾 | 战场可见地形与建筑、**不见其上敌部队**；仅己方部队路过的区域彻底点亮；科技点可开启视野（R13） |
| 御驾亲征 | **L1 出征必须武将带队**；L3 战场部队可**远程遥控**（两层规则并存）；角色编入部队可发动**主动战技**；部队被歼灭→角色成为独立单位（高移速、5s 无敌不可选取）；再被攻击则**被俘**并降己方士气（R13）；全部角色被俘=战役失败 |
