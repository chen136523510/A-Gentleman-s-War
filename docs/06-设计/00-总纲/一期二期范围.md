# 一期 / 二期范围切分

> 状态：✅ 已定 · 更新：**2026-11-16 院长令（一期=教学关卡+全内容+默认CN+固定工作流；二期=新地图/阵营+选阵营+平衡；系统成熟度原则保留）** · 2026-10-28 R42（环境五账本+面板进一期；全局失败结局入胜利判定）
> 原则：一期跑通"内政→出兵→占城→处置"完整战略循环 + **教学指引 + 默认 CN + 固定工作流**；二期加**新地图/新阵营/选阵营/平衡性** + 表现力/AI。
> **分期原则（R42 院长立，继续有效）**：分期不按工作量分，按**系统整体最优开发**分——一个系统整体成熟即整体进一期，避免两期接口割裂出 bug。
> **2026-11-16 补充（院长令）**：一期就是一套**成熟系统**，只缺"选阵营"环节；14 城/4 阵营/21 将/21 城上限是**一期剧本数据**，不是规则；**所有一期设定按二期最终版设计**——规则层不得写死阵营数、城市数、武将数、开局形态、胜利判定参数。
> **施工顺序（2026-11-16 院长令）**：**游戏本体基座全部完成 → 教学关卡 → 一期验收**；二期只做增量内容（新地图/阵营/平衡/表现力）。教程不在基座之前做。

## 一、两期定位

| 项 | 一期 | 二期 |
|---|---|---|
| 定位 | **教学关卡 + 最小可玩世界单元 + 工作流样板** | **新地图/新阵营 + 选阵营 + 副本（复苏/逐鹿/群星/复仇者/内战）+ 平衡性** + 表现力/AI |
| 世界线 | 14 城/4 阵营（CN/JP/KR/AU），固定归属 | 新地图/新阵营；开局形态未定（单城扩张/固定城市+历史事件/其他） |
| 玩家 | **默认 CN，无选阵营环节** | 选剧本/选阵营、多难度 |
| 内容 | **全部核心内容**：内政/科技/武将/外交/文化/环境/事件/三胜利条件/L1/L2/L3/教学 | 新内容 + 平衡 + 表现力/LLM |
| 教学 | **事件驱动教学剧本**（CN 视角；章节化 L1→L2→L3→外交→文化→科技胜利；**不要求 KR 自然文化胜利**，文化入侵用剧本事件演示） | 新手引导复用/扩展 |
| 工作流 | **固定工作流**：数据→美术→模拟→Unity→验收 | 沿用工作流批量扩内容 |
| 验收 | **完整内容 + 教学 + 默认 CN + 工作流 + L3 可玩** | 新地图/阵营 + 平衡 + 表现力 |

> **核心内容 vs 扩展内容**：一期=全部核心系统与核心内容（完整科技树、全部建筑、21 将、三胜利、L1/L2/L3、教学事件）；二期=新地图/新阵营+选阵营+平衡+扩展事件（天灾/异族等）+表现力/LLM。若院长要求扩展事件也进一期，按 R42"系统整体成熟"前移。

## 三、一期验收清单（院长令：完整内容+教学+默认CN+工作流）

1. **完整内容**：全部建筑/资源/科技树/21 将/三胜利条件/环境账本/外交会议/文化建设/L1·L2·L3 可玩；96draft 全部接入或明确"二期扩展"。
2. **教学指引**：默认 CN 开局；**事件驱动剧本，不是 100~200 回合自由沙盒**；章节覆盖 L1（地图/城池/建造/出征）、L2（内城/建筑/指标）、L3（手动战斗）、外交/文化/科技/环境、三种胜利条件的达成演示；**不要求 KR 自然文化胜利**（文化入侵用剧本事件演示）；提示/目标/UI 锚点可配置。
3. **固定工作流**：一份可复用的"新增内容工作流"文档（数据 schema→美术→模拟验证→Unity 接入→验收），二期按此批量扩地图/阵营。
4. **通用性**：规则层无 4/14/21 硬编码；至少一个 N 阵营 smoke test（如 6 阵营/20 城）证明新地图/新阵营只加数据不改规则。
5. **L3 可玩**：手动战斗与自动结算并存，教学可实际演示。
6. **打包验收**：黑机构建 exe，实机走通教学流程。

## 四、关键架构约束（新增 2026-11-16）

- **规则/剧本分层**：规则层 N 阵营无关；ScenarioDefinition 提供 factionCount/cityCount/startMode/初始归属/可玩阵营/胜利参数/事件集/教学开关；EventScript 提供条件→效果；TutorialDefinition 提供步骤/目标/提示。
- **科技树按世界线覆盖（2026-11-16）**：三线（红军事/蓝AI/绿民生）×六时代方向不变；`TechTreeDefinition` 可覆盖起点、发展速度、部分节点；教学关卡用剧本解锁，不要求玩家自然爬完整棵树。
- **禁止硬编码**：阵营数、城市数、武将数、地图尺寸、开局形态、UN 门槛/选举方式、文化胜利存活口径，全部读剧本参数或数据表。
- **一期即终局判定**：胜利判定只读全局状态（城池归属/科技完成度/关系值/文化值），不依赖战斗表现层；二期换剧本参数不换规则。
- **一套战斗判定两档共用**：自动结算=自动档，L3 手动档只加渲染与指令层，不写第二套规则。
- **数据即按二期战场实体建模**（设施等级/位置战场可读），避免两套数据。
- **数值一期成型后统一微调**；一期不做平衡目标（教学剧本的确定性结果可接受），二期再做平衡。

## 六、副本规划（二期内容；一期只留接口）

- 详见 [游戏模式与副本规划](./游戏模式与副本规划.md)：**L0 主界面 + 教学关卡 + 复苏/逐鹿/群星/复仇者联盟/内战**。
- 一期只做**教学关卡 + 底座兼容**；副本内容二期。
- 底座必须支持：可变阵营数（2/3/4/7/8）、随机开局（国名/颜色/武将/城位）、单城/固定城市、远古/中期/现代科技起点、胜利条件覆盖（仅军事/特殊/三胜利）、外交模式（正常/无外交永久战争/强制同盟不可背刺）、特殊阵营（邪族）与其单位/建筑/AI 波次、环境模式（碳/高频灾害）、动态连通（斗转星移）、L0 菜单/副本解锁/自动存档。
- **数值纪律**：当前 v22（S=8/14 城/4 阵营）是教学剧本数值，不是副本平衡；副本数值按 ScenarioDefinition/balance 覆盖，禁止写死 4/14/21。
- **复苏=主副本/通用规则基准（2026-11-16）**：8 阵营/固定城位随机分配/单城/远古/三胜利；其余副本只覆写差异；教程是特殊教学剧本。
- **基础数值定版后冻结（2026-11-16；当前可调）**：现有建筑产出/成本/单位属性/科技成本**全部不变**；副本只改规则/组合/地图/阵营/开局/胜利；新增内容（古代/中世纪节点、NPC、邪族单位）另加值。
- **武将池（2026-11-16）**：21 群友=通用池；各副本加不同 NPC；NPC 与初始将平级，但不遵 400 属性点原则。
- **文化胜利（2026-11-16）**：**存活阵营全入侵**（不要求初始全存活）；**复国国 UN 投票跟随复国者（不是额外一票）**；UN ≥2/3；选举第一轮相对多数/未过半空位；不做大国无反对；只有常任理事国一票否决（复苏通用规则）。
