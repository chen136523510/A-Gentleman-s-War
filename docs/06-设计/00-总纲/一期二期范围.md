# 一期 / 二期范围切分

> 状态：✅ 已定 · 更新：2026-10-26 R37（L3 手动档进一期+战役中途存档 v3 挂账；胜利=三途径 R27b；事件行补软引导和平期）
> 原则：一期跑通"内政→出兵→占城→处置"完整战略循环；二期加战场表现力、事件与 AI。

| 系统 | 一期（战略循环可玩版） | 二期 |
|---|---|---|
| 内政 | 六区域+城墙+资源+驻守城态（无槽位上限，范围成长） | 同 |
| 科技 | 占位树 3 节点（T2 解锁/市场/视野；R23 科技树 v1；科技线专题后置 R31） | 完整四线科技树（AI/天网/星链/无人机+环保民生） |
| 武将 | 21 将名册/驻守/个人忠诚/自立/俘虏四处置（武将轮与政策卡同期，R31） | 技能在实时战场释放 |
| **战斗** | **L3 手动档直接进一期（R36 推翻原"一期仅自动结算"）+自动结算并存**；**他国战争可观战**（AI 沙盒模拟，快进/跳过） | 表现力增强（战损演出/音效） |
| 战斗类型 | 按攻守城市对自动判定（内陆/登陆等） | 同，登陆战滩头表现细化 |
| 内政-战场联动 | 设施等级折算进结算数值 | 城墙/基地/箭塔实体化（红警范式） |
| 外交 | 规则判定+模板话术；处置俘虏引发关系变化；**复国会议（R35）** | +LLM 谈判（JSON 闸门） |
| 事件 | **城市起义 + 武将自立**；开局软引导和平期（前 10 回合，R25） | + 天灾（沙尘暴/海啸/污染）、异族入侵（西北陆患/沿海海盗）——R23 二期立项稿已备 |
| LLM | **不接**（系统雏形多，无可读现状） | 军师（只读 snapshot）先行，外交 LLM 随后 |
| 修改器 | **必做**：指令总线+设置界面内控制台 | +战时金手指 |
| 存档 | Unity persistentDataPath JSON；**战役途中可存档（R36 推翻回合边界快照口径，存档 v3 挂账）** | 同 |
| **胜利条件** | **三途径并存**（R27b）：统一 + 科技 + 文化（联合国路线），均为纯规则判定；外交并入文化链、不独立成胜利（见 [胜利条件.md](./胜利条件.md)） | 胜利演出/成就等表现力增强；判定不变 |

## 关键架构约束

- **一套战斗判定模型两档共用**：自动结算=自动档，L3 手动档同期并存（R36），手动档只加渲染与指令层，不写第二套规则。
- 一期数据结构即按二期战场实体建模（设施等级/位置战场可读），避免两套数据。
- 数值一期成型后统一微调，现阶段只定结构。
- **胜利判定只读全局状态**（城池归属/科技完成度/关系值/文化值），不依赖战斗表现层——一期判定即终局判定，二期无返工。
