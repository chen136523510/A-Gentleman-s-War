## 二、命名调研：其他游戏的六种流派

### 2.1 流派与代表

| 流派 | 代表游戏/卡 | 命名样本 | 特征 |
|---|---|---|---|
| **① 制度史** | 文明6：Serfdom/Collectivization/Five-Year Plan；V3：Universal Suffrage/Command Economy；全战三国：屯田/九品中正；HOI4：War Economy | "农奴制""集体化""五年计划""普选""命令经济" | 名词化制度，玩家觉得"在治理国家"；最主流的政策命名法 |
| **② 阶梯状态** | HOI4 征兵：Volunteer Only→Limited→Extensive→Service by Requirement→All Adults Serve→**Scraping the Barrel**；经济：Civilian→Early/Partial Mobilization→War Economy→Total Mobilization | 同一轴 5~7 档，**名字本身就是社会状态的推进**（"刮桶底"是招牌） | 每个名字有"往前一步"的代价感；最适合我们的互斥组 |
| **③ 意象宣言** | 群星：Fortify the Border/Map the Stars/A Grand Fleet/Will to Power/Hearts and Minds；Stellaris 天赋：One Vision/Technological Ascendancy；冰汽时代：Necessity/Proclamation/Public Penance | 动词短语/意象名词，有画面 | 记忆点强，但需翻译气质匹配 |
| **④ 政治学概念** | V3 全法律组：Governance Principles/Distribution of Power/Free Speech/Labor Rights；EU4：Smithian Economics | 学术概念 | 清晰系统，但冷；适合"制度百科"式游戏 |
| **⑤ 典故梗** | 三国志12 秘策：火计/连环计/空城计；全战三国历史改革；Kaiserreich/TNO 等 mod 的事件名 | 成语/计策/历史梗 | 中文玩家记忆点最强；与国风世界观天然契合 |
| **⑥ 现代议题** | 城市天际线：Free Public Transport/Smoking Ban/Industry 4.0；文明6 后期：Nuclear Disarmament/Collective Security | 现实政策直白名 | 贴现实，但趣味低（我们现状就是这一派） |

### 2.2 判断：本作最优 = ①+⑤ 混搭（国风典故为主 + 现代梗保留）

理由：
1. **《国男志》= 现代架空国风 + 学院梗**——典故名与现代梗（电子长城/基建狂魔）混搭正是世界观气质，不是违和；
2. 现有 6 张好名（电子长城/基建狂魔/万国来游/雅言远播/光影出海/百家争鸣）全部属于"意象/现代梗"，证明这个方向玩家接受；
3. 现状 44 张"政策术语表"（减税/消费刺激/招商引资/国企集中…）正是流派⑥，是"无趣"的直接来源；
4. HOI4 的**阶梯命名**（流派②）给我们一条额外启发：**互斥组的两个名字应该"一眼看出是两个方向"**——如"轻徭薄赋 × 横征暴敛""海纳百川 × 闭关自守"，比"减税 × 增税"有戏剧张力。

### 3.7 命名自检
- 保留原名 6 张：电子长城/万国来游/光影出海/雅言远播/百家争鸣/基建狂魔；
- 改名 45 张：四字典故 38 张 + 现代术语 7 张（碳配额/统制经济/万物互联/绿水青山/海晏河清/盐铁专营？——现代与原典混用）；
- 互斥组 10 组逐一检查方向感：轻徭薄赋×横征暴敛｜市井繁华×节用裕民｜添丁进口×优生优育｜市舶通商×盐铁专营｜府兵之制×庙算｜亲仁善邻×以力服人｜关税壁垒×通商互市｜歃血为盟×独善其身｜百家争鸣×防民之口｜电子长城×万物互联——**每组两名的气质对立成立**；
- 敏感自检：防民之口（史鉴，非褒）、横征暴敛（贬义，玩家装它=当恶人）、闭关锁国（史实）、绣衣直指（汉代监察）、均田制（历史制度）——均属"历史/制度名词"，无现实敏感主体。

## 五、机制存废评估（院长令 4）

### 5.1 现有资产盘点（已落库）
| 资产 | 状态 | 砍掉的代价 |
|---|---|---|
| `policies.json` 51 张 | 已落库 | 51 张卡面内容作废 |
| PolicySystem（装配/互斥/冷却/收费/预览/强制卡） | 已落库 | 删代码 |
| 政策面板 UI | 已落库 | 省下"等手绘稿"的 UI 工作 |
| PolicyAI（P2，AiSmoke 21 绿） | 已落库 | AI 五线变四线，测试删减 |
| **外交义务底座**（GrantPolicyCard/Mandates/违约；MandateSmoke 68 绿） | 已落库 | **环保主义强制卡失去载体**——外交内容专题 §六 须重写为"强制事件" |
| 事件加槽 `grantPolicySlot` | 接口已有 | 事件奖励少一类 |
| 存档 `policies` 字段 | 已定 | 保留空字段兼容即可 |
| sim v23 政策验证盘 | 已有 | 作废 |

### 5.2 砍掉的收益 vs 损失
- **收益**：少一个系统（每加新系统都要给它留落点）；少 51 张卡维护；少一个 UI 面板；玩家少一层"低频切面板"负担（院长本来就定"政策卡不是玩法重点"）。
- **损失**：**"国家长期方向"失去唯一载体**——科技树是线性全解锁（没有取舍）、建筑是局部产出、事件卡是一次性、大统领特性先天不可切换。"在有限槽位里做长期取舍"这层体验没有替代品。
- 判断：**这不是数值系统冗余，而是"玩家是否需要一个可切换的国家战略层"的取舍。**

### 5.3 若砍：四条替代路径

| 路径 | 做法 | 内容损伤 | 黑机工作量 | 玩法损失 |
|---|---|---|---|---|
| **① 国策事件化** | 51 张压缩为 **10~12 条"国策提案"**，进事件卡（历史/特殊级，选择型），选了给长期效果；事件卡加"持续效果"字段 | 51→12（保留名目的精华） | 删 PolicySystem/PolicyAI/UI + 事件扩字段 ≈2~3 天 | 失去槽位取舍；强制卡改强制事件 |
| **② 并入科技树** | 政策效果挂 40 科技节点（节点改名），科技全点=政策全拿 | 51→0 | 删系统 + 重排科技效果 ≈2 天 | 无取舍，科技树变胖 |
| **③ 并入大统领特性** | 每阵营 2~3 个先天国策（不可切换） | 51→0 | 删系统 ≈1.5 天 | "国家方向"变成开局固定 |
| **④ 极简制度板** | 保留槽位/装配，砍收费/冷却/互斥/强制卡，只留"选 N 个持续效果" | 51 保留 | 中改（框架简化） | 失去防折腾与外交义务 |

|---|---|---|---|---|

| **B 国策事件化**（路径①） | 51→12 条国策提案 | 2~3 天 | 槽位取舍/外交强制卡 | ⭐⭐⭐（若院长认为机制冗余） |
| C 并入科技树（路径②） | 51→0 | 2 天 | 取舍消失 | ⭐（不推荐） |
| D 全砍（路径③） | 51→0 | 1.5 天 | 国家方向层消失 | ⭐（不推荐） |

### 5.5 建议（决策树）

```
院长核心不满 = "名字无趣"
   │
   ├─ 先做 A（改名+概念+卡面）——黑机成本≈0，1 天可见效果
   │     │
   │     ├─ 改名后觉得"政策还是有存在感" → 保留机制，数值后续填 → 收工
   │     │
   │     └─ 仍觉得"整个系统多余" → 走 B（国策事件化，2~3 天，可控）
   │
   └─ 不建议 C/D：科技树全点无取舍、全砍后"国家方向"无处安放
```

**核心理由**：院长四条指示里 3 条都在说"内容/名字"，第 4 条是"都行，评估一下"——说明对机制无强偏好。而 **A 的成本≈0、收益最大**（名字是体验第一印象），应先把这刀砍下去再看机制。
