## 三、耦合关系（为什么按这个顺序过）

```
A1 人口初值 ─┬→ A4 粮食需求 ─→ B1 建筑产出
             ├→ A3 住房承载 ─→ 宜居/增长
             ├→ A2 征募 ─→ B3 战斗/伤亡 ─→ 人口
             └→ B12 财政/税收 ─→ 建造/军队
A4 粮食 ─→ 人口/民生 ─→ 忠诚 ─→ 起义/叛乱
B1 建筑 ─→ 产出/宜居/治安/粮食/承载 ─→ 几乎一切
B11 环境 ─→ 宜居/粮产/健康 ─→ 人口/民生
B5 文化 ─→ 同化/认同/文化胜利
B6 外交 ─→ 贸易/战争/碳额度/复国
B3 战斗 ─→ 占领 ─→ A6 占领城经济 ─→ 财政/人口
```

## 四、建议过审顺序（四波）

### 第一波：城市基础盘（P0，必须先过）
A1 人口初值 → A3 居民楼 → A4 粮食三来源 → B1 建筑全量 → B12 财政/税收 → B2 城市成长/城防。
> 没有这一波，人口/粮食/产出/建造全部悬空；也是黑机 L1 城市结算骨架的前置。

### 第二波：人口↔军队↔战争（P0/P1）
A2 征募/伤亡 → B3 战斗结算 → A6 占领城经济 → A5 迁移/难民 → B11 环境接口 → B9 事件（天灾/异族/核电站）。
> 打通"人口→军队→战争→占领→人口"的闭环。

### 第三波：长线系统（P1）
B4 科技 → B5 文化 → B6 外交 → B14 胜利判定 → B8 政策。
> 决定 200 回合的胜利节奏与 AI 行为。

### 第四波：支撑层（P1/P2）
B7 武将 → A7 医疗/疾病 → A8 文化接口 → A9 王乐添剧情 → A10 胜利接口 → B10 探索 → B13 AI → B15 俘虏/NPC。

## 五、每条过审的模板（避免拍脑袋）

1. **输入**：这条公式读哪些 L0 数据/上回合状态？
2. **公式**：写成一个可执行式子（不写"视情况"）。
3. **参数**：默认值、合理区间、进 `balance.json` 的键名。
4. **耦合**：改了它，哪些量会跟着变？是否回环？增益是否 <1？
5. **手感**：玩家朴素知识能否预期？有没有唯一最优解？
6. **沙盘**：单变量 + 耦合场景各跑一遍，给出验收区间。
