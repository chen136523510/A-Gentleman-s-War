# 数值设计总纲

> 状态：🏗️ v0 骨架（R23 建议稿，数值均为**起始默认值**，一期成型后按调参协议统一微调——R6 拍板不变）
> 定位：跨模块数值的**总纲与索引**（R9 定案：数值并入各模块，本文件不替代模块数值章节，只管全局公式/常数/协议）
> 方法论依据：[数值设计方法论调研](../../00-调研/数值设计方法论调研.md)（五条核心结论）；蓝本数值：主仓三国志 12 调研 §9.6
> 更新：2026-10-25 R23

## 一、数值设计五原则（从调研落地，长期有效）

1. **体验先行**：每条公式先写「制造什么体验」再写数学（下文每个公式块首行的 *体验：* 即此）。
2. **回合本位**：一切速率以「/回」表达；回合是一期战略循环的时间单位（实时要素仅存在于二期战场内）。
3. **收放成对**：每种资源的设计必须同时列「来源-sink 对账」，只有产出没有消耗的资源不允许上线（见 §3 对账表）。
4. **成本锚本地**：建筑/维护成本锚定**该城已建规模**（边际递增，反滚雪球）；科技成本锚定全局科技数但斜率压平（文明 6 教训，见调研 §三）。
5. **明牌难度**：难度=显式参数表（§五），禁用橡皮筋暗改（蓝本调研 §9.7 同向）；群友武将的"超模"落在技能模板内，不落在四维上（四维预算制）。

## 二、时间与单位约定

| 项 | 约定 |
|---|---|
| 回合 | 一期内政战略循环单位；1 回合 ≈ 剧情上 1 个月（仅叙事用，不参与计算） |
| 兵力 | 「军力」单位=兵员数（千人计；显示层可换算），部队规模即军力分配 |
| 城防 | 0~800 点（沿蓝本数量级），百分比扣减制 |
| 采配 | 战斗内技能资源 1~10 点（一期折算为结算系数） |
| 百分比 | 公式内一律小数；文档表格用 % 需标明 |

## 四、公式体系骨架（v0）

### 4.1 经济产出（*体验：精英分配与取舍，不是挂机膨胀*）

```
每回产出(城) = Σ(区域基础产出 × 等级系数(Lv n = n^1.4，取整))
              × 逐城系数（R11 逐城定制表）
              × (1 + 太守政治/150)
              × (1 + 派驻/政策等加成之和)          ← 加法叠乘区
              − 俸禄 − 维护费（见 3.1）
生产力额外 × (1 + min(人口/2000, 0.5))            ← 人口红利封顶 +50%
```

- 区域基础产出 v0：商业中心 金100/Lv、农田 粮80/Lv、工业区 生产力15/Lv、学院 科技8/Lv、军事基地 军力上限+50/Lv、娱乐区 宜居+6/Lv（模块细表回 [03-内政/区域与建筑.md]）。
- **来源-sink 对账表**（原则 3）：金（来源：商业/掠夺/外交收入｜sink：募兵/建造/俸禄/外交/赏赐）；粮（农田｜养兵/出征/赈济）；生产力（工业/人口红利｜建造占用）；生产资料（建造产出缓慢回充 20/回｜建造消耗）；科技值（学院｜科研）。审计时逐资源两边必须非空。

### 4.2 建造成本与工期（*体验：大城市越铺越贵，扩张有自然刹车*）

```
建造成本(金/生产资料) = Base × (1 + 0.12 × 该城已建建筑数)
工期(回) = ⌈Cost_生产力量 ÷ 每回投入生产力⌉，建造期间占用生产力（R13 拆除三分法不变）
```

### 4.3 人口-宜居-民生链（*体验：铺量吃红利 vs 控规模保稳定*）

```
人口增速/回 = 基础10 × min(粮安全,1) × 宜居度/60 × 住所富余率      （任一为 0 则不增/流失）
基建成本附加 = 1 + 0.08 × (人口 ÷ 1000)                            ← 高人口负反馈（R13 取舍环定量）
民生/回 = 0.4×宜居度 + 0.2×粮安全 + 0.2×太守治理(政治/100×100) + 0.2×事件政策修正（钳 0~100）
```

### 4.4 战斗结算（一期自动档；二期手动档共用同一内核）★核心

*体验：兵力优势真实但可被"配兵正确+城防+良将"翻盘；结果可解释（战报能列出每个乘区）。*

```
阶段：野战 → 城墙（城防百分比削减）→ 市政府血条（驻留读条）

部队战力   S = 军力 N × 质量 q
           q = 兵种基础 × 装备档系数 × (1 + 科技加成) × 克制系数 × (1 + 武将统率/200) × 技能系数
军团有效战力 A/D = ΣS × 态势乘区
           攻方乘区：登陆战 ×0.85（滩头劣势）/ 掠夺专注 ×0.9 等
           守方乘区：×1.25（守家优势）× (1 + 城防剩余/1600)（城墙阶段生效）
交换（兰彻斯特平方律离散化）：
           攻方损失率 = min(1, (D/A)²)；守方损失率 = min(1, (A/D)²)
胜负：守方有效战力归零前攻方粮草回合 T 耗尽 → 守胜；城墙阶段后攻入 → 市政府血条
       = 100 × (1 − 攻方残余有效战力占比) → 驻留读条 3 回合（可被巷战反夺，R13）
全角色被俘 = 判负（先于上述判定）；带队角色被歼 → 脱身概率 1 − 敌方剩余占比（一期参数）
```

- 平方律的意义（调研 §四）：10:8 的兵力差按平方兑现≈6:0 的战果——**兵力是硬道理，但克制环/守家/城防/技能全是乘区**，配兵与选址能把 30% 兵力差翻掉。
- 二期 RTS 的部队 AI 直接复用 `√(A²−D²)` 作估值函数（调研 Win Vector 节），AI 决策不用全模拟。

### 4.5 忠诚/俸禄（*体验：稳后方是成本，叛乱是管理失败不是随机恶意*）

```
俸禄/回 = 20 × (0.8 + 四维总和/400)          ← 强者贵（蓝本"薪资 vs 产出"张力）
忠诚事件表（±）：胜仗+5/败仗−8/赏赐+10(金200)/长期空虚−3/同城幕僚+2/相性事件±…（全表回 02-武将/忠诚度.md）
```

### 4.6 科技（结构见 [03-内政/科技树.md](../03-内政/科技树.md)；此处只管成本）

```
科技成本(n) = C0 × (1 + 0.15 × 已研究数)     ← 线性压平：后期科研仍"变贵但有收益"，不与产出赛跑（文明6教训）
C0 = 80 科技值；一二期科技不共用树（一期占位少量）
```

### 4.7 外交（数值细则回 [05-外交/外交行动.md](../05-外交/外交行动.md)）

```
关系值 −100~+100（同盟门槛 +60/停战期限 24 回合/劝降需兵力优势×关系×政治综合判定——蓝本"10 倍兵力"改综合判定）
```

## 七、调参协议（"一期成型后统一微调"的流程化）

1. **单一事实源**：全局常数只改本表 §三 + 对应模块文档，两处同步；
2. **修改器直调**：全部常数走指令总线（修改器一期必做），运行时可改可存——微调即开修改器试，不必重启；
3. **变更纪律**：数值变更记入对应模块 changelog（类型=修订，注明"数值"），批量微调轮记根 changelog；
4. **审计钩子**：每资源对账表（§4.1）+ 战报乘区明细（§4.4）是数值可解释性的两条底线，实现时不得省略。
