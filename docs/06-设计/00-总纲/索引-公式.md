## 一、文化输出（✅ 完整）

**权威源**：[文化输出算法.md](../00-总纲/文化输出算法.md) · 词条：[文化输出](../../08-百科/词条/文化输出.md)

```
① 城市文化产出（v0.2 建筑卡口径）
   城文化 = (基础值 + Σ建筑文化×在岗率)
            × (1 + 0.15×宜居因子 + 0.20×人口因子 + 0.15×科技因子)
            × (传媒大学?1.10:1) × (1 − 污染惩罚0~30%)
            + 典藏陈列末端注入（不吃因子）
   宜居因子=clamp((L−50)/50,−0.5,0.5)；人口因子=min(P/50000,1)；科技因子=min(科技数/38,1)
② 国家文化存量
   Culture_t = Culture_0 + Σ[ Σ城文化产出 × (1+政策加成) ]
③ 文化压力（每对国家每回合）
   P[A→B] = √Culture_A × 距离 × 联系 × 情报 × 战争 × 势差乘区
   势差乘区 = clamp((Culture_A/Culture_B)^0.5, 1.0, 2.0)   [攻击方文化建筑 ≥1 时生效]
④ 本国自压
   P[B→B] = √Culture_B        ← 2026-11-24 院长令：抵抗概念取消（原「× (1+抵抗加成)、上限 50%」删除）
⑤ 目标份额
   Target[A→B] = P[A→B] ÷ Σ_X P[X→B]
⑥ 认同收敛（每回合）
   Identity[B:A] += 0.05 × (Target − Identity)
   本国认同兜底 ≥ 20%
⑦ 完全入侵
   Identity[B:A] ≥ 60% 持续 5 回 → 入侵；< 50% 解除
⑧ 文化失所（多极碎片）
   Identity[B:B] < 40% 且 max(外国) < 60%
   → 征兵 ×0.85 + 战斗 ×0.9 + 忠诚流水 −0.5/回（不扣文化产出）
   Identity[B:B] ≥ 45% 解除
⑨ 文化胜利
   联合国成立 → 当选常任理事国 → 全部成员国完全入侵 + 维持 10 回
```

## 二、人口与民生（✅ 11-25 补全）

**权威源**：[人口算法-v1.md](../03-内政/人口算法-v1.md) / [人口数值表.md](../03-内政/人口数值表.md) / [人口体系架构.md](../03-内政/人口体系架构.md)

```
人口增速（单一公式，原出生/死亡分列作废）：
  g = 0.008 × h × f_L × f_F × (1.5 − r)
  r=人口/承载；h=医院乘区 1.05/1.10/1.20/1.30；f_L=宜居因子；f_F=clamp(F/70,0,1)
  （承载≠自动人口：粮安 f_F、宜居 f_L 跟不上就长不动——堆承载不堆粮=空转，2026-11-25 院长裁）
粮食安全：F = 100 × clamp((Q + K) / (1.2 × D), 0, 1)
  Q=农田+牧场+食品工业+进口；D=粮需（人口+服役）；K=库存
住房分：H = 100 × (0.5 × q/100 + 0.5 × crowd)     // q=居民楼质量加权，crowd=承载率分
宜居主式：L_raw = B_L + 0.40×(H−50) + 0.20×(E−50) + 0.25×(Se−50) + 0.15×(Me−50)
                  − 0.30×本地污染 − 10×海平面等级 − 0.30×臭氧 − 0.30×核残留 + pol_L
忠诚（流量积分）：ΔLoyalty = 民生流 + 治安流 + 治理流 + 外籍流 + 占领流 + 文化流 + 驻军流 + 武将流 + 自然回流
  民生流 = −0.15×(40−W)^1.1（W<40）/ +0.15×(W−55)^0.8（W>55）
  clamp(Δ, −10, +5)
同化：2%/回 × clamp(1+1.5×(Cnat−Cavg)/Cavg, 1, 2.5)，上限 5%/回
```

## 三、城市与建筑（✅ 11-25 补全）

**权威源**：[建筑数值表.md](../03-内政/建筑数值表.md) / [消费力专题.md](../03-内政/消费力专题.md) / [居民区专题.md](../03-内政/居民区专题.md)

```
生产 = 20 × 工期
财 = 4.5 × 生产
维护 = 造价 × 1%/回（商业建筑 3%，B12 11-25 定稿）
产出/等级 = × level^1.4；升级造价 ×1.6^(Lv−1)；维护 ×(1+0.5×(Lv−1))；Lv3 封顶
城市热度 = 10 + 城文化产出×0.8 + 陈列文物×1.2 + 事件（污染/战争/占领/起义衰减）
消费池 = 民用人口/1000 × 2.5 × K_desire × (1 + 政策 + 科技)
K_desire = clamp(1 + 0.30×(在岗率−0.95) + 0.20×(宜居−50)/50
                 − 0.15×交战 − 0.10×军管 − 0.20×税负压力 − 0.15×供给危机, 0.5, 1.5)
类份额 = 池 × {零售 60% / 娱乐 25% / 文旅 15%}；缺类/吃不完按权重回流（结算一次）
本类回收 = min(本类份额剩余, 单座上限) × 在岗率；单座上限：商业街 12 / 商场 60
住宅 9 建筑（3 线×3 级）：承载线 贫民窟-城中村-密集公寓（15,000→21,000/q12→30）；均衡线 小区-洋房-大平层（5,000→8,000/q70→85）；宜居线 独栋-别墅-大庄园（2,500→4,000/q90→100）；占全 2×2、无上限、零特效；升级=承载与 q 全维递增、劣势不越界（承载≤15,000、q≤90）
```
