# 全量模拟 v20：全内容 + 多 AI 倾向（院长口径）

> 起因（院长 2026-11-11）：固定地图无地价、每城可叠建造位/按队列分产能、学院不应有上限、新建不花钱（升级/维护花钱）；全量盘 = 所有讨论内容入模 + 不同倾向 AI 正常局 + 数据分析调整。
> 脚本：`tmp/sim-full-v20.js`；数据：`tmp/sim-full-v20-BASE-{mixed,commercial,industrial,tech,military,green}-seed42.txt`；对照 v18a/v19。
> 结论先行：**机制修正后建筑量确实上来了（总建筑 373~934），但只有“从开局就绿能”的 AI 能活到 t200；商业/工业/科技/军事/混合倾向全部在 t200 前后被海平面二级淹没。** 全量内容 + 正常 AI + 存活，目前不可兼得，需要设计/AI 再调。

## 一、v20 按院长口径改了什么

| 院长口径 | v20 实现 |
|---|---|
| 固定地图，没有地块地价 | `landPrice()` 恒为 0；建造不再收地价 |
| 每城可随便叠建造位，按队列分产能 | `city.queue` 多任务队列；每回合本城生产力平均分给队列内所有任务；队列上限默认 8（AI 软上限，可调） |
| 学院为什么有上限 | v19 的硬上限在 `canBuild`：学校 2、图书馆 1、研究院 1；`candidates` 里学校 1→2、图书馆/研究院仅学院城；generic `academy` 还有 `max:1`。这些**全是模拟器 AI 保护，不在 buildings.json**。v20 已全部删除硬上限；AI 目标改为学校 4/城、图书馆 2、研究院 2、学院 2 |
| 建造不花钱，升级/维护花钱 | 新建 `costW=0`、不扣财；升级仍扣 `costW`；维护按回合扣。新增“净收入维护预算”：`maint > (收入−俸禄−军饷−装备维护)×75%` 时停止扩张/只补低维护或商业 |
| 全量内容 | `buildings.json` 126 条全部映射进 CAT（93 条 draft 用通用字段临时入模，标注 `draft`）；21 将、科技、事件、战争、环境均在盘内 |
| 不同 AI 倾向 | `AGW_PROFILE=mixed|commercial|industrial|tech|military|green`；mixed=CN 商业/JP 科技/KR 工业/AU 绿能/WLT 军事 |

## 四、建筑内容覆盖审计

| 项 | 数据 |
|---|---:|
| `buildings.json` 总条目 | 126 |
| v20 CAT 全量映射 | 126（含 93 draft 临时入模） |
| green 盘实际建造的类型 | **38 种** |
| commercial 盘实际建造的类型 | 27 种 |
| 强制覆盖盘（`AGW_COVERAGE=1`） | 47 种，且 t220 海平面 1.128m、崩溃 |

**结论**：即使把 126 条全部放进内容池，正常 AI 在维护/环境约束下也只会自然选择 27~38 种。要验证全部建筑内容，不能靠经济 AI 自然铺开，必须单独做“内容覆盖盘”（逐类强制建造/校验产出/维护/升级/电力/污染），或先定稿 93 条 draft。

## 五、对院长四点的直接回答

1. **地价**：v20 已删除，固定地图不设地价；建造 0 财。
2. **建造位**：v20 改为多任务队列，生产力平均分配给队列；不再有“每城 1 个 active”限制。
3. **学院上限**：v19 的硬上限在 `canBuild`（学校 2/图书馆 1/研究院 1）+ `candidates` 的 `schoolCap` + generic `academy max:1`；v20 已全部删除。**“哪座”= 学院 `academy`（v19 CAT 里 `max:1`），以及学校/图书馆/研究院三个旧上限。**
4. **买不起就不建造**：v19 `buildTick` 里 `if (faction.wealth < total) continue`；强制单候选时会导致整城停摆。v20 新建免费，只保留升级扣财 + 维护支出；同时加净收入维护预算，防止无限扩张。

## 六、调整建议（v21 方向）

| 优先级 | 动作 | 理由 |
|---|---|---|
| P0 | **绿能前置**：所有 AI 从 t1 起把 grn4/太阳能纳入基线，而不是温度>20 才转 | 自适应绿能太晚；非绿盘 100% 二级淹没 |
| P0 | **维护预算再校准**：按净收入 75% 已能防破产，但绿能盘 CN 仍囤 26k、KR/AU 维护贴近收入；建议按“每建筑维护/产出比”动态限速 | 免费建造后维护是唯一约束，预算太松会囤财、太紧会卡商业 |
| P1 | **商业红线分档**：绿能高密度盘下商业:税 1.07~2.60；若坚持 2.5~3.5，需要更多商业位/降低商业维护，或接受绿色经济商业占比低 | 三者（密度/商业/环境）互斥 |
| P1 | **内容覆盖盘**：单独跑 126 类强制建造，输出逐类产出/维护/电力/污染；不要用正常 AI 盘代替 | 正常盘只自然建 27~38 种 |
| P2 | **draft 定稿**：93 条 draft 目前是通用字段临时映射，数值/机制未定；定稿后再进平衡盘 | 否则“全量”只是形式入池 |

## 七、结论

- v20 机制上已经按院长口径打通：无地价、多队列、无学院硬上限、建造免费/升级维护花钱、126 条内容入池、6 种 AI 倾向、正常战争局。
- 数据结论：**建筑量不再少（375~429 常态，green 421）；但环境是全局硬约束，非绿 AI 全部在 t200 前后灭世；绿能盘存活但商业:税只有 1.07~2.60。**
- 下一步不是继续堆建筑，而是先定“环境是否允许非绿路线存活”和“商业:税是否分档”；否则全量盘只会得到“全员灭世”或“全员绿能但商业不达标”两种结果。
