# 城市成长与城防

> 状态：✅ 结构已定（R6/R11），数值待一期成型后微调

## 城市范围成长（R6 拍板，替代文明 6 槽位制）

- **区域槽位不做数量上限**：六区域+城墙可自由建造。
- **核心机制**：城市发育越好（总投入/总产出/人口代理值越高）→ **城市范围越大** → 二期战场上可布防纵深越大（城墙圈更大、防御塔位更多、市政府离城门更远）→ **被攻破难度越高**。
- 取舍不靠卡位，而靠：①资源与时间预算（生产力有限）；②武将驻守能力；③维护成本。

### 数值骨架（待定数）

```
城市发育度 Dev = f(区域总等级, 城防建设, 科技, 在城武将)
城市范围等级 Tier(Dev) → 战场半径/塔位/市政府纵深（二期映射）
破城难度 = 城防值 × 范围系数 × 守军系数
```

### Dev 到底用来干什么（2026-11-05 院长问，白机答）

**Dev = 城市发育度**，是"这座城建得多好"的单一综合分。它**不是**建造槽上限（R6 已拍板：**区域槽位不做数量上限**，六区域+城墙可自由建），也不新增资源。它的**唯一用途**是把"内政投入"翻译成"战场优势"：

| 用途 | 归属 | 说明 |
|---|---|---|
| ① 城市范围等级 Tier | **二期战场** | Dev 高 → 城墙圈更大、塔位更多、市政府离城门更远 → 被攻破更难 |
| ② 破城难度系数 | **战争专题** | `破城难度 = 城防值 × 范围系数 × 守军系数`（系数待战争专题定） |
| ③ 视觉/面板 | 表现层 | 城市面板显示"发育度"作为综合评分（可选） |

**结论（v0.1 拆分）**：
- **Dev 公式本体**（区域总等级/科技/武将 → 0~100 分）可以一期先算出来，只作综合评分与 Tier 判定；
- **Tier→战场半径/塔位/市政府纵深**是**战争专题**内容（院长令），本文只留接口；
- **城防值/破城难度**同样是**战争专题**内容；
- **没有"建造槽上限"**——旧清单里 B2 写的"建造槽"是误述，实际待定的是**防滚雪球三预案**：区域维护费随数量递增、边际产出递减、空虚/起义惩罚随规模放大（本文 §已知风险）。

## 城防

- 参照三国志 12：城防总量按百分比扣减，攻城方打到 0 才破城（原版 800 制可借鉴，自洽重设）。
- **R11 占领判定**：城防归零=城墙防线崩溃，此后**占领市政府**才完全占城（见 [04-军事/战斗总述.md](../04-军事/战斗总述.md) 胜负节；市政府锚点在 L2 城市规划中体现）。
- 城防来源：城墙等级、军事基地、巡查/驻防类机制（二期实体化后为可拆墙体/城门/箭塔）。
- 一期：城防是数值结算中的减伤/坚守回合参数；二期：同一份数据渲染为战场实体（见 [04-军事/内政战场联动.md](../04-军事/内政战场联动.md)）。

## 已知风险与平衡阀（数值期处理）

无槽位上限 → 大城建全类区域后滚雪球。预案：
1. 区域维护费随数量递增；
2. 边际产出递减；
3. 空虚/起义的惩罚随城市规模放大（R11 三态，废弃已删）；
4. AI 阵营资源系数补偿（见各难度设计，待数值专题）。
