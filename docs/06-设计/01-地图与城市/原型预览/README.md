# 地图原型预览

本目录放地图相关的**可交互 HTML 原型**（设计验证用，非正式游戏代码；**历史存档，现状以 Unity 实装与 `连通图与航线.md` 为准**）。

| 原型 | 内容 | 状态 |
|---|---|---|
| [大地图总览-v1.html](./大地图总览-v1.html) | L1 大地图首版：Natural Earth 真实地理投影 + 13 城真实经纬度定位（历史；R22 后 14 城）+ 四阵营配色 + 15 条邻接连线（历史；R26 后 17 条）；悬停城市看驻守 | 🗄️ 历史原型（v1） |

## v1 说明

- 城市点大小=驻守将数（深圳 4 将最大，单将城最小）；**首都概念已于 R22 取消**，原型中的白点为历史痕迹。
- 近邻同城群（深圳/香港、首尔/仁川）在真实坐标上几乎重合，v1 用屏幕像素错位 + 引线方位区分——**微缩地图允许视觉错位，正式版可改为聚合点展开**。
- 两条金色点线（深圳—悉尼、东京—悉尼）为 R8 待定稿；**R26 已删除**（达尔文枢纽制），现状见 [连通图与航线.md](../连通图与航线.md)。
- 底图源：world-atlas countries-110m（TopoJSON），经 d3-geo Natural Earth 投影；仅设计预览。
