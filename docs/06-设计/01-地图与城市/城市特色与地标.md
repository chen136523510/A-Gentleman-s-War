# 城市特色与地标

> 状态：✅ 已定素材持续追加中（R26：7 城补齐 7 词条，含悉尼歌剧院接文化胜利） · 效果数值待数值期 · 更新：2026-10-26 R26
> 机制：现实地标作为城市**特色词条**（每城 1~3 个），给对应区域产出加成或挂专属事件；是"每城各有特色"的落地方式。
