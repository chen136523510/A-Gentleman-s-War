## 一、设计原则

1. **意图机 = 效用 + 概率，不是条件树**：每回合枚举候选行动，算效用 U，softmax 抽样，没有 `if R>60 then 同盟`。
2. **掷骰有意义**：人格决定效用权重与温度 T；随机是"性格的表达"，不是"不可解释的噪声"。
3. **基于本国发展情景**：效用输入包含人口/财/粮/科技/军事/胜利进度，不脱离内政谈外交。
4. **玩家与 AI 同规则**：AI 之间也走"提案 → 接受判定"；玩家发起走 `外交行动.md` 成功率公式。
5. **同 seed 可复现**：RNG 由 seed 派生，日志输出 U 分解，战斗/外交战报可回放解释。
6. **不追求绝对平衡**：允许早战灭国；验收看"首场战争不锁定结局"与"行为符合人格"。

## 二、决策架构（每回合每阵营 6 步）

```
① 情景感知：本国四线进度 + 外部威胁/机会 + 关系矩阵 + 条约 + 声誉
② 路径选择：胜利路径（军事/文化/科技/经济）→ 路径系数 1.0~1.3
③ 意图生成：枚举候选行动，逐项算效用 U
④ 概率决策：p(A)=softmax(U/T)，掷骰选 1~2 个行动
⑤ 结算：AI↔AI 提案/接受判定；AI→玩家 走成功率公式
⑥ 更新：关系 R / 声誉 rep / 条约 / 记忆 memory
```

## 三、状态变量（每阵营每回合）

```js
selfState = {
  population, treasury, food, tech, armyPower,        // 发展情景
  cities, warExhaustion,                              // 战争状态
  victoryProgress: { military, culture, tech, economy }, // 四线进度 0~1
  reputation: 0~100,                                  // 声誉（公共品）
}
relations[factionId] = R (-100~100)
treaties[] = { type, partner, expireTurn, points }     // 同盟/停战/共同发兵/贸易
memory[] = { type, target, turn, weight }              // 背信/援助记忆
personality = { aggression, caution, loyalty, greed, culture, tech, economy, temperature, affinity{}, seekProtection }
```

## 四、人格参数表（大统领驱动 · 4 位默认大统领 · 首版数值，模拟标定）

> 人格**跟领袖走，不跟国家走**（11-12 第 4 条）。下表为当前地图四位默认大统领；新地图只换领袖数据。

| 参数 | 含义 | CN 丘序明 | JP 陈睿 | KR 徐浩森 | AU 马逸杰 |
|---|---|---:|---:|---:|---:|
| `aggression` | 侵略性（宣战/扩张基础权重） | 0.35 | **0.90** | 0.20 | 0.25 |
| `caution` | 谨慎（风险规避） | 0.70 | 0.30 | **0.85** | 0.75 |
| `loyalty` | 守约（履约/维持同盟） | 0.80 | 0.40 | **0.90** | 0.70 |
| `greed` | 贪婪（城/资源欲望） | 0.45 | **0.80** | 0.30 | 0.60 |
| `culture` | 文化线倾向 | 0.85 | 0.40 | **1.00** | 0.45 |
| `tech` | 科技线倾向 | 0.80 | 0.60 | 0.85 | **1.00** |
| `economy` | 经济/贸易倾向 | 0.75 | 0.55 | 0.65 | **0.90** |
| `temperature` | 决策温度（越低越果断） | 0.45 | **0.25** | 0.55 | 0.50 |

**相性 affinity（0~1，结盟/求援/接受提案的加成）**：

| 主动方 → 对象 | CN | JP | KR | AU |
|---|---:|---:|---:|---:|
| CN | — | 0.25 | 0.75 | 0.60 |
| JP | 0.20 | — | 0.40 | 0.30 |
| KR | **0.90** | 0.15 | — | 0.45 |
| AU | 0.60 | 0.30 | 0.50 | — |

- `seekProtection`：KR 徐浩森 = `{ target: "CN", weight: 0.6 }`（威胁越大，求保护效用越高）；其余 null
- **玩家选该阵营**：玩家本人即大统领，该阵营走玩家操作，AI 人格不生效
- **自立阵营（WLT 等）**：personality 从**自立武将的倾向池**读取，不写死
- **大统领死亡/被俘**：由阵营内政治最高武将继任，人格切换到继任者数据（AI 阵营）

## 五、胜利路径选择器

```
每回合（t<50 允许漂移；t≥50 每 20 回合重算）：
  progress.military = 0.6×兵力排名归一 + 0.4×城数排名归一
  progress.culture  = 文化输出排名归一
  progress.tech     = tech / 38
  progress.economy  = 0.5×国库排名归一 + 0.5×商业产出排名归一
  w_i = progress_i × personality_i        // i ∈ {military, culture, tech, economy}
  主路径 = argmax(w_i)
  victoryBias = 1.0 ~ 1.3（主路径相关行动 ×1.3，其余 ×1.0）
```

- 路径影响：建造权重（学院/文化/商业/兵工厂）、外交倾向（军事线更爱结盟打仗、经济线更爱贸易、文化线更爱和平）
- 科技线**所有国家都有**（`tech` 0.6~1.0），只是权重不同（院长 11-12 第 6 条）

## 六、效用函数（候选行动）

> 记号：`U ∈ [-1, 1+]`；所有输入归一化到 0~1；权重首版给出，模拟标定。

### 6.1 宣战（对目标 T）

```
U_war(T) = 0.30 × 城价值(T) + 0.15 × 资源价值(T)
         + 0.25 × 军事可行性(T)          // 复用 §3.6 出兵概率：pr≥1.25 才饱和
         + 0.20 × 威胁消除(T)             // 对方威胁越高，主动开战收益越大
         − 0.30 × 预期战损 × caution
         − 0.25 × 联盟介入概率(T) × caution
         − 0.15 × 声誉代价(无CB)
         + 0.20 × aggression
```

- `军事可行性 = clamp(我军有效战力 ÷ (守方城防+守军) × 0.8, 0, 1.5) / 1.5`
- `联盟介入概率 = 目标盟友数 × 0.35 × (1 − 我与盟友关系)`
- 无 CB 宣战：全阵营 R−10、rep−5（A4）
- **冷却**：停战后 10 回合内不可再宣战；战争中不可再宣战第三方（maxWars=1/国）

### 6.2 结盟（对目标 T）

```
U_ally(T) = 0.35 × 共同威胁(T) + 0.30 × affinity(T) + 0.20 × (1 − 战力比)
          − 0.25 × 被拖入战争风险 × caution
          + 0.15 × 路径修正(文化/科技线偏好和平同盟)
          + seekProtection加成（KR→CN：+0.25 × 威胁值）
```

- 门槛：R ≥ 20 才进入候选（外交行动 v0 同盟门槛 60 是"成功率"门槛，非候选门槛）
- 每类同盟限 1 盟友（院长 15 条）；期限 24 回合

### 6.3 停战（对交战方 T）

```
U_peace(T) = 0.45 × warExhaustion + 0.35 × 战损比 + 0.20 × (1 − 战果预期)
           − 0.25 × aggression
```

- 触发候选：交战 ≥ 8 回合，或本土丢城，或战损比 > 1.5
- 接受方：对方同样算 U_peace，>0.1 接受

### 6.4 劝降（对弱势 T）

```
U_surrender(T) = 0.45 × 战力优势比 + 0.25 × 声誉差 + 0.15 × 关系 + 0.15 × greed
```
- 发起门槛：战力优势比 ≥ 1.8（外交行动 v0 综合值 ≥1.0 的简化）
- 接受方判定：`(综合值−1.0)×80%` 成功率，钳 5~90%

### 6.5 破弃（对条约对象 T）

```
U_break(T) = 条约收益 − 0.40 × 声誉损失 × (1 − loyalty) − 0.30 × 关系损失
```

### 6.6 共同发兵（对伙伴 B，攻目标城 C）

```
U_joint(B) = 0.35 × 报酬价值 × greed + 0.25 × 共同威胁(C) + 0.20 × affinity(B)
           − 0.30 × 出兵成本 × caution − 0.15 × 失期风险
```
- 发起方 A 先选定要攻的城 C（军事 AI 输出），再向 B 提案
- 合同见 §八

### 6.7 资源采购（缺口资源 r）

```
U_buy(r) = 0.50 × 缺口(r) − 0.30 × 价格 × (1 − economy) − 0.20 × 关系风险
```

### 6.8 会议提案

```
U_council = 0.30 × 议程收益 + 0.20 × 声誉收益 − 0.25 × 被否决风险
```
- 低优先级：每 10 回合最多 1 次；军事制裁提案（反法西斯战争）在目标 rep<20 时 U +0.4

## 七、概率决策与执行约束

```js
// 数值稳定 softmax
const maxU = Math.max(...candidates.map(c => c.U));
const p = candidates.map(c => Math.exp((c.U - maxU) / T));
const sum = p.reduce((a, b) => a + b, 0);
// 掷骰
let x = rng() * sum;
for (const c of candidates) { x -= c.p; if (x <= 0) return c; }
```

- **每回合最多执行 2 个外交行动**（防刷屏；宣战/停战单独占 1 个）
- **冷却表**：宣战 20 回合（战争结束起算）、停战 10 回合、同盟到期可续、会议 10 回合
- **不做的事**：不因"难度"直接改 AI 数值；难度只影响玩家侧（既有 §3.5 口径）

## 八、结算层（与玩家共用）

### 8.1 AI↔AI 提案/接受

```
对方接受 iff U_accept(T) = 收益 + 关系收益 + 安全收益 − 风险 − 机会成本 > 0.10
拒绝 → 记录模板理由（关系不足/收益不够/与你共同敌人过多/兵力不足）
```

### 8.2 共同发兵合同

```js
jointWarContract = {
  initiator, partner, targetCity, targetFaction,
  deadlineTurn,      // 约定回合（默认 5~10 回合内）
  minTroops,         // 带兵不少于 X
  reward: { treasury?, resource?, amount? },
  status: 'pending' | 'fulfilled' | 'broken'
}
```
- 履约：截至 deadlineTurn，伙伴部队抵达目标城下且 ≥ minTroops
- 攻占成功 → 城归发起方；伙伴拿报酬
- **失期**：R−10、rep−3；**攻占失败**：不扣 R，合同失效、无报酬（院长 11-12 第 2 条）
- 总攻各自操作（L3 多阵营部队同场，无统一指挥）

### 8.3 联盟参战（军事同盟）

- 防御性战争（成员被宣战）→ **全体自动参战**
- 主动宣战 → 其他成员**可选不参战**，不参战扣同盟点数 −20、**不扣声誉**（院长 15 条）
- 同盟 4 类 × 3 级（军事/经济/科研/文化），每类限 1 盟友，期限 24 回合

## 九、关系与声誉更新（每回合结算）

```
R 自然回归：R += (0 − R) × 0.01                     // 缓慢回中，防永久极端
R 事件增量：外交行动.md 事件表 + A4（掠夺/处决/破弃/无CB宣战）
rep 0~100：履约 +2/回、共同防御参战 +5、释放俘虏 +3、击退异族 +5
         破弃 −20、处决 −3/人、掠夺 −5（L3 布尔）、无CB宣战 −5、核武 −15/−100
rep < 30：他国对其宣战门槛 −20%、结盟门槛 −10%（平滑，非翻倍）
rep < 20：可被发起"军事制裁"（全球安全型会议）→ 通过后全阵营获合法战争 CB，持续 12 回合
memory[]：背信/援助记录，50 回合半衰；对背信者 R 恢复速度 ×0.5
```

## 十、数据结构（落库）

**人格挂在领袖上**（11-12 第 4 条）：

`officers.json` 大统领记录新增 `aiPersonality`：

```json
{
  "id": "chenrui", "name": "陈睿", "faction": "JP", "isLeader": true,
  "governance": "military",
  "aiPersonality": {
    "aggression": 0.90, "caution": 0.30, "loyalty": 0.40, "greed": 0.80,
    "culture": 0.40, "tech": 0.60, "economy": 0.55,
    "temperature": 0.25,
    "affinity": { "CN": 0.20, "KR": 0.40, "AU": 0.30 },
    "seekProtection": null
  }
}
```

- `governance`：治国路线（`military` / `culture` / `tech` / `commerce`），由大统领相性推导、手写定值；影响胜利路径选择器的人格权重
- 当前四统领：丘序明 `culture`、陈睿 `military`、徐浩森 `culture`、马逸杰 `commerce`（tech 权重靠人格参数）

`factions.json` 只引用领袖，不再内联人格：

```json
{ "id": "JP", "leaderId": "chenrui" }
```

- 新地图/新阵营：加 `leader + faction` 数据即可，不改规则代码（R49）
- 自立阵营：`leaderId` = 自立武将 id（其 `aiPersonality` 由倾向池生成或手写）
- 玩家阵营：`leaderId` 存在但人格不生效（玩家操作）
- 大统领继任：AI 阵营自动切到继任者 `aiPersonality`

`balance.json` 新增 `diploAI`：

```json
{
  "actionPerTurn": 2, "warCooldown": 20, "peaceCooldown": 10, "councilCooldown": 10,
  "allyMinRelation": 20, "allyTerm": 24, "peaceTerm": 12,
  "acceptThreshold": 0.10, "victoryBias": 1.3,
  "weights": { "war": {...}, "ally": {...}, "peace": {...} }
}
```

- 存档：`memory[]` / `reputation` / `treaties[]` 可缺省（默认 0/50/空），未知字段保留
- 人格缺失（旧档/新领袖未配）：回退到 `defaultPersonality`（aggression 0.5/caution 0.5/…）

## 十四、模拟接入修正（2026-11-12 首跑后回写）

> 首轮接入 `full.js` 时按实测修正 5 处，**均已验证**（见 [A1 验证报告](../00-总纲/全量模拟-v22-外交A1验证.md)）。

| # | 修正 | 原因 |
|---|---|---|
| 1 | **外交决策用"动员潜力"**（人口×10%），不用当前士兵 | 战争动员 10% vs 和平 0.5%，直接比会误判强者不可战胜 |
| 2 | **同盟可多成员**（不限每类 1 盟友）；U 随已有盟友数递减 | 每类 1 盟友导致 CN 只能保护 KR、AU 无保护必被灭 |
| 3 | **行动顺序每回合随机 + 全图上限 2 个** | 固定顺序时第一个阵营垄断行动权 |
| 4 | **劝降严格化**：目标仅剩 1 城 + 潜力比≥2.5 + 无盟友保护 + 接受判定 + 失败冷却 5 回 | 原条件开局就能劝降全图 |
| 5 | **同盟到期自动续约**（关系≥−50，静默不占行动） | 每 24 回合重签占满行动并刷屏 |

**首跑结论**：确定性 ✅｜联盟防御 ✅｜弱国求保护 ✅｜主路径分化 ✅｜全活率 1/5（❌ 待包围网）｜CN 滚雪球未解（BUG-G011）。
