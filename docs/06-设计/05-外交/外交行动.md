## 数值细则 v0（R23 补，挂 [00-总纲/数值设计总纲.md](../00-总纲/数值设计总纲.md) §4.7）

*体验：外交是"算得清的谈判"，不是抽卡；AI 拒绝要说得出理由（模板话术引用数字）。*

```
关系值 R：−100 ~ +100（初始 0；同阵营自动 +30 不存在——阵营即玩家，四阵营互为对手）
  事件增量：共同敌人交战 +10/次｜贸易协定 +3/回｜破弃 −40｜掠夺其城 −25｜俘虏处决 −30｜共同防御期 +20

成功率 = 基础值 + 关系修正 + 筹码修正 + 属性修正（钳 5%~95%，大额行动显概率给玩家）
  同盟（+60 门槛）：基础 20% + R×0.5% + 筹码(每 500 金 +5%，上限 +25%) + 使者政治×0.3%
  停战：基础 40% + R×0.4% + 筹码（双方均疲惫期 +15%——按近期战损判定）
  劝降：兵力优势比 × 政治系数 × 关系系数 三项连乘 ≥ 1.0 才可发起（替代原版"10 倍兵力"）；
        成功率 = (综合值 − 1.0) × 80%，钳 5~90%
  共同军/共同防御：需同盟关系（R ≥ 60）；AI 参战意愿 = 威胁评分（蓝本 §9.2 军事 AI 同公式）
  破弃：无成功率（主动行为）；代价 = 声望 −20 + 受害方 R = −40 + 全阵营关系 −15

AI 接受逻辑（与内政/军事 AI 同源，边际收益框架）：接受 iff（关系收益 + 资源收益 + 安全收益）> 阈值(难度参数)
  ——每个拒绝必须输出模板理由（"关系不足/筹码不够/与你共同敌人过多"），战报可解释性同款纪律
```

- 声望（新概念，外交子资源）：0~100，全阵营可见；来源：击退异族/履约/不掠夺；消耗：破弃/处决/掠夺。劝降与同盟门槛隐性消费声望 ≥20。
- 自立新阵营（WLT 等）：初始声望 10、关系全 −20（"叛徒debuff"）；可被讨伐/招降/联盟——招降=变相劝降公式（对其声望要求 ×0.5）。
- 二期战俘交换：俘虏筹码化（每俘虏 = 筹码修正 +8%），接 [02-武将/俘虏与处置.md](../02-武将/俘虏与处置.md)。
