## 一、上层履约架构（院长裁 1）

**提案类型 → 对应义务卡**，一套通用架构覆盖所有"通过后要挂卡"的提案：

| 提案类型 | 义务卡 | 义务期（建议） | 违约 CB |
|---|---|---|---|
| 环保提案（碳配额/环保合作） | **环保主义卡** | 15 回合（院长举例值） | **无** |
| 裁军提案（削军/服役率上限） | **裁军卡** | 待内容专题（建议 15~20 回合） | **有** |
| 核提案（去核化/禁核） | **去核化卡** | 待内容专题（建议 20 回合） | 待内容专题配置 |
| 未来新提案 | 新增映射行（数据） | 提案数据配置 | 提案数据配置 |

- **义务（Mandate）是通用附加标记**，不是特殊卡类型：卡本身是普通政策卡（有效果、占槽、收费、可自愿装）；`mandatory` 只表示"被提案强制要求挂着"。
- 数据落点：提案/UN 议程数据 `grants:[{cardId, durationTurn}]` + `violation:{rep, relProposer, relAgree, cb:bool}`；新增提案只加数据行，不改规则代码。

## 二、生命周期与收费（院长裁 2/3/4/5/6/7）

```
提案通过（当回合）→ 发卡（授予免费，进"待挂义务"）→ 义务期 durationTurn 回合
   └ 义务期内每回合结算检查：挂着 → OK；未挂 → 违约
   └ 义务期满 → 可卸下，也可继续装着（不违约）
```

| 项 | 规则 |
|---|---|
| **无宽限期** | 不设"通过→首挂"缓冲；**义务期内每个回合结算都必须挂着**（首检查点=通过回合结算；玩家在结算前装卡/腾槽） |
| **装卡收费** | **100 财/张**（政策发布与执行成本；卡面=政策结果；义务卡同样收；装一次收一次，义务期内维持不再收费） |
| **改动收费（11-19 优化）** | 槽位**冷却期内**改动政策（卸/换）**100 财/次**；**冷却期满后改动 0 财**——限制短期频繁折腾、鼓励长期调整（冷却期定义沿用：装卡后至 `slotUnlockDelay=2` 回合） |
| **占槽** | 义务卡占对应色槽（五槽 2/2/2/2/2）；槽满必须先卸一张（卸卡规则同上：冷却期内 100 / 冷却期外 0） |
| **锁定** | 义务期内不可卸；卸=违约（二次确认，列明代价） |
| **拒收** | 不设（通过前可投反对；通过后只能履约或违约） |
| **负财政** | **财政为负的阵营不接受带义务提案**：AI 表决自动反对/弃权；玩家负财时"接受/同意"置灰并提示（穷国优先发展，不参与治理类义务） |
| **到期** | 义务期满自动解除，可卸可留，不违约 |

> 收费规则**同步回写** [政策卡架构](../00-总纲/政策卡架构.md) v0.5 / [政策卡目录](../00-总纲/政策卡目录.md) / [政策卡内容专题](../00-总纲/政策卡内容专题.md)（装卡 100 不变；冷却=收费窗口）。待确认二义见 §十一.1。

## 三、违约认定（院长裁 2：违约=撕毁统一）

| 情形 | 是否违约 | 判定时点 |
|---|---|---|
| 义务期内某回合结算时未挂 | ✅ 违约 | 回合结算 |
| 义务期内主动卸卡（原"撕毁"，统一称**违约**） | ✅ 违约 | 立即 |
| 义务期满后卸卡 | ❌ | — |
| 拒收 | 不设此选项 | — |

- 不区分"违约/撕毁"——统一为违约（同一概念、同一后果组）。
- 违约后义务不消失：义务期内任意时刻补挂 = **补救**，恢复履约状态。

## 四、违约状态与后果（趋势数值白机定；CB 按提案配置）

**违约状态**：从违约判定起，持续到「补挂（补救）」或「义务期满」为止。

| 项 | 规则/数值 | 说明 |
|---|---|---|
| 国际声誉 rep | **−3** | 参照：宣战 rep−5、拒绝法案不扣 rep——违约轻于宣战、重于拒绝 |
| 关系（发起方） | **−15** | 拒绝法案 −5 的 3 倍；"拒签 < 违约" |
| 关系（同意方） | **−8** | 略轻于发起方 |
| 合法 CB | **按提案配置**：裁军提案=**授予**（发起方+同意方）；**环保提案=不授予**；未来提案逐个配置。**仅违约状态期间可发起**；违约状态解除即失效；已发起的战争不撤销 | "每个提案的后果不是都有 CB" |
| 累进（额外机制） | 同一方 100 回合内第 2 次违约 ×1.5、第 3 次起 ×2 封顶 | 防惯犯 |
| 补救（额外机制） | 义务期内补挂 → 解除违约状态；**已扣 rep/关系不退**；未发起的 CB 不能再发起 | 给回头路，不给刷分 |

- 三级语义：**拒签（关系 −5，轻）< 违约（rep−3/关系 −15/−8 + 按提案 CB，重）**。
- 违约不自动触发 UN 制裁会议（防链式失控）；发起方可手动提案走既有制裁流程。

## 五、AI 决策（无信相性 + 多义务权衡）

- **人格位 `perfidy`（无信/背信倾向，0~1，`officers.json aiPersonality` 扩展）**：越高越倾向违约。U 比较沿用 [AI政策细则](../00-总纲/AI政策细则.md) §3.2：
  - `U(履约) = gain(卡) − 挂卡 100 财 − 违约惩罚折算 × (1 + caution)`
  - `U(违约) = −违约代价 × (1 − perfidy)`
  - 有"无信"相性的 NPC 领导阵营**会主动选择违约**（设计意图）。
- **负财政投票**：带义务提案表决时，财政为负的 AI **自动反对/弃权**（不接义务）。
- **多义务叠加不特殊处理**：义务按提案独立记录；同 `cardId` 的多条义务由同一张卡自然同时满足；不同 `cardId` 冲突（同色超槽容量）时，由玩家/AI 在**表决阶段**自行取舍——**该拒绝就拒绝**（不设系统合并/溢出规则）。
- 节拍：义务期内每回合重算；首个检查点强制拍板（无宽限）；义务期外可自愿保留。
- 日志：`mandate.recv / mandate.eval / mandate.fulfill / mandate.default / mandate.repair`。
- 参数：`balance.ai.policy.mandateCaution`（既有）、`perfidyWeight`（建议 1.0）。

## 六、环保主义卡卡面（院长裁 8 + v0.3 修正）

| 效果 | 类型 | 落点/口径 |
|---|---|---|
| **无法新增和升级有污染的建筑** | `switch` | 建造/升级候选过滤：`buildings.json` 污染字段 >0 的卡（含升级链）不可新建、不可升级；已建成的保留 |
| **有污染的建筑产出下降 30%** | `mult` 0.7 | **建筑全部产出值** ×0.7（不区分主/副产出） |
| **全国城市宜居度 +5** | `bias` | 固定 **+5**（0-100 制；数值期可调） |

- 义务期 **15 回合**（院长举例）。
- 卡在 `policies.json` 为普通卡（属性/卡色按内容专题归类）；可自愿装；被提案发放时带 `mandatory`。
- 数据待黑机核：`buildings.json` 污染字段名/口径（`role=environment` 治理类不算"有污染"；判定与 `env` 结算一致）。
- 与既有环境系统：`env.carbonQuota`（配额法案）/`env.unGreen`（A1.6 环保合作）不冲突——环保卡是"政策结果"，配额/公平分摊是"法案数值"，叠加结算。

## 九、N 阵营与剧本裁剪

- 零阵营特判；无 UN 局：UN 议程来源缺席 → 机制自然降级；双边提案发卡为扩展点（数据配置）。
- 单城/内战局：无外交义务来源，机制静默；教学局默认不插入强制卡步骤。
- 2/4/7/8 阵营 smoke 必过；`durationTurn` 可 per-proposal 覆写。

## 十、验收

1. **履约全链**：提案通过→发卡→义务期内挂着→期满可卸可留；未挂→违约→声誉/关系/CB（按提案）全生效；卸卡=违约；补挂→违约状态解除、数值不退、CB 失效。
2. **收费与冷却**：装卡 100；冷却期内卸/换 100；冷却期外卸/换 0；义务卡腾槽遵循同规则。
3. **负财政**：负财 AI 对义务提案投反对/弃权；玩家负财时接受置灰。
4. **环保卡**：污染建筑禁新建/禁升级；已有污染建筑全部产出 ×0.7；全国宜居 +5；期满可卸。
5. **AI**：无信人格会违约；多义务冲突自行取舍；U 日志可查；同 seed 确定性。
6. **模拟盘**：v25 违约剧本盘（UN 环保提案通过 → 无信 AI 违约 → 关系演化/补救样本；裁军提案违约触发 CB）；报告单列。
7. **N 阵营 smoke**：2/4/7/8 通过。
