# 外交内容专题 v0.1（强制卡违约细则 · 2026-11-19 白机）

> 定位：B4.1（[B 组交接](../../04-技术笔记/B组交接-2026-11-18.md) §五 4.1）——**外交强制卡违约细则**。填两处留白：[政策卡架构](../00-总纲/政策卡架构.md) §7.2（"违约判定时点/惩罚/能否卸后续专题"）与 [政策与政体](../00-总纲/政策与政体.md) §四；并统一 [外交行动](./外交行动.md) 联合国会议系统的"撕毁法案"口径（声望 −X 待定）。
> 边界：本专题只定义**义务生命周期 / 违约认定 / 违约后果 / 数据接口 / AI 决策位**。**提案内容清单**（谁在什么会议发什么卡）归外交内容后续与 UN 议程数据；数值为建议值，属"基础数值当前可调"（一期成型后冻结）。
> 上游已定口径（不动）：[政策卡架构](../00-总纲/政策卡架构.md) §7.2（mandatory/不挂=违约/`grantPolicyCard`/UI 提示/存档 `mandates`）· [政策卡目录](../00-总纲/政策卡目录.md) v0.4 · [政策卡内容专题](../00-总纲/政策卡内容专题.md) §九.8（配额法案走 UN 环保提案发卡 mandatory）· [AI政策细则](../00-总纲/AI政策细则.md) §3.2（履约/违约二选一 + `mandateCaution`）· [外交行动](./外交行动.md)（法案通过/拒绝/撕毁三态 + 三案表决）。

## 一、核心模型：义务（Mandate）是本体，强制卡是载体

**裁定建议**：把"UN 法案履约"与"政策卡强制卡"统一为一个生命周期——**提案通过产生义务，强制卡是义务的可见执行载体**。

```
提案/法案通过（发起来源）
   ↓ 产生
义务 Mandate { cardId, source, deadlineTurn, durationTurn? }
   ↓ 执行载体
强制卡（mandatory，装卡=履约中；卸卡=撕毁）
   ↓ 结束
到期自动解除（不违约） / 违约（未挂满 或 撕毁）
```

- **不采用双层模型**（法案效果一套、卡只是 UI 标记）——两层状态易漂移，且"占槽=代价"的卡设计会失效。
- **撕毁法案 = 履约中卸下强制卡**：既有 [外交行动](./外交行动.md) 的"先同意后违约→声望 −X"由本模型统一承载（见 §五）。
- 义务的所有数值（宽限/惩罚/CB）走参数，剧本可覆写；阵营数/turn 无关。

## 二、发卡与生命周期（状态机）

| 阶段 | 时点 | 规则 |
|---|---|---|
| **发放** | 提案通过**当回合** | `grantPolicyCard(f, cardId, { mandatory:true, source, deadlineTurn })`；卡进"待挂义务"列表；**发卡免费**（义务不收费，见裁点 2） |
| **待挂（窗口）** | 通过回合 ~ deadline | `deadlineTurn = 通过回合 + graceTurn`（默认 5）；窗口内任意回合可装；HUD 倒计时提示 |
| **履约中** | 装卡后 ~ 到期 | 卡**锁定**（不可常规卸下；卸卡走撕毁二次确认）；效果正常结算；占对应色槽（见裁点 3） |
| **到期解除** | `durationTurn` 到达或法案撤销 | **自动卸下，不违约**、不扣关系；卸下免费 |
| **违约** | 见 §四 | 后果见 §五 |

- 槽位处理：同槽已有卡 → 先卸（卸卡免费，现有规则）；**槽满时腾槽是玩家义务，不豁免**（AI 同规则）。
- 若同一声明对某国发多张卡（罕见，数据控制）：各自独立 deadline，义务并行。

## 三、违约认定（四态，二违二不违）

| # | 情形 | 是否违约 | 判定时点 | 说明 |
|---|---|---|---|---|
| 1 | **未挂**：deadline 到达仍未装 | ✅ 违约 | 回合结算 | 主路径；UI 在 deadline 前 1 回合红字警告 |
| 2 | **撕毁**：履约中主动卸卡 | ✅ 违约 | 立即 | 二次确认（列明代价）；与 [外交行动](./外交行动.md)"撕毁法案"同一事件 |
| 3 | **拒收**：提案通过时拒绝接收卡 | ❌ 不设此选项 | — | 建议**不提供拒收**——要拒就"挂了再撕"或到期，语义清晰（简化，裁点 5） |
| 4 | **到期**：法案到期自动卸 | ❌ 不违约 | 自动 | 义务已尽 |

- 边界：**槽位不足不构成免责**；战争中被占城导致卡失效（如有）按数据配置处理，默认不豁免。
- 违约方身份是否被灭国/复国：**复国国不继承旧法案**（既有 R40c 口径）；违约记录保留（数据口径）。

## 四、违约后果（建议值，数值期可调）

| 项 | 建议值 | 与既有口径对照 |
|---|---|---|
| 国际声誉 rep | **−8**（全局） | [外交行动](./外交行动.md) 撕毁法案"声望 −X 待定"；拒签仅关系 −5 |
| 关系 | **发起方 −20 / 同意方 −10** | 拒绝法案"与发起国 −5"——违约应显著重于拒绝 |
| 合法 CB | 发起方 + 所有同意方获得对违约方**合法宣战理由 12 回合** | 沿用既有 CB 机制（如侵略 CB 12 回合） |
| 记录 | 世界会议面板可查违约清单；外交面板违约方标签 | 新表，见 §八 |
| 累进 | 同一方 **100 回合内第 2 次违约 ×1.5**（rep/关系），第 3 次起封顶 ×2 | 防惯犯刷违约 |
| 补挂救济 | 违约后 **3 回合内**补挂 → 恢复"履约中"，**已扣惩罚不退**；CB 保留至到期 | 给回头的路，不给刷分 |

- 拒绝 vs 违约 vs 撕毁 三级语义：**拒签（−5，轻）< 违约/撕毁（−20/−8 rep，重+CB）**。
- 违约不触发 UN 自动制裁会议（避免链式惩罚失控；如需要由发起方手动提案，走既有制裁流程）。

## 五、AI 决策接入（政策线，P2）

- 位置：[AI政策细则](../00-总纲/AI政策细则.md) §3.2 已留决策位——`U(履约) = gain(卡) − 违约惩罚折算 × (1 + caution)` vs `U(违约) = −违约代价`。
- 本专题补三条节拍规则：
  1. **deadline 前 1 回合强制拍板**（不允许"拖过期"式默认违约）；
  2. 待挂期内 AI 每回合重算一次（卡收益可能随局势变化）；
  3. 履约后进入锁定，AI 不可撕毁（**AI 一律不主动撕毁**——人格上无"背信"表达，简化；如院长要求战争型 AI 可撕，加 `allowRip` 人格位）。
- 日志事件：`mandate.recv / mandate.eval / mandate.fulfill / mandate.default / mandate.rip`，`U` 分解字段同骨架⑥。
- 参数：`balance.ai.policy.mandateCaution`（已定 1.0）、`ripPenaltyWeight`、`deadlineEvalAhead=1`。

## 六、UI / 提示

- **政策面板**：强制卡红标"提案义务"，卡面倒计时；槽位锁定角标；卸卡按钮→二次确认（写明 rep/关系/CB 后果）。
- **HUD 顶部**：义务提醒条（来源提案名/剩余回合/到期回合）。
- **世界会议面板**：违约记录 tab（违约方/事由/回合/惩罚），复用于 AI 关系记忆展示。
- 教程锚点：架构已有"首次收到强制卡"锚点——教学局是否真发卡留教学专题定（本专题只保证规则可运行）。

## 八、N 阵营与剧本裁剪

- 候选/判定零阵营特判；无 UN 局：UN 议程来源缺席 → 机制自然降级；双边提案发卡为**扩展点**（数据配置，不改规则）。
- 单城/内战局：无外交义务来源，机制静默；教学局默认不插入强制卡步骤。
- 2/4/7/8 阵营 smoke 必过；`graceTurn/cbTurns` 可 per-scenario 覆写。

## 九、验收

1. **规则全链**：通过提案→发卡→挂卡（履约）→到期自动卸（不违约）；到期前卸卡（撕毁）→rep/关系/CB 全生效；不挂过期→违约全生效。
2. **边界**：槽满腾槽；补挂救济（3 回合内恢复履约、惩罚不退）；累进（100 回合内二次 ×1.5）；旧档缺省。
3. **AI**：deadline 前 1 回合必拍板；零 `pr` 无关；U 日志可查；同 seed 确定性。
4. **模拟盘**：v25 违约剧本盘（UN 环保提案全票通过 → 2 阵营故意违约 → 观察 CB 使用/关系演化/无链式失控），或并入 v24.1；报告单列。
5. **N 阵营 smoke**：2/4/7/8 通过。
