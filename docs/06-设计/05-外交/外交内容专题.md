# 外交内容专题 v0.2（强制卡履约细则 · 2026-11-19）

> 状态：v0.1 开题（11-19）→ **v0.2 按院长 11-19 九条裁决重写**。核心变化：上层履约架构多提案通用；挂卡收费；义务卡占槽；**不设宽限期**（义务期=提案通过后 N 回合必须挂满）；违约=撕毁统一；数值白机定；无信相性 NPC；环保主义卡卡面落档。
> 定位：B4.1（[B 组交接](../../04-技术笔记/B组交接-2026-11-18.md) §五 4.1）——填 [政策卡架构](../00-总纲/政策卡架构.md) §7.2 与 [政策与政体](../00-总纲/政策与政体.md) §四留白，统一 [外交行动](./外交行动.md)"撕毁法案"口径。
> 边界：本专题只定义**义务生命周期 / 违约认定 / 违约后果 / 数据接口 / AI 决策位 / 首批卡面**。提案内容清单（谁在什么会议发什么卡）随外交内容后续与 UN 议程数据；数值为白机定值（基础数值当前可调，一期成型后冻结）。

## 一、上层履约架构（院长裁 1）

**提案类型 → 对应义务卡**，一套通用架构覆盖所有"通过后要挂卡"的提案：

| 提案类型 | 义务卡 | 义务期（建议） |
|---|---|---|
| 环保提案（碳配额/环保合作） | **环保主义卡** | 15 回合（院长举例值） |
| 裁军提案（削军/服役率上限） | **裁军卡** | 待内容专题（建议 15~20 回合） |
| 核提案（去核化/禁核） | **去核化卡** | 待内容专题（建议 20 回合） |
| 未来新提案 | 新增映射行（数据） | 提案数据配置 |

- **义务（Mandate）是通用附加标记**，不是特殊卡类型：卡本身是普通政策卡（有效果、占槽、收费、可自愿装）；`mandatory` 只表示"被提案强制要求挂着"。
- 数据落点：提案/UN 议程数据 `grants:[{cardId, durationTurn}]`；新增提案只加数据行，不改规则代码。

## 二、生命周期（院长裁 4/5/6/7）

```
提案通过（当回合）→ 发卡（授予免费，进"待挂义务"）→ 义务期 durationTurn 回合
   └ 义务期内每回合结算检查：挂着 → OK；未挂 → 违约
   └ 义务期满 → 可卸下，也可继续装着（不违约）
```

| 项 | 规则 |
|---|---|
| **无宽限期** | 不设"通过→首挂"的缓冲时间；**义务期内每个回合结算都必须挂着**（首检查点=通过回合结算；玩家在结算前装卡/腾槽） |
| **挂卡收费** | 100 财/张（**政策发布与执行成本**，卡面内容是政策结果——任何政策都有成本）；义务卡同样收 |
| **占槽** | 义务卡占对应色槽（五槽 2/2/2/2/2）；槽满必须先卸一张（卸卡免费） |
| **锁定** | 义务期内不可卸；卸=违约（二次确认，列明代价） |
| **拒收** | 不设（通过前可投反对；通过后只能履约或违约） |
| **到期** | 义务期满自动解除，可卸可留，不违约 |

## 三、违约认定（院长裁 2：违约=撕毁统一）

| 情形 | 是否违约 | 判定时点 |
|---|---|---|
| 义务期内某回合结算时未挂 | ✅ 违约 | 回合结算 |
| 义务期内主动卸卡（原"撕毁"，统一称**违约**） | ✅ 违约 | 立即 |
| 义务期满后卸卡 | ❌ | — |
| 拒收 | 不设此选项 | — |

- 不再区分"违约/撕毁"两个术语——**统一为违约**（同一概念、同一后果组）。
- 违约后义务并未消失：义务期内任意时刻补挂 = **补救**（恢复履约状态），见 §四。

## 四、违约状态与后果（院长裁 2；数值白机定）

**违约状态**：从违约判定起，持续到「补挂（补救）」或「义务期满」为止。**合法 CB 仅违约状态期间可发起**。

| 项 | 数值（白机定） | 说明 |
|---|---|---|
| 国际声誉 rep | **−3** | 参照既有：宣战 rep−5、拒绝法案不扣 rep——违约轻于宣战、重于拒绝 |
| 关系（发起方） | **−15** | 拒绝法案 −5 的 3 倍；"拒签 < 违约" |
| 关系（同意方） | **−8** | 略轻于发起方 |
| 合法 CB | **仅违约状态期间可发起**（对违约方宣战不额外扣 rep） | 违约状态随补救或期满解除 → CB 失效；已发起的战争不撤销 |
| 累进（额外机制） | 同一方 100 回合内第 2 次违约 ×1.5、第 3 次起 ×2 封顶 | 防惯犯 |
| 补救（额外机制） | 义务期内补挂 → 解除违约状态；**已扣 rep/关系不退**；CB 未发起的不能再发起 | 给回头路，不给刷分 |

- 三级语义：**拒签（关系 −5，轻）< 违约（rep−3/关系 −15/−8 + CB 窗口，重）**。
- 违约不自动触发 UN 制裁会议（防链式失控）；发起方可手动提案走既有制裁流程。

## 五、AI 决策（院长裁 3：无信相性）

- **人格位 `perfidy`（无信/背信倾向，0~1，`officers.json aiPersonality` 扩展）**：越高越倾向违约。U 比较沿用 [AI政策细则](../00-总纲/AI政策细则.md) §3.2：
  - `U(履约) = gain(卡) − 挂卡 100 财** − 违约惩罚折算 × (1 + caution)`
  - `U(违约) = −违约代价 × (1 − perfidy)`（无信者低估代价）
- 有"无信"相性的 NPC 领导阵营**会主动选择违约**（设计意图：外交世界里必须存在背信者）。
- 节拍：义务期内每回合重算；**首个检查点强制拍板**（无宽限）；已履约后可在义务期外自愿保留。
- 日志：`mandate.recv / mandate.eval / mandate.fulfill / mandate.default / mandate.repair`，U 分解同骨架⑥。
- 参数：`balance.ai.policy.mandateCaution`（既有）、`perfidyWeight`（建议 1.0，可调）。

## 六、环保主义卡卡面（院长裁 8）

| 效果 | 类型 | 落点/口径 |
|---|---|---|
| **无法新增和升级有污染的建筑** | `switch` | 建造/升级候选过滤：`buildings.json` 污染字段 >0 的卡（含升级链）不可新建、不可升级；已建成的保留 |
| **有污染的建筑产出下降 30%** | `mult` 0.7 | 建筑全部产出值 ×0.7（产出量纲与 sim/Unity 结算同源） |
| **全国城市宜居度 +** | `bias` | 建议 **+2**（固定值，0-100 制；数值期可调，院长可改） |

- 义务期 **15 回合**（院长举例）。
- 卡在 `policies.json` 为普通卡（属性/卡色=通用或外交，按内容专题归类）；可自愿装；被提案发放时带 `mandatory`。
- 数据待黑机核：`buildings.json` 污染字段名/口径（`role=environment` 治理类不算"有污染"；判定需与 `env` 结算一致）。
- 落点与既有环境系统：`env.carbonQuota`（配额法案）/排放乘区（A1.6 `env.unGreen`）不冲突——环保卡是"政策结果"，配额/公平分摊是"法案数值"，两者叠加结算。

## 九、N 阵营与剧本裁剪

- 零阵营特判；无 UN 局：UN 议程来源缺席 → 机制自然降级；双边提案发卡为扩展点（数据配置）。
- 单城/内战局：无外交义务来源，机制静默；教学局默认不插入强制卡步骤。
- 2/4/7/8 阵营 smoke 必过；`durationTurn` 可 per-proposal 覆写。

## 十、验收

1. **履约全链**：提案通过→发卡→义务期内挂着→期满可卸可留；未挂→违约→声誉/关系/CB 全生效；卸卡=违约；补挂→违约状态解除、数值不退、CB 失效。
2. **收费与槽**：义务卡挂卡扣 100 财；槽满腾槽后可挂；同一卡多义务合并（见 §十一.3）。
3. **环保卡**：污染建筑禁新建/禁升级；已有污染建筑产出 ×0.7；全国宜居 +2；期满可卸。
4. **AI**：无信人格会违约；首个检查点必拍板；U 日志可查；同 seed 确定性。
5. **模拟盘**：v25 违约剧本盘（UN 环保提案通过 → 无信 AI 违约 → CB/关系演化/补救样本）；报告单列。
6. **N 阵营 smoke**：2/4/7/8 通过。

## 十一、待院长确认（白机提出的 6 个实现问题）

| # | 问题 | 白机建议 |
|---|---|---|
| 1 | **穷国付费**：义务期 15 回合 × 100 财，AU 这类基线赤字国可能付不起 | 允许**负国库挂卡**（既有负库存量口径），不因财政违约；否则"穷=必违约"荒诞 |
| 2 | **槽位冷却冲突**：既有 t1-t2-t3 冷却（装卡后 2 回合冻结）vs"义务期必须立刻挂着" | 义务卡安装/腾槽**豁免槽位冷却**（义务优先） |
| 3 | **多义务叠加**：同类（同色）义务卡超过槽容量 2 张时怎么办 | 同一 `cardId` 的多条义务**合并为一条**（来源列表保留、期限取最长）；不同卡同色超容量时，后通过的义务仍需履约（玩家必须取舍，挤掉哪张自己定） |
| 4 | **"产出下降 30%"口径**：建筑全部产出 vs 主产出 | 全部产出值 ×0.7（与结算同口径，避免歧义） |
| 5 | **宜居 +** 的量纲/数值 | 固定 **+2**（0-100 制）；院长可改 |
| 6 | **"违约状态期间 CB"**：CB 宣战是否沿用既有结算（不额外扣 rep） | 沿用既有 CB 通道；CB 只解决"可发起"，宣战结算照常（战损/占领/声誉均按既有） |
