# 外交提案与表决分类（2026-11-13 院长令：调研现实与游戏后定稿）

> 状态：✅ **v1.0 提案（院长 11-13 指令：弃权不算同意、同意票过半；调研现实与游戏，按游戏性+真实性输出）**
> 关联：[外交AI决策规范 §十五](./外交AI决策规范.md)（制裁会议/领先制裁）、[外交行动.md](./外交行动.md)（会议三案 R41）、[战斗总述](../04-军事/战斗总述.md)（L1/L3 分工）
> 结论先行：**门槛分三档（全票 / 过半 / 附议即可发起），参与范围分三档（全员 / 同意+弃权 / 仅同意）**；制裁类用"同意严格过半、弃权不计入"（院长口径），战争制裁通过后**全员参与**（安全公共品），经济/裁军制裁**同意+弃权参与**。

## 一、现实依据（联合国）

| 机制 | 现实规则 | 出处 |
|---|---|---|
| **联大·简单多数** | "出席并参加表决"成员国**过半数**；**弃权不计入**（只算赞成/反对） | 《联合国宪章》第十八条；大会议事规则第八十五/八十六条 |
| **联大·重要问题** | **三分之二多数**（维持和平建议/新会员/预算等） | 宪章第十八条第二款 |
| **安理会·程序事项** | 9/15 理事国同意，**无常任否决** | 宪章第二十七条第二款 |
| **安理会·实质事项** | 9 票 + **全体常任理事国同意**（大国一致=否决权） | 宪章第二十七条第三款 |
| **决议强制力** | 安理会（第七章）有强制力；联大决议无强制力（道义/政治压力） | 宪章第六章/第七章 |

**对本作的关键启示**：①"弃权不算同意"是现实规则（院长口径完全一致）；②门槛应随提案重要性分级（简单多数/三分之二/全票）；③强制力决定"通过后谁受约束"（安理会 vs 联大）。

## 二、游戏先例

| 游戏 | 机制 | 优点 | 问题（教训） |
|---|---|---|---|
| **文明6 世界议会** | 每国 1 免费票 + 外交支持买票（20/30/40…递增）；A/B 二选一；票败 100% 退款、目标不符 50% 退款 | 票的"强度"可表达（二次投票思想）；议题有张力 | **永远有结果通过**（无真"否决"）；UI 把 A/B 画成赞成/反对，心智负担高；AI 行为可预测 |
| **三国志12** | 外交交涉=使者/舌战；军师给建议 | **领导感**：玩家只做决策，军师替玩家做调研；操作轻 | 表决层较薄（无多国议会） |
| **骑砍（反面）** | 自动战斗=抽象战力对比 | 快 | **手动无伤/自动惨死**——玩家被迫手动，负反馈（院长点名） |

**对本作的关键启示**：①不做"买票"（心智负担高、操作多）；②不做"A/B 二选一"（本作是"是否制裁/是否开战"的是非题）；③**军师/外交官给建议**（领导感）；④**永远有结果**不是问题，但要让"否决"有意义（否决=维持现状，本身是结果）。

## 三、本作模型：门槛 × 参与范围（两维）

### 3.1 门槛三档

| 档 | 规则 | 适用 |
|---|---|---|
| **全票** | 参与国**全部同意**（弃权/反对=不通过） | 区域经济型（贸易协定/关税同盟/碳配额），自愿加入、成员受限 |
| **过半** | **同意票 > 参与国半数**（严格过半：5→3、4→3、3→2、2→2；**弃权不计入同意**） | 安全型（战争制裁/共同防御/复国/裁军/经济制裁）、道义型 |
| **附议即可发起** | ≥1 国附议即可发起提案（通过仍按上面门槛） | 程序型（议程设置/谴责动议） |

> 院长口径：**"5 进 3、4 进 3、3 进 2、2 进 2"** = 严格过半（floor(n/2)+1）。弃权/反对都不算同意票。

### 3.2 参与范围三档（通过后谁受约束/谁参与）

| 档 | 规则 | 适用 | 现实对应 |
|---|---|---|---|
| **全员参与** | 通过后**所有国家**（含投反对者）受决议约束/参与行动；反对国可"不执行"但受声誉惩罚（−5） | **战争制裁/共同防御/复国**（安全公共品，不能搭便车） | 安理会第七章决议（成员国均有义务） |
| **同意+弃权参与** | 同意国主动参与；**弃权=随大流**（通过则视为参与）；**反对=不参与**（不获 CB、不承担义务、与被制裁者关系 +5） | **经济制裁/裁军制裁/禁运** | 现实制裁：参与国执行、不参与国继续贸易（如印度买俄油） |
| **仅同意国参与** | 只有投同意的国家参与/受益 | **道义型**（谴责/声援）、**区域型**（贸易协定）、自愿联盟 | 联大决议（无强制力）、RCEP 自愿加入 |

## 四、提案类型总表（本作首版）

| 提案 | 类型 | 门槛 | 参与范围 | 效果 | 强制力 |
|---|---|---|---|---|---|
| **战争制裁**（反法西斯/侵略者） | 安全型 | 同意严格过半 | **全员** | 全阵营合法 CB（12 回合）；目标无法缔约 | 有 |
| **共同防御** | 安全型 | 同意严格过半 | **全员** | 成员互防；目标被孤立 | 有 |
| **复国会议**（R35/R39） | 安全型 | 参与国过半（现行） | 同意国 | 复国据点/流亡政府转正 | 有 |
| **经济制裁**（科技/文化领先） | 安全型 | 同意严格过半 | **同意+弃权** | 目标商业收入/科技增速 ×0.7 | 有（对参与国） |
| **裁军制裁**（军事领先） | 安全型 | 同意严格过半 | **同意+弃权** | 目标服役上限 ×0.5、军饷 ×1.2 | 有（对参与国） |
| **禁运** | 安全型 | 同意严格过半 | 同意+弃权 | 对目标贸易清零 | 有 |
| **道义谴责** | 道义型 | 同意过半 | **仅同意国** | 目标 rep −10、关系 −10（无强制） | 无 |
| **贸易协定/关税** | 区域型 | **全票** | 仅成员 | 成员间加成、成员受限 | 有（成员） |
| **议程设置/推举常任** | 程序型 | 附议即可发起；过半通过 | 仅参与国 | 决定下次议题/常任席位 | 无 |

## 五、游戏性分析（院长标准：快乐 + 低心智负担 + 领导感）

1. **领导感（核心）**：玩家只做"立场选择"（同意/弃权/反对）——**外交官/军师面板给出"建议立场 + 一句话理由 + 影响预估"**（如"建议同意：CN 已侵略两次，制裁可获合法 CB；代价：与 CN 关系 −10"）。调研/算票由 AI 完成，玩家不做数据收集。参照三国志12 军师建议。
2. **快乐点**：①站队快感（选边）②通过/否决的即时反馈（战报式日志）③制裁生效的连锁（目标收入下降/盟友倒戈）④"我的一票决定了结果"的权重感。
3. **低心智负担**：①每回合最多 1~2 个提案（已有行动槽上限）②提案卡固定三行：`门槛/当前票数/通过后影响`③不做买票、不做 A/B 二选一、不做目标二次选择（避开文明6 的复杂性与挫败感）④弃权=随大流（不需要理解复杂规则）。
4. **反对的意义**：反对国不参与（不获 CB、不承担义务），保留"不站队"的收益——玩家投反对不是"无效操作"。

## 六、真实性分析

| 设计 | 现实依据 | 是否出戏 |
|---|---|---|
| 弃权不算同意 | 联大"出席并参加表决"排除弃权 | ✅ 完全一致 |
| 严格过半（5→3/4→3/3→2/2→2） | 联大简单多数；本作阵营数少，向上取整 | ✅ 合理 |
| 战争制裁全员参与 | 安理会第七章强制力 | ✅ 合理（反对国可"不执行"但付声誉代价） |
| 经济/裁军=同意+弃权 | 现实制裁执行不统一（印度买俄油） | ✅ 合理 |
| 全票=区域经济型 | RCEP 自愿加入、成员受限 | ✅ 一致 |
| 不做买票 | 现实无"买票"（游说存在但不公开计价） | ✅ 不冲突（文明6 的买票是游戏化） |
| 否决权 | 安理会五常否决 | 🟡 本作 4~5 阵营，常任否决过强 → 简化为"发起国无反对"（A1.1 口径） |

## 七、落地（首版）与后续

**本轮落地（模拟器）**：
- 制裁会议门槛改为**同意严格过半**（弃权/反对都不算）；`need = floor(参与国/2)+1`。
- 战争制裁（cb）通过后**全员参与**（含反对国，反对国 rep −5"不执行"）；经济/裁军通过后**同意+弃权参与**。
- 道义型/区域型后置（当前模拟器无对应系统）。

**后续（等 UI/会议系统）**：
- 军师建议面板（外交官给立场建议）——挂 UI 规格。
- 道义谴责/贸易协定/议程设置接入。
