### 2.2 电力

```
城市电力供给 = Σ 发电厂（火电 10 / 水电 8 / 核电 20 / 光伏 6 / 垃圾 6）× 在岗率 × 燃料满足率

电力满足率 pr = min(1, 供给/需求)；耗电建筑产出/效果 × pr；0 电才停
升级建筑 +4(Lv2)/+8(Lv3) 耗电；停电托底 = 1.05×Lv1
```

- 智能电网前：每城独立，盈余浪费；解锁后全国池调配 + 损耗 10%（工业区数值 §5.3）。

## 四、矿产结算（ResourceTick）

### 4.1 产出

```
矿场产出 = 建筑基础产出 × 矿脉档位系数 × 在岗率 × (若建筑耗电则 × pr)
```

- 金矿产出直接折财（1 金=8 财），不进池。
- 矿脉档位每 **50 回合**降一档（丰饶→富集→寻常→贫化→枯竭）；**深井开采（grn2b）后 100 回合/档**（枯竭速度 −50%）。
- 枯竭档位：产出 0；矿场不自动拆除（可拆），维护照付（待裁 #7）。
- 结算时点：`SettleGlobalPhase` 内、`MilitaryTick` 前（96draft 已实装顺序）。

### 4.3 分配顺序与短缺（待裁 #1）

**建议：燃料优先 + 同级按比例**

```
① 能源燃料：火电、核电（城市电力优先，防"缺煤→停电→全面打折"死亡螺旋）
② 军工/兵种生产（战争期；和平期可降档）
③ 钢铁/化工
④ 合成燃料（仅当池有余量）
每级：满足率 = min(1, 可用池 / 本级总需求)；同档各城/各建筑按需求比例分配
池不为负；剩余不足部分按满足率打折，不排队饿死
```

- 部分满足：产出 × 满足率（线性，不设悬崖）；燃料满足率 0 → 停机（产出 0，维护照付）。
- 短缺提示：城市面板资源行红字"缺煤/缺铁"；事件条/驻城武将汇报（不静默）；国家报表给"矿产自给率"。
- 备选：统一满足率（不分优先级，全部消耗方同一比例）——实现简单但缺电会拖垮全城，不推荐。

## 五、电网

### 5.1 城市级（智能电网前）

```
供给 S = Σ 发电厂（基础电力 × 在岗率 × 燃料满足率）
需求 D = Σ 耗电建筑（基础耗电 × 在岗率；Lv2+ 门槛）
pr = min(1, S/D)；D=0 → pr=1
耗电建筑产出 × pr；0 电停机（无产出无维护？——按现有：0 电停产，维护照付）
盈余浪费（不回池）
```

- 作用范围（96draft 已实装）：wealth/production/science、文化产出、娱乐/文旅池回收 ×pr；**医疗/治安等非产出效果不吃 pr**。
- 升级建筑 +4/+8 耗电；停电托底 `max(pr, 1.05/升级产出倍率)` 不变。

### 5.2 全国余电调配（智能电网 `ai6` 后）

```
本市余电 = max(0, S − D)               // 本地发电优先
可用余电 = Σ 本市余电 × (1 − 损耗)      // 损耗 10%；室温超导 grn10 → 0
总缺口   = Σ max(0, D − S)
调度满足率 = min(1, 可用余电 / 总缺口)
缺口城 pr = min(1, (S + 缺口城获得电量) / D)
缺口城获得电量 = (D − S) × 调度满足率
```

- 损耗只对**跨城输送部分**计（本地自发自用不损耗）；按缺口比例分配，不按关系/距离（抽象为全国电网）。
- 电网容量/输电线不建模（科技=唯一门槛）；余电城不收费（抽象为统一电网）。
- 数据：`power.transmissionLoss=0.10`、`power.superconductorLoss=0`、`power.gridUnlockNode="ai6"`。
- 电力页 UI：智能电网后显示全国余电/受入（L1 界面收集已有口径）。

### 5.3 与矿产的耦合

- 火电/核电燃料满足率 ↓ → 电力供给 ↓ → pr ↓ → 高新/文化产出 ↓（单一主链，不额外加环）。
- 电力 pr 不反过来影响矿场产出（矿场 Lv1 不耗电；升级矿场才耗电 +4/+8，此时吃 pr——待裁 #6）。
- 全国余电调配**不转移燃料**：A 城火电缺煤停机，B 城余电可补 A 城缺口（电可送、煤不送）。

- 事件卡（4.2）不直接改矿产/电力（无落点字段）；如未来加"能源危机"卡，须先补落点（BUG-G014）。

## 九、验收标准

1. **燃料扣减**：火电每回煤 −2、核电铀 −1（精确）；维修回合核电不耗铀；多座独立扣。
2. **短缺停机**：0 煤火电电力/生产 = 0、维护照付；部分满足按比例；钢铁 0 铁产出 0（旧"无铁仍产"销项）。
3. **分配顺序**：缺煤时火电先于钢铁拿到煤；同级按需求比例（若裁 `fuel_first`）。
4. **余电调配**：智能电网前余电浪费；解锁后余电城→缺口城，跨城损耗精确 10%；室温超导 0；本地优先；燃料不随电转移。
5. **库存上限**：石油/铁/煤/铀不超 5 回合收入（若裁统一）。
6. **深井/合成**：油田 +30% 精确；枯竭 100 回合/档；1 煤=0.3 油、化工厂上限生效。
7. **铀约束**：仅三城可采；无铀国核电需进口（缺铀停机不死锁）。
8. **存档**：矿池/燃料库存/核电维修计时/电网状态读档一致；旧档缺字段按默认。
9. **回归**：BUILD/SMOKE/NFACTION；v22 基线逐字节不动；新盘（v25）无死档、无负池。
10. **口径一致**：`balance.json` 与文档数值一致（BUG-G013）；sim 简化值不得混入。
