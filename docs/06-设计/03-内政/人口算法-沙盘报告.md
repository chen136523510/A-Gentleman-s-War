## 二、发现的问题

### P1｜粮食在 30~50 区间"饿但没感觉"（重要）

**证据**：只建房不建农，500 回合后 F=28.6、P=88.9k，但 W 仍有 47.5，无起义。原因：粮食项是线性 `0.22×(F−50)`，F=28.6 只扣 4.7 分，被宜居/治安/治理的加分完全抵消。

**建议**：加"饥荒膝"——缺粮按凸函数加速：

```
粮食项 = 0.22×(F−50) − 0.35×max(0, 50−F)^1.3
```

- F=50 → 0；F=35 → −15.4（原 −3.3）；F=20 → −35.6；F=0 → −67（W 归零）。
- 回测：同一"只建房"场景，t500 W 27.4，**t344 起义**；t200 W 37.2（有痛感但未死，留出补救窗口）。
- 为什么不用 sqrt/log：sqrt 会把 F=25 抬到 50，掩盖饥荒；饥荒需要**凸性**（越缺越痛），不是凹性。

### P2｜粮仓无上限（重要）

**证据**：建房+建农场景，t100 库存 K=1101（≈18 年需求），F 连续几十年 100，粮食系统失去张力。

**建议**：库存上限 `K ≤ 2×D`（两年需求；后期可挂"粮仓"建筑提升上限）。

- 回测：同场景 F 更早回落（t200 F 64.4 vs 100），长期均衡不变（W 54.6）；平衡发展仍然健康。
- 只建房场景 K 恒为 0，不受影响。

### P3｜没有城市忠诚度，占领/文化错位就是空转（关键）

**证据**：44% 外籍 + 占领（同化减半），W 41、无起义。占领在现行公式里只影响同化速度，不影响 W，也不进起义判定——**打下异族城市没有任何统治代价**。

**建议**：采纳 Q1（城市忠诚度）：

```
忠诚度 = clamp(W + 0.20×(S−50) − 15×占领 − 10×文化错位, 0, 100)
起义概率/回 = clamp((30−忠诚度)/30, 0, 1)
```

- 回测：同城 W=41.6、S=51.3、占领=1 → 忠诚度 **26.9**，起义 **10.5%/回**；文化错位再加 0.5 → 忠诚度 21.9，起义 **27.1%/回**。
- 结论：Q1 不是"多一个指标"，而是**占领玩法唯一的代价通道**；不采纳则征服无痛。

### P4｜战争只给一个 WAR 旗标太温和

**证据**：WAR=2 单开，W 最低 41.5，十年战争不死人；加上伤害包（粮−60%、L−15、W−12）后 W 最低 28.2，**t39 起义**。

**建议**：定义标准"战争伤害包"：开战即 `F −40%~60%`、`L −10~15`、`U +20`、`W −8~12`，随战线/围城程度分档。WAR 是持续压制项，不是全部代价。

### P5｜sqrt/log 实测：三处不适用，一处方向对

| 变体 | 结果 | 结论 |
|---|---|---|
| `f_C = sqrt(承载余量)` | P 87.6k（原 73k），F 29.1，W 47.8 | ❌ 更快撞粮线，拒绝 |
| `F = 100×sqrt(供需比)` | F 86.7（原 75.2），饥荒被掩盖 | ❌ 拒绝 |
| `crowd` 用 sqrt | W/L 几乎不变 | ❌ 无收益，拒绝 |
| 外籍摩擦加软分母 `/(1+0.6f)` | 44% 占领城仅 +1.8 分 | ⚠️ 收益太小，保留原 1.3 次方 |
| **粮食缺口的凸函数** | 见 P1 | ✅ 采纳 |

- 结论：本模型需要的是**缺口凸性**（饥荒、动员、外籍摩擦），不是全局 sqrt/log；凹函数只适合"边际递减的享受类"因子（娱乐、医疗），当前线性已够，暂不引入。

### P6｜稳定性与振荡

- 500 回合末 100 回合 W 极差：0.3~1.3 分——**无振荡**，25% 缓动是一阶过阻尼。
- 基线、动员、战争、难民、污染全部收敛；起义只在 W<30 连续 3 回合时触发（崩溃城 t7、重战 t39），规则符合预期。
- 唯一"长期陷阱"：只建房不建农 → 344 回合起义；这正是设计想要的"人口阀门 + 粮食刹车"。

## 三、v1.1 修订清单（建议）

1. 民生主式粮食项改为凸函数（P1）。
2. 粮仓库存上限 2×D（P2）。
3. 采纳城市忠诚度（P3，Q1）。
4. 定义战争伤害包（P4，设计层）。
5. 其余结构不动：线性承载因子、1.3 次方外籍摩擦、400v² 兵役负担、25% 缓动。
