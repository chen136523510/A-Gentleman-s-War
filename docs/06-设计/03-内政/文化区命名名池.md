# 文化区命名名池（B5 · #10）

> 状态：📝 **v1.0（2026-11-05 黑机产出；随文化区 v1.0 定稿）**；归属：文化区开题 §5 / [文化区数值.md](./文化区数值.md) 配套；只用于自动命名，不影响数值。
> 用法：开局每城按建筑类型从本城名池**随机洗牌、不重复**；本城池不足时用国家级池；玩家可随时更名；跨城同名自动加城市前缀（如“上海·上海博物馆”）。
> 锚点：现实文化设施/场馆，在 1999 架空世界观内视为“灾前旧名”；不使用真实人物名。每城每类 **≥6 项**，实际可支撑同城多座（上限 2~3 座）与升级换名。

## 四、命名规则

1. **随机洗牌、不重复**：开局按城按类型抽取；同城同类不重名；升级换名优先本城同线下一级名（如“博物馆→会展中心→世博会”）。
2. **玩家更名**：免费、即时；更名不影响数值/成就。
3. **历史感**：名池是“1999 灾前旧名”，灾后可能沿用、残破、合并或改作他用；UI 可显示“旧名/现名”双行（挂 UI 专题）。
4. **不新增专有名词负担**：名池只做风味，不进入规则文本；对外交/事件/百科引用时用建筑类型，不用具体馆名。
5. **与学院区名池的边界**：艺术学院/传媒大学归学院区名池（`学院区命名名池.md`）；本名池只管文化区建筑，避免跨区撞名（如“国家大剧院”只在本名池）。
6. **模拟验名池**：v11d/v11d-c 已按每城建筑上限统计名池消耗——单城单类最多 2~3 座，≥6 项足够两轮开局不重名；跨城同名由城市前缀兜底（详见 [文化区数值.md](./文化区数值.md) §九）。
