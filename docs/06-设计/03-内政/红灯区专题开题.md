# 红灯区专题开题（特殊服务业建筑）

> 状态：🏗️ **v0.3（2026-11-10 院长裁三条线/命名/特效排序 + 调研 v0.2）**——归属商业区、派驻魅力；三条线×三级（发廊→歌舞厅→风情街 / 按摩店→洗浴中心→泡泡浴 / KTV→夜总会→不夜城）；只禁邻学校、不做间谍接口。
> 一句话：红灯区不是普通产出建筑，而是**政策敏感型特殊服务业建筑**——高财收 + 强负外部性（治安/民生/声誉）+ 可被政策合法化/整顿/取缔，并与武将被动、文化舆论、事件卡深度交互。

## 一、为什么单开专题（院长 11-10 定）

- **政策交互密度高**：合法/许可/扫黄/取缔/征税/保护费，直接改变建筑存亡与产出——普通经济建筑没有这种“政策开关”。
- **特效区分度大**：财收高但治安/民生/外交声誉负外部性；不是“再造一个商业中心”。
- **叙事/玩梗空间大**：群友梗、城市特色、事件卡、AI 倾向都可挂。
- **跨系统接口多**：警察局（治安）、市政府（许可）、文化区（舆论/热度）、外交（声誉）、武将被动（陈睿）。

## 二、设计框架 v0.3（R1/R2/R4 已裁；其余待裁）

### 2.1 建筑分级（三条线 × 三级，2026-11-10 院长裁）

- **归属区域：商业区**（R1）；文化区只做热度/舆论接口。
- **三条独立升级线**，占地不同、**不做数量上限**（R3 已裁 11-10）：
  - **小众线（1×1）**：**发廊 → 歌舞厅 → 风情街**
  - **大众线（2×2）**：**按摩店 → 洗浴中心 → 泡泡浴**
  - **高端线（3×3）**：**KTV → 夜总会 → 不夜城**
- **建筑派驻主属性：魅力**（R4）；政治为副（许可/关系）。
- 升级不变占地（每条线保持自己的占地：1×1/2×2/3×3）。
- **特效排序（院长裁）**：从小到大——占地越大，**财收越高、城市热度越高、治安负越高、外交声誉影响越大**。
- **政策敏感**：做；具体政策留政策专题。
- **间谍接口：先不做**。

| 线 | 占地 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|---|
| 小众 | 1×1 | 发廊 | 歌舞厅 | 风情街 |
| 大众 | 2×2 | 按摩店 | 洗浴中心 | 泡泡浴 |
| 高端 | 3×3 | KTV | 夜总会 | 不夜城 |

> 城市特色名、店名池、特效量级带见 [调研](./红灯区专题调研.md)。

### 2.2c 规模效应（11-10 院长裁：不做上限，副作用递增）

- **数量上限：不做**（想铺就铺）；
- **正面产出**：每座按自身数值**线性累加**（财收/岗位/热度）；
- **副作用（治安/民生/声誉）**：同城红灯区建筑总数 `n` 越大，负外部性越强：
  - **规模系数 = `1 + 0.25 × (n − 1)`**（2 座 ×1.25 / 3 座 ×1.5 / 4 座 ×1.75 / 8 座 ×2.75）；
  - 该系数**只乘负外部性**，不乘正面产出——铺越多，净收益越差；
- **n = 同城三条线所有红灯区建筑总数**（不分线/等级）；
- 城市面板可显示“红灯区规模：零散/街区/红灯区/不夜城”作为风味标签（待定）。

### 2.2 产出与负外部性（方向，数值待定）

- **财**：高财收（高于同级商业中心），但税率/政策敏感；
- **就业**：提供岗位（在岗人口），可缓解低端就业；
- **文化/热度**：提供城市热度/文旅吸引力（与博物馆/剧院形成“雅俗”对照）；
- **治安**：负修正；
- **民生**：双向——就业/收入正、道德/舆论负；外籍比例高时摩擦放大；
- **外交声誉**：被敌对阵营拿来做舆论战/制裁借口（待外交接口）；
- **健康/疾病**：不做（避免系统膨胀）。
- **排序（院长裁）**：占地越大 → 财收越高、城市热度越高、治安负越高、外交声誉影响越大。

### 2.2b 选址（院长裁：只保留一条）

- **不能与学校相邻**；不做其他相邻加成/限制（玩家已要为 L3 战争做城市规划，不再叠加）。

### 2.3 政策交互（核心亮点）

| 政策档 | 效果方向 | 代价 |
|---|---|---|
| **合法化/许可制** | 建筑可建/可升级；税收正常；治安负外部性明面化 | 外交声誉 −；保守派舆论 − |
| **默许（灰色）** | 可建但税收打折；治安负外部性隐藏/延迟 | 被查处风险；事件卡“扫黄” |
| **整顿/限制** | 产出 −；治安负外部性 −；可保留建筑 | 财收损失；就业下降 |
| **取缔/扫黄** | 建筑停摆/拆除；治安 +；舆论 + | 财收归零；失业 |

- **政策卡槽位**：国家级政策卡占槽 vs 城市法令 → 待裁（政策专题处理）；
- **既有锚点（文化区 11-04 裁）**：红灯区=财数额高+降治安+**政策解锁+换政策收益减半**；本专题沿用。
- **执法强度**：警察局等级/驻军/武将武力影响查处概率（政策专题处理）。

### 2.4 武将交互

- **陈睿被动「洗浴高手」**：**陈睿所在城**存在任意红灯区建筑（三条线任意等级）时，该城所有武将**全属性 +5**（结算层、不加基础面板；见 [武将数值基线 §八](../02-武将/武将数值基线-v0.md)）；
- **建筑派驻主属性=魅力**（R4），政治为副（许可/关系）。

### 2.5 间谍接口（先不做）

- 院长 11-10 裁：**先不做间谍/黑市接口**；后续需要再开。

### 2.6 事件卡

- 「扫黄行动」「舆情风暴」「黑帮火并」「保护伞曝光」「城市名片/夜经济」等；
- 触发条件：治安低/取缔政策/高外籍/选举/外交冲突；
- 与事件卡总表同规则：明牌预警、低频、卡面显示实际数值。

### 2.7 AI 与模拟

- AI 是否建红灯区：按政体/难度/经济压力权重（保守政体低、经济困难高）；
- 玩家负反馈纪律：AI 不主动用红灯区舆论战恶心玩家（低权重）；
- 入模：建筑经济账 + 治安/民生流 + 政策开关；随 v18 或后续对照盘。

### 2.8 L2/L3 表现

- L2：建筑实体、夜间灯光/人流（美术方向待定）；
- L3：可被掠夺/占领？占领后自动取缔/保留？→ 待裁；
- 是否做“夜晚”状态（L2 光照）→ 待裁。

## 四、与既有专题边界

- **不重复经济建筑**：红灯区是“政策敏感型特殊建筑”，产出模型可复用商业区，但政策/声誉/治安交互是本专题独有；
- **不重复警察局**：警察局=治安主职；红灯区只产生治安负外部性，对冲手段仍归警察局/驻军；
- **不重复文化区**：红灯区可提供“城市热度/夜经济”接口，文化产出主职仍在文化区；
- **不与间谍挂钩**：院长 11-10 裁先不做间谍/黑市接口；
- **不重复武将**：陈睿被动归武将专题，本专题只定义“红灯区建筑存在”这一条件。
