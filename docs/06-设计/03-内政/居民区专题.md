# 居民区专题（B4.4 · 住宅定性 · v1.0 定稿）

> **AI 摘要**：居民区=**市政区子类**（七区=农业/工业/商业/学院/军事/文化/市政；居民区并入市政区，2026-11-25 院长令）。住宅=**3 条升级线 × 3 级**（承载线/均衡线/宜居线），占地全 **2×2**、**无数量上限、无城市特色、零特效**。数值权威=[居民区数值.md](./居民区数值.md)；本篇只记定性与裁定。
> 状态：✅ **v1.0 定稿（2026-11-25 院长系列裁定）**——3 线命名/升级两规则/占地统一/无上限/旧 8 型退役全部落定。
> 上游：[人口与宜居度.md](./人口与宜居度.md)（H 分接口）· [人口算法-v1 §2.1](./人口算法-v1.md)（住房分）· [市政建筑数值.md](./市政建筑数值.md)（同区）· [区域与建筑.md](./区域与建筑.md)

## 一、定性（2026-11-25 院长裁）

| 项 | 口径 |
|---|---|
| 归属 | **市政区**（住房=市政一环；居民区不再独立成区、不再是"六区域之外"） |
| 结构 | **3 条升级线 × 3 级**，参考其他区域"基础建筑→升级"模式 |
| 占地 | 全部 **2×2**（`landW=2, landH=2`；**减少变量，数值平衡只调承载/q/造价**；升级不变占地） |
| 数量 | **无上限**（不设每城每型座数限制；承载高了需粮食跟上才有人口——f_F 粮安天然制衡） |
| 特色 | **不做**（无城市绑定、无特效；特色建筑等基础建筑定完再点单） |
| 旧 8 型 | **退役**（鸽子笼/唐楼/人才公寓/高级公寓/筒子楼 作废；承载/q/造价随[数值篇](./居民区数值.md)新表） |

## 二、3 线命名与性格

| 线 | 性格 | Lv1 → Lv2 → Lv3 | 一句话（卡面） |
|---|---|---|---|
| **承载线** | 高承载低宜居 | **贫民窟 → 城中村 → 密集公寓** | "装得下，住得挤" |
| **均衡线** | 适中 | **小区 → 洋房 → 大平层** | "两头都过得去" |
| **宜居线** | 高宜居低承载 | **独栋 → 别墅 → 大庄园** | "住得好，装得少" |

## 三、升级两规则（院长令，2026-11-25）

1. **升级后数值必须优于升级前**：承载与 q 全维严格递增（造价/维护随通用曲线涨，不属"劣"）；
2. **劣势数值不越界**：任何升级建筑的**承载 ≤ 贫民窟 Lv1**（15,000）、**q ≤ 独栋 Lv1**（90）——升级只在本线性格内变强，不侵入他线地盘（3 级小区/3 级独栋承载不过贫民窟；密集公寓/3 级小区宜居不过独栋）。校验见[数值篇 §二](./居民区数值.md)。

## 四、人口衔接（设计原则，2026-11-25 院长裁）

- **承载≠自动人口**：人口增速 `g = 0.006 × h × f_L^1.5 × f_F × (1.5−r)`（[人口算法 §7.2](./人口算法-v1.md)）——承载只给上限（r=P/C），**粮安 f_F、宜居 f_L 跟不上就长不动**；堆承载不堆粮=空转。
- **不加公式门槛（方案 C）**：有的玩家愿意牺牲增速换数据好看（住别墅/大平层），有的玩家只对胜利有感觉（堆贫民窟快铺人口）——**两种玩法都允许**；平衡靠玩家自觉+美术表现差异（UI 到位后别墅/大平层比贫民窟好看）。
- **表现层给倾向不给答案**：建造预览双数字（`人口上限 +15,000` / `宜居 −3` 或 `增速 ↗`）+ 三线性格一句话；游戏内**不出现推荐配比/最优解**。
