## 二、升级规则与校验

**经济曲线**（通用，[建筑数值表 §5.1](./建筑数值表.md)）：造价 ×1.6（Lv2）/ ×2.56（Lv3）；维护 ×1.5 / ×2.0；工期不变；**升级不新增占地**（铁律）。

**规则 ①（升级全维优于前级）**：承载与 q 严格递增。

| 线 | 承载 | q |
|---|---|---|
| 承载线 | 15,000 → 18,000 → 21,000 | 12 → 20 → 30 |
| 均衡线 | 5,000 → 6,500 → 8,000 | 70 → 78 → 85 |
| 宜居线 | 2,500 → 3,250 → 4,000 | 90 → 95 → 100 |

**规则 ②（劣势不越界）**：承载 ≤ 贫民窟 Lv1（15,000）；q ≤ 独栋 Lv1（90）。

| 校验 | 值 | 上界 | 结果 |
|---|--:|--:|:--:|
| 大平层/洋房/小区 承载 | 8,000 / 6,500 / 5,000 | 15,000 | ✅ |
| 大庄园/别墅/独栋 承载 | 4,000 / 3,250 / 2,500 | 15,000 | ✅ |
| 密集公寓/城中村/贫民窟 q | 30 / 20 / 12 | 90 | ✅ |
| 大平层/洋房/小区 q | 85 / 78 / 70 | 90 | ✅ |
| 大庄园 q（宜居线优势项） | 100 | q 自身上限 | ✅ |

- **性格不越位**：3 级小区承载不过贫民窟、密集公寓宜居不过独栋；升级只在本线内变强。

## 三、人口衔接（制衡）

```
承载 C ──→ r = P/C ──→ 上限 1.5×C（1.5−r=0 停涨）
q ──→ H = 100×(0.5×q/100 + 0.5×crowd)，crowd = clamp(1.10−0.60r, 0, 1)
H ──→ 宜居 L ──→ f_L = clamp(L/60, 0.5, 1.5)
g = 0.006 × h × f_L^1.5 × f_F × (1.5 − r)      // f_F=粮安；承载高≠人口自动涨
```

- **承载给天花板、质量给速度、粮食给许可**——堆承载不堆粮=空转（f_F 卡增速）；堆质量不补承载=很快顶到 1.5C 停涨。
- **不加公式门槛（方案 C，2026-11-25 院长裁）**：允许"牺牲增速换数据好看"（别墅流）与"只对胜利有感觉"（贫民窟快铺）两种玩法；美术表现承担倾向（别墅/大平层比贫民窟好看）。
- **表现层**：建造预览双数字（人口上限/宜居或增速边际值）+ 三线性格一句话；不出推荐配比。
