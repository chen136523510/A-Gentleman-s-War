# 学院区命名名池（B1-E）

> 状态：📝 **v1.0（2026-11-03 黑机设定）**；归属：学院区开题 §3 配套；只用于自动命名，不影响数值。
> 用法：开局每城按建筑类型从本城名池**随机洗牌、不重复**；本城池不足时用国家级池；玩家可随时更名；跨城同名自动加城市前缀（如“深圳·深圳大学”）。
> 锚点：现实院校/图书馆/研究机构，在 1999 架空世界观内视为“灾前旧名”；不使用真实人物名。

## 三、命名规则

1. **随机洗牌**：开局按城按类型抽取，不重复；同城同类不重名。
2. **玩家更名**：免费、即时；更名不影响数值/成就。
3. **历史感**：名池是“1999 灾前旧名”，学院建筑在灾后可能沿用、残破或合并；UI 可显示“旧名/现名”双行（待 UI 专题）。
4. **不新增专有名词负担**：名池只做风味，不进入规则文本；对外交/事件引用时用建筑类型，不用具体校名。
