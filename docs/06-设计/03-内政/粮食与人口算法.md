## 〇、院长 17 条裁定（2026-10-30）

| 结论 | 内容 |
|---|---|
| ✅ 出征带粮 | **出征时一次性带出口粮**，所以出征部队不在驻军里，D 不重复计 |
| ❌ 地力机制 | **不做**。耐久度是很强的负反馈，且玩家不想对一块耕地反复调整作物 |
| ✅ 8 年储备 | **保留 8×D**。占领粮城几回合就让敌国崩，才是真正的滚雪球——粮食危机→民生降→产出降→战力降→更难收复，恶性循环。8 回合刚够组织反攻 |

| ✅ 库存趋势 | 显示**箭头**（红↓/绿↑，持平也算绿↑）+ 悬停显示"还有多久满仓/清仓" |

| ✅ 渔场 | 跟城走，**不做制海权** |
| ✅ 达尔文 | **独立粮池** |
| ✅ AI 进口 | AI 可以主动发起进口 |
| ✅ 开局无压力 | 压力放在**前中期**：人口快速上升期、生产力都投在别的区域时 |
| ✅ 城市损毁 | 只是世界观，**城市位置保留**（同达尔文形态）；真正的损毁态由三级天灾触发 |
| ✅ 余粮用途 | 需调研（见 §六） |
| ✅ AU 限制 | 卖粮赚钱合理，但 AU 优势过大，需要别的限制（见 §七.4） |

## 一、公式链（六段）

```
① 需求  D = Pc/1000 + 1.5×A_garrison/1000 + 出征携粮
② 供给  Q = Σ农田 + Σ牧场(饲料加成) + Σ渔场(环境修正) + Σ食品工业(固定)
③ 库存  K' = clamp(K + Q − D + 进口 − 出口, 0, 8×D)     // 可为负 → 饥荒
④ 饥荒  K<0 → 死亡 = Pc × min(5%, 10%×|K|/D)，L、W 直接扣
⑤ 民生  W 粮项 = 11 × clamp(m/4, 0, 1)   （m = K/D，库存覆盖年数）
⑥ 人口  增长 = Pc × 2% × f_L × f_F × f_C
```

**闭环**：`建居民楼 → C↑ → f_C↑ → 人口↑ → D↑ → K↓ → 危机 → 补农业 or 进口`。

> **关键**：中期的粮食压力不是"按时间安排"的，而是**玩家发展人口的自然结果**。想扩人口就得先解决粮食——这是天然耦合，不需要额外机制。

## 二、① 需求 D

```
D = Pc/1000 + 1.5×A_garrison/1000
```

| 项 | 口径 |
|---|---|
| `A_garrison` | **驻军**（不含出征部队） |
| 出征部队 | **出发时一次性扣粮**：`携粮 = 兵数/1000 × 1.5 × 预计回合 × 1.2`，从全国粮池扣除 |
| 1 粮 | = 1,000 人一年口粮 |

- **院长口径**：出征自带干粮，所以不计入日常 D。这比"出征部队算驻军"更符合古代行军逻辑，也避免了"军队在城外就不吃饭"的漏洞。
- **携粮一次性扣除的副作用（有意为之）**：大规模远征会瞬间抽空粮仓 → **发动战争前必须攒粮**。这是"战争需要粮食准备"的正确定价。
- 远征收的粮如果没吃完，回城时**返还 50%**（剩下 50% 算途中损耗/就地补给）。

## 三、② 供给 Q

```
Q = Σ农田 B×作物系数
  + Σ牧场 B×畜种系数×(1+饲料加成)
  + Σ渔场 48×(1 − 0.30×核污染 − 0.20×酸雨)
  + Σ食品工业 45
```

| 项 | 值 |
|---|:--:|
| 农田基准 B | **40**（模拟定值，见 §九） |
| 作物系数 | 玉米 1.15 / 大米 1.10 / 小麦 1.00 / 土豆 0.90 / 大豆 0.75 |
| 畜种系数 | 牛 1.125 / 猪 1.10 / 羊 1.05 / 鸡 0.95 |
| 渔场 | **固定 48**（不吃耕地） |
| 食品工业 | **固定 45**（院长第 9 条：科技只解锁，不参与产出计算） |

- **食品工业改为固定 45**：v2 写"20 + 0.5×科技"，被院长否决——科技应该是"解锁这个建筑"，不该直接变成粮食数字。
- 食品工业的定位：**不占耕地的高产粮源**，代价是科技门槛 + 1 座/城上限 + 工业产能占用。

## 四、③ 库存 K（唯一粮食安全指标）

```
K' = clamp( K + Q − D + 进口 − 出口 , −∞, 8×D )
```

- **上限 8×D**（院长第 3 条保留）。这是"战略储备"，也是占领粮城后敌国的崩盘缓冲期——8 回合够组织反攻。
- **下限不设 0**：K 可以是负数，负数是饥荒的深度指标。
- 分国粮池（R49b 口径），达尔文独立粮池。

### 4.1 UI：库存 + 趋势箭头（院长第 5 条）

```
显示：[ 库存 3.2 年  ↑ ]      鼠标悬停 → "按当前净产需，约 12 回合后满仓（8 年上限）"
显示：[ 库存 1.4 年  ↓ ]      鼠标悬停 → "按当前净产需，约 9 回合后清仓"
显示：[ 库存 −0.3 年  ↓ ]     饥荒：人口流失中
```

| 状态 | 箭头 | 颜色 | 含义 |
|---|---|---|---|
| Q > D（净增） | ↑ | 绿 | 粮食安全 |
| Q = D（持平） | ↑ | 绿 | 也算安全（院长口径：几乎不会刚好持平） |
| Q < D（净减） | ↓ | 红 | **粮食危机**（还不是饥荒） |
| K < 0 | ↓↓ | 红闪 | **饥荒**：饿死人 |

- **取消"粮安 F%"这个数字**。库存年数 + 箭头已经把所有信息表达完了，F 是多余的中间变量。
- 悬停显示"还有多久满仓/清仓" = `|8D−K| / |Q−D|` 或 `|K| / |Q−D|` 回合。

## 五、④ 饥荒（K < 0）

```
缺粮深度 d = |K| / D              // 缺几年口粮
年死亡 = Pc × min(0.05, 0.10×d)   // 最多死 5%/年
宜居 L  −= 15×min(d, 1)           // 一次性，逐回合累积到上限
民生 W  −= 30×min(d, 1)
```

- **饥荒 ≠ 危机**：K 只是下降（Q<D）是危机，出红色箭头 + 首长汇报预警；**K 跌到负数才是饥荒**，才死人。
- 饥荒期间人口增长按 −`min(5%, 10%×d)` 走（负增长），人口下限 1,000（城不会消失）。
- **拖后腿的城会被饿死**：见 §六 城级收支表——粮食危机的分布直接决定哪些城先饿。

## 七、进口与出口（外交定价 · 院长第 4、8 条）

### 7.1 定价链

```
① 卖方可供出口量   X_s = max(0, Q_s − D_s) × 0.60      // 留 40% 进库存，物理上买不空
② 买方缺口率       g = max(0, D_b − Q_b − K_b) / D_b
③ 卖方库存年数     m_s = K_s / D_s
```

**溢价公式**（v3 用"卖方库存年数"替代已取消的 F_s）：

```
m = clamp( 2.5×g^1.5                        // 买方缺口越大越贵（1.5 次方，断崖式）
         + 1.5×max(0, 2 − m_s)/2            // 卖方自己库存不足 2 年 → 加价（割肉价）
         + (50 − rel)/60                     // 关系：敌国 +，友好 −
         , 0, 6 )

P = P0 × (1 + m)                            // P0 基准价，B6 定，暂 1 财/粮
```

| 买方缺口 g | 卖方库存 m_s | 关系 | m | 价格 |
|:--:|:--:|:--:|:--:|:--:|
| 0.15 | 8 年 | 友好 | 0.15 | **1.15** |
| 0.15 | 8 年 | 敌对 | 1.82 | 2.82 |
| 0.50 | 8 年 | 友好 | 0.88 | 1.88 |
| 1.00 | 1 年 | 敌对 | 2.50+0.75+2.50 = 5.75 | **6.75** |

### 7.2 封堵"无脑买空"的四道闸

| 手法 | 为什么失效 |
|---|---|
| 拿钱买空对方粮 | 只能买当年余粮的 60%，卖方永远留 40% 进库存 |
| 砸钱把对方饿死 | 溢价里"卖方库存不足"项会加价，且关系 −5 |
| 低价囤积转卖 | 溢价跟着**买方缺口**走，同回合价格锁定，无套利 |
| 战时偷买 | 交战方禁止贸易 |

### 7.3 出口收益

```
出口收入 = V × P（进卖方国库）
```
- AU 开局可出口 (130−48)×0.6 = **49 粮/年**，按 1.15 价 = 56 财/回。

### 7.4 AU 优势的限制（院长第 8 条）

AU 已经有"2 城、兵少、科技低"的先天弱势，但 3 倍余粮 + 卖粮收入还是太肥。三个限制任选/叠加：

| 方案 | 机制 | 效果 |
|---|---|---|
| **A. 市场深度（推荐）** | 出口量受**买家缺口**限制：`实际出口 ≤ Σ全球买方缺口`。没人缺粮就卖不出去 | AU 想卖 49，但全球只有 CN+JP+KR 缺 39 → 只能卖 39，且剩余 10 粮白放着 |
| **B. 价格随量下跌** | 单回合出口量 > 20 时，价格每多 10 粮 −5% | 大量倾销收益递减，抑制"无脑卖粮" |
| **C. 粮非财（以物易物）** | 粮食出口不收财，只换"物资/科技/关系" | 最狠，但会让 AU 完全没钱，不推荐单用 |

- **推荐 A + B**：AU 的卖粮收入被"全球缺口"天然封顶，想多赚就得指望别人更缺粮（这本身是很好的外交博弈）。
- 额外一层：AU 只有 2 城，**卖粮收入必须用来买安全**（扩军/外交），否则 CN/JP 一波就推平——这是战略层面的软限制。

## 八、余粮用途（院长第 12 条调研）

### 8.1 先回答"余粮能一直满仓吗"——能，而且严重过剩

耕地容量 28 块 + 渔场上限 20 座：

```
Q_max = 28×40（农田）+ 20×48（渔场）= 1,120 + 960 = 2,080 粮/年
```

| 承载状态 | D | Q_max/D | 余粮 |
|:--:|:--:|:--:|:--:|
| 初始承载 489k | 489 | **4.25** | 1,591 |
| 每城 +3 座住宅（825k） | 825 | **2.52** | 1,255 |
| 每城 +6 座住宅（1,161k） | 1,161 | **1.79** | 919 |

- **结论**：把耕地和渔场全部建满，产能是人口需求的 **1.8~4.3 倍**。中后期必然满仓 + 大量余粮。
- 单看 CN：耕地 11 块 + 渔场 10 座 → Q_max 920，人口满编 427k（+4 座住宅）→ **2.15 倍**。
- **这不是 bug，是设计选择**：农业是"前中期议题"，后期粮食管够，玩家可以把精力转到战争/科技/文化。**但余粮必须有出口，否则农业区后期就是死资产。**

### 8.2 现实余粮用途（2023 年 IGC / OECD-FAO 口径）

| 用途 | 全球占比 | 说明 |
|---|:--:|---|
| 食用 | ~43% | 直接口粮（小麦 73%、玉米 18%） |
| **饲料** | **~38~45%** | 玉米是主力（占饲料粮 69%） |
| 工业加工 | ~16% | 淀粉/麦芽/葡萄糖/酒精（玉米 308 Mt） |
| **生物燃料** | **~7%** | 乙醇 164 Mt，美国玉米 40~45% 去做乙醇 |
| 其他 | ~13% | 种子、损耗、非食品工业 |

### 8.3 游戏映射：给余粮三条去处

| 去处 | 建筑 | 转化 | 现实对应 |
|---|---|---|---|
| **饲料** | 牧场（已有） | 猪场同城有玉米/大豆 +10%；新增：**每座牧场消耗 10 粮/回，产出翻倍** | 畜牧是最大粮食消费方（38~45%） |
| **工业加工** | 工业区·**酿造厂**（新增） | 粮 30/回 → **财 25/回** | 玉米制淀粉/酒精（16%） |
| **生物燃料** | 工业区·**生物燃料厂**（新增） | 粮 40/回 → **碳 −2/回**（替代化石能源） | 美国玉米 40% 做乙醇 |
| 出口 | 外贸（§七） | 粮 → 财/关系 | 现实粮食贸易 |
| 储备 | 8×D 上限 | — | 战略储备 |

- **酿造厂 / 生物燃料厂是新增建筑**，进工业区，需要科技解锁。它们把"余粮"变成"财"和"减碳"，让后期的农业产出仍然有用。
- **牧场消耗粮**是这次的加固：v2 里牧场只"看有没有玉米"给个 +10%，现在改成**直接吃粮**——这才符合"畜牧吃掉全球 40% 谷物"的现实，也让余粮有稳定出口。

## 九、人口增速公式与分析（院长第 17 条）

### 9.1 公式

```
增长 = Pc × 2.0% × f_L × f_F × f_C

f_L = clamp(L/60, 0.50, 1.50)                  // 宜居度：L=60 成熟社会
f_F = clamp(0.40 + 0.30×min(m, 2), 0, 1)       // 粮食：m=K/D 库存年数
f_C = clamp((C − P)/C, 0, 1)                   // 承载余量：P=C 时归零

if K < 0（饥荒）: 增长 = −min(5%, 10%×|K|/D)
人口下限 = 1,000
```

### 9.2 逐因子分析

| 因子 | 公式 | 取值示例 | 作用 |
|---|---|---|:--:|
| `f_L` 宜居 | `L/60` 夹在 [0.5, 1.5] | L=60→1.0、L=40→0.67、L=30→0.5 | 系数范围 0.5~1.5，影响较大 |
| `f_F` 粮食 | `0.4 + 0.3m` 封顶 1 | m=0→0.40、m=1→0.70、m=2→1.00 | 系数范围 0.4~1.0，**缺粮直接砍 60% 增速** |
| `f_C` 承载 | `(C−P)/C` | P/C=0.5→0.50、0.8→0.20、0.95→**0.05** | **主导因子**，把人口死死卡在承载下 |

### 9.3 敏感性：谁说了算

| 场景 | P/C | L | m | 实际增长率 | 200 年人口倍数 |
|---|:--:|:--:|:--:|:--:|:--:|
| 新城（承载充足） | 0.50 | 60 | 2 | **1.00%/回** | 7.3×（会被承载卡住） |
| 一般城 | 0.80 | 60 | 2 | 0.40%/回 | 2.2× |
| 一般城 + 缺粮 | 0.80 | 60 | 0.5 | 0.22%/回 | 1.6× |
| 一般城 + 宜居差 | 0.80 | 40 | 2 | 0.27%/回 | 1.7× |
| 接近承载 | 0.95 | 60 | 2 | **0.10%/回** | 1.2× |
| 饥荒 | — | — | <0 | −3~−5%/回 | 快速衰减 |

**结论三条**：

1. **人口增长由承载主导**（f_C 是唯一能到 0 的因子）。所以"人口快速上升期"= **玩家开始大量建居民楼的那段时间**，不是年份。
2. **粮食只能砍增速、不能直接砍人口**（除了饥荒）。这符合"危机≠饥荒"的设计——缺粮只是让人口长得慢，不会立刻死人。
3. **2% 基础增长率只在"新城"（P/C≈0.5）时才接近实际值**（1.0%/回），因为 f_C 直接砍半。所以不必为了"2% 太猛"去调基础值——**承载闸门已经把复利限制住了**。

> 这是对上一版我提的"2%→1.5%"的**自我否决**：问题不在基础增长率，在 f_C 的单一性。保持 2%，不动。

### 9.4 为什么"中期才有粮食压力"

```
玩家建居民楼 → C↑ → f_C↑ → 人口加速 → D↑ → Q 不变 → K↓ → 危机
```

- **开局**：C 只比 P 高 20%，f_C=0.2，人口年增 0.4%——粮食需求几乎不动，库存稳。
- **中期**：玩家建了 3~5 座居民楼，C 涨 40%，f_C 跳到 0.4~0.5，人口增速翻倍 → 粮食需求 10 年涨 20% → **库存开始掉**。
- **后期**：农业补齐，K 回满，人口继续爬到新承载。

这就是院长要的"前中期压力"——**压力是玩家扩张人口的后果，不是日历事件**。
