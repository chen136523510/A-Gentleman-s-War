# 粮食与人口算法（B1-F · v2 优化版）

> 状态：📝 草案 v2.0（2026-10-30）。**本文件是"粮 ↔ 人口"闭环的唯一权威**，覆盖 [数值公式总纲](../00-总纲/数值公式总纲.md) §2.3 / §3.3 粮项 / §4.2 人口增长 的旧口径。
> 上游：[人口数值表.md](./人口数值表.md)（A1~A3/A5~A10 不变）· [农业区数值.md](./农业区数值.md)（Q 的来源）· [人口算法-v1.md](./人口算法-v1.md)（W/忠诚主式）。
> 验证脚本：`tmp/sim-food-pop3.js`（分国粮池 200 回合模拟，全部数字可复现）。

## 〇、设计原则（院长 2026-10-30 三条定调）

1. **提高大城收益，而不是惩罚扩张**。文明 6 的病是"大城收益低 → 玩家铺鬼城滚雪球"。本作反过来：删维护费 + 税随人口，让大城净收益高于小城，玩家自然愿意经营大城。
2. **农业区要"持续经营"，不是一次性投资**。农田会衰退（地力），人口会增长，缺粮会反复出现。
3. **进口是外交行为，不是货架购物**。价格由卖方定、可坐地起价，且有硬性的"卖不空"保护。

## 一、公式链总图（八段）

```
① 需求 D   ← Pc（平民）+ 1.5×A（服役，含出征）
② 供给 Q   ← 农田(作物×地力) + 牧场 + 渔场×(1−环境) + 食品工业 + 进口
③ 库存 K   ← clamp(K+Q−D, 0, 3D)
④ 粮安 F   ← 0.75×满足率 + 0.25×库存缓冲      ← 本版重写
⑤ F → W   ← 粮项 0.22(F−50) − 0.35·max(0,50−F)^1.3
⑥ W → 忠诚 ← v1.3 流量模型（舒适带 40~55，不改）
⑦ F → 人口 ← 1.5% × f_L × f_F × f_C            ← 本版三处改
⑧ 进口     ← 外交定价（可出口量 + 缺口溢价 + 关系）
```

**闭环**：`人口↑ → D↑ → F↓ → W↓ → 人口↑放缓 / 忠诚↓ → 起义 → 城失 → D↓`。增益 <1，不发散（见 §六 模拟）。

## 二、① 需求 D

```
Pc = P − A                      // 平民；A 计入 P（总纲 §1.3）
D  = Pc/1000 + 1.5×A/1000       // 粮单位 = 千人份/年
```

| 项 | 口径 |
|---|---|
| **A** | **服役总数，含出征/在途部队**（不等于"驻军"） |
| 1.5 倍 | 军人热量消耗高于平民（体力劳动 + 战备冗余） |
| 1 粮 | = 1,000 人一年口粮 |

- **⚠️ 修正 1**：旧口径写 `A = 驻军（军队驻城部分）`。出征部队不在驻军里 → **出征时 D 反而下降，等于"打仗不吃饭"**。改为"服役总数"，出征部队照吃。
- 数值等价改写：旧式 `P/1000 + A/1000×0.5`（P 含 A）与 `Pc/1000 + 1.5A/1000` 完全等价，但后者可读、可直接对照 UI。

## 三、② 供给 Q

```
Q = Σ农田 B×作物系数×(地力/100)
  + Σ牧场 B×畜种系数×(1+饲料加成)
  + Σ渔场 B×1.20×(1 − 0.30×核污染 − 0.20×酸雨)
  + Σ食品工业 (0.5B + 0.5×科技值)
  + 进口
```

| 系数 | 值 | 来源 |
|---|:--:|---|
| 农田基准 B | **40** | §七 模拟定值 |
| 作物系数 | 玉米 1.15 / 大米 1.10 / 小麦 1.00 / 土豆 0.90 / 大豆 0.75 | [农业区数值.md](./农业区数值.md) §四 |
| 畜种系数 | 牛 1.125 / 猪 1.10 / 羊 1.05 / 鸡 0.95 | 同上 §五 |
| 渔场系数 | 1.20 | 同上 §六 |
| 饲料加成 | 猪场：同城有玉米或大豆 +10%，都没有 −15% | 同上 §五 |
| 食品工业 | 0.5B + 0.5×科技值（B=40 → 20 + 0.5 科技） | 同上 §七 |

**⚠️ 修正 2（新增机制）：地力衰退**

```
地力 fertility ∈ [0,100]，初始 100（每块农田独立）
每回合 −0.25（不建固氮作物/不科技升级时）
产出 × fertility/100
大豆：本城所有农田 +0.5/回合（上限 100）
科技「化肥」：衰减减半（−0.125/回合）
科技「轮作」：地力下限 60（不再掉到 0）
```

- **为什么加**：不加的话农业是"建一次管 100 年"——模拟显示 200 回合只需建 9 座就永远够吃，农业区在 t=10 之后就没用了。加了地力，农田需要**轮作/休耕/科技**，大豆的"固氮"才有真实价值。
- **实测（`tmp/sim-fertility.js`，B=40）**：

| 场景 | 200 回合农业座数 | 末态平均地力 | CN F 末值 |
|---|:--:|:--:|:--:|
| 无地力（对照） | 9 | 100 | 100 |
| 有地力 · 无大豆 | **12** | 61 | 100 |
| 有地力 · 有大豆 | 12 | **66** | 100 |

  → 地力把农业投入从 9 座拉到 12 座（+33%），且末态地力仍在 60 上下，**玩家必须持续维护**。大豆能缓解（+5 地力）但不逆天——这正是想要的"对冲而非免疫"。
- **参数教训**：大豆固氮最初定 +2/回合，实测等于"1 座大豆让全城农田永久免衰减"（+2 ≫ 0.25）。**定为 +0.5**（1 座大豆刚好保住 2 块地的地力）。
- ⚠️ 一期 AI 不会主动种大豆（B13 待做），玩家会。模拟"有大豆"一栏是强制建 1~2 座的对照。

## 四、③ 库存 K

```
K' = clamp( K + Q − D, 0, 3×D )
```

- **⚠️ 修正 3**：上限 **8×D → 3×D**。8 年储备在现实中不存在（中国储备粮约 1 年消费量）；8 年上限让后期粮食彻底失去意义（模拟里 t=200 时 K 打满 8D）。
- **⚠️ 修正 4**：**先算本回合 D，再截断 K**。否则征募导致 D 突增时，K 会被旧上限截断，凭空丢粮。
- 缺粮国（Q<D）K 单调递减到 0，之后 F 完全由 Q/D 决定。

## 五、④ 粮安 F（本版核心重写）

### 5.1 旧公式的三个毛病

```
旧：F = 100 × clamp((Q+K)/(1.2×D), 0, 1)
```

| 毛病 | 现象 |
|---|---|
| a. Q=D 时 F=83 | "刚好够吃"显示 83 分，玩家以为缺粮 |
| b. K 一大就永久 100 | 即使 Q 只有需求的 60%，只要库存厚，F 一直显示 100 → **玩家看不见自己在吃老本** |
| c. 1.2 系数无依据 | 拍脑袋的"20% 安全冗余" |

### 5.2 新公式

```
满足率 s = min(Q/D, 1)          // 当年产量满足率，封顶 1
缓冲率 b = min(K/D, 2) / 2      // 库存缓冲，2 年储备 = 满
F = 100 × (0.75×s + 0.25×b)
```

| 场景 | s | b | F | 解读 |
|---|:--:|:--:|:--:|---|
| 产需刚好、零库存 | 1.00 | 0.00 | **75** | 够吃但不健康（增长打折） |
| 产需刚好、2 年库存 | 1.00 | 1.00 | **100** | 真正的粮食安全 |
| Q=0.9D、零库存 | 0.90 | 0.00 | 68 | 温和缺口 |
| Q=0.9D、1 年库存 | 0.90 | 0.50 | 80 | 吃老本，但还稳 |
| Q=0.5D、2 年库存 | 0.50 | 1.00 | 63 | 靠库存硬撑 |
| Q=0.5D、零库存 | 0.50 | 0.00 | 38 | 饥荒前夜 |

- **75/25 的理由**：当年产出是主承重，库存是缓冲。靠库存活着应该"及格但不健康"（75），而不是满分。
- **富余不直接给分**：Q>D 时 s 封顶 1，只有 75 分；余粮进 K，下回合 b 上升 → F 才涨到 100。**这样"产粮过剩"会转化为"库存"，而不是直接变成高分**——玩家必须等 1~2 年才能看到 100。

## 六、⑤⑥ F → 民生 → 忠诚

```
W 粮项 = 0.22×(F−50) − 0.35×max(0, 50−F)^1.3
```

| F | 粮项贡献 | 说明 |
|:--:|:--:|---|
| 100 | +11.0 | 粮食充裕 |
| 75 | +5.5 | 基准线 |
| 50 | 0 | 中性 |
| 30 | **−21.6** | 饥荒膝启动（指数 1.3） |
| 20 | **−36.0** | 民生崩 |
| 0 | −56.0 | 大饥荒 |

- 忠诚沿用 v1.3 流量模型（舒适带 40~55，`kn=kp=0.15`），**不改**。
- 传导：F↓ → W↓ → 民生流为负 → 忠诚每年掉 → 普通城 `<30` 连续 3 回起义（R49b 口径）。

## 七、⑦ 人口增长（三处改）

```
f_L = clamp(L/60, 0.50, 1.50)
f_F = clamp(F/85, 0, 1)              ← 修正 5：原 /70
f_C = clamp(1.10 − P/C, 0, 1)        ← 修正 6：原 (C−P)/C

增长 = Pc × 1.5% × f_L × f_F × f_C   ← 修正 7：原 2%
if F < 20 或 L < 20: 增长 = −3%×Pc
人口下限 = 1,000                      ← 修正 8（新增）：不归零
```

| 修正 | 原 | 新 | 为什么 |
|---|---|---|---|
| 5 | `f_F = F/70` | `f_F = F/85` | 原式 F≥70 就不减速，等于"70 分算满分"。改 85 后 70~85 有梯度，CN 69% → 系数 0.81，增长慢 19% |
| 6 | `f_C = (C−P)/C` | `f_C = 1.10 − P/C` | 原式 P=C 时归零，**人口永远撞不到承载上限，拥挤机制形同虚设**。新式允许 10% 超载，配合 `crowd` 惩罚自然收敛 |
| 7 | 2%/回 | **1.5%/回** | 200 年跨度用 2% 复利太猛；且原式几乎全靠 f_C 单一刹车，极敏感 |
| 8 | 无 | 人口下限 1,000 | F<20 的 −3%/回 会让城市人口归零（城市"消失"），需要地板 |

## 八、⑧ 进口（外交定价 · 院长第 4 条）

### 8.1 定价链

```
① 卖方可供出口量
   X_s = max(0, Q_s − 1.0×D_s) × 0.60
   // 只卖当年余粮的 60%，40% 强制进库存 —— 卖方不会被买空

② 买方缺口率
   g = max(0, 1.05×D_b − Q_b − K_b) / D_b

③ 关系值 rel ∈ [−100, 100]

④ 溢价系数（可坐地起价）
   m = clamp( 2.5×g^1.5
            + 1.5×max(0, 85 − F_s)/85
            + (50 − rel)/60
            , 0, 6 )

⑤ 成交价
   P = P0 × (1 + m)          // P0 = 基准价，B6 定，暂定 1 财/粮

⑥ 成交量
   V = min(买方申报量, X_s)
   花费 = V × P
```

### 8.2 溢价示例

| 买方缺口 g | 卖方 F_s | 关系 | m | 价格（P0=1） | 场景 |
|:--:|:--:|:--:|:--:|:--:|---|
| 0.15 | 100 | 50 | 0.15 | **1.15** | 正常邻居小缺口 |
| 0.15 | 100 | −50 | 1.82 | 2.82 | 敌对国买粮 |
| 0.50 | 100 | 50 | 0.88 | 1.88 | 中度饥荒 |
| 0.50 | 60 | −50 | 1.32 | 2.32 | 卖方自己也缺 + 敌对 |
| 1.00 | 50 | −100 | 2.50+0.62+2.50 = 5.62 | **6.62** | 亡国前夜，被人宰 |

- **上限 6×P0**，防止无限坐地起价把游戏玩崩。
- **三种防护**：①可出口量硬上限（买不空）；②溢价随缺口 **1.5 次方**（越缺越贵，无脑囤粮立刻被宰）；③关系系数（敌国不卖或高价）。
- **卖到 F<85 要额外加价**：`m += 2`，且关系 −5（"割肉价"，有外交代价）。

### 8.3 对"无脑商业买空"的封堵

| 手法 | 为什么失效 |
|---|---|
| 拿钱买空对方粮食 | `X_s` 只能卖当年余粮的 60%，且卖方 F 掉到 85 以下要加 2.0 溢价 + 关系 −5 |
| 拿钱砸到对方饿死 | 卖方保留 1.0×D 的口粮，物理上卖不空 |
| 低价囤积转卖 | 溢价跟着**买方缺口**走，缺口越大越贵，转卖无套利空间（同一回合内价格锁定） |
| 战时偷买 | 交战方之间禁止贸易（B6 规则） |

### 8.4 出口收益

```
出口收入 = V × P（进卖方国库）
```
- AU 开局 Q=130 / D=48.2 → 可出口 (130−48.2)×0.6 = **49 粮/年** → 按 1.15 价格 = **56 财/回**。
- 这是 AU 的"粮霸"经济路线，也是 B6 贸易协定的第一个抓手。

### 9.2 选 40 的三条理由

1. **锚点干净**：1 粮 = 1,000 人份，40 粮 = 4 万人份 —— **一座农田恰好喂一座中城**。B=34 会变成"1.2 座喂 1 城"，B=46 变成"0.87 座喂 1 城"，都不如 40 好记。
2. **开局有压力但不折磨**：CN 69% / KR 55%，玩家必须在前 10 回合建 2~3 座农业（模拟确认 t=10 恢复到 95%）。B=46 时 AI 因为缺口太小反复抖动（t=27 才到 95%），手感差。
3. **耕地容量有意义**：大都市耕地 1（北京/上海/香港/首尔）在 B=40 时"一座农田勉强自给、无余量"，正好体现"大城市靠外部供给"；B=34 则连自给都做不到，玩家会觉得被坑。

### 10.3 结构性风险（提请注意）

1. **人口上限 = 居民楼上限**：44 座住宅（每城最多 3~4 座 × 14 城）把承载顶到 841k，人口 737k。如果后续加"末日 DLC"（超级多城市），承载上限会成倍提高，粮食需求随之爆炸——**地力机制必须在那之前上线**，否则 DLC 的粮食曲线不可控。
2. **W 对 F 的敏感区间很窄**：F 50~75 之间粮项只差 5.5 分，但 F<30 时掉 21 分。这意味着"温和缺粮"几乎没有 gameplay 反馈，玩家只会在"突然崩"时才发现。建议：F 在 40~60 之间加"预警 UI"（首长汇报），而不是等 W 掉。
