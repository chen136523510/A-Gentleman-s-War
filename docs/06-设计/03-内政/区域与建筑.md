## 六类区域（参考文明 6，现代化命名）

| 区域 | 产出 | 备注 |
|---|---|---|
| 学院 | 科技值 | 推进科技线 |
| 商业中心 | 财 | 募兵/外交/俸禄/升级；武将派驻→财政加成 |
| 军事基地 | 军力（兵力/城防） | 守军兵力上限；二期战场实体=补兵建筑；覆盖圈机制（练兵覆盖范围） |
| 工业区 | 生产力/科技值/能源 | **产业细分（R13）**见下节；仅涉及生产力/科技/能源，**不做居民就业概念** |
| 娱乐区 | 宜居度 | **细分（R13）**见下节；有生效范围（覆盖圈），离居民区越远效果越差 |
| 农田（种植/牧场两型，R44d） | 粮 | 养兵/出征消耗；影响人口增速；**种植与牧场同级同产出**，共享"耕地容量"上限；牧场偏草原地形，是可选的粮食来源 |

> **粮食三来源（R44d 院长定）**：农田（种植/牧场两型）、食品工业（轻工业·食品加工厂，罐头/预制菜）——工业粮不占耕地、受产能+科技约束。全国粮池统一调配，见 [人口算法-v1.md](./人口算法-v1.md) §2.4。六区域结构不变，牧场是农田子类型，不新增第七区域。

另有 **城墙**（城防建筑）、**居民楼**（人口承载量建筑，R13 新增，见 [人口与宜居度.md](./人口与宜居度.md)）、**医院**（R37 新增：伤员收治/撤离保全率提升——L3 撤离比例加成，边际效应上限）与 **警察局**（R45 新增：**治安直接来源**，行政建筑，提供 S_b；驻军不再加治安，治安间接靠降低外籍比例）——均非六区域之一。

## 工业区产业细分（R13 立 · R30 矿业新立定稿）

| 产业 | 方向 | 特点 |
|---|---|---|
| 重工业 | 矿采/冶炼/化工 | 生产力高；**环境污染**→宜居度降（世界级环境系统联动） |
| **矿业（R30 新立大类）** | 金属/化石/铀 | **产出带城市系数**：AU 两城 ×1.5 / 达尔文 ×1.2 / 其余 ×1.0；远期挂资源枯竭事件（环保联动） |
| 高新技术产业 | 互联网/外贸 | 生产力+科技值；低污染 |
| 能源产业 | 火电/水电/核电/光伏风电 | 生产力+能源；核电站有"核污染天灾变体"设定 |
| 轻工业 | 食品/纺织/家电 | 中低生产力低污染；**食品加工厂（罐头/预制菜）为粮食第三来源，产能+科技驱动、不占耕地（R44d）** |
| 特色产业 | 与城市地标联动的独占产业 | 名古屋汽车/长崎造船/台北代工+台积电/深圳华强北等（词条见 01-地图与城市） |

- **工业区不是工业城市专属（2026-10-28 院长口径）**：任何城市只要有工业区就能选择上述产业建筑；不同城市通过城市元素/地标提供**特色区域建筑、数值加成与初始建筑**（如 AU 矿业 ×1.5、达尔文 ×1.2），不是“只有工业城才能建工业区”。
- **环境排放映射**：现有初始建筑“重工业”按钢铁冶炼厂同类计 +8 碳/回合；后续建造按具体建筑名取排放值（火电 +6 / 矿业 +2 / 垃圾焚烧 +2），见 [00-总纲/环境系统.md](../00-总纲/环境系统.md) §2.1、§9.1。

## 娱乐区细分（R13）

名胜古迹景区、体育馆、公园、日本特色红灯区等——各自提升宜居度，各有**生效范围（覆盖圈）**，离居民区越远效果越差；城市地标（富士山/秋叶原等）作为特色娱乐区/产业词条挂接（见 [01-地图与城市/城市特色与地标.md](../01-地图与城市/城市特色与地标.md)）。

## 建造与拆除规则（R13 定）

**槽位原则（R6 拍板，不变）**：
- 区域槽位不设数量上限：六区域+城墙+居民楼自由建造；
- 取舍来自：生产力/时间预算、武将驻守能力、维护成本；
- 城市发育度决定城市范围→二期战场布防纵深（详见 [01-地图与城市/城市成长与城防.md](../01-地图与城市/城市成长与城防.md)）。

**建造**：
- 建筑需要**回合时间**建成（即时生效不存在）；
- 建造**占用生产力** + **消耗生产资料**（材料类资源统称，构成待数值期）；
- **建造预览弹窗（城市规划核心 UX，R13 定）**：拍地基时弹窗提前告知此操作会引起的变化——选择不同建筑/设施时能看到**各自生效范围**预览，以及建成后**数值具体变化**的窗口。

**拆除三分法（R13 定）**：
| 场景 | 规则 |
|---|---|
| 建成后当回合拆除 | **无损**拆除（全额返还） |
| 修一半就拆 | 返还 **9 成生产资料**，释放占用的生产力 |
| 修一半停工放着 | 释放生产力、**不返还生产资料**、持续占用地块；**随时可回来继续建造**（进度保留） |

## 武将派驻建筑（R11 立项，数值待定）

城中角色可分配到具体建筑挂职，给该建筑对应效果加成：
- 派驻**军事基地** → 练兵速度、兵员质量提升；
- 派驻**商业中心**（院长口称"交易所"）→ 财政收入提升；
- 其余区域同理（学院/工业区/娱乐中心/农田的效果方向待细化）。

不同角色有不同侧重（挂勾武将属性体系，见 [02-武将/属性体系.md](../02-武将/属性体系.md)）——**谁驻哪个建筑是内政策略层**。数值与侧重维度后续专题讨论（R11 院长：数值后续慢慢讨论，先把机制记下）。

## 二期战场实体化（红警范式）

内政建筑在二期实时战场中实体存在：城墙=可拆墙体/城门、军事基地=补兵建筑、附属箭塔=防御塔、农田/商业中心=城外地表可掠夺建筑。详见 [04-军事/内政战场联动.md](../04-军事/内政战场联动.md)。
