## 一、1999 灾后世界线与开局基线

- **14 城按正常城市表现**；1999 大灾变只做世界观背景：绝大部分城市毁灭、人口流失、科技退化；其他毁灭城市不在地图体现。**不做废墟美术/废墟机制**。
- **初始总人口 119k**（旧 398k 的 30%）：CN 48.5k / JP 28.4k / KR 17.9k / AU 21.1k / 达尔文 3.2k；每城人口 = 初始岗位 / 0.95（所有岗位填满，5% 赋闲）。
- **科技退化**：开局只有轻工业（纺织/家电）；重工/矿场/火电锁在「工业复兴」科技后，首科技目标 **t20~30**（CN t20 / JP t21 / KR t25 / AU t30 / WLT t44）。
- **WLT 第 2 回合军阀割据**；WLT 无矿，钢来源靠**外交/贸易进口**（见 §八）。
- 初始粮产按「每千人 0.8~1.2 粮」重算；CN/JP/KR 开局缺粮、AU 自给；初始粮库存 2 年（AU/NONE 3 年）。
- 初始国库 1,500；税 **30 + 人口/1000**（⚠️ 11-02 审计：与农业区 `100+P/1500`、引擎 `50 平税` 冲突；院长已裁 **60 + 1.5×民用人口/1000 + 商业维护 3%**，见 [人口税与土地价格.md](./人口税与土地价格.md) §二）；初始兵力 CN 200 / JP 120 / KR 80 / AU 60。

## 二、区域定位与总览

- **工业区 18 类**：重工 3 + 矿业 4 + 高新 3 + 能源 5 + 轻工 3。
- **造船厂归军事建筑**（**2026-11-06 暂不做：海军/海战挂起**），不在工业 18 类内；后续海军专题再启用。
- **特色工业区后期解锁**（台积电等），不初始；所有特色建筑默认 +文化，数值文化专题定。
- **工业区不设行政上限**；自然限制保留：矿脉/沿海/河流/每城垃圾/地标。真正的上限是**岗位（人口）+ L2 用地 + 电力/矿产**。
- **占地**：每建筑有 `w×h` 矩形占地。**L1 只展示总量、不设上限**；**L2 真实摆放**用同一组 `w×h`（数据不变）。

## 三、统一口径

| 项 | 口径 |
|---|---|
| 建造消耗 | **财 + 生产 + 用地（L2）**；**不耗铁/煤**（防“铁用完了还没矿场”死档） |
| 金 | **自动折算为财**：1 金 = 8 财；金矿 4 金 → 32 财/回；金不进全国矿产池 |
| 维护 | **财造价 × 1%**（四舍五入） |
| 岗位 | 每建筑有岗位上限；玩家分配人口；产出 = 基础 × 在岗/岗位；**低于 20% 不停摆**，0% 才封存（无产出无维护） |
| 电力 | **城市级**；发电厂产电；耗电建筑按满足率打折；**电力运输科技**后全国余电自动分配（10% 损耗） |
| 升级 | Lv2 选规模/精益/清洁三路径之一，Lv3 沿该路径；升级后耗电；**停电托底 = 1.05×Lv1** |
| 矿产 | 铁/煤/铀**全国池**；矿场按城产出；**按城 50 回合/档**（多矿只增产、不加速枯竭） |
| 污染 | 本地污染进宜居；碳/SO₂/CFC 待 B11 环境专题 |

## 五、电力系统

### 5.1 供给与需求

```
城市电力供给 = Σ 发电厂电力（受在岗率/矿耗影响）
城市电力需求 = Σ 耗电建筑（按在岗率）
电力满足率 = min(1, 供给/需求)
耗电建筑产出/效果 × 满足率；0 电才停
```

### 5.2 耗电名单

| 建筑 | 耗电 | 说明 |
|---|:--:|---|
| 信号基站（军事/行政） | 3 | 通信/探索；1/城支撑件 |
| 军事基地 | 4 | 指挥/雷达/营区 |
| 造船厂 | 6 | 船坞设备 |
| 医院 | 3 | 医疗设备 |
| 互联网产业园 | **8** | 数据中心 |
| 半导体厂 | **12** | 晶圆厂 |
| AI 算力中心 | **20** | 算力中心 |
| 学院 Lv2+ | 2 | Lv1 不耗电 |
| 商业中心 Lv2+ | 1 | Lv1 不耗电 |
| 钢铁/化工/军工/矿场/轻工 | 0 | 自供电/已抽象进生产；保持“发电厂 vs 重工”的取舍 |
| 升级建筑 | +4/+8 | Lv2/Lv3 追加 |

### 5.3 电力运输科技

- 未解锁：每城独立，盈余浪费，缺口按满足率打折。
- 解锁后：全国电力池，盈余自动流向缺口城市；**输电损耗 10%**（1 度盈余只有 0.9 度可用），本地发电优先。
- 科技节点放 B4 能源/信息线。

### 5.4 模拟发现

- 高耗电已生效：CN 互联网 13 座 → 电力需求 104；AI 只在缺电时建电厂，没有狂铺光伏。
- 多数城市电力 100%，台北/墨尔本 91~96%；升级建筑靠“1.05×Lv1 托底”仍略高于 Lv1。
- **待调**：发电厂生产仍偏高（火电 10/光伏 6），部分城市电力过剩；后续可降发电厂生产或提高耗电需求。

## 六、污染治理

**原则：治污不能是纯成本，必须有副产/共益。**

| 建筑 | 降污染 | 共益 | 电力 | 造价/维护 | 说明 |
|---|:--:|---|:--:|:--:|---|
| 污水处理厂 | **−4** | **+1 电力、+2 生产**（沼气/中水） | 2 | 300/60/3 · 3 | 市政/环保类，非工业 18 类 |
| 环保产业园 | **−3** | **+4 科技、+6 财**（绿色产业） | 4 | 450/80/4 · 4 | 环保+高新复合 |
| 垃圾发电厂 | 不算降污染 | **+6 电力**；消化垃圾；自身 +2 污染 | 产 6 | 450/80/4 · 5 | 垃圾能源化，不是治污 |
| 脱硫设施（B11） | SO₂ −50% | **+2 生产**（石膏/建材） | 2 | 400/80/4 · 4 | 酸雨减产/维护惩罚减半 |

- 垃圾发电厂**不能替代**污水处理厂/环保园；它降低垃圾/宜居压力，但自己排 2 污染。
- 碳/SO₂/CFC 的完整排放表与酸雨数值待 B11 环境专题。

## 七、升级

> **铁律（2026-11-02 院长令，商业区开题 §4.4 明文化）**：升级（Lv2/Lv3）**不改变占地 `landW/landH`**——只动产出/岗位/电力/污染/专属效果。升级变占地会摧毁玩家用地规划。本表三条路径原本即未动占地，此处明文化并全局适用。

### 7.1 三条路径（Lv2 选一，Lv3 延续）

| 路径 | 产出 Lv2/Lv3 | 岗位 Lv2/Lv3 | 电力 | 污染 Lv2/Lv3 | 适用 |
|---|:--:|:--:|:--:|:--:|---|
| **规模线** | ×1.45 / ×1.95 | ×1.12 / ×1.25 | +4/+8 | ×0.95 / ×0.90 | 人口充足、追求产量 |
| **精益线** | ×1.30 / ×1.69 | **×0.80 / ×0.64** | +4/+8 | ×0.90 / ×0.80 | 劳动力短缺，自动化减人 |
| **清洁线** | ×1.20 / ×1.44 | ×1.00 | +4/+8 | **×0.50 / ×0.25** | 污染高、宜居吃紧 |

- 升级造价：`财/生产 × 1.6^(Lv−1)`；工期 = 基准工期。
- 每建筑专属效果后置（钢铁「特种钢」、化工「化肥」、军工「坦克线/直升机线」、火电「超临界/超低排放」、高新「先进制程/研发中心」、轻工「自动化/品牌」等）。

### 7.2 停电托底

```
升级建筑有效产出 = Lv1 产出 × max(电力满足率, 1.05 / 升级产出倍率)
```

- 例：钢铁 Lv1 20；Lv2 规模线 29，耗电 4。
  - 有电 29；停电 21（1.05×20）；半电 50% → 29×0.5=14.5，但被 21 托底。
- Lv3 同理，停电仍是 21；有电 39。**升级不会因停电变成负收益，但只有通电才吃满。**

## 十、就业、岗位与在岗率

### 10.1 人口三分

```
总人口 = 在岗劳动力 + 服役 + 赋闲
可就业人口 = 总人口 − 服役
就业率 = 在岗 / 可就业人口
在岗率 = 在岗 / 岗位总数
```

- **不做基础就业**；初始人口 = 初始岗位 / 0.95，**95% 就业、100% 在岗、5% 赋闲**。
- 每人只能在一个建筑、服役或赋闲；赋闲仍吃饭/住房，压低民生/治安。
- 岗位/人口比是城市核心：岗位多、人少 → 在岗率低（缺人）；人多、岗位少 → 就业率低（赋闲）。

### 10.2 岗位表

| 建筑 | 岗位 | 建筑 | 岗位 |
|---|:--:|---|:--:|

- 产出 = 基础 ×（在岗/岗位）；**低于 20% 不停摆**，0% 封存；维护随在岗率变化。
- 玩家可手动分配，提供五套预设：农业优先 / 工业优先 / 科技优先 / 金融优先 / 均衡；AI 用自动分配。

### 10.3 超高人口限制

- 拥挤：`H = 100×(0.5q + 0.5×crowd)`，`crowd = clamp(1.1−0.6×人口/承载)`；人口顶满承载宜居下降。
- 就业：就业率 <90% 民生扣分，<80% 治安扣分/起义风险；在岗率 <80% 劳动力短缺警告。
- 粮食/污染/住房共同限制；不设硬上限。福利/救济/以工代赈政策（B8）可抵消就业率惩罚。

## 十一、AI 优先级

### 11.1 打分规则

```
分数 = 基础需求分 × 国家权重 × 战争/和平相位 + 城市缺口修正
取最高且可负担、合法的建筑
```

- 国家权重：CN 重工/军工 ×1.3、高新 ×0.9；JP 互联网/半导体/AI/学院/信号 ×1.4、重工 ×0.9；KR 商业/军事/军工 ×1.3、重工 ×0.9；AU 矿场/能源 ×1.4、军事 ×0.8；WLT 食物/轻工/军事 ×1.2。
- 战争期：军事/装备 ×2，钢铁/化工 ×1.3，高新 ×0.7；和平期：军事 ×0.6，高新/商业 ×1.2。
- 城市缺口：缺粮 +100、缺电 +100、污染 +80、岗位不足 +100、赋闲 +50。
- **不设工业软上限**；用高耗电/岗位/矿产/财自然卡住；AI 后期继续升级（AU 52 次、JP 29、CN 23、KR 9）。

### 11.2 建筑优先级（自上而下取最高分）

1. 严重缺电/重度污染（应急）
2. 食物（缺粮/库存 <2 年）
3. 住房（在岗率 <90% / 承载 >90%）
4. 学院（无学院/科技过低）
5. 矿场（铁/煤/铀池 <30 且有矿脉）
6. 军事（装备缺口/战争）
7. 钢铁/化工（有矿、岗位未超 1.10×）
8. 电力（需求 > 供给 1.1×）
9. 治污/环保园（污染 >15）
10. 互联网/半导体/AI（有电、岗位未超 1.10×）
11. 商业/学院/公园/医院
12. 轻工/钢铁填充（赋闲 >3,000）
13. 升级（稳定、财 >1,500）

### 12.3 结论与已知问题

- 工业 18 类的产出/岗位/占地/电力/污染/造价组合**可跑通**：无死档、无饥荒、无财爆仓。
- 劳动力是主约束：中期在岗率 87~94%，玩家需要住房/生育/移民；AI 仍偏贪心，JP/KR 会铺多岗位。
- 电力在多数城市不紧张；发电厂生产偏高，需降产或提高耗电。
- 环境治污有效但单座 −4 偏弱；垃圾发电不是治污。
- WLT 无钢，军备效率 55%；靠贸易/进口钢解决（见 §8.2）。
- 模拟是启发式“合理玩家”，非最优；数值为结构验证，不追求一次平衡。
