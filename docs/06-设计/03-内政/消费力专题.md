## 一、概念定义（专有名词纪律，首次出现即定义）

| 词条 | 定义 |
|---|---|
| **消费力** | 城市人口每回合的购买力总量。**定义式：`城消费力 = 民用人口/1000 × 2.5 × K_desire 财/回`**；**民用人口 = 总人口 − 服役**（服役人口的口粮/装备走军事供给，不进零售池）。系数可被政策/科技修正。它是城市**零售 + 娱乐 + 文旅**消费端收入的来源池；**跨城消费抽象为本城消费力**（本城人可去邻城、邻城人可来本城，简化不建模城际流动）。**城市级概念：不设全国消费池/全国汇总**（2026-11-02 院长裁）；人口迁移/城市易手时随人口走。**消费池/消费力池 = 同一概念的别名**——正文统一用"消费池"（池容量即消费力）。 |
| **消费欲望** | 居民"**愿不愿意花钱**"的宏观系数 `K_desire`（0.5~1.5，基准 1.0，11-12 院长令立）：受**就业（在岗率）/ 宜居度 / 战争 / 税负压力 / 基本需求供给（缺粮/缺电/民生<30）**影响；乘进池上限。`消费力 × 欲望 = 有效需求`——有钱不敢花时池上限低于购买力（预防性储蓄）。公式见 §1.1；调研见 [消费欲望与消费信心调研](../00-调研/消费欲望与消费信心调研.md)。 |
| **消费回收** | 商业/娱乐/文旅建筑把居民（及抽象访客）消费转化为收入的过程。**回收 = min(本类份额剩余, 单座上限) × 在岗率**——份额剩余代表本类消费容量，在岗率代表供给端服务能力；战时劳动力转向军工→在岗率下降→回收下降，**池本身不变**。商业街/商场是零售回收器；娱乐建筑（影院/乐园/体育馆等）与文旅建筑（酒店/会展/世博）同池竞争。 |
| **消费饱和** | 本类份额剩余趋零的状态——新建同类建筑收益边际递减，直至白建。表现为建造预览数字变小，无任何惩罚。**同池三类（零售/娱乐/文旅）会互相挤占**；v11d-c 定**固定份额 60/25/15**（先建先得会让文旅全零）；**缺类与吃不完的剩余按现存类权重回流**（§1.1）。 |

**概念边界（2026-11-02 院长修正版：商业街也是为居民消费的——灵活就业）**：

- **商业街**：居民日常小额消费 + 灵活就业（摊主即就业）——**吃池**，单座回收上限 12 财（固定值）。**小城的池回收器**：10k 小城池 25，两条商业街几乎吃满；
- **商场**：居民大额消费——**吃池**，单座回收上限 **60 财/回（固定值）**。**大城的高效回收器**；
- **娱乐/文旅**：影院/乐园/体育馆/酒店/会展等也**吃池**（11-05 裁）；文旅收入再乘城市热度 **`(0.5 + Heat/100)` 封顶 2.0**（11-05 B 方案：份额=本地居民的钱、乘区=**外来游客的钱**，无热度 0.5 保底=商务/过境客流）。**同池三类会互相挤占**；固定份额 **60/25/15**（缺类时按比例归一回流，11-05 裁）。
- **写字楼**：象征**小微企业/专业服务业**（B2B，服务企业和外部客户）——**不吃池**，产出挂岗位。城市经济的生产侧；
- **一句话**：池管所有"赚本地居民/访客钱"的建筑（零售+娱乐+文旅，同一池）；写字楼赚外面的钱（岗位驱动）。**同池多类按固定份额（60/25/15），同类别内按建造顺序依次结算**。

### 1.1 同池分配公式（固定份额 + 剩余回流 · 2026-11-12 明确）

```
K_desire = clamp( 1.0
  + 0.30 × (在岗率 − 0.95)          // 就业
  + 0.20 × (宜居 − 50)/50           // 宜居 ±10%
  − 0.15 × 交战  − 0.10 × 被占领军管 // 战争/占领
  − 0.20 × 税负压力                 // (实际税负−基准)/基准，clamp 0~1
  − 0.15 × 供给危机                 // 缺粮/缺电/民生<30 任一
, 0.5, 1.5 )

总池     = 民用人口/1000 × 2.5 × K_desire × (1 + 政策修正 + 科技修正)
类份额   = 总池 × { 零售 60% / 娱乐 25% / 文旅 15% }
本类回收 = min(本类份额剩余, 单座上限) × 在岗率        // 类内按建造顺序依次结算
剩余回流 = 某类建筑回收总额 < 类份额时，差额按现存类权重回流给其他类（结算一次）
```

- **份额是需求结构基准，不是硬上限**：60/25/15 来自真实居民支出结构（商品零售/教文娱/旅游），保证文旅不被零售饿死；但**某类没有建筑或吃不完，其份额不会蒸发**。
- **只做娱乐 → 娱乐吃满 100%**（零售/文旅无建筑，75 全部回流）；不是锁死 25%。
- **只做零售（1 条商业街上限 12）→ 零售吃 12，剩余 48+15 回流给娱乐/文旅**（按各自份额权重）。
- 回流规则=**本卡 11-12 补充明确**（原裁"缺类归一回流"的完整化）；v11d-c 模拟实现是否含"吃不完回流"待黑机核对，**v22 单城对照盘补"只做娱乐 / 只做零售"两个极限局验证**。
- 娱乐份额内实际参与者：文化区大众娱乐 + live/音乐厅/歌剧院 + **红灯区三条线九卡**（11-12 入池）。
- **欲望只改池上限、不改份额结构**：战争/重税压低的是有效需求总量，60/25/15 的消费结构不变。

### 1.2 三类消费的差异化收益（份额保底的目的：不让"只造零售"成为最优）

| 消费类型 | 财 | 非财收益 | 优势定位 |
|---|---|---|---|
| **零售**（商业街/商场） | 纯回收（单座上限 12 / 60） | 无 | 门槛低（1×1 / 30k 解锁）、确定性强、不依赖热度 |
| **娱乐**（文化区娱乐 + 红灯区） | 份额内回收 | **文化值 + 宜居 E + 城市热度**（红灯区另给热度、净财收益全表最高） | 财+文化双收；文化胜利的进度来源 |
| **文旅**（酒店/会展/世博） | 份额内回收 × **热度乘区 `clamp(0.5+Heat/100, 0.5, 2.0)`** | 文化值 | **突破本城消费池**（外来游客的钱，可溢出本地份额） |

- **份额保底**保证三类都有生存空间；**差异化收益**保证玩家有动机主动建娱乐/文旅，而不是"只造零售吃回流"：
  - 只造零售=只拿财，放弃文化胜利进度、宜居、热度与外来客流；
  - 娱乐/文旅单位占地收益更高（含乘区），且热度越高文旅越赚——**大城+高热度**时文旅是最优消费投资。
- 数值锚点见 [文化区数值 §2/§4](../03-内政/文化区数值.md) 与 [红灯区建筑数值](../03-内政/红灯区建筑数值.md)（九卡净收益 6~35 财/回）。

## 二、心智负担设计（院长核心考量：上手快 / 玩得动 / 玩得爽）

### 2.1 总纲：公式进引擎，玩家看结果

玩家**永远不需要知道"池"的存在就能玩**；池通过建造预览的数字自动表达自己。想玩深的人从数字规律里悟出深度——**不考试、不设门槛、不做强制交互**。

### 2.2 三层认知深度（渐进揭示，全兼容）

| 层 | 玩家的理解 | 怎么玩 | 对应人群 |
|---|---|---|---|
| **L0 零概念** | "建商业建筑就有钱" | 照建造预览的实际数字建（预览已算好边际收益，不会踩坑） | 大多数朋友 |
| **L1 一句话** | "人口越多商业越赚；大城建商场" | 城市规模导向建设 | 进阶 |
| **L2 深策略** | "消费有上限，堆消费端建筑会饱和；政策/科技能扩池" | 消费池管理 + 政策调控 | 高手 |

### 2.3 UI：数字自己会说话（三个展示位，零操作）

> **2026-11-02 院长裁：消费力只做城市级展示**——城市面板一行是唯一常驻位；不设全国汇总/全国池；建造预览与播报都按当前城市结算；人口迁移/城市易手时消费力随人口走。

1. **建造预览直接给净收益**：第二座商场预览显示 **"+15 财/回（本城消费趋于饱和）"** 而非理论值 60——边际递减不需要玩家懂池，预览数字自己说明一切；池剩余 <20% 时**红字警示**"本城消费已饱和"。
2. **城市面板一行**：`消费 60/75 ↗`（已回收/总池 + 趋势箭头，人口涨箭头绿）——看不看随缘；悬停出 tooltip（金色下划线专有名词机制复用）。
3. **商情播报（被动事件流）**："本城消费力提升"（人口过门槛）、"消费刺激政策生效，全城商业收入 +15%"——成长与政策的可感知表达，复用驻城武将汇报机制。

### 2.4 玩得爽：三个正反馈

1. **成长感**：人口涨 → 池自动扩 → 商场收入自动涨——**不操作也有收益成长**，是"城市变强"最直观的年度报表；
2. **解锁感**：30k 人口解锁商场=城市成长的明确里程碑（大城专属奖励）；
3. **政策爽点**：消费刺激政策一出全城普涨（宏观手笔感）——挂 B8。

### 2.5 防呆设计

- 30k 人口门槛本身是第一道防呆（池太小的城根本建不了）；
- 建造预览红字是第二道；
- **不做任何惩罚**：饱和只是"白建"，不亏钱不掉民生——试错成本为零。

### 2.6 消费情景标签（五档 · 2026-11-12 院长令）

> 用两个维度诊断城市消费状态：**池上限**（有效需求，主要由 K_desire 决定）与**利用率 U = 实际回收 / 池上限**（供给匹配度）。城市面板"消费"行后缀一个标签，玩家看标签就知道下一步，**不需要懂公式**（标签=诊断+行动提示，不做惩罚）。

| 标签 | 判定 | 经济学对应 | 玩家行动提示（tooltip 一句话） |
|---|---|---|---|
| **消费繁荣** | U ≥ 85% 且 K_desire ≥ 1.0 | 有效需求高、供给匹配（接近**市场出清**） | 状态好，保持或继续扩池 |
| **消费饱和** | U ≥ 85% 且 K_desire < 1.0 | 居民已充分消费，掏不出更多钱（**消费饱和**） | 扩池：人口增长 / 消费刺激政策 / 科技扩池 |
| **供不应求** | U < 50% 且 K_desire ≥ 1.0 | 有钱没处花（**供给不足 / 消费外流**） | 建消费建筑：商场 / 娱乐 / 文旅 |
| **消费低迷** | U < 50% 且 K_desire < 1.0 | 有余钱但不敢花（**预防性储蓄 / 低欲望**） | 提就业 / 宜居 / 降税 / 停战 |
| **平稳** | 其余 | 中间态 | — |

- **判定输入**：K_desire（§1.1 公式）+ U（城市实际回收/池上限），均为引擎内部量，UI 只显示标签与"消费 X/Y"数字。
- **与三展示位的关系**：城市面板一行 = `消费 60/75 🏷繁荣`（悬停 tooltip 解释标签含义）；建造预览仍给净收益与饱和红字（§2.3）——标签是第三展示位的升级，不新增操作。
- **状态随城市演变**：战争/重税会从"繁荣"滑向"低迷"；建满供给从"供不应求"转"繁荣"；人口增长从"饱和"转"繁荣"——玩家能直观看到自己决策的宏观结果。
- **术语锚点**：有效需求=池上限、消费实现=实际回收、市场出清=繁荣、消费饱和/低迷/供不应求=五档标签；详见 [消费欲望与消费信心调研](../00-调研/消费欲望与消费信心调研.md) §五。

## 四、与"财的出口"的关系（边界声明）

- 消费池=**需求侧上限**（居民/访客愿意花多少），**不是玩家的钱**；建筑回收=这笔需求转化为财政收入。池本身不扣国库；
- **娱乐/文旅维护费=出口侧**（持续 sink）；外交赠礼/买进度归 B12；
- **11-05 裁：娱乐消费进池**——居民娱乐支出占用池容量（视作间接税），与"娱乐建筑直产财"是**同一笔消费的两面，不双算**；维护费才是净出口；
- 远期接口：若做循环流模型（居民消费支出反过来消耗国库），池是现成地基——**本期不做**，挂账。

### 8.1 消费池真实世界调研（2026-11-05，白机）

- **调研文档**：[../00-调研/消费池真实世界运作调研.md](../00-调研/消费池真实世界运作调研.md)（中日韩澳官方家计口径 + 旅游数据 + 热度案例，均注来源年份）。
- **关键数**：①居民侧娱乐文教 7~12%、旅游 ≈14%——**60/25/15 中的"15"与真实居民旅游支出占比对齐**；②收入弹性 旅游>娱乐>零售（富起来先买体验）；③**旅游收入大头来自"别人的消费池"**（访日客消费占日本旅行总消费 23.7%，且日本人国内游也多为跨县流动）——真实世界文旅主要不与本地零售抢同一笔钱；④热度=脉冲乘数 **1.7~4 倍、数月衰减**（淄博/哈尔滨/大阪世博 2,901 万人次）；⑤同池挤出真实存在（2024 总消费 +5.3% 而旅游 +17.1%，增量被文旅虹吸、食品刚性）。
- **对表现行设计**：固定份额 60/25/15 获真实数据支持；热度乘区 >1 的溢出=外来消费的抽象位；节庆/赛事事件增益项与"脉冲衰减"先例吻合（数值可挂 +30~60 热度点、10~20 回衰减）。**张力**：调研启示"文旅应单列外部注入（可占文旅收入 60~90%）" vs 11-05 院长裁"不设独立游客池"——处理选项见文化区讨论，落档后回填本节。
