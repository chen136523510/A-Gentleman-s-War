## 三、口径对撞（11-05 院长五令后：#1 留待同批标定，#2/#3 已裁）

### 对撞 1（数值标尺）：文物加成 vs 文化区"基础文化值压低"——具体账（11-05 院长令详述）

**背景**：文化区第七轮把文化直产降档 ≈×0.7（六轮裁：博物馆 6→**4**、会展 9→**6**、世博 14→**10**、音乐厅→5、歌剧院→9），同时裁"基础文化值压低至占城文化产出 ≤20~30%"——即**建筑直产是文化主力（公式 A），其余来源全是添头**。而 §4.9 的草案示例"青铜器：文化 +3 / 本城陈列 +5"写于降档**前**的旧标尺（当时博物馆本体=6）。

**沿用旧标尺的后果（算账）**：
1. 单件 +3 = 降档后博物馆本体（4）的 75%；故乡件 +5 **反超**本体——一件文物比整座博物馆还"文化"，主客颠倒；
2. 满陈列 2 槽全是故乡件 = +10/回 > 博物馆+live house 之和（4+2=6）——**文物成了文化产出第一主力，建筑沦为配件**，违背公式 A；
3. v11c 实测文化输出整体是添头量级（k=0.0025 添头区、200 回合 0 完全入侵）——文物大加成会在模拟里主导文化输出曲线，v12 起所有文化侧模拟失真；
4. 稀缺品不可复制（每件独一无二），先挖到厚城的一方获得不可追赶的固定优势——**违背"负反馈纪律"**（前期差距应可追）。

**新标尺（草案，随 v0.2 建筑卡同批校准）**：文物文化基值 = 主力建筑的 **1/8~1/2**——普通 0.5 / 名品 1 / 传世 2，故乡 ×1.5 封顶 3/回（< 博物馆本体 4）。校验：西安满挖满陈 ≈6.75/回 ≈ 满配文化建筑产出（15~25/回）的 30% 上限内。一句话：**文物是博物馆的"子弹"，不是第二支枪**。

### 对撞 2（机制语言）：常驻件特效怎么落 → ✅ 已裁（11-05 院长令①：**结算末端注入外部参数**）

**院长裁定原文**："先结算公式，最后结算典藏提供的外部参数。"——典藏**不进任何主公式**（城市文化值/忠诚流水/同化等按 R47 管线正常结算），典藏效果一律作为**管线末端的注入参数**（末端加成或乘区）。落点：

| 注入点 | 形态 | 例 |
|---|---|---|
| 城市文化值结算末端 | +Σ陈列件基值（不吃因子/政策乘区，UI 流水明牌一行） | 名品陈列：城文化值 +1 |
| 忠诚流水结算末端 | ×(1+常驻件系数) 或 +系数/回 | 传国玉玺候选：民生流水末端 +0.5/回 |
| 同化/外交等各系统末端 | 同上逐系统登记 | 良渚玉琮试点：同化 +0.5%/回 |

- 与传媒大学"乘输出层防复利"同纪律：**末端注入不被下游因子放大**，数值可读可审计；主公式保持纯净（R47 总纲不因典藏改版）。
- **主动脉冲型候选**（调研结论 3，群星 Relics 式）：常驻件可带 CD 主动技能（如"大阅"：每 20 回合一次，全国忠诚流水脉冲）——主动效果=回合动作层一次性注入，同属末端注入制。是否采用→议题 #2 余项，院长裁。

### 对撞 3（获取节奏）：21 将宝物 → ✅ 已裁（11-05 院长令②：**部分开局自带，细则归武将专题**）

- 宝物**部分开局自带**成立（三国志 12 范式）；自带清单/属性/与个人忠诚公式的衔接**移武将专题**（21 将四维/技能本就待该专题，宝物与人物成对设计才是正确粒度——调研结论 5：宝物系统的情感重心在"宝物与人"）。

- B6 范围内获取节奏收敛为：考古（文物池 36 件 ✅）+ 事件卡投放 + 外交交易 + 掠夺（接口）。

### 5.2 单件配置字段（✅ v0.5：**三组效果可叠加**，11-05 院长样例确立）

> **模型变更**：院长给的 3 个样例（小霸王/台积电光刻机/兵马俑）都是"常驻 + 陈列 + 赐予"三组并存——所以不是"三选一部署"，而是**持有即常驻、部署再叠加**：
> **常驻（国家级）始终生效；该件再被放入博物馆（陈列）或赐予武将（赐予）时，额外获得对应效果。**

**字段规则**：
- **无 `tier`**（不做价值分类）；**无 `heat`**（不提供热度）；**无 `activeSkill`**（不做主动脉冲）；**无 `series`**（系列彩蛋暂缓，院长令"后续再提"）。
- `passive`/`display`/`grant` **三组均可为空**——有的件只有陈列效果，有的件三者俱全（院长样例即三者俱全）。
- `passive` 可含**质变型效果**（如 `techNodeDiscount`）——需科技树支持 `nodeCostMultiplier` 字段，接口留科技系统。
- **`revokePenalty` 铁律 > `grant.loyalty`**（保底 ×1.5，按武将性质再乘系数）；防"送了又收"刷忠诚。
- 数值量级（院长样例标定）：陈列文化 **+1~+4**、陈列科技 **+1~+2**、常驻文化 **+2**；赐予忠诚 **+2~+7**、属性 **+1~+2**。全池合计只需"不影响主系统"，**不做件间平衡**（院长 #12）。

### 5.3 三类部署 + 归属三规则（✅ #8 院长裁）

| 部署 | 生效 | 归属/掠夺 |
|---|---|---|
| **常驻（持有）** | `passive` 始终生效（国家级，不占槽） | **随国**——国家灭/投降则归征服方 |
| **陈列本城** | `display` 额外生效（城市级，占博物馆槽位）；故乡加成保留 | **随城**——城被占，陈列件归占领方 |

### 7.1 机制待裁详解（2026-11-05 白机算账）

#### B1：A/B 案——为什么 B 案数学上不可行

**起点：现行公式的硬伤**

```
现行：Δ = k × Output ÷ Resistance
      Output = √Culture_A × 系数（约 100~200 量级）
      Resistance = 40 + Culture_B / 50（存量越大越抗打，线性）
```

用 v11c 的 t200 实测存量代入（CN 34.4k / JP 20.7k / KR 14.0k / AU 14.5k）：

| 项 | 数值 |
|---|---|
| CN 抵抗力 | 40 + 34400/50 = **728** |
| KR 对 CN 的输出 | √14000 = **118** |
| 单回合转移（k=0.0025） | 0.0025×118/728 ≈ **0.0004 点/回** |

→ 200 回合合计约 0.08 个百分点。**等于没有。**

**B 案（保骨架）为什么救不回来**：把抵抗改成相对式（40~130）、k 提到 0.015，单回合 Δ = 0.015×118/130 ≈ 0.0136 点/回，200 回合约 1.8 个百分点。要到 60% 需要 **k≈0.33**——而 v11c 实测 k=0.01 时本国认同已崩到 24~41%。**k 每提高一个量级，先崩的是本国认同，不是达成入侵。** 根因是 `Δ∝绝对输出/绝对抵抗`，而两者随存量以不同幂次增长，比例永远趋近 0。

**A 案（份额收敛）为什么能成**：

```
P[A→B] = √Culture_A × 距离 × 联系 × 情报 × 战争     ← 每个国家对 B 的"文化压力"
P[B→B] = √Culture_B × (1 + 抵抗加成)                ← 本国自压（抵抗投入落点）
Target[A→B] = P[A→B] ÷ Σ所有对 B 的 P              ← 目标份额（市场份额）
Identity[B:A] += r × (Target − Identity)             ← 每回向目标收敛
```

**t200 实算（假设 CN 对 KR，系数全开 vs 无情报远洋）**：

| 输出国→KR | P 值 | 份额 |
|---|--:|--:|
| CN（邻接+航线+情报=1.0） | 185 | **52.7%** |
| KR 自压（无抵抗加成） | 118 | 33.6% |
| JP（远洋+无情报=0.18） | 26 | 7.4% |
| AU（远洋+无情报=0.18） | 22 | 6.3% |
| **合计** | **351** | 100% |

→ CN 52.7%，**差 7.3 个百分点到 60%**。玩家要做的就是补上这 7 点：
- **文化投入**：CN 存量翻倍到 68k（√=261）→ 份额 61.2% ✅ 达成；
- 或**削弱对手自压**：掠夺/占领 KR 城市（自压下降）；
- 或**提系数**：同盟（+0.2）叠满 → 份额进一步上升。

**A 案的关键优势**：
1. **阈值可达**（需要经营，不是需要作弊）；
2. **多极自动锁死**（两国输出相等 → 各 40%，谁也到不了 60%，不用特判）；
3. **抵抗有落点**（自压份额可被建筑/政策抬高，防御是主动行为）；
4. **不会崩本国认同**（本国自压是分母里的实打实一项，多国只分剩余份额）。

**结论：选 A。** B 案留作修改器"暴力文化"对照档（k=0.33 时确实能入侵，但所有国家都碎）。

#### B2：收敛速率 r 是什么、0.05 意味着什么

`Identity += r × (Target − Identity)` 是**指数收敛**：每回合走完剩余差距的 r 比例。

| r | 20 回 | 40 回 | 60 回 | 80 回 | 手感 |
|--:|--:|--:|--:|--:|---|
| 0.03 | 46% | 70% | 84% | 91% | 慢热：玩家投入 30 回合才明显见效，适合长局 |
| **0.05** | **64%** | **87%** | **95%** | **98%** | **推荐：约 10 回合看到"1/3 进度"，60 回合基本定型** |
| 0.08 | 81% | 96% | 99% | 100% | 快：一次性事件（战争/政策）影响被放大，曲线抖 |

- **r 太小（<0.03）**：文化胜利变成"挂机等"，玩家感受不到投入回报；
- **r 太大（>0.08）**：一场 20 回合战争把认同清零后，恢复也只需 20 回合——文化战变成短期冲刺，失去"长期经营"的味道；
- **兼作衰减**：战争期 P=0 → Target=0 → 认同以 r 速率回落。r=0.05 时，20 回合战争把 60% 认同打到 21.6%（约 1/3 保留），符合"打仗伤文化"的直觉。
- **建议 0.05，balance.json 留 0.03/0.05/0.08 三档**（难度/修改器用）。

#### B3：抵抗加成从哪来

抵抗不是独立数值，而是**抬高本国自压 P[B→B]**，从而稀释所有外国份额。

| 来源 | 加成 | 说明 |
|---|---|---|
| **文化建筑**（主源） | 每座博物馆 +3% / 会展 +5% / 世博 +8% | 与文化区谱系一致；满配（2 博+1 会展+1 世博）≈ +19%；回填 v0.2 建筑卡 |
| **政策卡** | "文化自信" +15%；"电子长城"特殊（互联网乘数双向失效，已定）；"开放社会"反向 −10%（换经济收益） | 政策与政体 §四 登记 |
| **科技** | 民生线文化相关节点每节点 +2%，封顶 +10% | 学院区科技树补 `cultureResistance` 字段 |
| **事件** | 临时 ±5~10%（文化节/外流潮） | 事件轮 |

- **总上限 +50%**（防叠成无敌；也保证文化胜利永远有可能达成——上限内 60% 份额仍可被 2 倍文化优势突破）。
- **设计意图**：抵抗投入花的是财/产能/政策槽，与军事防御争资源——**文化自守 vs 文化扩张**成为一组真选择，而不是"堆一个数字"。
- **反向验证（同一组数）**：
  - 若 **CN 满抵抗 +50%**：自压 185→278，分母变 278+118+26+22=444 → CN 份额 **52.7%→62.6%**，KR 份额 33.6%→26.6%。**KR 想入侵 CN 从此基本无望**；
  - 若 **KR 满抵抗 +50%**：自压 118→177，分母变 185+177+26+22=410 → CN 份额 **52.7%→45.1%**，KR 自守成功，CN 需再加文化投入才能破 60%。
  - → **建不建文化建筑，直接决定会不会被文化吞并**——抵抗从"数值墙"变成"可经营的战略选择"，这是本机制的策略深度所在。
