# 人口算法 v1（宜居度 / 民生）

> 状态：🏗️ **v1 提案（R44b）**——具体公式 + 常数默认值 + 验算案例；院长逐项拍板后进 `balance.json`。
> 上游：概念架构见 [人口体系架构.md](./人口体系架构.md)；本文件只写"怎么算"。
> 三条铁律：①**同步结算**——目标值一律读上回合末状态，避免三角循环死锁；②**每个参数都出现在式子里**，且升降方向单调；③**冲击是伤、目标是病**——瞬时冲击扣实际值，不污染目标值。

## 〇、单位与口径

| 量 | 单位 | 说明 |
|---|---|---|
| 人口 | 人 | 中城制：单城 15,000~50,000（Q0 默认） |
| **粮** | **千人份/年** | **1 粮 = 1,000 人一年的口粮**——这样 R37b 的"自给粮 20/城"与 3 万人口城市自洽（20 粮=2 万人份，缺口靠农田补） |
| 财 / 生产力 / 科技值 | 抽象点 | 沿用现有口径 |
| 军备 | 件 | 1 兵 1 械 = 满效率（K=1） |
| 服役 | 人 | 从本国人口扣 |
| 所有状态量 | 0~100 | 百分比/百分制；比例类另标 |

> 粮食安全字段挂城市层（接口不变），**v1 由阵营粮账统一计算后写入每城**（现有财粮是阵营账，改动最小）；地方粮仓差异化留 v2。

## 二、子式（六个）

### 2.1 住房分 H（用上承载率与住房质量）

```
拥挤分 crowd = clamp(1.10 − 0.60 × r, 0, 1)
住房分 H     = 100 × (0.5 × q/100 + 0.5 × crowd)
```
- r=0.9 → crowd=0.56；r=1.0 → 0.50；r=1.5 → 0.20；r=1.83 → 0。
- 住房质量四型默认分：鸽子笼 20 / 密集公寓 40 / 小区 70 / 别墅 90（按承载量加权）。
- 单调性：r↑→H↓；q↑→H↑。**两者全程有效**（无死区）。

### 2.2 外籍摩擦 Φ（用上外籍比例与舆论倾向）

```
Φ = 35 × f^1.3 × (1 − 0.005 × O)
```
- f=0.1 → 1.75；0.2 → 4.2；0.4 → 10.4；0.6 → 17.2（O=0）。
- O=−100（民族主义）→ ×1.5；O=+100（多元主义）→ ×0.5。
- 指数 1.3 = 边际递增：少数外籍无感，过半则剧痛。

### 2.3 兵役负担 Β（用上服役比例）

```
Β = 400 × v²
```
- v=2% → 0.16；5% → 1.0；10% → 4.0；20% → 16.0；30% → 36.0。
- **无硬阈值**：从 0 起就有边际，二次曲线让"大规模动员"的代价陡增。

### 2.4 粮食安全 F（全国统一粮池；农田/牧场/食品工业三来源；库存上限）

```
全国需求 D = Σ城市( P/1000 × 1.0 + 服役/1000 × 1.5 )     （粮单位=千人份）
全国供给 Q = 农田 + 牧场 + 食品工业 + 进口
             农田/牧场受"耕地容量"上限约束；食品工业受"产能+科技"上限约束
库存   K' = max(0, K + Q − D)，且 K ≤ 2×D                  （战略储备两年，不是种够一百年）
全国粮安 F = 100 × clamp( (Q + K) / (1.2 × D), 0, 1)
```
- **统一调配（R44d 院长确认）**：各城产出进全国粮池，按需求统一分配——**上海缺粮可以从西安调**；城市面板显示的是"全国粮安"，不是本城自产。只有被围/封锁时该城断供（本城 F 按 0~30 计）。
- **三来源平价**：农田与牧场同级同产出（牧场地形不同）；食品工业（罐头/预制菜）把产能+科技转成粮，不受耕地限制、但受产能与能源约束。
- Q=1.2D、K=0 → F=100；Q=D、K=0 → 83；Q=0.5D、K=0 → 42。
- 人口↑/服役↑ → D↑ → F↓；农田/牧场/食品工业/进口/库存↑ → F↑。全程单调。
- **耕地安全线**：全国食物产能 `Qcap < 1.2×D` 时面板报警（不是硬锁）——提示玩家补农田/牧场/食品工业/进口，而不是"种够一次就躺平"。
- **粮仓上限 2×D**：防止 `K=1101≈18 年需求、F 长期锁 100` 的失真（R44c 沙盘发现）。

### 2.5 舆论调制 Μ（用上舆论倾向与耐受度，决定事件符号）

```
signMod = 1 − 2 × (O/100) × s          （s=事件的外籍/意识形态载荷，−1~+1）
ΔW_evt  = clamp( −A × signMod × (1 − 0.005×T), −30, +30 )
```
- 接收难民 s=+1：O=−60 → signMod=2.2（冲击翻倍为负）；O=0 → 1.0；O=+100 → −1（**变正**）。
- 败仗/天灾 s=0：signMod=1，纯负面；耐受度 T 越高冲击越小（T=100 减半）。
- **这是"民族主义 vs 白左"的数学落点**：同一事件在不同舆论下符号相反。

### 2.6 耐受缓冲 Τ

```
直接项：+0.10 × (T − 50)          （T=100 → +5；T=0 → −5）
冲击项：× (1 − 0.005 × T)         （T=100 → 冲击减半）
```
- 爱国教育既抬基线、又抗冲击，两个通道都用上。

## 三、宜居度主式

```
L_raw = B_L
      + 0.40 × (H − 50)          ← 住房（承载率+质量）
      + 0.20 × (E − 50)          ← 娱乐
      + 0.25 × (Se − 50)         ← 治安
      + 0.15 × (Me − 50)         ← 医疗
      − 0.30 × U                 ← 本地污染
      − 10 × 海平面等级           ← 0/1（二级即淹没，不参与）
      − 0.30 × 臭氧伤害           ← 0~100
      − 0.30 × 核残留             ← 0~100
      + pol_L
L_target = clamp(L_raw, 0, 100)
```
- 全中性（各项=50、污染/环境=0）→ 50；全满且零污染 → 100；全零+重污染 → 0。
- **酸雨不进此式**（走粮产 −10% 与维护 +20%），避免同一环境因子双算。
- 输出：①生产全产出乘区（见 §七）；②人口增速因子；③民生输入。

## 四、治安主式

```
Se_raw = B_S
       + 0.40 × (W − 50)          ← 民生（唯一正反馈入口）
       − 25 × f^1.1               ← 外籍摩擦
       + 0.20 × (G − 50)          ← 治理
       + GAR                      ← 驻军/警力 0~25
       − 12 × WAR                 ← 战争 0~3
       − 10 × max(0, r − 1.0)     ← 超承载拥挤
       + pol_S
Se_target = clamp(Se_raw, 0, 100)
```
- **同化不直接进此式**：同化→外籍比例↓→摩擦↓，避免双算（架构文档同步修正）。
- 中性（各项=50、f=0、GAR=0、WAR=0、r≤1）→ 50。

## 五、民生主式

```
W_raw = B_W
      + 0.22 × (F − 50)          ← 粮食（F<50 时走饥荒膝，见 §十三）
      + 0.28 × (L − 50)          ← 宜居（主因子）
      + 0.12 × (Se − 50)         ← 治安
      + 0.10 × (G − 50)          ← 治理
      + 0.08 × (Ea − 50)         ← 财富与就业
      − Φ                        ← 外籍摩擦（含舆论调制）
      − Β                        ← 兵役负担
      + warSupport               ← 战争支持度（见下；不再是 −8×WAR）
      + 0.10 × (T − 50)          ← 耐受度直接项
      + 0.10 × M                 ← 短期情绪
      + pol_W
W_target = clamp(W_raw, 0, 100)
```

### 5.1 战争支持度（R44d 院长口径：战争负收益已足够，别把统一路线堵死）

```
warSupport = WAR × ((O < 0 或 军国主义) ? +3 : −2)   ← 民族主义/军国主义开战有rally；多元主义反战
             − 0.35 × warTurns            ← 战争疲劳（每回合累积，停战清零）
             − 0.15 × max(0, 50 − F)      ← 缺粮放大反战
```
- 民族主义 WAR=2：开战 +6，10 年后 +2.5，20 年后 −1，30 年后 −4.5——**先高涨后疲劳**。
- 多元主义 WAR=2：开战 −4，10 年后 −7.5——**一开始就不受欢迎**。
- 战争的真实代价走另外三条：**服役占人口（Β）+ 军用粮（D）+ 士兵/财消耗**；WAR 本身不再叠加大额直接惩罚。
- 击败/胜利另走事件情绪（M/首长汇报），不在此式重复。

- 全中性 → 50；典型开局 ≈60；被围+断粮+高外籍 → 个位数。
- **国家级民生 = 人口加权平均**（HUD 显示）。

## 六、状态更新（缓动 + 冲击）

```
每回合（全部读上回合末状态算目标）：
  L_actual += clamp( (L_target − L_actual) × 0.25, −10, +10 )
  Se_actual += clamp((Se_target − Se_actual) × 0.25, −10, +10 )
  W_actual += clamp( (W_target − W_actual) × 0.25, −10, +10 )

  然后应用本回合事件冲击：
  L_actual += ΔL_evt                      （天灾/轰炸，−N）
  W_actual += ΔW_evt                      （§2.5，±30 封顶）
  M ← clamp( 0.80 × M + 0.80 × ΔW_evt, −100, +100 )   （情绪跟随冲击、每回衰减 20%）
```
- 缓动 25% ≈ 9 回合走完 90% 缺口（1 回合=1 年）。
- 冲击只扣 actual，target 不变 → **自愈但需要时间**；恢复期内照样触发移民/起义。

## 七、后果式

### 7.1 生产产出（宜居乘区用上）

```
产出 = Σ(区域基础 × 等级^1.4)
      × (1 + 太守政治/150)
      × (1 + 0.5 × min(P/40000, 1))        ← 人口红利封顶 +50%
      × (0.8 + 0.4 × L/100)                ← 宜居乘区 0.8~1.2
      × (1 + 政策加成)
      − 俸禄 − 维护
```
- L=50 → ×1.0；L=100 → ×1.2；L=0 → ×0.8。**宜居度全产出同乘**（Q2 建议）。

### 7.2 人口增速（比例制）

```
f_L = clamp(L/60, 0.5, 1.5)
f_F = clamp(F/70, 0, 1)
f_C = clamp((C − P)/C, 0, 1)
增长 = P × 0.02 × f_L × f_F × f_C
if F < 20 or L < 20:  增长 = −0.03 × P      （断粮/低宜居→流失）
```
- 承载卡顶：满员不增；居民楼是人口阀门。
- L=60、F=70、余量 30% → 0.6%/回合。

### 7.3 同化（用上文化值）

```
文化因子 = clamp(1 + 1.5 × (Cnat − 50)/150, 1.0, 2.5)
同化/回 = min( P_f × 0.02 × 文化因子 × (1 − 0.5×占领), P_f × 0.05 )
```
- CN 文化 140 → 因子 1.9 → 3.8%/回；KR 文化 30 → 1.0 → 2%/回；上限 5%。
- 同化→外籍比例↓→Φ 与治安摩擦同步下降。

### 7.4 起义 / 叛乱（R47 口径：忠诚流量积分；细则见 [06-事件/起义与叛乱.md](../06-事件/起义与叛乱.md)）

```
Δ忠诚 = 民生流 + 治安流 + 治理流 + 外籍流 + 占领流 + 文化流
      + 驻军流 + 武将流 + 镇压流 + 自然回流
忠诚' = clamp(忠诚 + clamp(Δ,−10,+5),0,100)

民生流（舒适带[40,55]）：W<40 −0.15×(40−W)^1.1；W>55 +0.15×(W−55)^0.8
其他流：治安 −0.08×缺/+0.04×盈；治理 +0.05×(G−50)；外籍 −4f；
        占领 −2.5×(occPen/15)；文化 −2.0m；驻军 +1.0×min(g/0.05,1)；
        武将 +0.5；镇压 +3×5回；自然回流 +0.3×(60−忠诚)/60

触发（只看忠诚；外籍比例只定类别）：
  普通城 忠诚<30 连续 3 回合；占领城 忠诚<20 连续 10 回合
  触发后 f≥75% → 叛乱；f<75% → 起义（院长 2026-10-29）

起义：概率 = clamp((30−忠诚)/30,0,1)
      触发 = 驻军默认倒戈 → 整城带兵变中立/新阵营
叛乱：概率 = clamp((30−忠诚)/30,0,1) × (1 − (驻军/人口)/0.05)
      驻军/人口≥5% → 0；攻防战；叛军胜=归母国/复国
```

- 一年低民生只掉几分（100→94.8），长期低民生才到 30；正流慢、负流快，恢复是长跑（余震期）。
- 占领城：10 回合军管 Loyalty 维持 60 底线；本国人口 50→80% 占领/文化负流淡出；忠诚<20 连续 10 回合触发（**触发只看忠诚**，触发后按 f≥75% 归叛乱、f<75% 归起义）。
- 镇压：+3/回合共 5 回合、人口等量消耗、民生−5、声誉−5、无难民流。

### 7.5 自发移民（R43）

```
若 |W_A − W_B| > 20：流量 = (差 − 20) × 10~20 人/点/回
```
- 方向：低民生 → 高民生；城际记本国账，跨阵营记外籍账。

### 7.6 服役

```
服役比例 v = 服役 / P_total
军力 = 服役 × 战力 × 军备效率 × 修正器      （R38 不变）
兵役负担 = 400 × v²                        （已进民生主式）
```
- 征募只从本国人口扣；外籍同化后才可征；阵亡永久损失、退伍回城。

## 九、验算案例（三组极端场景）

### A｜北京开局（中城制稳态）

输入：P=30,000｜C=33,000（r=0.909）｜q=45｜E=50｜U=25｜Se≈66｜Me=50｜B=50｜无环境惩罚｜F=85｜G=60｜Ea=55｜f=0｜v=0.3%｜WAR=0｜T=50｜M=0

```
H = 100×(0.5×0.45 + 0.5×(1.10−0.60×0.909)) = 50.2
L = 50 + 0.40×0.2 + 0.25×(66−50) − 0.30×25 = 46.6
Se = 50 + 0.40×(60−50) + 0.20×10 + 10 = 66.0
W = 50 + 0.22×35 + 0.28×(46.6−50) + 0.12×16 + 0.10×10 + 0.08×5 = 60.1
```
**结果：宜居 46.6 / 治安 66 / 民生 60.1**——安全区，无起义。

### B｜接收 5,000 难民（民族主义 O=−60、耐受 T=40）

```
f = 5,000/35,000 = 0.143；r = 35,000/33,000 = 1.06
Φ = 35 × 0.143^1.3 × 1.3 = 3.6
H = 100×(0.225 + 0.5×(1.10−0.636)) = 45.7 → L（稳态）46.6→42.9
Se（稳态）66→58.3（外籍摩擦 + 超载）
F 85→72.9（需求 +16.7%）
W_target（稳态）= 49.7

```

## 十、稳定性与反馈

- 主回路：S→L→W→S，增益 = 0.25×0.28×0.40 = **0.028**；W→S→W 增益 = 0.40×0.12 = **0.048**；合计 ≈ **0.08 < 1**。
- 结论：**唯一的线性稳态，不发散**；外籍/战争/断粮是把稳态整体拉低的"外生位移"，不是数学双稳。玩家看到的是"低水平陷阱"，解法是同化/遣返/治安投入/建房——这些都在式子里有明确系数。
- 缓动 25% 相当于一阶惯性，时间常数 ≈ 3.5 回合。

## 十三、沙盘回测与 v1.1 修订建议（R44c）

> 完整测试矩阵与证据见 [人口算法-沙盘报告.md](./人口算法-沙盘报告.md)。200 回合 + 500 回合单城控制变量，结论：**稳定、不振荡、起义规则正常**，但四处需要修。

### 13.1 必改两处

```
① 粮食项加"饥荒膝"（凸函数）：
   粮食项 = 0.22×(F−50) − 0.35×max(0, 50−F)^1.3
   ——F=35 时由 −3.3 变 −15.4；F=20 时 −35.6；F=0 时 −67。
   回测：只建房不建农，t500 W 由 47.5 降到 27.4，t344 起义（原永不）。

② 粮仓库存上限：
   K ≤ 2 × D        （D=年需求；后期可挂"粮仓"建筑提升）
   ——回测：建房+建农不再出现 K=1101（18 年库存）、F 长期锁 100 的失真。
```

### 13.2 必采纳结构

```
③ 城市忠诚度（Q1）：
   忠诚度 = clamp(W + 0.20×(S−50) − 15×占领 − 10×文化错位, 0, 100)
   起义概率/回 = clamp((30−忠诚度)/30, 0, 1)
   ——回测：44% 外籍占领城 W=41.6/S=51.3 → 忠诚度 26.9、起义 10.5%/回；
      文化错位 0.5 → 21.9、起义 27.1%/回。没有它，占领无任何统治代价。
```

### 13.3 战争伤害包（设计层）

- WAR 旗标单独只让 W 降到 41.5；必须搭配 `F −40~60% / L −10~15 / U +20 / W −8~12`，才会出现 t39 起义。
- 建议把"战争伤害包"写进军事文档：开战/围城/轰炸分档施加，WAR 只做持续压制项。

### 13.4 sqrt/log 实测结论

- `sqrt(承载余量)` → 人口更快撞粮线（P 87.6k、F 29.1），**拒绝**。
- `sqrt(供需比)` → F 被抬高（86.7），饥荒被掩盖，**拒绝**。
- `sqrt(crowd)` → 无差异，**拒绝**。
- 外籍摩擦软分母 → 44% 占领城仅 +1.8 分，**收益太小，保留原 1.3 次方**。
- 结论：本模型要的是**缺口凸性**（饥荒/动员/外籍），不是全局 sqrt/log；凹函数只适合享受类边际递减（娱乐/医疗），当前线性已够。

### 13.5 稳定性实测

- 500 回合末 100 回合 W 极差 0.3~1.3 分，无振荡；25% 缓动为过阻尼一阶惯性。
- 动员 10%/20%、战争、难民、污染全部收敛；起义只在 W<30 连续 3 回合触发。
- 长期陷阱成立：只建房不建农 → 344 回合起义；建房+建农 → W 54.6 健康稳态。
