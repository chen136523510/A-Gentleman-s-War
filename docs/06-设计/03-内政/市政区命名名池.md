# 市政区命名名池（第七区）

> 状态：📝 **v1.0（2026-11-12 白机出）**；归属：[市政建筑数值.md](./市政建筑数值.md) §五；只用于自动命名，不影响数值。
> 用法（与学院/商业/文化名池同规）：开局每城按建筑类型从本城名池**随机洗牌、不重复**；池尽则"XX·2 号"编号；玩家可随时更名；跨城同名自动加城市前缀（如"上海·华山医院"）。
> 锚点：现实市政/医疗/警务/通信机构名，在 1999 架空世界观内视为"灾前旧名"；不使用真实人物名。每城医院/警察 **≥6**、基站 **≥3**、市政府 1 座固定名。
> 医院池**四级通用**（药店/诊所/医院/三甲共用，按等级档次挑名）；警察池**三级通用**（派出所/警察署/警察厅共用）。达尔文为无主城，池仅在占领后生效。

## 六、命名规则

1. **随机洗牌**：开局按城按建筑类型抽取，不重复；同城同类不重名。
2. **医院池四级通用**：药店/诊所取"社区/街道"味名也可（如"XX 社区卫生中心"），三甲取大医院名；玩家可随时更名。
3. **警察池三级通用**：派出所/警察署/警察厅共用一池，升级时沿用原建筑名（升级不改名）。
4. **跨城同名**自动加城市前缀；**玩家更名**免费即时、不影响数值。
5. **不使用真实人物名**；机构名视为"1999 灾前旧名"，可显示"旧名/现名"双行（待 UI 专题）。
