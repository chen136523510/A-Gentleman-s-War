## 一、院长 R44 裁决（定性总纲）

1. **民生不算资源**，是**最顶层的状态指标**——综合评估人民生活水平，不是可积累资源（资源轴见 [资源体系.md](./资源体系.md)）。
2. **宜居度**受：住房、娱乐区、环境污染、治安水平影响；**宜居度影响生产产出**。
3. **民生**受：粮食、宜居度、外籍人口比例、人民情绪舆论等影响；**民生影响忠诚度**。
4. **政策影响分直接/间接**：直接=改评分（爱国教育→提高耐受度→直接提升民生；强制兵役→直接降低民生）；间接=改状态量（建住房、遣返外籍人口）。
5. **事件影响分直接/间接**：直接=瞬时冲击（打败仗、天灾）；间接=改状态量再传导（接收难民→外籍比例↑+粮食消耗↑）。
6. **服役占人口**；**服役比例**（士兵人数/总人口）独立成概念，联合国裁军会议视作一项指标。
7. **同化**：基础 2%/回合 × 文化因子（1~2.5），上限 5%（R43 的 5% 保留为高文化上限）；同化影响外籍比例，从而进宜居/民生算法。
8. **难民**：瞬时冲击（舆论调制符号——民族主义高涨时接收难民降民生，多元主义当道时升民生）+ 空间压力（外籍比例→民生/治安；人口→粮食/住房）。
9. **先定性再定量**；现实人口领域因子过多，本作做简化建模，用算法实现现实世界是本项目价值所在。
10. **海平面**：一级前有趋势预警（按当前趋势还有多少回合到一级）；二级淹没前有撤离窗口；淹没后人口归零（**按比例形成难民群**），设施停用，城市保留。
11. 算法设计从**参数清单**起步，宜居度与民生两套算法先行。

## 二、概念字典

| 概念 | 层级 | 定义 | 直接后果 |
|---|---|---|---|
| **人口** | 城市 | 本国 / 外籍 / 在途三账；劳动力与兵源基础 | 生产红利、粮需、住房需求、兵源 |
| **住房承载 / 承载率** | 城市 | Σ居民楼容量；承载率=人口÷承载 | >100% 拥挤→宜居/治安/疾病 |
| **宜居度** | 城市 | 0~100，**客观**居住环境质量 | **生产产出乘区**、人口增速、民生输入 |
| **民生** | 城市（国家汇总） | 0~100，**最顶层状态指标**，综合评估生活水平 | **忠诚度/起义**、移民流向、文化输出、自立 |
| **治安** | 城市 | 0~100，城市秩序水平 | 宜居、民生、生产稳定 |
| **粮食安全** | 国家（统一粮池） | 0~100，全国供需与库存覆盖；各城共享，被围城断供 | 民生、人口流失 |
| **外籍人口比例** | 城市/国家 | 外籍÷总人口 | 民生−、治安−、同化基数、粮需 |
| **服役 / 服役比例** | 国家（城市征募） | 从本国人口征募；比例=服役÷总人口 | 军力、粮耗、劳动力−、兵役负担、**裁军会议指标** |
| **舆论倾向** | 国家 | 长期意识形态：民族主义 ↔ 多元主义（−100~+100） | **调制事件冲击的符号与幅度** |
| **短期情绪** | 国家 | 事件驱动的情绪值，逐回合衰减 | 民生（短期） |
| **耐受度** | 国家 | 政策养成的民生抗压能力 | 民生直接修正 + 缓冲负面冲击 |
| **同化** | 城市 | 外籍→本国，基础 2%/回 × 文化因子，上限 5% | 外籍比例↓、兵源↑、摩擦↓ |
| **城市忠诚度** | 城市 | 民生驱动 + 文化认同 + 占领状态（⛏ 待裁，见 §十 Q1） | 起义/倒戈判定 |

> **术语纪律**：城市层"忠诚度" ≠ 武将**个人忠诚**（后者管自立，见 [02-武将/忠诚度.md](../02-武将/忠诚度.md)）。历史上 R8 曾把"城市忠诚度"改名为民生；R44 院长口径是"民生影响忠诚度"，两者是否拆开待裁。

```
  民生（实际/目标）· 外籍比例 · 同化

  政策·直接 / 政策·间接 / 事件·瞬时 / 事件·间接
后果层
  生产产出 / 人口增速 / 起义 / 移民流向 / 文化输出 / 国防 / 自立 / 裁军压力
```

## 四、两套主算法 + 三条支撑算法

### 4.1 宜居度算法

```
宜居度目标 = 城市固有基线
           + f(住房：承载率、住房质量构成)
           + f(娱乐：覆盖圈 × 设施等级，距离衰减)
           − f(环境：本地污染、海平面、臭氧、核残留、酸雨)
           + f(治安)
           + f(医疗)
           ± 政策直接修正
实际值 = 向目标值缓动（建议 25%/回合）
瞬时冲击（天灾/轰炸）= 直接扣实际值，目标值不被永久污染
输出：生产产出乘区、人口增速因子、民生输入
```

- **影响生产产出的口径**：作为**全产出乘区**（财/粮/生产力/科技同乘），幅度待定（建议 ±20% 以内）；不是只影响生产力。
- **两处旧写法归一**：娱乐区"覆盖距离衰减"与"宜居 +6/Lv"不冲突——`+6/Lv` 是**满覆盖值**，覆盖圈外按距离折减。

### 4.2 民生算法

```
民生目标 = 城市固有基线修正
         + w1·粮食安全
         + w2·宜居度
         − w3·外籍人口比例摩擦
         + w4·治安
         ± w5·舆论（长期倾向 × 短期情绪）
         + w6·耐受度（政策直接）
         − w7·兵役负担（服役比例超阈）
         − w8·战争状态
         + w9·治理（太守政治）
         + w10·财富与就业（可选）
         ± 政策直接修正
         （钳 0~100；权重 w 待定，总和=1）
实际值 = 向目标值缓动（建议 25%/回合）
瞬时冲击 = 直接扣实际值；目标值不变 → 会自愈但要时间
输出：城市忠诚度 → 起义/倒戈；移民流向（民生差>20）；文化输出乘数；自立因子
国家级民生 = 人口加权平均（HUD 显示；附最低城告警）
```

- **"冲击是伤、目标是病"**：瞬时冲击扣实际值，不污染目标值——难民/天灾过后会自然恢复，但恢复期内民生低，仍会触发移民/起义。
- **外籍摩擦**：`−(外籍比例×K)`，同化后自动衰减（R43 已有设计）。
- **兵役负担**：服役比例超过阈值后，每超 1% 扣民生 X 点（强制兵役政策另走"政策直接"再扣一次——院长例）。

### 4.3 治安算法（支撑）

```
治安目标 = 城市治安基线
         − f(外籍人口比例)
         + f(民生)
         + f(驻军/警力/军事基地)
         − f(战争/动乱/被围)
         − f(超承载拥挤)
         ± 政策（严打/禁足令）
输出：宜居+、民生+、生产稳定（罢工/暴乱风险）
```
- **同化不直接进治安式**：同化→外籍比例↓→摩擦↓，经外籍比例传导，避免双算（与宜居同理）。

### 4.4 同化算法（支撑）

```
每回合转化 = 外籍人口 × 2% × 文化因子(1~2.5)，上限 5%
文化因子来源：本国文化值、文化认同（征服/占领城的认同更低）
输出：外籍↓、本国↑、摩擦↓、可征募兵源↑
对宜居的影响经治安传导：外籍比例↓ → 治安↑ → 宜居↑（不直接改宜居，避免同一因子双算）
```

### 4.5 服役算法（支撑）

```
服役 = Σ 城市征募（从本国人口扣，转为服役状态；不产出、吃粮）
服役比例 = 服役 ÷ 总人口（分母含外籍；征募只从本国）
阵亡 → 服役永久损失，不回人口；退伍 → 回人口
输出：军力（+）、劳动力（−）、粮耗（+）、兵役负担（民生−）、裁军会议指标
```

### 4.6 共享规则：直接/间接 × 政策/事件 四象限

| 通道 | 政策 | 事件 |
|---|---|---|
| **直接**（改评分） | 持续修正**目标值**：爱国教育→耐受度↑→民生+；强制兵役→服役比例↑、民生−；宣传→舆论倾向 | **瞬时冲击实际值**：败仗→民生−；天灾→宜居−、民生−；丑闻→情绪− |
| **间接**（改状态量） | 建居民楼→承载↑；遣返→外籍比例↓；建娱乐区→宜居↑；治安投入→治安↑；环保→污染↓ | 接收难民→外籍↑、粮耗↑→民生−；瘟疫→人口↓；暴动→治安↓ |

- **舆论调制**：事件冲击的符号与幅度由**舆论倾向**决定。例：接收难民在民族主义国家 → 民生−；在多元主义国家 → 民生+。幅度再乘 `(1 − 耐受度/200)` 之类缓冲（待定）。
- 这套四象限是"强大算法"的骨架：政策管长期形状，事件管短期波动，两条通道互不打架。

### 4.7 战争支持度（R44d 院长定：战争负收益别过重）

```
warSupport = WAR × ((O < 0 或 军国主义) ? +3 : −2)   ← 民族主义/军国主义 rally；多元主义反战
             − 0.35 × warTurns              ← 战争疲劳（停战清零）
             − 0.15 × max(0, 50 − F)        ← 缺粮放大反战
```

- **战争的真实代价不在此式**：服役占人口（兵役负担）、军用粮、士兵/财消耗才是主账；WAR 只做"支持度"调制，不再 −8/级硬扣。
- 民族主义 10 年战争：开战 +6 → 10 年后 +2.5 → 30 年后 −4.5（先高涨后疲劳）；多元主义开战即 −4。
- 胜负另走事件情绪（M/首长汇报），不重复扣分。

### 4.8 起义 / 叛乱（R44e 分线，细则见 [06-事件/起义与叛乱.md](../06-事件/起义与叛乱.md)）

```
起义（本国人口 ≥60%）：
  忠诚度_显示 = W + 0.20×(S−50) − 15×占领 − 10×文化错位
                + 20×min((驻军/人口)/0.05,1) + 武将坐镇
  起义概率 = clamp((30−忠诚度_显示)/30, 0, 1)
  触发 = 驻军默认倒戈 → 整城带兵变阵为中立新阵营（不另掷倒戈概率）

叛乱（外籍人口 ≥65%）：
  叛乱概率 = clamp((30−W)/30,0,1) × clamp((f−0.65)/0.35,0,1)
            × (1 − (驻军/人口)/0.05)      ← 驻军/人口≥5% → 0
  攻防战：外籍叛军（弱质量/低军备）攻，驻军守；
          守军胜=外籍人口等量消耗；叛军胜=城归母国（母国已灭→复国）
```

- 占领城前 10 回合军管：起义/叛乱概率=0；同化持续把外籍→本国，城市从"叛乱风险"转为"起义风险/稳定"。
- 镇压后果：忠诚度↑、民生−、声誉−、无难民流、人口间接流失。
- 驻军=军队（全国一个军队池）；驻军多→忠诚高但触发时丢兵多，撤军→概率高但兵保住。

## 八、补充因子、明确砍掉、人口与移民参数

### 8.1 白机补充进体系的因子（院长问"还有哪些要补充"）

| 因子 | 为什么补 | 归属 |
|---|---|---|
| **治安** | 院长已隐含（宜居受治安影响、治安受外籍比例影响），但此前没有独立状态量；它有独立输入与独立输出，必须单列 | 城市状态 + 支撑算法 |
| **粮食安全** | 人口/服役/贸易/环境（酸雨/海平面）的交汇点；没有它，"粮食影响民生"无法计算 | 国家状态（全国粮池，城市共享） |
| **医疗（医院）** | 医院建筑 R37 已入目录，此前无机制挂靠；进宜居 + 人口增速（死亡率） | 宜居输入 |
| **战争状态** | 被围/轰炸/占领对民生/宜居/治安是硬冲击，R36 战役规则已有一期实现 | 民生/宜居/治安输入 |
| **舆论倾向分两层** | 院长"民族主义 vs 白左"需要长期倾向（政体/政策）+ 短期情绪（事件、衰减）两层，否则同一事件无法既加分又减分 | 国家状态 |
| **耐受度** | 院长"爱国教育提高人民耐受度"的落点；既直接加民生，又缓冲负面冲击 | 国家参数 |
| **城市固有基线** | "每城独一无二"铁律的落地：14 城宜居/治安底子不同（沿海/内陆/历史条件） | 城市数据 |
| **同化进度** | R43 已定同化率，但此前没有把它接进外籍比例→民生/治安的链路 | 城市状态 |
| **环境健康修正** | 核/污染不只压宜居，还应压人口增速（死亡率），否则核污染的长期代价偏轻 | 环境→人口接口 |

## 九、反馈环（相互影响、相互制约）

| # | 类型 | 环 | 机制 |
|---|---|---|---|
| R1 | 负 | 拥挤环 | 人口↑→承载率↑→宜居↓→人口增速↓ |
| R2 | 负 | 同化收敛 | 外籍↑→同化人数↑→外籍↓→民生摩擦↓ |
| R3 | **正** | 治安恶化 | 民生↓→治安↓→宜居↓→民生↓（**需刹车**：治安投入/同化/遣返） |
| R4 | 负 | 兵役负担 | 服役↑→劳动力↓→产出↓→民生↓→兵源意愿↓ |
| R5 | 负 | 环境治理 | 工业↑→污染↑→宜居↓→民生↓→治理投入→污染↓ |
| R6 | 负 | 粮食约束 | 人口↑→粮需↑→粮食安全↓→民生↓→人口流失 |
| R7 | 负 | 舆论衰减 | 事件→情绪↓→民生↓→情绪逐回衰减→民生回升 |
| R8 | **正** | 难民空间压力 | 接收难民→外籍↑+住房紧→治安↓/宜居↓→民生↓ |
| R9 | 负 | 服役-国防 | 服役↑→国防↑，同时压民生与生产（取舍环） |
| R10 | 负 | 环境-迁移 | 矿尽/海平面→产出↓→民生↓→自发移民→人口↓ |

> R3/R8 是仅有的两条正反馈，必须靠"同化/遣返/治安投入/住房建设"刹车——这正是玩法的张力所在。

### 9.1 主因 / 副因分层（R44d 院长令：要有全局观）

| 层级 | 因子 | 为什么 | 影响幅度 | 时间尺度 |
|---|---|---|---|---|
| **主因** | 人口、粮食、服役比例、外籍比例 | 直接决定劳动力/兵源/吃饭/社会摩擦，系数最大且有长反馈 | 单项可拉低/抬高民生 10~30 分 | 长期（20~200+ 回） |
| **副因** | 宜居度、治安、治理、舆论倾向、耐受度、财富 | 通过主因或彼此传导；单项 3~10 分 | 中短期（3~20 回） |
| **三级** | 医疗、娱乐、住房质量、城市基线、政策直接、短期情绪 | 调节项/局部项；单项 1~5 分 | 短期（1~10 回） |

- 玩家面板只突出四个主因（粮/服役/外籍/人口），副因折叠、三级进详情——**不让玩家被 20 个数字淹没**。
- 主因之间互锁：人口→粮需/兵源；服役→人口/粮需；外籍→民生/治安/人口；粮食→人口/民生。这是"牵一发动全身"的来源。

### 9.2 传导矩阵（改一个因子，哪些跟着变，是否回到自身）

| 改这个 | 直接变 | 二次变 | 是否回环 | 环的性质 |
|---|---|---|---|---|
| 人口 ↑ | 粮需↑、承载率↑、兵源↑ | 粮食↓、宜居↓、产出↑ | 是（粮食→人口、宜居→人口） | 负反馈为主 |
| 粮食 ↓ | 民生↓、人口↓ | 治安↓、宜居↓、兵源↓ | 是（人口→粮需） | **负反馈**（人口下滑自动减压；饥荒膝保证"饿"真的会掉人口） |
| 服役 ↑ | 劳动力↓、粮需↑、国防↑ | 产出↓、民生↓、服役比例↑ | 是（民生→兵源） | 负反馈（取舍环） |
| 外籍 ↑ | 民生↓、治安↓、粮需↑ | 宜居↓、同化↑、兵源↓ | 是（同化→外籍） | 有正有负（同化收敛） |
| 宜居 ↓ | 民生↓、增速↓ | 治安↓ | 是（治安→宜居） | **正反馈**（需治安投入刹车） |
| 战争 ↑ | 支持度±、服役↑、粮需↑ | 民生±、治安↓ | 是（民生→兵源） | 短期正/长期负 |

### 9.3 时间尺度（短期/中期/长期分开看）

| 尺度 | 因子 | 典型恢复/生效 |
|---|---|---|
| 瞬时（1 回） | 事件冲击、政策直接、短期情绪 | 当回合 |
| 短期（1~5 回） | 舆论/耐受、战争 rally | 3~5 回见顶/衰减 |
| 中期（5~20 回） | 宜居、治安、民生缓动、战争疲劳 | 25%/回缓动，约 9 回走完 90% |
| 长期（20~200 回） | 人口、同化、粮食库存、治安-民生正反馈 | 同化半衰期 18 回；人口按承载/粮约束 |
| 超长期（50~200+） | 环境账本、海平面、矿脉枯竭 | 50 回合/矿档；海平面不可逆 |

### 9.4 边际效应（哪些是线性、哪些凸/凹）

| 因子 | 形态 | 理由 |
|---|---|---|
| 外籍摩擦 | **凸**（1.3 次方） | 少数外籍无感，过半剧痛 |
| 兵役负担 | **凸**（2 次方） | 小动员可承受，总动员伤筋动骨 |
| 粮食缺口 | **凸**（1.3 次方膝） | 缺一点能扛，缺多了雪崩 |
| 住房/承载 | 线性递减 | 拥挤感线性累积，够用 |
| 娱乐/医疗 | 线性 | 享受类；若后期要"边际递减"可改 sqrt 形（当前不必） |
| 人口增长 | logistic（承载余量） | 越接近满员越慢 |
| 同化 | 指数衰减 | 外籍越少同化越慢（自然收敛） |

### 9.5 游戏性原则（院长 R44d #6）

1. **多条路都能活**：农业（农田/牧场）、工业食品（罐头/预制菜）、移民同化、军事扩张、文化——每条路的瓶颈不同（耕地/产能/摩擦/兵役/文化），不能只有一条最优解。
2. **朴素知识对得上**：缺粮→民生降、外籍过多→治安差、战争→民族主义高涨但久战疲劳、占领→驻军压得住——玩家不用查表也能猜到。
3. **明牌不藏刀**：耕地安全线、粮仓上限、军管倒计时、战争疲劳都上 UI，不做暗扣。
4. **负反馈纪律**：不给"一步走错满盘皆输"的硬锁；饥荒/治安恶化都有刹车手段（补粮/治安投入/同化/遣返）。
5. **主因优先**：面板突出粮/服役/外籍/人口，副因折叠；防止玩家被细节淹没而"哪哪都不对"。

### 11.2 回合结算流水线（挂 R40 全局段）

```
全局段（世界级先于国家级，同步结算：目标值一律读上回合末状态）
 A 环境账本：排放→温度→海平面速率→过阈→预警倒计时/淹没/失败
 B 目标计算：宜居目标、治安目标（读上回合治安/污染/承载率）
 C 缓动更新：宜居、治安
 D 民生：目标计算→缓动→应用本回合瞬时冲击队列
 E 人口：增速/流失 → 移民（自发/配额/同化/遣返/在途到达）→ 超载校验
 F 粮食：产出+进口+库存 vs 人口+服役需求 → 粮食安全
 G 产出：区域基础 × 人口红利 × 宜居乘区 × 太守 × 政策 − 俸禄/维护
 H 军事：征募/退伍 → 服役比例 → 军备 → 军力
阵营段（R40 原顺序）
 移动/交战 → AI 决策 → 事件（起义/自立判定读已结算民生）
```

- **同步结算原则**：阶段 B 的目标值只读上回合末状态，避免"宜居↔治安↔民生"三角循环依赖；本回合写入的值不参与本回合目标计算。
- 淹没结算：剩余人口归零 → 按比例生成难民群（去向同 R39）→ 设施停用 → 城市保留（遗迹）。
