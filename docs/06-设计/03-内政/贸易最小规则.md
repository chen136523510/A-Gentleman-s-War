# 贸易最小规则（B1-C 附属 · v0.2 财流版）

> 状态：⏸ **2026-11-02 暂告一段落（随商业区暂停，v0.9 暂定）**；后续外交/B12 专题可能回改。
> 黑机重写 2026-11-02（院长 #3：民间贸易只体现为财，粮/铁/煤不进入贸易）；数值草案，未进 `balance.json`。
> 上游：[商业区开题.md](./商业区开题.md) §4.5⑤ 港口 / §4.7 概念债务 · [外交行动.md](../05-外交/外交行动.md) §贸易与出口体系 · [人口税与土地价格.md](./人口税与土地价格.md) §四（WLT/收复）
> 目标：**玩家只看到“贸易收入 +N 财/回”一个数**；不追踪货物、不记价格、不选航线。粮/铁/煤只在国内产需平衡，不进出口。

## 一、设计边界（做减法）

**做**：财流 / 贸易容量 / 伙伴关系 / 三档协定（民间通商/最惠/禁运/战时）。
**不做**：货物（粮/铁/煤/铀/装备）数量、价格表、断供品价格、逐条航线、运输队、外贸公司、陆港、路线开通费。**资源采购（铁/煤/铀/装备）不在本规则——走外交行动，由外交官讨价还价（院长 #2）。**

**玩家全部操作 = 签/撕协定**；民间贸易每回合自动结算，只产出一个财数。

> 院长口径：**“民间贸易只有财的体现”**。粮/铁/煤的余缺由国内产需/库存处理，不作为贸易货物；避免玩家在“粮够不够、铁够不够、价格多少”之间做微观管理。

## 二、定义（首现即定义）

| 词条 | 定义 |
|---|---|
| **贸易额** | 某伙伴每回合带来的**净财收入**（出口−进口已轧差），单位财/回。 |
| **贸易容量** | 全国贸易额上限，单位财/回。来源=港口：Lv1 50 / Lv2 80 / Lv3 110；保税线 Lv3「自由贸易港区」+20。**无港口=0**（内陆阵营只能靠本阵营沿海城）。 |
| **伙伴贸易线** | 一个伙伴阵营对应一条自动财流；不区分货物，不区分进出口。 |
| **民间通商** | 默认状态：R≥0 即可产生贸易额；不需要签协定。 |
| **最惠贸易** | R≥+20：该伙伴贸易额 ×1.2，关系 +2/回。 |
| **资源采购** | **不在本规则**：铁/煤/铀/装备走 [外交行动](../05-外交/外交行动.md) §资源采购，由外交官谈判价格/数量/期限（院长 #2）。 |
| **禁运制裁** | 同盟级/会议：该伙伴贸易额=0。 |
| **战时贸易线** | R≥+60：交战时该伙伴贸易额保留 50%；否则交战国之间=0。 |

## 三、财流公式（草案）

```
伙伴贸易额 = 伙伴商业产出 × 0.10 × 关系系数 × 协定系数 × 国家贸易倾向
关系系数 = clamp(0.50 + R/100, 0, 1.50)          // R −100~+100 → 0~1.5
国家贸易收入 = min( Σ伙伴贸易额, 贸易容量 )
```

- **伙伴商业产出**：伙伴全国商业建筑净产出（街/写字楼/商场/银行放大后的财/回）；不读货物。
- **0.10**：贸易渗透率——伙伴每 10 财商业产出，带来 1 财贸易额；草案，模拟标定。
- **国家贸易倾向**（数据驱动，`balance.json`）：AU 1.20（矿产出口）/ CN 1.15（制造出口）/ JP 1.15（技术与服务）/ KR 1.10（商业）/ WLT 0.80（封锁/自立弱势）。新城/新阵营只配系数，不加规则。
- **容量截断**：贸易额超过容量时按伙伴贸易额比例截断；UI 显示 `贸易 50/50（容量满）`。
- **不跟踪库存/价格/断供**：关系下降、战争、禁运直接改 `关系系数/协定系数`，贸易额自然下降；没有“某货物断供”这一层。

**示例**：60k 伙伴商业净 328 → 伙伴贸易额 32.8 × 关系 1.0 × 最惠 1.2 = **39.4 财/回**；两个伙伴 ~79，Lv1 港口容量 50 → 截断到 **50 财/回**。

## 四、四档协定

| 协定 | 门槛 | 效果 | 操作 |
|---|---|---|---|
| **民间通商** | R≥0 | 自动财流，无加成 | 无（默认） |
| **最惠贸易** | R≥+20 | 该伙伴贸易额 ×1.2；关系 +2/回 | 签/撕 |
| **禁运制裁** | 同盟级/会议 | 该伙伴贸易额=0 | 会议 |
| **战时贸易线** | R≥+60 | 交战时保留 50% | 签/撕 |

### 4.1 资源采购走外交（院长 #2）

- **铁/煤/铀/装备不在贸易系统**；在 [外交行动](../05-外交/外交行动.md) §资源采购 中，由**外交官**（己方武将兼任，政治/魅力影响成交价）与卖方讨价还价，谈价格/数量/期限。
- 外交采购不占贸易容量、不产生“伙伴贸易线”；它是一份**国家合同**，走外交面板，不走贸易面板。
- **WLT 必须能活（正确运营）**：种田 + 外交采购是可行路径；只有错误运营才会饿死/被收复；收复口径见 [人口税与土地价格.md](./人口税与土地价格.md) §四。

## 五、断供/禁运/战争（财流口径）

| 情形 | 规则 |
|---|---|
| 关系下降 | 关系系数降，贸易额自然降；不额外惩罚 |
| 战争 | 交战国之间贸易额=0；战时贸易线保留 50% |
| 禁运 | 被禁运方与参与方贸易额=0；参与方需同盟级 |
| 港口被封锁 | 贸易容量减半（挂军事专题）；不逐货物断供 |
| 撕协定 | 破弃 −40 关系（沿用外交行动）；贸易额下回合重算 |

> 原“断供品价格 ×1.5~3”“稀缺溢价”**全部删除**——没有货物，就没有货物价格。

## 六、UI 与操作（一个数）

- **外交面板**：`贸易 50/50（容量满）` + 伙伴列表（AU +32 / CN +18 / …）+ 协定列表。
- **建造预览**：港口 `+50 贸易容量`；升级 `+30 容量` / `+20 容量` / `战时保留 50%`。
- **城市面板**：不显示贸易（贸易是国家层）；只在国家 HUD 显示一个数。
- **商情播报**：协定签订/撕毁/禁运/战争关闭；不逐回合报价格。
- **不显示**：货物、价格、供需、航线。

## 七、数据 schema 草案

- `balance.json.trade`：`capacityPerPort=[50,80,110]`、`freeTradeZoneCapBonus=20`、`partnerOutputFactor=0.10`、`relationBase=0.50`、`relationScale=0.01`、`mostFavored=1.20`、`wartimeRetain=0.50`、`breakRelation=-40`。
- `factions.json`：`tradeProfile`（AU 1.20 / CN 1.15 / JP 1.15 / KR 1.10 / WLT 0.80）。
- 存档：`agreements[] {type, partnerFactionId, effect?, sinceTurn}`；`tradeCapacity` 汇总缓存；**不存货物**。
- 兼容：旧档无字段 → 容量 0/无协定（贸易关闭）；粮/铁/煤的国内产需仍走农业/工业/粮食 v4。
