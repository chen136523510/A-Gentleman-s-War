# 贸易最小规则（B1-C 附属 · v1.0 简化版）

> 状态：✅ **v1.0 定稿（2026-11-25 院长系列裁定）**——贸易=阵营间财流（海路+陆路统一容量）；中断规则简化（交战/封锁=双边中断、禁运并入封锁、第三方不受牵连、转口不做）；协定两档；倾向=国家性质×大统领相性派生。
> 目标：**玩家只看到"贸易收入 +N 财/回"一个数**；不追踪货物、不记价格、不选航线。
> 上游：[商业区开题.md](./商业区开题.md) §4.5⑤ 港口 · [外交行动.md](../05-外交/外交行动.md) §资源采购 · [武将倾向特性池.md](../02-武将/武将倾向特性池.md)（相性）。

## 一、定义（贸易=什么）

| 词条 | 定义 |
|---|---|
| **贸易** | **阵营之间商品/服务的交换，游戏内只体现为财流**（贸易额 财/回）——不追踪货物、不记价格、不选航线 |
| **海路/陆路** | 贸易路径两式，**统一容量口径**（§二）：内陆国照常有贸易（陆路）；海路城市可建**港口建筑**额外提升（§五） |
| **贸易额** | 某伙伴每回合带来的净财收入（出口−进口已轧差），单位财/回 |
| **伙伴贸易线** | 一个伙伴阵营对应一条自动财流；不分货物、不分进出口 |
| **内贸** | 阵营内城间流动**不算贸易**（已由国内产需/商业产出消化，防双算） |
| **资源采购** | **不算贸易**：铁/煤/铀/装备走 [外交行动](../05-外交/外交行动.md) §资源采购（外交官谈价，不占贸易） |

## 二、财流公式（统一容量）

```
城容量_i   = 城 i 商业净产出 × k_cap          // k_cap = 0.10（统一，不分海陆）
国家容量   = Σ 城容量_i
伙伴线额   = 伙伴商业净产出 × 0.10 × 关系系数 × 协定 × 倾向
国家贸易收入 = min(Σ 线额, 国家容量)           // 超额按线额比例截断
```

- **k_cap=0.10**：每城商业产出的 1/10 是该城的贸易吞吐上限；与渗透率同量级（容量≈可消化的线额规模）。
- **渗透率 0.10**：伙伴每 10 财商业净产出→1 财我方净得（院长 11-05 认；0.05 鸡肋/0.15 主力/0.20 失衡）。
- **关系系数** = clamp(0.50 + R/100, 0, 1.50)（R −100~+100）。
- 容量截断按伙伴线额比例；UI 显示 `贸易 50/50（容量满）`。
- 双向不对称：A 从 B 得=**B 的**产出×0.10…（各自算、各自受自己容量约束）——小国从大国赚更多但被自己容量卡住，逼发展商业。

## 三、中断规则（简化版，2026-11-25 院长裁）

| 情形 | 规则 | 波及 |
|---|---|---|
| **交战 A-B** | A-B 线**完全中断** | 只 A-B 一条线 |
| **封锁 A→B** | A-B 线中断（**禁运并入封锁**，不再单列） | 只 A-B 一条线 |
| **第三方** | **不受牵连**：A-B 交战，A-C/B-C 线不动（除非 C 自己参战/封锁） | 其余线照常 |
| **转口** | **不做**（转口概念删除） | — |
| 撕协定 | 破弃 −40 关系（沿用外交行动）；贸易额下回合重算 | 双边外交后果 |

> 旧口径作废：战时贸易线（R≥60 保留 50%）**删除**（交战=完全中断）；"封锁=容量减半"**删除**（封锁=中断）；禁运作为独立协定档**删除**（并入封锁）。

## 四、协定（两档）

| 协定 | 门槛 | 效果 | 操作 |
|---|---|---|---|
| **民间通商** | R≥0 | 自动财流，无加成 | 无（默认） |
| **最惠贸易** | R≥+20 | 该伙伴线额 ×1.2；关系 +2/回（11-24 终裁：+2 不动） | 签/撕 |

## 五、港口（海路城市的额外提升）

| 项 | 口径 |
|---|---|
| 定位 | **海路容量加成设施**（商业 5 类之一：港口物流园；维护 3%） |
| 效果 | 该城容量系数 **+0.05/Lv**（Lv1/2/3 = +0.05/+0.10/+0.15，叠乘该城商业净产出） |
| 旧值作废 | ~~容量 50/80/110、保税 +20~~（统一容量口径取代） |
| 特色 | 自由港/枢纽港/转口港/口岸等城市特色词条**删除**（不做特色） |
| 复苏副本 | **不出港口类建筑**（16 城仅 3 沿海；贸易走统一容量，内陆国照常） |

## 六、贸易倾向（派生，不写死数组）

```
倾向 = 国家性质基准(0.8~1.2) × 大统领相性修正(0.9~1.1)
```

- **国家性质**：`factions.json` 性质标签（如"制造出口/矿产出口/技术立国/内向自足"→基准值）；
- **大统领相性**：从武将倾向池读（贸易向相性 +修正）；在野/换人/大统领更替则倾向变；
- 新阵营/新剧本只配性质标签与相性，**不加规则**。

## 七、UI 与数据

- **外交面板**：`贸易 50/50（容量满）` + 伙伴列表（+32 / +18 / …）+ 协定列表；城市面板不显示（贸易=国家层）。
- **建造预览**：港口 `容量系数 +0.05/Lv`。
- **商情播报**：协定签/撕/封锁/交战中断；不逐回合报价格。
- **不显示**：货物、价格、供需、航线。
- **schema**：`balance.json.trade`（k_cap=0.10、partnerOutputFactor=0.10、relationBase=0.50、relationScale=0.01、mostFavored=1.20、breakRelation=-40、portCapacityCoefPerLv=0.05）；`factions.json`（性质标签）；存档 `agreements[] {type, partnerFactionId, sinceTurn}`；旧档缺省=贸易关闭。
