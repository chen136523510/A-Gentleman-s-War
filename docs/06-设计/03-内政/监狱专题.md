# 监狱专题（三级架构 · 收押 / 对话 / 劝降 / 处决 / 释放）

> 状态：📝 **v0.1（2026-11-17 白机出，院长 11-17 令）**——三级架构（名字 / 特效 / 名池）+ 监狱内四项交互（对话 / 劝降 / 处决 / 释放）+ 被关押武将一览；**数值占位、模拟盘闭环（院长只管定性，同市政裁定 10）**。
> 上游：[市政建筑数值](./市政建筑数值.md) §一 监狱行（市政区 / 2×2 / 每城 1 / 教程自带）· [俘虏与处置](../02-武将/俘虏与处置.md)（俘获判定与四处置→收押）· [教学关卡设计](../00-总纲/教学关卡设计.md)（灭国必俘 / 处置三选一 / 劝降在监狱 / 大统领不可劝降）· [在野与招安](../02-武将/在野与招安.md)（释放去向 / 劝降 vs 招安两套入口）· [武将倾向特性池](../02-武将/武将倾向特性池.md)（招安难度）· [忠诚度](../02-武将/忠诚度.md)（个人忠诚）
> 口径（2026-11-16 院长令，沿用）：
> 1. **监狱=市政区建筑**（第七区域），2×2、每城 1 座，**教程默认自带 Lv1**；升级与效果=本专题。
> 2. **城破处置面板只做三选一：收押 / 处决 / 释放**；**劝降只在监狱内进行**（不占处置面板）。
> 3. **灭国必俘**：大统领 + 随城武将必被俘（不走逃跑判定）；**大统领不可劝降**（监狱内也不可，仅可对话 / 处决 / 释放）。
> 4. 收押后武将状态 `captured`：**在监狱里占城、不产金、不吃俸禄、不占派驻**；释放后在野/归国见 §四.5。

## 一、在押流程（一图）

```
城破 / 灭国
  └─ 驻城武将逐个逃跑判定（沿用俘虏与处置：50%+(统率−50)×0.5%，钳 20~80%）
       ├─ 逃跑成功 → 邻接友城 / 在野
       └─ 被俘（灭国=大统领+随城武将必俘）
            └─ 处置面板三选一：收押 / 处决 / 释放
                 ├─ 收押 → 本城监狱（攻占城无监狱或满员 → 押送己方有监狱且有位的城，1 回合行程 / 50 财；无处可押 → 只能处决/释放）
                 │    └─ 监狱详情页：在押列表 → 对话 / 劝降 / 处决 / 释放
                 ├─ 处决 → 永久退场（宝物入国库）
                 └─ 释放 → 归国（原阵营存活）/ 在野（亡国）
```

- **劝降 ≠ 招安**：劝降=对**有主俘虏**（在监狱）；招安=对**在野**武将（人才市场）。两套入口不合并（沿用 [在野与招安](../02-武将/在野与招安.md) §三）。
- **押送**为收押的下级操作（不是第四种处置），满员/无监狱时才出现；押送目标城必须己方且 `jailFree>0`。

**统一口径**：

| # | 口径 | 说明 |
|---|---|---|
| 1 | **升级不变占地** | 三级全线 2×2（铁律）；升级单链、不可跳级（同医院/警察落库口径） |
| 2 | **造价基准** | 生产造价 = 20×工期、财 ≈5×生产（建筑数值表 §二）；三级走市政标准曲线（同警察链 300/480/768） |

| 4 | **岗位/电** | 岗位=就业上限，产出无（市政服务件）；电按市政同类档 1/2/3 |
| 5 | **在押容量** | 同时关押上限（含大统领）；**满员不驱逐**，只拦新收押（新俘只能处决/释放/押送他城） |
| 6 | **每城 1 座** | 不可与市政府同格？否——独立建筑，`maxPerCity=1`；达尔文无市政府→占领前无监狱 |
| 7 | **教程配置** | 教程剧本上海自带 **Lv1 看守所**（`tags:["initial"]`，不进建造目录）——灭国必俘收押王乐添用（容量 2 够） |
| 8 | **数值自治** | 容量/乘区/成本由模拟盘闭环校准；本卡数值先占位 |

## 三、三级逐卡

### 3.1 看守所（Lv1 · 羁押型）

| 项 | 值 | 说明 |
|---|---|---|
| 容量 | 2 将 | 够装一次灭国俘获（大统领+1 随城将）；大城多俘需升级/押送 |
| 劝降乘区 | ×1.0 | 基准；无审讯设施加成 |
| 对话冷却 | 5 回合/将 | 审讯资源有限 |
| 越狱乘区 | ×1.0 | 基准 |
| 定位 | 小城/前期 | 教程自带；县市级羁押设施 |

### 3.2 监狱（Lv2 · 标准型）

| 项 | 值 | 说明 |
|---|---|---|
| 容量 | 4 将 | 中等城市/连续作战 |
| 劝降乘区 | ×1.2 | 有独立审讯区/档案室 |
| 对话冷却 | 4 回合/将 | 审讯力量加强 |
| 越狱乘区 | ×0.8 | 看守更严 |
| 定位 | 中期主力 | 拿下一整片战区后的战俘集中关押 |

### 3.3 监狱城（Lv3 · 重刑型）

| 项 | 值 | 说明 |
|---|---|---|
| 容量 | 8 将 | 后期大战/灭国批量战俘 |
| 劝降乘区 | ×1.5 | 完整审讯与心理攻势体系 |
| 对话冷却 | 3 回合/将 | 专职审讯官 |
| 越狱乘区 | ×0.5 | 高度戒备 |
| 处决司法减免 | **声望惩罚减半** | "走司法程序"：rep −5→−2.5、其余阵营关系 −5→−2.5（当事阵营 −15 不变） |
| 定位 | 大后期/大国 | 一座监狱城关一个国家的残部 |

**设计意图**：三级不是线性加数值，而是三种玩法——Lv1 是"临时羁押、快速处置"；Lv2 是"养着慢慢劝"；Lv3 是"人才工厂+政治工具（依法处决低震荡）"。容量与劝降乘区拉开档次，让"要不要为战俘升监狱"成为城市建造决策。

## 四、监狱内四项交互

### 4.1 被关押武将一览（UI）

- **入口**：点击监狱建筑 → 监狱详情页（与城破处置面板分离；处置面板只在城破瞬间弹出）。
- **列表字段**：姓名 / 原阵营 / 五维 / 被动 / **关押回合** / **对话累计** / **劝降档（极高·高·中·低·拒绝）** / 持有宝物（随将暂存，释放归还、处决入国库）。
- **排序/筛选**：按五维、原阵营、关押时长、劝降档。
- **不显示**：相性数值、精确成功率（只给五档模糊反馈，与在野招安同纪律）。
- **大统领**：劝降档固定显示 **"拒绝"**（不可劝降）；对话仍可进行（情报价值最高）。

### 4.2 对话（审讯）

| 项 | 规则 |
|---|---|
| 次数 | 每名在押武将每 **N 回合 1 次**（N=监狱等级 5/4/3） |
| 成本 | **不耗财**（占 1 次交互，不占回合行动） |
| 方向选择 | 每次对话选 1 个方向：**邻城兵力 / 城防设施 / 科技与资源储备** |
| 成功判定 | 按被审武将智力：**≥80 必得 / 60~79 70% / <60 50%**；失败只提示"未开口" |
| 附带效果 | **+1 对话累计**（进劝降公式）；**+情报**（战争迷雾信息，显示 1 回合） |
| 大统领 | 情报必得（全方向最高价值），但劝降档恒为"拒绝" |
| 设计意图 | 对话=拷打机密的替代入口（原四处置"拷打机密"并入对话，取消独立入口）；审讯与劝降共用"对话累计"，一次交互两条收益 |

### 4.3 劝降

| 项 | 规则 |
|---|---|
| 成本 | **200 财/次**（三级同价；审讯设施只提成功率，不降成本） |
| 频率 | 每将 **1 次/回合**；失败 → 该将进入 **3 回合"婉拒"冷却** |
| 公式 | `P = 40% × K_jail × K_xiang × (1 + 0.03×D) × (1 − 0.005×L)`，**封顶 90%** |
| `K_jail` | 监狱等级乘区 1.0 / 1.2 / 1.5（§二） |
| `K_xiang` | 相性招安难度：易（A2 良禽择木 / A3 天下为公 / A5 投机分子）**1.5**；中性 **1.0**；难（A1 故国之思 / A6 复国志士）**0.6**；**死忠（A4 忠臣不事二主）= 0（直接"拒绝"，同招安口径）** |
| `D` | 对话累计次数（**封顶 10 次** = +30%） |
| `L` | 目标**当前**个人忠诚（初始 45~90；**关押每回合 −0.5，下限 20**——"岁月消磨"；被释放/处决不受影响） |
| 反馈档 | P≥70 极高 / 45~69 高 / 25~44 中 / <25 低 / K=0 拒绝 |
| 成功 | 加入攻方阵营，**个人忠诚 30~60**（与在野招安同口径），驻城待分配；宝物随将（进己方，不归还） |
| 失败 | 目标个人忠诚 **+5**（上限 95）；显示"婉拒"；不重置对话累计 |
| 大统领 | **K 恒为 0**（不可劝降）；UI 只显示"拒绝" |
| 示例 | Lv2 监狱 / 普通将当前忠诚 60 / 对话 5 次：`0.40×1.2×1.0×1.15×(1−0.30)=0.386`≈39%（中档） |

### 4.4 处决

| 项 | 规则 |
|---|---|
| 结果 | 该武将**永久退场**（21 初始池减员、不补员；NPC 从 NPC 池移除）——沿用俘虏与处置 |
| 宝物 | 归胜方**国库**（可陈列）——沿用俘虏与处置 |
| 外交 | 当事阵营关系 **−15**；其余存活阵营关系 **−5**（忌惮）；声望 rep **−5** |
| Lv3 司法减免 | 监狱城处决：rep **−2.5**、其余阵营 **−2.5**（当事阵营 −15 不变）——"依法处决" |
| 己方相性反馈 | 己方同阵营有 **C7 老好人 / C3 护短** 相性的武将个人忠诚 **−2**（狠活 backlash）；D4 清廉不额外 |
| 大统领 | **可处决**（教程三选一演示；外交震荡按当事阵营 −15） |
| 设计意图 | 处决=最省事的清库存，但人才永久减员+外交震荡+己方人心是三重代价；Lv3 用"司法程序"给大国一个降震荡的出口 |

### 4.5 释放

| 项 | 规则 |
|---|---|
| 去向 | 原阵营存活 → **归国**（回原阵营，驻城待分配）；原阵营已灭／不愿归 → **在野**（`status:free`，人才市场可招安） |
| 外交 | 原阵营关系 **+5**；释放**大统领**：原阵营关系 **+10**（已灭国→在野/复国事件钩子） |
| 个人 | 该武将对释放者记录隐藏好感 `gratitude`（日后在野更易招安、同阵营更稳） |
| 宝物 | **随将归还**——沿用俘虏与处置 |
| 设计意图 | 释放=外交投资，不是慈善；小阵营靠放俘换关系与「义名」 |

### 4.6 越狱（负反馈 · 建议保留，可砍）

| 项 | 规则 |
|---|---|
| 判定 | 每 **10 回合**对每名在押武将判定 1 次 |
| 概率 | `p = (50 − L) / 50 × 3% × K_escape`（**只有 L<50 才触发**；L≥50 → 0） |
| 结果 | 回原阵营（存活）／在野；该城**治安 −3（一回合）**并汇报"监狱失守" |
| 设计意图 | 低忠诚武将不能无限养；监狱等级越高越安全；与劝降的"忠诚消磨"形成时间压力（要么劝降要么处置） |
