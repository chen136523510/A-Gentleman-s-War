## 一、口径铁律（全表适用）

| # | 规则 | 说明 |
|---|---|---|
| 1 | **升级不变占地** | 升级线共用同一地块（landW×landH 不随 Lv2/Lv3 变化）；本表占地=该线任一等级占地 |
| 2 | **维护 = 财造价 × 1%** | 四舍五入到 0.5；文化建筑同样吃 1%，**是财的出口之一**（非纯消费） |
| 3 | **产出 × 在岗率** | 文化/娱乐/文旅收入都乘 `staff = 劳动力层级在岗率`；失业→建筑白建 |
| 4 | **岗位 ≠ 服务人口** | 岗位=就业（产出乘区）；服务人口=覆盖强度 `c=min(1, Σ服务人口/P)`（娱乐 E）；覆盖圈已删 |
| 5 | **文化产出 = 直产 × 因子 + 末端** | 建筑文化值是"裸值"，乘 §六 因子层；典藏陈列只在末端加法（不吃因子） |
| 6 | **消费池只约束本地份额** | 娱乐/文旅单座有"池上限"；文旅再乘热度 B 方案（外来客流，可溢出份额，封顶 2.0） |
| 7 | **每城上限是硬上限** | 与工业/商业/学院同口径；世博会额外 **每阵营 1 座** |
| 8 | **沿海/内陆判定读 `cities.json.coastal`** | 度假区 Lv3 双形态：沿海=滨海度假区，内陆=温泉度假村（同档不同特效） |

## 六、修正层系数（v1.0 定稿）

### 6.1 城文化产出（公式 A）

```
C_out = [ 基础值 + Σ(建筑文化值 × 在岗率) ]
        × (1 + 0.15×livF + 0.20×popF + 0.15×techF)
        × (1 − 污染惩罚)
        + 典藏陈列末端注入
```

| 因子 | 定义 | 范围 | 参数 ID |
|---|---|---|---|
| `livF` | `clamp((宜居L − 50)/50, −0.5, 0.5)` | −7.5%~+7.5% | `culture.factor.liv=0.15` |
| `popF` | `min(人口P/50000, 1)` | 0~+20% | `culture.factor.pop=0.20` |
| `techF` | `min(已研科技数/38, 1)` | 0~+15% | `culture.factor.tech=0.15` |
| 污染惩罚 | `clamp(本地污染U/100, 0, 0.30)` | 0~−30% | `culture.pollutionCap=0.30` |

> 因子层总乘区约 0.85~1.42；**不合并不叠乘同类项**。典藏陈列是末端加法，不吃上述任何乘区（B6 末端注入制）。
> **传媒大学 ×1.10 乘区已删（2026-11-09 院长改裁）**：传媒大学改为提供文化系 NPC 武将（培养制），本公式**不含传媒乘区**——`culture.mediaMult` 参数作废。

### 6.2 城市热度

```
Heat = (10 + C_out × 0.8 + 陈列文物数 × 1.2) × (1 − 污染惩罚) × 动荡系数
动荡：和平 ×1.0 / 交战 ×0.5 / 被占领军管 ×0.5 / 起义 ×0.2（映射既有城态，不新增状态量）
分档：<30 寂寂无闻 | 30~59 初露锋芒 | 60~99 声名远扬 | 100~149 名扬四海 | ≥150 万邦来朝
```

- 参数：`culture.heatBase=10`、`culture.heatCoef=0.8`、`cultureRelicHeat=1.2`（每件**陈列**文物；撤下/转移/交易即降，出土未陈列不提供）。
- **陈列文物提供热度**（11-05 晚补裁，覆盖 B6 旧裁"不提供热度"）；现实地标词条可另给少量基础值/热度，随城走。
- 实测：**中配全量流大城 30~41（含陈列）；满配静态 v11d-c 45~51（未计陈列，计陈列 +2.4~7.2）**。六轮"大城 50~65"的预期对应**满配+陈列+事件**口径。

### 6.3 文化进民生 B+C 与同化

```
n = min(1, C_out / 30)                     ← 阈值 30；一个旋钮两个效果
W_cap = 85 + 15 × n                        ← B：抬民生上限（不进生存主式）
W_target = clamp(W_raw, 0, W_cap)
忠诚文化项（正向流）= +0.5 × n              ← C：进 Δ忠诚 流量式
同化文化因子 = clamp(1 + 1.5×(Cnat − Cavg)/Cavg, 1.0, 2.5)
同化/回 = min(P_f × 0.02 × 因子 × (1 − 0.5×占领), P_f × 0.05)
```

- 无文化城 W 上限 85（W_raw<85 时完全无感，不惩罚生存）；文化产出 ≥30 解锁满上限 100；ΔW=15。
- 忠诚文化项与占领城文化错位负流并存；数值期如过强先削 C 的 0.5。
- 同化相对均值：Cavg=存活阵营存量均值；v11d 实测因子梯度 **1.00 / 1.12 / 1.61 / 2.50**（不再全顶格）。

| 娱乐回收 | `min(份额剩余, 单座上限) × 在岗率` | 娱乐建筑直产财；维护 1% 是净出口 |
| **红灯区（11-12 入池）** | **娱乐 25% 份额内** | 院长 11-12 裁：红灯区作为商业区建筑**共享需求池**，与大众娱乐同占娱乐份额；九卡单座上限 8~45、按建造顺序依次结算（[红灯区建筑数值](./红灯区建筑数值.md) §一）；池不够时维护照付 |

> **v11d-c 实测（SHARE 60/25/15 + 池 2.5）**：CN 娱乐收 118.8 / 文旅收 64.2 / 文化维护 250.0 / 净文化 −67.1；JP −21.6、KR −32.6、AU −35.6；**14 城文旅零收入 0**（有文旅建筑的城全部有收入）。税覆盖后总净为正；文化整体仍是**净 sink**（符合财出口定位）。
