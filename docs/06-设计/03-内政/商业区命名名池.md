# 商业区命名名池（B1-C · §4.8 命名系统配套）

> 状态：📝 **v1.0（2026-11-06 白机产出；随商业区 v0.9 复启一并定稿）**；归属：[商业区开题.md](./商业区开题.md) §4.8 建筑自动命名系统；只用于自动命名，不影响数值。
> 用法（与文化区名池同规）：开局每城按建筑类型从本城名池**随机洗牌、不重复**；池尽则"XX·2 号"编号；玩家可随时更名；跨城同名自动加城市前缀（如"上海·恒隆广场"）。
> 锚点：现实商业设施/街区/机构名，在 1999 架空世界观内视为"灾前旧名"；不使用真实人物名。每城每类 **≥6 项**。
> **建造条件照建筑卡（§4.1）不变**：港口物流园=沿海限定（**北京/西安/首尔不可建**，此列仅沿海城有效）；商场=人口 ≥30k（**达尔文开局不可建**）；银行=写字楼 ≥1。条件不满足时本城池子留存不生效。
