# 人口与宜居度

> 状态：✅ 结构已定（R13），数值待一期成型后微调；**R39 移民骨架 + R43 移民细则全量定稿**（自发移民/配额/遣返/同化/迁移）；**R44 概念架构定稿 → [人口体系架构.md](./人口体系架构.md)**（宜居/民生/人口/环境/服役的分层、因子、参数；算法系数待逐条讨论）

## 人口机制

- **人口三账（R44 明确）**：本国 / 外籍（移民）/ 在途（迁移中）；总人口=本国+外籍，在途不计产出；
- **存量与增速**：人口有存量与增长速率两个量，受 **粮食、宜居度、住所（居民楼承载量）、政策** 等因素影响；增速公式 R44 改**比例制**（人口×基础率×宜居因子×粮安全×承载余量），旧绝对值 v0 作废待认——见 [人口体系架构.md §4/§8](./人口体系架构.md)；
- **人口承载量**：由居民楼决定上限（见下节），无住所则人口不增长/流失；
- **人口的作用（取舍环核心）**：

```
高人口 → 生产提升（正反馈）
       → 基础设施建设成本提高 → 间接降低宜居度（负反馈）
低宜居度 → 居民流失、忠诚（民生）降低、生产力下降
```

玩家的取舍：铺人口吃生产红利 vs 控规模保宜居度；量质选择（鸽子笼塞人 vs 别墅养质量）。

## 移民与他国人口（R39 骨架 · **R43 院长拍板定稿**）

- **人口分账**：城市人口 = **本国人口 + 他国人口**（移民）两笔账，面板分别可见；
- **他国人口的来源**：武装难民接收（[04-军事/战斗总述.md](../04-军事/战斗总述.md)）、政策引入、自发移民（下条）；
- **他国人口的作用与代价**：可作**生产力**（政策引入移民劳动力）；**他国人口过多会持续压低民生**（文化/治安摩擦）——量价取舍；
- **自发移民（R43 院长定）**：**民生差超过 20 即发生自发流动，包括城市间的**——
  - 任意两城民生差 >20 → 低民生城人口流入高民生城（同阵营城际流动记**本国人口账**；跨阵营流入记**他国人口账**）；
  - 规模建议：`流入/回合 = (民生差 − 20) × 系数`（系数数值期，建议 5 人/点）；
  - **本国城际流动不可限制**（院长定）；移民政策**只能限制他国人民进入本国境内**；
  - 现实依据见 [00-调研/移民与遣返调研.md](../../00-调研/移民与遣返调研.md)。
- **配额（R43 定）**：城市级移民面板**五档**——关闭/低/中/高/不限（每回合 0/50/100/200/∞ 人，数值期）；**配额只管"政策引入"他国人口**；自发移民不受配额管，由"限制移民"政策开关控制他国入境（政策卡专题联动）；
- **遣返（R43 定）**：面板开启"遣返"→ 每回合送 N 他国人口回原籍（对方人口账 +N）——**不耗财**（现实常规遣返=送回家成本低，[调研依据](../../00-调研/移民与遣返调研.md)）、**无外交后果**（送人回家对方无怨言）；**真正代价=失去劳动力**（遣返者不再提供生产力）；
- **人口同化（R43 定）**：他国人口每回合转化 **5%**（约 20 回合转完）入本国人口账；**文化钩子（院长认可的好设计）**：同化速率 ×（1+文化认同因子）——KR 文化强城同化快，与文化系统联动；未同化人口持续压民生、同化后压力消失；
- **难民冲击公式（R39）**：接收武装难民 → 进驻城市民生直接降低 `冲击值 = 难民规模 / 本城人口 × 系数`（上限 30 民生）；
- **城市间主动迁移（R42 立 · R43 定稿）**：一次性迁移——选档位（500/1000/2000 人，数值期）、**耗时复用行军表**（内陆 1 回合/跨海 2~4，R38）、耗财（人头费）+粮（途中口粮）、**迁移中人口挂"在途"不产出（劳动力闲置）**；**迁出城无民生惩罚**（院长定：消耗财粮+劳动力闲置就是最大惩罚）；迁入城受承载量限制（超承载不进）；
- ✅ 概念架构已立项：**宜居度/民生/人口/环境/服役**的分层、因子全表、参数清单与反馈环见 [人口体系架构.md](./人口体系架构.md)（R44 定稿）；算法系数待逐条讨论。

## 居民楼（R13 新增建筑类别，六区域之外）

承载人口容量的专用建筑，类型按"量/质"分档：

| 类型 | 取向 | 特点 |
|---|---|---|
| 鸽子笼 | **量优先** | 单位面积承载量最高，宜居度贡献低（香港名场面梗） |
| 密集型公寓 | 量优先 | 承载量高，宜居度中低 |
| 小区 | **质优先** | 承载量中，宜居度贡献高 |
| 别墅 | 质优先 | 承载量低，宜居度贡献最高 |
| 其他类型 | 🏗️ 待补充 | 院长原话"以及一些其他类型"——待专题扩充 |

## 宜居度（R44 定性重构）

- **定义**：城市**客观**居住环境质量 0~100；是最顶层状态指标"民生"的主因子之一（R44 院长定）。
- **来源（院长 R44）**：**住房**（承载率、居民楼质量构成）、**娱乐区**（覆盖圈×等级，距离衰减；满覆盖=+6/Lv）、**治安水平**、医疗设施、城市固有基线；
- **减项**：环境污染——本地重工业污染、海平面（一级 −10）、臭氧（AU 先受逐回衰减）、核残留（−30 起，30 回合减半）；酸雨走粮产/维护，不进宜居直算；
- **效果（院长 R44）**：**影响生产产出**（作为全产出乘区）+ 人口增速因子；不再笼统写"生产力下降"；
- **算法形态**：目标值（基线+各项）→ 实际值每回合缓动（建议 25%）；事件瞬时冲击只扣实际值，目标值不污染；
- **与民生的关系（R14 院长确认，R44 强化）**：宜居度是民生的一项主因子（客观条件）→ 民生（主观综合生活水平）→ 城市忠诚度/起义。全表见 [人口体系架构.md §5/§6](./人口体系架构.md)。

## 与其他系统的联动

- **娱乐区生效范围**：离居民区越远效果越差（覆盖圈机制，见 [01-地图与城市/地图三层架构.md](../01-地图与城市/地图三层架构.md) L2 规划基点）——摆位策略：娱乐区贴居民区；
- **工业区污染**：重工业（矿采/冶炼/化工）造成环境污染→宜居度下降（环境系统 ⛏ 专题待开）；
- **城市发育度**：人口是城市发育度 Dev 公式的输入之一（见 [01-地图与城市/城市成长与城防.md](../01-地图与城市/城市成长与城防.md)）；
- **二期战场**：居民楼=城内地表建筑（可掠夺/掩体形态待战斗细则）。
