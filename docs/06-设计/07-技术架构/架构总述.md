# 架构总述

> 状态：✅ v2（R23 Unity 版重写；R1/R4 Web 版架构**已被 ADR-009 取代**，思想继承见下）
> 引擎：Unity 2022.3.62f3c1 LTS 中国版 + URP 2D（C#），单机 Windows exe 分发
> 更新：2026-10-25 R23

## 技术选型（现行）

| 项 | 定案 |
|---|---|
| 形态 | Unity 单机 exe（黑机构建 `Builds/Win64/`，分发由院长执行） |
| 渲染 | URP 2D：L1 大地图=离线烘焙大纹理+运行时 Sprite/航路/标签叠放（现状）；L2/L3 二期 |
| 数据 | JSON 数据驱动不变：`Assets/_Project/Data/*.json` 一份服三层（L1/L2/L3 同源铁律） |
| 逻辑 | 纯 C# 规则层（程序集内普通类，**不依赖 MonoBehaviour**——可单测、可被修改器/回放复用） |
| 序列化 | Newtonsoft Json.NET（R20 已引入）；存档/静态配置/战报同栈 |
| 依赖 | 全免费/开源，零订阅（红线） |

## 分层（思想自 Web 版平移，载体换 C#）

```
Unity 表现层（Scene/uGUI/相机/动画/音效）
        ↑ 只读状态 + 下发 Command
C# 规则层（唯一状态源：GameState——城市/武将/资源/外交/科技/战斗）
  ├── 规则系统（内政产出/忠诚起义/俘虏/外交判定/事件流——公式=数值设计总纲）
  ├── 算法 AI（三阵营内政军事：边际收益+威胁图+机会评分，蓝本 §9.2 伪代码）
  ├── 战斗模型（兰彻斯特平方律内核，自动/手动两档共用）
  └── 指令总线（所有状态变更的唯一入口，含修改器）
```

- 继承的四条第一天纪律（Web 版确立，全部保留）：①指令总线 ②设施=战场可读模型（不写两套数据）③一套战斗模型两档共用 ④数据与逻辑分离。
- LLM 纪律不变：二期军师只读 snapshot、外交 LLM 只出话术，JSON Schema+规则闸门（[05-外交/关系规则与LLM.md](../05-外交/关系规则与LLM.md)）。
- 难度=显式参数（总纲 §五）；AI 决策可解释（记录理由字符串）——战报与调试共用。

## 回合循环（一期主循环，R23 定框架）

```
玩家阶段（任意时长，无时间压力——单机友好）
  ├─ 内政操作（建造/分配/募兵/科研/外交）→ 逐条 Command 入总线
  └─ 点「结束回合」
结算阶段（原子执行，全程可生成战报）
  ├─ 产出结算（总纲 §4.1/4.3）→ 维护/俸禄扣除 → 人口/民生/忠诚漂移
  ├─ 事件判定（起义/自立/天灾二期）→ AI 三阵营决策（内政+军事）→ 移动/交战结算
  └─ 回合数 +1 → 自动存档钩子
```

- 回合是数值与存档的时间本位（总纲 §二）；战斗结算发生在结算阶段（一期无实时元素）。
- Command 全记录 → 天然支持：撤销（开发期）/回放（调试）/修改器审计。

## 不做

- 不做网络对战/多人同步/服务端对局；
- 二期 RTS 战场不做战中造兵（红警边界，战斗总述）；
- 不做热更新/Mod 系统（单机发朋友，版本=重发包）。
