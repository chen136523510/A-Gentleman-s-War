## 一、院长已定约束

1. **UI 大头右上**；顶部可放一部分；**左下可用**；**右下禁止任何常驻 UI**（遮澳洲）。

## 五、城名字标（统一行楷 + 阵营色）

- **资产**：`Assets/_Project/Resources/Wordmarks/{city}.png`（14 张，512×160 透明 PNG；白色渐变填充 + 深色描边/阴影）。
- **运行时**：`Image.color` 乘阵营色 → 字标呈现该阵营色；**字体始终行楷**，阵营变更只改 tint，不用换图；自立阵营给随机色即可。
- **阵营色**（`cities.json factions`）：CN `#C0392B` / JP `#E8C547` / KR `#F0F0F0` / AU `#3D8FD1` / NONE `#9AA0A6`。
- **自立阵营随机色去重**：新增阵营时从 12 色备选盘随机取色，跳过五主色与已用色（数据侧规则，M2 落地）。
- **样张**：`tmp/city-wordmark-sample-v2.png`（统一行楷 + 阵营配色）。
- **生成脚本**：`tools/art/gen_wordmarks.py`（本机 `C:\Windows\Fonts\STXINGKA.TTF`；换字体/换色重跑即可）。
- **字体授权说明（需院长知悉）**：华文行楷是 Windows/Office 自带字体，**不是开源字体**；本项目只把字**栅格化成 PNG**，不随包分发字体文件，玩家无需安装。若游戏要公开/商用分发，建议改用 OFL 字体（如霞鹜文楷、马善政楷书）重跑脚本，规避厂商字体授权风险。
- 城市面板头部的字标与地图城名共用同一张 PNG，保证“地图/面板同一套字”。

## 六、交互状态机

| 状态 | 触发 | 表现 |
|---|---|---|
| Normal | 默认 | 字标=阵营色 |
| Hover | 鼠标进入字标矩形 | 金色描边 + 1.12x + 金下划线 + tooltip“城名·阵营” |

| Hidden | 各块“－/×” | 块隐藏，原位出现“＋ …”恢复条 |
| Help/Menu | `?`/`设`/ESC | 说明/菜单面板；hover 与 tooltip 暂停 |

- 空白拖拽平移；滚轮缩放；ESC 菜单暂停相机。

## 十、2026-10-28 二轮 UI 口径（院长看图逐条修正）

1. **大统领=玩家**：HUD 显示“大统领（玩家）”，删除丘序明/陈睿等具名领袖；开局卡只留政体+城/将数。外交对外示人的是各国外交官（魅力/智力/被动技能），待外交轮实现。
2. **难度 UI 删除**：开局界面不再有简单/普通/困难；`GameState.Difficulty` 暂存“普通”，无 UI 入口。
3. **疆域显示删除**：顶部 `疆` 开关与全部柔光色块移除（未正确烘焙）；地形掩码只服务探索寻路/视野。
4. **HUD 加文化值**：六项资源后追加“文化值”（国家值=城市文化值总和，v0 占位见 `文化输出算法.md §2.1`）；HUD 高度 380，七行 24px，解决“民生”和“城6”重叠。
5. **空城面板不弹**：未选城市时城市面板与“＋城市”都不显示；选中城市才出现；城市面板删除 `note` 设计备注文案（如“富士康工业·低忠诚高自立风险”）。
6. **城市标签**：字标 PNG 裁掉透明边距（标签贴近城盘）；贴边城市自动翻到城上/城下；未选城时己方城市标签轻闪提示可点。
7. **他国数据**：城市存在/归属可见，城内数据（国防/民生/财/首长）一律 `？`，等情报/间谍体系。
8. **外交移到国家面板**（2026-10-28）：城市面板删“外交”，右上国家面板底部加“外交”按钮（国家维度）；城市面板只留 探索/军事/详情。
9. **国防**：城市面板“城防力量”统一改名“国防”（2026-10-28 院长口径）。
10. **城市金晕删除**：底图烘焙的城市金色高亮光晕已用 `tools/bakery/strip_city_glow.py` 逆合成抹掉，`paint-map.js` 后续重烘不再画；剩下的城市贴图底座/广场是美术本身。
11. **探索队标识**：世界空间队伍图标上方加文字标签“船队/探索队”，避免红色三角被误认。
