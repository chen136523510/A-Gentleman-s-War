## 一、院长已定约束

1. **UI 大头右上**；顶部可放一部分；**左下可用**；**右下禁止任何常驻 UI**（遮澳洲）。
2. 画风跟随本系统：深棕漆木/暖金描边/米白文字，古风质感。
3. **城名本身=悬停/点击区域**（不用城盘光圈）；悬停要高亮。
4. **城名统一行楷**；颜色随阵营：**中国红 / 日本黄 / 韩国白 / 澳洲蓝 / 无主灰**；自立阵营随机色去重；阵营变更字体不变。
5. 城市面板：**城防力量 / 民生 / 财 / 首长**（原守军/民忠/金/武将；金已统一为财，忠诚度口径统一为民生）。
6. UI 先展示；**每一块都要有隐藏/展示小按钮**。
7. 红框内为可玩区；最小缩放上下拖拽看澳洲（已接受）。

## 一之二、R37b 当前实现（2026-10-26）

### 开局
- 全屏开局界面：**选阵营（CN/JP/KR/AU）+ 难度（简单/普通/困难）**；卡片显示政体、领袖称呼、城/将数、推荐难度。
- 领袖：CN 丘序明（主席）/ JP 陈睿（君主）/ KR 陈楠（总统）/ AU 马逸杰（总统）；开局后主 HUD 显示 `称呼：姓名`。
- 难度写入 `GameState.Difficulty`（本轮 AI 未接，仅存值）。

### 主 HUD（右上 420×340）
- 六项资源：**财 / 粮 / 军力 / 生产力 / 科技值 / 民生**。
- 军力 = **服役人数 × 战斗力 × 军备**；底部小字展开分项（如 `500 × 1.0 × 1.0`）。
- 城/将数、探索次数、财/粮净收入/回；结束回合触发真实结算 + 自动存档。
- 顶部状态条：`第 N 回合 · 年份`（1999 起，1 回合=1 年）+ 事件条 + `疆`（疆域色块显隐）/ `设` / `?` / `－`。

### 城市面板（左下 380×260）
- 显示真实数据：**城防力量（当前/上限）/ 民生 / 财/回 / 首长**；底部状态行显示城市生产力、科技、探索次数。
- 按钮：**探索 / 军事 / 外交 / 详情**；探索=从己方城市揭示相邻未知城（每回合 1 次）；其余为后续轮占位。
- 默认选中玩家阵营的第一座城（CN 北京 / JP 东京 / KR 首尔 / AU 悉尼）。

### 迷雾与探索
- 开局**只看得见己方城市**；其余城市为深色迷雾 + `？`，城名/阵营/航线全部隐藏。
- 探索 1 次/回合：从己方城市出发，揭示所有直接邻接城；结束回合恢复次数。
- 航线仅在两座城都探明后显示。

### 疆域色块（试作）
- 每城一圈阵营色柔光（直径 340 世界单位，己方 α0.16 / 他国 α0.10 / 无主 α0.06），城盘中心留空。
- 顶部 `疆` 按钮可一键显隐，供院长对比评价；后续可按反馈调整半径/透明度/形状。

### 存档 v2
- `GameState` 全量（回合/阵营/难度/资源/城市/可见性/探索次数）+ 相机，写 `auto.agw.json` 与 `turnNNNN.agw.json`。
- 开局与结束回合自动存档；ESC 菜单手动存/读档；旧 v1 存档不兼容提示。

- **顶部状态条**（右对齐 62% 宽、44px）：`第 1 回合 · 2026 春` + 事件/操作提示 + `设`（ESC 菜单）/`?`（操作说明）/`－`（收起）。

## 五、城名字标（统一行楷 + 阵营色）

- **资产**：`Assets/_Project/Resources/Wordmarks/{city}.png`（14 张，512×160 透明 PNG；白色渐变填充 + 深色描边/阴影）。
- **运行时**：`Image.color` 乘阵营色 → 字标呈现该阵营色；**字体始终行楷**，阵营变更只改 tint，不用换图；自立阵营给随机色即可。
- **阵营色**（`cities.json factions`）：CN `#C0392B` / JP `#E8C547` / KR `#F0F0F0` / AU `#3D8FD1` / NONE `#9AA0A6`。
- **自立阵营随机色去重**：新增阵营时从 12 色备选盘随机取色，跳过五主色与已用色（数据侧规则，M2 落地）。
- **样张**：`tmp/city-wordmark-sample-v2.png`（统一行楷 + 阵营配色）。
- **生成脚本**：`tools/art/gen_wordmarks.py`（本机 `C:\Windows\Fonts\STXINGKA.TTF`；换字体/换色重跑即可）。
- **字体授权说明（需院长知悉）**：华文行楷是 Windows/Office 自带字体，**不是开源字体**；本项目只把字**栅格化成 PNG**，不随包分发字体文件，玩家无需安装。若游戏要公开/商用分发，建议改用 OFL 字体（如霞鹜文楷、马善政楷书）重跑脚本，规避厂商字体授权风险。
- 城市面板头部的字标与地图城名共用同一张 PNG，保证“地图/面板同一套字”。

## 六、交互状态机

| 状态 | 触发 | 表现 |
|---|---|---|
| Normal | 默认 | 字标=阵营色 |
| Hover | 鼠标进入字标矩形 | 金色描边 + 1.12x + 金下划线 + tooltip“城名·阵营” |
| Selected | 点击字标 | 提亮阵营色 + 1.16x + 4px 金下划线；左下城市面板打开/切换 |
| Hidden | 各块“－/×” | 块隐藏，原位出现“＋ …”恢复条 |
| Help/Menu | `?`/`设`/ESC | 说明/菜单面板；hover 与 tooltip 暂停 |

- 城盘金晕只是地标视觉，不参与点击。
- 按在城名/HUD 面板上均不触发地图拖拽（`BlockDrag` + `EventSystem.IsPointerOverGameObject`）。
- 空白拖拽平移；滚轮缩放；ESC 菜单暂停相机。
