## 方案（现行）

| 项 | 定案 |
|---|---|
| 位置 | `%USERPROFILE%/AppData/LocalLow/<company>/<product>/saves/`（Unity persistentDataPath） |
| 格式 | JSON 单文件（Newtonsoft，Indent 排版——朋友局可直接发文件互相看进度） |
| 槽位 | `turnNNNN.agw.json`（**按回合数命名**，院长 R21 指令）+ 1 个 `auto.agw.json` |
| 时机 | 手动（ESC 菜单=存/读）+ 自动（每回合结算后写 auto 档；读档默认开 auto） |
| 导出/导入 | 文件即导出（复制即分享）；导入=放进 saves 目录后在读档列表选——不做上传 UI |

## 存档结构 v2（回合制数据模型，M2 施工清单）

```jsonc
{
  "schema": 1,                    // 版本号，迁移函数用
  "turn": 42,                     // 回合数（槽位名同源）
  "difficulty": "normal",
  "faction": "CN",                // 玩家阵营
  "savedAt": "2026-10-25T12:00",
  "state": {                      // = GameState 完整快照（规则层唯一状态源）
    "resources": { ... },         // 阵营级资源（财/粮/军力/…）
    "cities": { ... },            // 14 城所有权/建筑/人口/民生/城防/城态
    "officers": { ... },          // 21 将位置/忠诚/被俘状态/技能冷却
    "diplomacy": { ... },         // 关系矩阵/条约/声望
    "tech": { ... },              // 各阵营已研节点
    "events": { ... },            // 活跃事件（起义进度/天灾冷却/异族波次）
    "environment": { ... },       // 世界级共享块（R42）：五账本累计值/温度指数/海平面/矿脉档位/配额状态——独立数据层，见 [00-总纲/环境系统.md](../00-总纲/环境系统.md) §十
    "rng": 123456                 // 随机种子（战报可复现）
  },
  "camera": { "x": 0, "y": 0, "zoom": 1.0 }   // 表现层状态（M1 桩已实现）
}
```

- **只存规则层状态**：表现层（相机/已开面板/音量）单独一小节；随机种子入库=同存档重打同结果（回放/调试免费获得）。
- 回合制存档的意义：天然防"S/L 大法"漏洞（v2=回合边界快照）；战报与存档同构可互查。
- **R36 变更**：**战役中途可存档**（推翻"无战中存档"口径）——需 v3 存档结构（战斗内单位/指令/随机状态入档），本文件施工前先升版。

## v2 字段扩展（2026-10-28 黑机 · 探索迷雾/军力 v0 实装）

- `FactionState.equipmentStock`：军备存量（旧 `equipment` 保留为系数；旧档缺失时按 `troops × equipment` 迁移）。
- `CityState.culture`：城市文化值（v0 占位，`cities.json` 的 `culture` 字段）；`FactionState.culture` 为城市总和，读档时重算；旧档缺失时按 `cities.json` 补齐。
- `state.explored`：每阵营一份 320×180 探索掩码（`byte[]` → JSON base64；1=已探索）。`visible` 每次载入/结算重算，**不入档**。
- `state.tasks`：探索任务列表（id/阵营/出发城/目标/陆海队/路径点/进度/总回合/耗财）；路径点为 `{X,Y}` 世界坐标。
- `state.knownCities`：保留为兼容/快速查询，载入时按玩家 `explored` 掩码与城市锚点重算；旧档只有 KnownCities 时，先把它折算成探索圆再补初始视野。
- 存档仍是 schema 2（增量字段，向后可读；v3 战役中途存档仍挂账）。

## 版本兼容

- schema 版本号 + 迁移函数链（`migrate_1_to_2()`…）；开发期可直接清档，正式发包后必须兼容（朋友局版本可能混发）。

## 与修改器的关系

- 修改器改的是**运行时 GameState**（走指令总线），存档照常快照——作弊档打 `"cheated": true` 标记（不隐藏，朋友局透明）；
- 修改器可开关自动存档、改回合数（跳章节调试）。
