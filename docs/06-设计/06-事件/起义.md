# 起义（城市中立）

> 状态：✅ 结构已定（R8/R39）；**2026-11-10 院长裁：删“叛乱（外籍）”支线、删概率、统一城市忠诚度单阈值**；起义城 AI 参考达尔文自行发展。
> 上游：[人口算法 §7.4](../03-内政/人口算法-v1.md)（城市忠诚度）· [02-武将/忠诚度.md](../02-武将/忠诚度.md)（自立/外逃）· [战斗类型](../04-军事/战斗类型.md)（平叛）· [L3战斗场景](../04-军事/L3战斗场景.md)。

## 触发（唯一开关：城市忠诚度）

- **普通城**：城市忠诚度 **<30 连续 3 回合** → 起义；
- **占领城**：**<20 连续 10 回合** → 起义；
- **不再掷概率**：删 `(30−忠诚)/30`、不再按民生直接判、不再有“驻军/人口≥5% 硬零”；
- 驻军/民生/治安/外籍/文化/占领等只通过**城市忠诚度流量**间接影响；
- **明牌**：事件面板可见各城忠诚/风险；回合末驻城武将汇报。

## 结局（起义触发时判定）

1. 城中**仅 1 名武将**且其**个人忠诚 <40** → 该将**带城自立**（WLT 等新阵营）；
2. 否则 → 城市**中立起义**：不属于任何阵营，只守不攻；
3. **玩家可预防**：起义触发前把孤城低忠诚将调走，城中无将→中立起义，不会自立；
4. **外逃先于起义**：低忠诚将先外逃，也不会自立。

## 中立起义城行为（参考达尔文）

- **AI 自行发展**：像达尔文一样经营经济/农业/军事，守军持续变强；**不对外扩张、不外交**；
- **其他阵营进驻/占领**：**走 L3 战争**（平叛/收复），不是点一下就进；
- 守军构成：**中立起义** = 原城防军 50% 转民兵、无武将指挥（战力打折）；**自立结局** = 该将带城 + 驻军，有武将指挥（WLT 新阵营）；
- 攻取后：民生/忠诚重置到基线（防连环再起义），驻将/建筑派驻按新城处理。

## 抑制

- 提高城市忠诚度（民生/治安/治理/文化/驻军/武将流，见人口算法）；
- 驻军提供忠诚正流；
- **多将同城** + 起义前调走孤城低忠诚将（防自立）；
- 赏赐/加俸稳个人忠诚（防外逃）。

## 王乐添

- **不是自然起义**：第 1 回合锁定台北与王乐添，第 2 回合固定事件触发 WLT（不可阻止）；见 [02-武将/忠诚度.md](../02-武将/忠诚度.md)。
