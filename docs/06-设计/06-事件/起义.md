# 起义

> 状态：✅ 结构已定（R8 改名+定机制），**M6 触发公式与细则定稿（R39）**，数值带一期成型后微调

## 两种"造反"，机制分开

| | 起义（城市） | 自立（武将） |
|---|---|---|
| 触发主体 | 城市/民众 | 武将个人 |
| 主因 | **民生**低到一定程度 | **个人忠诚**低 + 独领一城（通常也伴随民生低迷） |
| 结果 | 城池变**无主之地（中立）**，类似中立单位，**只守不攻** | 建立以头目名缩写命名的**新阵营**（如 WLT），城与驻军倒戈 |
| 文档 | 本文件 | [02-武将/忠诚度.md](../02-武将/忠诚度.md) |

院长原话："绝大多数情况下，只有民生低到一定程度，才会引发这种事件。"

## 起义城（中立）行为

- 不属于任何阵营，不主动进攻；
- 可被任何阵营攻取（平叛/收复）；
- 攻取后需派将驻守，否则走"衰减→空虚→民生恶化→再起义"链路（R11 三态，废弃已删）；
- **起义城自行发展（R39 院长定）**：一直不平叛，起义城市**由 AI 管理、自行经营成长**（内政发展+守城自固；不对外扩张、不外交）——久拖不决的起义会变难啃；
- 一期：以状态+数值结算实现；二期：平叛可作为一种战斗类型（见 [04-军事/战斗类型.md](../04-军事/战斗类型.md)），守军为起义民兵。

## 触发公式（R39 定稿）

- **随机滚动**：民生 <30 进入风险区，每回合起义概率 **p = (30 − 民生) / 30**；**民生归 0 必起义**。
- **明牌**：事件面板可见当前各城起义风险（不做暗判）；
- **不传染**：单城事件，不扩散邻城（负反馈纪律从轻）。

## 守军与攻取

- **起义民兵 = 原城防军 50%**、无武将指挥（战力打折待数值）；
- **攻取后民生重置到 60 基线**，后续靠衰减链自然演化（防连环再起义）。

## 抑制

资源足够即可稳住后方（院长原话）：娱乐中心/建设提升民生、驻军压制、太守能力；具体手段与数值待内政数值专题。

## 待数值

- 风险区概率曲线已定（p=(30−民生)/30）；民生基准值与各来源增减幅度待数值带；
- 起义城 AI 发展的强度曲线（多久长成什么样）；
- 中立城守军强度系数（50% 起步待调）。
