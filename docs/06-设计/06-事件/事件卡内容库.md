## 〇、通用规则速查

| 项 | 口径 |
|---|---|
| 领域图标 | 卡面右上角：经济=金色钱币 / 文化=紫色音符 / 军事=红色交叉双剑 / 科技=蓝色书本 / 政治=白色笑脸 / 生产=橙色齿轮 / 民生=绿色树叶 |
| 触发时机 | `turnStart`（回合开始，出现即生效）/ `preSettle`（归属阵营结算前出现，下回合初生效）/ `turnEnd`（全结算后，仅全局事件） |

| 描述风格 | 一两句话具象描述，不落情绪、不讲数值 |

## 一、普通卡（灰白 · 0 改数值 · 机制呈现）

### P1｜起义 `uprising` · 政治 · turnEnd

- **触发**：城市忠诚度 <30 连续 3 回合（普通城）/ <20 连续 10 回合（占领城）。
- **呈现**：城市中立（只守不攻，AI 自行发展）；守军 50% 转民兵；原城武将→最近己方城，飞城→归隐。
- **小字**：无数值（机制自身结算）；作用域从描述可读。

### P2｜叛逃 `defection` · 政治 · turnEnd（选择型→回合初弹）

- **触发**：驻城武将个人忠诚 <40，每回合末概率（⚙ `p=(40−忠诚)/40×3%`，上限 3%/回）。
- **交互**：**选择型**——随机选一个相邻其他阵营城市，对方阵营回合初三选一：
  | 选项 | 效果 |
  |---|---|
  | 接纳 | 与原阵营关系下降；武将进入此阵营此城市 |
  | 遣返 | 交原阵营收押（市政府内嵌）；与原阵营关系上升 |
  | 驱离 | 武将停留在该城市，在野 |
- **归隐分支**：无合适去处→原城在野（不弹选择）。

### P3｜破产 `bankruptcy` · 经济 · turnEnd

- **触发**：**国库归零且净增为负数**；**每阵营每局只出现一次**（首次破产后出现；AI 阵营同样走此卡——事件卡给 AI 权重感知）。
- **描述**：「政府已无力支付订单。」
- **小字**：无数值（财政崩溃由机制结算）。

### P4/P5/P6｜海平面上升 I/II/III `sea_level_1|2|3` · 民生 · turnEnd

- **触发**：地球环境面板海平面进入对应刻度（一级/二级/三级=+1.5m 灭世线）。
- **呈现**：沿海宜居/土地变化由环境机制结算；三张卡对应三种状态，各级一局一次。
- **小字**：无数值。

### P7｜婴儿潮 `baby_boom` · 民生 · turnEnd · 冷却 30

- **触发**：人口增速**连续 3 回合**超过阈值（⚙ ≥+2%/回）。
- **描述**：「新生儿的哭声响彻整个国度。」
- **小字**：无数值（人口加速由机制结算）。

## 二、特殊卡（蓝紫 · 改数值 · 条件→概率→独立限流）

### S1｜口红效应 `lipstick_effect` · 经济 · turnEnd

| 项 | 值 |
|---|---|
| 触发 | 民生 W<35 **或** 战争/封锁 ≥5 回合 |
| 概率/冷却/持续 | 20% / 40 / 5 回 |
| 范围 | **触发城** |
| 效果 | 商业街回收 ×1.20；商场回收 ×0.90 |
| 描述 | 「商场的口红被一扫而空」 |
| 小字 | 商业街收入 +20% · 商场收入 −10% · 持续 5 回合 |

### S2｜报复性消费 `revenge_spending` · 经济 · turnStart

| 项 | 值 |
|---|---|
| 触发 | 战争结束/解封后 **3 回合内** 且 **就业率未饱和** |
| 概率/冷却/持续 | **20%** / 50 / **1 回** |
| 范围 | **全国** |
| 效果 | 商场回收 ×1.25；娱乐建筑回收 ×1.15；商业街回收 ×0.95 |
| 描述 | 「压抑到极致的瞬间燃爆！」 |
| 小字 | 全国商场收入 +25% · 全国娱乐建筑收入 +15% · 全国商业街收入 −5% · 持续 1 回合 |

### S3｜低欲望社会 `low_desire` · 民生 · turnEnd

| 项 | 值 |
|---|---|
| 触发 | t>120（后期）**且** W>70（富足）**且** 人口与财政收入增速**连续 10 回合 <1%**（增长停滞）——后期富足陷阱 |
| 概率/冷却/持续 | 8% / 60 / 20 回 |
| 范围 | **全国** |
| 效果 | 消费池 ×0.90；娱乐建筑回收 ×1.10；民生 +1（instant 一次性，"不卷了"） |
| 描述 | 「开摆！」 |
| 小字 | 全国消费池 −10% · 全国娱乐建筑收入 +10% · 民生 +1 · 持续 20 回合 |

### S4｜彩票热 `lottery_frenzy` · 民生 · turnStart

| 项 | 值 |
|---|---|
| 触发 | 某城**就业率过饱和**（岗位>可用劳动力）**且商业财收低连续 3 回合** |
| 概率/冷却/持续 | ⚙ 25% / 40 / 5 回 |
| 范围 | **触发城** |
| 效果 | 民生 −1（instant）；消费池 ×1.15（ongoing 5 回） |
| 描述 | 「如果想知道什么是希望，请买一张彩票。如果想知道什么是绝望，请买一堆彩票。」 |
| 小字 | 民生 −1 · 消费力 +15% · 持续 5 回合 |

> **娱乐建筑**词条口径：文化区大众娱乐（影院/乐园/体育馆/live/音乐厅/歌剧院）+ 红灯区九卡的消费回收（消费池 25% 份额内）；不含文旅（酒店/会展/世博）。

## 三、历史卡（金黄 · 教学副本专属 · 节点触发）

- **小字**（他人阵营不显示）：文化值 +15
