## 一、事件等级与规则

| 项 | 口径 |
|---|---|
| 等级 | `major`（与王乐添自立同级：事件条 + 驻城武将汇报，不弹红窗） |
| 唯一性 | 非唯一（`unique:false`），可重复；王乐添自立是 `unique:true` |
| 冷却 | **40~60 回合/张**；两张卡之间全局至少 10 回合；200 回合内同类卡 1~3 次 |
| **随机性** | **满足条件后按 `triggerChance` 每回合掷骰；命中才触发**——不是条件满足就稳定给收益/减益 |
| 触发 | 回合结算时按条件/权重判定；**明牌**（触发前 1 回合驻城武将汇报预警） |
| 持续 | 5 / 10 / 20 回合（见卡） |
| 效果 | 只改**建筑类型系数/税/民生/治安**，不改消费池基数；到期自动恢复 |
| 玩家操作 | 无强制操作；可通过 B8 政策（消费刺激/紧缩/社保）对冲 |
| 叠加 | 同名不叠加；不同名可叠，但总倍率封顶（街/商场各 ±50%） |

> **命名原则（院长 #1）**：卡名必须是**专有名词/历史事件**（口红效应/报复性消费/低欲望社会），不用“税收 +10%”这种数值事件当卡名；数值变化只做卡面结果（见 §二·补）。**频率**：低频、严格触发；200 回合内同类卡 1~3 次。
> **随机性（院长 #1）**：条件满足后**不是必触发**，而是每回合按 `triggerChance` 掷骰；未命中下回合再判。建议：口红效应 20%/回、报复性消费 30%/回（3 回合窗口）、低欲望社会 8%/回。种子存档；读档重掷（金手指）；同一回合不重复掷。

## 二、事件卡（3 张，院长 #5 已批）

### 卡 1｜口红效应（小确幸）

- **触发**：民生 W < **35**，或战争/封锁持续 **≥5 回合**；**触发概率 20%/回**（条件满足时掷骰）；冷却 **40 回合**。
- **持续**：5 回合。
- **效果**：商业街回收 ×1.20；商场回收 ×0.90；商情播报“本城居民转向小确幸消费”。
- **数值（60k 城示例，3 街+2 商场，池 150）**：商业街 **36→43（+7）**；商场 **114→103（−11）**；净商业 **−4 财/回**；税收不变。
- **依据**：Hill 等 2012（JPSP）；Zhang 等 2026（NielsenIQ）；C&EN 1993 的 trading down 边界。

### 卡 2｜报复性消费

- **触发**：战争结束/解封后 **3 回合内**；**触发概率 30%/回**（窗口内掷骰）；冷却 **50 回合**。
- **持续**：5 回合。
- **效果**：商场 ×1.25；文化/娱乐 ×1.15；商业街 ×0.95。
- **数值（60k 城示例）**：商场 **114→143（+29）**；商业街 **36→34（−2）**；文化/娱乐 +15%；净商业 **+26 财/回**。
- **依据**：战后消费潮/后疫情“报复性消费”（媒体/书籍概念，★级；只做事件）。

### 卡 3｜低欲望社会

- **触发**：t > 120，W > 70 但人口/收入增长停滞（连续 10 回合 <1%）；**触发概率 8%/回**；冷却 **60 回合**。
- **持续**：20 回合。
- **效果**：消费池系数 ×0.90；文化/共享 ×1.10；民生 +1（“不卷了”）。
- **数值（60k 城示例）**：消费池 **150→135（−15）**；零售回收 150→135；文化/共享 +10%；民生 +1。
- **依据**：大前研一《低欲望社会》/三浦展《第四消费时代》（书籍概念，★级）；只做后期挑战事件。

## 二·补、卡面数值展示（院长 #2）

- **主数字 = 当前城市的实际 ±**；百分比只做副标题。例：
  ```
  口红效应
  商业街  +7 财/回（36 → 43，+20%）
  商场    −11 财/回（114 → 103，−10%）
  净商业  −4 财/回
  民生/税收：不变
  ```
- 计算：`Δ = 当前值 × (倍率 − 1)`；事件打开时按**当前城市**结算，不写死全局数字。
- 卡面必须列：财/回（分建筑）、民生、治安、税收、人口；无变化写“不变”。
- 当前城没有对应建筑：显示“本城无商场，无此项”，不显示该行。
- 多城事件：按城逐个结算/展示；国家报表只给合计。

## 三、消费结构：升级/降级是数据，不是事件（院长 #5）

> 消费升级/降级不单独做事件卡；它们是**城市商业数据的趋势读数**，由玩家/AI 从面板自行判断。

```
商场份额 = 商场回收 / (商业街回收 + 商场回收)
趋势 = 近 3 回合商场份额变化：
  > +2%  → 消费升级
  < −2%  → 消费降级
  其他   → 平稳
```

- **只展示，不改数值**：城市面板/国家报表可显示“消费结构：升级/平稳/降级”，悬停给出商场份额与趋势。
- **不触发事件、不乘任何系数**；玩家要“升级”就多建商场/提高民生；要“降级”就多建街/战时收缩。
- 这样“升级/降级”是玩家行为的**结果**，而不是系统硬塞的事件。

## 五、与消费力公式的关系（院长 #7）

- 本文件的系数**不写进** `城消费力 = 民用人口/1000×2.5`；它们只在事件持续期内乘在**建筑回收/税收**上。
- 触发条件读民生/战争/税收，但**民生不直接乘池**；这是“耦合”，不是“因子”。
- 事件到期自动恢复；不需要玩家逐回合管理。

## 六、数据 schema 草案

```json
{
  "id": "lipstick_effect",
  "class": "major",
  "unique": false,
  "cooldown": 20,
  "duration": 5,
  "trigger": { "welfareBelow": 35, "orWarTurns": 5 },
  "triggerChance": 0.20,
  "weight": 1.0,
  "effects": {
    "streetRecoveryMult": 1.20,
    "mallRecoveryMult": 0.90
  },
  "report": "本城居民转向小确幸消费"
}
```

- 存档：`activeEvents[] {id, startedTurn, endsTurn}`；读档恢复。
- 兼容：旧档无字段 → 无事件；事件系统未实装时不阻塞主循环。
