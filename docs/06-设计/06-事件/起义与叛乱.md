## 一、判定总表

| | 起义 | 叛乱 |
|---|---|---|
| 人口条件 | **本国人口 ≥50%**（占领城需≥75% 才可起义；50~75% 稳定） | **外籍人口 >50%** |
| 主体 | 本国人口 | 外籍人口 |
| 触发 | **忠诚度<30 连续 3 回合**（占领城 <20 连续 10 回合）+ 非军管 | **忠诚度<30 连续 3 回合** + 外籍>50% + 非军管 |
| 默认结果 | **驻军默认倒戈**，整城带兵变阵（中立新阵营） | 攻防战：叛军（外籍、弱军备）攻，驻军守 |
| 叛军来源 | 本国人口 + 倒戈驻军 | 外籍人口 |
| 消灭叛军 | 等量消耗本国人口 | 等量消耗外籍人口 |
| 硬零 | 无（驻军正影响内嵌忠诚度，见 §二） | **驻军/人口 ≥5% → 概率=0**（留 0.5% 容差） |
| 胜利归属 | 中立新阵营（可无武将） | 城市母国；母国已灭→复国 |
| 镇压后果 | 忠诚临时+15/5回、民生↓、声誉↓、无难民流、人口消耗 | 同左 |

- **混合城（外籍 35%~65%）**：两边都不占绝对多数，**不触发起义/叛乱**（分而治之；是否加"社会撕裂"低效代价待确认）。
- **概率可 SL**：读档重掷（金手指）；但概率 100% 时不可逃。
- **多城同时**：按阵营顺序（玩家优先，其余 CN→JP→KR→AU）逐城结算。
- **预警**：每回合结束，各城首长上报本城（风险/库存/驻军比/军管倒计时）；不弹红窗。
- **外部干预**：颜色革命（压民生/舆论）、鼓吹暴动（叛乱概率↑）、游说武将（个人忠诚↓）——接口挂外交/间谍轮。

## 二、起义（本国主体）

> **R47 口径：忠诚度是流量积分慢变量，民生只改升降速度，不直接改写忠诚值。** 权威公式见 [00-总纲/数值公式总纲.md](../00-总纲/数值公式总纲.md) §3.4。

```
Δ忠诚 = 民生流 + 治安流 + 治理流 + 外籍流 + 占领流 + 文化流
      + 驻军流 + 武将流 + 镇压流 + 自然回流
忠诚' = clamp(忠诚 + clamp(Δ, −10, +5), 0, 100)

民生流（舒适带 [40,55]）：
  W<40: −0.15×(40−W)^1.1
  W>55: +0.15×(W−55)^0.8
  带内: 0

其他流：治安 S<40 −0.08×(40−S)/S>60 +0.04×(S−60)；治理 +0.05×(G−50)；
        外籍 −4f；占领 −2.5×(occPen/15)；文化错位 −2.0m；
        驻军 +1.0×min(g/0.05,1)；武将 +0.5；镇压 +3/回合共5回；
        自然回流 W∈[40,55] 且无负项时 +0.3×(60−忠诚)/60

起义概率/回 = clamp((30 − 忠诚)/30, 0, 1)
触发：忠诚 <30 连续 3 回合（普通城）
      <20 连续 10 回合（占领城且本国人口≥75%，极难）
```

- **一年低民生只掉几分**：W=15 一年，100→94.8，仍忠诚；10 年才到 38.3（警戒），20 年才到 0（起义）。
- **不再单独算"倒戈概率"**（院长 #5）：驻军只提供正流；**只要起义触发，驻军默认倒戈**。
- **起义结果**：整城带兵变阵为**中立新阵营**；叛军兵种/装备以该城原有军队为基础（驻军倒戈→继承；若驻军被撤走→只有民兵，弱）。
- **武将**：坐镇提供 +0.5/回正流；起义时**带城起义**（成为新阵营武将或流亡）。
- **玩家取舍**：驻军多→忠诚正流、起义概率低，但触发时丢的兵多；撤军→忠诚失去正流、概率升，但兵保住、城可能丢。
- **镇压**：+3/回合共 5 回（合计 +15）、民生−、国际声誉−、**无难民流**、人口消耗。

## 三、叛乱（外籍主体）

```
叛乱概率/回 = clamp((30−忠诚度)/30,0,1)          ← 只看忠诚度
            × clamp((f−0.50)/0.50,0,1)           ← 外籍>50% 才可能
            × (1 − (驻军/人口)/0.05)             ← 驻军/人口≥5% → 0（留 0.5% 容差）
```

- **攻防战**：叛军=进攻方（外籍人口按转化率抽调，战斗力弱、军备低）；驻军=防守方（享受城防）。
- **守军胜**：叛军全灭，**外籍人口等量扣除**；民生−5；忠诚度临时+15/5 回合；声誉−；无难民流。
- **叛军胜**：城市**归母国**；母国已灭→**视为复国**（走复国会议/流亡政府规则）。
- **叛军战力**：质量≈0.3~0.4×正规军、装备≈0.2~0.3×（系数待定）。
- **同化**：被占领城市按同化机制产生**本国人口**；外籍占比下降后，城市从"叛乱风险"逐步转为"稳定/起义风险"（本国人口≥75% 才可能起义）。

## 四、军队（驻军=服役统一）

- 全国只有**一支军队池**：`service = Σ 各城驻军`；驻军是军队的**驻城部分**，不再区分"服役"与"驻军"。
- 驻军对城市忠诚度 +`20×min(驻军/人口/0.05,1)`；同时吃粮、吃饷、吃装备。
- **武将坐镇**：额外忠诚加成（数值待定）；起义时随城走。
- 军队战力：`军力 = 军队 × 战力 × 军备效率 × 士气 × 补给 × 城防`；士气/补给受粮食与民生影响（耦合链，见 §七）。
- **粮食不作为进攻时间逻辑**（院长 #4）：只做出兵规模与围城时间的**成本**；不再有"粮尽 T 回合强制撤退"的硬计时。

## 五、围城断供（只在围城驻扎时）

1. 触发：敌军城外驻扎围城（R36）。
2. **粮池切换**：该城 Q/D 从全国池剔除；只吃本城 Q/K/D；全国池不供给。
3. **本城产出不打折**（院长 #2）：城里能看到库存/产出/消耗，玩家用简单算术算坚持天数，不做额外心智负担。
4. 本城需求 = 人口 + 驻军×1.5。
5. 库存：本城粮仓；上限见 §六；每回合扣 `Q_local − D_local`。
6. `F_local` 替代全国 F 进民生。
7. 驻军士气：`F_local<30 → 战力×0.8`；`F_local=0 连续 3 回合 → 投降或突围`（玩家/AI 二选一）。
8. 人口：`F_local<20 → 人口流失/逃难`；逃难并入**外籍人口**（不另设难民账）。
9. 解围：友军抵达→围城解除、全国池恢复、围城军被攻击。
10. 城破：攻方获得剩余库存/人口；守军按 R36 撤离规则。
11. UI：围城图标 + 本城 F + 库存天数 + 驻军士气 + 投降倒计时；首长汇报。
12. **粮食运输**：平时全国池=运输网络抽象（默认即时、无损耗）；被围/封锁断供；是否加物流时间/损耗待确认。

## 六、粮仓上限

- 基础 `5×D`（5 年）+ 粮仓建筑每级 +1×D。
- **院长提到"5×8=40年"**——需确认口径：是 **40×D（40 年）** 还是 **8×D（8 年）**。白机建议 8 年上限：40 年会重新出现"种够躺平"。

## 七、耦合链（为什么不能单变量测）

```
围城 → 全国池剔除 → F_local ↓
  → 民生 ↓ → 治安 ↓ → 宜居 ↓（缓动）
  → 人口增速 ↓ / F<20 人口流失
  → 驻军/人口比 ↑（人口降）→ 忠诚↑（正影响）但与民生↓相互抵消
  → 士气 ↓（F<30）→ 军力 ↓ → 守城更弱 → 城破概率 ↑
  → 城破 → 全国池失去该城 Q、获得其人口/库存 → 其他城市 F 变化
```

- 起义/叛乱不是单点判定：民生→忠诚→驻军比→起义概率→城变阵→全国粮池/人口/军队池→其他城市，全部同回合耦合。
- 粮食不是独立资源：粮→民生→治安→宜居→人口→兵源/粮需，闭环。
- 战争不是独立旗标：动员→军队占人口→劳动力/粮需→民生→战争支持度→士气/战力→战果→伤亡→人口。

## 十一、耦合沙盘结果（R44f/R46，已跑）

> 三城网络（A 沿海无农 / B 粮仓 / C 工业食品）+ 全国粮池；Monte Carlo 1000 次跑概率事件。脚本 `tmp/pop_coupled_v13.js`（过程产物，不入库）。

### 11.1 日常产出耦合审计（院长 #2）

```
Pc = P − A（军队也算人口，但不产出）
产出 = base × (1+G/150) × (1+0.5×min(Pc/60000,1))
      × (0.8+0.4L/100) × (0.85+0.3S/100) × (0.8+0.4W/100)
产出 → Ea（人均财富）→ W → 产出（闭环，增益≈0.01，稳定）
A↑ → Pc↓、D↑、兵役负担↑ → 产出↓、W↓
F↓ → W↓ → 产出↓（饥荒膝）
```

- **审计修正**：①军队从总人口中扣除（Pc）再算人口红利——否则"驻军不生产"被吃掉；②驻军只加忠诚、**不再加治安**——否则军国主义会同时抬治安/民生，和"穷兵黩武有代价"矛盾；③产出加入 S/W 乘区——低民生即使忠诚被驻军撑住，产出照样掉（院长 #10）。
- 实测：驻军 0%→5%→10%，忠诚 43.6→50.8→41.7，产出 146→140→130——忠诚可被驻军抬高，产出仍随军队占用/民生下降。

### 11.2 围城链（A 无农；攻方粮 T 回合；守方库存 S×D）

| 攻方粮 | 守方库存 | A 城结果 | B/C 粮安 |
|---|---|---|---|
| 3 回合 | 0D | **t22 投降** | 100 |
| 3 回合 | 2D | 撑住，攻方 t23 撤军 | 100 |
| 3 回合 | 5D/8D | 撑住，攻方撤军 | 100 |
| 5 回合 | 0D/2D | **投降** | 100 |
| 5 回合 | 5D/8D | 撑住，攻方撤军 | 100 |

- 结论：**5D 是有效战略储备**（扛 5 回合围城），2D 是临界；0D 一围就崩。攻方粮尽撤军规则生效（`驻扎+进攻 > 粮草回合`）。
- B/C 因 A 被围而从全国池剔除需求，F 反而升到 100——**围城对友城是"减负"**，符合全国调配逻辑。

### 11.3 起义/叛乱（R45 忠诚度口径，Monte Carlo 1000 次）

| 场景 | 驻军 | 城变概率 |
|---|---|---|
| 起义（本国 70%，民生≈25） | 0% | **87.0%** |
| 起义 | 1% | 53.2% |
| 起义 | 3% | 1.0% |
| 起义 | 5%/10% | **0%** |
| 叛乱（外籍 70%） | 0.5% | **91.3%** |
| 叛乱 | 2% | 29.8% |
| 叛乱 | 5%（初始） | 33.6%（人口增长稀释比例） |
| 叛乱 | 5%（每回合维持 5%） | **1.0%**（留 0.5% 容差可归零） |

- **忠诚度公式换血后**：驻军 3% 压住民 25 的起义（1% 漏出），5% 归零；叛乱 5% 维持比例基本归零，但**人口增长会稀释驻军比**，玩家必须持续增兵——这是耦合，不是 bug。
- 民生极低时驻军也压不住：低民生→忠诚低，驻军只加 12 分，救不了根本。
- 外籍 30% 的"本国 70%"城，忠诚天然被 −25×f 拉低 7.5 分——**外籍比例本身是忠诚风险**，不是只影响叛乱。

- 驻军 5% 比 0.5% 稳；但占领城不能只靠驻军，要同化+民生一起做。

### 11.6 民生波动/忠诚流量（R47）

> R47 把忠诚从"目标跟随"改成"流量积分"：民生只决定每回合升降多少，不直接改写忠诚值。参数 `kn=kp=0.15`、舒适带 `[40,55]`、单回限幅 `[−10,+5]`。

| 场景 | 忠诚轨迹 |
|---|---|
| 一年 W=15（起始100） | **100→94.8**，仍忠诚 |
| 3 年 W=15（起始90） | 90→75.6，不反 |
| 10 年 W=15（起始90） | 90→**38.3**（警戒，未到30） |
| 20 年 W=15（起始90） | 0（起义） |
| 10 年低后 W=80 | 恢复到 60 需 **22 回合**（余震期） |
| 正弦 W20~60（100年） | 逐步降到 0（长期低均值，慢死） |

- **一年低民生只掉 5 分左右**：不会因为一次饥荒就叛变；10 年才逼近 30，20 年才翻。
- **正流慢、负流快**：信任建得慢、塌得快；高民生 W=80 也只 +1.5/回合，恢复是长跑。
- **占领城**：前 10 回合忠诚 60 底线；之后按流量走，同化降低 f 才能把外籍负流降下来。
- **这就是"民生→忠诚"不单调的来源**：民生是速度，不是位置；短期波动被积分吸收，长期趋势决定死活。

### 11.7 结论

- 耦合链跑通：围城→粮→民生→人口/士气→军力→城破；军队→平民减少→产出→民生；战争→动员→粮/劳动力→支持度。
- 无振荡、无单变量假象；5D 储备、3% 起义压制、5% 叛乱硬零、民族主义 rally 均成立。
- **R45 忠诚度换血后**：起义/叛乱只看忠诚；民生间接；外籍比例本身是忠诚风险；占领城靠同化+民生正常化。
- 唯一待调：5% 硬零的 0.5% 容差、占领城 75% 起义阈值是否合适。
