# 起义与叛乱（R44e 草案）

> 状态：🏗️ **R44e 草案**——院长 18 条口径已录；**待 10 个口径确认 + 耦合沙盘验证后定稿**。
> 上游：[人口体系架构.md](../03-内政/人口体系架构.md)、[人口算法-v1.md](../03-内政/人口算法-v1.md)、[06-事件/起义.md](./起义.md)、[04-军事/L3战斗场景.md](../04-军事/L3战斗场景.md)。
> 本文件替代原"起义"单线机制：起义（本国主体）与叛乱（外籍主体）分离，镇压与驻军/军队合并计算。

## 一、判定总表

| | 起义 | 叛乱 |
|---|---|---|
| 人口条件 | **本国人口 ≥60%** | **外籍人口 ≥65%**（远高于本国） |
| 主体 | 本国人口 | 外籍人口 |
| 触发 | 民生<30 连续 3 回合 + 非军管 | 民生<30 连续 3 回合 + 非军管 |
| 默认结果 | **驻军默认倒戈**，整城带兵变阵（中立新阵营） | 攻防战：叛军（外籍、弱军备）攻，驻军守 |
| 叛军来源 | 本国人口 + 倒戈驻军 | 外籍人口 |
| 消灭叛军 | 等量消耗本国人口 | 等量消耗外籍人口 |
| 硬零 | 无（驻军正影响内嵌，见 §三） | **驻军/人口 ≥5% → 概率=0** |
| 胜利归属 | 中立新阵营（可无武将） | 城市母国；母国已灭→复国 |
| 镇压后果 | 忠诚↑、民生↓、声誉↓、无难民流、人口间接流失 | 同左 |

- **混合城（外籍 35%~65%）**：两边都不占绝对多数，**不触发起义/叛乱**（分而治之；是否加"社会撕裂"低效代价待确认）。
- **概率可 SL**：读档重掷（金手指）；但概率 100% 时不可逃。
- **多城同时**：按阵营顺序（玩家优先，其余 CN→JP→KR→AU）逐城结算。
- **预警**：每回合结束，各城首长上报本城（风险/库存/驻军比/军管倒计时）；不弹红窗。
- **外部干预**：颜色革命（压民生/舆论）、鼓吹暴动（叛乱概率↑）、游说武将（个人忠诚↓）——接口挂外交/间谍轮。

## 二、起义（本国主体）

```
忠诚度_核心 = W + 0.20×(S−50) − 15×占领 − 10×文化错位
忠诚度_显示 = 核心 + 20×min((驻军/人口)/0.05, 1) + 武将坐镇加成
起义概率/回 = clamp((30 − 忠诚度_显示)/30, 0, 1)
```

- **不再单独算"倒戈概率"**（院长 #5）：驻军的正影响已内嵌在忠诚度里；**只要起义触发，驻军默认倒戈**。
- **起义结果**：整城带兵变阵为**中立新阵营**；叛军兵种/装备以该城原有军队为基础（驻军倒戈→继承；若驻军被撤走→只有民兵，弱）。
- **武将**：坐镇提升忠诚度（正影响）；起义时**带城起义**（成为新阵营武将或流亡）。
- **玩家取舍**：驻军多→忠诚高、起义概率低，但触发时丢的兵多；撤军→起义概率高，但兵保住、城可能丢。
- **镇压**（若起义被平息）：忠诚度**反而提升**（恐惧/管控）、民生−、国际声誉−、**无难民流**、人口因民生下降间接流失。

## 三、叛乱（外籍主体）

```
叛乱概率/回 = clamp((30−W)/30,0,1)
            × clamp((f−0.65)/0.35,0,1)          ← 外籍占比越高越危险
            × (1 − (驻军/人口)/0.05)            ← 驻军/人口≥5% → 0
```

- **攻防战**：叛军=进攻方（外籍人口按转化率抽调，战斗力弱、军备低）；驻军=防守方（享受城防）。
- **守军胜**：叛军全灭，**外籍人口等量扣除**；民生−5；忠诚度↑（镇压）；声誉−；无难民流。
- **叛军胜**：城市**归母国**；母国已灭→**视为复国**（走复国会议/流亡政府规则）。
- **叛军战力**：质量≈0.3~0.4×正规军、装备≈0.2~0.3×（系数待定）。
- **同化**：被占领城市按同化机制产生**本国人口**；外籍占比下降后，城市从"叛乱风险"逐步转为"起义风险/稳定"。

## 四、军队（驻军=服役统一）

- 全国只有**一支军队池**：`service = Σ 各城驻军`；驻军是军队的**驻城部分**，不再区分"服役"与"驻军"。
- 驻军对城市忠诚度 +`20×min(驻军/人口/0.05,1)`；同时吃粮、吃饷、吃装备。
- **武将坐镇**：额外忠诚加成（数值待定）；起义时随城走。
- 军队战力：`军力 = 军队 × 战力 × 军备效率 × 士气 × 补给 × 城防`；士气/补给受粮食与民生影响（耦合链，见 §七）。
- **粮食不作为进攻时间逻辑**（院长 #4）：只做出兵规模与围城时间的**成本**；不再有"粮尽 T 回合强制撤退"的硬计时。

## 五、围城断供（只在围城驻扎时）

1. 触发：敌军城外驻扎围城（R36）。
2. **粮池切换**：该城 Q/D 从全国池剔除；只吃本城 Q/K/D；全国池不供给。
3. **本城产出不打折**（院长 #2）：城里能看到库存/产出/消耗，玩家用简单算术算坚持天数，不做额外心智负担。
4. 本城需求 = 人口 + 驻军×1.5。
5. 库存：本城粮仓；上限见 §六；每回合扣 `Q_local − D_local`。
6. `F_local` 替代全国 F 进民生。
7. 驻军士气：`F_local<30 → 战力×0.8`；`F_local=0 连续 3 回合 → 投降或突围`（玩家/AI 二选一）。
8. 人口：`F_local<20 → 人口流失/逃难`；逃难并入**外籍人口**（不另设难民账）。
9. 解围：友军抵达→围城解除、全国池恢复、围城军被攻击。
10. 城破：攻方获得剩余库存/人口；守军按 R36 撤离规则。
11. UI：围城图标 + 本城 F + 库存天数 + 驻军士气 + 投降倒计时；首长汇报。
12. **粮食运输**：平时全国池=运输网络抽象（默认即时、无损耗）；被围/封锁断供；是否加物流时间/损耗待确认。

## 六、粮仓上限

- 基础 `5×D`（5 年）+ 粮仓建筑每级 +1×D。
- **院长提到"5×8=40年"**——需确认口径：是 **40×D（40 年）** 还是 **8×D（8 年）**。白机建议 8 年上限：40 年会重新出现"种够躺平"。

## 七、耦合链（为什么不能单变量测）

```
围城 → 全国池剔除 → F_local ↓
  → 民生 ↓ → 治安 ↓ → 宜居 ↓（缓动）
  → 人口增速 ↓ / F<20 人口流失
  → 驻军/人口比 ↑（人口降）→ 忠诚↑（正影响）但与民生↓相互抵消
  → 士气 ↓（F<30）→ 军力 ↓ → 守城更弱 → 城破概率 ↑
  → 城破 → 全国池失去该城 Q、获得其人口/库存 → 其他城市 F 变化
```

- 起义/叛乱不是单点判定：民生→忠诚→驻军比→起义概率→城变阵→全国粮池/人口/军队池→其他城市，全部同回合耦合。
- 粮食不是独立资源：粮→民生→治安→宜居→人口→兵源/粮需，闭环。
- 战争不是独立旗标：动员→军队占人口→劳动力/粮需→民生→战争支持度→士气/战力→战果→伤亡→人口。

## 八、统一与剧情

- **统一胜利**：场上必须不存在中立/其他阵营势力；起义中立城、叛乱复国城都算障碍。
- **自立不连锁**（院长 #9）：单个武将自立不影响其他城/将。
- **王乐添自立**（院长 #7）：第 2 回合历史事件（剧情杀），非通用自立算法；是否可阻止待确认。

## 十、耦合沙盘策略（待确认后跑）

- **模型**：三城网络（A 沿海被围无农 / B 内陆粮仓 / C 工业食品）+ 全国粮池；1 回合=1 年；200/500 回合；**Monte Carlo 1000 次**跑概率事件，报均值/p10/p50/p90。
- **状态向量**：人口（本国/外籍）、承载、宜居、治安、民生、粮食（Q/K/F）、军队（驻军/装备/士气/军力）、忠诚、占领/军管/围城、国家池/文化/舆论/战争。
- **场景**：
  - A 围城链：库存 0/2D/5D/8D；围城 1/3/5/10 回合；看 F→W→L→P→士气→军力→城破的连锁。
  - B 粮仓上限：2D/5D/8D/40D；看长期 F/W 与"种够躺平"。
  - C 起义链：本国 70%；忠诚 10/20/28；驻军 0/1/3/5/10%；看起义率、城变阵、丢兵、全国粮池后果。
  - D 叛乱链：外籍 70%；驻军 0.5/2/5%；看叛乱率、攻防、母国归属/复国、外籍人口消耗。
  - E 占领链：外籍 80% 占领 → 10 回合军管 → 同化 → 叛乱/起义/稳定拐点。
  - F 战争链：动员 10%/20%；10/30 年；民族主义/多元主义；看军队→粮→民生→支持度→士气→战果。
  - G 外部干预：颜色革命/鼓吹暴动/游说武将；看概率位移。
  - H 统一线：中立/复国城存在时胜利判定被阻断。
- **验收**：围城 5D 撑 5 回合、0D 1~2 回合投降；驻军 5% 叛乱=0；起义触发即丢驻军；撤军 p 升但兵保住；占领 10 回合不触发；无振荡；三条粮路/两条军事路线都可行；参数 ±20% 结论不翻转。
