## 驻城武将汇报（R39 院长立 · 事件预警渠道；11-10 细化选人规则）

- 武将全体平级、无领袖称谓（玩家/AI 意志=大统领）；进入城市时**驻城武将偶尔汇报内容**（不设“首长”）——预警/情报类信息的主要出口：
  - **选人规则**：①一般事件——从驻城武将中**随机**选 1 人汇报；②**事件与某建筑相关**（医院/警察局/农田/兵营/红灯区等）——优先由**该建筑派驻武将**汇报；③**仍有随机性**：即使有对应建筑派驻武将，也不是必定由他汇报（避免机械感）；无派驻则回落到随机驻城武将；
  - **城中无武将**：无武将汇报，但信息仍进事件面板/城市面板（不静默）；
  - 例：西安驻城武将汇报“根据历史数据，异族大约 X 回合后入侵，请早做打算”；
  - 形式：城市面板/事件条弹入，不打断操作；
  - 挂钩：异族波次预告（提前 5 回合）、起义风险、天灾预报等——与事件面板明牌规则一致（不做暗判）。
