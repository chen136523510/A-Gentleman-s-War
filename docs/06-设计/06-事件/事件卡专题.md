# 事件卡专题（B9 · v1.0）

> 状态：✅ **v1.0（2026-11-23 院长三级体系裁定）**——**普通/特殊/历史三级**（颜色/触发/数值干预三分）+ 卡面规则（描述内容+小字数值）+ 交互类型（通知/选择/隐藏；**连锁不做**）+ 内容维度 7 类 + 特殊卡独立限流 + 政策 AI 维度加权。**数值白机先定，后续靠模拟盘逆推调整（院长 11-23）**。 · 同步日期：**2026-11-24**（语义核对：过时口径词表零命中，机械指针段已清理）
> 输入：[事件卡总表](./事件卡总表.md) · [民生与消费事件](./民生与消费事件.md) · [起义](./起义.md) · [天灾与异族](./天灾与异族.md) · [代码规范](../../04-技术笔记/代码规范.md) EventDefinition · [AI 决策专题开题](../00-总纲/AI决策专题开题.md) §五
> 原则：**卡名专有名词**；低频+条件；出现即公开（明牌）；**卡面只显示变化项**；效果必须能在主公式找到落点（BUG-G014）；**三级颜色边框**；**连锁型不做**。
> **数据驱动纪律（院长 11-23）**：**事件卡不做硬编码**——卡名/描述/触发/效果/颜色/交互/文案全部在 `events.json` 卡数据，数值参数在 `balance.json eventCard` 组；代码只做**通用解释器**（按 `grade/interaction/effects` 字段分派，**禁止写卡名分支、禁止把本文数值写死在代码里**）。本文数值=设计参考，落库即入数据，改卡只改数据不改代码。

## 一、定位与三级体系（v1.0 核心）

### 1.1 三级定义（分类轴 = 机制趋势有无 × 数值干预程度）

| 级别 | 边框色 | 定义 | 数值干预 | 例子 | 触发 |
|---|---|---|---|---|---|
| **普通事件卡** | **灰白色** | 机制自然发生、有趋势体现；卡**不改数值**，只做事件化呈现（数值由既有机制结算） | **0 改动** | 低忠诚城市自立、某国破产、海平面上升 | **达成即触发**（不掷骰） |
| **特殊事件卡** | **蓝紫色** | 基础数值有趋势，但玩家难从数据读出/达成慢 → 卡**提前显性化 + 直接作用部分数值来强调** | **部分改、部分不动** | 低欲望社会、口红效应、报复性消费 | **条件→概率→独立限流** |
| **历史事件卡** | **金黄色** | 自然不发生、无趋势；剧情/隐藏设计；强特效、**巨幅数值/地图变化** | **巨幅改数值/地图** | 群星"斗转星移"（改 L1 地图连通四岛）、剧情卡 | **达成/剧本节点即触发** |

- **剧情卡归历史级**（金黄）：剧情相关的卡一般是历史卡；触发走 `EventScript`（剧本固定脚本），不进特殊卡的概率池。
- 普通卡是"机制的呈现层"：自立/破产/海平面由各系统自己算，卡只负责让玩家知道发生了什么。
- 特殊卡是"趋势的显性化器"：趋势已在跑，卡把抽象状态翻译成卡面数字，让玩家可感知、可对冲。
- 历史卡是"外部剧本力"：无趋势、无自然概率，纯剧情/隐藏/地图级设计。

### 1.2 分级判据量化（回答"三等级够不够"）

| 级别 | 判据（全满足） |
|---|---|
| 普通 | 事件卡自身对数值 **0 改动**；效果由既有机制结算；卡只输出展示/汇报 |
| 特殊 | 影响范围 ≤ 单城/单阵营；幅度 ≤ ~30%；持续 ≤ 20 回合；**不改地图** |
| 历史 | 跨阵营/全球影响，或幅度 >30%，或地图/规则变更，或剧本固定脚本 |

> **结论：三级够用**——"0 改动 / 部分改动 / 巨幅改动"是完备的分类轴，且与颜色/触发/交互规则一一对应。未来若出现"局势"（持续状态+进度条+玩家应对），作为**特殊卡的时间形态**（持续型），不新增级别；版本级大事件归历史卡。分级判据进代码注释，越界改级=改数据 `grade`。

### 1.3 事件卡的作用（沿用 v0.2，仍成立）

1. **状态可读化**：把机制内部状态量翻译成玩家看得见的局部经济变化——事件名即诊断信号。
2. **短期策略窗口**：改变局部最优，诱导 5~20 回合的经营调整。
3. **给对冲工具创造需求**：政策卡/科技/建筑需要"值得对冲的场景"。
4. **机制自动调节**：低民生缓冲/战后恢复/富足陷阱。
5. **叙事沉浸**（次要）：专有名词带来联想，但不存在理由。

### 1.4 三张特殊卡的存在检验

| 卡 | 服务的机制目的 | 去掉它少什么 |
|---|---|---|
| 口红效应 | 低民生/战争期的**缓冲阀** | 战争期商业只有线性下滑，无结构变化 |
| 报复性消费 | 战后恢复的**正反馈** | 战后无加速回暖窗口 |
| 低欲望社会 | 高福利后期的**富足陷阱** | 后期福利/消费无制衡 |

### 1.5 一期范围

- ✅ 3 张特殊卡（蓝紫）落库：数据+引擎判定/限流/持续/恢复；**普通/历史卡一期只留 schema 与颜色规则，不实装**（普通卡依赖机制事件呈现层，历史卡等群星/剧情）。
- ✅ 事件卡与商业回收/消费池/民生落点打通；❌ 不回溯补卡；❌ 天灾/异族不进卡池（二期接口，§十一）。

### 1.6 与政策卡的边界

| 维度 | 事件卡 | 政策卡 |
|---|---|---|
| 来源 | 外部冲击（机制趋势/历史/社会现象） | 玩家/AI 主动国策 |
| 时长 | 5/10/20 回合，到期恢复 | 装卡期间持续 |
| 操作 | 不可装/卸（选择型卡可按卡面选项响应） | 五槽 2/2/2/2/2 |
| 叠乘 | 事件乘区与政策乘区同乘区相乘 | 同左 |

## 二、内容维度（7 类，院长 11-23）

| 维度 | 覆盖 | 与相邻维度边界 |
|---|---|---|
| **社会** | 民生/人口/忠诚/就业/犯罪/城市自立 | **社会 ≠ 经济**：民生发展不等于经济发展 |
| **经济** | 财收/消费/产业/破产/贸易 | 经济发展走财/产业，不并入民生 |
| **政治** | 选举/政体/复国/UN/外交表决 | 内政制度与权力事件 |
| **环境** | 污染/气候/海平面/天灾/**自然环境全部** | 囊括自然环境 |
| **科技** | 突破/事故/技术封锁/时代节点 | — |
| **军事** | 战争/兵变/劫掠/劫狱/征兵 | — |
| **外交** | 条约/制裁/援助/大使事件 | 两国/多国互动 |

- 维度用于：①AI 加权映射（§十）②事件面板筛选 ③模拟盘统计口径 ④卡面描述归属。
- **与三级正交**：任何维度都可能有普通/特殊/历史卡（如环境：普通=海平面上升、特殊=极端气候、历史=斗转星移改图）。

### 2.1 数据落点

`type` 枚举新增 `special`：`historical|general|special|achievement|tutorial`；事件卡 = `card` 子对象（存在即卡）。旧档/旧事件零迁移。

```jsonc
{
  "id": "lipstick_effect",
  "type": "special",              // 新增枚举值
  "dimension": "economic",       // 7 类维度（社会/经济/政治/环境/科技/军事/外交）
  "card": {
    "grade": "special",          // normal|special|historical（=边框颜色：灰白/蓝紫/金黄）
    "interaction": "notice",     // notice|choice|hidden（连锁不做）
    "duration": 5,               // 持续回合（时间形态小字）
    "triggerChance": 0.20,       // 条件满足后每回掷骰
    "cooldown": 40,              // 同卡独立限流（院长 11-23：每张卡独立）
    "minInterval": 10,           // 任意特殊卡之间的最小间隔（保留）
    "globalMax": 1               // 全局同时最多 1 张
  },
  "trigger": { "any": [ { "welfareBelow": 35 }, { "warTurns": 5 } ] },
  "effects": { "ongoing": [ { "streetRecoveryMult": 1.20 }, { "mallRecoveryMult": 0.90 } ] },
  "display": {
    "title": "口红效应",
    "description": "商场的口红被一扫而空",   // 描述内容（不是数值讲解）
    "scopeText": "全城商业",                // 作用域（从描述内容可读）
    "lines": ["street", "mall"]             // 小字数值区（只显示变化项）
  },
  "report": "本城居民转向小确幸消费"
}
```

## 三、卡面规则（v1.0 · 院长 1/2/3/4/5）

### 3.1 级别颜色（边框）

| 级别 | 边框 | 说明 |
|---|---|---|
| 普通 | **灰白色** | 机制呈现类 |
| 特殊 | **蓝紫色** | 趋势显性化类（一期 3 张） |
| 历史 | **金黄色** | 剧情/隐藏/巨变类 |

### 3.2 卡面内容结构

```
┌─────────────────────────────┐  ← 边框颜色=级别
│  【卡名】                    │
│  描述内容（一句/两句，叙事）   │  ← 玩家视角文本，不讲解数值
│  作用域在描述中体现           │
│  ─────────────────────────  │
│  小字：商业街 +7 财/回        │  ← 小几号、样式不同于描述
│       商场 −11 财/回          │
│       持续 5 回合             │  ← 时间形态小字
│  ┌──────────┐               │
│  │ 知道了    │               │  ← 交互按钮（通知型）
│  └──────────┘               │
└─────────────────────────────┘
```

- **描述内容 ≠ 数值讲解**：例口红效应写"商场的口红被一扫而空"；报复性写"解封后的商圈人山人海"；低欲望写"年轻人不再追逐新款手机"。
- **小字数值区**：小几号、样式不同（如次要色/细体），写实际变化（财/回、民生、持续时间），只列变化项。
- **作用域**从描述内容可读（"全城"/"沿海城市"/"全世界"），不单设标签。
- **时间形态**（一次性/持续 N 回合/局势）放小字区，如"持续 5 回合"。

### 3.3 交互类型（按卡面处理区分）

| 交互 | 卡面 | 适用 |
|---|---|---|
| **通知型** | 卡面下**一个按钮"知道了"** | 默认；一期 3 张特殊卡全通知型 |
| **选择型** | 卡面下**多个选项**，每项展示**动作+成本+收益** | 需玩家决策的事件（如难民接收：接收/拒收） |
| **隐藏型** | 每张卡**单独设计**（不做统一模板） | 历史隐藏卡/剧情彩蛋 |
| **连锁型** | ❌ **不做**（院长 11-23） | — |

### 3.4 只显示变化项（2026-11-19 院长令，继续有效）

- 卡面小字只列本次事件产生变化的行；无变化的财/民生/治安/税收/人口行不显示。
- 主数字=当前城实际 ±（财/回、民生、治安）；百分比只做副标题。打开时按触发城当前值结算，不写死。

## 四、触发系统

### 4.1 条件 DSL（全部 AND；`trigger.any[]` 内 OR）

| 字段 | 含义 | 示例 |
|---|---|---|
| `turn` / `turnRange` | 回合/回合区间 | `{"turnRange":[121,999]}` |
| `welfareBelow` / `welfareAbove` | 民生阈值 | `welfareBelow:35`（口红）、`welfareAbove:70`（低欲望） |
| `warTurns` | 战争 ≥N 回合 | `warTurns:5`（口红） |
| `postWarTurns` | 停战后 ≤N 回合 | `postWarTurns:3`（报复性） |
| `growthStall` | 人口/收入连续 N 回合 <X% | `{"turns":10,"rate":0.01}`（低欲望） |
| `loyaltyBelow` / `goldBelow` / `buildingCount` / `techCompleted` | 机制类条件 | 普通/特殊卡按需 |
| `flag` | 剧本旗标 | 剧情卡/隐藏卡 |

### 4.2 三级触发规则（v1.0）

| 级别 | 规则 |
|---|---|
| 普通 | **达成即触发**：机制条件成立→事件出现（不掷骰、无冷却、不占特殊卡额度） |
| 特殊 | **条件→概率→独立限流**：条件满足才判定 → `triggerChance` 掷骰 → 本卡 `cooldown` 内不再判定；**每张卡独立限流**（院长 11-23：给玩家新鲜感） |
| 历史 | **达成/剧本节点即触发**：固定回合/旗标/隐藏条件成立→出现（不掷骰） |

- **特殊卡全局吞吐**（保留防刷屏）：每回合全局至多 **1 次**特殊卡判定——收集所有"条件满足且不在冷却"的卡/城→随机选 1→掷骰；命中即在该城出现。**每张卡另有自己的独立冷却**，两者并存。
- 两张特殊卡之间全局至少 10 回合（保留，后续细讲）。
- 条件必须**明确可读**（民生/战争/忠诚/人口/科技/建筑），禁止"每回合随机 1%"。

### 4.3 冷却与唯一性

```
全局同时最多 1 张特殊卡生效（globalMax=1）
同卡冷却：按卡独立配置（口红40/报复性50/低欲望60，可调）
任意两特殊卡之间 ≥10 回合（minInterval）
200 回合内同类卡 1~3 次（验收口径，非硬编码）
```

### 4.4 时点：过回合时出现，下回合开始结算（2026-11-19 院长令）

```
回合结束阶段：特殊卡判定+掷骰 → 命中则"出现"（事件条+汇报，数值不变）
下回合开始阶段：正式结算（instant 生效、ongoing 开始计时）
```

- 出现即公开（明牌）；存档 `pendingEvents[]` 保存"已出现未结算"。

### 4.5 随机性与存档

- 种子存档：同 seed 同开局可复现；读档重掷（已知且接受）；`lastRollTurn` 入档。
- 普通/历史卡无掷骰，不涉及随机性。

## 五、效果与落点（主公式）

### 5.1 两类效果（特殊卡）

| 类型 | 何时结算 | 用途 | 到期 |
|---|---|---|---|
| `instant` | 生效回合一次性 | 民生冲击/一次性财/人口 | 不返还 |
| `ongoing` | 持续期内每回合 | 建筑回收乘区/池乘区/税收乘区/民生偏置 | 自动恢复 |

- **普通卡**：`effects` 为空——数值由机制自己结算，卡只呈现。
- **历史卡**：可巨幅 effects + 预留 `mapChange`（一期不做）。

### 5.2 效果字段 → 主公式落点（每个字段必须找到位置，BUG-G014）

| 字段 | 作用对象 | 主公式落点 | 封顶 |
|---|---|---|---|
| `streetRecoveryMult` | 商业街回收 | `商业街回收 = min(零售份额剩余,12)×在岗率` 结果再乘 | ±50% |
| `mallRecoveryMult` | 商场回收 | 同构（单座上限 60） | ±50% |
| `entRecoveryMult` | 娱乐类回收（文化区娱乐+红灯区） | 娱乐 25% 份额内回收结果再乘 | ±50% |
| `tourismRecoveryMult` | 文旅类回收 | 文旅份额内回收×热度后再乘 | ±50% |
| `consumptionPoolMult` | 消费池上限 | `有效需求=民用人口/1000×2.5×K_desire×事件乘区`（不改基础公式） | ±50% |
| `welfareBias` | 民生目标值 | L2 民生目标 +N（持续期） | ±5 |
| `welfareInstant` | 民生冲击 | L3 民生一次性 ±N | ±10 |
| `securityBias` | 治安目标值 | L2 治安目标 +N（持续期） | ±5 |
| `taxMult` | 人口税/建筑财 | `财富=(建筑财+税项)×税收乘区` 再乘 | ±30% |

- 禁止虚空产出；同名不叠加（取新触发覆盖旧）；同城同类总倍率封顶 ±50%（民生/治安偏置 ±5）。
- 与政策乘区同乘区相乘，封顶各自独立。

|---|---|:--:|:--:|:--:|:--:|:--:|---|---|

| **低欲望社会** | `low_desire` | 社会 | t>120，W>70，人口/收入连续 10 回合<1% | 8% | 60 | 20 | 消费池 ×0.90；娱乐 ×1.10 | 民生 +1 |

### 6.1 卡面文案（描述内容 + 小字数值，示例）

| 卡 | 描述内容（大字） | 小字数值区 | 时间小字 |
|---|---|---|---|
| 口红效应 | 「商场的口红被一扫而空，人们用很小的代价维持体面」 | 商业街 +7 财/回 · 商场 −11 财/回 | 持续 5 回合 |
| 报复性消费 | 「解封后的商圈人山人海，积压的欲望一夜之间释放」 | 商场 +29 财/回 · 娱乐 +15% · 商业街 −2 财/回 | 持续 5 回合 |
| 低欲望社会 | 「年轻人不再追逐新款手机，够用就好成了新的体面」 | 消费池 −15 · 娱乐 +10% · 民生 +1 | 持续 20 回合 |

- 数值=60k 城示例（3 街+2 商场，池 150）；实机按触发城当前值结算（§3.4）。
- 低欲望"民生 +1"按 `welfareInstant` 一次性（11-19 院长口径 §12.1 #3）。

### 6.2 三卡的一期验收口径

- 200 回合内三卡合计触发 1~3 次/类（低频）；独立冷却生效；全局同时最多 1 张。

## 七、频率与卡池

- 一期卡池 3 张（全特殊/蓝紫）；普通/历史卡只留 schema。
- 特殊卡：条件+概率双闸 + 独立冷却 + 全局吞吐 1/回合 + 双卡间隔 ≥10 回合。
- 普通卡：达成即触发（不做频率限制——机制发生就是发生了）。
- 历史卡：剧本/隐藏条件触发（一局 0~1 次）。
- 天灾/异族不是卡（二期）；起义/自立/外逃是机制事件（普通层呈现），不占特殊卡额度。

## 八、数据 schema 与存档

### 8.1 events.json（见 §2.1 示例）

- `grade` 必填（normal/special/historical）；`interaction` 必填（notice/choice/hidden）；`dimension` 7 类必填。
- 旧 `events.json` 事件零改动；缺 `card` 块=机制事件；未知字段读档保留。

### 8.2 存档

```jsonc
"pendingEvents": [ { "id": "lipstick_effect", "cityId": "beijing", "appearedTurn": 87 } ],
"eventCards": [ { "id": "lipstick_effect", "cityId": "beijing", "settledTurn": 88, "endsTurn": 93 } ],
"eventCardCooldown": { "lipstick_effect": 48 },
"eventCardLastTurn": { "lipstick_effect": 48 },
"eventLastCardTurn": 88
```

- 出现/结算分离：`pendingEvents`→下回合初结算；`eventCards`=生效中；`eventCardCooldown`=逐卡独立冷却。
- 旧档无字段→无卡/冷却清零；读档恢复 pending 与生效中卡。

## 九、UI/面板

- **统一事件面板**：机制事件/事件卡/剧本事件同一事件流；卡出现=事件条+驻城武将汇报，不弹红窗。
- **卡面**：边框颜色=级别（灰白/蓝紫/金黄）；描述内容大字；小字数值区（小几号/样式不同，只列变化项）；时间形态小字；交互按钮（通知型="知道了"，选择型=多选项带成本/收益）。
- 生效期：城市面板显示卡图标/剩余回合；到期提示并自动恢复。

## 十、AI 接口（维度加权，数值先定后靠模拟调优）

- 事件出现 → 记 `recentEvents[]`：`{ id, dimension, severity, cityId, t, expire }`（只读）。
- **维度 → AI 关注映射**（政策 AI pressure 加权；建造/科技可选后续接）：

| 事件维度 | 政策卡加权维度 | 建造需求 | 科技线（可选） |
|---|---|---|---|
| 社会 | liv/consumption/民生类卡 | housing/medical | grn（民生科技） |
| 经济 | tax/pool/income 类卡 | wealth/consumption | ai（经济科技） |
| 政治 | dip/治安类卡 | security | — |
| 环境 | environment/greenPower 类卡 | environment/greenPower | grn |
| 科技 | science 类卡 | science | ai |
| 军事 | military 类卡 | military | mil |
| 外交 | dip 类卡 | — | — |

- **加权公式（先定）**：`eventBoost = severity × 0.15`（严重度 0.5~2.0 → +0.075~0.30），持续 20 回合线性衰减；同维度多事件叠加上限 +0.30。
- 例：AI 原本不关心环境，环境事件出现 → 环境类政策卡 pressure +0.15，AI 临时把环境卡纳入评估。
- **数值靠模拟盘逆推**（院长 11-23）：内容广了之后局部判断不可靠，用全量盘观察"事件后 AI 行为是否响应/是否过度"，再回调权重。
- 剧本事件分支（`EventScript.branches`）走 AI 开题 §五（按 U 选），不新增 IF 树。

## 十一、天灾/异族（二期接口，不实装）

- 不进卡池、不用 `card` 块；预留 `eventClass: hazard|barbarian` + `hazard` 子对象。
- 已有口径引用 [天灾与异族](./天灾与异族.md)：五类天灾/核泄漏双触发线/异族 50 回合波次/提前 5 回合明牌。
- 二期按"普通事件卡（灰白）"呈现：机制自然发生、卡不改数值（损失由天灾系统自己结算）。

## 十二、验收标准

1. **三级**：`grade` 三值在数据/卡面边框/触发规则三处一致；普通卡 effects 为空；历史卡不在特殊卡池。
2. **频率**：特殊卡 200 回合 1~3 次/类；独立冷却生效；全局同时最多 1 张；双卡间隔 ≥10 回合；普通卡达成即触发且不占特殊卡额度。
3. **随机性**：特殊卡条件不满足不掷骰；同 seed 可复现；pending 入档。
4. **落点**：卡面小字与实际 ± 一致（Δ=当前值×(倍率−1)）；只显示变化项；到期恢复。
5. **卡面**：颜色/描述/小字数值/时间小字/交互按钮齐全；描述不含数值讲解。
6. **AI**：事件后对应维度政策 pressure 提升（模拟盘观测）；权重可按盘回调。
7. **存档**：pending/生效中/逐卡冷却三态读档一致；旧档不崩。
8. **不回归**：机制事件阈值结算不变；v22 基线数字不动（事件卡不进 v22，模拟验证挂后续盘）。
