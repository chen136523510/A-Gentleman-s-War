## 一、规则（2026-11-25 院长令 + 既有口径）

1. **NPC 不遵 400 属性点原则**：单属性 1~99，**总属性不设区间**（符合世界观即可）；21 初始将固定 400 不适用于 NPC。
2. **结构同初始档案**：五维 / 倾向（隐藏，诗词简介）/ 被动（显式）/ 主动（L3 实时战技）/ 初始忠诚 / 前端文案两行。
3. **副本专属标记**：`scenarioTag`（复苏 / 逐鹿 / 群星 / 复仇者 / 内战），缺省 = 通用池（所有副本可分配）。
4. **档案池非冻结**：可后续扩充/调整；新增 NPC 若引入新倾向 → 同步 [倾向池](./武将倾向特性池.md)；新概念 → 同步术语表/百科。
5. **档案里的武将 = 游戏里本来就有的武将**；局内培养/招募生成的武将只在存档里，不进档案。

## 二、字段结构（对齐 `officers.json`）

| 字段 | 说明 |
|---|---|
| `id` / `name` | 稳定字符串 ID（英文）/ 中文名 |
| `scenarioTag` | 适用副本（缺省=通用池） |
| 统/武/智/政/魅 | 单属性 1~99，总属性不设区间 |
| `passive` / `active` | 被动（显式，名称+效果）/ 主动（L3 实时，冷却按秒） |
| `traitMain` / `traitSub` | 主/副倾向（隐藏，诗词简介暗示） |
| `intro` | 诗词 + 一句人设 |
| `loyalty` | 初始忠诚 |
| `frontPassive` / `frontActive` | 玩家可见文案（原描述措辞 + 程度副词，不列数值） |
