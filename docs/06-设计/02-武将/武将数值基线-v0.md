## 一、五维总则（平衡框架）

| 项 | 规则 |
|---|---|
| 范围 | 每维 **基础分配 1~100**；**外部因素（宝物/被动）可使有效值 >100**（院长 11-10 裁） |
| 总和 | **21 初始每人固定 400**（五维）；允许若干项堆到 100，其余相应降低；NPC 预算后续讨论 |
| 分布 | 允许两种：**专精型**（若干项 100 + 明显短板）或**均衡型**（五项 80）；避免 21 人全是同一模板 |
| 阵营均衡 | 每阵营至少 1 名 S 级（90~100）；CN 将多（11 人）靠人数覆盖，不靠单体总和 |
| 21 将成长 | **不再培养**；只能靠典藏**赠予物件**加属性（裁定 4） |
| 负伤 | 全属性 −30%，紫字；不叠加取最长 |

## 五、平衡校验清单（分配后逐条过）

- [ ] 每人五维总和 **= 400**（21 初始），基础单项 ≤100（外部加成可超）；
- [ ] 每维 S 级（90~100）全服 **2~3 人**，且每阵营至少 1 名 S；
- [ ] 允许专精（若干项 100 + 短板）或均衡（五项 80）；避免 21 人同一模板；
- [ ] 被动 1 个/人：同城同域取最高，不叠加；全服域覆盖大体均衡；
- [ ] 主动 1 个/人：采配总和阵营差 **≤4**；冷却与采配匹配（高采配长冷却）；
- [ ] 王乐添：五维正常，**初始忠诚特低**（另行安排）；
- [ ] 陈梓键：普通武将，无特殊数值待遇。
