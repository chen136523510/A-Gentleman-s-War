# 俘虏与处置

> 状态：✅ 结构已定（R8）；**2026-11-10 院长裁定**：不区分太守/幕僚；城破俘获对象改为**驻城武将逐个判定**；**不做 21×21 相性矩阵**（改个人倾向/性格）；宝物归属随俘获规则。
> 数值待一期成型后微调。

## 俘获

- 攻破城池时，**全部驻城武将逐个逃跑判定**：
  - 成功 → 撤往邻接友城或成为在野；
  - 失败 → 被俘；
  - **在外领兵的武将不参与城破俘获**（随军判定，见战斗总述）。
- 逃跑率 v0 提案：`50% + (统率−50)×0.5%`，钳 20~80%（待裁，见武将开题 Q2）。
- 一期数值结算下，俘虏按结算结果+概率产生。

## 四种处置（玩家选择，R8 拍板）

| 处置 | 效果方向 | 外交影响（每件都引起外交变化，数值待定） |
|---|---|---|
| **劝降** | 招入己方（受个人忠诚、原势力关系、倾向/性格影响；**不做相性矩阵**） | 与原势力关系恶化；成功能瓦解敌方人才 |
| **释放** | 放其归国或在野（见 [在野与招安](./在野与招安.md)） | 小幅善意/声望；与该将个人好感+ |
| **拷打机密** | 获取情报：邻城兵力/城防/科技等战争迷雾信息 | 该将忠诚/健康受损；被曝势力关系恶化；可能有假情报/失败风险 |
| **处决** | 该武将**永久退场**（21 初始将池减员、不补员；NPC 武将从 NPC 池移除） | 强烈外交震荡（其他势力忌惮/愤怒）；可能引发同阵营死战不降 |

## 宝物归属（11-10 裁定 9）

| 场景 | 宝物去向 |
|---|---|
| 武将**被俘** | **宝物随将**（由俘获方暂存） |
| 武将**释放/赎回** | 宝物**归还**该将 |
| 武将**处决** | 宝物→**胜方国库**，可陈列 |

## 设计重量

- 21 初始武将不补充，处决=永久减员，拷打可能致残/降属性——人才决策重量远高于三国志 12；
- 后续 NPC 武将可培养补充，但同规则（可被俘/处决/劝降），不是廉价耗材。
