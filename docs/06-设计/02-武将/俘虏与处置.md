# 俘虏与处置

> 状态：✅ 结构已定（R8）；**2026-11-10 院长裁定**：不区分太守/幕僚；城破俘获对象改为**驻城武将逐个判定**；**不做 21×21 相性矩阵**（改个人倾向/性格）；宝物归属随俘获规则。
> **2026-11-16/17 院长令（覆盖 R8 的四处置面板）**：城破/灭国处置面板改**三选一（收押 / 处决 / 释放）**；**劝降移到监狱内**（不再占处置面板）；**拷打机密并入监狱"对话（审讯）"**；**大统领不可劝降**（监狱内也不可）。监狱三级架构、名池、四项交互（对话/劝降/处决/释放）见 [监狱专题](../03-内政/监狱专题.md)。
> 数值待一期成型后微调。

## 俘获

- 攻破城池时，**全部驻城武将逐个逃跑判定**：
  - 成功 → 撤往邻接友城或成为在野；
  - 失败 → 被俘；
  - **在外领兵的武将不参与城破俘获**（随军判定，见战斗总述）。
- 逃跑率 v0 提案：`50% + (统率−50)×0.5%`，钳 20~80%（待裁，见武将开题 Q2）。
- 一期数值结算下，俘虏按结算结果+概率产生。

## 处置（2026-11-16 院长令：面板三选一 + 监狱四交互）

### 城破/灭国处置面板（三选一，玩家当场选）

| 处置 | 效果方向 | 外交影响（每件都引起外交变化，数值见监狱专题） |
|---|---|---|
| **收押** | 进本城监狱（无监狱/满员→押送己方有位的城）；此后在监狱内做对话/劝降/处决/释放 | 暂无；劝降成功后与原势力关系恶化 |
| **处决** | 该武将**永久退场**（21 初始将池减员、不补员；NPC 从 NPC 池移除）；宝物→国库 | 强烈外交震荡（其他势力忌惮/愤怒）：当事阵营 −15、其余 −5、rep −5 |
| **释放** | 放归原阵营（存活）/在野（亡国）（见 [在野与招安](./在野与招安.md)）；宝物随将归还 | 小幅善意（原阵营 +5）；释放大统领 +10；与该将个人好感+ |

### 监狱内四项交互（收押后，随时可做）

| 交互 | 效果方向 | 说明 |
|---|---|---|
| **对话（审讯）** | 获取情报（邻城兵力/城防/科技储备）+ 招降进度 +1；按武将智力判定 | **原"拷打机密"并入此项**（取消独立入口）；不耗财；每将每 N 回合 1 次（监狱等级 5/4/3）；大统领情报必得 |
| **劝降** | 招入己方（受个人忠诚、原势力关系、倾向/性格影响；**不做相性矩阵**） | **只在监狱内**；200 财/次、失败 3 回婉拒冷却；公式与相性乘区见 [监狱专题 §四.3](../03-内政/监狱专题.md)；**大统领不可劝降** |
| **处决** | 同上表"处决" | 监狱内可执行；Lv3 监狱城"司法程序"处决声望惩罚减半 |
| **释放** | 同上表"释放" | 监狱内可执行 |

- **劝降 ≠ 招安**：劝降=对有主俘虏（监狱）；招安=对在野无主武将（人才市场）——两套入口不合并，见 [在野与招安](./在野与招安.md) §三。
- **灭国必俘**（2026-11-16）：灭国时大统领+随城武将**必被俘**（不走逃跑判定），随后走三选一。

## 宝物归属（11-10 裁定 9）

| 场景 | 宝物去向 |
|---|---|
| 武将**被俘** | **宝物随将**（由俘获方暂存） |
| 武将**释放/赎回** | 宝物**归还**该将 |
| 武将**处决** | 宝物→**胜方国库**，可陈列 |

## 设计重量

- 21 初始武将不补充，处决=永久减员，审讯/劝降是长期人才战——人才决策重量远高于三国志 12；
- 后续 NPC 武将可培养补充，但同规则（可被俘/处决/劝降），不是廉价耗材。
