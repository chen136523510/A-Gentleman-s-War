## 一、双层结构（每人固定配置）

| 层 | 数量 | 生效 | 位置 |
|---|---|---|---|
| **被动** | 1 个 | **全局（L1/L2/L3）**，常驻 | 武将面板 + 城市面板小字 + 战报 |
| **主动（战技）** | 1 个 | **仅 L3 实时战斗内**释放（**不消耗采配**，D6 砍采配/战法），**冷却按真实时间（秒）** | L3 技能条；L1 自动结算不发动 |

> **被动定位（2026-11-11 院长令）**：被动是角色**显式表现**的一维，与**属性、相性（倾向）、战技**并列——战技取名场面（如诸葛亮火攻/借东风），被动取“这个人能直接看到的东西”（如诸葛亮发明创造：木牛流马/诸葛连弩）。每将被动必须**具象、可解释**，不再用通用数值池硬套。
> **L3 实时化**：L3 为即时战斗、**无回合**；主动冷却=秒级（轻技 30~45s / 主力 60~75s / 大招 90~120s），持续时间同样按秒；**采配/战法已砍（2026-11-22 D6 裁定：不需要指挥点和战法，武将技能就够）**——原"采配每 5 秒 +1、池=10+统率/20"作废。

- 纪律：**名字可玩梗，效果必须落统一模板**；五维预算内出强度，技能不补数值差。
- 每人 1 句人设台词（名册登记；L3 首次释放气泡——二期表现）。
- **同城同域被动取最高、不叠加**（防多将堆料）；被动是“人格”不是“装备”。

## 二、效果统一模板

```jsonc
// 被动
{ "名称", "域": "经济|军事|政治|文化|个人|间谍", "效果": [{ "层": "L1|L2|L3", "字段", "数值" }] }
// 主动（战技，L3 实时）
{ "名称", "类型": "伤害|增益|弱化|恢复|士气|控制|伏兵|传送",
  "目标": "自身|单体|圆形|指定点|全体", "范围": "半径 X 格（1 格=100m）",
  "冷却": "秒", "数值", "持续": "秒" }
```

| 类型 | 数值字段 | 挂点 |
|---|---|---|
| 伤害 | 附加损失率 % | 直接加进己方交换比 |
| 增益 | q +% / 受伤 −% / 移速 +% / 士气 +% | q 或态势乘区 |
| 弱化 | 敌 q −% / 士气 −% / 技能命中 −% | 敌 q 乘区 |
| 恢复 | 伤兵回补 % | 交换后结算 |
| **士气** | 敌/友士气 ±点 | 单位级 m（0~100） |
| **控制** | 晕眩秒数/概率、随机攻击秒数 | 目标 AI 状态机 |
| **伏兵** | 进入隐匿状态（雷达不可探测） | L3 状态机（见 L3 文档 §十五） |
| **传送** | 空投至范围内指定点 | 位置状态 |

> **采配（❌ 2026-11-22 D6 已砍）**：原 11-11 裁定"保留采配、每 5 秒 +1、池=10+统率/20"已作废——L3 不需要指挥点/战法资源，武将主动战技只受**冷却**约束（决策依据见 [L3战斗层开题 §4.6](../04-军事/L3战斗层开题.md)）。下表"采配"列仅作强度档位的历史对应。

## 三、强度分档（原采配分档；采配已砍）

| 原采配档 | 定位 | 效果量级（v0 强度带） | 冷却参考（实时） |
|---|---|---|---|
| 1~3 | 轻技/连发 | 单项 ±8%~15% | 30~45 秒 |
| 4~6 | 主力技 | 单项 ±16%~30%，或双效果中低值 | 60~75 秒 |

- **冷却为主动战技的独立属性**（院长裁定 7），**2026-11-11 改按真实时间（秒）**；被动无冷却。
- **L1 自动结算不发动主动**（院长裁定 16）：L1 战报只列五维（武力 q）+ 被动系数。

## 四、被动模板（六域）

> **2026-11-11 方向修正**：下表六域数值带保留为**效果强度参考**；被动名称/表现改为**每将具象化**（显式表现型，如「算力调度」「止损线」「藏品陈列」），不再直接套 P01~P14 通用池；同城同域仍取最高、不叠加。

| 域 | 示例钩子 | 数值带（v0） |
|---|---|---|
| 经济 | 财产出 +10% / 商业中心财 +15% | 产出乘区 +5%~+15%，单域 |
| 军事 | 练兵速度 +20% / 城防 +15% / 部队 q +5% | 速度/修复/战力乘区 |
| 政治 | 民生 +5 / 治理 +10 | 状态点 +5~10 |
| 文化 | 文化 +15% / 忠诚流 +0.5/回 | 产出/流量 |
| 个人 | 忠诚下限 60 / 被俘概率 −10% | 忠诚/俘虏挂点 |
| 间谍 | 反谍 +20% / 敌方技能命中 −10% | 情报/抗性挂点 |

- 被动**全局生效**：一个被动可同时有 L1/L2/L3 效果（如「文化推手」L2 文化 +15%、L3 文化入侵抗性 +15%）；无对应层的效果留空。

## 五、技能 × 科技联动（与科技树对齐）

- 科技树军事线节点**解锁/强化主动战技变体**：无人机线→「空袭/蜂群侦察」类；星链线→侦察/反谍被动强化；AI 天网线→弱化系 +效果；
- 联动原则：**科技开门、技能进人**——科技只解锁“可学/可换”，某人是否带该战技看名册配置。

## 八、玩家可见文案规范（2026-11-25 院长令：后端取值 ≠ 前端措辞）

> 规则（院长 11-25 修订）：**前端文案=沿用武将档案原描述的措辞，只把具体数值/秒数/格数换成程度副词**——不自由创作、不列具体数字；后台字段（`q`/`m`/乘区/格/秒）一律不上屏。**内容唯一源=[武将档案-v0](./武将档案-v0.md) 的"前端·被动 / 前端·主动"两行**。

| 要素 | 规则 | 示例（陈梓键） |
|---|---|---|
| 标题 | 技能名（可玩梗，本人过目后定稿） | 摸鱼 |
| 描述 | **改档案原描述**：术语换玩家词（q→战力）、数值换程度副词 | 原文"敌方士气 −15、友方 +15，持续 10 秒" → "一定范围内敌军士气下降、我军士气上升，持续短暂时间" |
| 程度副词表 | 略→小幅→明显→大幅→极大；时长：短暂/较长；范围：一定范围内/较远范围 | +5% 略微 / +8% 小幅 / +10~12% 明显 / +15~20% 大幅 / +25%+ 极大 |
| 被动展示 | 名称 + 档案原描述（程度副词版）+ 生效范围（全局 / L2 城市 / L3 战场） | 「串子」阵营军力弱于世界平均时所领部队战力明显提升…（全局） |
