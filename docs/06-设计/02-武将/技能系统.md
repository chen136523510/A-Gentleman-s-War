# 技能系统（特技 + 招牌战法）

> 状态：🏗️ v1 框架（R23 建议，样板技能全部**草案待本人过目**——真人玩梗红线）
> 依据：属性体系已定框架（四维/2~4 特技/1 招牌战法/名字玩梗效果统一）；数值字段挂接 [00-总纲/数值设计总纲.md](../00-总纲/数值设计总纲.md) §4.4
> 更新：2026-10-25 R23

## 一、双层结构（每人固定配置）

| 层 | 数量 | 生效 | 位置 |
|---|---|---|---|
| **特技**（被动） | 2~4 个 | 全局/内政/个人域，常驻 | 城市面板+战报小字 |
| **招牌战法**（主动） | 1 个 | 战斗内释放，消耗采配 | 一期=结算系数；二期=暂停中主动放 |

- 纪律不变：**名字可玩梗，效果必须落在统一模板**；四维预算内出强度，技能不补数值差。
- 每人 1 句人设台词（名册登记，战斗首次释放战法时气泡展示——二期表现，一期进战报文字）。

## 二、效果统一模板（四类，字段定义）

```
技能 = { 名称, 载体(特技/战法), 类型, 目标, 持续, 数值, 条件, 采配(战法必填) }
类型 ∈ 伤害 | 增益 | 弱化 | 恢复（可组合，组合型采配 +2）
目标 ∈ 己方单部队 / 己方全体 / 敌单部队 / 敌全体 / 城市域(内政类特技)
```

| 类型 | 数值字段 | 战斗乘区挂点（总纲 §4.4） |
|---|---|---|
| 伤害 | 附加损失率 % | 直接加进己方交换比 |
| 增益 | 己方质量 q +%/态势乘区 +% | q 或 A 乘区 |
| 弱化 | 敌方 q −%/装备档降档 | q 乘区 |
| 恢复 | 损失率回补 % / 士气（二期） | 交换后结算 |

## 三、采配分档与强度带（战法）

| 采配 | 定位 | 效果量级（v0 强度带） |
|---|---|---|
| 1~3 | 轻技/连发 | 单项 ±8%~15% |
| 4~6 | 主力技 | 单项 ±16%~30%，或双效果中低值 |
| 7~8 | 大招 | 单项 ±31%~45%，或双效果高值 |
| 9~10 | 战役级 | ±50%+ / 全体 / 附带机制（如装备档降档、强制撤退判定） |

- 一场战斗采配总池 = 10 + 统率/20（一期折算入系数，二期实体池）；
- **一期折算公式**（总纲 §4.4 技能系数）：双方战法净效果 = Σ(己方战法量级) − Σ(敌方)，钳 ±30%，进 q 乘区——自动战报逐条列出（可解释性底线）。

## 四、特技被动模板（四域）

| 域 | 示例钩子 | 数值带（v0） |
|---|---|---|
| 经济 | 「市长的钱包」金产出 +10% | 产出乘区 +5%~+15%，单域 |
| 军事 | 「练兵狂魔」军事基地练兵速度 +20% / 「城墙工程师」城防修复 ×1.5 | 速度/修复乘区 |
| 外交 | 「酒桌文化」外交行动效果 +1 档概率 | 判定修正 ±10 |
| 个人 | 「忠诚的老伙计」忠诚下限 50 / 「卧薪尝胆」被俘后劝降抵抗 +20 | 忠诚/俘虏系统挂点 |

- 特技不叠乘：同域多特技取最高（防堆料）；特技是"人格"不是"装备"。

## 五、技能 × 科技联动（与 N4 科技树对齐）

- 科技树军事线节点直接**解锁/强化**战法变体：无人机线→「蜂群侦察」类战法解锁；星链线→侦察/视野特技强化；AI 天网线→弱化系战法 +效果；
- 联动原则：**科技开门、技能进人**——科技树只解锁"可学"，某人是否带该战法看名册配置（配兵/配将策略层）。
