# 技能系统（被动 + 主动战技）

> 状态：🏗️ **v2（2026-11-10 院长 16 条裁定）**——每将 **1 被动（全局）+ 1 主动（仅 L3）**；取代 R23 的“2~4 特技 + 1 战法 + 一期折算”。
> 依据：[属性体系.md](./属性体系.md)（五维/预算）；[武将专题开题 §二](./武将专题开题.md)（五维分层作用面）；数值字段挂接 [00-总纲/数值设计总纲.md](../00-总纲/数值设计总纲.md) §4.4。
> 样板技能全部**草案待本人过目**（真人玩梗红线）。

## 一、双层结构（每人固定配置）

| 层 | 数量 | 生效 | 位置 |
|---|---|---|---|
| **被动** | 1 个 | **全局（L1/L2/L3）**，常驻 | 武将面板 + 城市面板小字 + 战报 |
| **主动（战技）** | 1 个 | **仅 L3 战斗内**释放，消耗采配，有冷却 | L3 技能条；L1 自动结算不发动 |

- 纪律：**名字可玩梗，效果必须落统一模板**；五维预算内出强度，技能不补数值差。
- 每人 1 句人设台词（名册登记；L3 首次释放气泡——二期表现）。
- **同城同域被动取最高、不叠加**（防多将堆料）；被动是“人格”不是“装备”。

## 二、效果统一模板

```jsonc
// 被动
{ "名称", "域": "经济|军事|政治|文化|个人|间谍", "效果": [{ "层": "L1|L2|L3", "字段", "数值" }] }
// 主动（战技）
{ "名称", "类型": "伤害|增益|弱化|恢复", "目标", "采配"(1~10), "冷却"(L3 回合), "数值", "持续" }
```

| 类型 | 数值字段 | 挂点 |
|---|---|---|
| 伤害 | 附加损失率 % | 直接加进己方交换比 |
| 增益 | q +% / 受伤 −% / 移速 +% / 士气 +% | q 或态势乘区 |
| 弱化 | 敌 q −% / 士气 −% / 技能命中 −% | 敌 q 乘区 |
| 恢复 | 损失率回补 % | 交换后结算 |

## 三、采配分档与强度带（主动战技）

| 采配 | 定位 | 效果量级（v0 强度带） | 冷却参考 |
|---|---|---|---|
| 1~3 | 轻技/连发 | 单项 ±8%~15% | 1~2 回合 |
| 4~6 | 主力技 | 单项 ±16%~30%，或双效果中低值 | 2~3 回合 |
| 7~8 | 大招 | 单项 ±31%~45%，或双效果高值 | 3~4 回合 |
| 9~10 | 战役级 | ±50%+ / 全体 / 附带机制 | 4~5 回合 |

- L3 采配总池 = `10 + 统率/20`（统率 60 → 13 点，可放 2~3 个主力技）。
- **冷却为主动战技的独立属性**（院长裁定 7），按 L3 战斗回合计；被动无冷却。
- **L1 自动结算不发动主动**（院长裁定 16）：L1 战报只列五维（武力 q）+ 被动系数。

## 四、被动模板（六域）

| 域 | 示例钩子 | 数值带（v0） |
|---|---|---|
| 经济 | 财产出 +10% / 商业中心财 +15% | 产出乘区 +5%~+15%，单域 |
| 军事 | 练兵速度 +20% / 城防 +15% / 部队 q +5% | 速度/修复/战力乘区 |
| 政治 | 民生 +5 / 治理 +10 | 状态点 +5~10 |
| 文化 | 文化 +15% / 忠诚流 +0.5/回 | 产出/流量 |
| 个人 | 忠诚下限 60 / 被俘概率 −10% | 忠诚/俘虏挂点 |
| 间谍 | 反谍 +20% / 敌方技能命中 −10% | 情报/抗性挂点 |

- 被动**全局生效**：一个被动可同时有 L1/L2/L3 效果（如「文化推手」L2 文化 +15%、L3 文化入侵抗性 +15%）；无对应层的效果留空。

## 五、技能 × 科技联动（与科技树对齐）

- 科技树军事线节点**解锁/强化主动战技变体**：无人机线→「空袭/蜂群侦察」类；星链线→侦察/反谍被动强化；AI 天网线→弱化系 +效果；
- 联动原则：**科技开门、技能进人**——科技只解锁“可学/可换”，某人是否带该战技看名册配置。
