# 属性体系

> 状态：✅ **v0.2（2026-11-10 院长 16 条裁定落档）**——五维 + 1 被动 + 1 主动；五维分层作用面见 [武将专题开题 §二](./武将专题开题.md)。 · 同步日期：**2026-11-26**（11-26 机械刷新：上游自立删减等裁定，本文无实质口径变化）
> 蓝本：三国志 12 四维+特技+战法 + 魅力（本项目第五维）。

## 框架

- **五维**：统率 / 武力 / 智力 / 政治 / **魅力**。
  - 范围 **1~100**，**单项上限 100**；**21 初始每人总和固定 400**（允许若干项堆到 100，其余相应降低；NPC 后续另定）；
  - **分层作用面（裁定 11）**：L1 战略层 / L2 城池层 / L3 战斗层各维分项乘区，详见开题 §二。
- **1 个被动**：**全局生效（L1/L2/L3）**，四域（经济/军事/政治/文化/个人/间谍），同城同域取最高不叠乘。
- **1 个主动（战技）**：**仅 L3 可用**；**不消耗采配**（2026-11-22 D6 裁定「砍采配/战法」），只受独立**冷却**约束。
- **1 句人设台词**。
- **21 初始武将不再培养**，只能通过典藏**赠予物件**提升属性；**NPC 武将 = 预设档案武将**（[NPC武将档案](./NPC武将档案.md)，不遵 400 点、可副本专属）；**局内培养武将** = 五系建筑培养生成（动态存档数据，**不入档案**）——两者与 21 初始将同等地位（可驻城/带队/被俘/处决，2026-11-25 院长令）。

## 设计纪律

- **名字玩梗、效果统一**：技能命名可任意玩梗，效果必须落在统一模板里：**伤害 / 增益 / 弱化 / 恢复** 四类（可组合）。
- 主动战技**无采配消耗**（D6 砍采配/战法，11-22）；冷却**按真实时间**（轻技 30~45s / 主力 60~75s / 大招 90~120s，见 [技能系统](./技能系统.md)）。
- **L1 自动结算不发动主动战技**（主动仅 L3 手动）；L1 战斗吃五维（武力 q）+ 被动。
- 21 将不补员，人物强度差异是趣味而非纯数值竞赛；NPC 武将可补充但同规则。
