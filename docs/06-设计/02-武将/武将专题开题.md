## 二、五维分层作用面（裁定 11 权威表）

### 2.1 作用面总表

| 维 | **L1 战略层**（大地图/外交/间谍） | **L2 城池层**（内政/建筑） | **L3 战斗层**（英雄单位） |
|---|---|---|---|
| 统率 | 无直接作用 | **城防 / 征兵** | **带兵速度**（临界值；低于=默认移速，不做负反馈） |
| 武力 | **间谍刺杀成功率** | **治安** | **所领部队战斗力** |
| 智力 | 无直接作用 | **科技** | **抵抗部分敌方武将技能** |
| 政治 | **外交友好** | **财 / 民生** | **抵抗所领部队受到的文化入侵 debuff** |
| 魅力 | **提案成功率**（联合国会议） | **忠诚 / 文化** | **降低被俘虏概率** |

### 2.2 v0 数值公式（提案，模拟校准）

> 纪律：只做**正向加成**（低于基准 50 不倒扣），符合“太守不在只减加成、不衰败”的负反馈纪律；常数入 balance.json。

| 层 | 效果 | v0 公式 | 100 时量级 |
|---|---|---|---|
| L1 | 外交友好 | 外交官政治：关系修正 `+(政治−50)/5` | +10 |
| L1 | 提案成功率 | `+(魅力−50)×0.5%` | +25% |
| L1 | 间谍刺杀 | 沿用间谍 §四：`25% + 0.8%×(武力差)`，钳 5~60% | — |
| L2 | 财 | `(1 + max(0,政治−50)/150)` | ×1.33 |
| L2 | 民生 | 治理 `G = 50 + max(0,政治−50)/2` | 75 |
| L2 | 城防 | `(1 + max(0,统率−50)/200)` | ×1.25 |
| L2 | 征兵 | 缓解 `(1.5−忠诚/100) × (1−统率/400)`，钳 0.3~1.2 | 双 100 时 ×0.375（越低越好） |
| L2 | 科技 | `(1 + max(0,智力−50)/150)` | ×1.33 |
| L2 | 忠诚 | 武将流 `+0.5 + max(0,魅力−50)/100`（/回） | +1.0 |
| L2 | 文化 | `(1 + max(0,魅力−50)/200)` | ×1.25 |
| L2 | 治安 | `+ max(0,武力−50)/10` | +5 |
| L3 | 文化入侵抗性 | `max(0,政治−50)/2 %` | 25% |
| L3 | 带兵速度 | 统率 ≥ **60**：`+ (统率−60)×0.5%`；<60 默认移速 | +20% |
| L3 | 技能抗性 | `max(0,智力−50)/2 %` | 25% |
| L3 | 被俘概率 | `×(1 − max(0,魅力−50)/200)` | −25% |
| L3 | 战斗力 | q `×(1 + 武力/200)`（**替换原统率/200 乘区**） | +50% |

### 2.3 驻城武将与建筑派驻（裁定 14）

- **无太守/幕僚/首长**：每城驻若干武将，全部平级；
- 每名驻城武将**可分配到一个建筑**（军事基地/商业中心/市政府/学院/研究院/文化建筑/警察局/农田…），提供该建筑主属性加成；
- 城市五维轴（财/民生/城防/征兵/科技/忠诚/文化/治安）由**对应建筑派驻武将**的相应属性提供；无派驻=基础值（不吃加成）；
- **一座城无武将驻守**：无任何建筑加成；守军无武将指挥→战力打折（无 L3 英雄单位/无主动战技/低士气）；
- 征兵修正取**部署在兵营（动员中心）的武将**（无部署=无缓解乘区），强征 −3 该将忠诚；
- 城市面板显示**驻城武将列表**（无“首长”），汇报由驻城武将发出。
