# 在野与招安（武将池）

> 状态：🏗️ **v0.1 开题（2026-11-10 院长令：外逃/释放/城破逃跑的武将需要有入口查看并招安）**。
> 一句话：**在野**=不属于任何阵营的武将池；玩家可在国家面板查看，花财+政治/魅力判定**招安**；AI 也可招安；倾向特性（隐藏）影响成功率与忠诚。
> 上游：[忠诚度.md](./忠诚度.md)（外逃）· [俘虏与处置.md](./俘虏与处置.md)（释放）· [武将专题开题](./武将专题开题.md)（倾向/在野字段）· [武将倾向特性池](./武将倾向特性池.md) · [外交行动](../05-外交/外交行动.md)（关系）。

## 一、在野来源

| 来源 | 说明 |
|---|---|
| **外逃** | 个人忠诚<40 的驻城武将每回合概率离城→在野（见 忠诚度） |
| **释放** | 俘虏四处置之“释放”→归国或在野（原势力已灭/不愿归→在野） |
| **城破逃跑** | 城破时驻城武将逃跑成功且无邻接友城→在野 |
| **亡国** | 阵营被灭、未随流亡政府的散将→在野（可选） |
| **初始** | 开局可预置少量在野武将（数据驱动，可选） |

## 二、入口与查看（院长 11-10 要求）

- **入口**：国家面板 → **人才** → **在野**（与“本国武将”并列 tab）；
- **列表展示**：姓名 / 原阵营 / 五维 / 被动 / 主动 / **个人简介（倾向藏在简介文字里，不显性标注）** / 状态（在野时长、是否被 AI 接触）；
- **不显示**：倾向的数值修正、招安成功率精确值（只给“高/中/低”或模糊反馈）；
- **排序/筛选**：按五维、原阵营、在野时长；
- **地图**：在野武将不占城，可显示在“人才市场”抽象层；不在地图实体化（待定）。

## 三、招安（行动）

| 项 | 规则（v0 提案） |
|---|---|
| 花费 | 财（按五维总和/被动强度定价）+ 可能的外交代价（原阵营关系 −） |
| 判定 | `政治/魅力 + 倾向匹配 + 原阵营关系 + 财礼` 综合；给“高/中/低”三档反馈 |
| 冷却 | 失败后该武将进入 5~10 回合“婉拒”冷却；可重复尝试 |
| 结果 | 成功→加入招安方，驻城/待分配；初始个人忠诚按倾向/原阵营/招安方式定 |
| 死忠/故国倾向 | 招安难度极高或直接拒绝（隐藏，玩家从简介/失败反馈推断） |
| AI | AI 也可招安在野武将（低权重；不与玩家抢同一人时按先到/判定） |

- **招安 vs 俘虏劝降**：招安=对在野（无主）武将；劝降=对俘虏（有主）——两套入口，不合并。
- **招安后宝物**：在野武将持有宝物随将；招安成功一并获得（待定）。

## 四、在野行为

- 在野武将**不产金、不吃俸禄、不占城**；
- **不会自动消失**（长期在野可被 AI 招走；可设“在野池上限/老化”待定）；
- 在野武将可被事件卡/外交/间谍接触（如“游说”“挖角”）；
- **倾向**影响：故国派难招、慕强派看阵营实力、金钱派看财礼、闲不住派看是否给建筑派驻。

## 五、UI/数据

- 数据：`officers.json` 增加 `status: "active|free|captured|exile"`；`free` 时 `faction=null`、`city=null`；
- 存档：`state.officers[id].status/freeSince/originFaction`；
- UI：国家面板→人才→在野 tab；招安弹窗（花费/成功率档/倾向简介）；事件汇报“某在野武将加入某阵营”。
