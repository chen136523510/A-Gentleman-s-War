# 在野与招安（武将池）

> 状态：✅ **v0.2（2026-11-25 院长令：在野武将实体化到城市 + 只能招募己方控制城的在野）**——v0.1（11-10）开题：外逃/释放/城破/亡国武将的入口与招安。 · 同步日期：**2026-11-26**（11-26 机械刷新：上游回合节点/自立删减/监狱内嵌/事件卡领域裁定，本文无实质口径变化）
> 一句话：**在野**=不属于任何阵营、但**有城市位置**的武将；**只有该城的控制者**能招安（北京招不到深圳的人→鼓励扩张）；AI 同规则；倾向特性（隐藏）影响成功率与忠诚。

## 一、在野来源

| 来源 | 说明 |
|---|---|
| **外逃** | 个人忠诚<40 的驻城武将每回合概率离城→在野（见 忠诚度） |
| **释放** | 俘虏四处置之“释放”→归国或在野（原势力已灭/不愿归→在野） |
| **城破逃跑** | 城破时驻城武将逃跑成功且无邻接友城→在野 |
| **亡国** | 阵营被灭、未随流亡政府的散将→在野（可选） |
| **初始** | **复苏：13 将全部在野，分布 16 城**（8 空城各至少 1 + 余 5 随机到 16 城；开局无在职武将除 8 大统领） |

## 二、入口与查看（2026-11-25 院长令：在野武将**实体化到城市**）

- **入口**：国家面板 → **人才** → **在野**（与"本国武将"并列 tab）+ **城市面板**（点击己方城，显示该城在野武将）；
- **位置**：在野武将**有城市位置**（`city` 字段）——不是抽象人才市场，而是"某城的地方人士"；
- **招募权限**：**只能招募己方控制城市里的在野武将**（"北京招不到深圳的在野武将"）——**鼓励扩张**：占更多城 = 更多可招募人才；
- **列表展示**：姓名 / 所在城 / 五维 / 被动 / 主动 / **个人简介（倾向藏在简介文字里，不显性标注）** / 状态（在野时长、是否被 AI 接触）；
- **不显示**：倾向的数值修正、招安成功率精确值（只给"高/中/低"或模糊反馈）；
- **排序/筛选**：按所在城、五维、在野时长；
- **地图**：在野武将在城下显示（如"城名 · 在野 2 人"），点开看列表。

## 三、招安（行动）

| 项 | 规则（v0 提案） |
|---|---|
| **前提** | **该城由己方控制**（2026-11-25 院长令：占城才能招该城在野武将；空城的在野武将必须先占领空城） |
| 花费 | 财（按五维总和/被动强度定价）+ 可能的外交代价（原阵营关系 −） |
| 判定 | `政治/魅力 + 倾向匹配 + 原阵营关系 + 财礼` 综合；给“高/中/低”三档反馈 |
| 冷却 | 失败后该武将进入 5~10 回合“婉拒”冷却；可重复尝试 |
| 结果 | 成功→加入招安方，驻城/待分配；初始个人忠诚按倾向/原阵营/招安方式定 |
| 死忠/故国倾向 | 招安难度极高或直接拒绝（隐藏，玩家从简介/失败反馈推断） |
| AI | AI 也可招安**其控制城**的在野武将（低权重） |

- **招安 vs 俘虏劝降**：招安=对在野（无主）武将；劝降=对俘虏（有主）——两套入口，不合并。
- **招安后宝物**：在野武将持有宝物随将；招安成功一并获得（待定）。

## 四、在野行为

- 在野武将**有城市位置**（`city`=所在城），但**不产金、不吃俸禄、不占建筑**；
- **不会自动消失**（长期在野可被该城控制者招走）；
- 在野武将被招募后从该城移除；城被敌方占领时，该城在野武将**留在城内**（归新控制者招募）；
- 在野武将可被事件卡/外交/间谍接触（如"游说""挖角"）；
- **倾向**影响：故国派难招、慕强派看阵营实力、金钱派看财礼、闲不住派看是否给建筑派驻。

## 五、UI/数据

- 数据：`officers.json` 增加 `status: "active|free|captured|exile"`；`free` 时 `faction=null`、**`city`=所在城**（不为空）；
- 存档：`state.officers[id].status/freeSince/originFaction/city`；
- UI：国家面板→人才→在野 tab + **城市面板在野列表**；招安弹窗（花费/成功率档/倾向简介）；事件汇报"某在野武将加入某阵营"。
