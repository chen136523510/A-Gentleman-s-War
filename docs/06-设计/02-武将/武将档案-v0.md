> 纪律：**名字可玩梗、效果必须落统一模板**；**相性只影响忠诚/外逃/招安等隐性数值，不直接加可见数值**；**L3 实时无回合，主动冷却/持续按秒**；**同城同域被动取最高、不叠加**。

## 一、分配规则（2026-11-11 院长新裁）

1. **四维分工**：属性（五维）/ **相性（倾向，隐藏）** / **被动（显式表现）** / **主动（L3 实时战技）**——四者不混。
2. **相性不直接加可见数值**：只影响忠诚变化率、外逃率、招安难度、自立倾向等隐性/间接数值；产出/战力/防御等可见数值一律不挂相性。
3. **被动=显式表现维度**：每将具象化、可解释（如「串子」「开庭」「潜水」），全局 L1/L2/L3；同城同域取最高、不叠加。
4. **主动=L3 实时战技**：无回合，冷却/持续按秒；必须带**生效范围**（自身/单体/圆形半径 X 格/指定点/全体）；采配消耗（是否随时间回复待裁）。
5. 主动采配 4~8、冷却 45~90 秒；每阵营人均采配差 ≤4（本轮 1.00）。
6. 初始忠诚：常规 70~90；**王乐添 45（特低，2t 事件不变）**。
7. 台词每人 1 句；简介=主相性诗词 + 一句人设（相性藏在文字里，不显性标注）。
