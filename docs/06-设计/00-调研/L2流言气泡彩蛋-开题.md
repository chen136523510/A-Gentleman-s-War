# L2 流言气泡（彩蛋级内容）· 开题

> 状态：📝 **开题（2026-11-13 院长第 12 条：L2 彩蛋级，非核心、可删）**
> 定位：**L2 城池内景的彩蛋内容**——玩家在战报之外，从建筑上的可点击气泡看到"流言蜚语"，用于提示间谍行动/游戏指示/纯趣味文字。**删去不影响玩家游玩**。
> 关联：[间谍专题 §7.5](../04-军事/间谍专题开题.md)（L2 建筑级任务）· [L2 地图规划](../04-技术笔记/L2地图规划与烘焙管线.md) · [L2 城内视觉需求](./L2城内视觉需求-2026-11-11.md)

## 一、设计目标（院长原话）

> "玩家视角下能从战报之外看到一些流言蜚语，比如证券交易所建筑上面有一个可以点击的气泡，点击后能看到'周围人们都神色紧张，彼此间传着一些关于市场崩溃的传闻'。有时是居民楼建筑的气泡，点击后看到'这公摊的也太多了吧'或者'怎么找工作这么难'。用来提醒玩家城市有间谍行动或者一些游戏上指示或者纯趣味性文字。趣味性文字控制频率。"

- **三类气泡**：①间谍提示（有间谍在活动）②游戏指示（就业/消费/电力等状态提示）③纯趣味（氛围文字）。
- **彩蛋级**：数据驱动、可整体删除、不参与结算、不影响胜负。

## 二、三类气泡设计

### 2.1 间谍提示型（功能性）

| 建筑 | 文案示例 | 触发条件 |
|---|---|---|
| 证券交易所 | "周围人们都神色紧张，彼此间传着一些关于市场崩溃的传闻" | 敌方"散布谣言"任务进行中/成功 |
| 军事基地 | "最近夜里总有军车进出，哨兵换岗比平时更频繁" | 敌方"窃取军情"任务进行中 |
| 学院/研究院 | "教授们说有几份研究报告不见了" | 敌方"窃取研究"任务进行中 |
| 任意驻将建筑 | "府邸的守卫最近换了生面孔" | 敌方"刺杀/游说"任务进行中 |

- 作用：给玩家**反谍线索**（对方间谍在活动），但不直接暴露间谍是谁/何时来——玩家可派己方间谍反谍或加强该城情报建筑。

### 2.2 游戏指示型（状态提示）

| 建筑 | 文案示例 | 触发条件 |
|---|---|---|
| 居民楼 | "怎么找工作这么难" | 城市在岗率 < 85% |
| 商业街/商场 | "生意冷清，老板们在门口抽烟" | 消费供给不足（零售 < 池 60%） |
| 工厂 | "又停电了，机器停了一半" | 电力满足率 < 90% |
| 医院 | "排队的人从大厅排到了街上" | 医疗覆盖不足 |
| 农田 | "今年雨水不好，收成悬" | 粮安 < 85 |

- 作用：把数值状态"翻译成人话"，降低玩家查面板的心智负担（符合"领导感"：不用自己调研，城市会说话）。

### 2.3 纯趣味型（氛围）

| 建筑 | 文案示例 |
|---|---|
| 居民楼 | "这公摊也太多了吧" / "楼上又在装修" / "电梯又坏了" |
| 公园 | "大爷们的棋局围了三圈人" / "广场舞音响又升级了" |
| 夜市/商业街 | "老板说这条街的铺租又涨了" |
| 学院 | "又有学生在通宵赶论文" |
| 港口 | "码头工人说这船货等了一星期" |

- **频率控制（院长明确）**：趣味型每城每 5 回合最多 1 条；同屏最多 3 个气泡；间谍提示 > 游戏指示 > 趣味（优先级）。
- 文案池按建筑类型分组，每条权重随机；同一条文案 20 回合内不重复。

## 三、交互与表现（院长 11-13 第 7/9 条）

- **气泡形状**：**箭头气泡指向某座城市**（建筑/城），气泡内是**省略号"……"**，点击后才输出文本（不提前剧透）。
- 气泡挂在建筑顶部（L2 内景），轻微浮动动画；**每城冒泡时间错开**（不同城市不同相位，避免同屏一起冒）。
- 点击弹出 1~2 行文字 + 关闭；未点击 10 秒自动淡出（不堆积）。
- 不打断操作（非模态）；不弹窗、不强制阅读。
- **纯文本**（院长第 9 条）：**流言不改变任何游戏数值/结算**——纯氛围/提示，删去不影响游玩。
- 玩家可在设置里关闭"流言气泡"（彩蛋级可选项）。

## 四、实现与数据（数据驱动）

```json
// rumors.json（L2 数据；可整体删除）
{
  "bubbles": [
    { "id": "rumor_market", "building": "stockExchange", "type": "spy",
      "texts": ["周围人们都神色紧张，彼此间传着一些关于市场崩溃的传闻"],
      "trigger": "enemySpyActive", "weight": 1 },
    { "id": "idle_job", "building": "residence", "type": "hint",
      "texts": ["怎么找工作这么难"], "trigger": "employmentRate<0.85", "weight": 1 },
    { "id": "fun_density", "building": "residence", "type": "fun",
      "texts": ["这公摊也太多了吧", "楼上又在装修"], "trigger": "always", "weight": 1,
      "cooldown": 5, "maxPerScreen": 3 }
  ]
}
```

- **可删性**：`rumors.json` 缺失/为空 → 游戏正常运行（无气泡）；代码只做"读表→挂气泡"，不含硬编码文案。
- 与间谍联动：间谍任务状态写入城市 `spyActivity`，气泡系统只读该状态。
