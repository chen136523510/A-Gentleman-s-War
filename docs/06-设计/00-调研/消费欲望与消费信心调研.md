# 消费欲望与消费情景调研（2026-11-12 院长令）

> 用途：为"**消费欲望**"参数（参与消费池上限）与"**消费情景标签**"提供现实依据；服务 [消费力专题](../03-内政/消费力专题.md)。
> 触发：院长指出"消费饱和（掏不出钱）与消费低迷（不肯花钱）是两种相反状态"，并要求欲望受就业/宜居/战争/供给侧/税收影响。
> 方法：检索消费者信心指数（CCI）、预防性储蓄、税收—消费、供给短缺—消费外流四组文献，提炼可游戏化的因子与阈值。

## 一、消费者信心（CCI）的实证结构

- **三因子结构**：消费者信心可分解为**宏观经济信心 / 微观收入信心 / 投资信心**（《数理统计与管理》2020，两岸四地结构方程）；收入与就业是分群差异的关键变量。
- **官方指数分解（上海财经大学 CCI）**：收入评价指数、**就业形势评价指数**、购买意愿指数。
- **收入预期显著、意愿不显著**（《经济研究导刊》2026，2021–2025 季度 OLS）：收入信心对消费修复显著正相关；而"倾向更多消费"的意愿份额统计不显著——**意愿不必然转化为支出**，被预防性储蓄、就业预期、大额支出约束截留。
- **失业率是 CCI 的短期首要决定因素**（欧洲数据）；CCI 对消费有因果影响但预测力随时期不对称。

**游戏映射**：就业（在岗率）与收入预期是欲望主因子；"想花≠花得出"正好对应游戏里"欲望高但供给不足→回收低"的情景分离。

## 二、预防性储蓄与不确定性（战争/危机）

- 理论链：Keynes（1936）不确定性 → **Leland（1968）** 收入不确定性抬高储蓄需求 → **Deaton（1991）/ Carroll（1997）** 缓冲存量（buffer-stock）行为。
- **Pozzi & Sadaba（2023，Bank of Canada）**：1870–2016 年 16 个工业经济体，战争/大流行/大萧条期间**消费平滑显著下降**——更多 rule-of-thumb 消费者 + 更强预防性储蓄动机；覆盖一战、二战、西班牙流感、大萧条。
- **Achleitner（2020）**：1870–2016 危机期储蓄率研究，战争/衰退/大流行分别建模，均推高预防性储蓄。
- 贸易战/冲突证据（Waugh 2019 NBER；Wu & Zhao 2022；Ma et al. 2025）：政策不确定性与冲突抑制可选消费。

**游戏映射**：交战/军管直接压低欲望（储蓄替代消费），且对"可选消费"（娱乐/文旅/高端红灯区）打击更大——可做战争期娱乐份额额外下滑（简化：统一 K_desire 下降）。

## 三、税收与可支配收入

- **减税 DID（王鑫 2011《世界经济》）**：2006 个税起征点提高，收入增量的**边际消费倾向 1.40~1.66**（消费增加大于减税额）；食品/交通通讯/教文娱增加显著。
- **2018 个税改革（尹志超等 2026《经济研究》）**：家庭消费平均 +592 元、**MPC ≈ 0.14**；中低收入家庭 MPC 更高。
- **宏观税负双效应（王悦红 2024）**：税收扩张可改善消费环境（挤入），但税负过高通过可支配收入与相对价格约束消费（挤出）——存在"合意宏观税负"。

**游戏映射**：税负高于基准 → 可支配收入下降 → 欲望下降（挤出）；减税/消费刺激政策 → 欲望上升（挤入）。MPC 的异质性简化为一个系数，不做家庭分层。

## 四、供给短缺与消费外流

- **短缺经济**：改革前中国长期供不应求，消费需求被"抑制需求"式管理压制——**供给不足直接压抑消费**。
- **消费外流**：国内高质量供给不足 → 购买力外流（年万亿级）；"不是需求不振，是需求变了、供给没跟上"（人民日报/发改委；余红心 2026《供需失衡、消费外流与中国产业结构升级》）。
- **供需结构错配**：低效供给过剩与高质量供给不足并存（"供强需弱"辨析）。

**游戏映射**：单类建筑供给不足 → 回收受限（已有 `min(份额剩余, 单座上限)`）；**基本需求危机**（缺粮/缺电/民生低）→ 安全感崩塌 → 欲望下降（预防性储蓄）。两者分工，不双算。

## 五、游戏化映射（结论）

### 5.1 消费欲望系数 K_desire（乘进消费池上限）

```
K_desire = clamp( 1.0
  + 0.30 × (在岗率 − 0.95)          // 就业：95% 基准（初始就业纪律）；满岗 +1.5%
  + 0.20 × (宜居 − 50)/50           // 宜居：±10%
  − 0.15 × 交战                     // 战争：预防性储蓄
  − 0.10 × 被占领军管
  − 0.20 × 税负压力                 // (实际税负−基准)/基准，clamp 0~1
  − 0.15 × 供给危机                 // 缺粮/缺电/民生<30 任一
, 0.5, 1.5 )
```

- 最好 ≈1.4（高就业+高宜居+低税+和平），最差 0.5（战争+重税+缺粮）。
- **供给侧的两个通道**：单类供给不足走回收公式；基本需求危机走欲望——不重复。
- 只影响**池上限**，不影响"份额 60/25/15"（结构不变）。

### 5.2 消费情景标签（五档，城市面板一行）

| 标签 | 判定（U=实际回收/池上限） | 经济含义 | 玩家行动提示 |
|---|---|---|---|
| **消费繁荣** | U ≥ 85% 且 K_desire ≥ 1.0 | 有效需求高、供给匹配（接近市场出清） | 保持/扩池 |
| **消费饱和** | U ≥ 85% 且 K_desire < 1.0 | 钱都花出去了、池小（居民已充分消费） | 扩池：人口/政策/科技 |
| **供不应求** | U < 50% 且 K_desire ≥ 1.0 | 有钱没处花（供给不足/消费外流） | 建消费建筑 |
| **消费低迷** | U < 50% 且 K_desire < 1.0 | 有余钱但不敢花（预防性储蓄/低欲望） | 提就业/宜居/降税/停战 |
| **平稳** | 其余 | 中间态 | — |

- 标签=**诊断+行动提示**，不做惩罚；tooltip 一句话解释（如"居民有钱但不愿花：交战/重税压低消费意愿"）。
- 与心智负担设计一致：L0 玩家看标签照做，L2 玩家看数字规律。

### 5.3 三类消费的差异化收益（让"只造零售"不是最优）

| 消费类型 | 财 | 非财收益 | 优势定位 |
|---|---|---|---|
| **零售**（商业街/商场） | 纯回收（12/60 上限） | 无 | 门槛低（1×1/30k）、确定性强 |
| **娱乐**（文化区娱乐 + 红灯区） | 回收（份额内） | **文化值 + 宜居 E + 城市热度** | 财+文化双收；红灯区净财收益最高 |
| **文旅**（酒店/会展/世博） | 回收 × **热度乘区（0.5+Heat/100，cap 2.0）** | 文化值 | **突破本城消费池**（外来游客的钱） |

**结论**：只造零售能赚钱，但放弃文化胜利进度、宜居度、热度与外来客流——数值上娱乐/文旅单位占地收益更高且带乘区，结构上"零售独大"不是最优。
