## 一、五款横向

### 1. 文明 6（✅ 已核实：Theming bonus）

- 巨作/文物入博物馆槽位；**主题化（Theming）**：考古博物馆=同**时代**、不同**文明**的文物填满全馆 → **全馆产出 ×2**；艺术博物馆=同**类型**、不同**艺术家**填满 → ×2。
- 关键机制点：奖励不是单件叠加，而是**组合达成后整体翻倍**——收藏从"逐件优化"变成"凑一套"的拼图玩法；凑不齐 = 零奖励，交易/掠夺外国文物的动机由此产生。
- 与我们对齐：我们槽位小（草案 2/4/6），×2 太猛；但"组合条件"思路可接——**候选：同出土地系列凑齐给小乘区**（见开题议题 #5 补充）。

### 2. 纪元 1800（✅ 已核实：Museum）

- 展品**稀有度五档**（Common/Uncommon/Rare/Epic/Legendary）→ 直接映射**吸引力** 10/20/30/40/50——档位=强度线性表，无其他隐藏量。
- **套装（Set）**：同套展品集齐于**同一馆** → 全岛建筑奖励（跨博物馆拼套无效；同套不可重复生效）——套装奖励作用于岛屿生产层，跳出文化系统本身。
- **文旅闭环**：博物馆吸引力 ≥300 + 公交网联酒店 → 游客需求满足 → 酒店 +幸福、+收入（高收入档 +468.75/分/馆）。**博物馆→吸引力→游客→财**的链路与本项目"城市热度→文旅财乘区"完全同构，方向验证 ✅。
- 展位可扩（每展位 500 财+10 影响力，上限 100）；展品来源=远征/打捞/任务/贸易/**攻占岛屿**/世博会奖励/研究。
- 与我们对齐：①档位→固定数值的干净映射值得照抄（我们的"价值分类"同理）；②"世博会奖励出展品"=我们世博会建筑的远期联动候选；③攻占夺宝=我们的掠夺出口。

### 3. 群星（⚠️ 泛知识待核：Relics，Ancient Relics DLC）

- 遗物=**国家级唯一**（全游戏每件仅一件），主要获取=考古遗址挖掘/击败危机/大事件链。
- **被动 + 主动双效**：永久被动加成之外，可**主动激活**（消耗影响力，冷却约 10 回合量级）产生脉冲型强效果（例：Prethoryn 皇后被动加人口增长、激活召唤舰队；Galatron 激活随机吐资源）。
- 与我们对齐：**常驻典藏（国家级）的双效结构**是"传国玉玺们"的样板——被动小加成（常态）+ 主动大脉冲（CD 型，如"大阅"：全国忠诚流水脉冲/外交声势脉冲）。正好落院长裁定的"末端注入外部参数"管线：被动=结算末端常驻参数，主动=回合动作注入一次性参数。→ 开题议题 #2 落地候选。

### 4. 十字军之王 3（⚠️ 泛知识待核：Artifacts，1.9 Lance）

- 宝物**质量五档**（Fine→Medium→Excellent→Masterwork→Legendary），类型=武器/盔甲/饰物/书籍/旗帜/王冠。
- 加成直给持有者属性/威望等；**获取=定制委托（付钱打造）/战利品/继承/赠予/事件**；有**耐久度**（随年月损耗，需维护）。
- 与我们对齐：①质量档直接对标我们的"价值分类"（我们 3 档更克制）；②"定制委托"思路=后期"文化建筑自然产出艺术品"候选的变体（花钱造传世件？留 DLC）；③**耐久度不建议接**——增加维护税负感，与单机爽感冲突，院长"负反馈纪律"下不做。

### 5. 三国志 12（⚠️ 泛知识待核：宝物）——**项目灵魂对标**

- 宝物=武将装备位：名马/名剑/书物/玉玺等，加武将四维（统率/武力/智力/政治），部分名品附带忠诚巩固；获取=搜刮城池/赏赐流通/交易。
- 系统极简：**一件=几条属性+一个主人**，没有槽位组合没有套装——流通与人的故事（赐宝拉拢、夺城搜宝）才是玩法核心。
- 与我们对齐：这正是 §4.9 已立的"赐予武将"路线的本源（名剑：统率+3、忠诚+10）；典藏系统的**情感重心应压在"宝物与人"（武将/城市羁绊）而非数值最优化**——21 将宝物表归武将专题时按此原则写。

## 二、结论五条（对齐典藏开题议题）

1. **档位=线性数值表**（纪元 1800 验证）：价值分类每档给固定文化/热度基值，不搞隐藏量——议题 #1 支持 3 档（普通/名品/传世），档少密度高，契合"每件独一无二"。
2. **组合奖励=收藏深度来源**（文明 6/纪元 1800 验证）：候选"同系列凑齐小乘区"（如同城全套/同朝代套），强度远低于文明 6 的 ×2——进议题 #5 候选，数值随 v0.2 建筑卡同批。
3. **常驻件双效结构**（群星启发）：被动常驻参数 + 主动 CD 脉冲——传国玉玺候选设计样板，进议题 #2 落地方案；与院长"先结算公式、最后注入典藏外部参数"管线天然兼容（主动脉冲=回合动作层注入）。
4. **文旅联动同构验证**（纪元 1800 验证）：博物馆档位→吸引力→游客→收入的链路 = 我们"价值分类→文化/热度→文旅财乘区"，已裁方向正确，无需返工。
5. **不接的东西**：CK3 耐久度（维护税负感）；文明 6 全馆 ×2 量级（槽位小会失衡）；群星"全游戏唯一"的强稀缺叙事照搬到普通件（我们普通件保考古真实感，稀缺叙事只给传世档与常驻件）。
