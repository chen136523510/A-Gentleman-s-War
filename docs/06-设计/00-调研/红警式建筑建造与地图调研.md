## 一、红警建筑"怎么在地图上建起来"（机制拆解）

### 1.1 玩家可见流程（RA2 口径）

1. 侧栏点选建筑 → **放置预览**：跟随鼠标显示建筑**脚印（footprint）**，逐格铺绿色/红色覆盖块（可建/不可建）；
2. 落位 → 建筑立即出现，播放 **build-up（make）动画**：建筑由脚手架/半透明状态自下而上"实体化"，伴随完成瞬间尘埃/闪光；
3. 完成 → 进入正常态（带血条/选中框）。RA2 **没有工地期**——建造时间在科技建筑生产队列里，落位即成。

### 1.2 OpenRA 源码对照（机制权威）

| 机制 | OpenRA 实现 | 关键字段/结论 |
|---|---|---|
| 脚印 | `Building` trait | `Dimensions`（占地尺寸）+ `Footprint` 字符串逐格声明：`_`空 / `=`占且可通行 / `x`占 / `X`占不可瞄准 / `+`仅过境；字符数必须= X×Y，否则报错 |
| 建造动画 | `WithMakeAnimation` | 名为 **`make`** 的 sprite 序列在 actor 生成时播放一次（`PlayCustomAnimation`），出售/变卖时**倒放**；只管表现，不管时长 |
| 放置预览 | `FootprintPlaceBuildingPreview` | 每格覆盖图取序列 `build-valid-{tileset}`（缺省 `build-valid`）与 `build-invalid`，按深度 -511 画在地表上 |
| 建造时长 | 生产侧 | 与 make 动画解耦——时长由生产/队列决定，动画只是落位瞬间表现 |
| 地形限制 | `Building.TerrainTypes` / `Buildable` | 建筑声明可放地形类型；逐格校验 |

**对本作的改造（回合制适配）**：保留"落位即播放 make 动画"的表现，但把 RA2 队列期改造成**工地期**——建筑落位后以工地形态（脚手架）驻场 N 回合，按建造进度切换工地阶段图，完工回合播放 make 动画转为完成态。这与 L1 `ConstructionSystem`（城级多队列、造价工期）直接对接。

### 1.3 画面要点（红警2截图结论）

- 斜俯视 tile 地形，格子感清晰但地形有**自动过渡**（岸边/道路/悬崖）；建筑有厚重的墙+顶+出入口细节，配选中框/血条；
- 建筑贴图自带"设施感"：烟囱、油罐、雷达、天线、进出坡道——一眼可读功能。

## 二、红警地图设计与开发思路（tileset/编辑器）

OpenRA RA temperat.yaml（tileset 权威结构）：

- **TerrainType@**：`Type`（Water/Clear/Rock/Beach/River/Road/Ore…）+ `TargetTypes`（Ground/Water/Bridge）+ 编辑器 `Color`（小地图/编辑器显示）+ `AcceptsSmudgeType`（弹坑/焦痕）；
- **Template@N**：把 tile 图集里的具体 tile 编号映射到地形类型；一个模板内部可混多种类型（**岸边过渡模板**：同一模板里 Rock/Clear/Beach/Water 拼在一起）；
- **悬崖/坡**：专门的 ramp 模板组（编号 135~172）；水域悬崖镜像一套；
- **道路/海岸/河流**：`MultiBrushCollection` 分段画刷（`Start/End/Points`），编辑器里"画一段路"自动铺整条——**手工地形靠画刷，不靠逐格手摆**；
- **树木/平民建筑**：作为 actor 列表挂在 tileset，编辑器按权重随机撒。

**开发思路结论**：红警系地图=「分层：地形类型层（数据）+ 地形贴图模板层（美术）+ 单位/建筑 actor 层（逻辑）」，编辑器只做"画类型/画路/摆东西"三件事，表现层由 tileset 决定。**改画风不改地图数据**——与我们 R49 数据驱动铁律同构。

## 三、L2 落地方案（底座设计）

### 3.1 数据层（buildings.json + map.json）

1. `buildings.json` 每建筑增 `size: [w,h]`（格）——**复用既有施工单 schema 字段 `Size`**（C# `BuildingDefinition.Size`，draft 条目已用）；暂缺者由运行时按 `category` 回退默认（2×2，工业 3×2），**权威值随各区 L2 化补齐**；
2. `map.json` 不动（`t/v/b/d` 已够；`b`=可建格）——**可建判定只用 b**（ADR-011 既定），footprint 落位时逐格校验 `b`+地形例外（渔场/港口须临海）；
3. 建造阶段数定 **4**（stage0 打桩/工地 → stage1 框架 → stage2 墙体 → stage3 封顶未完工），完工播 make 动画转 idle。

### 3.2 渲染层（烘焙管线）

| 产物 | 生成器 | 说明 |
|---|---|---|
| `{city}-base.png` 3072² | bake_terrain.py | 纯地形，无建筑无标注（已有） |
| `buildings/{id}/idle.png` | bake_buildings.py（新） | 完成态建筑 sprite，64px/格，透明底，RA 式描边+设施细节 |
| `buildings/{id}/stage0~3.png` | 同上 | 工地→框架→墙体→封顶四阶段 |
| `buildings/overlay-valid/invalid.png` | 同上 | 放置预览单格覆盖图（绿/红半透明） |
| `buildings-sheet.png` | 同上 | 全建筑 contact sheet 供验收 |

### 3.3 运行时层（Unity）

- `L2CityView`：加载 base + 建筑 sprite（按 buildings.json footprint 摆放）；
- 建造中：`progress → stage = floor(progress×4)`，切换 sprite；完工时 make 动画（自下而上升起 + 尘土粒子）转 idle；
- 放置预览：选中建造项 → 按 footprint 逐格铺 valid/invalid overlay（读 map.json 的 `b`）；
- 工地期与 `ConstructionSystem` 城级队列对接（剩余回合→进度百分比）。
