## 二、低生育率的成因（研究共识）

1. **城市化与生活成本**：城市住房/教育/医疗成本高，生育的"影子价格"上升。
2. **女性教育与就业**：女性受教育程度和劳动参与率提高，但社会规范（谁带孩子）变化滞后 → 工作-家庭冲突；研究指出关键不是"女性工资上涨"，而是"相对社会规范涨得太快"。
3. **养育成本与教育竞争**：韩国"过酷的教育竞争"使单孩成本极高；中国高育儿成本抑制生育。
4. **婚姻延迟与不婚**：高房价抑制结婚；女性面临"职场成功+家务繁重"双重负担，选择少生/不生/不婚。
5. **性别分工与制度**：父权制/传统性别分工延续、劳动力市场对女性歧视，是东亚共同特征。

## 三、政策效果（韩日经验）

| 政策 | 效果 | 结论 |
|---|---|---|
| 现金补贴（韩国"初次见面券"200 万韩元、父母津贴） | 生育率仍 OECD 最低 | **单纯给钱不足** |
| 育儿假/免费托育/住房支持（日本天使计划起三阶段） | 遏制下滑（维持 1.2~1.3），未能回升 | 覆盖广但力度/企业配合不足 |
| 性别平等（男性育儿参与、企业文化建设） | 研究认为最关键 | 结构性改革 |
| 移民 | 短期补人口，长期同化后生育率同样下降 | 补丁，非解药 |

**共识**：可持续提升生育率需要**综合性结构改革**（劳动力市场/性别平等/住房教育/托育），现金激励只是辅助。

### 4.2 可选的游戏化方向（三案，待院长选）

**案 A：维持现状（只靠 r + 宜居 + 医院 + 政策）**
- 优点：简单、已验证（t200 2.4~3.1 倍）、心智负担低。
- 缺点：没有体现"发达病"（城市越发达越不生），与现实的强负相关脱节。

**案 B：加"机会成本"小系数（推荐）**
- 在 g 上加两个小乘区（各 ±10~15%，不改变主结构）：
  - `f_emp = 1 − 0.15 × clamp(在岗率 − 0.9, 0, 0.3)/0.3`（女性就业/机会成本：在岗率越高，生育略低）
  - `f_dev = 1 − 0.10 × clamp((tech/40) − 0.5, 0, 0.5)/0.5`（发达病：科技越高，生育意愿略低）
- 优点：贴合现实"越发达越不生"；让"科技/就业"有隐性代价；幅度小不影响军事节奏。
- 缺点：多两个参数；玩家可能不理解"为什么科技高反而人口少"（需 UI 解释/百科）。

**案 C：加"结构改革"政策卡（扩展 B8）**
- 新增两张政策卡：**托育补贴**（耗财，g ×1.08，同时 +宜居）、**性别平等**（g ×1.06，+在岗率）；与现有生育补贴/计划生育组合。
- 优点：给玩家"政策组合"乐趣，贴合现实"结构改革>现金"；缺点：政策卡数量增加（院长此前定"只两张"）。

### 4.3 讨论点（请院长裁）

1. 是否要体现"发达病"（科技/就业越高生育越低）？幅度多大（建议 ≤15%）？
2. 政策卡是否从 2 张扩到 4 张（加托育/性别平等）？还是维持 2 张？
3. 人口 t200 目标区间：当前 2.4~3.1 倍（CN 366~473 万），是否合适？若要更低，growthBase 可再降。
4. 是否引入"移民"作为人口补充（现实经验：短期补丁）？当前只有同化（外籍人口），无主动移民政策。

### 4.4 现实数据对"平衡点 1.5 倍承载"的校验

- 现实更替线 2.1，游戏平衡点 1.5 倍承载——**游戏比现实更"能生"**（否则单局 200 回合人口上不去，影响兵源/税基节奏）。
- 院长口径"乱世人口是正收益"与"平衡点 1.5"一致：游戏不是现实人口危机模拟器，而是"乱世经营"——人口增长服务于军事/经济节奏，由承载/宜居/政策调节。
- 因此**不建议**引入现实中的"长期萎缩"（负增长不可逆），只保留"超载回压"（r>1.5 时负增长）。

## 五、结论（含院长裁定）

- 现实低生育率是**结构性/发达病**，现金补贴作用有限；游戏若完全照搬会破坏"乱世人口正收益"的节奏。
- ~~建议案 B（小系数机会成本+发达病）或案 C（政策卡扩展）~~ → **院长 2026-11-13 裁定：维持现状**（案 A）——"现实都解决不了此问题，我们不做无用功，以游戏性为主"。
- **最终口径**：A1.3 已落地的限速参数（growthBase 0.006、±2%、宜居^1.5）+ 承载 r + 医院 h + 生育政策两卡，不再引入机会成本/发达病/新政策卡。
