## 一句话定位

仿三国志 12 的实时策略经营游戏 × 文明 6 区域/科技内政 × 红警式"内政建筑即战场实体"联动；架空东亚微缩地图，学院 21 名群友分属 **CN/JP/KR/AU** 四阵营逐鹿 **14 城**（13 阵营城+达尔文无主城，R22）。**Unity 单机**（2022.3 LTS 中国版 + URP 2D，R18 转向；Web 版已归档主仓），打包 exe 分发，零订阅。**内容体量优先**（R14：AI 搭建、玩法拼凑精华、体量留人）。

## 当前全局快照（一屏版）

- **14 城已定档**（R22 起）：CN 6（北京/上海/深圳/西安/香港/台北）、JP 3（东京/长崎/名古屋）、KR 2（首尔/仁川）、AU 2（悉尼/墨尔本）+ **达尔文（无主城，占领后市政规划，初始=农田+铁匠）**；初始建筑 v1 已配（待院长验收）；台北富士康+台积电双产业（WLT 自立底子）、西安城墙=秦长城视觉
- **21 将驻守全定档**（不加 NPC、不补员）；玩家开局自选阵营（CN 简单档 / KR·AU 困难档）；太守候选层=21 命名武将
- **内政**：六区域（产业/娱乐已细分目录 v1：产业 14 项+娱乐设施 10 项）+居民楼四型+城墙，槽位无上限；**人口/宜居度机制**（高人口生产↑但基建成本↑→宜居度↓取舍环）；建造预览弹窗+拆除三分法；交通不作概念；城态三态（正常-空虚-起义）+公务员培养；武将派驻建筑
- **战斗**：胜负=攻方粮草定时限+**市政府血条清零+陆战驻留占领**；守方两胜法（拖粮尽/端根据地）；战争迷雾+侦察（外交/科技）；部队双模式（遥控/御驾亲征，角色可被俘降士气，全俘=战役败）；掠夺有四代价；攻空虚城面对城防部队、攻起义城面对起义民兵
- **一期**：内政循环 + 城市起义/武将自立 + 俘虏四处置 + 规则外交 + **L3 手动档与自动结算并存（R36）** + 修改器
- **二期**：L3 表现力增强（战损演出/音效）、登陆战滩头细化、天灾异族、军师 LLM、外交 LLM
- **设计原则**：负反馈纪律（不教玩家/前期少战事/不轻易破坏修复）；**单局时长不设上限**
- **战斗类型由攻守城市对自动判定**（如西安→深圳=内陆战，深圳→台北=登陆战）
- **胜利条件三途径并存**（R27b）：统一（13 阵营城，达尔文不计）+ 科技 + 文化（联合国路线），一期纯规则判定；外交并入文化链（见 [胜利条件.md](./00-总纲/胜利条件.md)）
- **开局软引导和平期**（R25）：前 10 回合 AI 出兵阈值 ×1.5、冲突事件缓排、玩家行为不受限（无硬锁）
- **L1 战略层（R37c 已实装）**：开局选阵营+难度、六项资源真数据、军力=服役×战力×军备、城市面板真数据、初始迷雾+每回合 1 次探索、疆域柔光试作、存档 v2
- **数值原则**：现阶段只定结构与公式骨架，一期大体实现后统一微调

## 📜 AI / 接手者阅读协议（上下文成本纪律）

1. 先读本文件（全局快照+文档地图）；
2. 讨论/修改哪个系统，只读对应**模块 README + 目标文件 + 该模块 changelog 顶部索引表**；
3. 禁止默认全量加载所有模块文档；需要"为什么这么定"时查模块 changelog 或归档纪要；
4. 每次讨论后：更新对应模块的"当前真值"文件 + 在该模块 changelog 追加一条（统一格式见下）；跨模块大事件才写根 changelog；
5. 空专题（⛏标记，如科技树/技能/兵种/天灾）启动时再建文件，先在模块 README 挂占位。

## changelog 统一格式（所有模块一致，便于检索）

每个 `changelog.md` 顶部是**快速索引表**（只读它即可定位）：

```
| 日期 | 轮次 | 类型 | 一句话 |

```

- 类型枚举：`决策`（院长拍板）/ `新增` / `修订` / `拆分`（文档结构变更）

```
## 2026-10-22 R8 · {标题}
- 类型：决策
- 依据：院长第八轮原话/纪要 §x
- 变更：{改了什么}
- 影响：{波及哪些文件/系统}
```
