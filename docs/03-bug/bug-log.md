## BUG-G022 · L2 裙边颜色南北颠倒

- 发现时间：2026-11-28（修 BUG-G021 出图探针时发现）
- 环境：`L2CityView.BuildBackdrop → EdgeColor`；出图 `tmp/l2-3d-shots/overview.png`
- 现象：全图视野下北裙边呈海色、南裙边呈陆色（顶部海带接陆地、底部裙边是海色）。
- 根因：BUG-G015① 修地形 uv v 翻转时本函数采样行号未同向修——`LoadImage` 后 `GetPixels32` 的 y=h−1 行=PNG 顶行=数据北缘，原 case 0（北）却采 y=2（PNG 底行=南缘）；东西方向 x 不翻转故正确。
- 修复：case 0↔1 采样行对调，注释锚定行号语义。
- 教训：uv/采样行号语义必须与翻转修复联动改；目检出图要选"方向敏感"的地图（海陆分界）才验得出颜色颠倒。

## BUG-G021 · L2 滚轮拉远屏幕上方大片灰绿空白（BUG-G019 残留漏洞）

- 发现时间：2026-11-28（院长报图）
- 环境：`L2CityView` 轨道相机（96×96 图，FOV 38°，俯仰可拖 20°~78°）
- 现象：滚轮拉远后屏幕上方约 60% 是灰绿空白（背景色/雾色混合），地图只占下方。
- 根因：G019 修复只锁"目标点+背景外延"两维；缩放上限 `Size×1.25=120` 写死、与俯仰角无联动——低俯仰（20°）拉远时视锥上缘俯角仅 1°，上缘光线落地 ~2350m：超 farClip（背景色）、超裙边 0.9 图（虚空）、超 fogEnd 249.6（雾色），三色近同合成大片空白。
- 修复：①`MaxDistFor(el)`——缩放上限改为俯仰的函数（视锥上缘光线必须落在裙边实面内），拉远受阻自动缓动抬俯仰，连续滚轮自然停在斜俯视全图；右键拉低俯仰同步收缩距离；②默认视野=全图入画（`FitDist(55°)`，2026-11-28 院长令）；③`L2BackdropUnder` 四向对称外延（原 z 起点在地图内部、南侧有缺口）；④雾距随拟合视野缩放（fit×2.0/×4.5，首版 ×1.5 实证裙边远端被洗灰）；⑤V 键复位全图；farClip ≥1500 保险。
- 教训：3D 轨道相机"不露虚空"是三维问题——目标锁界+背景外延+**俯仰×视锥联动**，缺一不可；任何相机上限都应写成"覆盖几何"的函数而非写死距离。

## BUG-G019 · L2 相机操作反向 + 最远缩放露虚空

- 发现时间：2026-11-25（院长 L2 验收）
- 环境：`Assets/_Project/Scripts/L2/L2CityView.cs`（轨道相机）
- 现象：WASD 按世界轴平移（W 往南/屏幕下）、中键与左键拖拽方向相反、滚轮方向反、缩放到最远能看到地图外的虚空背景。
- 根因：`fwd` 取 `-_camT.forward`（方向反）、键盘直接读 `GetAxis` 世界轴、max dist 固定 320 且目标可越出地图 ±20。
- 修复：`fwd=ProjectOnPlane(_camT.forward)`；WASD 视角相对；左/中键抓取语义（内容跟手）；上滚=拉近；`_dist` 限 12~1.25×图幅；`_orbitTarget` 锁 `[2, Size-2]`；地形四边外延裙边（取边带平均色）+ 雾色兜底地面。
- 教训：3D 轨道相机的"不露虚空"必须**目标锁界 + 背景外延**双保险，仅限距不够。

## BUG-G017 · 生育补贴按全人口计费（口径=半数人口）

- 发现时间：2026-11-25（复苏盘定 16 城/国库时，院长要求"不要一直保持负财政"）
- 环境：`sim/v26/policy.js` 结算（`birthCost`）
- 现象：复苏盘个别阵营（F2/F7）t200 国库为负（−7,564 / −1,404）；把国库初值从 3 万提到 6 万/9 万**无效**（越给越亏）。
- 根因：**生育补贴按全人口计费**——`birthCost = 人口 × subsidyCost(0.0025)`，而文档与代码注释口径都是"**人口一半** × 0.0025"。单城 24 万人 = 594 财/回（占收入 61%），装"生育补贴"卡的阵营结构性亏损。
- 修复：`× 0.5`；修后复苏 4 seed × 8 阵营 200 回合终局**全正**（最低 4,592），教程盘数值不变（1,246,462 等四阵营与修前一致）。
- 教训：**政策卡"成本类"效果必须用 `financeTrace` 逐项对账**（税/商/维护/军饷/俸禄/政策/补贴），只看终局国库会把"某张卡太贵"误判成"国库不够"；**加钱不能治结构性亏损**。

- 现象：用户侧 exe 双击启动出现空白，而自验管线 `-screen-fullscreen 0` 窗口化启动始终正常——两条启动路径的差异全在屏参
- 根因：Unity Player 的分辨率/全屏模式偏好持久化在注册表，**优先于 PlayerSettings 默认值**；若曾存过坏状态（如独占全屏失败分辨率），后续启动还原坏状态

- 教训：**exe 行为问题先分清启动路径**（双击 vs 带参自验），注册表偏好是 Unity Player 的隐形配置层；复现「只有某些机器/某些时候」的屏参问题先查 `HKCU\Software\<公司名>`

## BUG-G003 · uGUI 按钮全部无响应（缺 GraphicRaycaster + EventSystem）

- 发现时间：2026-10-25（上轮发现并修复于工作区，本轮提交+实测确认）
- 环境：编辑器与 Player 均复现（纯代码构建 UI 的通病）
- 现象：ESC 菜单能显示，但存档/读档/退出按钮点击无任何反应
- 根因：`BuildUi()` 只创建了 `Canvas + CanvasScaler`——**缺 `GraphicRaycaster`**（Canvas 无射线器=命中检测不存在）且全场景**无 `EventSystem`**（无输入分发）；两者缺一按钮即死
- 修复：Canvas 挂 `GraphicRaycaster`，运行时创建 `EventSystem + StandaloneInputModule`；本轮 exe 全屏实测按钮点击（存档落盘/读档回显/退出干净关闭）与悬停高亮全部正常
- 教训：**uGUI 三件套缺一不可：Canvas + GraphicRaycaster + EventSystem**；「UI 显示正常」≠「UI 可交互」，验收必须点一遍

## BUG-G002 · 打包后 Shader.Find 为 null → 游戏窗口空白（仅 Player 复现）

- 发现时间：2026-10-25（院长验收：exe 构建成功但"Game 窗口什么都没有"）
- 环境：Unity 2022.3.62f3c1 + URP 14.0.12；Windows Player
- 现象：exe 启动后画面全空（相机背景色都没有的城市/航路/标签）；Player.log 报 `ArgumentNullException: shader at Material..ctor ← L1MapBuilder.BuildRoutes`
- 根因：`Shader.Find("Universal Render Pipeline/2D/Sprite-Lit-Default")` **在打包后返回 null**——该 shader 无任何资产引用时不进包（Shader.Find 只对已包含的 shader 生效）；`new Material(null)` 抛异常打断 `Awake`，整个地图构建中止。编辑器里 Shader.Find 永远可用 → 编辑器验证掩盖此 bug
- 修复：材质资产化——场景 `routeMaterial` 字段引用 URP 包内 `Runtime/Materials/Sprite-Lit-Default.mat`（guid a97c105638bdf8b4a8650670310a4cd3），被场景引用=shader 必进包；运行时 `Instantiate` 出实例再贴虚线纹理；编辑器内 Shader.Find 仅作兜底。附带修复：CS0109（删多余 new）、菜单启动 exe 改绝对路径（Win32Exception 根因=相对路径+编辑器 CWD 不定）
- 教训：**Unity 打包资源包含规则：Shader.Find/动态加载只对"被引用或显式包含"的资产生效——运行时用 shader 必须走资产引用**；"编辑器能跑"≠"包能跑"，**验收必须在真实 exe 上做**（tools/verify-build.bat 无头构建+启动自验管线已建立）
