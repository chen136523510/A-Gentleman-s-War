## 一、管线总览

```
docs/06-设计/L2地图档案/{city}.json   ← 地理档案（纯文本可 diff，AI 编写/院长看预览验收）
    ↓ node tools/l2planner/plan.js --city {city}   （31ms/城，确定性 sha256 自证）
Assets/_Project/Data/L2/{city}/map.json   ← chunk 化 tile 数据（16×16 chunk，t/v/b/d）
tmp/planner-preview/{city}.png + -report.txt   ← 预览图+校验报告（过程件）
    ↓ python tools/l2planner/bake_art.py --city {city}   （~40s，PIL）
tmp/baked-l2/{city}-full.png(6144²) / -overview.png(1800) / -detail-*.png / ui-base.jpg(1600 干净底图)
```

- **b 标记**：规划器算好的可建格（陆地=1；海/浅滩/河/岩/丘/路=0）。L2 落地判定**只用 b**（粗粒度零心智负担），渔场/港口附加"须临海"（邻接非可建格判定）。
- **装饰层**：tile 带 v（variant 色差）+树点/条田由档案 decorate 控制（treeDensity 深圳现值 0.12=街树尺度）。
- **CLI**：`--city X` 单城 / `--all` 全量（无档案跳过）/ `--sheet` 拼图。零 npm 依赖（PNG 用 zlib 手写 encoder）。

## 二、烘焙器算法（bake_art.py）

1. **区域分层合成**：每类地形一整层连续纹理 × 羽化掩码（按类不同 feather 倍率：城区/居住/工业 2.4×格宽，草地 0.8，海 0.6）——格间过渡带约 1~2 格，消除逐格马赛克。
2. **偏移羽化平铺**（v2，弃镜像）：每格从纹理随机窗取块，前向叠加，左/上边缘 64px 线性渐隐——无镜像万花筒对称、无硬缝。PIL 坑：逐通道最小值是 `ImageChops.darker` 不是 `.min`。
3. 海面族额外高斯柔焦（blur 14）压波纹方向性。
4. 海岸浪线/沥青路网/树点为后绘制层；市政府 3×3 金框+血条（院长口径）；ui-base.jpg 在画建筑**之前**导出（UI 交互层自己叠加建筑）。
5. 已知极限（BUG-G008 登记在案）：源纹理非数学无缝，平铺单元边界大尺度仍可察觉——后续方向=同地形多变体纹理池/2048 源图/接缝修补/运行时程序化水面。

## 三、ComfyUI 纹理生成踩坑（tmp/gen_l2_textures.py）

1. **分辨率硬上限 768²**：FLUX.1-dev-fp8 在 12GB 卡上 1024² 必然部分卸载回 CPU（112s/步 vs 768² 1.15it/s，差 80 倍）。纹理烘焙只取 64px 块，768 绰绰有余。
2. **GPU 必须独占**：浏览器/Unity 等占几百 MB 显存就会把 768 也挤卸载——生图前关掉一切吃显存的窗口；任务中断后 ComfyUI 队列可能留僵尸任务，`/interrupt` 不一定生效，**taskkill 大内存 python + 重启 ComfyUI** 最干净（aki 包：`E:\ai\ComfyUI-aki(1)\ComfyUI-aki-v3\start_comfyui.bat`）。
3. 英文提示词（中文会无视底色/纹理指令，美术登记表同款踩坑）；"seamless"提示词只是内容适合平铺，不产生数学无缝。
4. 写实单体建筑/城区：现代中国都会口径（世界观：剧变后、年份不明，剧变前遗物）；单体建筑顶视 FLUX 可用（小区样图已获院长风格认可），整城写实 FLUX 不可用（R24f 已证伪）。

## 四、深圳档案校准依据

按真实卫星结构（调研：[../06-设计/00-调研/深圳核心区航拍结构与绿地比例参考.md](../06-设计/00-调研/深圳核心区航拍结构与绿地比例参考.md)）：建成区绿化覆盖率 45.72%（2025 官方）=城内绿地非野林；福田-南山-罗湖连片高密度；深南大道主轴；梧桐山东北角；深圳湾东南内凹。v4 配比：建成区 25%+/绿地 33.8%（公园草坪纹理）/海 32.7%/山 4%/农田 1.5%。

## 五、v4 渲染底座（2026-11-11，ADR-012：空地制 + 红警式建造）

> 院长令：L2=空地+初始建筑+自然地形；画风参照三国志12；机制参照红警。v2 平铺照片纹理/v3 卫星复刻均废弃。

```
plan.js → map.json（不变，可建判定只用 b）
bake_terrain.py --city X [--painted tmp/.../X-painted.png]
    → tmp/baked-l2/{X}-terrain.png (3072², 32px/格，纯地形无建筑无标注)
bake_buildings.py [--tile-px 64]
    → tmp/baked-l2/buildings/{id}/{id}-stage0..3.png + {id}-idle.png（64px/格，透明底）
    → tmp/baked-l2/buildings/overlay-valid|invalid.png + buildings-sheet.png
bake_city.py --city X
    → tmp/baked-l2/{X}-city-sample.png / -overview / -detail（样张：初始建筑+工地+放置预览演示）
```

- **画风增强（可选）**：程序化布局降 768² → ComfyUI FLUX img2img（`oil_painting_slider` LoRA 0.55 / denoise 0.42 / 16 步 / 提示词见 tmp/gen_l2_painterly.py）→ 放大 3072 → 矢量海岸/河流/森林叠加。不跑 ComfyUI 时纯程序化照常出图。
- **建造阶段约定**：进度→stage=floor(progress×4)，0 打桩/材料堆，1 钢架，2 低墙，3 封顶未完工；完工运行时播 make 动画（升起+淡入）转 idle——数据 `buildings.json size`（复用 schema），权威值 cityHall 3×3 / militaryBase 4×3 / 农田 4×4。
- **Unity 底座**：`Scripts/L2/L2MapData.cs`（map.json 模型+加载器）、`L2CityView.cs`（base/建筑层/CanPlace/PlaceBuilding/SetProgress/放置预览）、`L2ConstructionSite.cs`（阶段+make 动画）；菜单 `AGW/L2 预览（深圳）`。预览直读 tmp/，定版迁移 Resources 后置。
- **踩坑（新）**：ComfyUI FLUX fp8 在 12GB 卡上被后台应用（壁纸引擎/Steam/微信等）挤占显存 → 200s/步级卡死；生图前必须独占 GPU（后台也关），中断后重启最干净。
- **建造系统接入（同日）**：`L2CityController` 把视图接到 `ConstructionSystem`——`TryEnqueue(s, cityId, id, at)` 带 L2 落位，`ConstructionJob.At`/`BuildingState.At` 随存档序列化；工地 sprite 进度=`1−max(回合比,生产比)`，完工 `SetProgress(1)` 触发 make 动画。L1 城市面板「城内」按钮进入（`L1MapBuilder.EnterCityInterior/ExitCityInterior`），自检菜单 `AGW/L2 自检·建造链路` 可 batchmode 断言。
- **放置细节（同日）**：`L2CityView` 补格子网叠加（放置时显示，程序化生成）、悬停高亮、渔场/港口临海例外（`CoastalOnly`=至少一格邻接 sea/shallow/river）；GUI 区点击已排除误落位。
