# 施工单 — L3 战场模板池 + 参数注入（M1 前置 · B 方案）

> 立单：2026-11-29 黑机 · 上游：[L2L3关联性讨论 v2.0](../06-设计/00-总纲/L2L3关联性讨论.md)（院长裁 B）· [L3战斗层开题 v0.3](../06-设计/04-军事/L3战斗层开题.md)（E1~E10 不变）
> AI 摘要：战场=模板池（地形类型×6 张参数化）+BattleContext 单向注入；墙体/城门/梯子机制归模板实体；M1 范围不变、几何来源改为模板池；3 阶段，与 M1 联调收官。

## 一、定位

B 方案下 L3=独立会战图：**战场几何不再来自 L2 格网，来自模板池**。本单给 M1（BattleSimManager+30Hz tick+命令流+4060 压测）提供战场数据来源，并落地 L2/L1→L3 的单向数据接口。E 裁（SoA/spatial hash/命令流/三态迷雾）全部不变——模板池只回答"sim 吃哪份几何"。

## 二、战场模板 schema（BattlefieldTemplate · JSON 数据驱动）

```jsonc
{
  "id": "tpl_plains_city",            // 模板 ID
  "terrainType": "plains",            // plains/hill/coastal/river × city/field
  "kind": "city",                     // city=城战 / field=野战
  "bounds": { "w": 120, "h": 90 },    // 战场格 bounds（L3 格≠L2 格，独立尺度）
  "wall": {                           // kind=city 才有
    "segments": [[x1,y1,x2,y2], ...], // 墙段（摧毁后网格更新——E 裁沿用）
    "gates": [[x,y], ...],            // 城门（突破口）
    "levels": { "hp": [3000, 5000, 8000] }  // 墙等级→耐久（BattleContext.wallLevel 索引）
  },
  "features": [                        // 地物：河流/山体/林地（阻挡/掩体）
    { "type": "river", "poly": [[..]] }, { "type": "hill", "rect": [..] }
  ],
  "spawn": { "defender": [[x,y]...], "attacker": [[x,y]...] },
  "objectives": [                      // RTK12 据点三件套（本阵/兵法阵/城门）
    { "type": "home", "at": [x,y] }, { "type": "gate", "at": [x,y], "hp": 4000 }
  ],
  "ladderAnchors": [[x,y], ...]        // 梯子吸附点（11-25 城墙机制归模板）
}
```

## 三、模板清单 v1（6 张参数化）

| id | kind | terrainType | 覆盖 |
|---|---|---|---|
| tpl_plains_city | city | plains | 平原城战（缺省兜底） |
| tpl_hill_city | city | hill | 山地城战（山体咽喉） |
| tpl_coastal_city | city | coastal | 滨海口城战（登陆/岸线） |
| tpl_river_city | city | river | 河流城战（渡口咽喉） |
| tpl_plains_field | field | plains | 平原野战 |
| tpl_hill_field | field | hill | 山地野战 |

- v1 全部**程序化生成**（几何=代码按 schema 布点生成 Mesh）；美术精修随 ComfyUI 样张批次
- 每城→模板映射：城市档案 `terrainType` 字段（cities.json 已有 coastal 等）+ kind=城战/野战由交战类型定

## 四、参数注入（BattleContext · 单向快照）

```csharp
public class BattleContext {          // L2/L1 开战时构造（构造点：L1MapBuilder 出阵流程）
    public string CityId;             // 攻城目标（野战 null）
    public string TemplateId;         // 由 terrainType+kind 解出
    public Defender Defender;         // { Garrison, MilitiaPool, WallLevel, GateCount }
    public Attacker Attacker;         // { FactionIds[], TotalForce, Officers[] }
    public string[] OfficerIds;       // 双方参战武将（L3 单位=部队+武将，D 裁）
    public float[] Buffs;             // 政策/事件卡 L3 占位（PolicyModifiers L3 段）
}
```

- **注入点**：L1MapBuilder 出阵/被围时构造 → `BattleLauncher.Launch(ctx)` → 选模板 → 实例化（守军布点密度=兵力/城门耐久=wallLevel 索引）→ 进 BattleSimManager
- **回写**：`BattleResult { Winner, Casualties, Captured[], CityCaptured? }` → L1 结算（占领/损毁/俘获）——现 L1 无战争引擎，回写消费点随战争引擎落库（WarAI 接线同批）
- 一期教学盘默认攻城战=深圳 tpl_plains_city（或 coastal per 档案）

## 五、施工步骤

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0 | schema+模板加载器（JSON→运行时结构）+2 张程序化模板（plains_city/plains_field）生成 Mesh | 编辑器预览战场几何+布点可视化 |
| P1 | BattleContext+BattleLauncher（快照构造/模板实例化/布点密度） | 伪快照注入→战场实例化参数生效（墙耐久/守军数） |
| P2 | 与 M1 联调（模板几何→SoA/spatial hash 初始化；梯子吸附点→攻城器械） | M1 压测场景改由模板池供几何 |
| P3 | 6 张全量+回写管道占位+`-agwshot-l3` 自检（新） | L3Smoke 过（若 M1 已立）；6 模板出图目检 |

## 六、边界

- 战斗机制（士气/战法/部队 AI/迷雾）全部归 M1/M2 施工单——本单只管"战场从哪来+参数怎么进"
- 美术精修（战场地表/墙造型/据点物件）等样张批次；P3 前全部程序化
- 野战触发（行军遭遇/野战选择）随战争引擎落库——本单只供模板
