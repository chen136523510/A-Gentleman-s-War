# ADR-010 · 1999 灾后世界线与内政新系统（就业/电力/工业/军备）

> 状态：✅ 已接受（2026-11-01 院长多轮拍板）
> 关联：[03-内政/工业区数值.md](../06-设计/03-内政/工业区数值.md) v1.0 · [03-内政/农业区数值.md](../06-设计/03-内政/农业区数值.md) v1.1 · [03-内政/粮食与人口算法.md](../06-设计/03-内政/粮食与人口算法.md) v4.0 · [03-内政/资源体系.md](../06-设计/03-内政/资源体系.md) · [07-技术架构/L1界面与交互收集-2026-10-29.md](../06-设计/07-技术架构/L1界面与交互收集-2026-10-29.md)
> 过程件：`tmp/build-sim.js` 200 回合 ×3 随机种子（42/43/44），不入库。

## 背景

B1 建筑全量从农业区进入工业区；院长要求把工业区做成完整专题，同时解决：
- 旧世界线（14 城现代大都市）与“王乐添第 2 回合自立”的合理性；
- 玩家“分配人口到建筑”的就业机制，而不是系统自动铺岗位；
- 财/军备/矿产/污染/电力之间的取舍；
- AI 不能只靠数值模板，后期不能进入“垃圾时间”。

## 决策

1. **世界线改为 1999 大灾变**：绝大部分城市毁灭、人口流失、科技退化；**14 城按正常城市表现，不做废墟美术/废墟机制**；其他毁灭城市不在地图体现。初始总人口 **119k**、开局只有轻工、首科技目标 t20~30；WLT 第 2 回合军阀割据。
2. **就业机制**：总人口 = 在岗劳动力 + 服役 + 赋闲；**不做基础就业**；每建筑有岗位上限，玩家分配人口；**就业率**（在岗/可就业）与**在岗率**（在岗/岗位）双指标；初始 95% 就业/5% 赋闲；超高人口靠拥挤/就业/粮/污染软限制。
3. **工业区 v1.0**：18 类（重工3/矿业4/能源5/高新3/轻工3）+ **造船厂归军事** + 特色工业后期；**无行政上限**，自然限制（矿脉/沿海/河流/每城垃圾/地标）+ 岗位/L2 用地/电力/矿产为真实上限；L1 占地只展示，L2 真实摆放。
4. **电力城市级**：发电厂产电+生产；耗电建筑按满足率打折；高产出耗电（互联网 8/半导体 12/AI 20）；**电力运输科技**后全国余电自动分配（10% 损耗）；重工 Lv1 不耗电，升级 +4/+8，停电托底 1.05×Lv1。
5. **升级三路径**：规模/精益/清洁（Lv2 选一、Lv3 延续），不是单纯加数值；每建筑专属效果后置。
6. **治污共益**：污水厂（−4 污染 +1 电 +2 生产）、环保园（−3 污染 +4 科技 +6 财）、脱硫（SO₂ −50% +2 生产）；垃圾发电厂是垃圾能源化，不算治污。
7. **军备/军工**：装备上限 `min(1.5×兵力, 1,000+基地×2,000+军工厂×1,000)`；钢支撑 0.55+0.45×钢铁/军工（化工 +5%）；双方战损、和平期裁军、战时临时征兵/建军；军饷 0.05、装备维护 0.005。
8. **矿产**：铁/煤/铀全国池；金自动折财（1 金=8 财）；矿脉按城 50 回合/档（丰饶/富集/寻常/贫化/枯竭），无城市系数；AU 无煤（达尔文有煤）、铀仅西安/达尔文/悉尼；WLT 无矿，钢靠贸易/进口。
9. **AI**：需求分 × 国家权重 × 战争/和平；CN 重工/军工、JP 科技、KR 商业/防御、AU 矿业、WLT 生存；无工业软上限，用高耗电/岗位/矿产/财自然卡；后期继续升级。

## 否决方案

| 方案 | 结论 | 理由 |
|---|---|---|
| 保留现代大都市世界线 | 否决 | 与“台北第 2 回合自立/军阀割据”不协调；人口/劳动力数值难调 |
| 基础就业池（传统部门） | 否决 | 院长明确“不做基础就业”；改为初始人口=岗位/0.95，5% 赋闲 |
| 劳动参与率乘总人口 | 否决 | 与“一个人口要么劳动/服役/赋闲”口径冲突 |
| 工业区行政上限 1~3 座 | 否决 | 院长要求不设区域数量限制；用岗位/人口制衡 |
| 每矿加速枯竭 | 否决 | 多矿会 60 回合内挖空；改为按城 50 回合/档 |
| 纯数值升级 | 否决 | 院长要求趣味性；改三路径 + 专属效果 |
| 国家电力池（一开始） | 否决 | 削弱“发电厂 vs 重工”的地方取舍；先城市级，运输科技后再全国 |
| 垃圾发电厂算治污 | 否决 | 它是垃圾能源化，自身 +2 污染；治污另设污水厂/环保园/脱硫 |
