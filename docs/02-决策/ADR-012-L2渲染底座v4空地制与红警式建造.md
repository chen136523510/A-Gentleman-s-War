# ADR-012 · L2 渲染底座 v4：空地制 + 红警式建造表现 + 量产管线

> 状态：✅ 已拍板（2026-11-11 黑机执行，院长令：①L2=空地+初始建筑+自然地形 ②画风参照三国志12 ③机制参照红警）
> 取代：v2「ComfyUI 照片纹理平铺」（棋盘格已证伪，BUG-G008 相关）与 v3「深圳卫星结构复刻」（院长否决——调研只为自然地理，不画城区/道路/建筑肌理）。
> 关联：[红警式建筑建造与地图调研](../06-设计/00-调研/红警式建筑建造与地图调研.md) · [ADR-011](./ADR-011-L2大地图圈地制与规划器量产管线.md) · tools/l2planner/

## 背景

L2 首轮烘焙（bake_art v2 平铺照片纹理 / bake_whole v3 程序化城市肌理）均被院长否决：L2 是**地块经营图**——初始只有自然地形+5 座初始建筑，其余全是空地；道路/城区/农田都是玩家建出来的内容。同时院长指示学习红警的"建筑如何在地图上建起来"与地图设计思路，并要求优先开发底座。

## 决策

1. **base=纯地形整图**：3072²（32px/格）一张地形烘焙图（海岸/河流/森林/山体/空地），**不含任何建筑、道路、标注**；建筑全部走 sprite 层。
2. **建造表现=红警式改造（回合制适配）**：
   - 放置预览：逐格 valid/invalid 覆盖（OpenRA `FootprintPlaceBuildingPreview` 机制）；
   - 工地期：建造进度 → **4 阶段 sprite**（stage0 打桩/材料 → stage1 钢架 → stage2 低墙 → stage3 封顶未完工），与 `ConstructionSystem` 剩余回合换算进度；
   - 完工：**make 动画**（升起+淡入，OpenRA `WithMakeAnimation` 机制）转 idle 态。
3. **建筑数据 `size`**：复用既有施工单 schema 字段（`BuildingDefinition.Size`，draft 条目已用）；本轮回填 33 个 active 建筑（权威值：cityHall 3×3 / militaryBase 4×3 / 农田 4×4（ADR-011）；其余=规划器/类别暂定），缺省按 category 回退（2×2，工业 3×2）。可建判定仍**只用 map.json 的 b**（ADR-011 既定），size 只做落位/预览/碰撞。
4. **管线（tools/l2planner）**：
   ```
   plan.js → map.json
   bake_terrain.py --city X [--painted 重绘图] → {X}-terrain.png (3072²)
   bake_buildings.py → buildings/{id}/{id}-stage0..3.png + idle.png (64px/格)
                        buildings/overlay-valid|invalid.png + buildings-sheet.png
   bake_city.py --city X → {X}-city-sample.png（base+初始建筑+工地+预览演示样张）
   ```
   画风增强（可选）：程序化布局降到 768² → ComfyUI FLUX img2img（oil_painting_slider LoRA 0.55 / denoise 0.42 / 16 步）油画重绘 → 放大回 3072 → 矢量海岸/河流/森林细节叠加。**AI 重绘是增强不是依赖**——不跑 ComfyUI 时纯程序化管线照常出图。
5. **运行时底座（Unity）**：`Scripts/L2/` 新增 `L2MapData`（map.json 数据模型+加载器，复用 L1 BuildingDefinition）、`L2CityView`（base 渲染/建筑层/CanPlace/PlaceBuilding/SetProgress/放置预览）、`L2ConstructionSite`（阶段切换+make 动画）；编辑器菜单 `AGW/L2 预览（深圳）`。预览直读 `tmp/baked-l2/`（编辑器期产物不记构建），定版后迁移 Resources/Addressables。

## 后果

- 正面：14 城量产管线齐备（同一命令换 --city）；建造系统（L1 城级队列）与 L2 表现打通的数据/接口底座完成；画风可整体替换而不动数据（tileset 思想）。
- 代价/挂账：①768 重绘放大到 3072 偏软 → 1024/1536 重绘或分块超分；②33 建筑 sprite 为程序化初版，待美术精修/AI 单体贴图；③山体岩石/河流自然感二轮；④渔场/港口"须临海"落位例外未接；⑤L2 预览仅编辑器直读 tmp，构建产物迁移后置。
