# ADR-011 · L2 大地图圈地制与规划器量产管线

> 状态：✅ 已拍板（院长 2026-11-08 六批指令）；实施：规划器 MVP 已落地，L2 运行时待施工
> ⚠️ **修订（2026-11-09 院长令）**：**决策 2"玩家自主圈地"条款作废——改固定地块制**：不做扩地、不做买地/地价（人口税与土地价格 §三 废弃）、不做行政容量门控；**每城初始即给出限定大小的全部可建地块**（"足够大"口径=满足满配建筑+预留余量，具体分档由规划器档案定+白机校验），理由：扩地指数成本体验差、固定边界让 L3 同步更简单。决策 1/3~7 维持不变——预规划地图/L3 同图/规划器管线全部照旧，只是"拓展=揭示已规划土地"改为"初始全量可见"。
> 取代：R15 拍板的"L2 网格基点=12×12 总幅面/开发区 8×8"中固定幅面部分；城市成长"人口阈值发育圈"口径同步作废
> 关联：[01-地图与城市/地图三层架构.md](../06-设计/01-地图与城市/地图三层架构.md) · [01-地图与城市/L2地图档案/](../06-设计/01-地图与城市/L2地图档案/) · tools/l2planner/

## 背景

R15 的 L2 方案（固定 12×12 幅面、8×8 开发区）在开工前被院长重新定义：①地块要能"足够大+玩家自主拓展"，不受人口阈值圈死；②14 城逐城手工摆格不可量产；③L3 战场要读 L2 的同一份数据（红警范式），且改 L2 不能引发 L3 重算；④美术要写实、要像真实城市而非空白网格。

## 决策

1. **每城一张预规划大地图**：96×96 格起步（可按城调整，如达尔文 64），**1 格 = 100m = 1 公顷**（小区 2×2=4ha/农田 4×4=16ha 真实；L3 直射武器 2~4 格=200~400m 街区战合理；96×96≈9.6km 方=城区+近郊）。
2. **拓展=玩家自主圈地**：地图内土地由玩家圈选开发，数值门控=开发成本/行政容量（**不是**人口阈值）；运行时零程序化生成，扩张=揭示已规划土地。
3. **L3 = L2 的战争状态**（文明 6 式同图）：同一份 tile 数据，和平态=经营摆放，战争态=叠加单位实体+建筑战损（完好/受损/废墟）+迷雾；掠夺/占领（市政府控制权）/部署全部直读 tile 与建筑实例——**L2 编辑只写 tile diff，L3 零转换零重算**。
4. **量产 = L2 地图规划器**（编译器式管线，AI 友好）：每城一份地理档案 JSON（海岸/山脊/河流/分区/路网/地标/初始建筑/种子，纯文本可 diff）→ tools/l2planner 确定性编译（地形合成/分区/路网/装饰/校验）→ map.json（chunk 化 tile 数据）+ 预览 PNG + 文本校验报告。同输入必同输出（sha256 自证），改规则=改代码重跑 14 城，不改图。
5. **落地判定粗化**：只用规划器产出的 b 标记（陆地可建/海·山·河·路禁建），不给玩家细分区限制（渔场/港口"须临海"为唯一例外，来自既有 coastalOnly 设计）。
6. **性能红线**：tile 是表现+交互层，**不做逐格模拟**——经济保持城级聚合（建筑级产出）；渲染按 chunk（16×16）局部重烘；远块卸载，同一时刻只驻留一座城。
7. **兼容性铁律延续（R49）**：加建筑=加 JSON+贴图；建筑占地/限制/成本全数据驱动。

## 后果

- 正面：14 城量产从"9216 格/城手摆"降为"每城数百行档案"（AI 写档案、院长看预览验收）；L2↔L3 同步问题被"同一份数据"直接消灭；画风连续性（L1 卫星→L2 航拍）成立。
- 代价/新依赖：烘焙依赖 ComfyUI 本地纹理（768² 上限，见 04-技术笔记/L2地图规划与烘焙管线.md 的显存踩坑）；平铺接缝仍是已登记质量问题（BUG-G008）；L2 运行时（map.json 加载+chunk 渲染+放置接建造系统）为下窗施工单。
- 摒弃方案：运行时无限程序化生成（不可控不可评审）、外部工具手绘（非 AI 友好、二进制）、Unity Editor 内工具（batchmode 分钟级启动、MCP 未接线）。
