# 3D 资产三阶段工作流（院长 2026-11-12 定）

> 适用范围：L2 城内 3D 建筑、地形装饰、道具、特色建筑。**任何 3D 资产从建模到进 exe 必须走三阶段；阶段未过不得跳级。**
> 关联：[ADR-012](../02-决策/ADR-012-L2渲染底座v4空地制与红警式建造.md) · [L2 城内视觉需求](../06-设计/00-调研/L2城内视觉需求-2026-11-11.md) · [L2 地图规划与烘焙管线](../04-技术笔记/L2地图规划与烘焙管线.md)

## 一、三阶段（Definition of Done）

| 阶段 | 载体 | 交付物 | 验收内容 | 通过后 |
|---|---|---|---|---|
| **基础版** | 网页查看器（`tools/3d-viewer/`） | `model.json` + 参考渲染 + `.blend` 源 | 造型/比例/朝向/材质基调/体块；**可旋转拖动** | 进入批量，等下一批一起进地图 |
| **进阶版** | 网页地图查看器 | 地图场景 + 资产实例 + 光照 | 在地图里的尺度/遮挡/与地形关系/与相邻建筑风格一致 | 进入归档 |
| **归档版** | Unity 构建 exe | prefab + LOD + 碰撞/点击 + 贴图 | 最终画质/交互/点击/性能/存档 | 登记入库 |

**批量纪律（院长原话）**：

1. **先批量过基础版**——一次审一批（如 33 类建筑），不要单件从基础版一路精修到最终。
2. **然后一起放到地图里观察**——同一城/多城总览 + 近景，检查整体风格与尺度。
3. **最后一起构建到 exe 里验收**——包括交互，**绝大部分建筑都可以点击**。

**返工规则**：地图阶段/归档阶段发现造型问题，回基础版改，重新过三阶段；**不允许在地图或 exe 里直接改造型**。

## 四、建模与导出规范

1. **坐标**：Blender Z-up，建筑正面朝 **-Y（南）**；Unity 导出为 **-Z forward、Y-up**。
2. **尺度**：**1 格 = 20m**；3×3 建筑 = 60×60m；Unity 导出 `global_scale=0.05`（1 格 = 1 unit）。
3. **原点**：footprint 中心，底面 y=0；建筑必须落在 footprint 内（挑檐/屋顶可出格，需在数据里标注）。
4. **材质**：PBR（base color / metallic / roughness）；程序化材质只用于渲染参考，导出前必须烘成贴图或平色。
5. **面数**：LOD0 ≤ 20k tris/单体；LOD1 ≤ 5k；LOD2 ≤ 1k 或 billboard。材质数 ≤ 6/建筑。
6. **合并**：按材质合并 mesh（避免 159 个 draw call）；碰撞体单独命名 `UCX_`。
7. **施工态**：stage0~3 + idle 各一套；3D 版按阶段换 mesh/材质。
8. **贴图**：ComfyUI 本地免费；付费 API 先确认（AGENTS 红线）。

## 五、基础版查看器规范

- 启动：`python tools/3d-viewer/serve.py --port 8765`（脚本打印 URL）。
- 必须支持：左键旋转、滚轮缩放、右键平移、**50/55/60/70° 预设**、3×3 地块网格、线框、投影、参考渲染图。
- 页面必须显示：资产名/阶段/三角面/网格数/材质数/尺寸/包围盒。
- 通过标准：比例正确、**正面朝南**、无穿插/漏面、材质基调可辨、任意角度无破面、与参考渲染风格一致。
- 当前默认：**55°~60° 倾斜、固定朝北**；院长可在页面上切换对比。

## 六、进阶版（地图）规范

- 场景：目标城 L2 地形 + 已有建筑 + 新资产，默认倾斜 55°~60°、固定朝北。
- 检查项：与地形贴合、遮挡排序、阴影方向、道路/广场关系、相邻建筑尺度、整体色调。
- 通过标准：放进地图不突兀；总览/近景都可读；与参考渲染风格一致。
- 批量：33 类建筑一起放同一张地图，出 **contact sheet（总览 + 近景）**。

## 七、归档版（Unity）规范

- **URP 3D**（Universal Renderer）；L1 保留 2D Renderer，L2 切 3D 相机，互不影响。
- prefab：LOD Group、BoxCollider（点击）、施工阶段、make 动画、点击信息面板。
- 验收：`AgwMenu.BuildOnly` 构建 exe；**绝大部分建筑可点击**；点击弹出建筑信息；1080p ≥ 60fps；存档兼容。
- 通过后才登记 `美术资产登记-3D建筑.md` 并提交 `Assets/_Project/Art/3D/`（LFS）。

## 八、工具与成本

- 主线：**Blender 5.2 参数化建模**（本机 `E:\Blender`）+ ComfyUI 本地贴图。
- **Hi3D / 混元 3D 暂不接主线**：市政府等硬表面建筑优先手搓（拓扑/UV/比例可控、免费、可复用）；Hi3D 留作装饰件/雕塑/废墟/树石的加速器，或手搓效果不满意时的 A/B 备选。
- 付费生成 API 一律先确认院长；ComfyUI 出图 GPU 必须独占。
