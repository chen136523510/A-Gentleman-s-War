# 武将 3D 形象方案（21 初始将 · 火柴人基底）

> **AI 摘要**：21 初始将**不各做独立模型**，用**同一火柴人基底 + 数值/装饰区分**；差异靠 6 个维度（身高/体型/主色/头饰/披风/武器），一期只做 1 套基底 + 21 套配置。依据：院长 2026-11-24 第 3 条「21 初始将的建模，可以先用 3D 火柴人来实现，调整点数值和装饰做区分」。状态：📝 方案定，未建模。
> 关联：[3D资产工作流](./3D资产工作流.md) · [美术纪律](./美术纪律.md) · [武将名册](../06-设计/02-武将/武将名册.md) · [属性体系](../06-设计/02-武将/属性体系.md)

## 一、决策（院长 2026-11-24）

> 「21 初始将的建模，可以先用 3D 火柴人来实现，调整点数值和装饰做区分」

- **一套基底**：火柴人（简化人体：头/躯干/四肢/手/足，无面部细节）——一期**不做**写实武将模型。
- **区分手段 = 参数化 + 装饰件**，不新增独立网格。
- **理由**：①21 个独立模型成本高、且一期不做平衡/表现力优先级 ②火柴人符合"表现力从简、数值优先"的项目纪律 ③装饰件可复用，后续换皮不动逻辑 ④L3 大战场（万人级）本就用"表现比例"，武将火柴人在同风格内。

## 二、区分维度（6 轴，全部数据驱动）

| # | 维度 | 实现 | 区分度 | 示例 |
|:--:|---|---|:--:|---|
| 1 | **身高** | 缩放 Y（0.9~1.15） | 中 | 猛将高、谋士矮 |
| 2 | **体型** | 躯干/四肢粗细（0.85~1.25） | 中 | 武力型粗壮、智力型瘦削 |
| 3 | **主色** | 材质主色（按阵营色 + 个体明度差） | 高 | CN 红系 / JP 蓝系 / KR 青系 / AU 金系 |
| 4 | **头饰** | 挂点替换（无/头盔/斗笠/发冠/军帽） | 高 | 与"倾向特性"绑定 |
| 5 | **披风/背饰** | 挂点替换（无/短披/长披/旗帜） | 高 | 统率型长披、智力型旗帜 |
| 6 | **武器** | 手持挂点（无/剑/枪/弓/扇/槌） | 极高 | 按主属性：武力→枪/槌、智力→扇/书、政治→笏、魅力→无 |

> 原则上 **①身高②体型③主色** 参数化即得 21 种可辨识组合；**④头饰⑤披风⑥武器** 是强化记忆点（每个武将固定一套，不随机）。

## 三、数据驱动结构（配置进武将数据，不进模型）

```json
// officers.json（示例字段，随黑机落库补充）
{
  "id": "officer_01",
  "body":  { "height": 1.05, "bulk": 1.15, "color": "#C0392B" },
  "deco":  { "hat": "helmet", "cape": "long", "weapon": "spear" },
  "silhouette": "猛将型"   // 仅描述用，不进渲染
}
```

- **模型侧**：`officer_stickman.fbx`（1 套）+ `deco_hat_*.fbx` / `deco_cape_*.fbx` / `deco_weapon_*.fbx`（各 3~5 件）。
- **渲染侧**：按 `body` 参数缩放、按 `deco` 挂点实例化；21 将 = 21 条配置，**零新增网格**。
- **换皮友好**：二期若要写实化，只换基底 FBX，配置结构不变。

## 四、验收与工作流衔接

- 走 [3D资产工作流](./3D资产工作流.md) 三阶段：**基础版**（网页查看器旋转/查造型）→ **进阶版**（地图内查尺度/遮挡）→ **归档版**（Unity exe）。
- 一期验收标准：①21 将同屏可区分（隔 2 米能认出至少 3 个特征）②L3 万人场景下火柴人剪影可读 ③装饰件不穿模、不掉挂点。
- **不做**：面部表情、布料物理、骨骼动画（一期用 idle/走/攻 3 个基础动作即可，随 L3 战斗动画）。
