## 一、七区配色（权威表）

配色**写进资产材质本体**（`Assets/_Project/Art/3D/*/Mats/*.mat`），不是运行时滤镜；建造目录 UI 同口径。

| 区 | 覆盖 building.category | 材质基色（sRGB，已降饱和） | 说明 |
|---|---|---|---|
| 工业 | industry / industrial / utility | 灰黑 | 厂房、矿场、电厂、水污设施 |
| 学院 | science | 蓝 | 大学、研究所、军校、实验室 |
| 商业 | commerce / tourism | 黄 | 商业中心、银行、商场、酒店、物流 |
| 文化 | culture / entertainment | 紫 | 博物馆、剧院、影院、娱乐；**红灯区后续单独做彩色** |
| 农业 | agriculture | 绿 | 农田、牧场、渔场、粮油加工 |
| 军事 | military / defense | 红 | 兵营、军工厂、城防、雷达 |
| 市政 | administration / medical | 白 | 市政府、警局、医院、公共设施 |
| **居民** | residential | **暖砂**（与市政纯白区分） | 居民区归市政区；为避免全城灰白，住宅单用暖砂色 |

- **饱和度统一 ×0.55**（2026-11-26 院长「降档」）。
- 只染**墙体/屋顶**类材质（stone_light/stone_white/stone_dark/grey_panel/plaster_warm/concrete/steel/brick_red/white_sign/roof_metal/roof_slate/roof_edge）。
- **玻璃、绿化、招牌、金色装饰保持原色**——避免把幕墙/树木/徽记一并染色。

## 二、建筑细节 pass（2026-11-26）

`tools/blender/buildings_v1.py` 的 `detail_dressing(bid)` 在每座建筑生成后自动补：

1. **侧/背立面横向玻璃带**（±X 面与 +Y 面；-Y 正面不动，避免盖住橱窗与招牌）；
2. **屋顶设备**：1~3 个空调机组（金属）、高塔排风管；
3. **大屋顶检修房**（w×d>140㎡）+ 门。

口径：主楼体=尺寸 ≥5×5m 且高 ≥4.5m 的轴对齐网格体；斜屋顶/旋转体跳过。
149 座已于 2026-11-26 全量重生成并重导入 Unity（149/149、problems=0）。

## 三、样板城密度与街道表现（评审用）

- 样板城按 `map.json` 可建连通块自动铺满：**2×2 街墙 + CBD 3×2/4×2/3×3 大体量**；
- **1×1 小件补缝 28%**；城内草地块→公园树丛；沿街行道树 + 路边车 + 铺装/路缘；
- 区块判定：主导地形 ∈ urban/residential/industry，填充率 ≥0.6，面积 ≥12 格；
- 2026-11-26 样板城：36 街区 / 347 座。

**已知限制**：2×2 地块自带庭院/退线（小区 3 板楼、商业中心留内院），城市尺度仍偏稀疏；下一轮为**地块 massing 重构**（沿街贴线/压缩内院/提高填充率），不是配色问题。

## 四、管线与纪律

完整步骤见全量仓 `tools/blender/README.md`，关键纪律：

1. **顺序**：建模 → FBX 导出 → catalog 统计 → Unity `Art3DImport` 重导入 → **`tint_buildings.py` 重刷区色**；
2. **导入会重写 `.mat` 颜色**，所以区色必须是管线最后一步，不能只改一次就以为永久生效；
3. `catalog.json` 是资产事实源（tris/meshes/bbox），重导后必须补统计；
4. `tmp/blender/` 是过程目录，可复现副本已归档 `tools/blender/`。
