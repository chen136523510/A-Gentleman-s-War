## 二、v1 诊断：为什么“头上丑”

1. **一整块光滑曲面**：没有脊线、分缝、檐口、收边——像一块蓝色雨布/肥皂。
2. **体量过大**：44×21.5m，几乎盖住整个建筑，立面只剩 2 层可见；屋顶成了唯一主角。
3. **没有端部收头**：翼尖只是网格边缘，没有金属收边/结构表达。
4. **没有峰值/天际线**：55° 看是一个蓝色椭圆，缺少政府建筑的庄重感。
5. **材质单一**：深蓝金属 + 程序化条纹，读起来像瓦楞铁皮，不像屋面板。

## 四、三个屋顶方案（同一 body）

### 方案 A：中央塔冠 + 平顶（推荐）

- **做法**：删掉翼形屋顶和翼下柱；主楼改**平顶 + 1.2m 女儿墙 + 1.0m 出挑檐口**（檐口板 0.35m 厚，深色滴水线）。
- **中央塔**：8×8m，屋顶以上 **13m**，中心后移 2m；石材竖缝 + 玻璃竖槽；顶部 **5m 阶梯式塔冠**（深金属）+ 金色顶饰；南面 26m 高处放金色徽标/时钟。
- **两侧附楼**：平顶 + 1.0m 女儿墙；屋顶加 2 个 AHU 设备箱（2×1.5×1m）+ 细栏杆。
- **入口**：把现有雨棚升级为 **3m 深、16m 宽石柱廊**（4 根 0.5m 柱）+ 0.8m 檐部；保留“市政府”金标。
- **参考**：东京都厅（塔冠）、Cities: Skylines 市政厅（钟塔）、中国市政楼（对称+门廊）。
- **优点**：峰值明确、庄重、立面可见；屋顶被塔/女儿墙/设备打碎。**缺点**：较通用（符合“建筑不做差异化”）。

### 方案 B：三段式坡屋顶（庄重备选）

- **中央主体**：20×16m，墙到 17.5m；**四坡屋顶**，脊高 21m，檐口 17.5m，出挑 1.2m。
- **两翼**：10×14m，墙到 13.5m；四坡屋顶，脊高 16m，出挑 1.0m。
- **中央脊上**：3×3m 采光亭/钟亭，1.8m 高 + 金色顶饰。
- **材质**：深蓝灰金属屋面（立边咬合）、浅色脊瓦/檐口、暖色檐下。
- **参考**：三国志12（坡面受光/脊线）、Anno 1800（三分式）。
- **优点**：三国志12 式可读性、坡面受光、脊线清楚。**缺点**：可能偏传统，需用金属/细檐口保持现代感。

### 方案 C：折板翼形 + 脊线/分缝（最小改动）

- **缩体量**：40×19m（原 44×21.5），厚 0.7m，抬高 0.6m，出挑 2.5m；翼尖更窄（半宽 2.8m）、上翘 +5.5m。
- **加结构**：中央脊梁 0.5×0.4m；横向肋每 2.5m（0.12×0.1m，随屋面曲率）；周边檐口 0.45m；暖色檐下。
- **分三段**：x=±11m 做 0.2m 凹缝；端部收头 1.5×0.8×0.6m 浅金属。
- **材质**：去程序化条纹，改几何分缝 + 金属板。
- **优点**：保留院长已认可的翼形，改动最小。**缺点**：屋顶仍大，政府感不如 A/B。

## 七、验收标准（基础版）

- **轮廓**：55°/60° 下屋顶有明确**脊线/峰值/收边**，不再是一整块光滑面。
- **立面**：至少 3 层玻璃/横带可见，不被屋顶完全遮住。
- **结构**：屋顶有支撑/檐口/檐下/设备，逻辑自洽。
- **比例**：3×3=60×60m；建筑高度 ≤ 35m（A 塔冠最高）；挑檐不超出 footprint 2.5m。
- **面数**：单方案 ≤ 25k tris；材质 ≤ 20；无破面/穿插。
- **网页**：三个 JSON 都能在查看器加载，旋转无破面；对比页可切换。
- **文档**：登记表 + 工作流 §九 + handoff 更新。
