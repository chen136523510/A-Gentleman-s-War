# L2/L3 界面美术方向开题 — 2026-11-28

> 状态：**v0.1 开题（待院长裁方向）** · 触发：院长令"L2/L3 游戏主题界面美术设计，尤其地图不和谐，多开拓视野参考已有游戏"
> 调研来源：8 个参考作品+通用理论拆解（一手来源为主，详见 §五来源）；AI 友好摘要：根因 5 条 / 方向 3 个 / 推荐 C / 落地 5 步 / 全部调校不重做。

## 一、和谐问题诊断（5 根因）

| # | 根因 | 现状证据 | 参照解法 |
|---|---|---|---|
| 1 | **隐喻断裂**：L1 是手绘漆木"图"，L2 是写实卫星"照片"，两层视觉隐喻并存无过渡 | L1 漆木大地图 → 点进 L2 变航拍照片 | 文明6：全游戏只锚定一个隐喻（古地图），所有资产为它服务 |
| 2 | **三层色板不同带**：卫星底图航拍色温 / 建筑 ×0.55 降饱和 / 深棕金 UI，三者饱和度与色温未收进同一带 | 远景看建筑像照片上摆积木 | 纪元1800：全部资产锁同一条饱和度/明度带 |
| 3 | **光照语言未统一**：L2"轻雾+暖光"是氛围参数，未与底图烘焙时的光照方向/色温对齐 | 建筑接地阴影弱、底图无光向概念 | 全战三国/CS：先定全图单一光照方向+色温 |
| 4 | **UI 与场景材质不同源**：漆木母题只活在 UI，3D 场景零回声 | 深棕金古风框体罩在现代卫星城上 | 冰汽时代/HighFleet：现代内容+文化滤镜成立，前提是场景沾染该文化的光与色 |
| 5 | **信息层未分离**：格线/分区色直接画死在底图里（烘焙的城市肌理），与写实互斥 | 街区灰色铺装板突兀 | CS：真实层与信息层分离，信息层半透明独立绘制 |

铁律（多源交叉）：**一致性 > 单件质量**——三国志14 用统一水墨撑住塑料感建模；三国志12 是反面教材（页游风=UI 与地图材质脱节+饱和度失控），L3 仿 12 只取"斜俯视+分区框体"的信息布局，配色必须重定。

## 二、三个可选方向（院长裁）

| 方向 | 内容 | 优点 | 代价 |
|---|---|---|---|
| **A. RTK12 式战略地图化** | L2 抽象化为斜俯视战略图：地形手绘化、建筑图标化、UI 主导；L1/L2/L3 同一"图"语言 | 与 L1 最和谐、三层一步到位 | 推翻 149 座写实 prefab，与"现代城市经营"卖点冲突，观感棋盘化 |
| **B. 全战三国式统一写实化** | 保留 L2 写实，反向拉齐 L1 写实化+全链写实光效 | 气质最"现代经营"，上限高 | L1 重做成本高、逐城调底图、后处理管线要求最高 |
| **C. 风格化统一（推荐）** | 确立唯一隐喻"**漆木屏风上的现代疆域**"：L2 底图烘焙加统一 LUT/色温映射（卫星色拉进漆木暖带）、信息层从底图分离成半透明层、雾化地平线、锁定饱和度带；UI 母题（漆色/暖金/印章色块）以细节回声进 3D 场景；L3 按同一隐喻起规范 | 全部在现有资产上**调校而非重做**；与现有漆木 HUD 完全兼容；L3 零沉没成本 | 低~中（管线后处理+校准迭代数轮）；风险=调校不到位仍显分裂，需 style guide 硬约束 |

## 三、方向 C 落地路线（裁 C 后执行）

1. **Style guide 先行（黑机 1 文档）**：定色板（地形 ramp/建筑七区带/UI token 对齐）、单一光向与色温、饱和度/明度带上下限——写成硬约束文档，所有产出对表验收
2. **底图烘焙后处理（tools/l2planner + bake_art.py）**：烘焙管线加 LUT/色温映射步，卫星底图拉进漆木暖带；信息层（城市肌理/分区色/格线）从底图剥离，运行时半透明叠加
3. **建筑色板收敛**：149 座七区配色在 0.55 降饱和基础上按新色带校准（重生成批次，管线现成）
4. **L2 氛围对齐**：雾色/环境光/光向与底图 LUT 同源（参数进 style guide，L2CityView 引用）
5. **L3 风格规范起步**：战斗地图按"漆木屏风上的现代疆域"隐喻定 UI 框体/单位标记/地形绘制规范（M1 开工前落，避免返工）
