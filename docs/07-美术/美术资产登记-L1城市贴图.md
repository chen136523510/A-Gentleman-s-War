## 六、R24i 城名字标（统一行楷，Resources）

- 用途：L1 地图城名 + 左下城市面板头部。Unity 运行时 `Image.color` 乘阵营色：CN 红 `#C0392B` / JP 黄 `#E8C547` / KR 白 `#F0F0F0` / AU 蓝 `#3D8FD1` / NONE 灰 `#9AA0A6`；**字体始终行楷**，阵营变更只换色

- 授权：华文行楷是 Windows/Office 字体，**非开源**；本仓只随包栅格化 PNG，不随包分发字体文件，玩家无需安装。公开/商用分发建议改用 OFL 行楷（霞鹜文楷/马善政楷书）重跑脚本
