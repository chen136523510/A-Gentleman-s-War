## 维护纪律（从主仓继承）

- changelog：`06-设计/changelog.md` 倒序，快速索引表 + 固定字段正文（日期/轮次/类型/一句话）
- 文件移动必须同步引用；目录名自解释；先查后建
- 迁移自主仓的文档内相对链接可能仍指主仓路径，**渐进修复**（见 04-技术笔记/迁移清单）
- **参数纪律（2026-11-05 院长令）**：任何公式的任何常数必须在 [08-百科/索引-参数.md](./08-百科/索引-参数.md) 有参数ID + 基础数值出处；新裁定同步更新百科词条+参数表+决策索引
